# fofa-guanshi —— 佛法观世系列文章生成

本 Skill 用于在「大乘百法明门论」学习项目中，把一次「世俗来源 + 唯识/佛法反思」的讨论，整理成一篇「佛法观世」系列文章。

「佛法观世」是项目的一个文章系列：**用唯识 / 佛法框架，重看一个世俗现象**（经济、社会、科技、人事……）。系列物理位置 `notes/佛法观世/`，在 `notes/专题索引.md` §五·二 登记。

**范例**：[经济租与种子现行](../../../notes/佛法观世/经济租与种子现行.md) —— 系列第一篇，本 skill 即由整理它的流程提炼而成。

## 何时触发

- **显式**：用户输入 `/fofa-guanshi`。
- **意图**：用户带来一份世俗材料（读到的文章 / 书 / 新闻 / 一段生活见闻），表达了从唯识·佛法角度的反思，并希望把它整理成文章 / 新记录。

**不要**仅因为对话里出现了佛法话题就触发——本 skill 针对的是"世俗现象 × 佛法视角 → 成文"这一特定动作。

## 本 skill 的方法论核心

模板只是容器。真正的价值在**讨论的纪律**——尤其"非奉承式校准"。学习者慧根利、善建假说，假说网络容易内部自洽到"新材料被动印证而非主动挑战"。本 skill 存在的意义，是保证每一篇佛法观世文章都经过真正的摩擦检验，而不是把用户的想法换成佛学词汇复述一遍。

## 核心流程（五阶段）

### 阶段 0 — 定位

确认三件事：
1. **世俗来源**是什么（文章 / 书 / 视频 / 新闻 / 生活见闻）。
2. 用户的**初始佛法 / 唯识想法**是什么。
3. 这是否真要**成文**（而非闲谈）。

若来源是**付费 / 版权内容**：记下——现象段只能概述、不可复制原文。

### 阶段 1 — 讨论驱动（核心，不可跳过）

> 例外：若讨论已在本对话中充分展开、且用户已明确认可结论，可直接进入阶段 2。

- **讨论先行**：CLAUDE.md 笔记更新规则——讨论完成并经用户确认后才写笔记，讨论中不写入。讨论中可提出写法建议。
- 用唯识 / 佛法框架展开用户的想法。
- **非奉承式校准**（本 skill 方法论核心）——不要顺着用户一路点头，每轮主动做三件事：
  - **找摩擦点**：过强的全称判断（"所有……都……"）→ 给出严格成立的读法 + 守住**边界**（哪些情形不在其内）。
  - **找经典挑战处**：用户的映射 / 推论是否有经典立场与之龃龉？主动找，不只找印证。
  - **找理由需更换处**：用户的结论可能对，但所给理由不准——换成更准的机制。
- **学术诚实三层区分**（边讨论边标，不事后补）：
  - 第一层 = 经典引用；第二层 = 经典框架的应用映射；第三层 = 自主推论。
- **经典 > 假说**：遇假说与经典冲突，信经典。
- 多轮往返，直到用户明确说定稿 / "直接写"。

### 阶段 2 — 经典核对（写入前，凡含第一层内容）

- 第一层经典内容（经名、品名、术语清单、教法归属）写入前，用 WebSearch 核对。
- 核不准的：**不编造出处**。改为标注"出处待核"，或不写硬清单、只陈述原则与说法对象。

### 阶段 3 — 用户确认后写入

- 文件：`notes/佛法观世/<中文标题>.md`，标题简洁。
- 套用下方**文章模板**。
- 三层标注逐处落实。
- **纯中文，无英文词**（项目规则；术语用中文 / 中译，避免英文与梵文转写）。

### 阶段 4 — 配套登记

- **concept-card**：运行 concept-card skill 扫描新文，新概念建卡、首次出现加链。
- **专题索引**：在 `notes/专题索引.md` §五·二（佛法观世系列）登记一条——标题 / 触发 / 核心内容 / 关联假说 / 状态；视情况加入 §六 横向索引。
- **回填清单**：文中若出现跨阶段的"待回填"，在 CLAUDE.md 跨阶段回填清单加条目；阶段内待办留在文中即可。

## 文章模板

```
# <标题>——<副标题>

> **类别**：佛法观世（唯识看世俗现象系列）· 第 N 篇
> **创建日期**：YYYY-MM-DD
> **起点**：<触发的世俗来源 + 反思，一句话>
> **性质**：三段结构（现象 → 分析 → 应用与感悟）+ 经典印证、学术诚实、关联三节为支撑；三层占比简述

---

## 一、现象
对世俗来源的概述（非佛法内容；版权来源只概述、不复制原文）。

## 二、分析
用唯识 / 佛法框架重看（2.1 / 2.2 …，逐节；每节标第一 / 二 / 三层）。

## 三、应用与感悟
修行态度的落点（通常全属第三层；务必落到实修，不止于智识）。

## 四、经典印证
第一层。佛典里的相关教法与故事，与二、三节相互印证。
末设"关键发现"小节——核对经典是否**锐化或挑战**了前面的分析。
（标准节；若该主题经典材料确实稀少，可缩短，但不省略核对动作。）

## 五、学术诚实：三层区分
表格：第一层（经典引用）/ 第二层（框架映射）/ 第三层（自主推论）。

## 六、关联与待深入
关联文档 + 待深入。
```

- **N**（第几篇）：看 `notes/专题索引.md` §五·二 现有条目数 + 1。
- 文末附一行系列说明，注明三段结构与三层标注。

## 重要约束

1. **讨论先行，确认后写**——CLAUDE.md 笔记更新规则。
2. **学术诚实三层**——逐处标注，讨论时同步标，不事后补。
3. **经典 > 假说**——引用项目已有假说时标明其第三层属性；冲突时信经典。
4. **纯中文无英文**——notes 下的 .md 笔记须纯中文散文。
5. **第一层出处先核对**——核不准不编造，宁可 hedge。
6. **配套不可省**——concept-card 必扫、专题索引 必登记。

## 与其他 skill / 文档的关系

- 调用 **concept-card** skill 完成概念卡层。
- 登记入口为 `notes/专题索引.md`（§五·二）。
- 遵循 `CLAUDE.md` 的笔记更新规则、学术诚实原则、回填触发机制——本 skill 不引入新规则，只为"世俗现象 × 佛法视角 → 成文"这一动作提供固定流程。
