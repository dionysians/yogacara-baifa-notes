# 实修日志管理与对话

## 触发条件

- 用户输入 `/shixiu`
- 用户带来实修数据（如"记录今天实修"、"今天坐了 XX 分钟"）
- 用户想讨论实修状态（如"看看最近实修情况"）

## 启动时必读文件

每次触发本 skill 时，先读取以下文件建立上下文：

1. `notes/实修/实修反馈日志.md`（主日志——演化追踪表 + 监测原则 + 近期条目）
2. `notes/实修/当前修行内容.md`（当前修行计划 + 三轨结构）
3. `CLAUDE.md` 中的以下章节（不需全文）：
   - "修行者基础状况"（路径风险 / 应对原则 / 操作核 / 当前核心缺口）
   - "当前修行阶段状态"（三层状态表）

按需追加读取：
- `notes/教学操作核/教学操作核-04-轻安anchor.md`（坐中体验相关）
- `notes/教学操作核/教学操作核-05-不放逸.md`（触发点 / 连续性相关）
- `notes/教学操作核/教学操作核-06-行舍.md`（三相监测 / 征兆标的分判）
- `notes/实修/logs/历史/`（需深度追溯时读月归档）

## 模式 1 · 记录（用户带来实修数据时）

### 步骤

1. **读取当前状态**（见上方必读文件）

2. **基于监测原则追问**（按需，不每次全问）
   - 真定 vs 惛沉："那段时间是否还在守所缘？"
   - 三个不要：是否出现提速 / 固化 / 兴奋倾向？
   - 连续天数：中断了？原因？
   - 触发点：是否生效？
   - 出座原因 / 方式（若未报告）

3. **格式化精简条目**（写入主日志）

   模板（20—30 行）：
   ```markdown
   ## YYYY-MM-DD [时段]：[一句话主信号]

   **时段** HH:MM—HH:MM（N 分钟）/ **所缘** XX / **坐姿** XX

   ### 数据
   - [2—5 条主数据]

   ### 关键判读
   [1—2 段最重要的信号或风险解读。推论处显式标"推论"。]

   ### 当前定位（仅变项）
   - [只列与上次相比的变化]

   → 完整记录：[YYYY-MM 月归档](logs/历史/YYYY-MM-实修反馈.md)
   ```

4. **写入完整条目到月归档**
   - 路径：`notes/实修/logs/历史/YYYY-MM-实修反馈.md`
   - 完整条目包含：详细分析 / 框架映射 / 监测原则对照 / 学术诚实标注
   - 月归档不存在时创建（加标准头）

5. **更新演化追踪表**
   - 在主日志顶部更新各 series 最新数据点
   - 只加数据点，不加解读

6. **检查 14 天窗口**
   - 若主日志有超过 14 天的精简条目，从主日志移除（完整版已在月归档）

## 模式 2 · 对话（用户想讨论实修状态时）

### 步骤

1. **加载上下文**（见上方必读文件 + 按需文件）

2. **分析近期趋势**
   - 连续天数 + 中断模式
   - 关键现量信号演化（暗静对治链、五识收摄、酸胀阈值）
   - 与前期对比（月归档提供历史基线）

3. **路径风险扫描**（基于 CLAUDE.md 修行者画像）
   - 风险 #1 干慧：禅定主轨是否推进？
   - 风险 #2 想通≠跃迁：近期"想通"后有无事件层验证？
   - 风险 #4 闻思快奖励：是否出现实修慢节奏隐性厌恶？
   - 连续性中断：触发点是否失效？中断有无结构性原因？

4. **连接操作核**（按场景）
   - 坐中体验 → 轻安锚操作核
   - 触发 / 连续性 → 不放逸操作核
   - 境界追求 / 征兆标的 → 行舍操作核
   - 嗔 / 自责 → 嗔事件层操作核

5. **结构化反馈**
   - 连接修行者应对原则（盯频率不盯时长 / 盯心所配置不盯用力 / 完成动作即通行证）
   - 建议下一步（若有）
   - 避免过度分析——该修行者倾向精简检验

## 关键原则（贯穿两个模式）

### 项目规则
- **笔记不出现英文**（项目规则，文件路径 / CLAUDE.md 等结构性引用除外）
- **不默认添加"修行者相劫持监测"**（已确认低风险，重复 = 噪音）
- **学术诚实三层标注**：主日志全局声明 + 推论处标签；月归档完整标注

### 修行学原则
- **遵循三步循环**（看破→熏种→常态）：任何修行命题设计时遵循
- **单一现量检验**：该修行者倾向精简检验，避免多维监测
- **经典 > 假说**：引用假说时标第三层
- **盯频率不盯时长，盯心所配置不盯用力**
- **退转 = 正常，不是失败**
- **标的 ≠ 征兆**（行舍正直一相）：不追体验深度 / 速度 / 时长
- **主动暂停优于反向熏种**：散乱厚重时主动起座调整

### 记录原则
- **只记修行者报告的**——不编造未报告的体验
- **变项优先**——当前定位只列与上次相比的变化
- **不重复稳定项**——B / C 轨无变化时不列

## 文件结构

```
notes/实修/
├─ 实修反馈日志.md         ← 主日志（瘦）：演化追踪表 + 监测原则 + 近 14 天精简条目
├─ 当前修行内容.md          ← 修行计划（三轨结构 / 具体安排）
├─ 修行者画像.md            ← 稳定参考（基本情况 / 早年经历 / 定力底子）
├─ 修行全景框架.md          ← 框架（罕变）
├─ 心所专修/                ← 路径文档（信的修习路径 等）
└─ logs/历史/
    ├─ 2026-04-实修反馈.md  ← 月归档（完整条目）
    ├─ 2026-05-实修反馈.md
    └─ ...（按月自然增长）
```

## 归档规则摘要

| 项 | 规则 |
|---|---|
| **主日志保留窗口** | 近 14 天 |
| **完整条目去向** | 当月月归档 |
| **归档时机** | 每次新条目写入时检查；超 14 天的精简条目从主日志移除 |
| **月归档排序** | 最新在前 |
| **学术诚实** | 主日志 = 全局声明 + 推论标签；月归档 = 各条目完整标注 |
| **月归档创建** | 首次该月有条目时创建，加标准头 |
