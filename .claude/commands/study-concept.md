# 创建概念笔记 - Study Concept

为学习中的重要概念创建结构化笔记。

## 使用方法

```
/study-concept <概念名称>
```

**示例**:
```
/study-concept 触
/study-concept 眼识
/study-concept 末那识
```

---

## 功能说明

这个命令帮助你：
1. 为每个重要概念创建标准化笔记
2. 使用统一的模板确保完整性
3. 建立概念之间的关联
4. 方便后续复习和查找

---

## 执行步骤

### 1. 检查参数

如果用户没有提供概念名称：
```
❌ 请提供概念名称

使用方法:
/study-concept <概念名称>

示例:
/study-concept 触
/study-concept 眼识
```

### 2. 确定概念分类

引导用户选择概念所属的类别：

```
📚 概念分类

"{概念名称}" 属于百法中的哪一类？

1. 心法 (8法) - 八识
2. 心所法 (51法) - 心理作用
   2.1 遍行心所 (5)
   2.2 别境心所 (5)
   2.3 善心所 (11)
   2.4 烦恼心所 (6)
   2.5 随烦恼心所 (20)
   2.6 不定心所 (4)
3. 色法 (11法) - 物质现象
4. 心不相应行法 (24法)
5. 无为法 (6法)

请选择类别 (输入编号，如: 1 或 2.1):
→ {user input}
```

### 3. 收集基本信息

#### 问题1：原文引用
```
📖 原文引用

《大乘百法明门论》或相关注释中关于"{概念名称}"的原文是什么？

(可以直接粘贴，或稍后补充)

→ {user input}
```

#### 问题2：白话解释
```
💬 白话解释

用你自己的话，"{概念名称}"是什么意思？

→ {user input}
```

#### 问题3：核心特征
```
🎯 核心特征

"{概念名称}"有哪些核心特征？(每行一个，至少3个)

示例:
- 是心与境接触的关键
- 属于遍行心所，八识都有
- 是认识过程的第一步

→ {user input}
```

#### 问题4：日常实例
```
🌟 日常实例

能举一个日常生活中体现"{概念名称}"的例子吗？

→ {user input}
```

#### 问题5：相关概念
```
🔗 相关概念

"{概念名称}"与哪些其他概念相关？(用逗号分隔，可选)

示例: 作意, 受, 想, 思

→ {user input}
```

### 4. 确定文件路径

根据分类确定文件保存路径：

```
notes/
├── 01-准备阶段/
├── 02-心法/
│   ├── 眼识.md
│   ├── 耳识.md
│   └── ...
├── 03-心所法/
│   ├── 遍行心所/
│   │   ├── 触.md
│   │   ├── 作意.md
│   │   └── ...
│   ├── 别境心所/
│   ├── 善心所/
│   └── ...
├── 04-色法/
├── 05-心不相应行法/
└── 06-无为法/
```

文件路径格式: `notes/{阶段目录}/{子类目录}/{概念名称}.md`

### 5. 生成概念笔记

使用模板 `.aiwork/templates/concept_note.md` 创建笔记文件，填充用户提供的信息。

**填充规则**:
- `{概念名称}`: 用户输入的概念名称
- `{类别}`: 用户选择的类别
- `{子类}`: 具体的子分类
- `{学习日期}`: 当前日期
- `{引用原文}`: 用户输入的原文
- `{白话解释}`: 用户的解释
- `{核心特征}`: 转换为编号列表
- `{日常实例}`: 至少包含用户提供的一个实例
- `{相关概念}`: 如果提供了，列出来

未填写的部分保留模板占位符，供后续补充。

如果不存在，创建 `notes/concept_index.md`：

如果已存在，在对应分类的表格中添加新行：

```markdown
| {概念名称} | [笔记](./path/to/{概念}.md) | {日期} | ⭐ 初识 |
```

### 7. 建立概念关联

如果用户提供了相关概念，检查这些概念的笔记是否存在：
- 如果存在，在新笔记的"关联笔记"部分添加链接
- 同时在相关概念的笔记中添加反向链接

### 8. 更新当天学习日志

如果今天的学习日志存在 (`notes/logs/{today}_study_log.md`)，在关键概念部分添加：

```markdown
- [{概念名称}](../path/to/{概念}.md) - {白话解释的简短版}
```

---

## 注意事项

1. **自动创建目录**: 根据分类自动创建必要的子目录
2. **文件名规范**: 使用概念的中文名称作为文件名
3. **避免重复**: 如果概念笔记已存在，提示用户是否更新
4. **模板完整性**: 确保所有模板字段都正确填充
5. **关联建立**: 正确建立概念之间的双向链接

## 错误处理

### 概念笔记已存在
```
⚠️ 概念笔记已存在

文件: notes/{路径}/{概念名称}.md

选项:
1. 查看现有笔记
2. 更新现有笔记 (保留已有内容，添加新信息)
3. 覆盖现有笔记 (⚠️ 将丢失原内容)
4. 创建副本 ({概念名称}_v2.md)

选择 (1/2/3/4):
```

### 无效的分类选择
```
❌ 无效的分类选择

请输入有效的分类编号 (1, 2.1, 2.2, ..., 5)

可用分类:
1. 心法
2.1 遍行心所
2.2 别境心所
...
```

## 高级功能

### 批量创建概念笔记

如果用户想一次创建多个概念：

```
/study-concept 触,作意,受,想,思
```

依次为每个概念创建笔记，询问基本信息。

### 从学习日志提取概念

读取今天的学习日志，提取关键概念列表，询问是否为这些概念创建笔记。
