# 每日学习记录 - Study Log

记录每天的学习内容、时长、心得和疑问。

## 使用方法

```
/study-log
```

**无需参数**，交互式引导。

---

## 功能说明

这个命令帮助你：
1. 记录每次学习的内容和时长
2. 跟踪学习进度
3. 记录心得体会和疑问
4. 自动更新学习统计
5. 生成学习日志文件

---

## 执行步骤

### 1. 检查会话状态

读取 `.aiwork/session.yaml`，确认是学习类型的会话。

如果不是学习会话，显示错误：
```
❌ 此命令仅用于学习类型的会话

当前会话类型: {type}

请先初始化学习会话。
```

### 2. 获取学习信息

引导用户输入以下信息：

#### 问题1：学习日期
```
📅 学习日期

默认：今天 (2025-11-03)

如果是补记之前的学习，请输入日期 (YYYY-MM-DD)：
→ {user input or default}
```

#### 问题2：学习阶段
```
📚 学习阶段

当前项目的学习阶段：
1. 阶段一：准备与概览
2. 阶段二：心法（8法）
3. 阶段三：心所法（51法）
4. 阶段四：色法（11法）
5. 阶段五：心不相应行法（24法）
6. 阶段六：无为法（6法）
7. 阶段七：整合与深化

请选择今天的学习阶段 (1-7)：
→ {user input}
```

#### 问题3：具体学习内容
```
📖 学习内容

今天具体学习了什么？(可以多行输入)

例如：
- 学习了八识中的前五识
- 阅读了《百法明门论》第一段
- 复习了遍行心所的五个概念

→ {user input}
```

#### 问题4：学习时长
```
⏱️ 学习时长

今天学习了多长时间？(分钟)

例如：60 (表示1小时)

→ {user input}
```

#### 问题5：学习心得
```
💭 学习心得

今天有什么收获或感悟？(可选，按回车跳过)

例如：
- 理解了"触"心所是心与境接触的关键
- 发现日常生活中的很多情绪都可以用心所法解释

→ {user input}
```

#### 问题6：疑问记录
```
🤔 疑难问题

今天遇到了什么不理解的问题？(可选，按回车跳过)

例如：
- 末那识的"恒审思量"具体是什么意思？
- 无表色和有表色的区别还不太清楚

→ {user input}
```

#### 问题7：关键概念
```
🔑 关键概念

今天学到的关键概念或术语 (用逗号分隔，可选)

例如：前五识, 意识, 触, 作意, 受

→ {user input}
```

```markdown
> **学习阶段**: {阶段名称}
> **学习时长**: {时长}分钟 ({小时}小时)
> **日期**: {YYYY-MM-DD}

---

## 📖 学习内容

{学习内容}

---

## 💭 学习心得

{心得体会}

{如果为空，显示：_今日无特别心得记录_}

---

## 🤔 疑难问题

{疑问列表}

{如果为空，显示：_今日无疑问记录_}

---

{概念列表，每个概念一个 bullet point}

{如果为空，显示：_今日无关键概念记录_}

{可以让用户输入，或留空待填写}

_记录时间: {timestamp}_
```

### 4. 更新会话文件

更新 `.aiwork/session.yaml` 中的学习统计：

```yaml
# 在 progress 部分更新
progress:
  started_date: "2025-11-03"
  target_completion: null
  current_phase: "{当前阶段}"
  completion_percentage: {根据学习进度计算}
  last_study_date: "{学习日期}"

# 在 study_log 部分更新
study_log:
  total_sessions: {累加1}
  total_hours: {累加本次时长}
  last_session_date: "{学习日期}"
  last_session_content: "{简短内容摘要}"
```

> **`last_session_content` 写入硬约束（防字段膨胀）**：
> - 只写**最近一场的一句话摘要 + 指针**（建议 ≤ 100 字），如"X 精修（阶段 N/M，时长）；逐场完整摘要见 STUDY_PLAN.md 学习记录表 + notes/logs/"。
> - **覆盖，不串联**——绝不用"｜以下为前次…"把历史场次往前累积。逐场完整摘要由 `STUDY_PLAN.md` 学习记录表 + 每日日志 + `CLAUDE.md` 画像演化表承载，session.yaml 不留全历史。
> - **不新增 `previous_session_content` 键**——YAML 同名键无效（只保留最后一个、其余静默丢弃）。需要历史就查 STUDY_PLAN 表。
> - `stage_history[].update_note` 同理：写阶段状态摘要（进度 + 当前法位 + 指针），不串逐法全文。

### 5. 更新学习计划

更新 `.aiwork/STUDY_PLAN.md` 中的学习记录表：

在 "五、进度跟踪" -> "5.2 学习记录" 表格中添加新行：

```markdown
| {日期} | {学习内容摘要} | {时长}分钟 | [查看日志](../notes/logs/{日期}_study_log.md) | {心得摘要} |
```

> **心得列写入硬约束（防字段膨胀）**：心得列只写**一句话核心产出**（建议 ≤ 80 字、关键词形式，用 `+` / `/` 串联要点）；**不写整段主线全文、不复述笔记内容**。完整内容由"笔记链接"列指向的单日日志 / 单法笔记承载，`CLAUDE.md` 画像演化表另存一份。这是一行索引，不是档案。

### 6. 更新复习跟踪

如果不存在，创建 `.aiwork/review_tracker.yaml`：

```yaml
# 复习跟踪文件
# 基于艾宾浩斯遗忘曲线：1天、2天、4天、7天、15天后复习

reviews:
  - date: "{学习日期}"
    content: "{学习内容摘要}"
    concepts: [{概念列表}]
    review_schedule:
      - day: 1
        due_date: "{日期+1天}"
        completed: false
      - day: 2
        due_date: "{日期+2天}"
        completed: false
      - day: 4
        due_date: "{日期+4天}"
        completed: false
      - day: 7
        due_date: "{日期+7天}"
        completed: false
      - day: 15
        due_date: "{日期+15天}"
        completed: false
```

如果已存在，追加新的复习条目。


---

## 注意事项

1. **自动创建目录**: 如果 `notes/logs/` 目录不存在，自动创建
2. **日期校验**: 确保日期格式正确，不能是未来日期
3. **时长合理性**: 如果时长超过8小时，给出提醒确认
4. **概念提取**: 如果用户没有输入关键概念，尝试从学习内容中自动提取关键词
5. **统计准确性**: 确保累计统计的计算准确无误

---

## 错误处理

### 文件已存在
```
⚠️ 今日学习日志已存在

文件: notes/logs/{日期}_study_log.md

选项:
1. 查看现有日志
2. 追加新内容到现有日志
3. 覆盖现有日志 (⚠️ 将丢失原内容)

选择 (1/2/3):
```

### 会话文件损坏
```
❌ 无法读取会话文件

请检查 .aiwork/session.yaml 是否存在或格式正确。

修复建议:
- 使用 /session-init 重新初始化
- 手动检查 YAML 格式
```
