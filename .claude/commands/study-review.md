# 复习提醒系统 - Study Review

基于艾宾浩斯遗忘曲线的智能复习提醒和管理系统。

## 使用方法

```
/study-review [选项]
```

**选项**:
- 无参数：查看今日待复习内容
- `due`：查看所有到期的复习
- `upcoming`：查看即将到期的复习
- `all`：查看所有复习计划
- `complete <id>`：标记复习完成
- `schedule`：查看复习日历

**示例**:
```
/study-review              # 查看今日待复习
/study-review due          # 查看到期复习
/study-review upcoming     # 查看未来7天的复习
/study-review complete 5   # 标记第5项复习完成
/study-review schedule     # 查看复习日历
```

---

## 功能说明

这个命令帮助你：
1. 基于遗忘曲线自动安排复习
2. 提醒到期的复习内容
3. 跟踪复习完成情况
4. 优化记忆效果

---

## 复习计划规则

基于**艾宾浩斯遗忘曲线**，每个学习内容的复习时间安排：

```
第1次复习：学习后 1天
第2次复习：学习后 2天
第3次复习：学习后 4天
第4次复习：学习后 7天
第5次复习：学习后 15天
第6次复习：学习后 30天 (可选)
第7次复习：学习后 60天 (可选)
```

完成5次复习后，概念被认为已经牢固掌握。

1. 标记当前复习轮次为完成
2. 如果还有后续复习，保持 schedule
3. 如果所有复习完成，标记为 "fully_reviewed"
4. 在概念笔记的"复习记录"表格中添加一行
5. 更新 session.yaml 中的复习统计

**掌握度不足的处理**:
- 如果掌握度 ≤ 2：重置复习计划，从第1次开始
- 如果掌握度 = 3：保持原计划，但标记为需要特别注意

## 复习跟踪文件结构

```yaml
# 复习跟踪文件

last_updated: "2025-11-03"

# 复习规则配置
review_rules:
  intervals: [1, 2, 4, 7, 15, 30, 60]  # 复习间隔（天）
  mastery_threshold: 5  # 达到这个次数认为已掌握
  low_mastery_reset: 2  # 低于此掌握度重置计划

reviews:
```

## 自动化功能

### 1. 学习时自动创建复习计划

当用户通过 `/study-log` 记录学习或 `/study-concept` 创建概念笔记时：
- 自动在 `review_tracker.yaml` 中创建复习条目
- 根据学习日期计算所有复习到期日

### 2. 每日复习提醒

在用户开始会话时，检查是否有到期复习：

```
👋 欢迎回来！

📅 今天是 2025-11-05

{如果有到期复习}
📚 复习提醒:
你有 {count} 项内容待复习（其中 {overdue} 项已超期）

查看详情: /study-review

{如果没有到期复习}
✅ 太好了！今天没有待复习的内容
可以专注于学习新知识

继续学习: /study-log
```

### 3. 智能调整复习计划

根据掌握度自动调整：
- 掌握度高（4-5星）：保持正常计划
- 掌握度中（3星）：下次复习提前1天
- 掌握度低（1-2星）：重置复习计划，或缩短间隔

## 注意事项

1. **时区处理**: 确保日期计算准确
2. **批量操作**: 支持一次标记多个复习完成
3. **数据备份**: 定期备份复习跟踪文件
4. **性能优化**: 对大量复习项进行分页显示
