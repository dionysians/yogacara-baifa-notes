# 开始新阶段 - Study Stage

开始一个新的学习阶段，创建阶段文档和准备工作。

## 使用方法

```
/study-stage <阶段编号>
```

**阶段编号**: 1-7

**示例**:
```
/study-stage 1    # 开始阶段一：准备与概览
/study-stage 2    # 开始阶段二：心法
/study-stage 3    # 开始阶段三：心所法
```

---

## 功能说明

这个命令帮助你：
1. 正式开始一个新的学习阶段
2. 创建阶段专属目录和文件
3. 设置阶段学习目标
4. 准备阶段学习材料

---

## 特殊处理

### 阶段一（准备阶段）

如果开始阶段一，额外创建：
- `texts/` 目录（存放原文）
- `resources/` 目录（存放参考资料）
- 基础文档模板

### 阶段七（整合阶段）

如果开始阶段七，额外：
- 创建整合工作表
- 链接所有前面的阶段
- 准备总结文档框架

---

## 阶段完成

当阶段完成时（通过 `/study-progress update` 标记），自动：

1. 更新阶段状态为 "completed"
2. 设置完成日期
3. 提示填写阶段总结
4. 建议开始下一阶段

---

## 注意事项

1. **顺序学习**: 建议按顺序完成各阶段
2. **灵活调整**: 可以根据实际情况调整阶段内容
3. **充分准备**: 确保前一阶段充分理解后再进入下一阶段
4. **及时记录**: 阶段进行中要及时记录心得和疑问

---

## 错误处理

### 目录已存在
```
⚠️ 阶段目录已存在

目录: notes/{阶段编号}-{阶段名称}/

可能的情况:
1. 该阶段之前已开始
2. 目录结构被手动创建

选项:
1. 查看现有目录
2. 继续使用现有目录（不创建新文件）
3. 清空目录重新开始（⚠️ 会删除现有内容）
4. 创建新版本目录（{阶段名}_v2）

选择 (1-4):
```

### 阶段跳跃过大
```
⚠️ 跳跃学习提醒

你正在开始阶段{N}，但前面的阶段还未完成:

- 阶段{X}: {progress}%
- 阶段{Y}: {progress}%

跳跃学习可能导致:
- 基础不牢固
- 理解困难
- 影响学习效果

建议先完成前面的阶段。

仍要继续？(y/n)
```
