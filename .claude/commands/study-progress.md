# 查看学习进度 - Study Progress

查看和更新学习项目的整体进度。

## 使用方法

```
/study-progress [选项]
```

**选项**:
- 无参数：查看当前进度
- `update`：更新阶段进度
- `stats`：查看详细统计

**示例**:
```
/study-progress          # 查看当前进度
/study-progress update   # 更新进度
/study-progress stats    # 查看统计
```

---

## 功能说明

这个命令帮助你：
1. 可视化查看整体学习进度
2. 更新各阶段的完成状态
3. 查看学习统计数据
4. 生成进度报告

## 进度计算逻辑

### 整体完成度计算

根据各阶段的权重和完成度计算：

```
阶段一：准备与概览 - 权重 5%
阶段二：心法 - 权重 10%
阶段三：心所法 - 权重 35% (最复杂)
阶段四：色法 - 权重 10%
阶段五：心不相应行法 - 权重 20%
阶段六：无为法 - 权重 10%
阶段七：整合与深化 - 权重 10%

总完成度 = Σ(阶段完成度 × 阶段权重)
```

### 阶段完成度计算

可以基于：
- 手动设置的完成度
- 或自动计算：(已完成任务数 / 总任务数) × 100%
- 或混合：结合学习日志数量、概念笔记数量等

## 自动更新机制

以下操作会自动触发进度更新：

1. **创建学习日志** (`/study-log`)
   - 更新总学习次数
   - 更新总学习时长
   - 更新最近学习日期

2. **创建概念笔记** (`/study-concept`)
   - 更新概念笔记数量
   - 可能影响阶段完成度

3. **标记阶段完成**
   - 自动计算新的整体完成度
   - 更新当前阶段

4. **更新概念索引** (`notes/concept_index.md`)
   - 每次执行 `/study-progress` 时，扫描各法笔记的实际掌握度
   - 与 `concept_index.md` 中的记录进行比对
   - 更新不一致的掌握度和状态
   - 更新统计概览中的数字
   - 更新"按掌握度查找"分组

## 进度报告生成

可以生成进度报告文件：`reports/progress_report_{date}.md`

```markdown
# 学习进度报告

**生成日期**: {date}
**报告周期**: {start_date} ~ {end_date}

## 概览

{整体进度可视化}

## 本周期成果

- 学习 {days}天
- 累计 {hours}小时
- 完成 {concepts}个概念
- 撰写 {logs}篇日志

## 阶段进展

{各阶段的详细进展}

## 亮点与成就

{识别出的学习亮点}

## 挑战与改进

{遇到的困难和改进建议}

## 下周期计划

{下一阶段的学习计划}
```

## 注意事项

1. **数据一致性**: 确保从多个文件读取的数据一致
2. **性能优化**: 对于大量文件的统计，使用缓存
3. **错误处理**: 文件不存在或损坏时的处理
4. **可视化**: 使用 ASCII 图表让数据更直观

---

## 错误处理

### 会话文件不存在
```
❌ 找不到会话文件

请先初始化学习会话或检查文件是否存在：
.aiwork/session.yaml
```

### 数据不一致
```
⚠️ 检测到数据不一致

session.yaml 显示总学习次数: {count1}
实际日志文件数量: {count2}

是否重新同步数据？(y/n)
```

如果选择同步，扫描所有日志文件，重新计算统计数据。
