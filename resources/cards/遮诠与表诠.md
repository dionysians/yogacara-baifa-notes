# 遮诠与表诠

**遮诠 / 表诠**是佛教诠释学（教法如何用语言指示事物）的一对基本术语，广见于华严、禅、因明各系统：

- **遮诠 = 遣其所非**：通过否定"它不是什么"来显示——不生不灭、不垢不净、无我、空、非有非无；
- **表诠 = 显其所是**：直接肯定"它是什么"——常、乐、知、觉。

[宗密](宗密.md)《禅源诸诠集都序》的定义与例子最直白：

> 「遮谓遣其所非，表谓显其所是。……如说盐，云不淡是遮，云咸是表；说水，云不干是遮，云湿是表。」

## 各系统中的使用

| 系统 | 用法 |
|---|---|
| **般若 / [中观](中观.md)** | 空性教法以遮诠为主干——八不中道（不生不灭、不常不断……）、「无智亦无得」，遮遣一切自性执而不立正面命题 |
| **如来藏 / 涅槃系** | 多用表诠——常乐我净、本觉、「知之一字众妙之门」（宗密以此判禅门深浅） |
| **因明（陈那系）** | 「遮遣他义」（apoha）——词义由排除他者成立（"牛"之义 = 排除一切非牛），是遮诠的知识论深化 |
| **唯识** | 二者并用——说真如「真谓真实显非虚妄，如谓如常表无变易」（遮表各半）；说空用遮、说依他起因果用表 |

→ 一个教法传统的"遮 / 表配比"会塑造学人慧的运作习惯——这是本项目引申用法的经典侧根据。

## 本项目的引申用法：从"诠"到"操作"〔第二层框架映射〕

本项目在懈怠 / 放逸精修（专题《修道点火与遮强表弱》）中把这对词从**语言层**（教法怎么说）引申到**心行操作层**（心怎么用功）：

- **遮性操作** = 否定式用功：看破、斩断、截断、清场（如惭愧瓦解染念、空性斩贪紧迫）；
- **表性操作** = 肯定式用功：正向生起（如升起精进勇悍、生起悲心、生起法喜欲）。

**引申的逻辑**：空性见是遮诠之学，由遮诠教法长期训练出的慧，其熟练操作集中在遮侧——故有修行者"**遮强表弱**"的结构签名（能斩断、升不起）。

**学术诚实标注**：遮诠 / 表诠之分是第一层（经典明文）；"遮性 / 表性操作"及"教法遮表配比 → 训练出操作层遮表强弱"的引申是**第二层框架映射**（经典无"操作遮表"的说法）；"遮强表弱"作为对特定修行者的诊断是**第三层**（自我诊断、不作跨人假说、不入假说表）。
