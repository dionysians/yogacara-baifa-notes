# 增上缘

**增上缘**(梵 *adhipati-pratyaya*)是唯识[四缘](四缘.md)之第四缘——[因缘](因缘.md)、[等无间缘](等无间缘.md)、所缘缘(参见[所缘](所缘.md))、增上缘——指对某法的生起**不起障碍、乃至有助力作用**的一切条件。

增上缘的范围最广——凡是对某果法不起障碍的一切法,都可以是它的增上缘。

## 二分:有力 vs 无力

- **有力增上缘**:对果法有正面助力(如善知识对修行的助益)
- **无力增上缘**:仅不障碍,不积极助力(如背景中无干扰的外境)

## 与[因缘](因缘.md)的辨异

这是初学最易混的一对:

| | [因缘](因缘.md) | 增上缘 |
|---|---|---|
| 与果的关系 | **亲生** | **助生 / 不障碍** |
| 性质 | 直接产果 | 提供条件 |
| 唯识对应 | 种子 | 一切不障碍因素 |

例:过去世善业种子是根本因([因缘](因缘.md)),今世的文化环境、师长教导、个人努力等是增上缘。**种子加增上缘和合,才有现行**。

## 与[所依](所依.md)的部分重叠

[所依](所依.md)中的"俱有依"(心-心所相依、八识相依等)在缘的分类上属增上缘——但不是所有增上缘都是俱有依,增上缘范围更广(还包括外境、辅助条件等)。

## 注意:"增上"≠"增上缘"

"**增上**"在唯识 / 阿毗达磨中是个**多义**修饰语,可单独使用:

- "增上缘"——本卡所论的四缘之一
- "增上依"——等同于俱有依([所依](所依.md)的一种)
- "信增上 / 慧增上"——某心所力量增强、占主导
- "增上义"——具有强化、提升、不障碍的功能

→ 使用时需依上下文确定具体所指,不可一律等同于"增上缘"。

出处:《俱舍论》、《成唯识论》、《瑜伽师地论》。
