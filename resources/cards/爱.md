# 爱

**爱**（梵 *tṛṣṇā*，巴 *taṇhā*）是[十二缘起](十二缘起.md)第八支，即对乐受的初起染著——在唯识体系中与[贪](../../notes/03-心所法/烦恼心所/贪.md)心所同体。

## 在十二缘起中的位置

```
触 → 受 → 【爱】→ 取 → 有 → 生 → 老死
```

爱是**受转为轮回动力的转折点**——受（乐受）本身不生苦，爱（对乐受的染著）才把链条接上[取](取.md)→有→轮回。

## 爱与取的关系

爱 = 初起染著（刚刚抓住）；取 = 染著增长为追逐执取（扩张）。两者是同一贪在两个时点/强度的展开。

## 惑·业·苦三分中的位置

爱与取同属"惑"（烦恼 / 驱动力），与无明并列为十二支中仅有的三个惑支——**无明（根）+ 爱、取（现世转折点）**构成轮回的两个关键节点。

## 与贪心所的关系

《成唯识论》："谓由**爱**力，取蕴生故"——明文将贪心所与十二缘起的爱接通。两者体性相同（染著），爱是贪在十二缘起结构中的名称。
