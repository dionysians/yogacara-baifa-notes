# 见道

**见道**是唯识五位（资粮、加行、通达、修习、究竟）中的第三位（**通达位**），指无漏智首次现前、亲证真如、初登圣位的关键跃迁。声闻乘称"见谛"，大乘称"见道"或"通达位"。

## 见道的核心成就

- **顿断分别二执**：分别我执、分别法执（依邪师邪教邪思惟而起的二执）于此位顿断
- **证真如**：根本智亲证二空真如，进入无漏摄
- **入圣位**：从凡夫位进入圣者位，不退转

## 见道 vs 修道

| | 见道 | 修道 |
|---|---|---|
| 所断 | **分别**二执 | **俱生**二执 |
| 速度 | 顿断 | 渐断（修道至佛地，历三大阿僧祇劫余） |
| 智 | 根本智初现 | 后得智辗转增上，俱生执种子渐除 |
