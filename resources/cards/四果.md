# 四果（阿罗汉）

**四果**，又名**阿罗汉**（梵 arhat / arhant，意译"应供" / "无生" / "杀贼"），是声闻乘四果中的最高果位。证此果者已断尽三界一切见惑、修惑（含三界俱生贪、嗔、慢、不共我痴等），究竟解脱，不再受三界生死。

## 名义

- 梵文 **arhat / arhant**：常释为三义——
  - **应供**：堪受人天供养
  - **无生**：永不再受三界生死
  - **杀贼**：杀尽烦恼贼
- 与四果位次序列对应：[初果](初果.md) 须陀洹 → [二果](二果.md) 斯陀含 → [三果](三果.md) 阿那含 → **四果 阿罗汉**

## 断惑位次

四果断尽**三界全部修惑**——含三界俱生贪、嗔、慢、不共我痴等。

与本项目相关的关键断惑节点：

- **四果断俱生贪**——欲界贪在三果断 / 色无色界俱生贪在四果断（贪通三界俱生）
- **四果断俱生我慢**——欲界俱生我慢在三果断 / 色无色界俱生我慢（B 组纵向慢的禅定境界对比）在四果断
- **四果断不共我痴**——末那相应的恒行不共无明在四果断，这是四果与三果最深的差异
- **嗔已三果断**——嗔不需要等到四果

## 与本项目的关联

- **四果断俱生贪**：[贪.md](../../notes/03-心所法/烦恼心所/贪.md) 引用——贪因有末那我爱底层支持，俱生最深
- **四果断色无色界俱生慢**：[慢.md §四.2](../../notes/03-心所法/烦恼心所/慢.md) 引用——色无色界 B 组纵向慢需四果才彻底断
- **四果断不共我痴**：[痴.md](../../notes/03-心所法/烦恼心所/痴.md) 引用——末那恒行不共无明最深，等待四果
- **慧解脱 vs 俱解脱**：四果阿罗汉分两类——慧解脱（断惑而无四禅八定）与俱解脱（断惑且具四禅八定）。本项目修行者路径偏 [慧解脱](慧解脱.md) 传统
- **大乘视角下的四果**：大乘视阿罗汉为初阶圣果，菩萨道目标超越阿罗汉直至佛果；但阿罗汉断三界烦恼障的位次仍为大乘所承认（《成唯识论》卷十）

## 三果与四果的位次差异概要

| | 三果（阿那含）| 四果（阿罗汉）|
|---|---|---|
| 断惑范围 | 欲界全部修惑 | 三界全部修惑 |
| 嗔 | 已断 | 已断 |
| 慢 | 欲界断 / 色无色界未断 | 全部断 |
| 贪 | 欲界断 / 色无色界未断 | 全部断 |
| 不共我痴 | 未断 | **断** |
| 生死 | 不还欲界（可生色无色）| 究竟解脱 |
