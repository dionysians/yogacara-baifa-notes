# 六散乱

《大乘阿毗达磨杂集论》卷一在散乱条下开列的六种散乱：**自性散乱、外散乱、内散乱、相散乱、粗重散乱、作意散乱**。它不是六个并列的心所，而是"流散"行相在六个不同场域 / 尺度上的分类学——其属义比散乱心所宽（凡"离所修善品"皆计为散）。

## 六种（大意）

| # | 种 | 义 |
|---|---|---|
| 1 | 自性散乱 | 五识身——自性外门转、于内静定无功能（**借名**：结构事实非烦恼，否则善位五识亦在烦恼中） |
| 2 | 外散乱 | 正修善时，心驰散于五欲外境 |
| 3 | 内散乱 | 正修定时，沉、掉、**味著**（味定在分类学中的席位——定内的易缘） |
| 4 | 相散乱 | 为令他归信，矫示修善之相（所缘框架层的偷换：真所缘被换成"被看见的我在修法"） |
| 5 | 粗重散乱 | 依我我所执、我慢品粗重之力，于修善时已生起的体验计我、我所、我慢，间杂取相（六种中最深——把定修体验收编为"我的境界"） |
| 6 | 作意散乱 | （约菩萨说）舍大乘相应作意、退习余乘诸作意（道向层的偷换、尺度最大） |

## 出处与派系说明

出《大乘阿毗达磨杂集论》卷一（文句常以大意转述）。杂集论自身以贪嗔痴三分为散乱之体（集论传立场）；六分法与本体诤议正交，护法"别有自体"立场下照用不误。

## 本项目读法

六散乱 = **"易缘"在六个尺度上的分形**（刹那所缘 → 业处 → 目的框架 → 体验归属 → 道的方向；自性散乱为底层结构常数）——尺度越大、"换"得越慢越不可见，散乱最深的形态恰恰最不像散乱〔第二层整理〕。对治归口分坐中敌（外、内——定门内事务）与道途敌（相归惭愧、粗重归无我观与[末那](末那.md)识破、作意归胜解与信）——单靠修定治不完散乱。详见 [散乱笔记 §四](../../notes/03-心所法/随烦恼心所/散乱.md)。
