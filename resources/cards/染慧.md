# 染慧

**染慧**指被烦恼染污的慧（简择能力）。慧本身通三性（善 / 恶 / 无记），染慧 = 慧 + 无无痴 = 慧的简择功能在场但**见地锚不在场** → 颠倒推度而非如理简择。

## 核心机制

[假说 16](../../notes/假说/假说-16-慧无痴俱起分判.md)：**慧 + 无痴是稳定见的双条件**，缺一则见有问题：

| 条件状态 | 结果 |
|---|---|
| 慧 + 无痴俱起 | 善慧（朝向决了的如理简择）|
| 慧 + 无无痴（缺无痴）| **染慧**（颠倒推度 / "看穿者我相"）|
| 慧缺位 | 疑（见的未稳定态）|

## 染慧的三种稳定度形态

恶见精修揭示染慧不是单一形态，**有三种稳定度**：

| 稳定度 | 形态 | 经典对应 |
|---|---|---|
| 临时染色 | 染慧在临时简择中现行 | "看穿者我相" 等临时染色 |
| 稳定化 | 染慧 + 已稳定 = **恶见** | 五见（身/边/邪/见取/戒禁取）|
| 稳定 + 自抬 | 染慧 + 已稳定 + 自抬 = **增上慢** | 慢精修中识别的特例 |

## 染慧 = 恶见的体性

《[成唯识论](《成唯识论》.md)》卷六：
> 云何恶见？于诸谛理颠倒推度，**染慧为性**。

→ [恶见](../../notes/03-心所法/烦恼心所/恶见.md)（五利使总名）的体性就是**染慧的稳定化形态**。

## 染慧的精巧化命题

恶见精修揭示**慧根利者双面性命题**：

> **染慧 ≠ 智力低**。恰恰相反 — 染慧是"聪明的烦恼"，越聪明的人染慧越精巧。
> **慧根利 = 染慧的精巧化风险 + 善慧的极致潜力 = 结构性双面性**。

→ 这给修行者画像"知识贪 / 见解贪 / 见解嗔 / L4 位置慢复合机制"一个统一的机制层根源 — 全部根植于"染慧的精巧化"。
