# 慧解脱

**慧解脱**(梵 *prajñā-vimukti*)是阿罗汉的一种类型——**以慧为主、定支足以承载即得解脱**,**不另入色界 / 无色界八等至 / 灭尽定的深定位**。与之对的是**俱解脱**——慧 + 深定俱足、并能入灭尽定的阿罗汉。

## 关键厘清:慧解脱 ≠ "无定的解脱"

常见误读:慧解脱者只修慧不修定,纯靠慧得解脱。**这是错的**。

经典立场:

- 慧解脱者**仍需基本定支**(至少未到地定 / 初禅近分)——没有任何定支无法断惑(参见[无想定](无想定.md) vs [灭尽定](灭尽定.md))
- 区别仅在**定支的深度**:俱解脱者深入八等至 + 灭尽定,慧解脱者定支够断惑即止
- **般若是断惑的根据,定是承载;慧解脱者两支都有,只是定不进深位**

→ 慧解脱不是次等解脱——所断烦恼障与俱解脱完全相同(都是阿罗汉),只是不具神通自在(那需要深定)。

## 修行学意义

慧解脱传统是修行者偏定不深、偏慧根利者的经典路径——闻思 + 基础定支即足,不必长期专修甚深禅那。本项目修行学路径(闻思 + 禅定双支撑,禅定为承载、不追求甚深定位)与慧解脱传统结构同构。

出处:《杂阿含经》、《俱舍论》、《瑜伽师地论》。
