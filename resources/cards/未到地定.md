# 未到地定

**未到地定**（又名近分定、未至定）是**初禅根本定之前的近分位**——已离欲界粗散、得身心轻安成就的奢摩他，但尚未入初禅根本定（离生喜乐）。它是欲界定与色界初禅之间的过渡定地。

修行学上的关键意义：**它是断惑发观慧的最低充分定支**。经典立场（《俱舍论》、《杂阿含经》须深经、《菩提道次第广论》）——

- 成就奢摩他（[九住心](九住心.md)圆满 + 身心轻安）即得未到地定，得"作意"。
- **[慧解脱](慧解脱.md)阿罗汉依未到地定（或初禅近分）即可发观慧、断惑证果，不必入四禅八定乃至初禅根本定**。
- 四禅八定的甚深定位是俱解脱、神通所需，非解脱慧所必须。

故对偏慧根、走慧解脱路径者，未到地定 + 身心轻安是定的"够用线"——定够稳到承载观慧穿透即可，不必为深而深。

## 与本项目的关联

未到地定是本项目"定修到什么程度才够用"的经典答案的静态版：修行者偏慧解脱传统，其定的够用线约为**未到地定 + 身心轻安**，不必更深。但 [无我见从比量到现量](../../notes/修行学/无我见从比量到现量.md) §五进一步给出动态版——够用线不是固定刻度，而是"定的火力须持续够得着闻思当前推进到的那一层烦恼的现证"（[止观双运](止观双运.md)的动态相称）。
