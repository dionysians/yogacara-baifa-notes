# 护法

中印度那烂陀寺时期的唯识大论师（约 530-561 CE），是法相唯识宗在印度的核心代表人物之一。其见解通过弟子戒贤、再传弟子玄奘传入中国，构成汉传法相宗（慈恩宗）的根本立场。

## 在唯识传承中的位置

护法是世亲（《唯识三十颂》作者）之后众多注释家中**最权威的一支**：

| 论师 | 时代 | 与护法的关系 |
|---|---|---|
| 世亲 | 4-5 世纪 | 《唯识三十颂》作者，护法所注 |
| 亲胜 / 火辨 / 难陀 / 德慧 | 5-6 世纪 | 各家注释，与护法有立场分歧 |
| **护法** | 6 世纪 | 综合各家 + 自家立场 |
| [安慧](安慧.md) | 6 世纪 | 与护法同时期，立场多有分歧 |
| 玄奘 | 7 世纪 | 把护法立场为主综合各家译为《成唯识论》|

## 主要作品

- 《唯识三十颂释》（玄奘揉译入《成唯识论》主体）
- 《广百论释》
- 《观所缘缘论释》

## 在《成唯识论》中的核心地位

[《成唯识论》](《成唯识论》.md)由玄奘在 659 CE 译出，以**护法为正义**、合糅其他九位论师注释而成。这意味着汉传唯识基本以护法立场为主流，**与护法不同的立场（特别是安慧派）通常被列为"异说"或"小乘见"**。

## 与本项目相关的护法派典型立场

| 议题 | 护法派立场 | 对偶立场 |
|---|---|---|
| 无痴体性 | [别有自性](别有自性.md) | 安慧 / 难陀派：无痴即慧，不别立体 |
| 五种姓说 | 五种姓决定，包括无种姓（一阐提）| 部分大乘：一切众生皆有佛性 |
| 阿赖耶识 | 凡夫位有，圣者位转依 | 部分立场：圣者位仍有 |
| 不放逸 | [无别体](../../notes/03-心所法/善心所/不放逸.md)——即精进三根于所断修事上的防修，假立非实 | 安慧派：别有自性 |
| 行舍 | 无别体——即精进三根令心平等正直无功用住为性 | 部分论师：别有自性 |
| 末那识 | 恒审思量我执（俱生我执） | 部分立场：仅在加行位起 |

## 本项目立场

本项目采用护法派立场作为默认起点，与玄奘 / 《成唯识论》传统一致。遇有分歧（如安慧派立场）时单独说明，不强行收敛。
