# 初果（须陀洹 / 入流 / 预流果）

**初果**，又名**须陀洹**（梵 srotāpanna，意译"预流"或"入流"），是声闻乘四果中的第一果位。证此果者从凡夫位入圣位，进入"圣流"，从此**不退转**，最多七返人天必证四果阿罗汉。

## 名义

- 梵文 **srotāpanna**：srota（流）+ āpanna（入），字面"入流者"
- 玄奘译为"预流"，音译"须陀洹"
- 与四果位次序列对应：**初果 须陀洹** → 二果 斯陀含 → [三果](三果.md) 阿那含 → [四果](四果.md) 阿罗汉

## 断惑位次

初果断除[三结](三结.md)：

| 结 | 内容 |
|---|---|
| 身见（萨迦耶见）| 执五蕴为我的颠倒见 |
| 戒禁取 | 执非因为因 / 执外道戒为解脱因 |
| 疑 | 对四谛 / 三宝 / 业果犹豫不决 |

→ 三结同断 = 现观四谛 → 见稳且正 → 入圣位。这是凡夫位 → 圣位的**关键临界点**。

## 见所断 vs 修所断

初果通过**见道**断除分别起的二执 + 三结。这是"见所断"烦恼的代表性断位——见道时通过现观四谛 / 缘起 / 真如得见稳定，分别疑当下断除。

俱生起的烦恼则要修道渐断（二果 → 三果 → 四果）。

## 初果的关键性质

| 性质 | 内容 |
|---|---|
| **不退转** | 入圣流后绝不退回凡夫位 |
| **七返** | 最多人天往返七次必证阿罗汉 |
| **三恶道不堕** | 已断身见 → 不再造作堕三恶道之业 |
| **疑断** | 对四谛 / 三宝 / 业果不再有犹豫 |
