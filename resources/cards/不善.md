# 不善

**不善**（梵 *akuśala*，即"恶"）是唯识 / 阿毗达磨判一切心、心所、业之道德性质的**三性**（善 / 不善 / 无记）之一。注意：此处"三性"指**善恶无记**，与[三性](三性.md)说之"遍计 / 依他 / 圆成"（三自性）是同名而异指的两套概念。

## 三性（善 / 不善 / 无记）

| 性 | 含义 | 感果 |
|----|------|------|
| **善** | 顺益此世他世 | 感可爱异熟（乐果） |
| **不善（恶）** | 违损此世他世 | 感非可爱异熟（苦果、恶趣） |
| **无记** | 非善非不善 | 不感异熟（不招善恶果） |

## 不善心的精确定义（三判准互印）

1. **业果判准**：能感苦果 / 恶趣（不可爱异熟）。
2. **心所判准（唯识最精确）**：**与无惭无愧相应**的染心。无惭无愧（大不善地法）遍一切不善心，是"不善"这一性的结构性标记。
3. **界地判准**：唯欲界系。上二界（色 / 无色）无不善（无苦受、无嗔），上界烦恼全是有覆无记。

## 无记再分两类

- **有覆无记**：染污（有烦恼相应）、但势力羸劣**不感苦果**，只"覆"障圣道。典型 = [末那](末那.md)恒行的[我痴](我痴.md)我见我慢我爱；上二界被定所伏的贪慢。
- **无覆无记**：非染非善的中性心。如阿赖耶识（异熟）、走路坐卧（威仪）、做手工（工巧）时的中性心。

## 命脉：染心 ⊋ 不善心

> 染污心 = 不善心（感苦果）∪ 有覆无记（染而不造恶）

**不是所有"有烦恼 / 染污"的心都是不善心**。末那那个恒时现行的我执是染的（有覆），却不是不善（不感苦果、无无惭无愧）。一个干净的对照：**嗔**唯欲界、现行必不善（起嗔那刹那一定不善、一定无惭无愧俱）；而末那的"我慢"恒时在，却是有覆无记、没有无惭无愧俱。

## 在本项目中的使用

不善 / 有覆无记 / 无覆无记的分判是学习随烦恼**中随（无惭无愧）**的命脉——无惭无愧"遍一切不善心、不遍有覆无记"，恰好标记染心里"不善那一格"的边界。详见 [无惭无愧合论 §二](../../notes/03-心所法/随烦恼心所/无惭无愧合论.md)。
