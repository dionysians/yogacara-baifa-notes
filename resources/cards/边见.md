# 边见

**边见**（antagrāha-dṛṣṭi）= 边执见，[五利使](五利使.md)之第二，恶见之一。指在 [身见](我执.md) 所立"我"之上随执常或断的偏见 — 障"处中行"（中道）与出离。

## 经典定位

《[成唯识论](《成唯识论》.md)》卷六：
> 二边执见，谓即于彼随执断常。障处中行出离为业。

## 两种边见

| 边见类型 | 内容 | 实例 |
|---|---|---|
| **常见** | 执"我"死后永恒存在 | 灵魂不灭 / 永恒自我 |
| **断见** | 执"我"死后断灭 | 人死灯灭 / 唯物虚无 |

## 结构性特征

- **依身见而立**：必须先立"我"才能对"我"做常 / 断判断 — 身见破 → 边见自动失所缘
- 与佛法**中道**严格对反：中道 = 离常断二边 = 缘起 / 无我 / 非常非断
- 不是"折中"，是**结构性瓦解常断二边的所依（身见）**

## 俱生 vs 分别分布

- **分别边见**：后天哲学 / 宗教所立断 / 常 — 见所断
- **俱生边见**：与生俱来对死后存续的直觉判断 — 修所断（与俱生身见同位次）
