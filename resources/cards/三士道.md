# 三士道

**三士道**是《菩提道次第》（阿底峡《菩提道炬论》→ 宗喀巴《菩提道次第广论》）对修行者按发心高下安立的三层道次第——下士道、中士道、上士道。三者次第递进、下下为上上之基。

本项目主要从**"欲-钩"（修道动力的点火源）总架构**的角度引用它：三士道恰好对应三种递进的"驱动修行的欲"。

## 三士的发心与"欲-钩"

| 士道 | 思维所缘 | 所生的"欲"（动力点火源）|
|---|---|---|
| **下士道** | 念死无常、三恶趣苦、皈依、业果 | **求增上生**（畏恶趣、求人天善趣）——情感逼迫 / 恐惧型动力 |
| **中士道** | 苦谛、集谛、十二缘起、轮回过患 | **求解脱出离**（出离心、saṃvega）——见轮回不安稳而求自证 |
| **上士道** | 知母念恩 / 自他相换 → 大悲 | **求成佛**（菩提心）——为利众生愿成佛 |

→ 下士求自身离苦、中士求自身解脱、上士求一切众生解脱。**欲的所缘逐层扩大、染分逐层减薄**。

## 与精进 / 懈怠的关系

精进的起手需要"欲"作点火钩（信→欲→精进）。三士道即经典对"用什么欲驱动修行"的系统安立——懈怠的治本，不只是策励，更是**找到能点火的那个欲**。对理性派 / 慧解脱型修行者，下士道的情感恐惧型动力（相）易冷、点不着，可直接走中士（求解脱 / 不退）+ 上士（见众生苦 → 悲 → 菩提心）的理路欲-钩。
