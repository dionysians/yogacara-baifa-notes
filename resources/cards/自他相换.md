# 自他相换

**自他相换**是寂天《[入菩萨行论](《入菩萨行论》.md)》第八品（静虑品）所传**生起菩提心的修法**，与[七因果](七因果.md)并列为道次第生菩提心的两大法门。

## 核心次第

```
自他平等（我与他人离苦得乐之愿求平等无别）
   ↓
自他相换（把执爱自己的心，换到执爱他人上）
   ↓
取舍修（取众生苦、舍自己乐）
```

寂天的论证锋利处：执爱"我"是一切苦的根，执爱"他"是一切乐的根——故应把"我爱"换成"他爱"。它直接对治萨迦耶见（我爱），故又是末那对治的深法。

## 与本项目的接点

自他相换是"见众生苦 → 悲 → 利他欲"这条欲-钩的另一条经典路径，并与本项目"破实我中心"一把钥匙（慢 / 嫉 / 憍 / 害报复型同收）同源——它把利他动力与无我见接通。属道次第 / 菩萨道经典、不在《百法》范畴，系统修学待相应阶段。
