# 七因果

**七因果**（七因果教授）是《菩提道次第》中**生起菩提心的两大修法之一**（另一为[自他相换](自他相换.md)），传承自阿底峡。以"知母"为起点，经七重因果次第引生菩提心。

## 七重次第

```
① 知母（一切众生皆曾为我母）
② 念恩（忆念母恩深重）
③ 报恩（生起欲报恩之心）
④ 悦意慈（视众生如独子般可爱）
⑤ 大悲（不忍众生受苦、愿拔其苦）
⑥ 增上意乐（"我来荷担"的承当心）
⑦ 菩提心（为利众生愿成佛）
```

前六为因、菩提心为果。其中**⑤大悲是枢纽**——大悲生则菩提心可成。

## 与本项目的接点

七因果是把"见众生苦 → 大悲 → 利他欲（菩提心）"系统化的经典修法，即修行者"见众生苦生冷悲"这条欲-钩的**经典具体路径**。但它属道次第 / 菩萨道经典、不在《百法》范畴，系统修学待相应经典阶段（与利他善巧轴回填触发一致）。现阶段先用"见众生苦 → 冷悲（认知路径）"起头。
