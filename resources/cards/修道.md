# 修道

**修道**(梵 *bhāvanā-mārga*)是大乘菩萨五位中第四位,亦是声闻四位中介于[见道](见道.md)与无学(阿罗汉)之间的修习阶段。**渐次断除俱生烦恼**——见道顿断的是分别起烦恼,修道则要长时熏修对治俱生起烦恼(无始任运而起的微细烦恼)。

## 与[见道](见道.md)的对比

| | [见道](见道.md) | 修道 |
|---|---|---|
| 性质 | 根本无分别智一念现前 | 长时反复熏修 |
| 所断 | 分别我执 / 分别法执(粗、起于邪教邪思惟) | 俱生我执 / 俱生法执(微细、任运而起) |
| 时长 | 一念顿超 | 极长(声闻数生 / 菩萨二大阿僧祇劫) |
| 圣位 | 入圣 | 修圣 |

## 断惑次第

- **见道**——断分别二执(顿)
- **修道**——断俱生二执(渐)
  - 俱生[我执](我执.md)断尽 → 声闻阿罗汉 / 菩萨八地
  - 俱生[法执](法执.md)究竟断 → **唯佛地**

→ 修道的长时性,是修行者把"看破"(见道)沉为"常态"(任运)的承载阶段——与"看破 → 熏种 → 常态"的常态化机制严格同构。

出处:《俱舍论》、《成唯识论》、《瑜伽师地论》。
