# 灭尽定

**灭尽定**(梵 *nirodha-samāpatti*,亦称**灭受想定**)是圣者(三果阿那含以上、阿罗汉、菩萨)所修的深定,在定中**灭第六识及其相应心所 + 染污末那现行(末那的我痴、我见、我慢、我爱)**。是九次第定的最后一定。

## 与[无想定](无想定.md)的核心区别

虽然二定都"灭心",但**根本不同**:

| | [无想定](无想定.md) | 灭尽定 |
|---|---|---|
| 修者 | 外道 | 圣者(三果以上) |
| 定的深度 | 深(灭第六识) | 深(灭第六识 + 染污末那现行) |
| **般若现观** | **无** | **有**——以已立的无我现观为前提 |
| 对末那[我执](我执.md) | **完全没动** | **能伏染污末那现行** |
| 出定后 | 染污如旧 | 圣者智不退 |

→ 关键不在定更深,**在有没有般若现观作前提**——这才是能动末那根的根本条件。

## 修行学意义

灭尽定是"止观双运 / 定慧具足"的最高定位现行——**圣者**已立无我现观(般若),配合深定,才能伏到末那染污层。凡夫不能修灭尽定(没有般若现观作前提)。

灭尽定 vs [无想定](无想定.md)的对比是经典对"**断惑必须止观双运**"的最强锚——同样深的定,有般若与否决定能不能动末那的根。

出处:《俱舍论》、《成唯识论》、《瑜伽师地论》。
