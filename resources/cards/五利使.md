# 五利使（见惑）

**五利使**指**身见 / 边见 / 邪见 / 见取见 / 戒禁取见**五种见解面根本烦恼——又名**见惑**，因其依止于"见"（认知 / 见解面运作），见道一时断尽（速度快、起效猛烈，故称"利"）。与依止于"思"（情绪 / 情感面）的[五钝使](五钝使.md)（贪 / 嗔 / 痴 / 慢 / 疑）并列，合称**十使**或**十根本烦恼**。

## 名义

- **利**：指对治起效快、断除速度猛——见道一次破见即断尽（区别于五钝使的"钝"，钝使需修道反复对治）
- 经典出处：《俱舍论》卷十九 / 《成唯识论》卷六 / 《大乘阿毗达磨集论》等
- 在百法烦恼心所中，五利使全归"恶见"一法下，作为恶见的五种内容

## 五利使内容

| 利使 | 内容 | 性质 |
|---|---|---|
| **身见**（萨迦耶见）| 执五蕴假合为实"我" | 我执的认知层根基（参 [我执 / 萨迦耶见](我执.md)）|
| **边见** | 执"我"为常 / 为断（断常二见）| 身见的延伸——常见 / 断见 |
| **邪见** | 拨无因果 / 不信圣道等 | 否定基本佛法真理 |
| **见取见** | 执自所见为最胜 | 对自见的取著 |
| **戒禁取见** | 执非因为因（如执苦行 / 邪戒为得解脱因）| 错误归因解脱因 |

## 五利使 vs 五钝使

| 维度 | 五利使（见惑）| 五钝使（思惑）|
|---|---|---|
| 性质 | 见解 / 认知面烦恼 | 情绪 / 情感面烦恼 |
| 内容 | 身见 / 边见 / 邪见 / 见取 / 戒禁取 | 贪 / 嗔 / 痴 / 慢 / 疑 |
| 断除位次 | **见道一时断** | 修道渐次断（俱生分三果四果断）|
| 对治 | 闻思现观（一次性破见）| 长期熏修 |
| 隐喻 | 利剑斩——快猛 | 钝杵磨——慢长 |

## 五利使断除位次

五利使全部在**见道（初果须陀洹）**一次性断尽——这就是见道"破见"的本质：

> 见道前凡夫位由身见为根，引生边见 / 邪见 / 见取 / 戒禁取等错见；见道一刹那现观四谛 / 二空 → 五利使一时断尽（因见已破，依见而立的其余四见自然瓦解）。

→ **见道是凡夫位与圣位的分水岭**——见道前是凡夫（五利使在），见道后是圣者（五利使断尽，但五钝使俱生仍在）。
