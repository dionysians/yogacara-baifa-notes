# 二空

**二空**指**人空**(人无我)与**法空**(法无我)——大乘对"无我"的二层展开。

| | 人空 | 法空 |
|---|---|---|
| 所空 | 五蕴假合上立的"我" | 一切法(含五蕴本身、教法、修行) |
| 对治 | [我执](我执.md)(烦恼障) | [法执](法执.md)(所知障) |
| 二乘所证 | 证(声闻、缘觉皆证人空) | 不证(二乘只证人空、未证法空) |
| 大乘所证 | 证 | 证(大乘二空俱证) |

## 大乘 vs 二乘的根本分界

二空次第正是大乘 / 二乘的根本分界:

- **二乘**:只证人空(断[我执](我执.md) / 烦恼障)→ 阿罗汉 / 辟支佛
- **大乘**:证二空(断[我执](我执.md) + [法执](法执.md) / 烦恼障 + 所知障)→ 佛

→ "为什么阿罗汉不是佛?"——因为只证人空、未证法空。

## 与"了无自性"的关系

"了无自性"如果只指"人无自性"= 人空;如果含"法无自性"= 二空俱含。**修行者若早年内化的"了无自性"不限于人、含法空一面,即是接近大乘见地的空性见**(本项目修行者[无痴](../../notes/03-心所法/善心所/无痴.md) §七 跨世种子证据 #4 的具体内涵)。

出处:《大般若经》、《中论》、《成唯识论》。
