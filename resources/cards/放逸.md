# 放逸

随烦恼心所之一，与[不放逸](../../notes/03-心所法/善心所/不放逸.md)相反——是常态层的懈怠态。

## 体性

[《成唯识论》](《成唯识论》.md)卷六：

> **云何放逸？于染净品不能防修，纵荡为性，障不放逸，增恶损善所依为业。**

- **不能防修**：失去断恶 / 修善方向上的常态守护
- **纵荡为性**：心识纵任放纵、漂荡不收
- **增恶损善所依**：作为一切恶法增长 / 善法损减的运作基础

## 派系归属

| 派系 | 立场 |
|---|---|
| [护法](护法.md)派 | 放逸**无别体**——即懈怠 + 贪 + 嗔 + 痴四法所摄，假立为放逸 |
| 部分论师 | 放逸**别有自性** | 独立心所 |

放逸与不放逸是经典明文的"对治对偶"——二者皆为"假立非实"（前者由懈怠 + 贪嗔痴假立，后者由精进 + 三善根假立）。

## 与不放逸的精确对偶

| 维度 | 放逸 | 不放逸 |
|---|---|---|
| 依四法立 | 懈怠 + 贪 / 嗔 / 痴 | 精进 + 无贪 / 无嗔 / 无痴 |
| 时态 | 常态层 | 常态层 |
| 业用 | 增恶损善 | 防修 / 成满世出世间善事 |
| 当代触发条件 | 注意力经济 + flow-trap 设计精准制造 | 修行者主动建立的失念对治通道 |

## 与失念 / 懈怠 / 散乱 / 不正知的协同

不放逸缺位时五随烦恼协同显现：

```
放逸（常态懈怠态）
   ↓
懈怠（动力中断）
失念（念所缘从善法滑离）
散乱（注意力被外境带走）
不正知（慧的简择失位）
```

放逸是这层网络的**核心 manifest**——其他四者是放逸在动力 / 念 / 注意力 / 慧各维度的具体显现。

## 当代变形

[假说 14](../../CLAUDE.md#跨阶段回填清单)（方便层瓦解的普遍性元假说）在不放逸场的验证：放逸的**工业化反向**形态 = **注意力经济** + **flow-trap 设计**——产品本身被精心设计为 hijack 注意力的 sink（AI / 短视频 / 推送 / 游戏）。失念现象因此**结构性强化**，不放逸建立通道因此**结构性变窄**。

## 修行学含义

- 放逸的对治不在"用第六识鞭策自律"，在让不放逸（精进 + 三善根力层涌现的常态守护）自然显现
- 不放逸涌现的关键通道 = 精进根→力转变 = 事件层频次累积（详见 [不放逸.md §五](../../notes/03-心所法/善心所/不放逸.md)）
- 当代修行者需用 trigger design 在单人独修条件下建立失念对治
