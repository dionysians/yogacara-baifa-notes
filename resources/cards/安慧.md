# 安慧

印度大乘唯识论师（约 510-570 CE），与[护法](护法.md)同时期，是世亲后唯识传承中**与护法立场多有分歧**的主要代表之一。

## 在唯识传承中的位置

安慧是世亲弟子德慧的弟子（一说为德慧 / 难陀派系），其立场与护法派多有差异。在[《成唯识论》](《成唯识论》.md)合糅十师注释时，安慧立场常被列为对偶 / 异说，但其论著本身仍是大乘唯识的重要资源。

## 主要作品

- 《大乘阿毗达磨杂集论》（与杂集论合糅，详见 [《大乘阿毗达磨杂集论》](《大乘阿毗达磨杂集论》.md)）
- 《唯识三十论释》（与护法《唯识三十颂释》对偶，部分章节传入藏地）
- 《俱舍论实义疏》

## 与护法的主要立场差异

| 议题 | 安慧派立场 | 护法派立场 |
|---|---|---|
| 心心所体性 | 心 / 心所**一体**——心所是心的特性展开 | 心 / 心所**别体**——心所有独立体性 |
| 见相二分 | 见 / 相二分**虚妄**——只有自证分实有 | 四分（相 / 见 / 自证 / 证自证）说 |
| 无痴体性 | 无痴**即慧**，不别立体 | 无痴[别有自性](别有自性.md) |
| 不放逸体性 | 不放逸**别有自性** | 不放逸**无别体**——即精进三根假立 |
| 行舍体性 | 行舍**别有自性** | 行舍**无别体** |
| 失念 / 不正知 | 兼有念 / 慧 + 痴二分 | 即念 / 慧为体 |

## 安慧立场的内在逻辑

安慧立场的总倾向是**"承认更多独立体性"**——这反映他对心所功能不可还原性的强调。其与护法分歧的根源在于：

- 安慧：每个 manifest 功能不可被还原即应别立——保持心所分判的细颗粒度
- 护法：体性独立需经"功能不可还原 + 三性归属独立 + 结构对称"严格判别——保持心所分判的简洁性

→ 安慧立场更倾向"加法"，护法立场更倾向"简化"（奥卡姆剃刀风格）。

## 与本项目相关的安慧立场争议

[不放逸](../../notes/03-心所法/善心所/不放逸.md)的体性争议是本项目假说 15 v3 的首个非三善根验证场：

- **护法派**（不放逸**无别体**）→ v3 不需扩 dimension，不放逸是守护面（运作机制层）正交于 anchor / 反应面
- **安慧派**（不放逸**别有自性**）→ v3 可能需扩成三 dimension，"持续守护"不可由空间双 anchor 推出

本项目按"经典 > 假说"原则采用护法派立场，但承认安慧派的"持续性"直觉有其根据——通过修行者 "精进根→力转变 自然涌现持续性" derivation 调和（详见 [不放逸.md §二](../../notes/03-心所法/善心所/不放逸.md)）。
