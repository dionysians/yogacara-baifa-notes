# 因缘

**因缘**(梵 *hetu-pratyaya*)在唯识体系中有**两个不同层次的用法**,使用时必须分清,否则机制分析会糊。

## 一、严格义:四缘之第一(亲因缘)

[四缘](四缘.md)之首,指**亲能生果的根本因**——能直接产生果法、与果法体性相称的那个缘。

唯识系统中"亲因缘"的精确所指:

- **种子 → 现行**:阿赖耶识中的种子是现行法的因缘
- **现行 → 熏种**:七转识的现行是新生种子的因缘
- 这两条合起来即"种子生现行、现行熏种子"的因果循环——种子与现行**互为因缘**

因缘是亲、近、直接的;其他三缘([等无间缘](等无间缘.md)、所缘缘、[增上缘](增上缘.md))是辅助、间接的。**只有因缘是"亲生果"的;其他三缘是"助生"的**。

## 二、宽泛义:"因"与"缘"合称

日常 / 通俗用法中,"因缘"是"原因和条件"的合称(因 = 主要原因,缘 = 辅助条件)。这与严格义不同——严格义只指[四缘](四缘.md)的第一缘,宽泛义则涵盖一切原因和条件(包括四缘全部)。

经典文本中两种用法都出现,需依上下文判别。**讨论唯识机制时一律取严格义,避免混用**。

## 与[增上缘](增上缘.md)的辨异

这是初学最易混的一对:

| | 因缘 | [增上缘](增上缘.md) |
|---|---|---|
| 与果的关系 | **亲生** | **助生 / 不障碍** |
| 性质 | 直接产果 | 提供条件 |
| 唯识对应 | 种子 | 一切不障碍因素 |

例:今世修行善法

- **因缘** = 过去世修行善法所熏的善种子(亲能生今世善行现起)
- **增上缘** = 善知识、寺院环境、教法可得、闲暇时间等(助善种现行,不亲生)

→ 两者**和合**才有果。缺因缘则[增上缘](增上缘.md)无所成熟之物,缺[增上缘](增上缘.md)则因缘种子无缘现起。

## 修行意义

唯识立"因缘"为种子,直接导出修行的根本机制:**修行的本质是在因缘(种子)上用功**——熏对治善种、不熏烦恼种。[增上缘](增上缘.md)(外境、师友等)的作用是不可忽视的辅助,但不是修行的根本——根本在因缘。

出处:《俱舍论》四缘说、《成唯识论》卷七及卷八。
