# 所依

**所依**是佛教法相学分析一法时的核心要素之一，指**该法所依托、依止而起的基础**。任何一法都不能孤立存在，必有所依——知道它依何而起，才能知道它如何运作、如何中断、如何强化。

## 三种所依

唯识学通常把"所依"分三层：

### 1. 因缘依（种子依）
**种子**是法的亲因缘——任何现行的法必依其种子而起。信心现行需信的种子，烦恼现行需烦恼的种子。这是从阿赖耶识层面谈所依。

### 2. 俱有依（增上依）
法起时同时存在的依托：
- **前五识** 依 **五根**（眼识依眼根，耳识依耳根……）
- **前五识** 依 **第六识**（分别依）
- **前六识** 依 **第七识**（染净依）
- **前七识** 依 **第八识**（根本依）
- **第八识** 依 **第七识**（互依）

这一套俱有依关系揭示了八识的互相依持结构，是唯识学的精妙之处。

### 3. 开导依（等无间缘依）
前一念心灭为后一念心**开导**（让位、引导）——这是时间维度上的依止。

## 心所的所依

各心所也有其所依：

- **所依之心王**——心所必依心王起，心王灭则心所不存（这是[相应](相应.md)的基础）
- **所依之根身**——如前五识的心所依五根，意识的心所依意根
- **所依之种子**——每个心所有自己的种子，依种子起现行

## 与[业用](业用.md)、[所缘](所缘.md)、[相应](相应.md)的区别

这四个是分析一法的四栏：

| 要素 | 回答 |
|------|------|
| [体性](体性.md) | 它是什么？ |
| [业用](业用.md) | 它做什么？ |
| **所依** | 它依什么起？ |
| [所缘](所缘.md) | 它攀缘什么？ |
| [相应](相应.md) | 它与谁同起？ |

学习任何一法时围绕这五问展开，即是[阿毗达磨](阿毗达磨.md)法相分析的标准方法。

## 修行意义

"知所依"在修行上极其重要——**中断一法或强化一法，关键是在其所依上用功**：

- 想要强化正念 → 在"意识"这个俱有依上用功（六识清净）+ 在"种子"层面反复熏习念的种子
- 想要对治贪 → 不是直接压贪，而是在贪所依的遍计所执上破除（所缘上用功），或在其种子上伏断

[转识成智](转识成智.md)本质是**所依的根本转变**（转依，āśraya-parāvṛtti）——阿赖耶识这一根本所依从染污转为清净。
