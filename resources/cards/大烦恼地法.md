# 大烦恼地法

**大烦恼地法**是[《俱舍论》](《俱舍论》.md)（说一切有部五位七十五法体系）心所分类中的一类：**遍一切染污心**的六个心所——

> 痴、放逸、懈怠、不信、惛沉、掉举（《俱舍论》卷四本颂：「痴逸怠不信，惛掉恒唯染」）

"地"指心所活动的所依范围：大地法遍一切心、大善地法遍一切善心、**大烦恼地法遍一切染心**、大不善地法遍一切不善心、小烦恼地法局部现行。

## 与唯识"大随烦恼八法"的对照

| | 有部大烦恼地法（6）| 唯识大随烦恼（8）|
|---|---|---|
| 成员 | 痴、放逸、懈怠、不信、惛沉、掉举 | 掉举、惛沉、不信、懈怠、放逸、失念、散乱、不正知 |
| 差异 | 痴列入（作遍染心所） | 痴归根本烦恼；另加失念、散乱、不正知 |
| 共同点 | "遍一切染心"的外延标准一致 | 同 |

## 放逸别体之诤（本项目引用要点）

有部立放逸为**实体**（七十五法之一、别有自体）；唯识护法判放逸「**非别有体**」（懈怠 + 贪嗔痴的复合分位）。这一立场反转说明护法"别有体两刀"（通染心不能尽 + 独立业用 / 行相）是**能输出否定结论的真检验**——对掉举 / 惛沉 / 不信 / 懈怠输出"是"（各有推究不尽的剩余行相），对放逸输出"否"（纵荡推究无异门、离四法无剩余）。
