# 邪见

**邪见**（mithyā-dṛṣṭi）= [五利使](五利使.md)之第三，恶见之一，是五见中**最严重**的染慧 — 直接破坏修行前提（业果信解）。

## 经典定位

《[成唯识论](《成唯识论》.md)》卷六：
> 三邪见，谓谤因果作用实事，及非四见诸余邪执。

## 四种形态

1. **拨无因**：否认善恶业因
2. **拨无果**：否认善恶业果
3. **拨无作用**：否认轮回 / 三世 / 业用相续
4. **谤圣贤**：诽谤佛 / 法 / 僧 / 圣人

## 为什么五见中最重？

- 直接破坏**修行的前提**（业果信解）— 不像身见 / 边见还在"如何理解我"上偏，邪见**直接拨掉佛法地基**
- → **邪见 = 染疑的稳态终点**（疑精修中已建立"染疑攻击披甲基础"）

## 与疑的精确对照

| 心所 | 对业果谛理的姿态 |
|---|---|
| **染疑** | 犹豫（未稳定）— "可能有也可能没有" |
| **邪见** | 已稳定拨无（决了到否定方向）— "确定没有" |
| **善慧 / 正见** | 已稳定信解（决了到肯定方向）— 业果如实 |

→ 染疑 → 邪见是**结构性堕落路径**。

## 修行者位置的微细谤圣贤形态

恶见精修中揭示修行者位置上**微细谤圣贤俱生现行**（与 [法嗔](法嗔.md) 同步）：
- 不是直接谤佛 / 谤经典（结构性化解）
- 而是微细形态 — 在派系争议处 / 见解被质疑时，对持不同见者的轻视
- 是法染色层主战场的一个成分（与见解嗔三层复合俱生绑定）
