# 七憍

**七憍**，经论所列**[憍](../../notes/03-心所法/随烦恼心所/憍.md)所缘"自盛事"的七种细目**——凡可被读作"我之盛"者皆可成憍（于自盛事深生染著醉傲）的所缘处。诸论开合略异，通行七数为：

| 憍 | 所盛事 |
|---|---|
| 无病憍 | 恃身体康健而醉傲 |
| 少年（少壮）憍 | 恃年壮力盛而醉傲 |
| 长寿（命）憍 | 恃寿命长久而醉傲 |
| 族姓憍 | 恃门第出身而醉傲 |
| 色力（端正）憍 | 恃容色 / 体力而醉傲 |
| 富贵（自在）憍 | 恃财位自在而醉傲 |
| 多闻（聪慧）憍 | 恃学识聪敏而醉傲 |

两点要义：

1. **从物理到建构的谱系**——所盛事从最物理的（无病 / 少壮 / 色力）到最世俗建构的（族姓 / 富贵 / 多闻），但"以之为盛而醉傲"这层读取一律是**世俗概念假立**（"盛"无自性）。
2. **七憍是举例、非滤网**——不是"够这七格才算憍"的客观清单。尤其**无病憍 / 少年憍**证明：憍所缘**不需稀缺 / 区隔**（健康、年轻都不稀缺），故"盛"是"自身正价"、不是"胜过他人"（后者是[慢](../../notes/03-心所法/烦恼心所/慢.md)）。

出处：《瑜伽师地论》本地分等（诸阿毗达磨论所列，开合不一）。在百法学习中，七憍是理解憍所缘"自盛事"结构的经典骨架——尤其其"盛=建构正价、非客观胜出"的边界。
