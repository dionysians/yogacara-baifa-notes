# 十二缘起

**十二缘起**（梵 *dvādaśāṅga-pratītya-samutpāda*）是佛教对生死流转因果链条的根本分析，由十二支组成：

**无明 → 行 → 识 → 名色 → 六入 → 触 → 受 → 爱 → 取 → 有 → 生 → 老死**

## 核心义

- **此有故彼有，此生故彼生**——缘起性空的根本陈述
- **此无故彼无，此灭故彼灭**——还灭门，由智断无明则生死链断

## 三世两重因果（说一切有部经典解释）

| | 因 | 果 |
|---|---|---|
| 过去世 | 无明、行 | — |
| 现在世 | （识、名色、六入、触、受 = 过去因之果）（爱、取、有 = 现在因） | — |
| 未来世 | — | 生、老死 |

## 唯识的诠释

唯识不专取三世两重模式，更强调**无始相续 + 阿赖耶识种子-现行机制**——无明熏识中种子，种子遇缘现行为名色六入等，每一刹那皆是十二支的循环。
