# 失念

随烦恼心所之一，与念心所相反——念心所失去，所缘从善法所缘滑离到其他对象。失念**不是"忘了这件事"**，而是"曾决定要做的善法事没有被持续记得"。

## 体性

[《成唯识论》](《成唯识论》.md)卷六：

> **云何失念？于诸所缘不能明记为性，能障正念，散乱所依为业。**

- **不能明记**：念心所失位，所缘失明记功能
- **障正念**：失念现起时正念退失
- **散乱所依**：失念为散乱心所提供运作基础

## 派系归属

| 派系 | 立场 |
|---|---|
| [护法](护法.md)派 | 失念**即念为体**——非别立体，是念心所的反面 |
| 部分论师 | 失念**痴一分**——是无明的具体显现 |

[安慧](安慧.md)派立场：失念兼有念与痴二分。

## 与不放逸的对偶

失念是[不放逸](../../notes/03-心所法/善心所/不放逸.md)缺位时的精确显现之一：

```
不放逸缺位
   ↓
随烦恼网络协同显现：
   - 放逸（常态懈怠态）
   - 懈怠（动力中断）
   - 失念（念所缘从善法滑离）← 当代修行者最常见的失败模式
   - 散乱（注意力被外境带走）
   - 不正知（慧的简择失位）
```

→ 不放逸的精确机制 anchor = **念在 time domain 持续在场 + 精进力层稳定 + 三善根 anchor 在场**；失念是这层机制失效的典型形态。

## 当代修行者的典型显现

当代条件下失念被注意力经济与 flow-trap 设计**结构性强化**：

- 修行者意识层有"要做"的决定（第六识胜解 + 善法欲在场）
- 但"投入之前正在进行中的事情后不自觉把修行时间挤占"——念所缘没切换到修行
- end up 修行没发生不是"明决定不做"，是**注意力被其他活动吸引**

→ 这是失念的精确机制，不是末那运作（突然就不在做了）也不是第六识决定（找借口推延）。

## 修行学含义

- 失念的对治不在"用第六识鞭策自己继续做"（用力 framing），在让念心所稳态化
- 念稳态化的三层条件：**确定时间 + 确定模式 + 提高优先级**——念 + 胜解 + 善法欲三层别境心所协同
- 与九住心配六力四作意中"内住 / 续住 = 听闻力 + 思惟力"严格对应
- trigger design（外部 cue 触发念回归善法所缘）是当代单人独修条件下对治失念的具体操作核
