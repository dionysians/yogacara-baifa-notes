# 掌中毛喻

**掌中毛喻**（眼中毛喻）用"一根毛置于手掌则毫无所觉、置于眼中则刺痛难忍"，比喻**行苦极细微**——凡夫如手掌、对行苦置之不觉，圣者如眼、对行苦即觉即厌。是解释"为什么行苦现量够不着、却不是行苦不在"的经典譬喻。

## 经文锚 + 譬喻

**经文锚**〔第一层·《瑜伽师地论》行苦定义〕：

> 有漏诸行，由**麁重**所随故，**性不安隐**。

——行苦的体是"不安隐"、因"麁重（烦恼种子粗重）所随"，**恰恰是感受不到的那种苦**（三苦中最细，要圣慧照见、非现量感受）。

**譬喻**〔通行于道次第 / 阿毗达磨传承·**原始出处待考**，不杜撰经号〕：

> 一根毛发置于**手掌**，毫无所觉；同一根毛置于**眼中**，则刺痛难忍。诸异生（凡夫）如手掌，于行苦不觉；诸圣者如眼，于行苦即觉即生厌患。

## 逐句比量

| 喻 | 法 | 比量点 |
|---|---|---|
| 毛 | 行苦（取蕴不安隐） | 体极细、本身不"重" |
| 掌 / 不觉 | 凡夫位粗心 | 慧不够细 → 碰不到那一层 |
| 眼 / 刺痛 | 圣者无漏慧 | 慧够细 → 一触即觉即厌 |
| 同一根毛、两处不同 | 行苦客观恒在、觉不觉随慧 | "觉不到" ≠ "不在"，只是位差（掌 / 眼） |

**核心比量**：「**现量感受不到逼迫 = 凡夫位标准态、不是行苦的反证**」——不是看一个不存在的东西，是站在掌位看一个要眼位才显的东西。这把修行者历来"行苦够不着"的困惑，转成**经典早已预言的标准态**：它本来就该现量够不着。"觉行苦"= 有照见取蕴不安隐的慧；建行苦比量 = 给自己一个**比量版的圣慧之眼**（比量代现量）。
