# 五钝使（思惑 / 修惑）

**五钝使**指**贪 / 嗔 / 痴 / 慢 / 疑**五种根本烦恼——又名**思惑** / **修惑**，因其依止于思（情绪 / 情感面运作）、需通过修道反复对治才能断除，故称"钝"。与依止于"见"（认知 / 见解面）的[五利使](五利使.md)（身见 / 边见 / 邪见 / 见取见 / 戒禁取见）并列，合称**十使**或**十根本烦恼**。

## 名义

- **使**（梵 anuśaya / saṃyojana）：随眠的别名，指潜伏于心相续中、能驱使心起恶业的烦恼力量
- **钝**：指对治难、起效慢，需长期修道反复熏对治才能断除（区别于五利使的"利"，利使在见道一次断尽）
- 经典出处：《俱舍论》卷十九 / 《成唯识论》卷六 / 《大乘阿毗达磨集论》等

## 五钝使内容

| 钝使 | 体性 | 体性方向 |
|---|---|---|
| **贪** | 染著（于有有具染著为性）| 摄受 |
| **嗔** | 憎恚（于苦苦具憎恚为性）| 推拒 |
| **痴** | 蔽暗（无明为性）| 暗 / 不明 |
| **慢** | 高举（恃己于他高举为性）| 自抬 |
| **疑** | 犹豫（于诸谛理犹豫为性）| 不决了 |

## 五钝使 vs 五利使

| 维度 | 五钝使（思惑）| 五利使（见惑）|
|---|---|---|
| 性质 | 情绪 / 情感面烦恼 | 见解 / 认知面烦恼 |
| 内容 | 贪 / 嗔 / 痴 / 慢 / 疑 | 身见 / 边见 / 邪见 / 见取见 / 戒禁取见 |
| 断除位次 | 修道渐次断（见道断分别 / 三果四果断俱生）| 见道一时断 |
| 对治 | 长期熏修 | 闻思现观（一次性破见） |

## 五钝使断除位次概要

各钝使在四果断除位次的差异：

| 钝使 | 见道（初果）| 三果（阿那含）| 四果（阿罗汉）|
|---|---|---|---|
| 贪 | 断分别 | 断欲界俱生 | 断色无色俱生 |
| 嗔 | 断分别 | **断俱生**（嗔三果尽）| 同三果 |
| 痴 | 断分别 | 断俱生（部分）| 断不共我痴 |
| 慢 | 断分别 | 断欲界俱生 | 断色无色俱生 |
| 疑 | **断**（疑三性对治为见，见道断尽）| 同 | 同 |

→ **嗔最早彻底断**（三果） / **疑见道即断** / 贪痴慢最晚（含四果方面）。
