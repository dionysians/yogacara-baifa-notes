# 七圣财

**七圣财**指七种依修行而成就的功德法财——信、戒、惭、愧、闻、施、慧。它们是出世的真实财富，与会被五家（水、火、盗贼、恶王、不肖子孙）夺去的世间财相对。

## 七项

| 财 | 义 |
|---|---|
| **信** | 信受正法，生持法之力 |
| **戒** | 戒为解脱所依，防身口意之非 |
| **惭** | 于所造不善，自觉羞耻而改 |
| **愧** | 于所造不善，畏世讥责而止 |
| **闻** | 多闻正法，长养正解 |
| **施** | 以平等心舍财、法，离悭贪 |
| **慧** | 摄心不乱，如实了知诸法 |

## 说明

七圣财把"财富"一词从世间财引向法财：世财为五家所共、聚散无常；七圣财则修行所自成、他人夺不走，且能资行者趣向解脱。经论常以七圣财劝在家人于积聚世财之外，更积聚此不坏之财。
