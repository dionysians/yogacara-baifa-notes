# 盲龟喻

**盲龟喻**是佛教用来形容**人身（暇满）难得**的核心譬喻——以一只盲龟在无边大海中、百年一浮头而恰好穿入随风漂流之浮木孔的极小概率，比喻众生于五趣轮回中再得人身之稀有。

## 经文

〔第一层·《杂阿含经》卷十五（盲龟经）〕

> 尔时，世尊告诸比丘：「譬如大地悉成大海，有一盲龟寿无量劫，百年一出其头；海中有浮木，正有一孔，漂流海浪，随风东西。盲龟百年一出其头，当得遇此孔不？」……佛告阿难：「盲龟浮木，虽复差违，或复相得；**愚痴凡夫漂流五趣，暂复人身，甚难于彼！**」

亦见 **龙树《亲友书》**（劝乐行王莫空过人身）、**寂天《入菩萨行论》**第四品（「人身极难得」并引盲龟颈入轭木孔）、**《大般涅槃经》**（「生世为人难，值佛世亦难，犹如大海中，盲龟遇浮孔」）。

## 逐句比量

| 喻 | 法 | 比量点 |
|---|---|---|
| 大海无边 | 五趣轮回 | 流转域极广 |
| 盲龟 | 漂流五趣的众生 | **龟盲 = 无明**：不能自择方向、无法自力趋向善趣 |
| 百年一出头 | 偶得善趣 / 暂复人身的机会 | 时间尺度上极疏 |
| 浮木一孔 | 人身 / 暇满 | 标的极小 |
| 随风东西漂流 | 因缘无定、不由自主 | 标的还在动、不在固定处等你 |
| 龟头恰入孔 | 再得暇满人身 | 两个小概率事件叠加 = 稀有之极 |

**核心比量**：得人身不是"默认会有"，是盲（无明）× 疏（百年一遇）× 动（浮木随风）三重小概率的叠加。**对"命好者"的用法**：现量从无"稀缺"经验 → 难得全靠比量，盲龟喻正是**比量代现量的脚手架**（用鲜活影像顶替缺失的稀缺现量）。取此喻走「**难得故应即用此窗口**」（理 / 义大侧），不走「失则堕恶趣」（恐怖侧）。
