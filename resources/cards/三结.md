# 三结

**三结**指**身见**、**戒禁取**、**疑** —— 证初果（须陀洹）必须断除的三种结缚烦恼。三结同断 = 证初果（入流）= 由凡夫位入圣位的关键跃迁。

## 三结的具体内容

| 结 | 内容 | 与"见"的关系 |
|---|---|---|
| **身见**（萨迦耶见）| 执五蕴为我的颠倒见 | 见已稳但偏（执我）|
| **戒禁取** | 执非因为因（持戒方式错误）/ 执外道戒为解脱因 | 见已稳但偏（错执因）|
| **疑** | 对四谛 / 三宝 / 业果等谛理犹豫不决 | 见在两可未稳定 |

→ 三者都涉及"见的不正运作"——身见和戒禁取是**见已稳但偏**，疑是**见未稳定**。证初果 = 现观四谛 → 见稳且正 → 三结同时断。

## 证初果（须陀洹 / 入流）

断三结 = 进入"圣流"，从此不再退转，最多七返人天必证四果（阿罗汉）。这是凡夫位 → 圣位的关键临界点。

声闻乘四果阶位：

| 果位 | 断结 |
|---|---|
| **须陀洹**（初果 / 入流）| 断三结 |
| **斯陀含**（二果 / 一来）| 三结 + 减贪嗔痴 |
| **阿那含**（三果 / 不还）| 三结 + 五下分结（贪欲 / 嗔恚）|
| **阿罗汉**（四果 / 无学）| 五下分结 + 五上分结 |

- 《俱舍论》《成唯识论》对三结的分判
- 《清净道论》二十二根章节
