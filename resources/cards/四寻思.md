# 四寻思

**四寻思**是唯识加行位菩萨入唯识性、观能取所取空的观行方便，出《瑜伽师地论·真实义品》（亦见《摄大乘论·入所知相分》）。"寻思"即推求伺察，于所观境推求其四个方面，皆见为假立、唯识所现、不可得：

1. **名寻思**——推求"名"只是名言安立，离名无实。
2. **事寻思**（亦作义寻思）——推求名所诠的"事／义"，离名言不可得。
3. **自性假立寻思**——推求境上被执为本具的"自性"，实为假立。
4. **差别假立寻思**——推求种种好恶、彼此等"差别相"，实为假立。

四寻思深观成就，引生[四如实智](四如实智.md)（能取所取空、并正了八种分别）。它的作用方式是"减法"：不直接给出境的正面内容，而是剥除加于境上的[遍计所执](遍计所执.md)，令缘起如实自现。
