# 别有自性

唯识学专业术语,指**某一心所(或法)在体性层面有自己独立的、不与其他法共的本质规定性**,不能还原为别的法的别名或一分。"别"= 独立、单独、不共;"自性"= 自己的体(svabhāva)、本质规定性。

## 核心含义

当唯识论师判定某个心所"别有自性"时,是在主张:此心所在 51 心所(或更广的一切法)结构中**独立占一格**,有自己专属的体性,不能被还原为其他心所的功能展开或变现。

反面立场是"**即某法为体**"或"**不别立体**"——主张该心所的运作可以完全用别的心所的体性解释,无需另立。

## 典型争议:无痴的体性

《成唯识论》卷六记录唯识内部对无痴体性的两派立场:

| 派系 | 立场 | 核心理由 |
|---|---|---|
| 护法派(本论主)| 无痴**别有自性** | 慧通三性(善 / 恶 / 无记),无痴唯善——若无痴 = 慧,无痴的"唯善"属性失去独立体性 anchor;且三善根需齐立(无贪、无嗔皆别有自性) |
| 安慧派 / 难陀派 | 无痴即慧,不别立体 | 慧的"于所观境简择为性"已涵盖"明解理事",无需另立 |

护法派坚持"别有自性"是为了保证三善根结构齐整 + 保证无痴的唯善性质 + 区分"明解"(无痴)与"简择"(慧)在体性层面的不同。

## 别有自性 ≠ 孤立现行

重要的精度:**别有自性是体性层面的独立,不等于现行时单独起**。

窥基明确承认:无痴现行时常与慧俱起(无痴起则慧亦在);但反向不成立(慧起未必有无痴——邪慧、无记慧时没有无痴)。同理,无嗔别有自性,但无嗔现行时常与慈悲、不害等同时起。

→ 体性独立(别有自性)与功能协同(现行时与他心所俱起)在唯识中是两个不同维度,不冲突。

## 判别"别有自性"的依据

唯识论师判定某心所是否别有自性,通常依据:

1. **功能不可还原**:此心所的作用不能完全由其他心所的功能解释
2. **三性(善 / 恶 / 无记)归属独立**:若此心所唯属某性,而被怀疑还原的对象通三性,则唯属某性的属性需独立 anchor
3. **结构对称要求**:在已确立的法数结构中(如三善根、五遍行等),需保证体性齐立

## 在唯识中的更广运用

"别有自性"不只用于无痴,贯穿 51 心所的体性判定:

- 五别境(欲 / 胜解 / 念 / 定 / 慧)各别有自性,不能互相还原
- 善心所中无贪、无嗔、无痴各别有自性(三善根);轻安、不放逸、行舍、不害也别有自性
- 部分心所则被判为"即某法为体"——如**不放逸即精进 + 三善根为体**(无别体,体性 = 此四法的合用),这是相对"别有自性"的反面立场

## 修行学含义

- 闻思深度通透的产出在心所层面**不只是慧增,还有无痴增**——这是两个独立心所的并熏
- "想通"(慧的简择产出)与"如实见"(无痴的明解稳态)在体性层面是两件事,不能混为一谈
- 同理,"努力压住怒火"如果是意识用慧作判断后强压,与"无嗔别有自性的现行"(对苦受不起作损恼相)是两件事,后者才是真无嗔
