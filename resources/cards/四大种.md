# 四大种

地、水、火、风四界，是一切色法的**能造**。「大」谓其体宽广、遍一切所造色处；「种」谓其为能生之因。一切色法或是四大种自身，或是四大种所造。

《大乘五蕴论》的定义以「性」不以物：

| 大种 | 体性 |
|---|---|
| 地界 | 坚强性 |
| 水界 | 流湿性 |
| 火界 | 温燥性 |
| 风界 | 轻等动性 |

这一点最易误读：四大种不是「土、水、火、空气」四种物质，而是坚、湿、暖、动四类性质。骨是坚故属地界，血是湿故属水界，同一块物事上四大种俱在，只是何者增盛不同。

四大种**不在百法色法十一之列**，却是十一法的地基——《大乘五蕴论》说所造诸色是「眼根、耳根、鼻根、舌根、身根，色、声、香、味、所触一分、无表色等」，五根五境无一不冠以「四大种所造」。《显扬圣教论》卷一则把四大种与所造色合数，说「色者有十五种」，是另一种开合。

四大种与所造色的关系有一处结构上的特异：《俱舍论》卷二引契经明五根与色声香味皆「四大种所造」，唯独触是「四大种**及**四大种所造」——即触处兼摄能造与所造两分。这就是各论说触境时都要限定为「所触**一分**」的原因：另一分即四大种自身。

《显扬圣教论》卷一另对四大种作内外二分：身内者为五根及其居处所依止、有执受性（如发毛爪齿之属地、洟泪涎汗之属水），身外者为五境所依止、非执受性（如砾石丘山之属地、泉源溪流之属水）。
