# 三果（阿那含 / 不还果）

**三果**，又名**阿那含**（梵 anāgāmin，意译"不还"）、**不还果**，是声闻乘四果中的第三果位。证此果者已断除欲界全部修惑，尤其是欲界俱生贪、嗔、慢等粗品烦恼，命终不再生还欲界——故名"不还"。

## 名义

- 梵文 **anāgāmin**：a-（否定前缀）+ āgāmin（来者），字面"不再来者"
- 玄奘译为"不还"或音译"阿那含"
- 与四果位次序列对应：[初果](初果.md) 须陀洹 → [二果](二果.md) 斯陀含 → **三果 阿那含** → [四果](四果.md) 阿罗汉

## 断惑位次

三果断除欲界**九品修惑**全部——包括欲界俱生贪、嗔、慢的全部品类。

特别值得注意的几个断惑节点（与本项目相关）：

- **三果断俱生嗔**——嗔在三果即彻底断尽（这是嗔与贪、痴断除位次差异的关键）
- **三果断俱生慢**——欲界俱生我慢在三果断尽；色无色界俱生我慢需四果阿罗汉位才彻底断
- **三果断俱生贪欲界部分**——欲界贪在三果断尽；色无色界贪需四果断

## 三果与四果的差异

| 维度 | 三果（阿那含）| 四果（阿罗汉）|
|---|---|---|
| 断惑 | 欲界全部修惑断 | 三界全部修惑断（含色无色界俱生贪、慢、痴）|
| 生死 | 不还欲界（但可生色无色界）| 究竟解脱，不再生死 |
| 嗔 | 已断俱生 | 同三果（嗔三果断） |
| 慢 | 欲界俱生我慢断 / 色无色界俱生我慢未断 | 全部俱生我慢断 |
| 贪 | 欲界贪断 / 色无色界贪未断 | 全部贪断 |
| 痴 | 不共我痴未断（俱生不共无明）| 不共我痴断 |

## 五种阿那含

经典中三果再细分为五种（按断惑方式与寄生处的差异）：

1. **中般阿那含**——死后于中阴身般涅槃
2. **生般阿那含**——生于色界即般涅槃
3. **有行般阿那含**——生于色界后加行修而般涅槃
4. **无行般阿那含**——生于色界后不加行任运般涅槃
5. **上流般阿那含**——生于色界后辗转上生至色究竟天般涅槃
