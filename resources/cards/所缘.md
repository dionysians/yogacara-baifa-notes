# 所缘

**所缘**（梵 *ālambana*）是佛教法相学分析心识活动时的核心要素——指**心识所攀缘、所取的对象**。"缘"在此处作动词"攀缘"解，所缘即"被攀缘的对象"。任何心识活动必有所缘——没有所缘的识不成立。

## 心识结构中的位置

唯识学认为心识活动必有两面：
- **能缘**（能取）——作攀缘作用的主体（识本身、见分）
- **所缘**（所取）——被攀缘的对象（相分、境）

能所一对俱起，不可分割。这构成了最基础的"识—境"结构，是唯识"一切法唯识所现"的起点。

## 四缘中的所缘缘

佛教讲四缘（因缘、等无间缘、所缘缘、增上缘），"所缘缘"即此处的所缘作为缘起条件——心识必**以所缘为缘**方能起。

## 亲所缘 vs 疏所缘

唯识学进一步区分：

| 类型 | 含义 |
|------|------|
| **亲所缘缘** | 识亲自变起的相分（内所缘） |
| **疏所缘缘** | 所托之境（外所缘，如他人的识变现的相） |

这是唯识学中一个精细的区分，用以说明"为何我看到的颜色与你看到的颜色看似相同但实为各自识变"——每人各有自己的亲所缘（内识变），又依共业所现的疏所缘为托。

## 各识的所缘

| 识 | 所缘 |
|----|------|
| 眼识 | 色境（色尘） |
| 耳识 | 声境 |
| 鼻识 | 香境 |
| 舌识 | 味境 |
| 身识 | 触境 |
| 意识 | 法境（通缘一切法） |
| 末那识 | 恒缘阿赖耶识见分为"我" |
| 阿赖耶识 | 缘根身、器界、种子 |

## 心所的所缘

心所通常与其心王**同所缘**——心王缘什么境，心所也缘什么境（[相应](相应.md)的条件之一："同所缘"）。这是一条关键规则。

例如眼识缘色时，与之相应的触、作意、受、想、思等遍行心所也同缘此色。

## 修行意义

所缘是修行的操作面之一。**在所缘上下功夫**是所有禅修的共通方法：

- 观呼吸——所缘是呼吸
- 念佛——所缘是佛号或佛相
- 观心——所缘是心识活动本身
- 参话头——所缘是疑情

[转识成智](转识成智.md)的一个侧面就是**所缘的转变**——从缘[遍计所执](遍计所执.md)相（染污依他起）转为缘[依他起](依他起.md)与[圆成实](圆成实.md)（清净境）。修行上的"换所缘"（从染法换到净法）是最常见的对治手段。
