# 五盖

**五盖**指**贪欲**、**嗔恚**、**惛眠**、**掉悔**、**疑** —— 障碍禅修入定的五种烦恼。"盖"（nīvaraṇa）意为覆盖、障蔽——遮蔽心识的清明，使禅定不能成就。

## 五盖的具体内容

| 盖 | 内容 | 障碍的禅支 |
|---|---|---|
| **贪欲盖** | 对五欲（色声香味触）的贪著 | 障"一境性" |
| **嗔恚盖** | 对违境的憎恚 | 障"喜" |
| **惛眠盖** | 身心的沉闷迷糊 | 障"寻" |
| **掉悔盖** | 心散乱不安 + 对过去事的悔恼 | 障"乐" |
| **疑盖** | 对法（佛 / 法 / 僧 / 学处 / 修道）的犹豫 | 障"伺" |

→ 五盖一一对应五禅支的对治——禅修前必断五盖，禅支才能现前。

## 五盖 vs 五钝使（思惑）

五盖与五钝使有重叠但侧重不同：

| 维度 | 五盖 | 五钝使 |
|---|---|---|
| 立场 | **禅修学** 立场（障定）| **断惑学** 立场（断烦恼）|
| 范围 | 贪欲 / 嗔恚 / 惛眠 / 掉悔 / 疑 | 贪 / 嗔 / 痴 / 慢 / 疑 |
| 核心 | 障碍禅定入定 | 修道渐断的根本烦恼 |
| 与"见"关系 | 不直接谈见的层 | 五钝使中疑与"见"高度耦合 |

→ 疑既是五盖之一也是五钝使之一——表明疑的"基底破坏型"性质在禅修学和断惑学两层都成立。
