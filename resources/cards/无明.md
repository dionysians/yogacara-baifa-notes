# 无明

**无明**（梵 *avidyā*，"明"的否定）指对诸法实相（特别是无我、缘起、四谛）的根本不了知，是十二缘起之首支、一切烦恼的总根。在百法系统中，无明即根本烦恼之**痴**。

## 二种无明（唯识立场）

| | 内容 | 断除位 |
|---|---|---|
| **分别无明** | 后天邪师邪教熏习而起 | 见道顿断 |
| **俱生无明** | 无始任运而起，与第七末那相应 | 修道渐断，至佛地究竟断 |

俱生无明与末那俱起、恒缘阿赖耶为我，是俱生我执的认知基础。

## 与痴 / 无痴的关系

- **痴** = 根本烦恼心所，即无明
- **无痴** = 善心所，对治痴

无明非"知识不够"，而是对**实相**的迷暗——可以世间博学却仍具足无明。无痴亦非"知识丰富"，而是对**理事如实明解**。
