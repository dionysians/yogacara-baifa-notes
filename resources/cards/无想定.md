# 无想定

**无想定**(梵 *asaṃjñi-samāpatti*)是外道修的一种深定——以"无想"(无心想活动)为涅槃,入此定时**灭第六识及其相应心所**,心识表层活动暂停。

## 与[灭尽定](灭尽定.md)的核心区别

无想定与灭尽定都是"灭心"之定,但**根本不同**:

| | 无想定 | [灭尽定](灭尽定.md) |
|---|---|---|
| 修者 | 外道 | 圣者(三果以上) |
| 定的深度 | 深(灭第六识) | 深(灭第六识 + 染污末那现行) |
| **般若现观** | **无**——只灭现行,无无我智 | **有**——以已立的无我现观为前提 |
| 对末那[我执](我执.md) | **完全没动** | **能伏染污末那现行** |
| 出定后 | 染污如旧 | 圣者智不退 |

→ 同样深的定,**有没有般若决定能不能动末那的根**。**定的深度不是断惑的根据,般若现观才是**。

## "无想"被执为涅槃——长寿天难

外道修无想定者,常将"无想"误执为涅槃,死后生**无想天**(色界第四禅"广果天"中)——五百大劫无心,期满后心识恢复,见五蕴又起,因之诽谤涅槃,堕入恶趣。佛经列为**八难**之一(无想天难 / 长寿天难)。

→ 这是缺乏般若导引、单纯求定的根本风险。

## 修行学意义

无想定 vs [灭尽定](灭尽定.md)的对比,是经典对"**断惑必须止观双运、单靠定不能断根**"的最强锚——任何"只要定够深就能解脱"的暗示,都被这一对比直接驳倒。

→ 缺定的般若 = 干慧(般若停在比量)
→ 缺般若的定 = 无想定 / 邪定(只伏不断,反成所知障[增上缘](增上缘.md))

出处:《俱舍论》、《成唯识论》、《瑜伽师地论》。
