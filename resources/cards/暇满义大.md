# 暇满义大

**义大**是《菩提道次第广论》「暇满」三段——**正明暇满 → 思其义大 → 思惟难得**——的**正中一段**。它不讲"有多难得"（那是难得段），而讲**"这难得的窗口能办多大的事"**：一具暇满身能通办现前增上生 + 究竟决定胜二重大利，故当**摄取心要、莫令徒耗**。对修行者是暇满教法里最贴得动的一段——走「**求**」（表 / A 线果德侧），不走"失则堕恶趣"的恐怖侧（[修道点火 §4.3](../../notes/修行学/修道点火与遮强表弱——懈怠根诊断与欲钩双线.md) 选材校准）。

## 一、义大的骨架：一身通办现前 + 究竟

〔第一层·《广论》义大段〕核心句：

> 观待若**增上生**，若**决定胜**，义大之身。

| 二利 | 内容 | 三士道位 |
|---|---|---|
| **现前 · 增上生** | 断恶修善、如理取舍 → 来生胜今生、生生增上 | 下士 / 中士所依 |
| **究竟 · 决定胜** | 证空性、脱生死，乃至一切智成佛 | 上士 / 究竟 |

**比量点**：义大 = 这具身"**能当办这两重不可替代的大事**"。不是它现在有多稀罕（难得段的活），是它**用途极大** → 空过即是最大浪费。

## 二、摄取心要：莫令此身徒耗

〔第一层·《广论》义大段〕

> 应当作是念，而发欲乐**摄取心要**，谓若使此身为恶行者，是**徒耗费**，应修正法而度时期。

**逐句比量**：

| 原文 | 比量点 |
|---|---|
| 发欲乐摄取心要 | 义大的落点是**发欲**（欲钩）——不是吓，是"这么大用途别浪费"引出的**求**（接 [欲](../../notes/03-心所法/别境心所/欲.md) / A 线果德侧欲钩） |
| 若使此身为恶行者，是徒耗费 | 反面警策走**机会成本**（"徒耗"）而非**堕落恐吓**——对命好者钩得动的那一路 |
| 应修正法而度时期 | 结论是正向"当修"，不是"否则如何" |

## 三、人身筏喻：能渡大苦海（义大的经典影像）

〔第一层·《广论》引寂天《入菩萨行论》〕

> 由依**人身筏**，当度大苦流，此筏后难得，愚莫时中眠。

**逐句比量**：

| 喻 | 法 | 比量点 |
|---|---|---|
| 人身筏 | 暇满身 | 身是**渡河的工具**（工具义 = 义大：不为它本身、为它能载你过河） |
| 当度大苦流 | 渡生死苦海（决定胜） | 筏的**用途**极大 → 这是"义大"的影像化 |
| 此筏后难得 | 暇满难再得 | 义大**接住难得**（用途大 × 稀有 = 双钩，[暇满难得](暇满难得.md)） |
| 愚莫时中眠 | 得筏不渡 = 睡在筏上 | **有窗口不用 = 睡在渡船上**——精进的反面（懈怠）被点名；接 [§3.5 不进则退](../../notes/修行学/修道点火与遮强表弱——懈怠根诊断与欲钩双线.md) |

**核心比量**：筏喻把义大讲成**工具-用途**结构——不夸身本身，夸"它能载你过那条你必须过的河"。这正是 A 线果德侧的钩法（求那件不可替代的大事），非恐怖侧。

## 四、玛卡喀喻：得之当生欢喜

〔第一层·《广论》博朵瓦（bo do wa）〕博朵瓦以"**玛卡喀**"（一座久已失去、复又寻回的古楼房 / 宝宅）故事设问——久失复得当生何等欢喜；结句：

> 今得暇满，亦应获得如是欢喜，而修正法。

**比量点**：义大不止是"该修"的**义务感**，更是"这么好的东西到手了"的**欢喜**——欲钩的正向情绪面。对信德冷质地的修行者，此条走"**理上认到用途之大 → 生取用之乐**"，非煽情。

## 五、对修行者：义大 = A 线果德侧的点火燃料

- **走"求"不走"怕"**：义大讲"能办大事"（表 / 果德侧）；堕恶趣恐吓（相 / 恐惧侧）对修行者冷、收效弱——义大是暇满四角（自性 / 义大 / 难得 / 长寿天难）里**最钩得动**的一角（[修道点火 §4.3 §4.4](../../notes/修行学/修道点火与遮强表弱——懈怠根诊断与欲钩双线.md)）。
- **与难得对接**：义大（用途大）× 难得（窗口稀）= 双钩；筏喻"此筏后难得"一句同时挂两头。
- **与 §3.5 对接**：义大 = A 线**果德侧点火燃料**，喂结构性胜解（理型），**非造紧迫感**（相型·修行者做不了）；"愚莫时中眠"= 有窗不渡 = [§3.5 不进则退](../../notes/修行学/修道点火与遮强表弱——懈怠根诊断与欲钩双线.md) 的道次第原话对应。
