# 我执

**我执**指于五蕴假合身心上执有一独立、常一、主宰的"我"。是一切烦恼的根本，所障为涅槃，故名**烦恼障**。与执法实有的**法执**（所知障）并立。

## 分别我执 vs 俱生我执

唯识严分二种：

| | 分别我执 | 俱生我执 |
|---|---|---|
| 起因 | 后天受邪师邪教邪思惟熏习 | 无始以来任运而起 |
| 表现 | 显粗，可被反思识别 | 微细，不待思惟自然现行 |
| 所依 | 主要在第六意识 | 第六意识 + 第七末那识皆有 |
| 断除位 | **见道**位顿断 | 修道位渐断，至阿罗汉 / 八地菩萨究竟断 |

## 末那与俱生我执

末那识恒缘阿赖耶识见分为"我"，恒审思量，是**俱生我执**最深层的发动机。第六识能起的"我相"是末那现行的表面化——第六识不能直接断末那俱生我执，需见道时无漏智现前才能撼动。
