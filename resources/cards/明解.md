# 明解

[无痴](../../notes/03-心所法/善心所/无痴.md) 心所的体性——**于诸理事，明解为性**（《成唯识论》卷六）。

## 与"理解"的区别

- **理解**：意识层的命题性把握（"我懂这个道理"）——属比量层 / 慧的简择产物
- **明解**：**如实见的稳态**（不被颠倒覆盖）——属现量层 / 心所现行
- 明解必须**驱动作善**（窥基 slot 业用项），不能停在"我知道应该这样"

→ 明解 = 现量层稳态，不是比量层产物。这是无痴 ≠ 慧的精确锚点（慧通三性，可纯比量；无痴必现行作善）。

## 双层含义

明解涵盖：

1. **于理明解**：对佛法义理（[四谛](四谛.md) / [十二缘起](十二缘起.md) / 二空真如 / 唯识中道 / 缘起性空等）的如实见
2. **于事明解**：对世间事相（因果业报、根境识三和合、五蕴差别等）的如实见

→ 理事不离——理在事中显，事不离理而立。

## 修行学含义

修行者达到明解的轨迹（"闻思 + 禅定双支撑"path）：

| 层级 | 心所配置 | 状态 |
|---|---|---|
| 闻思想通 | 慧（简择已成）| 比量层完成 |
| 定中持守 | 慧 + 无痴形成俱起 | shift 进行中 |
| 事件场所缘到来时如实见自动升起 | 无痴现行（明解稳态）| shift 完成 |

→ "想通"是 sign，"明解作为现量稳态"才是 target（[假说 17](../../CLAUDE.md#跨阶段回填清单)）。

## 与"了无自性"/"所有错=无知"的关系

明解作为现量稳态可由不同 anchor formulation 承载——修行者本人的双 anchor：

- **了无自性**（ontological 层 anchor）：处理现象层执着的不实
- **所有错=无知造成的**（actor / 因果层 anchor）：处理错的根因 = 痴根

→ 二者**互补不重合**，共同构成 State D（烦恼起 + 双 anchor 同步覆盖痴根 + 立刻放下）的精确机制。
