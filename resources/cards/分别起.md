# 分别起

**分别起**（烦恼）指依赖**概念框架**（邪教、邪思惟、后天推理）才能现行的烦恼。与[俱生](俱生.md)烦恼相对。

## 核心特征

| | 分别起 | [俱生](俱生.md) |
|---|---|---|
| 现行依什么缘 | 概念框架（邪教/邪思惟） | 种子力本身，不需概念支撑 |
| 识层 | 只在第六识 | 第六识 + 末那 |
| 断位 | [见道](见道.md)断 | [修道](修道.md)渐断 |

## 关键精确化

分别起与俱生的区别**不在形成时间**（后天 vs 与生俱来），在**现行机制**——分别起烦恼依赖概念框架才能现行，见道摧毁概念框架后种子永远失去现行的缘，故种子断。

## 见道为什么能断

[见道](见道.md)的根本无分别智**摧毁分别起烦恼赖以现行的概念基础设施**——不是"从此不再新增"，是种子本身断（现行的缘永远不再具足）。
