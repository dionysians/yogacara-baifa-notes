# 相应

**相应**（梵 *saṃprayukta*）是佛教法相学描述**心王与心所、或心所与心所之间同时同境同行的关系**的术语。两法"相应"即两法同时生起、同依一根、同缘一境、同一个行相——不是因果先后关系，而是一刹那内共起、协同运作的关系。

## 相应的四个条件

唯识学立**四义平等**作为相应的判准：

1. **时平等**——同一刹那生起，不是前后
2. **所依平等**——依同一个心王或同一个根
3. **所缘平等**——缘同一个境（[所缘](所缘.md)同）
4. **事平等**——同一个行相、同一个运作

四义齐备，方称相应。这比"同时出现"严格得多——同时出现的二法可能各自缘不同境、依不同根，就不算相应。

## 相应的典型场景

### 心王 ↔ 心所
最常见的相应关系。如眼识生起时，必与触、作意、受、想、思五遍行心所相应——眼识缘色的同时，五个心所也同缘此色、同依眼根。

### 心所 ↔ 心所
同一刹那被同一心王所带动的诸心所，彼此也是相应关系。如眼识带起触+作意+受+想+思，则这五个心所互相之间也相应。

## 五位百法中的"心相应行"

百法分五位：
- 心法 8
- 心所有法 51
- 色法 11
- **心不相应行法 24**
- 无为法 6

"心所"又称"心相应行"——即**与心相应而起的行**（行 = 有为法、造作法）。这与"**心不相应行法**"形成对照——后者是既非心、非色、又不与心相应的假立法（如得、非得、众同分、命根等）。

这里的"相应"正是本卡所论之义。

## 心所彼此之间的相应限制

不是任何两个心所都能相应——有些心所彼此**决定不相应**：

- **善心所 与 根本烦恼心所**——不能同起（善恶不俱）
- **疑 与 胜解**——不能同起（疑是不决定，胜解是决定）
- **散乱 与 定**——不能同起（一散一专一）

理解哪些心所能/不能相应，是分析心识状态的重要工具。

## 修行意义

抓住相应关系是**辨识心理状态**的关键——很多时候自己辨不清当下是什么心所在主导，可以通过"与什么相应"来反推：

- 若当下心中有追悔、有不安 → 可能是"悔"心所与"不善根"相应
- 若当下心中有明记、有专一 → 可能是"念"与"定"相应
- 若当下心中有轻安、有明晰 → 可能是"轻安"与"慧"相应

这种**通过相应关系反推心所主导状态**的方法，是唯识修行的实用技艺之一。
