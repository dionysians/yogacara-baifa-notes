# 五果

**五果**是唯识 / 阿毗达磨对业种子变现果报的五重分类——**等流果、异熟果、增上果、士用果、离系果**。出《成唯识论》《瑜伽师地论》等。

## 五果分类

| 果 | 内涵 | 举例（以害业为例）|
|---|---|---|
| **等流果**（同类相续）| 因果同类——善因感善习、恶因感恶习；同类种子越熏越厚 | 起害心一念 → 下次更易起害心 |
| **异熟果**（异时异类）| 跨世果报——善恶因经长时间感招中性的（无记的）果报身/境 | 累积害业 → 感招短寿、多病、易遭怨憎会 |
| **增上果**（共业感招）| 共业层面的环境感招 | 害业累积 → 所处环境多冲突、暴力 |
| **士用果**（当下作用）| 因当下直接造作的结果 | 起害心外显成行为 → 立即造成对方苦受 |
| **离系果**（择灭涅槃）| 由智慧断烦恼所得的解脱果——不属业感 | 见道断分别我执后所得的择灭 |

前四果通业感（与种子-现行机制相关），第五果属解脱道果（与对治智相关）。

## 等流果 vs 异熟果——最易混淆处

两者都是种子-现行机制的果报形态，但运作机制根本不同。

| 维度 | 等流果 | 异熟果 |
|---|---|---|
| 因果类型 | **同类**（善因感善习、恶因感恶习） | **异类**（善/恶因感**无记**果） |
| 时间 | **同时或近时**（这一念熏种 → 下一念现起更易） | **异时**（跨世——今生熏种、来世或更远世感果） |
| 体性 | 与因同性（恶心生恶习）| 与因异性（善恶因 → 中性的果报身/境）|
| 现量观察 | 可直接观察（"上次起嗔下次更易起"）| 不可直接观察（需信因果） |
| 在修行学的位置 | "事件层每次现行都在累积"的精确机制 | "今生为什么生此身、遇此境"的因果说明 |

**关键的概念难点——"异时异类"的精确含义**：

异熟果的"异类"是因（善/恶）→ 果（无记）的**性质转换**。为什么是无记？因为果报身体本身没有善恶——身体不是"善身体/恶身体"，它只是"业感的载体"。短寿、多病、生在战乱地——这些境本身**是中性**的（无记），它们只是恶业种子在缘成熟时变现的舞台。是这个**舞台**让恶业的等流果有更多现行机会。

→ 所以等流和异熟是**协同运作**的：异熟果提供"果报身/果报境"（舞台），等流果在这个舞台上让"同类心所反复现起"（演员）。一个恶业种子既感招"易遭怨憎会"的境（异熟），又让"在此境中起嗔的频率/强度增加"（等流）。

**举例对照**：
- 一念嗔心熏种 → 下次类似境再现时嗔更易起、起得更厚 = **等流果**
- 长期累积嗔业 → 来世感招多病、短寿、所处环境多冲突的果报身/境 = **异熟果**
- 在那个果报身/境中，嗔仍然更易起 = **等流果在异熟舞台上的现行**

**为什么经典分立两果**：单一种子机制不足以解释两种不同现象——"为什么此生我嗔越来越容易起"（等流，可观察）与"为什么我生在这样的身境"（异熟，不可观察）属不同因果通道，需分别安立。

## 与无嗔 / 害的关系

[无嗔](../../notes/03-心所法/善心所/无嗔.md) §九 用五果中前四果分析"害种子的变现"与"修无嗔的反向四果动力学"——每一念无嗔现行都同时熏入无嗔种子，通过等流果让下次更易起、通过异熟果跨世感招慈悲场境、通过增上果改变所处环境共业密度、通过士用果当下不损恼受者。
