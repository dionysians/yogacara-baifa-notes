# 可意境 / 不可意境 / 中庸境

唯识对所缘境的三分分类——按引发的受相属性区分：

| 境 | 引发受相 | 末那典型反应 | 对治善根 |
|---|---|---|---|
| **可意境**（顺境）| 乐受 | 黏著（贪）| 无贪 |
| **不可意境**（违境）| 苦受 | 损恼（嗔）| 无嗔 |
| **中庸境** | 舍受（不苦不乐）| 不察（痴 / 无明）| 无痴 |

## 关键性质：关系属性而非客观属性

可意 / 不可意 / 中庸**不是境的客观属性**，是**境与心识的关系属性**——同一所缘对不同有情、不同时刻可能落在不同分类：
- 一杯咖啡：对爱咖啡者可意，对过敏者不可意，对从未喝过者中庸
- 同一句话：因文化背景 / 心境 / 既往经验差异，可意 / 不可意 / 中庸不同

决定可意性的因素：
1. **业感（异熟果）**：决定大致苦乐倾向（果报身禀赋）
2. **末那"我所"投射**：决定具体爱憎方向（我所认同→可意；我所排斥→不可意）
3. **当下心识状态**：决定阈值（疲惫 / 散乱时阈值降低）

## 与三毒 / 三善根的对偶

三类境严格对应三受、三毒、三善根，构成末那"我所"对所缘反应模式的全覆盖结构——见 [无嗔.md §三](../../notes/03-心所法/善心所/无嗔.md)（项目内第三层假说，待校准）。
