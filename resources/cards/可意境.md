# 可意境 / 不可意境 / 中庸境

唯识对所缘境的三分分类——按引发的受相属性区分：

| 境 | 引发受相 | 末那典型反应 | 对治善根 |
|---|---|---|---|
| **可意境**（顺境）| 乐受 | 黏著（贪）| 无贪 |
| **不可意境**（违境）| 苦受 | 损恼（嗔）| 无嗔 |
| **中庸境** | 舍受（不苦不乐）| 不察（痴 / 无明）| 无痴 |

## 关键性质：关系属性而非客观属性

可意 / 不可意 / 中庸**不是境的客观属性**，是**境与心识的关系属性**——同一所缘对不同有情、不同时刻可能落在不同分类：
- 一杯咖啡：对爱咖啡者可意，对过敏者不可意，对从未喝过者中庸
- 同一句话：因文化背景 / 心境 / 既往经验差异，可意 / 不可意 / 中庸不同

决定可意性的因素：
1. **业感（异熟果）**：决定大致苦乐倾向（果报身禀赋）
2. **末那"我所"投射**：决定具体爱憎方向（我所认同→可意；我所排斥→不可意）
3. **当下心识状态**：决定阈值（疲惫 / 散乱时阈值降低）

## 与三毒 / 三善根的对偶

三类境对应三受、三毒（贪 / 嗔 / 痴），但**严格三角对偶在 2026-05-03 已校准为不严格**：

- **可意境 / 不可意境**与贪 / 嗔的对应在反应面上结构平行（无贪 / 无嗔分别对治，有特定境）
- **中庸境与痴**的对应**经典上不严格**——痴的所缘是"诸理事"（不限于中庸境），痴遍贪嗔起处（"一切杂染所依"，《成唯识论》卷六）；无痴对治"诸理事的迷暗"，作所有善法的总 anchor（不限于中庸境的不察）

→ 三善根升级为**"二境对治 + 一总 anchor"的二阶结构**（[假说 15 v2](../../CLAUDE.md#跨阶段回填清单)），非平行三角对偶。详见 [无痴.md §三](../../notes/03-心所法/善心所/无痴.md)。
