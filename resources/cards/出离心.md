# 出离心

**出离心**指对三界轮回果报不希求、欲求解脱之心，是声闻乘修道的根本动力，也是大乘菩提心的基础（无出离心则菩提心难真实生起）。

## 体性 = 无贪

唯识系统中，出离心不是独立心所，是**无贪**对"三有"所缘的具体现行——对欲有、色有、无色有不染著、不希求。窥基释无贪"于有有具无著"，正涵盖出离的体性。

## 常见误解

出离心常被理解为"逃避世间"或"消极厌世"，其体性实为**不黏着**而非**逃避**：

| 误解 | 实义 |
|---|---|
| 离开世间 | 在世间但不被世间黏住 |
| 厌恶六尘 | 不被六尘染著（尘相不必排斥） |
| 弃舍责任 | 责任仍尽，但不在其中起我所执 |

真正的出离是境上不动心，不是境外求清净。

## 与 saṃvega（厌离警栗）的关系

**saṃvega**（巴利/梵 *saṃvega*，厌离、警栗、修行的紧迫感）是出离心的**动力前行**——见轮回过患、念死无常而生的"警栗逼迫感"，推动行者由放逸转向精进。其生起前行是**念死无常 / 暇满难得 / 轮回过患 / 业果不虚**（道次第共下士道思维、四念处无常观）。saṃvega 偏"逼迫动力"、出离心（naiṣkramya）偏"不希求轮回"的稳态，前者引生后者。若对无常/暇满法理"未现量通透"，saṃvega 不生 → 精进无源、易堕懈怠。
