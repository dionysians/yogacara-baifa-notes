# 暇满难得

**暇满**（leisure and endowment）指**有暇修法 + 修法顺缘具足**的稀有人身——离八种无暇（[八难](八难.md)）名「有暇」，具十种圆满名「圆满」。**暇满难得**是道次第（《菩提道次第广论》）下士道开篇所修，目的是对治"易得故不知珍"、令人善用此身。

## 自性：八无暇 + 十圆满

**有暇** = 离八无暇（[八难](八难.md)：三恶趣 / 长寿天 / 边地 / 邪见 / 喑哑诸根不具 / 佛前佛后）。

**十圆满**〔第一层·《瑜伽师地论·声闻地》，《广论》卷二引〕：

- **五自圆满**（自身具足）：① 得人身 ② 生于中土（有佛法、四众处）③ 诸根具足 ④ 不堕边业（未造无间）⑤ 于正法处生净信。
- **五他圆满**（外缘具足）：① 佛降世 ② 佛说正法 ③ 教法住世 ④ 法住随转（有随学者）⑤ 他具悲愍（有施主供资具）。

> **比量第一招 = 化笼统为可数**：把抽象的"珍贵"还原成 **18 个可逐条核验的条件**（八无暇 + 十圆满），"难得"从感叹变成可清点的结构。

## 义大：这窗口能办不可替代的大事

〔第一层·三士道义〕此暇满身能办增上生 / 决定胜 / 乃至一生成佛，"较如意宝尤为难得"。修此一门走「**求**」（正面欲钩、果德侧），不走「失则堕恶趣」（恐怖侧）。

## 难得三门

| 门 | 比量 | 依据 |
|---|---|---|
| **因门** | 暇满须净戒为本 + 施等助善 + 净愿回向为因；众生多造恶、鲜修此因 → 因稀果稀 | 《广论》 |
| **数量门** | 恶趣众生如大地土、善趣如爪上尘 | [爪上土喻](爪上土喻.md) |
| **喻门** | 盲龟百年一浮、颈恰入风飘木轭孔 | [盲龟喻](盲龟喻.md) / 入行论 / 亲友书 |

连"修福之念"都罕如闪电（《入菩萨行论》浓云夜中刹那闪电喻）。**现量无"稀缺"者（命好），难得全靠比量** → 喻 = 比量代现量的脚手架。

## 长寿天难 = 福报即障

[八难](八难.md)之「长寿天难」明文：天人福报极大、寿命极长、一切舒适有序 → **反不生出离心、无缘闻法**。说明**福报本身不是解脱条件、甚至可能成障**——是"暇满"判摄里对"舒适消解出离"的经典命名。对福报优渥者，此条比"堕恶趣恐吓"更对治得动（走结构反转之理、不走恐惧之相）。
