# 取

**取**（梵 *upādāna*）是[十二缘起](十二缘起.md)第九支，即[爱](爱.md)（初起染著）增长后的追逐执取——染著的扩张形态。

## 四取

| 取 | 内容 |
|---|---|
| **欲取** | 向感官方向扩张——执取五欲 |
| **见取** | 向知见方向扩张——执取邪见 |
| **戒禁取** | 向仪式/方法方向扩张——执取非因计因的戒律仪式 |
| **我语取** | 向自我叙事方向扩张——执取"我"及我所 |

## 与爱的关系

爱 = 初起染著；取 = 染著增长为追逐执取。两者是同一[贪](../../notes/03-心所法/烦恼心所/贪.md)在两个时点的展开。

## 与染著扩张性的对接

取的四类是**染著扩张性在经典中的精确展开**——扩张不只朝一个方向，而是同时向感官、知见、方法、自我叙事四个方向蔓延。
