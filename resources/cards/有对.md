# 有对

「对」谓障碍、拘碍。有对即有质碍，二物不能同处；无对则无此拘碍。与「有见 / 无见」（是否为眼所见）交叉，构成色法的经典三分。

《俱舍论》卷二引契经，逐处给出判属：

> 「眼谓内处四大种所造净色，有色无见有对，乃至身处广说亦尔。……色谓外处四大种所造，有色**有见有对**。声谓外处四大种所造，有色**无见有对**。香味二处，广说亦尔。触谓外处，是四大种及四大种所造，有色无见有对。」

法处所摄色则属第三类，《大乘五蕴论》说无表色「**无见无对**」，《显扬圣教论》卷一说法处所摄色「一切时意所行境，色蕴所摄，无见无对」。

三分因而是：

| 类别 | 所摄 |
|---|---|
| 有见有对 | 唯色境一法 |
| 无见有对 | 五根、声、香、味、触 |
| 无见无对 | 法处所摄色 |

这个三分不是注疏的整理，而是经论自带的判属维度，因此可以直接充当色法单法拆解的一个固定槽位。它同时揭示一个容易被忽略的事实：五根是**有对**的（有质碍的色），不是抽象的能力或功能概念——尽管唯识另有「识上色功能名五根」的判法，两说的会通须在五根单元处理。

「有对」在阿毗达磨中另有障碍有对、境界有对、所缘有对三义的细分，此处取其最通行的障碍有对义。
