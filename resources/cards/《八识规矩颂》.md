# 《八识规矩颂》

传为玄奘所造的颂文，将八识分四组（前五识 / 第六识 / 第七识 / 第八识），每组十二句，概括各识的三性、三量、三境、界地、心所相应、转依成智等——是唯识心识论的袖珍纲要，后世注疏极多（如憨山、蕅益诸解）。

## 本项目常引处

前五识颂首二句「**性境现量通三性，眼耳身三二地居**」后的心所相应句「**遍行别境善十一，中二大八贪嗔痴**」——前五识相应心所三十四（遍行五 + 别境五 + 善十一 + 中随二 + 大随八 + 贪嗔痴三）。散乱精修中用以厘清"五识有定心所俱起"与"五识于内静定无功能"（自性散乱借名）是两个层次。
