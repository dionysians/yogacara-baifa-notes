# 俱起

**俱起**(梵 *saha-utpāda*)指**两法或多法在同一刹那同时生起**的事实。是法相分析中的基本时间关系术语,主要用于描述心王、心所的同刹那共起。

## 与[相应](相应.md)的关系

"俱起"是基础事实,[相应](相应.md)是更严格的结构关系:

| | 俱起 | [相应](相应.md) |
|---|---|---|
| 含义 | 同刹那生起 | 五义平等(时、依、缘、行相、事) |
| 严格度 | 低(只要时同) | 高(五义齐) |
| 关系 | 相应必俱起 | 俱起不必相应 |

- [相应](相应.md) → 必然俱起(同时是必要条件)
- 俱起 → 不必然相应(两法可同时起但缘不同境)

实际唯识文本中,"俱起"在心王-心所、心所-心所语境下,因为它们自动满足相应条件,所以"俱起"和"相应"常被替换使用。但在严格分析时,"俱起"专指**时同**这一层,不含其他四义。

## 在烦恼分析中的典型用法

烦恼之间的"俱起"关系是分析心识状态的重要工具:

- **贪俱痴**——贪起的同刹那痴也起
- **嗔俱痴**——嗔起的同刹那痴也起
- **慢俱痴**、**疑俱痴**、**见俱痴**——同例

→ 所谓"痴遍贪嗔起处"、"痴为一切杂染所依",在"俱起"这一层有精确表述:**根本烦恼现行时,痴必与之俱起**(以[相应](相应.md)义)。

## 与[所依](所依.md)的区别

俱起是**时间关系**(同刹那),[所依](所依.md)是**依托关系**(谁依谁起)。两者可以共存但是不同维度:

- 心所与心王既[相应](相应.md)俱起,又以心王为[所依](所依.md)
- 但"俱起"本身不蕴含"依托"——两法可同时起而无依托关系

法相分析中"俱起"与"[所依](所依.md)"必须分判,不可混用。

出处:《俱舍论》、《成唯识论》。
