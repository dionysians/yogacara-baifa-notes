# 依他起

**依他起**（梵 *paratantra-svabhāva*）是[三性](三性.md)中的第二性——指**依托众多他缘而起**的存在方式。任何现象都不是自己孤立地存在，而是由因缘和合而成；这种"依他而起"的性质本身就是一种存在方式。依他起 = 缘起。

## 核心特征

1. **缘起有**——确实存在，不是虚无（区别于[遍计所执](遍计所执.md)之纯妄）
2. **无独立自性**——不是自己决定自己，依赖他缘（区别于外道实体观）
3. **虚妄分别所摄**——有漏位的依他起被遍计所执染污而显现
4. **[圆成实](圆成实.md)所依**——圆成实不离依他起；真如即是依他起上的远离遍计所执

## 绳喻中的位置

绳蛇喻中：
- **蛇**——[遍计所执](遍计所执.md)，本无
- **绳**——依他起，由麻缕因缘而成，假有
- **麻**——[圆成实](圆成实.md)，绳的实质

绳**作为绳的相**是依他起——它不是蛇（假相是遍计执），也不是孤立实体（麻缕合而为绳）。

## 染净依他起

依他起本身不是染也不是净，关键看它**上面有没有[遍计所执](遍计所执.md)**：

| 状态 | 现起的相 |
|------|----------|
| **染污依他起** | 依他起 + 遍计所执 = 凡夫所见的虚妄境 |
| **清净依他起** | 依他起 - 遍计所执 = 圣者所见的如实境（即圆成实的展现） |

因此修证不是"消灭现象"，而是**在现象上去除妄执**——现象仍在，但不再被误认为独立实体。

## 心识与依他起

唯识学的核心主张之一：**一切法唯识所现，一切识相皆是依他起**。

- 八识、心所、相分见分——皆是依他起
- 它们由种子、作意、所缘等众缘而起
- 没有任何法是"独立自存"的，哪怕阿赖耶识也是恒转如瀑流

这就把依他起与唯识论牢牢绑定：唯识论 = 一切法都是依他起缘起的识变现，遍计所执是错认、圆成实是其实相。

## 修证上的意义

- 观依他起即缘起——破执
- 观依他起本无[遍计所执](遍计所执.md)——显二空
- 证依他起即圆成实——入真如
- [转识成智](转识成智.md)所缘转变的核心：从"染污依他起"转到"清净依他起"
