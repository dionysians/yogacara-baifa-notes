# 末那（manas · 第七识）

**末那**是唯识八识中的第七识，梵文 manas（意 / 思量）。其核心功能是**恒审思量**——恒时审察思量第八识阿赖耶识的见分为"我"。是俱生我执的发动机，也是凡夫位"我"感的最深结构性来源。

## 核心特性

唯识立末那两个核心特性：

- **恒**：恒时现行，不间断（区别于第六识有间断）
- **审思量**：审察思量第八识见分为"我"

→ 二者合为"**恒审思量**"。

## 末那的所缘 = 自内我

末那恒缘第八识见分为"我"（不缘外境）。这决定了末那的烦恼配置：

- 末那四烦恼："**我痴 + 我见 + 我慢 + 我爱**"
  - 我痴 = 不见缘起无我（恒行不共无明）
  - 我见 = 执见分为"我"（= 俱生身见 / [萨迦耶见](我执.md)）
  - 我慢 = 在"我"上起自抬
  - 我爱 = 对"我"的染贪着

→ 这四烦恼**恒时与末那俱起**，凡夫位无间断。

## 末那两核心特性各排除一个烦恼

[假说 12](../../notes/假说/假说-12-惭愧末那二维辐射.md) 揭示：嗔与疑都不通末那，分别因末那两个核心特性排除：

| 末那核心特性 | 排除的烦恼 | 机制 |
|---|---|---|
| **摄受**（恒缘自内我，非推拒）| 嗔 | 嗔的"推拒"方向与"摄受"对反 |
| **恒决了**（恒审思量之"审"）| 疑 | 疑的"犹豫"与"恒决了"对反 |

## 末那的"附着"作用（2026-06-XX 精化）

恶见精修中揭示末那"摄受"特性的精确机制层 = **"附着"作用**——末那把"我"隐性附着到对象上：

| 末那附着的对象 | 显现 |
|---|---|
| 第八识见分（五取蕴）| 俱生身见 / 末那俱生我执 |
| 结构 / 法尘 | 法贪 + 末那附着 → "我所立"隐性形态 |
| 见地 / 立场 | 见取见 |
| 境 / 现象 | 慢的"举我" |

→ 末那"附着"作用是身见 / 见取见 / 慢 / 法贪共同根机制。

## 断除位次

- **末那"我见 / 我慢 / 我爱 / 我痴"**：与末那俱生我执同位次
