# 布施波罗蜜

**布施波罗蜜**为大乘六度（六波罗蜜）之首，指以**三轮体空**摄持的布施，能令行者超越生死、到达涅槃彼岸（pāramitā = 到彼岸）。

## 三类布施

经典通常分三：

| 类 | 内容 |
|---|---|
| **财施** | 内财（身命）、外财（资具）的施与 |
| **法施** | 以正法饶益众生 |
| **无畏施** | 救护众生离怖畏 |

## 体性 = 无贪

布施波罗蜜的心所体性是**无贪**——施时不染著施者、施物、受者，即三轮体空。无三轮体空摄持的布施只是世间福行，不成"波罗蜜"。

## 内 / 外双层

[无贪](../../notes/03-心所法/善心所/无贪.md) 笔记 §六 中扩展："作善"的双层覆盖让施不只是 outer（财 / 法 / 无畏），也包括 internal——定中让心识不抓住任何所缘，本身就是无贪现行的密集场域，构成内层的"自施"（不黏所缘）。这与修行者"闻思 + 禅定"path 中"定中持守看穿"是同一回事。

## 与其他五度的关系

持戒、忍辱、精进、禅定、般若——皆需无贪体性贯穿，否则各度都可能被我所贪所染。布施列首，亦因其最直接显现"舍我所"。
