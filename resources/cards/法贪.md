# 法贪

**法贪**指对法尘（特别是精巧的概念结构、见解结构、知识体系）的俱生贪着，是贪心所在法尘层的具体形态。与欲界五尘贪（物质 / 身体感受贪）相对。在唯识传统中接近"名言种子贪"，结构上等同 [法执](法执.md) 的一个具体显现。

## 精确机制（恶见精修中现量分诊揭示）

修行者通过现量分诊揭示**"我提出的结构很精彩 → 涌起喜悦" 序列在事件场几乎不组成完整链**，实际现行的是三种心所细分：

| 心所 | 染净 |
|---|---|
| 慧 + 胜解俱起（结构形成时的确认感）| 无染 |
| 信增强（感悟佛理后）| 无染 |
| **对精巧结构的俱生贪** | **染 = 法贪** |

→ 法贪的精确机制 = **对法尘的俱生贪 + [末那](末那.md)隐性把"我"附着到结构上 → "我所立"隐性形态**。

## 修道位

色界 / 无色界仍有法贪 → **修道渐断**范围。即使破欲界五尘贪，法贪仍可在色界 / 无色界微细现行。

## 慧根利者的特殊风险

法贪在慧根利者位置上特别危险：

- 越聪明 → 越能构建精巧结构 → 法贪所缘越多
- 法贪伪装为善法欲 → 持续驱动闻思追求 → 与实修慢节奏抢占心识
- → CLAUDE.md 路径风险 #4（闻思快奖励对实修慢节奏的隐性厌恶）**机制层闭合**

## 法染色层主战场命题

法贪 + 末那附着 + L4 位置慢复合 + [法嗔](法嗔.md) + 微细谤圣贤 = **法染色层统一现行结构**（恶见精修中揭示）。

→ 慧根利者方便层瓦解后必然出现法染色层主战场（[假说 14](../../notes/假说/假说-14-方便层瓦解普遍性.md) 2026-06-XX 升级）。
