# 我痴

**我痴**（梵 ātma-moha，又作我无明）是末那识（第七识）恒常相应的**四根本烦恼**之一，指迷于"无我"之理的根本无明——不了"我"本无自性，默认有一个实有的自我中心存在。它是末那四惑的**前导**，其余我见、我慢、[我爱](./我爱.md)皆依之而起。

## 在末那四惑中的根本地位

《成唯识论》卷四：第七识恒与「我痴、我见、我慢、我爱」四惑相应。四者次第——因**我痴**（不了无我）→ 起我见（执有实我）→ 于此实我起我慢（高举）与我爱（贪着）。故我痴是俱生我执的总根，亦即"痴为诸烦恼根本"在末那层的具体落处。三毒内在次第 **痴 → 贪 → 瞋** 即由此展开。

## 作为"实我中心"的运行

我痴的现行形态 = **默认以"我"为实有中心**，一切境界都绕这个原点被重新加工：

- 顺我所爱者 → 贪
- 违我所爱者 → 瞋
- 把"他人有"读成"我损"（如嫉）、把"我胜他"读成实有的高下（如慢）——都是实我中心在不同朝向上的运行

→ 凡"避免不了把我拿来对比"的场景，底层都是我痴在运行。

## 修行学含义

我痴属俱生无明，唯无我慧（了无自性）现量照破方能渐伏渐断，非见道一时顿除，乃修道乃至转依所断。对治的总钥匙是"了无自性"——实我中心一旦被照破，依之而起的我见 / 我慢 / 我爱及一切贪嗔分位（慢 / 憍 / 嫉等）同失所依。
