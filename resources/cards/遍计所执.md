# 遍计所执

**遍计所执**（梵 *parikalpita-svabhāva*）是[三性](三性.md)中的第一性——指**周遍计度、妄执为实**的那种存在方式。"遍"即周遍一切处；"计"即分别计度；"所执"即被执取的相。合起来：凡夫以分别心周遍地在一切法上计度执着、认为其有独立实体——这种执着所现起的相，就是遍计所执。

## 核心特征

1. **本来无**——遍计所执的对象**根本不存在**，纯是妄情所计
2. **执为实**——但凡夫却把它当成真实独立的存在
3. **一切染污之根**——烦恼、业、生死轮回，皆以遍计所执为起点

## 绳蛇喻

唯识学最常用的比喻：
- 暗中见绳，错认为蛇
- "蛇"即遍计所执——根本不存在，纯是错觉
- 不是"有蛇但不真实"，而是**从来没有蛇**

注意：这区别于[依他起](依他起.md)——绳本身是依他起（由麻缕因缘成），绳的相不是遍计所执。遍计所执是在绳上计度出来的"蛇"。

## 两种遍计所执

唯识学进一步分：

| 分类 | 内容 |
|------|------|
| **能遍计** | 能作计度的心（第六识、第七识） |
| **所遍计** | 被计度的境（一切[依他起](依他起.md)之相） |
| **遍计所执** | 在所遍计上被计度出来的妄相（我、法二执） |

注意：能遍计的**心**本身是依他起，不是遍计所执；它在境上**计出**的"独立我"与"独立法"，才是遍计所执。

## 与二障的对应

- **我执**（末那对阿赖耶识见分的执"我")→ 遍计所执之一
- **法执**（意识对一切境相的执"实")→ 遍计所执之一
- 二者是**烦恼障**与**所知障**的根本

## 修证上的意义

- **见道位**证[圆成实](圆成实.md)，第一次断除一部分分别起的遍计所执
- **修道位**渐断俱生起的遍计所执
- **究竟位**彻底断尽，圆成无上菩提

[转识成智](转识成智.md)的核心正是遍计所执的消除——识转为智，不是识"变"了，而是识所缘的遍计所执相脱落，现依他起与圆成实之实相。

## 与中观"无自性"的关系

[中观](中观.md)说"诸法无自性"——这里的"自性"即相当于遍计所执义上的独立实体。二者立义相通，但唯识学进一步明确**"什么法"无自性**（遍计所执），同时肯定**依他起与圆成实并非全无**（相有、性有）。这是唯识对中观的精细化。
