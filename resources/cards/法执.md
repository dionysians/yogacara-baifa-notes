# 法执

**法执**指执一切法（现象、教法、概念）为实有自性的执着，是与**我执**并立的二种根本执着之一。法执所障的是所知（一切法的真实相），故又名**所知障**；我执所障的是涅槃，名烦恼障。

## 二执对比

| | 我执 | 法执 |
|---|---|---|
| 所执 | 五蕴假合上立"我" | 一切法（含五蕴本身、教法、修行、佛果）上立自性 |
| 所障 | 涅槃（烦恼障） | 所知（所知障） |
| 断除位 | 阿罗汉断尽 | 仅佛地究竟断尽 |
| 微细度 | 较粗 | 极细 |

## 分别 vs 俱生

法执亦分两类：

- **分别法执**：依邪师邪教邪思惟而起，**见道**位顿断
- **俱生法执**：无始熏习、任运而起，修道位渐断，**佛地**究竟断

## 与求成佛贪的关系

[无贪](../../notes/03-心所法/善心所/无贪.md) §七 中，"求成佛贪"被诊断为最精微的法执变形——把"成佛"做成实有可求之法，把"修行"做成实有的自我延伸。此种贪的体性与粗境贪同（皆是末那把对象做成"我所"），但种子势力厚度极大，需长劫对治；凡夫位看清是必要的，但不应期望看清等于消解。
