# 唯识闻思 + 实修 学习引擎（以《大乘百法明门论》为开篇）

> **项目本质**：一台以唯识为骨架的 **闻思 + 实修** 双轮学习引擎。
> **开篇教材**：《大乘百法明门论》（世亲菩萨造，玄奘译）。
> **起始日期**：2025-11-03｜**状态**：活跃（心所法 · 烦恼阶段 + 实修起步期）
>
> 本文件定义**项目的范畴与身份**（稳定、罕变）。每次会话的 operational 规范（学习者画像、当前阶段、回填清单、实修状态）见 [`CLAUDE.md`](CLAUDE.md)——那是工作时的唯一真理来源；本 README 只回答"这个项目是什么、边界在哪、如何演进"。

---

## 一、这个项目是什么

它**不是**一个"读完一本论就结束"的读书项目。它在学习《百法》的过程中，逐步长成了一台**通用的唯识闻思 + 实修学习引擎**：

- **闻思轮**：以经典为教材，逐法深挖通透，严格区分经典依据与自主推论（学术诚实三层标注），并在跨域映射中建构、审视假说。
- **实修轮**：闻思所得的"见"下沉为现量——坐中修（建定）+ 生活修（看破→熏种→常态对治）+ 现量反向深化闻思。
- **双轮咬合**：闻思建见 → 定中持守下沉为现量 → 事件场验证 → 现量反向深化闻思，循环上升。

《百法》是装进这台引擎的**第一部教材**，不是引擎本身。

## 二、框架的两层（决定可扩展性）

| 层 | 绑定对象 | 是否随教材更换 |
|---|---|---|
| **方法 / 基建层** | **学习者 + 实修**——学术诚实三层标注、修行者画像 + 对治教学、实修循环（看破→熏种→常态）、假说网络、回填清单、专题索引、概念卡、各 skill | ❌ 经典无关，持续延续 |
| **内容层** | **具体教材**——单法/单章笔记、整体认知文档、阶段方法论、"当前学习阶段"指针 | ✅ 每部经典各有一套 |

方法层绑的是"学习者这个人 + 一条实修命"，不是某本书。这是项目可承载多部经典的结构基础。

## 三、项目范畴与演进规则

**当前范畴**：《大乘百法明门论》五位百法的完整闻思 + 配套实修。

**演进规则**（《百法》完整学完后）：新经典在**同一项目内**展开，遵循——

1. **方法层延续**——画像、实修循环、假说网络、三层标注等全部承接，不重起炉灶（连续性是本项目最有价值的积累）。
2. **内容层并列叠加**——新经典获得自己的顶层目录（与 `notes/03-心所法/` 等并列），各有整体认知与阶段方法论。
3. **《百法》封存为完成模块**——学完即整体封存、保持完整闭环，新经典是叠加而非交织。

**候选延伸方向**：菩萨道次第（《瑜伽师地论·菩萨地》/《菩提道次第》/《摄大乘论》等）——补"体到行法"的落地（如四摄、方便、后得智；详见生活修对治案 001 成分二）。

**到那一步时需有意识拍板的**：
- **项目命名 / 身份**——是否从"百法学习"正式重述为"唯识闻思+实修体系"（百法为开篇）。
- **内容顶层组织**——新经典目录的命名与归位。

> 以上为前瞻规划。《百法》尚未收完前不启动，相关线头登记在 CLAUDE.md「跨阶段回填清单」。

## 五、核心方法（方法层要点）

- **学术诚实三层标注**：第一层经典引用（标出处）/ 第二层经典框架的应用映射 / 第三层自主推论（明确标注，不当定论）。详见 CLAUDE.md 顶部。
- **对治教学**：基于 `reports/` 评估同步的修行者画像（核心特质 / 路径风险 / 当前缺口），每次对话针对性地对治式教学。
- **实修循环（看破 → 熏种 → 常态）**：学习者核心修行学逻辑；闻思深挖看破 → 反复熏种 → 任运现行成常态。坐中修 + 生活修对治案（`/shixiu`）双场验证。
- **假说网络**：跨域建构的第三层假说（浮尘根三层级、禅定双轴、AI 色法镜像等），在后续学习中主动寻找冲突材料审视，**经典 > 假说**。
- **回填触发机制**：跨阶段待办集中维护于 CLAUDE.md「跨阶段回填清单」，完成迁入历史归档。
