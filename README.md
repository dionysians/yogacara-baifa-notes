## 📚 项目简介

本项目旨在系统性地学习和理解《大乘百法明门论》这部唯识学入门论典，通过结构化的学习方法，建立对大乘唯识学的基本认识。

### 关于《大乘百法明门论》

- **作者**: 世亲菩萨（Vasubandhu）
- **译者**: 玄奘法师
- **性质**: 唯识学入门论典
- **核心内容**: 将一切法归纳为五位百法

### 五位百法

1. **心法** (8法) - 八识
2. **心所法** (51法) - 心理活动
3. **色法** (11法) - 物质现象
4. **心不相应行法** (24法) - 非色非心的现象
5. **无为法** (6法) - 真实法
