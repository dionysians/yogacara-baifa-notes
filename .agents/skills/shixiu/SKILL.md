# 实修日志管理与对话

本 skill 覆盖修行三层中的**坐中修**与**生活修**两条记录线，互不污染：

| 模式 | 触发 | 用途 | 文件 |
|---|---|---|---|
| 1 · 坐中记录 | 坐中数据 | 一座的反馈记录 | `实修反馈日志.md` |
| 2 · 状态对话 | "看看最近实修" | 讨论实修趋势 | （读为主）|
| 3 · 生活修对治流程 | `/shixiu life` / 生活现行困扰 | 走完看破→熏种→常态，开对治案 | `生活修对治内容.md` + `实修/logs/生活修日志/` |
| 4 · 回访 review | `/shixiu review` | 扫未闭合对治案，逐个回访 | 同上 |

## 触发条件

- 用户输入 `/shixiu`
- 用户带来坐中数据（如"记录今天实修"、"今天坐了 XX 分钟"）→ 模式 1
- 用户想讨论实修状态（如"看看最近实修情况"）→ 模式 2
- 用户输入 `/shixiu life`，或带来**生活中发生的现行困扰**（如"今天又对孩子起了害心"、"刚才评判了同事"）→ 模式 3
- 用户输入 `/shixiu review`，或"回访一下对治案" → 模式 4

## 启动时必读文件

每次触发本 skill 时，先读取以下文件建立上下文：

1. `notes/实修/实修反馈日志.md`（主日志——演化追踪表 + 监测原则 + 近期条目）
2. `notes/实修/当前修行内容.md`（当前修行计划 + 三轨结构）
3. `AGENTS.md` 中的以下章节（不需全文）：
   - "修行者基础状况"（路径风险 / 应对原则 / 操作核 / 当前核心缺口）
   - "当前修行阶段状态"（三层状态表）

按需追加读取：
- `notes/教学操作核/教学操作核-04-轻安anchor.md`（坐中体验相关）
- `notes/教学操作核/教学操作核-05-不放逸.md`（触发点 / 连续性相关）
- `notes/教学操作核/教学操作核-06-行舍.md`（三相监测 / 征兆标的分判）
- `notes/实修/logs/历史/`（坐中需深度追溯时读月归档）

**模式 3 / 4（生活修）额外必读**：
- `notes/实修/生活修对治内容.md`（对治案清单 + 当前状态——是 review 模式的扫描入口）

- 按场景追加对应操作核文件：`notes/教学操作核/教学操作核-01-亲子场无嗔.md` / `-02-嗔事件层.md` / `-03-无痴双线.md`

## 模式 1 · 记录（用户带来实修数据时）

### 步骤

1. **读取当前状态**（见上方必读文件）

2. **基于监测原则追问**（按需，不每次全问）
   - 真定 vs 惛沉："那段时间是否还在守所缘？"
   - 三个不要：是否出现提速 / 固化 / 兴奋倾向？
   - 连续天数：中断了？原因？
   - 触发点：是否生效？
   - 出座原因 / 方式（若未报告）

3. **格式化精简条目**（写入主日志）

   模板（20—30 行）：
   ```markdown
   ## YYYY-MM-DD [时段]：[一句话主信号]

   **时段** HH:MM—HH:MM（N 分钟）/ **所缘** XX / **坐姿** XX

   ### 数据
   - [2—5 条主数据]

   ### 关键判读
   [1—2 段最重要的信号或风险解读。推论处显式标"推论"。]

   ### 当前定位（仅变项）
   - [只列与上次相比的变化]

   → 完整记录：[YYYY-MM 月归档](logs/历史/YYYY-MM-实修反馈.md)
   ```

4. **写入完整条目到月归档**
   - 路径：`notes/实修/logs/历史/YYYY-MM-实修反馈.md`
   - 完整条目包含：详细分析 / 框架映射 / 监测原则对照 / 学术诚实标注
   - 月归档不存在时创建（加标准头）

5. **更新演化追踪表**
   - 在主日志顶部更新各 series 最新数据点
   - 只加数据点，不加解读

6. **检查 14 天窗口**
   - 若主日志有超过 14 天的精简条目，从主日志移除（完整版已在月归档）

## 模式 2 · 对话（用户想讨论实修状态时）

### 步骤

1. **加载上下文**（见上方必读文件 + 按需文件）

2. **分析近期趋势**
   - 连续天数 + 中断模式
   - 关键现量信号演化（暗静对治链、五识收摄、酸胀阈值）
   - 与前期对比（月归档提供历史基线）

3. **路径风险扫描**（基于 AGENTS.md 修行者画像）
   - 风险 #1 干慧：禅定主轨是否推进？
   - 风险 #2 想通≠跃迁：近期"想通"后有无事件层验证？
   - 风险 #4 闻思快奖励：是否出现实修慢节奏隐性厌恶？
   - 连续性中断：触发点是否失效？中断有无结构性原因？

4. **连接操作核**（按场景）
   - 坐中体验 → 轻安锚操作核
   - 触发 / 连续性 → 不放逸操作核
   - 境界追求 / 征兆标的 → 行舍操作核
   - 嗔 / 自责 → 嗔事件层操作核

5. **结构化反馈**
   - 连接修行者应对原则（盯频率不盯时长 / 盯心所配置不盯用力 / 完成动作即通行证）
   - 建议下一步（若有）
   - 避免过度分析——该修行者倾向精简检验

## 模式 3 · 生活修对治流程（看破 → 熏种 → 常态）

> 用于处理**生活中发生的现行困扰**。骨架 = 修行者核心修行学逻辑「看破 → 熏种 → 常态」三步循环。一次走完 = 开一个**对治案**（一案一文件）。这是引导式对话，不是事后填表。

### 步骤

1. **加载上下文**（见上方「模式 3 / 4 额外必读」）

2. **阶段 A · 看破**（讨论现量内容 → 分析根因 / 机制 → 达成看破）
   - 先让修行者报告**现量内容**：事件原貌（哪个场 / 起了什么心所 / 当下如何）
   - 深挖根因 / 机制——连接对应操作核（亲子场无嗔 / 嗔事件层 / 无痴双线）
   - 用已有假说时**标第三层**；经典依据**标出处**；**经典 > 假说**
   - 看破的标志：看到该现行背后的根因（如反应式嗔 → 层 4 强加），不是停在"知道不该"
   - 利根者风险：警惕"已看穿"框定出现在习气**未真现起**的场景（看穿 vs 绕过——区分点：习气真现起但当下识破 = 看穿真）

3. **阶段 B · 熏种**（设计对治方案）
   - 对治方案 = 现实中**反复熏种的具体触点**（不是一次性意志动作）
   - **遵循三步循环**：给熏种路径（反复触点），**不评判常态是否到达**
   - **不设计"分阶段渐进 + 多指标检验"**——违背修行者路径简洁性，易过度保守
   - 优先连接修行者最强暴露面（亲子场）而非抽象境

4. **阶段 C · 评估指标**（达成常态的现量检验）
   - 定义**单一现量检验**（该修行者倾向单一检验，非多维监测）
   - 典型形态：同类境再现时**当下识破 + 反应强度下降**（路径风险 #2「想通≠跃迁」的现量入口）；或事件中**真实锚是否现行**（标的，非"是否更快放下"这一征兆）
   - 标的 ≠ 征兆：不取"速度 / 体验 / 心理满足感"作指标

5. **流程末尾询问是否立案**
   - 并非每次生活讨论都需立案熏种——有些聊完看破就够了
   - 问一句："**这个要立案熏种吗？**" 修行者确认才开案

6. **开案 · 写文件**（确认立案后）
   - 案文件：`notes/实修/logs/生活修日志/YYYY-MM-标题.md`（年-月 + 简短标题；目录不存在则创建）
   - 用下方「对治案文件模板」
   - 同步在 `notes/实修/生活修对治内容.md` 对治案清单加一行（最新在前），状态 = `熏种中`

### 对治案文件模板

```markdown
---
状态: 熏种中
开案: YYYY-MM-DD
末次回访: —
评估指标: [一句话——单一现量检验]
触发场: [亲子场 / 工作场 / 反应场 / 独处反刍 / ...]
---

# 对治案 · [主题]

> 学术诚实：第一层 = 修行者现量；第二层 = 唯识映射；第三层 = 推论（文内标"推论"）。

## 一·现量内容
[修行者报告的事件原貌]

## 二·看破（根因 / 机制）
[讨论达成的看破结论。操作核 / 假说处标第三层，经典标出处。]

## 三·对治方案（熏种触点）
[现实中反复熏种的具体触点。]

## 四·评估指标（单一现量检验）
[达成常态的单一判准。]

## 五·回访记录
- （开案，待回访）
```

## 模式 4 · 回访 review（`/shixiu review`）

> 修行者**手动触发**（不自动）。扫描未闭合对治案，逐个用其评估指标问现量，更新状态。

### 步骤

1. **读 `生活修对治内容.md`**，列出所有 `熏种中` / `需重新看破` 的对治案
   - 若修行者指定某案，只回访该案；否则逐个过

2. **逐案回访**——读该案文件，用 §四 评估指标问现量
   - 问法对准标的不对准征兆：问"**同类境再现时反应强度 / 当下识破比例**"，不问"是否更快放下 / 体验如何"
   - 同步扫路径风险：#2 想通≠跃迁（反应强度未降 = 停在比量）/ #3 看穿 vs 绕过（习气是否真现起过）

3. **更新状态判读**（写入该案 §五 回访记录 + frontmatter `末次回访`）
   - `熏种中` → **常态**：评估指标现量达成（反应强度下降已任运 / 当下识破自然），案闭合
   - 维持 **熏种中**：方向对但未到任运厚度，继续熏（不催速度——盯心所配置不盯用力）
   - → **需重新看破**：反应强度未降、停在比量，说明看破不够深，回流模式 3 阶段 A

4. **同步索引**：更新 `生活修对治内容.md` 清单对应行的状态 + 末次回访日期

5. **结构化反馈**——精简，连接应对原则（退转 = 正常 / 主动暂停优于反向熏种）

## 关键原则（贯穿四个模式）

### 项目规则
- **笔记不出现英文**（项目规则，文件路径 / AGENTS.md 等结构性引用除外）
- **不默认添加"修行者相劫持监测"**（已确认低风险，重复 = 噪音）
- **学术诚实三层标注**：主日志全局声明 + 推论处标签；月归档完整标注

### 修行学原则
- **遵循三步循环**（看破→熏种→常态）：任何修行命题设计时遵循
- **单一现量检验**：该修行者倾向精简检验，避免多维监测
- **经典 > 假说**：引用假说时标第三层
- **盯频率不盯时长，盯心所配置不盯用力**
- **退转 = 正常，不是失败**
- **标的 ≠ 征兆**（行舍正直一相）：不追体验深度 / 速度 / 时长
- **主动暂停优于反向熏种**：散乱厚重时主动起座调整

### 记录原则
- **只记修行者报告的**——不编造未报告的体验
- **变项优先**——当前定位只列与上次相比的变化
- **不重复稳定项**——B / C 轨无变化时不列

## 文件结构

```
notes/实修/
├─ 实修反馈日志.md         ← 坐中主日志（瘦）：演化追踪表 + 监测原则 + 近 14 天精简条目
├─ 生活修对治内容.md        ← 生活修对治案清单（瘦索引）：链接 + 当前状态
├─ 当前修行内容.md          ← 修行计划（三轨结构 / 具体安排）
├─ 修行者画像.md            ← 稳定参考（基本情况 / 早年经历 / 定力底子）
├─ 修行全景框架.md          ← 框架（罕变）
├─ 心所专修/                ← 路径文档（信的修习路径 等）
└─ logs/
    ├─ 历史/                ← 坐中月归档
    │   ├─ 2026-05-实修反馈.md
    │   └─ ...（按月自然增长）
    └─ 生活修日志/           ← 生活修对治案（一案一文件）
        ├─ 2026-05-亲密关系场理解他人因与利他善巧.md
        └─ ...（命名 YYYY-MM-标题）
```

> **两条记录线分工**：坐中 = 时段封闭，按日累积进 `notes/实修/实修反馈日志.md` + 月归档；生活修 = 事件触发，一案一文件进 `notes/实修/logs/生活修日志/`，`notes/实修/生活修对治内容.md` 只做索引。互不污染。

## 归档规则摘要

### 坐中（模式 1）

| 项 | 规则 |
|---|---|
| **主日志保留窗口** | 近 14 天 |
| **完整条目去向** | 当月月归档（`logs/历史/`）|
| **归档时机** | 每次新条目写入时检查；超 14 天的精简条目从主日志移除 |
| **月归档排序** | 最新在前 |
| **月归档创建** | 首次该月有条目时创建，加标准头 |

### 生活修（模式 3 / 4）

| 项 | 规则 |
|---|---|
| **记录单位** | 一个对治案 = 一个文件（`notes/实修/logs/生活修日志/YYYY-MM-标题.md`）|
| **状态元数据** | 存案文件 frontmatter（状态 / 开案 / 末次回访 / 评估指标 / 触发场）|
| **索引同步** | 每次开案 / 回访后同步 `生活修对治内容.md` 清单行 |
| **闭合处理** | 达成常态后，案文件 frontmatter 状态改 `常态`，索引行更新——**文件留原处不迁移**（一案一文件本身已瘦）|
| **学术诚实** | 案文件 = 全局声明（模板内）+ 推论处标第三层 |
