# 【明日早晨第一步】

**明天早上 9:00，拿出手机，打开备忘录，写下三行字：**

```
1. [传承名]：___（填你现在最感兴趣的那个法门/道场/老师）
2. 他的老师叫___，老师的老师叫___
3. 这个传承的其他当代弟子有___（至少写两个名字）
```

- 如果第 2 行你写不出完整三代，或者第 3 行只能写出一个名字（就是你关注的那个人自己），**立刻删掉这个传承，今天不要再看任何相关内容。**
- 如果能写满，今天中午前用搜索引擎交叉验证：那两个"其他弟子"是否真实存在，是否互相承认对方。

**禁止动作：**
- 不要去问那个老师本人（废话，骗子都会给你编家谱）
- 不要"先听听课再说"（你已经在听了，现在是验货环节）
- 不要写"我还需要再了解了解"（这是拖延症，不是行动）
