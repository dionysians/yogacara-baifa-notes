## 📖 学习路径建议

### 初学者路径

1. **第一步**: 阅读 [百法明门论_原文.md](百法明门论_原文.md)
   - 通读全文，了解整体结构
   - 不要求完全理解，先有整体印象

2. **第二步**: 配合 [基础概念解释.md](现代注释/基础概念解释.md)
   - 理解核心概念（法、无我、唯识）
   - 学习五位百法的分类逻辑
   - 重点掌握八识和常用心所

3. **第三步**: 遇到问题查阅 [学习问答.md](现代注释/学习问答.md)
   - 针对性解决疑问
   - 深化理解

4. **第四步**: 深入研读 [百法明门论疏_窥基.md](百法明门论疏_窥基.md)
   - 学习传统权威注释
   - 理解更深层含义

### 进阶学习者路径

1. 直接研读原文和窥基疏
2. 对照现代注释理解难点
3. 结合日常观察实践
