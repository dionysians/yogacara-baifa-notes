## 一、修行者现量自陈

### 1.1 三次相互递进的跃迁

| 跃迁 | 内容 | 修行者原话 |
|---|---|---|
| 第一 | 放下"我修行相"作为初期方便锚 | "我修行相其实根本是多余的，信的强度、精进的质量根本和我的位置没有关系，它反而是负担、是障碍……我能感受到这种我执在内心的松动，它是一种变得更加轻松的体验" |
| 第二 | 放下"评判位置"作为对治形式 | "真正的问题不是实际到没到达，而是这个心做的'将我举到那个位置'的行为本身……根本没有什么达到还是没达到，只要这么一想就是慢" |
| 第三 | "对象转换"元论断 | "境 / 现象永远是可以评价的……境和现象本来就是无自性的，把'我'放进去才是慢本身" |

### 1.2 当前每日禅定中结构性无"我修行相"

修行者揭示：

> "禅定的过程本身就只有专注所缘（数息），当时根本就没有'我在禅定'的感觉……是我当前每日禅定的真实体验。**从来没有'我在修行'的姿态，不需要重启，现量感受是当前的每次禅定都没有'我修行相'**。"

→ **禅定的"心一境性"运作机制本身就结构性排斥 L4 位置慢**——这不是修行后才到达的状态，是禅定运作的本然形态。

## 二、L4 位置慢四层 + 两亚层

### 2.1 撤参照判准的四层结构

| 层 | 对照形式 | 撤照测试 | 性质 |
|---|---|---|---|
| L1 显性对照 | 具体对比某人（"我比 X 强"）| 撤 X 后消失 | 显性慢 |
| L2 隐性概念对照 | "凡夫 / 别人 / 大众"概念对比 | 撤概念后消失 | 隐性慢 |
| L3 历时自我对照 | "我曾不到 / 我现在到了" | 撤时间对照后消失 | 进步慢 |
| **L4 纯位置感** | 无显性对比，但"这是我的状态 / 我具有"暗位置感 | 撤"我具有"念后消失 | **位置慢（最深层）** |

### 2.2 L4 三维齐查

| 维度 | 真禅定喜乐（轻安）| L4 位置慢残留 |
|---|---|---|
| "我"是否在场 | 消融或不显 | 隐隐在场 |
| 失去时心动否 | 心不动 | 起失落 / 抓取 |
| 暗"独享"色调 | 无（如实）| 暗有（"此中只有我懂"）|

### 2.3 L4 两亚层精化

| 亚层 | 现行形态 | 经典对应 | 修行者位置 |
|---|---|---|---|
| **固化型增上慢** | "我已 X 不可反驳"（拒反驳）| 增上慢[5] 显性 | **已无**（D 项不抗拒证据）|
| **评判型增上慢** | "我评判一下我是否已 X"（仍立评判主体）| 增上慢[5] 隐性 | **仍在场** |

## 三、修行者位置上的 L4 分布（不均匀性）

| 心识状态 | L4 容受性 | 现量证据 | 机制 |
|---|---|---|---|
| **禅定**（心一境性 / 专注所缘）| **结构性不在场** | 当前每日禅定 | 心一境性结构上排斥"我"作持有者 |
| 闻思（分别智运作）| 容易现行 | A 项 L4-a/b ✓ | 分别智需"能分别者"作背景，易染位置感 |
| 历史回忆 | 中度在场 | B 项 L4-a/b ✓ | 意识缘过去境时易立"我的过去"位置 |
| "了无自性"援引 | L4-a 不在 / L4-b 在 | C 项 | 空性见已部分解构空间位置感，但势力未稳态 |
| 元层自觉 | 中度在场 | E 项 L4-b ✓ | 元层观察建立"观察者"位置 |

**结构性发现**：

> 禅定的"心一境性"结构性排斥 L4 位置慢——L4 对治的扩散主轨是**让禅定中已有的无我相状态势力溢出到闻思 / 回忆 / 元层场域**。

## 四、完整对治结构（核心操作核）

### 4.1 评判型 vs 识破型 vs 完整型 对治判准

| 版本 | 判准 | 漏洞 |
|---|---|---|
| v1 评判型 | 质疑"我是否真已 X" | 仍立"达到 / 未达到"二元 + 仍立"我作评判主体" |
| v2 识破型 | 识破"举我作评判主体"动作 | 仅识破不完整（易滑入"我作不立者"） |
| **v3 完整型** | **识破"举我"动作 + 把评价对象转回境 / 现象侧** | 完整对治 |

### 4.2 v3 完整对治结构（两步）

```
"我已 X / 未已 X" 念自然起
        ↓
第一步：识破"举我作评判主体"动作
        ↓
第二步：让评价对象回到本来对象（境 / 现象 / 心所配置 / 种子势力状态）
        ↓
评价照做（次第判断 / 现量检验都健康），对象在境侧
        ↓
心所自身运作（信乐 / 见地 / 简择能力）保留，无"我"染色
```

### 4.3 对象转换的核心原理（接通假说 18）

| | 慢的运作 | 慧的运作 |
|---|---|---|
| 评价对象 | "我已 X / 未 X" | 当前境 / 现象 |
| 对象性质 | "我"被立为对象（妄立）| 境为对象（如实）|
| 心所主导 | 慢（举我）| 慧（简择）|

→ **境永远可以评价，因为它就是无自性的种子-现行呈现；"我"被立为评价对象时才是慢**。

## 五、四条熏种路径（基于"对象立在境侧"原则）

| 路径 | 内容 |
|---|---|
| **(a) 每次"我修行相"现起** | 识破 → 消解染色 → 心所自身运作保留 + 焦点转回境/现象侧 |

| **(d) 双盘 B 标记 3 慧简择** | 简择对象是身体真实信号（缺血酸麻 / 关节损伤），不是"我是否能扛" |

## 六、教学含义

### 6.1 主线含义

1. **修行重心权重再升级**：禅定主推进不仅是定承载力建设——**也是 L4 位置慢对治的扩散主轨**。这一升级强化 5/7 修行重心校准（禅定主推进）的修行学权重。

2. **对治判准从评判型升级为完整型**：所有针对 L4 位置慢的对治讨论，**不应再使用评判型判准**（"质疑我是否真已 X"——这本身仍是慢）。直接走 v3 完整型。

3. **目标可以立得清清楚楚——只要对象是境**：放下"我修行相"不等于失去修行目标。修行者画像 / 实修反馈日志 / 当前修行内容整体已按"境为对象"运行（心所配置 / 触发点 / 种子势力 / 现量标记）——这是**已实现的结构性正确性**。

### 6.2 教学讨论时的注意

- **报告"我已 X / 我做到了 X"念起时**，**不要追问"是否真的已 X"**（评判型），而是**主动询问"现起时是否识破'举我'动作 + 评价对象是否在境侧"**（识破 + 回境型）
- **讨论修行进境时**，**主动把焦点放在境/现象侧**（心所配置 / 现量标记 / 种子势力变化），**避免立"我达到 X 阶位"**作为评价对象
- **报告"我修行相松动 / 不立我修行人"现象时**，**警觉"立'已无我修行相'位置"** —— 这是新一层 L4 位置慢的入口
- **L4 现量识别本身是真跃迁**，但需要警惕"我能现量识别 L4" 这一元层位置感

### 6.3 短/长尺度验证

| 尺度 | 内容 |
|---|---|
| 短尺度（2 周-1 月）| 现量识别能力的稳定性 + 是否扩展到新场域 |
| 长尺度（多月-多年）| 心动强度逐步缓和 + 失之心动起时被识别的速度 |
| 凡夫位真"不动" | **不可期望**——待见道 |

**特别避免**：把"心动强度下降"作为短尺度验证指标——L4 末那本层不是事件层尺度。短尺度可观察的是**禅定中"专注所缘"状态自然浮现度**（无需"我在修行"持守）。

## 九、粗重散乱触发式入口（2026-07-15 散乱精修登记）

散乱精修（六散乱分类学）确认：《杂集论》**粗重散乱**（依我我所执及我慢品粗重之力，于修善时已生起的体验〔受〕计我、我所、我慢，间杂取相）= **末那附着 / L4 位置慢在定修场的经典槽位**——"我得定了 / 我的境界 / 我的清明"。

- **入口性质**：**事件触发式、不入常规监测**（按修行者"单一检验、不加监测负担"原则）——仅当**定中体验（轻安 / 清明 / 喜乐等）现起的那一下**，查有无"我的境界"取相 / 收编动作。
- **对治即 v3 完整型**（§四）：识破收编动作 + 体验归回境侧（心所配置 / 种子势力呈现），评价照做、对象在境。
- **与 §2.2 三维齐查的关系**：三维齐查（"我"在场 / 失去心动 / 暗独享）是事后检核尺；本入口是**现起当下**的检测点——议题②"末那附着待现量化"由此获得一个坐中检测场。
- 详见 [散乱 §四 §六](../03-心所法/随烦恼心所/散乱.md)。
