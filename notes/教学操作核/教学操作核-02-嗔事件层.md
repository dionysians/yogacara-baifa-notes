# 教学操作核 2：嗔的事件层操作

> **reveal 日期**：2026-05-02
> **回链**：[CLAUDE.md 各心所事件层操作核](../../CLAUDE.md#各心所事件层操作核)

修行者嗔的对治不依"跨心所通用 trigger"框架，使用基于无嗔本心所现行 phenomenology 的四个独立 trigger（详见 [无嗔.md §十二.4](../03-心所法/善心所/无嗔.md)）：

1. **"受 → 爱憎"识破**——苦受现起即识"这是受不是嗔"，覆盖反应式 / 反刍式嗔
2. **"我所感"现量觉察**——扫描"我对此场域扩张了什么'应该如何'的我所投射"，覆盖隐性轻慢 / 比较。**最深的运作场（2026-05-02 reveal）**：对他人因缘流的"应该如何"标准投射——评判他人"不合理"本身是末那 imposing，是微细嗔；扫描时问"此标准是经典依据 / 缘起如实见，还是'我天生 / 我习惯 / 我以为的常识'"
3. **"评判心"现量觉察**——觉察对所缘起二元标签时即看穿其末那运作，覆盖冷漠 / 标签化
4. **"自责式嗔"慢性扫描**——定中扫"对自己有什么持续的不满 / 评判"，覆盖自责 / 闻思快奖励反向

## 嗔系多层 stable base 概况（2026-05-02 整合 reveal + 多次精细化）

| 层 | 现行场 | 修行者状态 |
|---|---|---|
| Layer 1 | 苦受场上不起嗔（身体不适 / 病痛）| ✅ 天然安受苦忍 stable |
| Layer 2 | 社会场域奖励嗔不被吸引（围观 / 极化 / 网暴聚集）| ✅ 天然不参与 stable |
| **Layer 3a** | **反应式嗔（即时反应）** | 🟡 已建设场景（亲子场）当下识破；未建设场景 5 分钟 self-correct；反复触发场不可控 |
| Layer 3b | 反复回放（事后反刍）| ✅ stable——自省即识，想明白就放下 |
| **Layer 4** | **隐性轻慢 / 评判他人"不合理"作为 imposing** | 🟡 **主修区**——同时是 Layer 3a A 类反应式嗔的**根因** |
| Layer 5 | 自责式嗔 / 闻思快奖励反向（可能存在） | 待观察（trigger 4 扫描）|

## Layer 3a 与 Layer 4 的根 / 干关系（2026-05-02 reveal 修正）

Layer 3a 反应式嗔分两类——**A 类**：根因是 Layer 4 末那 imposing（外境违境通过"他/这事不应该如此"转译为嗔），看穿 Layer 4 即釜底抽薪解构；**B 类**：根因不是 Layer 4，需要其他手段。

**对修行者本人**：Layer 1 已 stable → Layer 3a 反应式嗔几乎全为 A 类 → **修行者主要的 Layer 3a 修法 = Layer 4 看穿的扩展应用**（不是两个独立层并列修行，是对同一根的不同显现层一次性解构）。

## 修法序（2026-05-02 修正）

1. **Layer 4 看穿优先**——釜底抽薪解构 Layer 3a A 类反应
2. **Layer 3a 直接 trigger 识破**作辅助——针对未通过 Layer 4 解构的部分
3. **反复触发场的间歇恢复 + 等流累积识别**——独立于 Layer 4，处理 buffer 累积
4. **未 cool state 建设场景**——系统性识别 + 主动建设（Layer 4 看穿可能是 cool state 的核心内容之一）

## 双层操作（与无贪场结构差异）

- **cool state 主轨**：闻思看穿（特别是 Layer 4 imposing 看穿）+ 定中持守
- **hot state 局部辅助**：奖励嗔信息环境 partition——对修行者本人 Layer 2 天然 stable，任务量 trivial
