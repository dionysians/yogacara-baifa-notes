## 二、两大俱生层主战场分诊（核心操作框架）

```
战场 A：法染色层（俱生层 · 微细）
├─ 法贪（贪精巧结构 · 名言种子贪）
├─ 末那附着（"我"附着到结构 → "我所立"隐性形态）
├─ L4 位置慢复合（稳定见 + 法贪 + 法嗔 + 末那举我）
├─ 法嗔（见解嗔第一阶段 · 二阶现行结构）
└─ 微细谤圣贤（与见解嗔三层复合俱生现行）
   ↑ 触受激活场域（具体他人质疑 / 结构构建）

战场 B：触受爱憎链激活场域（俱生层 · 粗显）
├─ 反应式嗔（情感性嗔）
└─ 俱生身见同步现行（跳过分别层）
   ↑ 触受激活场域（共业场景）
```

→ **二者不在同一对治通道** — 战场 A 不能用嗔事件层操作核（不在反应触发场）；战场 B 不能用见取见对治（不在法层）。

## 三、触受爱憎链统一开关命题（核心新揭示）

> **俱生层烦恼现行的开关 = 触受爱憎链的激活状态**。
> 触受激活 → 俱生层烦恼跳过分别层直接现行；
> 触受未激活 → 俱生层烦恼无现行通道。

| 场域 | 触受爱憎链 | 俱生层烦恼现行 |
|---|---|---|
| **共业场景**（亲子 / 反应触发处）| 直接激活 | 俱生身见 + 反应式嗔同步 |
| **派系争议处**（具体他人质疑见解）| 直接激活 | 见解嗔 + 微细谤圣贤俱生绑定 |
| **跨域映射 / 结构构建** | 法尘激活 | 法贪 + 末那附着主战场 |
| **路径选择处**（概念性多元化认知）| **未激活** | **结构性化解** |
| **元层 / 禅定中观所缘** | 未激活 | 俱生身见无通道 |

→ **修行学操作含义**：俱生层对治的关键 = 在触受激活的场域中识破。

## 四、四个独立触发点（恶见维度事件场操作）

### 触发点 1：法贪现量觉照（战场 A 核心入口）

**现行场域**：跨域映射 / 闻思深挖 / 假说构建 / 结构构建

**修行者现量分诊**（区分善慧 + 信 vs 法贪）：

| 现量 | 心所归位 | 染净 |
|---|---|---|
| ① 结构形成时的慧 → 胜解的确认感 | 慧 + 胜解俱起 | 无染 |
| ② 感悟佛理后的信增强 | 信 | 无染 |
| ③ **对精巧结构的俱生贪** | **法贪 / 名言种子贪** | **染** |

**操作**：
- 觉照第 ③ 项现行 — "这是对法尘精巧度的贪着"
- 同步觉照末那隐性附着 — "'我'被附着到结构上 → '我所立'是末那附着的产物"
- **法贪识破后不需解构结构本身**（结构仍可作闻思工具保留）

### 触发点 2：末那附着识破（战场 A 关键机制）

**现行场域**：任何法染色层场域

**操作**（应用 [假说 18 对象转换](../假说/假说-18-对象转换元假说.md) 的精确机制层）：
- 不只是识破"举我"动作（粗化框定）
- 而是识破**末那隐性把"我"附着到结构 / 见 / 境上的过程**
- 把对象转换实施：评价对象保留在境侧（结构、见地、修行进展等）；不让末那把"我"附着上去

### 触发点 3：见解嗔二阶现行结构觉照（战场 A 法染色层完整识别）

**现行场域**：派系争议处 / 具体他人质疑见解时

**第一阶段（俱生同步 · 法染色层）三层复合**：
- 法贪被损（贪所立结构遭质疑）
- 末那附着（"我"被附着到结构）
- 微细谤圣贤（轻视质疑者）

**操作**：
- 同步觉照三层（不要单挑某一层）
- 识破"嗔（针对人）" 在此阶段不直接现行 — 第二阶段才滞后引发
- → 修行者第二阶段嗔已基本稳态化（不经常）→ 主战场在第一阶段

### 触发点 4：俱生身见同步现行识破（战场 B 核心入口）

**现行场域**：共业场景（亲子 / 争辩 / 反应触发处）

**核心机制**（修行者现量自陈）：
> 贪嗔容易现行的地方，就是俱生身见容易现行的地方 — 它直接跳过慧的分辨过程，直接现行。

**操作**：
- 触受激活时同步觉照三者：触受 + 反应式嗔 + 俱生身见
- 看穿"层 4 强加"（来自 [教学操作核 02 §三](教学操作核-02-嗔事件层.md)）= 看穿"俱生身见在反应式嗔同步现行的过程"
- 釜底抽薪解构 = 识破"贪嗔 + 俱生身见同步绑定"的结构
