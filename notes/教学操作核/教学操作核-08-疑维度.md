## 一、修行者现量自陈

### 1.1 染疑现行结构性极低

> "我自己没有这个感觉，当我发现在知识层面理解了以后完全没有犹豫的体验"

> "对于'对未触及谛理的隐性犹豫'我没有，我自我的解释是，经典本身是有菩萨等打得大德写下的，经过无数人的验证，当前我本人对经典的完整自洽完全信服，在没有非常特殊的证据和现量体验时，从贝叶斯的角度，相信本身就是最自然的做法。"

### 1.2 思维底层接受度

> "我在思维底层就对佛法俱备极高的接受度，闻思的完备是强化和验证，并不是接受的原因"

### 1.3 俱生疑在场（凡夫位精确自我定位）

对甚深谛理（真如 / 佛智 / 究竟果位 / 业果细节）—— 现量状态 = **"比量接受 + 现量无真切印持"**。

### 1.4 因缘工程的现量识破

> "这里很神奇的是，当时我还小，也没有真正的修行经历，就是正常上学-工作，现在说起来时，当年仅仅是对我说过的事情，居然记得这么清楚，就好像在修行一开始，那些需要的东西在路上就准备好了"

→ 这不是当下惊叹时刻——修行者在听到"逻辑外冲击 / 未来可能问题"时**立即识破**"这些问题对我其实不是问题，我应该早就准备好面对它了"。

## 二、染疑入口的五层守护机制

### 2.1 五层守护结构

```
最深层：思维底层对佛法接受度（俱生）
   ↓
种子层：不动摇种子 + 信能胜解（多世熏出）
   ↓
激活层：闻思强化 + 验证（这一世，亦可由善知识引导等其他方式替代）
   ↓
对治层：勇猛精进对治原则（童年善知识植入"阶段性高强度考验 + 过不去时勇猛精进"）
   ↓
[元层：经典作贝叶斯先验 + 空性见作最终评判 / 整合元立场]
```

### 2.2 五层守护精确机制表

| 层 | 内容 | 修行者来源 |
|---|---|---|
| **最深层** | 思维底层对佛法接受度 | 俱生 |
| **种子层** | 不动摇种子 + 信能胜解 | 多世闻思 + 持戒 + 定 熏出 |
| **激活层** | 闻思强化 + 验证（这一世）| 系统学习百法 |
| **对治层** | 勇猛精进对治原则 | 童年善知识植入 |
| **元层** | 经典作贝叶斯先验 + 空性见作最终评判 | "了无自性"早年内化 |

→ 染疑攻击披甲基础在修行者位置 = 五层全部封住 + 元层兜底 = **结构性不发生**。

## 三、疑的层级分诊（修行者位置）

| 疑的层级 | 修行者位置 |
|---|---|
| **分别疑**（见所断）| 五层守护已结构性截断 → 几乎不现行 |

| **末那层** | 结构性不通（疑因"决了态对反"不通末那）→ 不需扫描 |

## 四、比量披甲 vs 现量披甲

| 类型 | 来源 | 稳态条件 | 修行者现状 |
|---|---|---|---|
| **不动摇种子**（俱生）| 多世累积 | 已稳 | ✓ 已在 |
| **种子现行（依激活方式）** | 这一世特定激活路径触发 | 当前激活方式 = 闻思 | ✓ 闻思激活已运作 |
| **种子任运现行**（现量披甲）| 不需特定激活方式，自然现行 | 修行目标 | 🟡 部分趋近 |

→ **"想清楚才稳"不是脆弱性**，而是激活路径的特定形态。**真正的修行目标是把"种子现行"做得更自动化、不依赖特定激活方式** —— 这就是任运不动。

→ 干慧风险 #1 在染疑维度的精化：**激活方式单一化风险** —— 如果只依赖闻思激活，逻辑外冲击可能让激活方式短暂失灵，种子虽在但短期不现行。**定中持守是把激活路径扩展到不依赖比量的现量任运**。

## 五、慧根利者特殊对治维度——见解贪嗔觉照

### 5.1 L4 位置慢复合机制反向形成俱生疑

```
慧根利 → 见快速稳定
       ↓
   ┌───────────┴───────────┐
   ↓                       ↓
末那劫持机会多        对见解产生贪 + 对不认可者产生嗔
   ↓                       ↓
"我已 X" 位置感          种子化进入末那层
   ↓                       ↓
   └───────────┬───────────┘
               ↓
   L4 位置慢（复合：稳定见 + 见解贪 + 见解嗔 + 末那举我）
               ↓
   长期种子化 → 加重对"已立见"的执着
               ↓
   反向形成 俱生疑（对甚深谛理无真切印持）
```

### 5.2 特殊对治维度三条

| 对治维度 | 机制 | 操作 |
|---|---|---|
| **见解贪的觉照** | 对自己见解涌起喜悦 / 占有感时 | 觉照"这是名言种子贪在见解层的现行" |
| **见解嗔的觉照** | 对不认可自己见的人涌起不悦 / 评判时 | 觉照"这是嗔的微细形态，针对'我所立见'" |
| **俱生疑预防** | 见解贪嗔种子化是俱生疑的形成通道 | 上述两个觉照不仅对治当下烦恼，更预防其种子化形成俱生疑 |

### 5.3 接驳已有标记

修行者画像中分散两处的内容在此**机制层闭合**：

| 已识别 | 新归位 |
|---|---|
| "泛化的精致深刻知识贪"（中风险，已识别）| **L4 位置慢的隐性根因之一 + 俱生疑的隐性形成原因** |
| **"见解嗔"**（新识别）—— "对认定的事不被认可产生的嗔" | 嗔的微细形态，与嗔精修触发点 2 最深层"评判他人不合理"同源但更深一层 |

## 六、教学含义

### 6.1 报告"想清楚了所以稳"时的诊断方向

- **不要**追问"为什么没怀疑" → 这把焦点放在情感稳定度
- **要**询问"是哪一层守护在运作" → 把焦点放在结构机制

### 6.2 报告"对甚深谛理感觉模糊"时的诊断方向

- **不要**理解为"信不足" → 这会把焦点错放到信德热度
- **要**理解为"俱生疑在场"（凡夫位精确特征）→ 把焦点放在"通过定中持守把比量见地下沉为现量印持"

### 6.3 报告"对自己见解涌起喜悦"时的诊断方向

- **不要**单独识破"举我"动作（只对治 L4 一面）
- **要**识破"举我" + 同时觉照"这是见解贪在见解层的现行" + 预防种子化形成俱生疑

### 6.4 报告"对不认可自己见的人涌起不悦"时的诊断方向

- **不要**只对治嗔事件层 → 这只处理粗显嗔
- **要**识别这是嗔的微细形态（针对"我所立见"）+ 觉照其反向形成俱生疑的种子化通道

### 6.5 长期搁置原因诊断

如果修行者出现长期搁置 / 起步困难——

- **不要**只看精进力一面 → 这只是一个维度
- **要**查"修行机制认知根据"是否建立 —— 染疑入口的存在可能与精进力不足共同作用导致搁置（三不足模式之三）

### 6.6 起步期激活路径设计

- 慧根利 + 信能胜解强者：通过"想清楚"激活
- 信德热 + 师承印持者：通过师承印持激活
- **不强求统一激活方式** —— 激活的种子是同一个，路径取决于根器
