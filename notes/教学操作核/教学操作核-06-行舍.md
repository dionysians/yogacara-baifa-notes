# 教学操作核 6：行舍三相 轴 + 后位涌现态的"不直接 operate"原则

> **揭示 日期**：2026-05-16（行舍正式学习中假说 17 闭合 + 三相 轴 结构 推出 + 5/16 现量精确诊断）
> **回链**：[CLAUDE.md 各心所事件层操作核](../../CLAUDE.md#各心所事件层操作核)

行舍作为后位涌现态（任运面）的修行操作核与前面几个善心所（无嗔 / 无痴 / 轻安 / 不放逸）操作核结构上不同——其他操作核都有 活跃 operation 模式，而**行舍的核心操作恰是"不直接 operate 行舍 显现，只操作 基质"**。

## 核心 揭示 1：行舍三相 轴 复合 + 后位涌现态结构

行舍三相 = **平等 / 正直 / 无功用住**（《成唯识论》卷六"平等正直无功用住，初中后位辨舍差别"），5/16 校准为 轴 复合 + 后位涌现态结构：

| 相 | 轴 | 对治掉举层 | 是否可直接操作 |
|---|---|---|---|
| 平等 | 振幅 轴 | 粗显掉举（心浮 / 杂念 / 起伏）| ✅ 可（不放逸 基质 + 三段式催熟）|
| 正直 | 方向 轴 | 微细掉举（征兆/标的 错位 / 推进感 劫持）| ✅ 可（闻思 深挖 + 冷态 看穿）|
| 无功用住 | 用力 轴 后位 | 最微细掉举（残余 用力 相 / 修行者相）| ❌ 不可——前二相 稳态 后自然涌现 |

→ **行舍整体 显现 不是 operation 标的**——直接 深挖"我要无功用住" / "我要任运" = 征兆/标的 错位 = 行舍者相 劫持 入口。可操作的是 基质（前二相），无功用住是后位涌现态。

## 核心 揭示 2："不直接 operate"原则的精确机制

经典《成唯识论》"由不放逸先除杂染，舍复令心寂静而住"明确次第结构。5/16 推出 功能基质排序：

```
不放逸（守护面）stable
   ↓ 守护 substrate 立稳
平等（amplitude axis）stable    ← 行舍初位
   ↓ 粗显掉举对治 ground
正直（directional axis）stable  ← 行舍中位
   ↓ 微细掉举对治 ground
无功用住（effort 后位）涌现     ← 行舍后位 = 任运态
```

→ 操作目标永远在 **基质 层**（不放逸 / 平等 / 正直），不在涌现态（无功用住 / 行舍整体 显现）。

**教学含义**：
- 修行者报告"心很平静 / 状态很好"时，**优先询问"是否在 基质 层"**（不放逸 触发 是否运作 / 平等是否在场 / 正直是否在场）而非"是否已得行舍"——前者是 标的 check，后者是 征兆 错位入口
- 报告"似乎到了某种 stage"时，**用三相 轴 精确分诊代替整体性 标签**——避免给 integer 标签 让末那 劫持 为 行为者地位

## 核心 揭示 3：5/16 现量精确诊断 — "正直一相 部分 显现"严格 框定

修行者 5/16 实修反馈"未追求更好 / 更久 / 更稳 / 想确认境界"——按主线 1-2 框架 精确诊断 = **正直一相的 部分 显现**：

| 三相 | 5/16 基质 状态 |
|---|---|
| 平等 | 🟡 部分（粗显掉举减少，明记断片仍频繁）|
| 正直 | 🟡 部分 稳态（征兆/标的 不错位在场）|
| 无功用住 | 🔴 未涌现（三段式仍需主动 catch + 提明分）|
| 不放逸（基质）| ✅ 触发 四次验证稳定 |

**三种解读判别**：

| 解读 | 判定 |
|---|---|
| A（行舍 显现 早期信号）| 错——"行舍 显现" 暗示三相整体涌现 |
| B（仅闻思熏种）| 错——已是 倾向性的 state 部分 |
| **C（正直一相 部分 显现）** | ✅ 严格 + 健康 框定 |

→ **行舍 显现 严格意义 = 三相协同涌现 + 无功用住后位达成**。修行者 5/15-5/16 冷态 中表现态度（"明记断片仍频繁——继续每日累积，不试图一次解决"）= 第三 框定 的 implicit 实操。

**教学含义**：修行者报告"似乎已达成某种 稳态"时，**应用严格 框定 防止 征兆 错位**——具体诊断在三相 轴 上的位置（"X 一相 部分 / Y 一相 稳态 / Z 一相未涌现"），而非给一个整体性 标签。

## 核心 揭示 4：行舍者相 劫持 防御（锚表述偏移 在行舍场）

行舍场的 行为者地位 偏移 形态：

| 偏移 signal | 含义 |
|---|---|
| "我已得行舍" | 把 部分 显现 升级为整体 显现 = 征兆 错位 |
| "我已任运" | 把 in-session 稳态 degree 误识为稳态 disposition |
| "X 是行舍 显现 早期信号" | 把正直一相 部分 误识为整体涌现起点 |

→ **行舍者相 劫持 = 最微细掉举形态本身**——把"我在维持行舍稳态"作为残余 用力 = 无功用住的反面 = 加行 → 任运过渡场的精确风险。

利根者最易撞的形态 = "把正直一相 部分 显现 升级为行舍整体 显现"。修行者当前双 锚（"了无自性" + "所有错=无知造成的"）都不指向 行为者 status，但坐中起步阶段 部分 显现 升级误识仍是结构性风险。

**教学含义**：
- 修行者出现"我已 X"类表述时**立即递归识破**（假说 13 递归惭愧机制）
- 用三相 轴 精确分诊代替整体性 标签
- 监测信号：冷态 中如出现"我已得行舍 / 我已任运 / X 是行舍 显现"= 风险信号；如保持"X 一相 部分 / 继续累积" 框定 = 健康

## 核心 揭示 5：受舍 vs 行舍 切分 现量入口 = "守所缘"判准

5/16 推出 出**受舍（受蕴 身心 feeling）vs 行舍（行蕴 倾向性的 state）切分 的精确机制 锚** = 睡前禅定监测原则中"那段时间我是否还在'守'所缘？"判准：

| 判准答案 | 现量层 切分 |
|---|---|
| "在守" | 倾向性的 活跃 = **行舍**方向（能动性 在场）|
| "失守 / 不知道" | 身心 passive = **受舍 + 惛沉 / 散乱**|

修行者 5/15-5/16 "明记断片"被 健康 判为非真定——这层判别现量中已运作，**受舍 vs 行舍 切分 已在场**，只是未 明文 命名。

**教学含义**：
- 修行者报告坐中体验时，**优先询问"是否在守所缘"**而非"体验是什么"——前者直接命中 切分 现量入口
- "心很平静"未必是行舍，可能只是受舍——必须 check 能动性 / 守所缘判准
- 切分 是 dynamic in-session 现量层，不是稳态 disposition——不能由"我一般在守"等 trait-style 答复 归约

## 核心 揭示 6：行舍 vs 不放逸 维度 ⊥ + 当前修行重心

| 维度 | 不放逸（守护面）| 行舍（任运面）|
|---|---|---|
| 答的是什么问题 | "还在开吗？"（运动连续性）| "开得自如吗？"（运动质量）|
| 显现 层 | 时间域 | 状态域（三相 轴 复合）|
| 失败模式 | 停下来 = 放逸 | 行驶不稳 = 掉举 |
| 操作 模式 | 直接 operate (触发 设计) | 不直接 operate (操作 基质) |
| 当前修行者位置 | 🟡 活跃 操作区 | 🟡 监测 区（不在 活跃 深挖）|

→ **不放逸是修行者当前 活跃 操作区，行舍是后位涌现 监测 区**——当前修行重心仍在不放逸 基质 稳态 累积 + 平等 基质（禅定主轨）累积，行舍只做 in-session 三相 稳态 degree 评估即可。

**教学含义**：
- 后续讨论中，不在行舍层施加操作压力——禅定主轨 深挖 是为了平等 基质 累积，不是为了"得行舍"
- "5/26 触发 设计 回填" + "B 双盘训练座启动"是当前 基质 活跃 操作目标
- 行舍场只做 in-session 现量 监测，不做 深挖
