# 教学操作核 6：行舍三相 axis + 后位涌现态的"不直接 operate"原则

> **reveal 日期**：2026-05-16（行舍正式学习中假说 17 闭合 + 三相 axis 结构 derive + 5/16 现量精确诊断）
> **回链**：[CLAUDE.md 各心所事件层操作核](../../CLAUDE.md#各心所事件层操作核)

行舍作为后位涌现态（任运面）的修行操作核与前面几个善心所（无嗔 / 无痴 / 轻安 / 不放逸）操作核结构上不同——其他操作核都有 active operation pattern，而**行舍的核心操作恰是"不直接 operate 行舍 manifest，只操作 substrate"**。

## 核心 reveal 1：行舍三相 axis 复合 + 后位涌现态结构

行舍三相 = **平等 / 正直 / 无功用住**（《成唯识论》卷六"平等正直无功用住，初中后位辨舍差别"），5/16 校准为 axis 复合 + 后位涌现态结构：

| 相 | axis | 对治掉举层 | 是否可直接操作 |
|---|---|---|---|
| 平等 | amplitude axis | 粗显掉举（心浮 / 杂念 / 起伏）| ✅ 可（不放逸 substrate + 三段式催熟）|
| 正直 | directional axis | 微细掉举（sign/target 错位 / 推进感 hijack）| ✅ 可（闻思 push + cool state 看穿）|
| 无功用住 | effort axis 后位 | 最微细掉举（残余 effort 相 / 修行者相）| ❌ 不可——前二相 stable 后自然涌现 |

→ **行舍整体 manifest 不是 operation target**——直接 push"我要无功用住" / "我要任运" = sign/target 错位 = 行舍者相 hijack 入口。可操作的是 substrate（前二相），无功用住是后位涌现态。

## 核心 reveal 2："不直接 operate"原则的精确机制

经典《成唯识论》"由不放逸先除杂染，舍复令心寂静而住"明确次第结构。5/16 derive functional substrate ordering：

```
不放逸（守护面）stable
   ↓ 守护 substrate 立稳
平等（amplitude axis）stable    ← 行舍初位
   ↓ 粗显掉举对治 ground
正直（directional axis）stable  ← 行舍中位
   ↓ 微细掉举对治 ground
无功用住（effort 后位）涌现     ← 行舍后位 = 任运态
```

→ 操作目标永远在 **substrate 层**（不放逸 / 平等 / 正直），不在涌现态（无功用住 / 行舍整体 manifest）。

**教学含义**：
- 修行者报告"心很平静 / 状态很好"时，**优先询问"是否在 substrate 层"**（不放逸 trigger 是否运作 / 平等是否在场 / 正直是否在场）而非"是否已得行舍"——前者是 target check，后者是 sign 错位入口
- 报告"似乎到了某种 stage"时，**用三相 axis 精确分诊代替整体性 label**——避免给 integer label 让末那 hijack 为 actor-status

## 核心 reveal 3：5/16 现量精确诊断 — "正直一相 partial manifest"严格 framing

修行者 5/16 实修反馈"未追求更好 / 更久 / 更稳 / 想确认境界"——按主线 1-2 framework 精确诊断 = **正直一相的 partial manifest**：

| 三相 | 5/16 substrate 状态 |
|---|---|
| 平等 | 🟡 部分（粗显掉举减少，明记断片仍频繁）|
| 正直 | 🟡 partial stable（sign/target 不错位在场）|
| 无功用住 | 🔴 未涌现（三段式仍需主动 catch + 提明分）|
| 不放逸（substrate）| ✅ trigger 四次验证稳定 |

**三种解读判别**：

| 解读 | 判定 |
|---|---|
| A（行舍 manifest 早期信号）| 错——"行舍 manifest" 暗示三相整体涌现 |
| B（仅闻思熏种）| 错——已是 dispositional state partial |
| **C（正直一相 partial manifest）** | ✅ 严格 + healthy framing |

→ **行舍 manifest 严格意义 = 三相协同涌现 + 无功用住后位达成**。修行者 5/15-5/16 cool state 中表现态度（"明记断片仍频繁——继续每日累积，不试图一次解决"）= 第三 framing 的 implicit 实操。

**教学含义**：修行者报告"似乎已达成某种 stable"时，**应用严格 framing 防止 sign 错位**——具体诊断在三相 axis 上的位置（"X 一相 partial / Y 一相 stable / Z 一相未涌现"），而非给一个整体性 label。

## 核心 reveal 4：行舍者相 hijack 防御（anchor formulation drift 在行舍场）

行舍场的 actor-status drift 形态：

| drift signal | 含义 |
|---|---|
| "我已得行舍" | 把 partial manifest 升级为整体 manifest = sign 错位 |
| "我已任运" | 把 in-session stable degree 误识为稳态 disposition |
| "X 是行舍 manifest 早期信号" | 把正直一相 partial 误识为整体涌现起点 |

→ **行舍者相 hijack = 最微细掉举形态本身**——把"我在维持行舍稳态"作为残余 effort = 无功用住的反面 = 加行 → 任运过渡场的精确风险。

利根者最易撞的形态 = "把正直一相 partial manifest 升级为行舍整体 manifest"。修行者当前双 anchor（"了无自性" + "所有错=无知造成的"）都不指向 actor status，但坐中起步阶段 partial manifest 升级误识仍是结构性风险。

**教学含义**：
- 修行者出现"我已 X"类表述时**立即递归识破**（假说 13 递归惭愧机制）
- 用三相 axis 精确分诊代替整体性 label
- 监测信号：cool state 中如出现"我已得行舍 / 我已任运 / X 是行舍 manifest"= 风险信号；如保持"X 一相 partial / 继续累积" framing = healthy

## 核心 reveal 5：受舍 vs 行舍 partition 现量入口 = "守所缘"判准

5/16 derive 出**受舍（受蕴 phenomenal feeling）vs 行舍（行蕴 dispositional state）partition 的精确机制 anchor** = 睡前禅定监测原则中"那段时间我是否还在'守'所缘？"判准：

| 判准答案 | 现量层 partition |
|---|---|
| "在守" | dispositional active = **行舍**方向（agency 在场）|
| "失守 / 不知道" | phenomenal passive = **受舍 + 惛沉 / 散乱**|

修行者 5/15-5/16 "明记断片"被 healthy 判为非真定——这层判别现量中已运作，**受舍 vs 行舍 partition 已在场**，只是未 explicit 命名。

**教学含义**：
- 修行者报告坐中体验时，**优先询问"是否在守所缘"**而非"体验是什么"——前者直接命中 partition 现量入口
- "心很平静"未必是行舍，可能只是受舍——必须 check agency / 守所缘判准
- partition 是 dynamic in-session 现量层，不是稳态 disposition——不能由"我一般在守"等 trait-style 答复 reduce

## 核心 reveal 6：行舍 vs 不放逸 dimension ⊥ + 当前修行重心

| 维度 | 不放逸（守护面）| 行舍（任运面）|
|---|---|---|
| 答的是什么问题 | "还在开吗？"（motion continuity）| "开得自如吗？"（motion quality）|
| manifest 层 | time domain | state domain（三相 axis 复合）|
| 失败模式 | 停下来 = 放逸 | 行驶不稳 = 掉举 |
| 操作 pattern | 直接 operate (trigger design) | 不直接 operate (操作 substrate) |
| 当前修行者位置 | 🟡 active 操作区 | 🟡 monitor 区（不在 active push）|

→ **不放逸是修行者当前 active 操作区，行舍是后位涌现 monitor 区**——当前修行重心仍在不放逸 substrate stable 累积 + 平等 substrate（禅定主轨）累积，行舍只做 in-session 三相 stable degree 评估即可。

**教学含义**：
- 后续讨论中，不在行舍层施加操作压力——禅定主轨 push 是为了平等 substrate 累积，不是为了"得行舍"
- "5/26 trigger design 回填" + "B 双盘训练座启动"是当前 substrate active 操作目标
- 行舍场只做 in-session 现量 monitor，不做 push
