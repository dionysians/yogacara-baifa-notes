# 教学操作核 1：亲子场无嗔

> **reveal 日期**：2026-05-02
> **回链**：[CLAUDE.md 各心所事件层操作核](../../CLAUDE.md#各心所事件层操作核)

修行者亲子场作为无嗔最关键现量训练场，其精确操作不在"努力压住害心"，在两条更深的线：

1. **三种现行净配比** — 事件层"是否成功不起害"是次要的，关键是每次现行后两类种子的最终净配比（详见 [无嗔.md §十.1](../03-心所法/善心所/无嗔.md)）：
   - 一念害心起（未外显）→ 害种子（低强度）
   - 一念害心起 + 即时识破（无嗔现行）→ 害种子已熏 + **无嗔种子更强**（净配比正向）
   - 完全无害心起，慈悲心直接现行 → 无嗔种子高强度
   → **起害心后快速识破并起无嗔补偿，比"努力压住不起害心"更重要**——前者熏厚对治种子，后者可能反向熏种（压抑造成的不安隐感）

2. **真无相缘的长期一致训练** — 对孩子施"无差别对待 / 平等慈悲"的长期一致缘，**actor 心所层的不害圆满，且不主动激发受者我执**（详见 [无嗔.md §七](../03-心所法/善心所/无嗔.md)）。鉴别真不害 vs 伪不害的判准：
   - 慈悲行起时是否伴随"我在爱他 / 我为他付出"自我形象？
   - 是否能在不被孩子"反馈感恩 / 接受"时仍保持平等慈？
   - 是否能允许孩子拒绝你的慈悲方式？
   → 三问皆肯定时为真无相缘；任一否定则需校准
