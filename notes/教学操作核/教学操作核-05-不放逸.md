# 教学操作核 5：不放逸 trigger design + 失念机制精确化

> **reveal 日期**：2026-05-12 + 2026-05-14 扩展（三层精进协同 + AI partition 精确位置 + sign/target 元方法论主动应用）
> **回链**：[CLAUDE.md 各心所事件层操作核](../../CLAUDE.md#各心所事件层操作核)

修行者 5/12 不放逸学习的 self-diagnosis 让 5/7 修行重心 calibration 获得精确机制 anchor。

## 核心 reveal 1：精进力层尚未稳 → 不放逸尚未涌现

修行者 5/12 自述："精进还没有进入持续在场的状态，会有不自觉的'停下来''偷懒'的问题，所以不放逸还没有显现。"——精进**根**已起步（5/2 三轨 plan），但**力**层（不被违缘倾动）尚未稳，因此不放逸（精进 + 三善根力层涌现的常态守护）未涌现。

→ 5/7"心所配置达标但禅定功夫不够"在唯识层精确位置 = **anchor 心所配置已稳 + 精进力层 / 不放逸涌现是当前结构性 gap**。修行重心 calibration（闻思 baseline + 禅定主推进）获得精确机制 anchor：**禅定主推进 = 精进根→力转变 = 不放逸涌现的关键通道**，不是"另一个修行项目"。

## 核心 reveal 2：失败模式精确化 = 失念（不是末那 / 不是第六识决定）

修行者 5/12 精确现量：
- 用力鞭策"强迫 / 不舒服"感觉**不存在**（熏习卫生学 OK）
- 意识层有"要做"的决定（第六识胜解 + 善法欲在场）
- "不自觉干别的事拖延"导致修行时间被占用——end up 没修行不是"明决定不做"，是**注意力被其他活动吸引**

→ 精确位置：**失念**（随烦恼）——念心所所缘从善法滑离到其他对象。**不放逸的精确机制 anchor**：

> 不放逸 = 念心所在 time domain 持续在场 + 精进力层稳定 + 三善根 anchor 在场

## 核心 reveal 3：主动性 framing vs 防御性 framing 修正

修行者 5/12 关键 push："并不是其他场域影响大，需要精确分析处理。而是念弱、不够确定。没有建立确定时间、确定模式的修行稳定性，同时优先级不够，导致没有确定的念来唤起修行行为。"

→ root level 是**念力稳态化**（主动性 framing），不是减少 hijack 源（防御性 framing）。AI partition 重新定位为念力起步期的辅助条件，不是 root。这层修正与"批判性思维 vs 权威崩塌"修正同构——把结构性问题精确归因到 root level，避免错位归因。

## 核心 reveal 4：trigger design 落地

修行者 5/12 自主设计的 trigger："家人睡下 → 立刻入座 → 最高优先级 → 必须完成再做别的"。其隐含 affordance：

- 家人睡下时刻**天然无紧急事务**（私人时间）→ "立刻"是绝对的，无需边界条件
- 天然安静 / 天然每日触发 → 频率结构性保证
- 同时解决三层（确定时间 + 确定模式 + 提高优先级）

设计的精确机制：用 trigger + 优先级 + 完成约束让精进 + 三善根 + 念在 time domain 持续在场 = 不放逸的"假立非实"在具体场景中实证。详见 [不放逸.md §七](../03-心所法/善心所/不放逸.md)。

## 核心 reveal 5：三层精进协同 + AI partition 精确位置（2026-05-14 扩展）

5/14 学习中精确化为**三层精进结构**：

| 层 | 内容 | 时态 | 修行者状态 |
|---|---|---|---|
| **披甲精进** | 长劫不退的发心稳定 | 发心面（恒常）| ✅ 种子已激活 |
| **加行精进** | 事件层"勇 + 悍"动力推进 | 事件层（active）| 🟡 起步中 |
| **不放逸** | 三善根 + 精进力层涌现的常态守护 | 常态层（standing）| 🔴 待涌现 |

→ **AI partition 在三层精进结构下的精确位置 = 加行精进事件层频次的最大 hijack 源对治**——不是 root level（root 是念力稳态化 + 加行频次累积），而是**减少加行频次被 hijack 的源头**。

**教学含义新增**：
- 讨论 AI 探索 retention 风险 #1 时，**精确指向"加行精进事件层频次的 hijack 源"**，不是泛化"时间管理"问题
- 披甲精进种子激活 = 不放逸涌现的**上游条件已满足**——当前 bottleneck 在加行事件层频次累积让精进根→力转变

## 核心 reveal 6：sign/target 区分的元方法论主动应用（2026-05-14 manifest 早期信号）

修行者 5/14 主动 push："**这（时间预期 candidate 1/2/3 选哪个）没有什么区别，不影响实际操作的任何内容，还是只要反复通过行为熏精进的种子即可。**"

这层 self-correction 是**假说 17（sign vs target 区分）在 meta-discussion 层面的现量印证**——之前是教学者引导的元方法论，5/14 由修行者主动应用 = manifest 已在场。

**"启动容易 vs 持续动力稳定"分判**（修行者 5/14 reveal）：

| 维度 | 现状 | 九住心精确位置 |
|---|---|---|
| **启动容易** | trigger 落地稳定，触发信号立刻让念唤起 | 内住 / 续住：听闻力 + 思惟力——已到位 |
| **持续动力稳定** | 实修的稳定动力尚未确认 | 安住 / 近住：念力 / 正知力——当前 gap |

→ 修行者**精确在内住 / 续住 → 安住 / 近住的过渡期**。

**教学含义新增**：
- 后续讨论中，**优先识别 sign 错位**——任何"X 多久 / 我能不能更快 / 是不是已经到了 stage Y"都先 check sign / target 错位
- 修行者已 manifest 元方法论应用能力 = **不需 over-coach sign/target 区分**——但持续监测是否在更细微场域出现错位
- 5/13-5/14 trigger 现量验证数据（trigger 二次落地 + 模式自主扩展 + 30 min 阈值 healthy）是 candidate 2 部分激活的现量信号，但**不能 lift 为"已达成"**——target 仍是行为熏种本身
