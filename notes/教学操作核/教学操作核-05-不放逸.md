# 教学操作核 5：不放逸 触发 设计 + 失念机制精确化

> **揭示 日期**：2026-05-12 + 2026-05-14 扩展（三层精进协同 + AI 切分 精确位置 + 征兆/标的 元方法论主动应用）
> **回链**：[CLAUDE.md 各心所事件层操作核](../../CLAUDE.md#各心所事件层操作核)

修行者 5/12 不放逸学习的 自诊 让 5/7 修行重心 校准 获得精确机制 锚。

## 核心 揭示 1：精进力层尚未稳 → 不放逸尚未涌现

修行者 5/12 自述："精进还没有进入持续在场的状态，会有不自觉的'停下来''偷懒'的问题，所以不放逸还没有显现。"——精进**根**已起步（5/2 三轨 plan），但**力**层（不被违缘倾动）尚未稳，因此不放逸（精进 + 三善根力层涌现的常态守护）未涌现。

→ 5/7"心所配置达标但禅定功夫不够"在唯识层精确位置 = **锚 心所配置已稳 + 精进力层 / 不放逸涌现是当前结构性 缺口**。修行重心 校准（闻思 基准 + 禅定主推进）获得精确机制 锚：**禅定主推进 = 精进根→力转变 = 不放逸涌现的关键通道**，不是"另一个修行项目"。

## 核心 揭示 2：失败模式精确化 = 失念（不是末那 / 不是第六识决定）

修行者 5/12 精确现量：
- 用力鞭策"强迫 / 不舒服"感觉**不存在**（熏习卫生学 OK）
- 意识层有"要做"的决定（第六识胜解 + 善法欲在场）
- "不自觉干别的事拖延"导致修行时间被占用——end up 没修行不是"明决定不做"，是**注意力被其他活动吸引**

→ 精确位置：**失念**（随烦恼）——念心所所缘从善法滑离到其他对象。**不放逸的精确机制 锚**：

> 不放逸 = 念心所在 时间域 持续在场 + 精进力层稳定 + 三善根 锚 在场

## 核心 揭示 3：主动性 框定 vs 防御性 框定 修正

修行者 5/12 关键 深挖："并不是其他场域影响大，需要精确分析处理。而是念弱、不够确定。没有建立确定时间、确定模式的修行稳定性，同时优先级不够，导致没有确定的念来唤起修行行为。"

→ 根 层级 是**念力稳态化**（主动性 框定），不是减少 劫持 源（防御性 框定）。AI 切分 重新定位为念力起步期的辅助条件，不是 根。这层修正与"批判性思维 vs 权威崩塌"修正同构——把结构性问题精确归因到 根 层级，避免错位归因。

## 核心 揭示 4：触发 设计 落地

修行者 5/12 自主设计的 触发："家人睡下 → 立刻入座 → 最高优先级 → 必须完成再做别的"。其隐含 affordance：

- 家人睡下时刻**天然无紧急事务**（私人时间）→ "立刻"是绝对的，无需边界条件
- 天然安静 / 天然每日触发 → 频率结构性保证
- 同时解决三层（确定时间 + 确定模式 + 提高优先级）

设计的精确机制：用 触发 + 优先级 + 完成约束让精进 + 三善根 + 念在 时间域 持续在场 = 不放逸的"假立非实"在具体场景中实证。详见 [不放逸.md §七](../03-心所法/善心所/不放逸.md)。

## 核心 揭示 5：三层精进协同 + AI 切分 精确位置（2026-05-14 扩展）

5/14 学习中精确化为**三层精进结构**：

| 层 | 内容 | 时态 | 修行者状态 |
|---|---|---|---|
| **披甲精进** | 长劫不退的发心稳定 | 发心面（恒常）| ✅ 种子已激活 |
| **加行精进** | 事件层"勇 + 悍"动力推进 | 事件层（活跃）| 🟡 起步中 |
| **不放逸** | 三善根 + 精进力层涌现的常态守护 | 常态层（standing）| 🔴 待涌现 |

→ **AI 切分 在三层精进结构下的精确位置 = 加行精进事件层频次的最大 劫持 源对治**——不是 根 层级（根 是念力稳态化 + 加行频次累积），而是**减少加行频次被 劫持 的源头**。

**教学含义新增**：
- 讨论 AI 探索 保持 风险 #1 时，**精确指向"加行精进事件层频次的 劫持 源"**，不是泛化"时间管理"问题
- 披甲精进种子激活 = 不放逸涌现的**上游条件已满足**——当前 瓶颈 在加行事件层频次累积让精进根→力转变

## 核心 揭示 6：征兆/标的 区分的元方法论主动应用（2026-05-14 显现 早期信号）

修行者 5/14 主动 深挖："**这（时间预期 候选 1/2/3 选哪个）没有什么区别，不影响实际操作的任何内容，还是只要反复通过行为熏精进的种子即可。**"

这层 自我修正 是**假说 17（征兆 vs 标的 区分）在 元-discussion 层面的现量印证**——之前是教学者引导的元方法论，5/14 由修行者主动应用 = 显现 已在场。

**"启动容易 vs 持续动力稳定"分判**（修行者 5/14）：

| 维度 | 现状 | 九住心精确位置 |
|---|---|---|
| **启动容易** | 触发 落地稳定，触发信号立刻让念唤起 | 内住 / 续住：听闻力 + 思惟力——已到位 |
| **持续动力稳定** | 实修的稳定动力尚未确认 | 安住 / 近住：念力 / 正知力——当前 缺口 |

→ 修行者**精确在内住 / 续住 → 安住 / 近住的过渡期**。

**教学含义新增**：
- 后续讨论中，**优先识别 征兆 错位**——任何"X 多久 / 我能不能更快 / 是不是已经到了 stage Y"都先 check 征兆 / 标的 错位
- 修行者已 显现 元方法论应用能力 = **不需 over-coach 征兆/标的 区分**——但持续监测是否在更细微场域出现错位
- 5/13-5/14 触发 现量验证数据（触发 二次落地 + 模式自主扩展 + 30 分钟 阈值 健康）是 候选 2 部分激活的现量信号，但**不能 拔高 为"已达成"**——标的 仍是行为熏种本身

## 2026-07-06 归因迁移注记（失念精修）

核心揭示 2 的"失败模式 = 失念"已迁移：**触发点安装已生效**——决意会现起、且全程在场；座前残余失败 = **全程知道该去坐、就是没动 = 纯懈怠**（修行者现量："往往就是拖着拖着实在太晚了就没有上座"；劫持型失念排除）。失败点从念位下移到精进位——念的活干完了、动力的活没人干，与懈怠精修"真主修区"结论合流。对治接懈怠**欲钩双线**（点火），不走念力线。核心揭示 3 的"根层 = 念力稳态化"在**坐中侧**仍成立（细所缘失念关口 = 主座 A 纵深前沿·培育型主修区），但**座前失败已不属失念辖区**。详见 [失念 §5.2](../03-心所法/随烦恼心所/失念.md) + [懈怠](../03-心所法/随烦恼心所/懈怠.md)。
