# 教学操作核 3：无痴的双线操作

> **reveal 日期**：2026-05-03
> **回链**：[CLAUDE.md 各心所事件层操作核](../../CLAUDE.md#各心所事件层操作核)

修行者无痴的修行操作不依"ε 缩小"作目标（这是 sign 不是 target，假说 17 提示），而依两条独立工作线并行 push：

- **线 1：烦恼种子势力弱化**
  - 操作核心 = **事件层每次现行后真实 anchor 现行**（不强 push 速度）
  - 烦恼起 + 即时识破 + 双 anchor 现行 → 不熏新烦恼种子，反熏对治种子 → 旧烦恼种子无新熏 + 缘缺自然衰减
  - 关键判准：事件结束后是否真有"无痴 anchor 现行覆盖了痴根"，还是仅"烦恼自然消退"（境缘衰减不是修行成果，且烦恼仍熏新种子）

- **线 2：无痴 anchor 加强**
  - 操作核心 = **闻思 push 通透（深入诸理事）+ 定中持守 anchor 作所缘**
  - anchor 种子势力增厚 → 在更广场域、更高境强度下仍稳；让 anchor 不只在事件触发时升起，在定中作背景持续运作（D- → D+ 下沉）
  - 关键判准：anchor 是否在**未触发场域**也作背景运作，还是仅在触发时即时升起

- **ε 缩小（速度变化）**：仅作伴随观察，**不作直接目标**

## 双 anchor formulation（修行者童年内化）

- "了无自性"——ontological 层 anchor，处理现象层执着的不实（去主体化）
- "所有错都是无知造成的"——actor / 因果层 anchor，处理错的根因 = 痴根（去 actor 化）
- 两 anchor **互补不重合**，State D 同步升起的精确机制 = 双 anchor 简并覆盖痴根
