### 四、恨单法精修（第二场 · 60 分钟 · 单法学习循环五段）

新建 [恨.md](../03-心所法/随烦恼心所/恨.md)（重写 2026-03-05 模板初稿）。恨为 E 分位假立小随、见自侧已在忿精修预闭合，故主线收为 **2 条**，重心在主线 1"现行↔基态"与见众生"恨底层是爱"。

- **① 概念（闻）**：恨 = 瞋"怀怨储存分位"（"由忿为先、怀恶不舍、结怨为性、恒热恼"）；三个"恨独有"锚点——"由忿为先"生起次第明文 / "不舍"静态储存相 / "恒热恼"对内自苦（恨主要受害者是自己）。
- **② 主线 1（分位机制 + 嗔系链位置）**：忿→恨是一次**相变**（发出态→储存态：忿有自然衰减、恨无，须主动舍）；**现量精化——静态储存 = 微观脉冲串**（"持续"实为反复触发的"主动重新结怨"，无衰减真相是反复续命）；**"不舍"双层 = 现行↔基态种子线**（主动不放 = 现行 / 无法放下 = 熏成基态；"独立无先后 + 基态由现行熏成"= 种子↔现行标准结构，修行者拒立膨胀把并列二分收成一条线）；两种恨所缘二分（贪粘着对象被损 / 我执认定被破，触发源不同但恨体仍瞋一分）。
- **③ 见自**：**不是截断点位、是归因方向从源头改道**（双锚"所有错=无知"去行为者 → 无知非可怨对象 → 直接抽掉恨的所缘基础，与忿"愧上游截"是同一去行为者机制两出口）+ **递归惭愧 = 纵向下沉、终点无常无我**（修行者澄清"不存在横向递归"，归为假说 13 本义，够用就停）+ **"觉得人坏"=恨恼产物**（双锚改道故很少觉得谁坏）+ 见自侧结构性不现行（闭合）。
- **④ 见众生 + 利他善巧轴归位（本法关键产出）**：**恨底层是爱**（凡夫"明知苦还抱怨"实为抱底层所爱不舍 = 由爱生嗔）+ **见自见众在无常无我合流**（修行者出口 / 凡夫缺口）+ **利他善巧轴缺口精确归位**——缺口在**心侧**（理解烦恼内在机制）非境侧（外缘处境修行者能理解，修正"把人当可建模对象/对事"旧框）+ **"烦恼少者反向利他缺口"**（自身烦恼少 → 缺被烦恼绑架的经验 → 补法走认知路径非情感共情）+ **见众生线 = 利他善巧轴百法内直接修学路径**（缺口二分：百法内学烦恼机制 / 百法外四摄方便待菩萨道）。

## 💭 学习心得

- **学习流程的元级调整**：把"补强闻的前端"与"不削弱现量分诊后端"同时守住，是这次方法论调整的核心张力；并沉淀出"指导各归其位、不重复登记硬规则"的 CLAUDE.md 维护元原则。
- **现量分诊多次修正比量框定**（一如既往的核心价值产出）：不是评判而是"我所强加" / 感应器先起非识破先 / 愧惭是嗔链上的时序双点而非仅方向对偶。
- **见自见众是同一跃迁两面**：愧（不强加）负向清场 + 悲悯理解正向涌现——利他善巧轴缺口第一次有了现量填补信号，不再是结构性等待。
- **看破在闻思、常态在事件**：识破来不及在事件中当场发生，必然落在闻思预载层；事件里跑的是被熏成常态的惭愧感应器——这是"看破→熏种→常态"三步循环的机制兑现。
- **（恨场）拒立膨胀的现量收敛**：修行者把"主动不放 / 无法放下"的并列二分自行收成一条"现行↔基态"种子线，又一次把模型分出的两个结构收回成一个（递归=纵向下沉同理）——向已有结构收敛、不立新假说的现量级警觉持续运作。
- **（恨场）利他善巧轴缺口的精确化**：缺口不在"觉得人坏需要转变"（修行者无）、也不在"理解外缘处境"（能），而精确在"理解烦恼内在机制"（为何放不下 / 为何明知蠢还做）——"烦恼少者反向利他缺口"是个反直觉而深刻的结构：修行越好越缺被烦恼驱动的切身经验，故补法走认知路径。见众生线由此升级为利他善巧轴的百法内直接修学路径。
