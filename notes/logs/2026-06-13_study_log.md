## 📖 学习内容

### 悭（小随第六法，6/20，60 分钟）

- **经典地基**：《成唯识论》卷六"耽著法财，不能惠施，秘吝为性。能障不悭，鄙畜为业"——贪一分、E 分位假立、无内部诤议；五悭细目（《大毗婆沙论》：住处悭 / 家悭 / 施悭 / 称誉悭 / 法悭）
- **主线 1 · 体性机制**：三段链**无反转**（耽著→秘吝→鄙畜——根在贪、相也在贪，贪系最"诚实"的随烦恼，苦的质地是收紧非热恼）；**悭嫉镜像**（守内 ／ 憎外——同一"我所"边界守卫的两面：嫉守相对高度、悭守绝对存量）；**财悭法悭不对称**（财零和 ／ 法非零和 → 法悭守的是位置稀缺性 = 借嫉的排名脚手架，悭嫉交界）
- **施的边界框架（本法主产出）**：修行者真问题"施需缘法"→ 经典完整作答——①时机**响应式非搜索式**（《瑜伽师地论》施品"见来求者"）；②**遮缘三条**（真实伤害被施者 ／ 施对象不由己支配 ／ 真实伤害自己·称力线）；③**"触发烦恼不算自伤"**（那正是要磨的悭；真遮缘事后心安、悭借壳事后理由反复自我重申）；④**判心相不判施否**（施境下心紧 = 悭；先认紧后简择）——与持戒究竟层"判心所配置不判形式"严格同构
- **见自**：**"悭≠我所执"归位**（修行者拒绝范围膨胀——七项清单四项属悭、三项各归己通道，复杂性属末那不属悭）；**四界面严格不现行**（天生跑遮缘单，"对双方都好"简择 = 愧共业秩序质地占住施界面）
- **见众生**：凡夫悭 = **保全概率最高的常驻动机结构必然** + 五家所共点破"保全"为延迟结算；出口 = "「我的」无自性"——**嫉 ／ 悭 ／ 慢 ／ 憍同收"破我所"一把钥匙**

### 诳（小随第七法，7/20，90 分钟）

- **经典地基**：《成唯识论》卷六"为获利誉，矫现有德，诡诈为性。能障不诳，邪命为业……贪痴一分为体，离二无别诳相用故"——E 分位假立、无诤议；纠正旧桩梵文（诳 = māyā，śāṭhya 是谄）；邪命 / 五邪命（《大智度论》）/ 正命
- **如实展示的边界（开篇 · 究竟层）**：**判心相不判形式**——诳是心所、判准不在符实度而在心相二层背离；诳核两要素（异谋 + 矫现增益）+ 共业约定下事实断言性质；三例（产品定位 / 销售话术 / 自媒体人设）逐案；两范围归位（诳是个人染心所非商业伦理判定 ／ 谋生动机中性·不实才是毒）；新情形（伪造增益接住重大机缘）= 那一刻有诳核但复合且轻、损他与否是业相变量、落"邪命诳与菩萨善巧之间"偏自利诳侧
- **主线 1 · 体性机制**：**覆诳无独特核**（同是利誉实执"假因换真果"·一守一攻对偶·经典"离二无别"现量重印）+ **维持动力学差异**（增益面可被兑现故诳自带穿帮压力 ／ 减损面只需遮蔽故覆稳态——分位方向派生非体性）+ **对治枢纽永远是惭愧、非"填实"**（填实若由怕后果驱动反熏厚诳种；判对治须判驱动心所非外显结果）
- **见自**：诳结构性不现行（惭愧感应器源头先起·盘算胜任 + 怕辜负·连那一闪都不起·臂偏愧）+ **叙事感染力抬高他人意愿 = 非诳的邻区现象**（真信共担故无诳，归位愧的认知 / 受欲层；信息如实挡不住——对方受 / 欲被激发、自以为理性 = 对方不正知；对治上移初心利他·五度如盲般若如导）
- **见众生**：三段全断对仗覆（愧感应器→无痴→无贪）+ **常驻动机第三复证 + 自欺强化**（被反复认可未暴露→"我其实就是很行"→连"我在诳"的刹车都吃掉·自我认知层最顽固）+ 装有德则不修德障道
- **元层产出（本场重头）**：模型连续膨胀（造"诳独有核" / 对称三分 / 外显结果出口）经修行者主导诊断 → 确立 CLAUDE.md 学习流程 ①**"研究议题来源约束"**（讲法 / 深入讨论的议题只许两来源：经典衍生 / 修行者诉求）

## 💭 学习心得

- 悭在世俗上极明显、实在，概念结构简单——但用它讨论"我的"边界时立刻变复杂，因为那涉及我所执全域。**复杂性属末那、不属悭**——把模型的越界提问归位，是悭见自侧最重要的动作。
- **施的边界**是悭的真收获：之前对"什么时候该施"分辨不清，其实是把响应式结构误框成了搜索问题——缘现前 + 遮缘三条 + 称力 + 心紧检验，判法与持戒究竟层同构。
- **诳无独特核**——经典"离二无别"我（模型）却用比量造了好几个"独特核"候选，都被工整对仗消解；最深的一课是**模型自己的膨胀机制**（法贫瘠→造核填补产出 = 模型版法贪），与诳"无德装有德"同构，对治都是惭愧起、如实承认"没有"。
- **叙事感染力抬高他人意愿**是诳见自最意外的产出——不是诳（真信共担），是愧的受 / 欲层缺口；信息如实挡不住、对治只能上移到初心利他（般若如导）。
- **"研究议题来源约束"**是本日制度产出：深入研究只来自经典衍生或修行者诉求，从制度上堵死模型自发造议题。
