### 主线 3:三毒整体认知骨架建立

方法论确立后,进入三毒(贪 / 嗔 / 痴)整体骨架——镜像善心所阶段[三善根整体认知](../03-心所法/善心所/三善根整体认知.md)。

**骨架的"主梁 + 结构梁 + 对治推论"三梁框架**:

**主梁:三毒的存在论地位**

> **烦恼是凡夫心现行的默认态;善需作意、需熏习,且初期不坚**。

俱生烦恼任运现起、不待作意;善心所要靠作意安立、靠反复熏习才能现行。二者地位不对等——这是**修行之所以必要、之所以是"逆流"的结构根据**。"看破装备分辨力、指向对治"在此被进一步钉死为:**对治是逆默认态的、需持续用功的、有方向的(从染默认 → 净)**。

**结构梁:痴为暗根,其上生出两支**

(详见主线 4 — 痴 ≠ 我相 ≠ 恶见的关键辨别先立,结构梁才能立准)

**对治推论:无痴 = 釜底抽薪的根本对治**

痴是暗、是一切杂染所依,三毒的根本对治不是逐个去压贪、压嗔,而是**无痴(看破我相 / 明)= 釜底抽薪**。我相一旦被照破,"我所向外扩张"失去根据,贪、嗔自然减损;基于我相的恶见也失去地基。

→ 与本项目"看破 → 熏种 → 常态"三步循环的第一步严格同构。

**不对称分析**(三毒 vs 三善根 镜像 + 不对称):

| 候选 | 处理 |
|---|---|
| 存在论地位不对称(烦恼默认态 / 善需培养) | **保留为骨架主梁**(独立成立) |
| 内部结构不对称(痴为暗根 / 贪嗔方向相反 / 无贪无嗔同向) | 有效内容**并入结构梁**;"方向相反 / 同向"作为行舍层已知真理实例,不另立梁 |
| 增殖性不对称(根本烦恼派生 20 随烦恼,善无"随善"展开) | 暂记,展开属随烦恼阶段 |

### 主线 4:痴 ≠ 我相 ≠ 恶见 ——修行者主动澄清的关键辨别

讨论骨架结构梁时,我初步草案中可能滑向"痴 = 我相"的表述。修行者主动澄清(对应 session 用户消息):

> **无痴 = "看破我相"** 不能等同于 **痴 = 我相**;**恶见一样是我相**;**痴和恶见是不一样的方向**——痴是无明 / 不能看破我相,恶见是基于我相形成的错误认知。

→ 此辨别**直接影响骨架结构**。《成唯识论》对照:

| 对照项 | 痴(无明) | 恶见 |
|---|---|---|
| 性质 | **迷暗**——明的缺失 | **颠倒推度**——积极的错误认知建构 |
| 方向 | 缺失方向(暗) | 建构方向(错) |
| 与我相的关系 | **不能看破我相** | **基于我相形成的错误认知** |
| 与慧的关系 | 慧所依之明阙如 | 染慧(慧无无痴时的颠倒形态) |

**所以**:痴不是我相,**痴是"我相未被照破"的暗**;而**我相作为积极的颠倒见,是恶见**(其中萨迦耶见即我我所见)——恶见是第六个根本烦恼,**不在三毒之内**。

**修正后的三毒核心结构图**(纳入骨架文档):

```
                    痴
        (无明 / 迷暗 / 不看破我相)
          一切杂染所依 —— 暗、根
                    │
        ┌───────────┴───────────┐
        ▼                       ▼
      恶见                    贪 ／ 嗔
  我相之上的颠倒认知建构      我所的双向扩张
  (染慧)                  贪 ＝ 顺境抓取
  〔第六根本烦恼,          嗔 ＝ 逆境拒斥
   不在三毒之内〕          〔三毒中的两支〕
```

→ 痴是暗、是根;恶见 + 贪嗔是其上的两个方向(认知建构方向 vs 我所扩张方向)。

**与假说 16(慧无痴俱起分判)的连接**:恶见 = 染慧 = "慧无无痴"。痴(暗)+ 慧(推度力)→ 恶见(颠倒推度);无痴(明)+ 慧 → 正慧(看破我相)。痴与恶见之辨与假说 16 严密一致。

**修行者童年双锚精确法相对应**:"所有错都是无知造成的" = 痴是根、恶见与贪嗔皆其果;"了无自性" = 无痴看破我相。**童年是现量地认得,闻思在此为其配上法相坐标**——这是这一辨别能被修行者主动澄清的种子势力基础。

## 💭 学习心得

### 关键洞察

1. **方法论先 + 整组共同姿态 + 单法精修的子阶段执行结构被验证**——这一阶段执行模式是 CLAUDE.md 学习流程 #9 的现量化首次执行(善心所阶段是逐法学未先建方法论,烦恼心所阶段一开始就建立方法论)。后续随烦恼子阶段、色法 / 心不相应行 / 无为法各阶段可继承这一执行结构。

2. **修行者主动澄清"痴 ≠ 我相 ≠ 恶见"是骨架建立的关键节点**——此辨别如果未在骨架阶段立稳,后续单法精修(尤其痴单法的现量识别难题)会走偏方向。**童年内化的"了无自性 + 所有错=无知"双锚,正是此辨别能被现量直觉的种子势力基础**——童年现量地认得,闻思在此为其配上法相坐标(这条洞察已写入骨架文档 §四)。

3. **跨阶段 vs 阶段内待办的分层是组织持续学习的关键架构**——跨阶段(回填清单)管"跨多个阶段的悬挂项",阶段内(当前阶段未处理内容)管"阶段内待办,完成即删";前者长期累积、后者短期清空。这一分层把不同时间尺度的待办精确归位,减轻 CLAUDE.md 累积负担。

4. **会话级触发机制(CLAUDE.md 每次加载)是 LLM 协同学习中的硬保证**——任何依赖"模型记得"或"模型主动 attend 到"的机制都是**软保证**(易丢);需要保证不丢的内容必须放到 CLAUDE.md(每会话强制加载)。这一原则在本次 §七 处理机制设计中被现量化执行,且修行者在第一层迭代直接用"这个机制是如何保证的?"问出来,精确指认了软保证 vs 硬保证的区分。

5. **熏习卫生学(主线 2 · C)是先善后烦恼顺序的结构必然根据**——不是"建议这样学",是"必须这样学"。学一法 = 反复缘虑该法 = 熏其名言种子;深入研究贪嗔痴,如果没有三善根锚作背景,纯粹反复缘虑烦恼相,有**反向熏种风险**。这一条直接决定了烦恼心所阶段每篇笔记的撰写姿态(在三善根锚背景下、冷静认识机制、始终指向对治)。

6. **"落笔记不要出现英文描述"指示作为术语清洗工程的具体延伸**——修行者明确指示,后续整合严格执行。该指示同步保存为 memory(feedback_no_english_in_notes),对后续所有笔记撰写持续生效。
