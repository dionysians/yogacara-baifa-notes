## 📖 学习内容

### 主线 1：贪单法 · 经典定位

**起点**：贪.md 原是 2026-03-05 占位 stub（通用模板），无贪.md 已有深研但贪本身的经典定位和体性分析从未系统学过。

**四槽位精确化**：所缘（有 + 有具）/ 体性（染著）/ 对治（无贪）/ 业用（障无贪 + 生苦）。梵文 rāga（染色）/ lobha（抓取）与"染著"二字精确对应。

**与嗔的严格平行**：贪（有/有具 + 染著）vs 嗔（苦/苦具 + 憎恚）——所缘结构完全平行（果+因双层），体性对反。直接坐实骨架"贪嗔 = 我所双向扩张"。

**贪 vs 欲辨别**：欲通三性（善法欲/染欲/无记），贪永远是染。分判在心所配置中有没有"我所"渗透。

### 主线 2：贪单法 · "染著为性"精确机制

**核心发现**："染著"拆开是**两步复合**——

- **染**（rāga 本义 = 染色）：心被所缘品质渗透，心取了对象的颜色 = 空间维度
- **著**（lobha 本义 = 抓取）：渗透后拔不出来，心反复返回 = 时间维度

**与痴的根本结构差异**：痴 = 缺失性（明的缺失），贪 = 积极性（心被主动渗透）。这决定了现量识别路径完全不同——痴只能靠无痴反向照见，贪有现象特征可直接觉察。

**触→受→贪转折点**：受（乐受）≠ 贪。受是遍行心所的中性感应，贪是受之后心对"味"的抓取。关键分叉由不正作意触发——痴在背景提供四颠倒。

**四颠倒——痴在贪机制中的具体运作**：常/乐/净/我四种系统性误读。四颠倒中**三个直接支撑贪**（常、乐、净），这解释了经典四对治观中三种针对贪（无常观/苦观/不净观/无我观）。

**修行者现量印证**：常倒最典型——好听的音乐体验需要心境+认知+耳识+音响条件全部到位（缘起），但常倒让心把"拥有录音"当作"保留体验"。

**对心三效果**：色调改变 / 我所边界移动 / 种子层加固（正反馈循环 = 上瘾的精确种子机制）。

### 主线 3：贪单法 · "有有具"与染著扩张性

**"有具"（惑、业、资具）三类精确化**：修行者要求详细展开。惑 = 烦恼本身（动机层）；业 = 惑驱动下的具体行为（行动层）；资具 = 支撑存在的物质条件。三者协同感招三有。

**修行者第一个关键修正——有具 = 心构造的因果叙事**：

修行者指出："条件只是凡人'认为'它是产生果的条件，而不是实际的条件"。精确化为：经典"有具"是存在论描述（有具**是**惑业资具），修行者体验中的"贪有具"靠痴构造的因果叙事运作——两层同时成立，落差正是痴。

**修行者第二个关键修正——染著的扩张性**：

经一天沉淀后修行者提出更根本的描述：贪有具的递归不只靠"因果叙事"（那是痴的贡献），**染著本身就有扩张性——心被染色后颜色向相邻所缘自动渗透**。"爱屋及乌"是经典例证（乌鸦不是爱人的因，没有因果叙事，只有染著的渗透）。

→ 双层机制确立：层一（贪自身扩张性 = 更根本）+ 层二（痴给扩张提供轨道 = 加速定向）。层一解释了为什么单独破痴不能完全止贪。

**十二缘起爱→取精确对接**：取的四类（欲取/见取/戒禁取/我语取）= 染著扩张性在经典中的精确展开——扩张同时向四个方向蔓延。

**"生苦为业"苦的谱系**：修行者从自身体验列出完整谱系——没得到的苦 / 方法不完美的不满 / 结果不如预期的不满 / 达成后的满足感（满足感本身是下一轮贪的种子 = 苦的驱动器）。

### 主线 4：贪遍三界 + 断除次第 + 分别起/俱生

**贪遍三界**：三毒中唯一遍三界的（嗔只在欲界）。三界贪体性相同（染著），所缘从粗到细（五欲→禅定境→无色定境）。

**五下/五上分结**：色贪、无色贪与无明在同一组（五上分结）——最后断的烦恼。三果不还圣者已断欲贪和嗔，仍有色贪无色贪。

**分别起 vs 俱生精确化**：修行者初始提出"本质上是一个东西，只是形成时间差异"——这在种子层对（都是种子），但经典区别在**现行机制**：分别起依赖概念框架（见道摧毁框架→种子断），俱生不依赖概念（想通不等于不贪，需修道渐弱种子势力）。第二次说明从经典核心定义出发，修行者确认更准确。

### 主线 5：贪的现行形态——识层分布与末那我爱

**识层分布**：前五识（触境即起）/ 第六识（主要显现场）/ 末那（我爱，恒时不断）/ 第八识（无贪——只与遍行五相应）。

**与痴三分的关键不对称**：痴在末那可以"独行"（恒行不共无明），贪在末那必须与我痴、我见、我慢**四者俱起**。→ 末那的贪以痴为前提，反过来不成立。"痴为根、贪为枝"在最深的末那结构层的精确落实。

**末那四烦恼逻辑依赖**：我痴→我见→我爱→我慢——恒时俱起但有逻辑依赖方向。修行者确认这是"推出"而非顺序——"爱我"必然蕴含"我与别人不同/我比别人好/我喜欢的最好"。

**§七 贪侧闭合**：我爱 = 贪在末那的精确形态，是一切"我所扩张"的源头。

### 主线 6：贪的现量识别——五层光谱

**识别 ≠ 对治（vs 痴的识别 = 对治）**：贪有现象特征可直接觉察，但觉察不等于消退——贪是积极性力量，不会因为被看见就消失。

**五层光谱**：
1. 粗显——"想要的张力"（"欲罢不能"触发）
2. 中等——"不想停/还要更多"（"能否自在停下"判准）
3. 微细——"我所感/持有感"（"消失测试"判准）
4. 精微——方法贪/修行贪（"满足感有无我味"判准）
5. 极微细——末那我爱（凡夫位不可操作）

修行者确认前四层都能清晰分辨——与无痴种子已厚直接相关。

### 主线 7：十二缘起中的贪——两个关键节点

**修行者观察**：十二缘起有两个关键节点（无明 + 爱），中间环节像"自动进行"。

**经典对应**：惑/业/苦三分——惑只有三支（无明 + 爱 + 取），苦类（识→名色→六入→触→受）= 果报自动展开不待作意。修行者的"自动进行"体感精确对应"苦"类。

**与痴三层对治的结构映射**：受→爱 = 层一（事件层干预）；闻思深挖 = 层二；无明 = 层三（止观双运）。

## 💭 学习心得

### 六个关键洞察

1. **"染著"拆为"染+著"两步的结构分析方法有通用价值**——"染"是心被渗透（空间维度）、"著"是心回不来（时间维度），两步合一才是完整贪。这对未来分析其他烦恼的体性可能有迁移价值。

2. **贪与痴的"积极性 vs 缺失性"对比，决定了现量识别路径的根本差异**——"识别=对治"只对痴成立，对贪则"识别"只是入口。这个区分避免了"我已看见贪所以贪应该消退"的微细我相。

3. **"有具=心构造的因果叙事"揭示了贪与痴的结构性缠绕**——凡夫贪有具时靠的是痴构造的因果图（常倒最典型），但染著扩张性作为贪自身的本性更根本——两层同时运作。这解释了为什么单独破痴（想通道理）不能完全止贪。

4. **末那四烦恼的逻辑依赖方向（痴→见→爱→慢）把"痴为根贪为枝"从骨架比喻落实为心所配置的结构事实**——我爱必须以我痴为前提，反过来不成立。

5. **分别起 vs 俱生的核心差异在现行机制而非形成时间**——见道断分别起是因为摧毁了概念框架（种子失去现行缘），俱生不走概念通道所以想通不等于不贪。初次说明偏表象，从经典核心定义重新说明后修行者确认更准确。

6. **十二缘起"两个关键节点"观察与经典惑/业/苦三分精确对应**——无明（根）+ 爱/贪（现世转折点）是修行干预的两个关键位置；苦类是果报的自动展开。

### 修行学落地

- **受→爱分叉 = 事件层操作核的精确机制背书**：已有的操作核（嗔四触发点、无痴双线等）本质上都在"受→爱/嗔"这个分叉点运作。
- **四颠倒 = 痴的具体运作形态**：后续事件层觉察中可以用更精确的标签——不只"这里有贪"，还能识别"哪个颠倒在支撑贪"。
- **色贪远期提醒**：修行者"对精巧的天然喜好"在禅定深入时可能以色贪形态现行。不是当前议题，但定位已立。

### 元-学习

- **修行者两次修正（因果叙事 / 染著扩张性）体现了"讨论中沉淀→精确化"的节奏**——第一次提出"因果叙事"是讨论当场的修正，第二次提出"扩张性"是经一天沉淀的进一步精化。这种"即时修正 + 延迟精化"的双步骤值得后续保持。
- **分别起/俱生的两次说明（表象→核心）提示教学中首次说明要从经典核心定义出发**，而非先给表面特征再补核心——修行者在第二次说明后明确认定更准确。

## 🔑 关键概念

- **染著为性**：贪的体性——染（渗透）+ 著（黏住），积极性力量（vs 痴的缺失性）
- **四颠倒**：常/乐/净/我——痴在贪机制中的具体运作，三个直接支撑贪
- **受 ≠ 贪**：乐受是中性感应，贪是受后心对"味"的抓取——不正作意为转折触发
- **染著扩张性**：贪的本性——向相邻所缘自动渗透，对接十二缘起爱→取
- **有具双层**：经典存在论（惑/业/资具）+ 修行者现象学（痴构造的因果叙事）
- **分别起 vs 俱生**：差异在现行机制（依概念 vs 种子力自动），不在形成时间
- **末那我爱**：贪在末那的精确形态——以我痴为前提、我所扩张的源头
- **识别 ≠ 对治**：贪有现象特征可直接觉察，但觉察不等于消退
- **十二缘起双节点**：无明（根）+ 爱/贪（转折点）= 修行干预的两个关键位置
