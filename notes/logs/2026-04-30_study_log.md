### 主线一：假说 8 的潜在冲突点 → 假冲突，闭合

修行者 push："经典所谓'精进力度'如何体现，又应该如何执行？"

**讨论结论**：原潜在冲突点是把"如救头燃"读成现代汉语的"用力大小"——这是误读。

- "如救头燃"紧接"无令失时"——失的是**时**（机会、无常），不是力。比喻对治的是懈怠 / 拖延 / 放逸，不是用力大小
- 《入菩萨行论》四力（信解 / 坚固 / 欢喜 / 暂止）全在心所配置层。**暂止力**明文说"过度用力反害精进"，与假说 8 同向
- 经典"力度"的真实操作内容 = 不拖延 / 频次密 / 方向清晰 / 遇阻不退——**全部是心所配置质量，不是意志肌力**
- 两传统（无功用 vs 如救头燃）不是张力，是**同一件事在加行 / 任运两个阶段位置的不同表现**

**整合动作**：

- 熏习机制与"用力"观.md 新增 §六"经典两传统的协调"，对此潜在冲突做主动校准
- §七~§十 顺延，学术诚实节补充《佛遗教经》/《入菩萨行论》经典依据

### 主线二：假说 11 的真问题——方便层在当代瓦解

修行者 push："窥基方便层（'怕讥嫌'）在我看来与究竟层冲突非常大。情绪基调'怕'具体怕什么？怕谁的惩罚？在崇尚个人表达的多元世界中，曾经的方便说法已经不是好的形式。"

**展开对话**——把潜在冲突点从**文献学问题**（窥基是否真支持二阶判分）升级为**实操层真问题**（方便层在当代是否还能工作）：

#### 三层瓦解机制

1. **共识场解构**：当代多元化使讥嫌来源不再统一；网络时代任何立场都有反对群体——所缘对象失稳
2. **机制本身被时代否定**：当代价值观（个人表达 / 独立判断 / "我命由我不由天"）把"因怕外界评价而不坚持己见"诊断为依赖型人格 / 社交焦虑——方便层的运作机制本身被时代价值观斥为人格弱点
3. **凡人对"恶"的认知错位**：违法 ≠ 造恶；社会主流接受的可能正是佛教定义的恶（如以"自我实现"包装的贪 / 以"竞争"包装的嗔）——讥嫌反映的更多是利益冲突，不是道德共识

#### 现代化方便层经不起推敲

修行者进一步 push（第二轮）："小共识社群中怕失去尊重 / 现代化重述的怕伤害关系等仍不成立——商业社会中社群本身基于利益重组流动，退出无强制后果；'别人的讥'更多是利益冲突，不是社会共识。"

| 现代化变形 | 实际机制（细查） |
|---|---|
| 怕伤害关系 | 要么"怕失去关系功用"（损益计算，非愧）；要么"伤害关系 = 在缘起网中给他人添苦"（**已迁究竟层缘起所缘**） |
| 怕违背承诺 | "鄙视的标准"从哪来？要么社会内化（已瓦解），要么自我审判（仍喂我相） |
| 小共识社群中怕失去尊重 | 商业社会中社群本身流动重组，无强制后果——共识场不稳定 |

**核心 insight**：方便层在当代不是"失效"，是"**瓦解**"。能在当代未破我执者身上继续工作的所有"愧式机制"，结构上都已**悄悄迁移到究竟层所缘**——即使当事人未意识到。

### 主线三：究竟层所缘的实操核——non-imposition

修行者再 push（第三轮）："抛开个人特性，从理性分析角度也很难从道德 / 社会共识谴责'坚持己见 / 不按常理 / 标新立异'。我个人理解中大多数应该愧的行为是'**将自身想法、认识、利益强加到他人**'——'己所不欲勿施于人'。"

**精化**——把当代理性可辩护的"恶"内容从经典方便层的"违反讥嫌"中扣除掉所有"在当代反而应被赞许的特质"后，剩下的真正"该愧"内容收敛到一个非常窄的核：

> **将自己的想法 / 认识 / 利益强加于他人**

这跟现代政治哲学 harm principle、康德"把他人当目的不当工具"、儒家恕道是同一收敛核。

**唯识 / 缘起观下的更深根基**：

- 每个有情是无始无明业种自相续的独立流（自因自果）
- 强加于他人 = 否认对方因缘自相续 = **把"我所"扩张到他人因缘流中**
- 由此：**究竟层愧的所缘 = "不向他人扩张我所" = 末那"我所执"对外辐射的事件级对治**

### 主线四：假说 12 升级——末那二维辐射的双轴对治

原"空性双面投射（法性 / 缘起）"在 non-imposition 实操核基础上获得更具实操性的运作含义：

| | 内向轴（向"我"内部） | 外向轴（向他人外部） |
|---|---|---|
| **惭** | 不固化身份相为"我"——"本来不应如此" | — |
| **愧** | — | 不向他人扩张"我所"——non-imposition |

末那俱生我执有内 / 外两个辐射方向：内向凝聚为"我"（自身相被固化），外向扩张为"我所"（把他人因缘流吞并入"我"的边界）。**惭对治内向凝聚，愧对治外向扩张**——比"法性 / 缘起"的方向描述更接近实操判准。

### 主线五：对修行者自身定位的补充——operating system 即究竟层结构

**第三层驱动的发现**——修行者直接走究竟层不只来自利根 + 空性见内化：

> 修行者的 operating system 本身就是究竟层结构的世俗化版本——universalizability（"如果大家都这样做，组织会变好还是变乱"） + reciprocity（"己所不欲勿施于人"）。这些不是"世俗替代品"，是**究竟层所缘在未明言的世俗语言中的现行**。

修行者不是"绕过方便层走究竟层"，是**从未在方便层运作过**——方便层在该修行者所处文化场中本就不成立。

这反向解释了之前几个特征：天然抗拒烟酒（不是"怕健康"或"怕嫌弃"，是缘起秩序中的自然回避）/ 小时候空性见的"认得"（共业秩序的现量识别）/ 在亲子教育中能放下"权威感"（自他平等的现量运作）。

教训：**假说网络一致性 ≠ 假说成立**。每条假说独立审视，比满足于"网络自洽"重要。

### 2. push 的层层递进威力

本日修行者三轮 push（怕讥嫌问题 → 现代化方便层不成立 → non-imposition 是真核）层层精化，每一轮都把对话推到更深的位置。

观察：当修行者主动 push 时，对话的产出质量远高于被动展开——主动 push 强迫框架经历真实的反例考验。

### 3. "方便层瓦解"对学术诚实的考验

承认"经典明文表述（怕讥嫌）在当代基本失效"是个**比"二阶引申"更激进**的论断。需要警惕：是否会因修行者文化场的特异性，而误把局部条件当成普遍条件？

但反过来——回避此论断而坚持"方便层在当代仍工作"也是不诚实的。结论应是：**方便层瓦解作为修行学观察成立，作为普世断言需更多 case 验证**。

### 4. non-imposition 作为不依信仰前提的入路

这个 insight 的修行学价值很大——它给当代世俗背景的修行者一个**不需要先证悟空性、不依赖任何信仰前提**的具体入路。但需要警惕的伪究竟层风险也对应升级：non-imposition 判准本身可被末那做成"我是有道德判断力的人"的精致我相。
