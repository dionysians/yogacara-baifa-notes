## 📖 学习内容

随烦恼小随第四法**恼**单法精修（沿用单法学习循环五段）。恼 = 瞋一分"追触暴热狠戾"分位（忿恨为先 / 追触暴热 / 狠戾为性 / 能障不恼 / 蛆螫为业），E 分位假立、**无内部体性诤议**（覆有安慧 / 护法之争，恼回到嗔系纯瞋平地）。恼是嗔系链"忿 → 恨 → 恼"的暴发点（第三相）。

**本法最大的产出不是结论、是一次现量自我校正**：精修中途模型把修行者亲子场的强忿误判为恼、并以"类化 / 俱生装载"顶替缺位的恨；修行者以"严格回经典 + 没有恨累积只是评估严重性"两步把这个双重膨胀拆掉，校回**强忿**。

### 一、概念讲解（闻）+ 一个关键澄清

- **恼的双爪所缘**：追**往恶**（已结之怨 = 恨的储存）+ 触**现违缘**（当下新违境）——唯一一个过去 + 现在两时所缘叠加的小随。
- **辨异**：忿（现前发作 · 热 · 执仗身业）/ 恨（境过怀怨 · 冷储存 · 热恼）/ 恼（追触 · 毒 · 蛆螫口业）= 一股瞋三换相位。
- **关键澄清（恼 ≠ 强忿）**：修行者问"为什么不把恼当成更强的忿"。回经典——**唯识按行相分立心所、不按强度**（贪强弱皆贪 / 慢七慢靠行相）。恼单列是因为**行相多了一根过去爪 + 质变出戾毒 + 出口换口业**，不是强度高。

### 二、主线 1 · 体性机制

- **恼 ≠ 强忿是双刃**：强忿仍是忿（强度非判据）/ 恼也非强忿（需恨结怨之往恶 + 狠戾 + 蛆螫，行相级另立）。
- **往恶爪严格 = 恨结怨之追忆**：经典"追往恶、触现违缘，心便狠戾，蛆螫他"锁成一条机制 = 追怨生毒。瞋种厚度 / 类化看不惯属**忿的强度源、非恼的库存**（订正一处膨胀）。
- **狠戾来自恨怨发酵**：怀恶不舍 · 热恼即发酵，越久越毒 = 恼比忿多一层戾的来源。
- **双爪对治**：断现前 + 清恨怨，戾毒为果、断两源即熄，不需第三味药。

### 三、主线 2 · 见自见众双线

- **见自 · 恼结构性不现行**：恼需「忿恨为先 + 追往恶」，修行者恨不现行（归因改道、无结怨）→ 无往恶可追 → 经典上够不成恼。嗔系链三相 = 忿（现行）/ 恨（不现行）/ 恼（不现行）。
- **见自 · 亲子训斥经现量校正 恼 → 强忿**：两点现量——① **愤发**（凶、大声、纠正性，明确无刺伤毒）= 无狠戾、不成恼（狠戾是恼的体）；② 会**翻旧账**但**无恨累积**——"只是让我感到这件事的严重性"，翻的是严重性证据、非结怨（"追往评估" ≠ 恼的"追往恶 · 追怨生毒"）。**强忿强度源 = 见解嗔"覆该禁"我所强加 + 屡犯严重性评估**（皆非恨；覆案最初的"见解嗔"判对了）。
- **见自 · "没认识到 = 分别"判定锁**：见解嗔伪装成客观标准 → 惭愧不亮 = 没认识到（非来不及）；闻思一拆即松（覆案看通三段皆缺后已能不发脾气）⟹ 出身分别（见道断分别、修道断俱生）。
- **见众生 · 嗔系链封顶**：凡夫真有恼（恨现行、有怨发酵）。恼 ← 恨 ← 贪——链根是没放下的贪；"他坏"看链末毒、"他苦"看链根爱执 = 苦因非坏人。**越陷越深苦**（戾 = 陈怨发酵到极毒，越刻毒者陷得越深）= 利他善巧轴第三层最彻底一填，连"最像坏人"的都还原成"陷得最深的苦"。

## 💭 学习心得

- **这一法真正学到的是"经典 > 假说"的现量演练**：模型连立的"恼-重判 + 类化库存爪顶替恨"双重膨胀，被"严格回经典搜三定义 + 现量没有恨累积"拆掉。误判被记进笔记作样本，比一个正确结论更有价值。
- **强度不是分立心所的判据**——这条在恼上第一次被逼到要害：一个很强的忿依然是忿，恼也不是强忿。判据永远是行相（所缘 / 体性 / 业用）。
- **"只是感到严重性，不是恨累积"是分诊的钥匙**：把"翻旧账"从恼里摘出来——追忆作"评估严重性"（喂忿的强度）≠ 追忆作"结怨生毒"（恼的往恶爪）。

## 🤔 疑难问题

- **恨库存的非记忆装载到底归谁**：修行者最初的"一看就想揍、无具体旧事"两机制（类化 / 俱生），经校正归为**忿的强度源**（瞋种厚度），不是恼的往恶爪。凡夫"看不惯某类即暴戾"是忿还是恼，仍需逐例用"有无狠戾毒 + 翻旧账是追怨还是评估"判，留待嫉 / 害等后续法复看。
- **亲子场强忿的对治执行**：闻思拆"覆该禁"我执（减强度源）+ 实修截现前忿，已给路径；任运程度待对治案 003 熏种追踪。

## 🔑 关键概念

- 恼 = 瞋一分"追触暴热狠戾"分位（E 分位假立 · 无内部体性诤议）
- 恼 ≠ 强忿（双刃）：唯识按行相非强度分立——强忿仍是忿 / 恼非强忿需恨 + 狠戾
- 双爪结构（现前爪触现违缘 + 往恶爪追往恶 = 恨结怨之追忆）
- 往恶爪严格 = 恨结怨之追忆（类化 / 俱生瞋种厚度属忿强度源、非恼库存）
- 狠戾来自恨怨发酵
- 恼结构性不现行（修行者恨不现行 → 无往恶可追 → 够不成恼）
- 亲子训斥经现量校正 恼 → 强忿（愤发无狠戾毒 + 翻旧账评估严重性非结怨）
- 强忿强度源 = 见解嗔"覆该禁" + 屡犯严重性评估
- "没认识到 = 分别"判定锁（闻思一拆即松 ⟹ 分别 · 见道断分别修道断俱生）
- 见众生：嗔系链 恼 ← 恨 ← 贪封顶 + 越陷越深苦（利他善巧轴第三层最彻底一填）
- 经典 > 假说 + 拒立膨胀现量自我校正样本（误判恼 → 严格回经典 → 校回强忿）
