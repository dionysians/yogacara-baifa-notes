## 📖 学习内容

### 无惭无愧（中随两法合修，11–12/20，120 分钟，中随收官）

- **经典地基 + 交叉反转**：《成唯识论》卷六——无惭"不顾自法，轻拒贤善"/ 无愧"不顾世间，崇重暴恶"；惭崇善愧拒恶 → 无惭拒善无愧崇恶（交叉反转、非简单加"无"）；**不耻过恶是二通相非别相**（圣教假说为体）。
- **概念追问 ①「知 / 不知」**：知归痴（迷暗于理）、耻归无惭无愧（不顾不耻）——别有体；"不知"落痴、既不召唤也不解除无惭无愧；无惭无愧所缘标尺是**客观贤善 / 暴恶**（法本如是 / 共业秩序），非主观是否认知到。
- **概念追问 ②「不知时无惭无愧干什么」= 灯灭 / 刹车松**：痴是灯灭（照不见）、无惭无愧是刹车松（纵恶放行、生长恶行）；**有覆无记 vs 不善** = 同有痴、差别卡在无惭无愧在不在场（在 → 不善生长恶行 / 不在 → 染而不造恶）= 别有体决定性反证。
- **§ 不善心与三性**：三性（善 / 不善 / 无记）+ 无记分有覆 / 无覆；不善三判准（感苦果 / 与无惭无愧相应 / 唯欲界）；**染心 ⊋ 不善心**（末那我执是染·有覆无记、非不善）。
- **主线 1 · 必俱起（定不相离）**：一把尺两面（自法 / 世间）+ 单一刹那 vs 跨刹那拼接；**过恶两面俱全 → 单一不耻必落两面**；排混搭（善不善不俱）+ 排单飞（无单面之恶）；善侧惭愧亦必俱。**刹那级业用**：刹那生灭 + 等无间缘 → "将起 / 中断"合一、惭愧逐刹那截断；**惭愧四情况**（预防 / 常态崇重 / 追忆 / 见地升级）= 善心所有独立正面体性、非烦恼函数。
- **主线 2 · "中"之指代落实**：中 = 不善心位结构性标记；恰好 2 法 = 善恶标尺两面决定；对治深度深一层 = **善心所对偶级**（立惭愧、非破事相；搭惭愧通道不另立）。回填骨架 §2.7。
- **主线 3 · 见自（核心更正）**：无惭无愧**确实现行**（非结构性不现行）——中随遍不善心、不挂靠特定境；现行场 = 残余不善心两处（亲子场强忿 + 法染色层见解嗔一阶，皆嗔系脉冲）；现量印证法染色层"我所立见"被损时**首刹那真起微细嗔（A 不善）→ 惭愧究竟层即刻截断**（脉冲 + 回落）；两场同型 = 皆愧外向轴清场；截断加速 = 征兆（标的 = 反应强度下降）。
- **主线 4 · 见众生 + 合流**：凡夫无耻 = 惭愧因缘两层不足（俱生种子薄 + 现世见地缘缺：方便层社会缘瓦解 + 究竟层内在缘未立）= 结构必然非品行缺陷；见自见众**同一跃迁两面**（看通"惭愧因缘决定不能升起" = 松"他应该有耻"见解嗔 / 我所强加）；利他落点 = 补缘（究竟层借用）、走认知路径。
- **§ 别有体诤议（经部还原 vs 护法别立）**：核心论据 = **没有根本烦恼外延 = 不善心**（贪嗔各偏、痴遍染太宽）→ 逼出别立；大不善地法（遍不善）vs 大烦恼地法（遍染）经典明文分格；动力 ≠ 不善性 / 熏贪嗔种 ≠ 熏不善业种 / 不归痴；现量感受不到 = 缺位型质地、不构成反驳。本项目宗护法、还原侧记第三层视角。

## 💭 学习心得

- 本场最硬的一关是**"定不相离"的两步证明**：排除善染混搭（善不善不俱）只证到一半，真正堵死"单飞"的是"**过恶本身两面俱全**"——单一不耻必落两面。修行者连续追问逼出了这个缺口，是我最初没讲透的。
- **灯灭 / 刹车松 + 有覆无记反证**是理解无惭无愧别有体的钥匙：痴负责"为什么没看见"、无惭无愧负责"没看见却照样不羞愧地把恶做大"。有覆无记（有痴无无惭无愧、染而不造恶）一刀证明二者别体。
- **见自的更正很重要**：无惭无愧不像多数小随"结构性不现行"——它遍不善心、是残余不善心（亲子场 + 法染色层）的伴生标记，确实现行（脉冲）。两场同型于愧外向轴清场，把中随接进了已有的惭愧线。
- **刹那生灭把"将起 / 中断"合一**：进行中的恶是不善刹那相续，惭愧逐刹那截断 = 阻止本应续起的下一个不善刹那——修行者这一步比我的"粗时"框架精确。
- **别有体诤议是"经典 > 假说"的又一次落地**：修行者重走经部还原路追问，经典（护法外延论据）正面回应，还原直觉记第三层视角而不取代护法。
