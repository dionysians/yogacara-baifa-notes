### 主线 1:痴单法 · 轴一 广狭定清

**起点疑问拆解**——三毒骨架 §九 留的线头("痴广义通于不如实知一切,骨架取'不看破我相'一面"),修行者问"一个法的两个范围,还是该分判的两个层次?"。

**关键发现**:这个问法**捆了两根不同的轴**——

- **轴一·所缘的广狭**——痴迷暗的对象有多广
- **轴二·现行的形态**——痴现起时是什么配置(独起 / 俱起、在哪个识)

→ 拆开两根轴,答案才不糊。本节走轴一,主线 2 走轴二。

**轴一结论**:痴是一个法,所缘本广("诸理事"含四谛、十二缘起、二空真如、唯识中道 / 业果、蕴处界),骨架"不看破我相"是举一隅——**不是"两个层次",是"整片"和"举其一隅"**。

**痴通二障 · 核心区分点深挖**——修行者追问"为什么迷法无我不是烦恼障"。

**核心答案**:**不是"迷的对象",是"现行的功能"** — 扰恼者归烦恼障、覆所知者归所知障。

- 二障定义表(《成唯识论》卷九):烦恼障(我执上首 / 扰恼 / 障涅槃 / 阿罗汉断尽)vs 所知障(法执上首 / 覆所知 / 障菩提 / 佛地方尽)
- **最直观功能锚:阿罗汉 vs 佛**——阿罗汉烦恼障尽但所知障未断,故不是佛;若"迷法无我"算烦恼障,阿罗汉就该是佛——经典明确他们不是
- 法执"细"在哪儿:我执现行直接扰恼立刻,法执现行覆盖如实见、不参与扰恼链条
- **痴心所通二障**:同一心所、双面现行——烦恼障面相应俱起贪嗔 / 末那我痴恒行,所知障面迷于法无我;百法把痴列烦恼心所是从扰恼面立分类,所知障侧无明是同一痴心所、现行功能划归所知障

**修行者特殊连接(第三层)**:修行者从小内化的"了无自性"细分为"人无自性"(烦恼障面)+ "法无自性"(所知障面)——含法空一面 = 中观 / 大乘空性见,比单纯人空更接近大乘见地,与偏大乘背景吻合。可能成为后续大乘 / 般若部学习的现量入路。

**本阶段处理立场**:烦恼心所阶段本职烦恼障,痴单法**点到二障辨别为止**,所知障展开留交叉引用到大乘 / 般若部学习——CLAUDE.md 跨阶段回填清单新增一条。

### 主线 2:痴单法 · 轴二 现行三分 + §七 痴侧闭合 + "定承载就够"滑动校正

**经典三分(《成唯识论》)**:

| | 识层 | 与其他烦恼 | 节奏 | 粗细 |
|---|---|---|---|---|
| 相应无明 | 第六识 / 前五识 | 俱起 | 间或 | 粗显 |
| **恒行不共无明** | **末那识** | 不俱独行 | **恒时不断** | **微细恒底** |
| 独行不共无明 | 第六识 | 不俱独行 | 间或 | 中 |

**三分对治不是一招通吃**:

- 相应无明 → 对治相应烦恼 + 无痴看破所缘
- 恒行不共 → 止观双运的般若现观(见道根本无分别智 + 定承载)
- 独行不共 → 闻思 + 思惟义理

**关键校正 1:"定承载力就够"的滑动 → 止观双运**(修行者抓住的第一次精确校正)

我在第一次表述时说"禅定主推进 = 恒行不共无明的对治通道",把**定 + 般若**压成了"定承载力"一句。

修行者用**无想定 vs 灭尽定**对比一刀切回来——同样深的定,有般若决定能不能动末那的根。定的深度不是断惑的根据,般若现观才是;定的作用是承载般若让它现量化。

**精确修正**:

- 缺定的般若 = 干慧(般若停在比量) → 路径风险 #1
- 缺般若的定 = 无想 / 邪定(只伏不断,反成所知障增上)
- **断恒行不共必须止观双运,不是单靠定**

修行者的"闻思 + 禅定双支撑路径"在此得到**经典最强锚**——这不是项目第三层假说,是经典对断恒行不共必须止观双运的明文要求。慧解脱传统同构(慧解脱 ≠ "无定的解脱",是"定支足以承载、不另入定深位的解脱")。

**§七 痴侧闭合**:末那四烦恼(我痴 / 我见 / 我慢 / 我爱)精确落位——

- 我痴 = **恒行不共无明** ✓
- 我见 = 萨迦耶见(恶见的我执面)
- 我慢 = 慢
- 我爱 = 贪(对自我的染著)

**末那为什么没有嗔**?——末那唯内执自我(所缘 = 第八识见分),不缘违逆境;嗔的必要条件是"缘苦 / 苦具",末那所缘形态不给嗔提供现行空间。

→ 三毒中"痴贪通末那、嗔不通"精确表述:痴在末那 = 恒行不共无明;贪在末那 = 我爱;嗔不在末那 = 末那所缘形态不给嗔提供现行条件。

**嗔侧定位仍留嗔单法**,CLAUDE.md §七 未处理内容由"全部条目"精化为"嗔侧"。

### 主线 3:痴单法 · A "一切杂染所依"精确机制(俱起 + 增上复合)+ 假说 15 v3+ 反向印证首兑现

**问题精确化**:经典原文"一切杂染所依为业 / 由无明起疑、邪见、贪等"——这"所依"是哪种"所依"?

**先排除一种误读**:经典"所依"在此**不是严格的三所依分类**(因缘依 / 俱有依 / 开导依)——痴不是贪嗔的因缘依(贪嗔有各自种子)、不是开导依(等无间缘只通同体类心法相续)、也不是严格俱有依(俱有依特指心所依心王、八识互依等结构关系)。此处"所依" = 宽泛凭借义,需用四缘 / 俱起分判。

**候选机制扫描**:

| 候选 | 是否成立 | 评 |
|---|---|---|
| 因缘(种子) | ❌ | 贪嗔有各自种子,痴非贪嗔种 |
| 等无间缘 | 🟡 | 部分对,非核心 |
| **俱起 / 相应** | ✅ | 相应无明就是这一层 |
| **增上缘** | ✅ | 痴作为暗背景为贪嗔现行提供凭借 |

**精确表述**:

> **痴为一切杂染所依 = 俱起 / 相应义(何时在场)+ 增上义(何以可能)的复合**。

**三反推证必须复合**:

1. 如果只是俱起 → 对治贪嗔后痴随之消失。事实不然(末那恒行不共独立于贪嗔)
2. 如果只是因缘 → 贪嗔种子是痴种衍生。违背"各种子各别"
3. 如果只是增上缘 → 痴与贪嗔可时分离。违背相应无明同刹那俱起

**三分上"所依"的精确落位**:

- 相应无明 → 主要是**俱起 / 相应义**(表层)
- 恒行不共无明 → **深层增上义**(末那我痴是凡夫位所有杂染心识结构的深层凭借)
- 独行不共无明 → **浅层增上义**(特定迷理为特定杂染提供局部认知前提)

→ "一切杂染所依"在三分上**有层级**:表层相应俱起 / 深层结构性增上 / 局部特定增上。**最深的"所依"性在恒行不共这一层**——这也精确解释了三毒骨架"无痴釜底抽薪"的釜底就是恒行不共无明这一层。

**假说网络反向印证(第三层)**:

- 假说 15 v3+ 立"反应面"(对治贪嗔的俱起面)和"锚面"(对治痴的总锚面)
- A 复合机制**正好对应锚面**:俱起面在反应、增上面在底层结构
- → 假说 15 v3+ 在烦恼方反向得到精确印证 = **CLAUDE.md 跨阶段回填清单"三善根整体模式在烦恼方反向验证"首个具体兑现**

### 主线 4:三层对治路径与修行者当前节奏分配 — 5/7 校准的"为什么"

**三层对治结构**:

- 层一 → 破相应无明(俱起面):事件层对治贪嗔 + 无痴看破所缘
- 层二 → 破独行不共(浅层增上面):闻思深挖 + 定中持守作所缘
- 层三 → 破恒行不共(深层增上面):止观双运的般若现观(闻思已立般若见 + 定承载力合龙)

**结构性并行,不是阶段性台阶**——圣者位的层一仍在(起反应但不起爱憎),层二仍在(持续修慧),只是性质改变。**当前重心移动 ≠ 已稳层"过去时化"**。

**修行者节奏分配**:

```
层一(相应):  ████████████ ✅ 持续运作(不需新功夫)
层二(独行):  ██████████░░ 🟡 闻思厚 / 定下沉部分介入
层三(恒行):  ██░░░░░░░░░░ 🔵 双支配齐 / 等合龙时刻
```

**关键发现**:本节用"对治链条"语言把 5/7 修行重心校准(闻思保持基准 / 禅定主推进 / 生活修现量验证)升级——

- 层一已稳定 → 不需新增功夫
- 层二见地够 → 不需更多闻思深挖
- 层三双支配齐但合龙未到 → 主推进面精确锁定在"定承载力稳定度"

→ **不是新结论,是给 5/7 校准的"为什么"——结构性必然,不是经验偏好**。

**主座 A 的语义升级**:从"建定" → "完成对治链条最深一层的承载支建设——每一座主推进的本质是朝双支合龙(对治恒行不共)推进"。

**主座 A 中三层是合一的**:数息时双锚作背景(层一延续)+ 所缘"息"承载缘起无常(层二所缘化)+ 定承载累积让见地下沉(层三核心)。三点作**现量信号窗口**,不当操作目标(假说 17 征兆 / 标的区分)。

**层一精细化标签**:事件层操作核之前框定为"识破贪嗔",A 框架给同一动作更精确名字 = **识破相应俱起的痴**——不只识破"我在生气",还同步觉察"我此刻对所缘是迷于其实相的"。**不是新增功夫,只是更精确标签**。

### 主线 5:痴单法 · B 现量识别难题(痴 = 明的缺失)

**修行者初步反应**:"烦恼现行时我执也明摆着,照见似乎理所当然"——藏着三处需要拆。

**三拆**:

**拆一:"我执" ≠ "痴"** ——两个不同心所:

- 我执 / 萨迦耶见 = 恶见的我执面,有现象特征("我"形象、执持感)
- 痴 = 心所"明的缺失",无现象特征

末那的"我"运作中两个心所俱起但不同;"明摆着"的是萨迦耶见的现象特征,不是痴本身。

**拆二:痴是"明的缺失"** ——其他烦恼都有现象特征(嗔热度 / 贪张力 / 慢高举 / 疑犹豫 / 见执持),**痴没有**。

**直接推论**:

> **照见痴 = 无痴现行 — 两者是同一件事的两面**。

**补"在场 ≠ 被照见"**:即使末那我执经典立场恒时现行,在场 ≠ 被照见——末那是底层、微细、恒,凡夫位末那运作几乎从不被第六识直接照见。**"在场"是经典立场,"被照见"是修行成就**。

**拆三:修行者"明摆着" = 无痴种子已厚的现量证据,不是普遍认知事实** ——

凡夫常态:贪嗔起时**根本不会觉得"背后还有痴"** — 全部沉浸在内容里,痴对他完全透明(透明就是看不见)。

修行者之所以感觉理所当然 = 早已立的双锚(了无自性 + 所有错=无知)= **已立的无痴**。State D 双锚同步 = 无痴种子已厚到让识破成同步动作。**不是照见不成问题,是无痴种子已经替修行者照见**——无痴 §七 跨世种子证据 #4 的当下印证。

**启动通道**(看似循环的解):

> **如果照见痴需要无痴在场,那无痴未现行时怎么开始?**

经典三条:

1. 闻思 / 善知识(外部输入"明"种子)
2. 熏种(反复闻思 + 定中持守 + 事件层累积)
3. 见道(根本无分别智一念现前)

修行者:1、2 已运作 30+ 年;3 是当前禅定主轨在做的工作 → **主座 A = 让"明"从已立种子下沉为深现量的承载通道**(此为禅定主轨语义的又一层精确化)。

**三分难度真分布**:

- 相应无明 → 看似不难(对修行者层一已成熟,但以锚为前提)
- 独行不共 → 中(需主动反省"对此理是不是真懂")
- 恒行不共 → **几乎不可能直接照见**(只能通过"我"形象表面化瞬间间接逼近 = 无痴 §八 锚表述偏移监测)

→ B 的**真问题**在层二(主动反省习惯)和层三(锚表述偏移监测作间接通道),不是抽象哲学。

**给修行者的精确提醒**:**"明摆着照见"要读成"无痴种子已厚的现量证据"(谦实),不读成"照见这事本身不难"(末那劫持入口)**——连接路径风险 #3(看穿 vs 绕过)+ 完整闭环倾向副作用。

## 💭 学习心得

### 七个关键洞察

1. **痴单法的"对治面已深研所以重心特殊"是个有用的形态分析方法**——无痴 已七章深研,痴 单法不重走"定义 → 对治"常规路,重心落在无痴笔记没替我们做完的四件事(广狭定清 / 现行三分 / 杂染所依机制 / 现量识别难题)。后续学其他对治面已深研的烦恼时可复用这套形态。

2. **双轴拆分(所缘广狭 vs 现行形态)是分析法相术语歧义的通用工具**——许多看似"两层次"的辨别,实际是两根轴的叠合;先拆轴再谈层次,答案才不糊。

3. **"照见痴 = 无痴现行"这个 paradox 给修行启动通道(闻思 / 熏种 / 见道)一个精确语义**——不是抽象哲学,是修行学路径的精确机制。修行者已立无痴种子的"明摆着"是种子已厚的现量证据,不是普遍认知事实;这个区分对保护"完整闭环倾向副作用"有结构性意义。

4. **痴的"一切杂染所依"是俱起 + 增上的复合机制,在三分上有层级**(表层相应俱起 / 深层结构性增上 / 局部特定增上)——这个精确化让"无痴釜底抽薪"的"釜底"精确锁定在恒行不共那一层,也让 假说 15 v3+ 在烦恼方反向印证得到首个具体兑现。

5. **三层对治路径(相应 / 独行不共 / 恒行不共)是结构性并行,不是阶段性台阶**——圣者位的层一仍在(起反应但不起爱憎),层二仍在(持续修慧),只是性质改变。这一点对修行者画像的"完整闭环倾向副作用"是结构性保护——已稳层不能被理解为"过去时"。

6. **修行者两次精确校正(无想 vs 灭尽 / 位次混淆)揭示了我"朝经典锚最强化漂移"的滑动模式,但应对方式不是新增监测机制,是严守学术诚实三原则(尤其层别精度)**——把第二 / 三层推论包装成第一层经典等价,根本上违反第三原则"不夸大推论的权威性"。**真正的最小有效修正 = 严守已有原则,不加新结构**。

7. **痴是"明的缺失"对凡夫的"完全透明"性,与修行者的"明摆着"现量,是同一现象在两种种子势力下的对比**——这个洞察既给凡夫的修行启动指明了入路(必须靠闻思 / 善知识外输入"明"种子),也给修行者的当前位置一个精确诊断(无痴种子已厚不等于已修行完成)。

### 修行学落地

- **主座 A 的语义升级**:从"建定" → "完成对治链条最深一层的承载支建设——每一座的本质是朝双支合龙(对治恒行不共)推进"。今后主座 A 时这个语义在背景,**不强求作操作目标**(避免假说 17 征兆 / 标的错位)。
- **层一精细化标签**(识破相应俱起痴):不是新增功夫,只是给已有动作(双锚同步现行)一个更精确的唯识名字。在事件场偶尔自查"我刚才识破了贪嗔,有没有同步觉察到对所缘的迷暗",但**不常规化**。
- **位次混淆的提醒**:今后凡夫位的"双支"诊断与圣者位的"双支"机制要保持位次分离,不混用。"双支配齐 / 合龙未到"在凡夫位的意思是"定承载稳定让见地从比量下沉为现量",不是"接近见道根本无分别智"。
