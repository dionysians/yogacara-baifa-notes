## 📖 学习内容

### 掉举（大随八法第一法，13/20，120 分钟，大随开篇）

- **概念地基（闻）**：《成唯识论》卷六——掉举"令心于境不寂静为性，能障行舍、奢摩他为业"；梵文 auddhatya（ud 上 + dhā 置 = 心高举不安）；四维拆解（所缘不固定 / 体性"不寂静"飞扬 / 业用障行舍奢摩他 / 五盖之掉举盖）；与散乱（流荡多境）、惛沉（沉钝下坠）的三法辨异。
- **发散一 · "举我"机制**：举我作掉举的引力中心（心飞扬需引力源 = 末那举我）——**但现量未印证**（举我捕捉不到、两个可分的不同层面机制），降为第三层假说；L4 位置慢 ⊃ 掉举（末那静态举我可独立 / 第六识掉举飞扬必依）。
- **发散二 · DMN + 后得智**：默认模式网络（DMN）↔ 掉举 / 散乱 / 举我色法镜像（DMN 自我枢纽 ↔ 举我）——校正"证明"为"色法镜像、非证明"（色心二法不可塌缩）；由"消解 DMN 会不会出生存问题"逼出**功能-染色二分**（对治掉举 = 释放染色非删功能）→ 转识成智 / 后得智（功能保留、净化为权智 = 议题⑤缺口）；中道贯身心两层；破"消解 = 丧失生存功能"伪问题（圣者存在性证明）。
- **主线 A · 体性机制**：举我引力中心（第三层未印证）+ L4 ⊃ 掉举 + 三法辨异。
- **主线 B · 见自核心更正**：掉举**罕现非主现行**——闻思场主现行是"想搞明白的驱动力"（欲性非飞扬）；自立**驱动力三态分诊**（精进 = 善欲 / 纯粹好奇 = 无记欲 / 法贪 = 染欲，核心判准 = 观照贪心所有无"抓取放不下"）；法贪层进展 = 定力支撑识破 + 及时中断（边界：末那附着层 + 无记好奇时间维度待补）；念力反比双因素 + **禅定中惛沉 > 掉举**（下一法主修区）。
- **主线 C · 对治理解**：功能-染色二分 → 掉举对治终点 = 后得智（凡夫位缩影）+ 中道贯身心 + 破伪问题 + 接议题⑤（**现量印证：我执着色薄→看系统更清明**）。
- **主线 D · 别有体定夺**：护法两刀（通一切染心〔贪分不能尽·偏说贪分因贪相显〕+ 独立业用），与无惭无愧别有体诤议同构 = 独立体性 + 外延宽度不同（不善心 / 染心）。
- **主线 E · 见众生 + "大"起步**：凡夫掉举 = 举我恒转 + 无念力收 = 结构必然（走认知路径）；**"大"之指代起步**——两维独立共变（影响范围 / 对治深度·"能浅层处理就不成基底"）+ 对治深度三尺（看破难度 / 时间 / 定力配合强度·三层级非连续），待大随八法收官落实、骨架 §2.8。

## 💭 学习心得

- **本场最大的现量更正在主线 B**：原比量框定"掉举 = 法染色层主战场心举"被修行者现量否决——闻思场真正现行的是"想搞明白的驱动力"（欲性、可专注寂静），不是掉举（不寂静飞扬）。掉举在修行者位置罕现、是大随八降级第二例（不信首例）。
- **驱动力三态分诊**是修行者自立的现量操作，把议题②"善法欲 vs 法贪"二分**精化为三分**（独立切出"无记好奇"中项，与"欲通三性"严格对上），并用"抓取放不下"作贪的体性签名判准——干净、可直接进操作核。
- **两步发散收得很实**："举我"机制虽现量未印证（守住第三层标注），但 DMN 联想 + 后得智那一线非常有价值——**功能-染色二分**破了"消解我执 = 丧失生存功能"的伪问题，且修行者现量印证"无我化 → 看系统更清明"，给议题⑤后得智路径补了现量锚。
- **"大"之指代框架被修行者推进一步**：两维独立共变 + 对治深度三把尺（看破难度 / 时间 / 定力配合强度），把"看破深度尺"操作化、坐实"三层级非连续"——待大随收官用三尺量八法齐证后落实。
- **别有体诤议是"经典 > 假说 / 护法通用招式"第二次落地**：与无惭无愧同构（独立体性 + 外延宽度差一层），修行者用自己的"抓取 check"现量工具切开贪 / 掉举，教理与现量在同一把尺收口。
