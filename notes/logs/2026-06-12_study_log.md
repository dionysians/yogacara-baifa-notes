## 📖 学习内容

随烦恼小随第三法**覆**单法精修（沿用单法学习循环五段）。覆 = 贪痴一分"覆藏自罪"分位（于自作罪 / 恐失利誉 / 隐藏为性 / 能障不覆 / 悔恼为业），E 分位假立；安慧"唯痴一分" / 护法"贪痴一分"诤议（本论从护法）。覆是经典顺序里**首个跨出嗔系、首个有内部体性诤议**的小随。

### 一、概念讲解（闻）

- **所缘首次转向自身**：忿恨恼嫉皆缘他 / 违境，覆是小随中首个所缘 = 自作罪（向内）；发动机是"恐失利誉"（怕罪暴露失利养名誉），不是怕罪本身。
- **派系诤议**：安慧"唯痴一分"（论唯说痴分） / 护法"贪痴一分"（恐失利誉=贪分，论据粗显故唯说痴）。
- **与诳 / 谄辨异**：覆=藏已有之罪（减）/ 诳=诈现未有之德（加）/ 谄=曲顺以网他（曲）。

### 二、主线 1 · 体性机制（升级版）

- **痴分三层**（修行者现量延伸，唯识无明遍染 + 遍计所执框架支持）：浅=后果之痴〔经典明文〕/ 中=罪·利誉实执 / 深=负罪我执。护法立贪痴时"恐失利誉"已暗含中层实执。
- **所缘三层前提栈**：①有"罪"②是"我"作③暴露失利誉——抽掉任一层覆即无处可挂。覆缠的是"他自己认定的罪"（认定因人而异）→ 暴露覆所缘的非究竟性。
- **障不覆 → 自苦闭环**：藏→堵死发露→罪留种 + 怕暴露的持续不安隐→悔恼→更藏（闭环自续）。
- **三段接力对治**（现量自陈）：① 惭·感应器（"藏"念一起本能不适、"像闻到烟味般"，先于慧）→ ② 无痴（藏也没用、改变不了什么）→ ③ 无贪（失了利誉也没什么大不了，**收尾必需**）。
  - **感应器先起是共性、依法不同臂**：忿用愧 / 覆用惭；烟味签名 = 跨世惭愧种子（假说 10 再确认）。
  - **无贪收尾必需 = 现量印证护法"贪痴一分"、否安慧"唯痴"**：俱生贪（利誉）真在生效、是"想藏"一闪的真正动力源——若唯痴则看破即散、不需无贪。

### 三、主线 2 · 见自见众双线

- **见自**：分别覆塌（认知层无贪无痴 + 愧主动拆前提栈——"看破永远对自己 / 说人话尊重共业"）+ **俱生覆动意一闪不成操作**（"想隐藏"一闪而过、记忆中无真正隐藏操作；拦截在"想隐藏意愿→隐藏操作"之间，同忿恨上游截族）。
- **见众生**：覆不现行须三段全断、**顽固度 = 三段难度乘积**；**覆"常驻动机"结构候选**（有贪 + 露则失 + 藏有非零保全概率 = 间歇强化最顽固）。
- **亲子样本 · 见解嗔合流（本法关键产出）**：孩子覆藏问题"特别重"= 修行者**见解嗔重场**（无感于覆 + 见后果重 → 训斥严厉）。看通三段机制（孩子结构性三段皆缺）→ 训斥"应该不藏"的强加基础被抽掉（归因改道族）→ **理解覆机制（见众）= 同时松见解嗔（见自）= 同一跃迁两面**。开生活修对治案 003 承载。

## 💭 学习心得

- **覆把"痴"的颗粒度撑开了**：修行者从"自作罪"概念延伸出"小随颗粒越粗、所对概念越不究竟"的体感——覆的痴不止后果之痴，更罩在"罪 / 负罪的我"的实执上。小随"双重假"（体分位假 + 所缘世俗概念假）候选由此立（先记不立、待小随复证）。
- **现量校经典派系**：用"缺了无贪就放不下"这条对治序列判据，从修行者位置独立给护法"贪痴一分"投了一票——又一次现量分诊印证 / 校准经典，且校的是真实诤议点。
- **见自见众又一次同一跃迁两面**：覆这一法落到一个修行者自身见解嗔重场（亲子），理解孩子的覆机制与松开自己的见解嗔是同一件事——利他善巧轴在百法内的认知路径填补再得一例。
- **拒立膨胀持续运作**：把"想隐藏意愿 / 隐藏操作"分清为"俱生覆动意一闪"与"不成操作"，没有外推为新结构；两条候选结晶都按"先记不立"处理。

## 🤔 疑难问题

- **小随"双重假"+ 两条轴是否吻合经典本意**：修行者第一体感（现行相状轴 / 离究竟轴两条），不确定是否经典区分小 / 中 / 大的本意，待后续学习中分辨。
- **覆"常驻动机"结构是否可推广**：小随其余法是否有同型"动力 + 失则损 + 行有保全 / 宣泄概率"结构，待逐法复证。
