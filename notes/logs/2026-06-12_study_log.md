# 一、覆（50 分钟）— 首个跨出嗔系、首个有内部诤议的小随

## 📖 学习内容

覆 = 贪痴一分"覆藏自罪"分位（于自作罪 / 恐失利誉 / 隐藏为性 / 障不覆 / 悔恼为业），E 分位假立；安慧"唯痴一分" / 护法"贪痴一分"诤议（本论从护法）。

- **所缘首次转向自身**：忿恨恼嫉皆缘他 / 违境，覆是首个所缘 = 自作罪（向内）；发动机是"恐失利誉"（怕罪暴露失利养名誉），非怕罪本身。
- **痴分三层**（现量延伸）：浅 = 后果之痴〔经典明文〕/ 中 = 罪·利誉实执 / 深 = 负罪我执。
- **所缘三层前提栈**：①有"罪" ②是"我"作 ③暴露失利誉——抽掉任一层覆即无处可挂；覆缠的是"他自己认定的罪"→ 暴露覆所缘的非究竟性。
- **三段接力对治**（现量自陈）：① 惭·感应器（"藏"念一起本能不适、"像闻到烟味"，先于慧）→ ② 无痴（藏也没用）→ ③ 无贪（失利誉也没什么大不了，**收尾必需**）。感应器先起是共性、依法不同臂（忿用愧 / 覆用惭，假说 10 再确认）。
- **无贪收尾必需 = 现量印证护法"贪痴一分"、否安慧"唯痴"**：俱生贪（利誉）真在生效，是"想藏"一闪的真正动力源。
- **见自见众**：分别覆塌（认知层无贪无痴 + 愧主动拆前提栈）+ 俱生覆动意一闪不成操作；覆不现行须三段全断、顽固度 = 三段难度乘积；**亲子样本见解嗔合流**——看通孩子三段结构性皆缺 → 训斥"应该不藏"的强加基础被抽掉 = 理解覆机制（见众）同时松见解嗔（见自）= 同一跃迁两面（开对治案 003）。

## 💭 学习心得

- 覆把"痴"的颗粒度撑开，"小随双重假"候选由此立（体分位假 + 所缘世俗概念假，先记不立、待小随复证）。
- 用"缺了无贪就放不下"对治序列判据，从修行者位置给护法"贪痴一分"独立投一票——现量校经典真实诤议点。
- 见自见众又一次同一跃迁两面（亲子见解嗔重场）。

## 🔑 关键概念

覆 = 贪痴一分覆藏自罪（E 分位 · 首个跨出嗔系）· 安慧"唯痴"/护法"贪痴"诤议 · 覆/诳/谄 = 减/加/曲 · 痴分三层 · 所缘三层前提栈 + 非究竟性 · 障不覆自苦闭环 · 三段接力对治（惭→无痴→无贪）· 无贪收尾印证护法 · 俱生覆动意一闪不成操作 · 顽固度=三段难度乘积 · 覆"常驻动机"候选 · 亲子见解嗔与覆机制合流 · 小随"双重假"候选

# 二、恼（90 分钟）— 回到嗔系 · 一股瞋三换相位之第三相暴发点

## 📖 学习内容

恼 = 瞋一分"追触暴热狠戾"分位（忿恨为先 / 追触暴热 / 狠戾为性 / 障不恼 / 蛆螫为业），E 分位假立、**无内部体性诤议**（覆有安慧/护法之争，恼回到嗔系纯瞋平地）。嗔系链"忿→恨→恼"暴发点。

- **恼的双爪所缘**：追**往恶**（已结之怨 = 恨的储存）+ 触**现违缘**（当下新违境）——唯一过去+现在两时所缘叠加的小随。
- **恼 ≠ 强忿（关键澄清）**：唯识按**行相**分立心所、不按**强度**——恼单列因行相多一根过去爪 + 质变出戾毒 + 出口换口业，非强度高。一个很强的忿仍是忿。
- **往恶爪严格 = 恨结怨之追忆**：「追往恶、触现违缘，心便狠戾，蛆螫他」锁成一条机制 = 追怨生毒；瞋种厚度/类化看不惯属**忿的强度源、非恼的库存**（订正一处膨胀）。
- **狠戾来自恨怨发酵**；双爪对治 = 断现前 + 清恨怨，戾毒为果、断两源即熄。
- **见自 · 恼结构性不现行**：修行者恨不现行（归因改道、无结怨）→ 无往恶可追 → 够不成恼。嗔系链三相 = 忿（现行·亲子场强忿）/ 恨（不现行）/ 恼（不现行）。
- **见自 · 亲子训斥校正 恼→强忿**：① 愤发（无刺伤毒）= 无狠戾、不成恼；② 会翻旧账但无恨累积——"只是让我感到这件事的严重性"（追往评估 ≠ 恼的追往恶追怨生毒）。强忿强度源 = 见解嗔"覆该禁"我所强加 + 屡犯严重性评估（皆非恨；覆案 003 最初的"见解嗔"判对了）。
- **"没认识到 ≠ 来不及"= 分别出身判定锁**：闻思一拆即松 ⟹ 分别（见道断分别、修道断俱生）。
- **见众生**：凡夫恼←恨←贪封顶（链根没放下的贪）+ **越陷越深苦**（戾 = 陈怨发酵到极毒）= 利他善巧轴第三层最彻底一填，连"最像坏人"的都还原成"陷得最深的苦"。

## 💭 学习心得

- 这一法真正学到的是"**经典 > 假说**"的现量演练：模型连立的"恼-重判 + 类化库存爪顶替恨"双重膨胀，被"严格回经典搜三定义 + 现量没有恨累积"拆掉，误判入笔记作样本。
- **强度不是分立心所的判据**——第一次被逼到要害。
- "只是感到严重性，不是恨累积"是分诊钥匙——把"翻旧账"从恼里摘出来。

## 🔑 关键概念

恼 = 瞋一分追触暴热狠戾（E 分位 · 无诤议）· 恼 ≠ 强忿（行相非强度·双刃）· 双爪结构（现前爪 + 往恶爪）· 往恶爪严格=恨结怨之追忆 · 狠戾来自恨怨发酵 · 恼结构性不现行 · 亲子训斥校正 恼→强忿 · 强忿强度源=见解嗔"覆该禁"+屡犯严重性评估 · "没认识到=分别"判定锁 · 嗔系链恼←恨←贪封顶 + 越陷越深苦 · 经典>假说自我校正样本

# 三、嫉（60 分钟）— 首个离嗔系违境链、起于他荣境

## 📖 学习内容

嫉 = 瞋一分"不耐他荣"分位（殉自名利 / 不耐他荣 / 妒忌为性 / 障不嫉 / 忧戚为业），E 分位假立、**无内部诤议**。首个把所缘从"违境链"断开、转向他荣境的小随。

### 一、概念讲解（闻）

- **三段链 + 反转**：殉自名利（根·贪）→ 不耐他荣（反转点）→ 妒忌·忧戚（相·瞋）。
- **根在贪、相在瞋**：动力在贪（殉自名利），现行体相是瞋（不耐他荣），经典据现行相判瞋一分。
- **顺境被我执读成逆境**：嫉脱离忿恨恼违境链的机关——他荣本是顺境（好事），"殉自名利"这把尺把它量成"我损"。
- **辨异**：与忿恨恼（违境链 → 他荣境断点）/ 与悭（悭守内 ／ 嫉憎外）/ 与慢憍（我他对比三朝向：我胜他 / 自盛 / 他胜我）。

### 二、主线 1 · 体性机制

- **"嗔←我爱←我痴"通则的显式书写**（修行者主导）：嫉根在贪却判瞋，不是嫉独有谜题——**所有嗔的来源都来源于贪 / 我爱**（末那俱生四惑我痴我见我慢我爱，嗔依"违我所爱"而起、无所爱则无所嗔）。"殉自名利"就是嫉体性定义里的前提部分，不需另找身份。
- **嫉为何挑明贪根**：忿恨恼的"违"是境直接违我所爱（贪根藏在背后）；嫉的"违"是顺境被我执二次加工，**不点破"殉自名利"就解释不了他荣凭什么成逆境** → 贪根必须挑明才接得住反转。

### 三、主线 2 · 见自见众双线 + 对治

- **见自二分 → 拆掉零和**：他荣起忧戚转瞬有，分非零和场（贪内容本身 → 转研究姿态）/ 真实零和场（贪排名 → 忧戚明显）。**修行者自主究竟**：二分本身默认排名实有，但**排名是比较心产物（想比则有、不想比则无），无天然带排名的境** → 零和场也能拆纯境（"零和场更难看破，正是契机"）。〔精度护栏：所空的是"我相对于他的价值序"，不否认物理结果。〕
- **对治双入口分离**：贪的求不得（回贪根，另一回事、可留贪作世俗动力）／ 嫉（拆"我他对立"动作）。命门在后者、**不必动贪根**；且**随喜反向磨贪**（一动作破嫉 + 磨贪，比硬断贪根善巧）。
- **究竟收于我痴**：连排名都不实 → 嫉究竟根 = 我痴（立实我中心 → 造比较 → 默认"别人有=我损"）。对治究竟 = **了无自性锚照破排名不实** → 嫉自动消，**收进无痴双线、不需独立通道**；慢/憍/嫉同一把钥匙（破实我中心，假说 18 一致）。
- **随喜质地"冷→平"校正**：模型曾推"随喜冷质地、缺为他高兴的情感"——属表层标签转移（信德冷质地〔限三宝〕泛化到对人随喜），经现量否决：实为**情感基线低波动但为他＝为己等量、无狂热极端、本具足**，不需"培养热情"（反成装相）。
- **见众生**：凡夫嫉 = 看不破排名无自性的结构性必然（把比较产物当实有、默认别人有=我损），非"心眼小"品行问题 = 利他善巧轴第三层最深一填。

## 💭 学习心得

- **见自侧由修行者主导逼到究竟根**：从"非零和/真实零和"二分，自拆"排名实有"预设，逼出"嫉究竟是我痴"——对治随之收进早已运作的无痴双线，嫉不需独立通道。
- **又一次"现量 > 假说"自我校正**：模型提"假说 18 在真实零和场无处可转、嫉必回贪根"，被修行者现量（排名不实）证伪。叠加一处模型"表层标签转移"自查（冷→平）。
- 慢 / 憍 / 嫉收成一把钥匙（破实我中心），三个我他对比朝向同源。

## 🤔 疑难问题（本日累积）

- **覆"常驻动机"结构是否可推广** + **双重假两条轴是否吻合经典本意**：仍待逐法复证（先记不立）。
