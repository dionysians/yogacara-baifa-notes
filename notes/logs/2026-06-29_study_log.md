# 场一 · 不信（大随第三法，90 分钟）

## 📖 学习内容

随烦恼大随第三法 **不信**（āśraddhya）单法精修，完整走单法学习循环（①概念讲解 → ②主线设计 → ③逐主线讨论 + 章末检验 → ④适应性扩展 → ⑤整合）：

- **①概念讲解**：完整镜像信（大随唯一与单一善法逐字镜像）、"心秽为性"、护法别有体、"惰依为业"校正（非"堕依"）、三法辨异、见众生形态。
- **②主线设计**：4 主线（A 体性与别有体定夺 / B 见自降级首例 / C 见众生+生起次第 / D "大"续推）。
- **③逐主线 + 5 章末检验**：
  - **主线 A**：别立"招式第四次落地"（护法两刀，落点在"自秽+秽他"独立业用）；横向/全局污染 vs 纵向专障；无明三显现面（了理/堪能/趋向）。
  - **主线 B**：降级首例落实——四要素现量未发现残留（守"未发现≠确证无"）；**信德冷质地校正为分面（实面起毛喜热法喜 / 德面冷）**。
  - **主线 C**：凡夫不信三面 + 心秽无报警 + 不信→懈怠生起次第；修行者懈怠根切分（精进力+痴一分 saṃvega，不走凡夫链）。
  - **主线 D**："大"三尺齐证基底配置级、不信是"基底义最纯"的一法。
- **⑤整合**：不信.md 改写为正式八节笔记 + 骨架 §2.8/§6.1/§3.2/§九 + 画像 §8.23 + CLAUDE.md 6 处 + 新建《清净道论》《喜（pīti）》两卡。

## 💭 学习心得

1. **检验一现量深化（修行者贡献）**：不信"全局污染"的真正结构 = 信"心净为性"是**善心所运作的公共基底**，不信污染的是这个基底本身（非逐个污染余心心所）——比模型原框更省更狠，给"别立自体"提供最强论据。
2. **检验三击穿"信德冷质地"标签（最重产出）**：闻思甚深法理打通现场**起毛喜**（浑身发麻、毛孔竖立 = 《清净道论》五喜之小喜）→ "信乐"按所缘面分质地：**实面（法理）强热质地法喜 / 德面（三宝人格化）冷质地**。"信德冷质地"精确限定为"德面冷"、不泛化到实面——"**热在理、冷在相**"是慧解脱信德的典型形态。冷质地 ≠ 不乐。
3. **懈怠根预埋（接下一法）**：修行者场域 B 懈怠不走"不信→懈怠"凡夫链，根 = 精进力 + **痴一分（saṃvega 紧迫感未通透）**；用"了/痴之别"切出双层（元认知无痴正知 + 法理层痴所障 = 递归的痴觉照）。治本要补这一分痴（思维无常/暇满令法理从比量通现量），非单靠策励。
4. **守界**：四要素降级"未发现残留、不作确证无"——降级首例不靠"证明没有"、只靠"现量找不到现行"，反更稳（修行者拒立膨胀的一贯姿态）。

## 🤔 疑难问题

1. **德面"冷"的开放点**：德面冷质地是质地真冷、还是"人格化崇拜型触发"在修行者理性结构/文化场里从未运作过（类比惭愧"方便层从未运作"）——留待将来遇三宝相关强境再现量核。
2. **理热相冷候选（第三层·不立定论）**：德面冷质地（信侧）+ 紧迫感未起（懈怠痴根侧）是否同源 = 慧解脱理性派"理热相冷"统一结构——待懈怠单法精修现量核。

# 场二 · 懈怠（大随第四法，90 分钟）

## 📖 学习内容

随烦恼大随第四法 **懈怠**（kausīdya）单法精修——大随八**第一个对修行者确实现行的真主修区**（前三法掉举罕现 / 惛沉降级 / 不信降级，唯懈怠现行）。完整走单法学习循环，重心从"落实降级"翻转为"对真主修区的深度诊断"：

- **①概念讲解**：完整镜像精进（继不信镜像信之后第二个逐字镜像）、方向判准「于诸染事而策勤者亦名懈怠·退善法故」（判方向退善法、非活动量）、本体归属**别有体无诤议**（对偶精进体性最鲜明 → 招式收束/终点）、三法辨异、入行论三懈怠。
- **②主线设计**：5 主线（A 定义镜像别有体 / B 见自主修区双根诊断 / C 对治双根双策略 / D 见众生 / E "大"续推+理热相冷收口），B/C 分开各自专注。
- **③逐主线 + 5 轮章末检验**：
  - **A**：方向判准用到 AI 探索（修行者精化判定路径：判"退善法"非"染净"·身忙而于修断事懈怠）；招式收束。
  - **B（最重·真主修区）**：懈怠根**三块并列**（痴侧暇满/行苦未现量·命好遮自苦 / 精进力双不足+无转换链 / 元层**遮强表弱**）——修行者否决"痴上游、双不足中性"上游假说；**遮强表弱**（空性见遮诠之学的结构签名：斩断〔遮〕能/升起〔表〕不能）→ **2D 模型**（操作遮/表 × 所缘理/相）→ 统一签名**"用果位见地消解因位动力"**（干慧机制）。
  - **C（对治）**：欲是点火、**欲非升起是胜解**（慧的活·点火开关在慧手里 → 遮强表弱非死局）；**欲钩双线**（A 求果德/不退/大自在·B 见众生苦→冷悲→菩提心）；经典骨架三士道 + 入行论精进品四力；善精进熏显非升起、靠现行熏。
  - **D**：见众生 + 见众生苦**撬入自苦**（绕命好遮蔽·见自见众苦谛现量合流·三合一）。
  - **E**：三尺齐证基底配置级（**第一个现量位证据**）+ 理热相冷收口（点火必走理路/胜解、不走情路/恐惧·并入 2D）。
- **⑤整合**：**新建专题文章《修道点火与遮强表弱——懈怠根诊断与欲钩双线》**（重点方向文档）+ 懈怠.md 改写 + 骨架 §2.8/§3.2/§九 + 画像 §8.24 + CLAUDE.md（含议题①干慧根因更新）+ 新建 4 卡（三士道/七因果/自他相换/不退转）+ 专题索引登记。

## 💭 学习心得

1. **懈怠是大随八第一个真主修区**：前三法皆"不现行/降级"，懈怠确实现行 → 从懈怠根一路挖到**修道动力（欲）如何点火**，这是罕有的对修行者真实主修区的深度诊断。
2. **遮强表弱（核心·空性见结构签名）**：修行者能**斩断**贪驱动紧迫（遮）、却**升不起**纯净精进（表）——能清楚分辨贪紧迫 vs 善 saṃvega（非表层标签转移）。贯穿惭愧清场强/悲悯涌现弱、干慧见空强/动力生弱。整合为 **2D 模型**（操作遮/表 × 所缘理/相：遮全能 / 表×理热 / 表×相冷）；统一签名 = **"用果位见地消解因位动力"**（干慧的精确机制）。
3. **对治的翻转（最实用产出）**：找不到"升起精进的心法"，因为**善精进不是升起的、是熏显的**；而点火的"欲"也不是升起、是**胜解**出来的（慧的活——所以表链点火开关在慧手里、遮强表弱不是死局）。欲钩双线：A 求不退/大自在（"不安稳"的表翻面·接披甲种子）+ B 见众生苦→冷悲→菩提心（认知路径·非热共情）。
4. **行苦厘清 + 见众生苦撬入自苦**：行苦 ≠ 被感受到的逼迫（"不执着就没逼迫"是现行级真证量，行苦是种子级"不安稳"·掌中毛感受不到才是凡夫位标准）；修行者自己的行苦被命好掩盖，但众生苦是显的 → **见众生苦撬入自苦**（绕命好遮蔽），见自见众在苦谛现量合流。无死恐惧大半是真资粮、不可动，只破"拿它给不急背书"。

## 🤔 疑难问题

1. **无死恐惧是否现量 + 中阴资粮**：现量自核为"非现量、是比量+想象"；中阴"认光明"的能力（偏空性见认本初光明那条、未现世专修中阴成就法）是否够——开放项，接主座 A 慧定匹配（空性见沉现量 = 中阴正资粮）。
2. **暇满/行苦"连比量都没有"**：对治起点比一般"比量沉现量"更靠前 = "无 → 比量 → 现量"；暇满/行苦的比量须先建起来。

## 🔑 关键概念
