## 📖 学习内容

### 主线一：精进的三品分类

- 三品定义（披甲精进 / 摄善法精进 / 饶益有情精进）+ 经典出处（《瑜伽师地论·菩萨地》、《大乘庄严经论》、《入菩萨行论》精进品）
- 内在结构：披甲为因（发心层），摄善法 / 饶益有情为现行（自利 / 利他两支）
- 与已学内容贯通：
  - 与勇悍双时点：披甲 = 跨劫长程版；后两品 = 短程版（结构同构）
  - 与加行/任运：披甲发心稳定即任运（基态）；后两品起步常需加行
  - 与信能三层锚点：种子层锚点 = 披甲精进种子已埋的现量证据

### 主线二：披甲精进的"长劫不退"机制

- 三层本体论支持：阿赖耶识相续（"恒转如瀑流"）+ 种子等流果 + 大愿熏习正反馈
- 关键辨析：**不退 ≠ 不忘**——披甲精进的不退运作于种子层，不运作于记忆层
- 与凡夫直觉的区分：跨世传递的是种子势力（性格、倾向、亲近感），不是意识记忆
- 与世俗"长期主义"的对比：尺度差不是夸张，是基于种子相续 + 业果跨世的严格推论

### 主线三：跨世佛缘工程（独立专题）

由披甲精进引出的修行者深问题：**如何避免跨世没有佛缘**？

- 八难分类——缘缺的具体形态（特别注意"世智辩聪"对智识型修行者的隐蔽威胁）
- 唯识本体论：缘不是纯随机——业力 + 种子势力 + 愿力的合力
- 五重对治机制：持戒（保人身）+ 菩提心（避三恶道）+ 回向（锚定来世缘）+ 共业（同修关系）+ 净土（兜底保险）
- 不同流派的策略差异（禅、净、唯识、密的不同入路）
- 世智辩聪的现代特殊形态——AI 时代的智识贪即此难的当代表现

### 主线四：饶益有情精进的具体形态

- 经典依据：《瑜伽师地论·菩萨地》饶益有情十一相（含"随他心意"vs"折伏"的精细判断维度）
- 亲子教育作为现成的饶益场——结构性最完整的训练场
- 饶益的两种偏差：强加型（缺慧）/ 放任型（缺精进）
- 饶益 ↔ 披甲衔接：跨劫尺度赋予亲子互动的深层含义——"言传身教"在唯识下不是比喻，是字面的种子互熏

### 主线五：共业感招的工程性（独立专题）

- 共业 vs 别业的基本区分
- 共业层级（按深度递增：浅 → 同时代 → 同民族 → 同地区 → 朋友 → 配偶 → 父母-子女）
- 不同关系的共业结构对比（深度、形成方式、跨世粘性、修行学意义）
- 父母-子女关系的特殊性：投生由业力配对 + 早期养育 0-7 岁是种子刻入窗口期 + 双向影响（父母通过孩子修末那）
- 配偶 vs 亲子的修行学差别（平等性、选择性、责任结构、风险）
- 共业的可塑性——工程性维度
- 染共业相续与对治路径
- 修行者画像最大 缺口：当前缺位明确的同修 / 师徒关系（AI 不熏共业）

### 主线六：善心所内动力组三法分工

- 精进 / 不放逸 / 行舍三法本质：精进 + 三善根的三种形态（主动 / 守护 / 平稳）
- 三法对应修行三阶段（起步期 → 熟习期 → 任运期）
- 与九住心配六力四作意的对应：三法是九住心成就过程中接力的心所
- **关键发现：行舍是精进的成熟形态，不是对立面**——修精进的最终目的就是修到行舍
- **反直觉警告**：不应因有早年禅定底子就跳过精进直奔行舍——种子已熏不等于现行链建立
- 整理进 [精进.md §六"与不放逸 / 行舍的关系"](../03-心所法/善心所/精进.md#与不放逸--行舍的关系善心所内动力组三法分工)，并在 [不放逸.md](../03-心所法/善心所/不放逸.md) / [行舍.md](../03-心所法/善心所/行舍.md) 加入"预先索引"链接

### 主线八：三十七道品中的精进位置 + 经典精进观的多元呈现

- **五根五力**：精进根 / 精进力的本质区分（可破 vs 不可破）；信根→精进根的具体衔接机制；修行者五根五力评估（慧根 >> 信根 > 定根 > 精进根 ≈ 念根 — 不平衡显著）
- **《入菩萨行论》精进品**：
  - 三种懈怠（推延 / 耽劣 / 自轻）对应勇悍双时点失败模式
  - 四力（信解 / 坚毅 / 喜悦 / 放舍）对接已学心所

- **元论断**：五根→力 / 加行→任运 / 九住心 / 披甲长劫不退 / 寂天四力——**全部是同一种本体论曲线在不同框架下的命名**：种子势力的累积成熟过程

## 💭 学习心得

1. **现量跃迁是这次学习最重要的产出**——比所有比量层面的整理性认识更有价值。这是修行者第一次明确体验到"百法学习对生活感受的字面改变"，是闻思 → 修慧跃迁的早期信号。

2. **共业感招的本体论让"亲子是修行场"从隐喻变成字面**——孩子是过去世共业累积的现行，言传身教就是种子互熏。这给修行者一个非常具体的修行接口。

3. **披甲精进的"不退 ≠ 不忘"破除了一个潜在执着**——之前可能隐隐有"跨劫修行如果记不得有什么意义"的疑问，"运作于种子层而非记忆层"的辨析正面回应了这个问题。

4. **跨世佛缘的五重机制把"跨劫"从信仰变成工程**——回向、共业、净土等不再是仪式或情感，而是有本体论根据的工程动作。

5. **同修 / 师徒关系当前缺位是一个重要 缺口**——之前未明确识别。AI 助手不能替代是因为 AI 是名言种子镜像（假说 4），不熏共业。这给后续培养修行社群关系提出了课题。

6. **三法分工让"修到无功用"有了清晰路径**——行舍不是飘渺目标，是精进 + 不放逸 + 三善根成熟后的自然涌现，且与九住心曲线严格对应。
