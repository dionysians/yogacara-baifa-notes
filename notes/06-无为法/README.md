## 📖 阶段概述

无为法是百法中的最后一类，共六种。与前面四位（心法、心所法、色法、心不相应行法）都属于"有为法"不同，无为法是非因缘所生的真实法，代表的是不生不灭、恒常不变的真理层面。

在唯识学中，无为法虽然不是因缘所生，但也不是独立于识而存在的实体——它仍然是识所显现的真理层面。六种无为法代表了不同角度、不同层次对"无为"真理的描述。

理解无为法，对于把握整个百法体系的究竟意义至关重要——前面的有为法告诉我们"一切现象是什么"，无为法则指向"现象背后的真实"。

## 📖 重要概念辨析

### 有为法 vs 无为法

| 维度 | 有为法 | 无为法 |
|------|--------|--------|
| 生灭 | 有生有灭 | 不生不灭 |
| 因缘 | 因缘所生 | 非因缘所生 |
| 变化 | 刹那变化 | 恒常不变 |
| 数量 | 94法 | 6法 |
| 性质 | 现象层面 | 真理层面 |

### 六种无为法的关系

六种无为法并非六个不同的"东西"，而是从不同角度、不同层次描述同一个"无为"的真理：

- **虚空无为** — 从"空寂无碍"的角度
- **择灭无为** — 从"智慧断惑"的角度
- **非择灭无为** — 从"缘缺不生"的角度
- **不动灭无为** — 从"四禅境界"的角度
- **想受灭无为** — 从"灭尽定境"的角度
- **真如无为** — 从"诸法实性"的角度（最根本）
