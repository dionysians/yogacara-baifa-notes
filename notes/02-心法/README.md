## 📖 阶段概述

心法，即八识，是百法之首。《百法明门论》以心法为首位，因为"一切最胜故"——一切有为法中，心法最为殊胜，是万法生起的根本。

唯识学认为"万法唯识"，一切现象都是八识的变现。因此，理解八识是理解整个百法体系的基础和关键。

八识按层次分为三类：
1. **前五识**（眼、耳、鼻、舌、身）——感官认识，直接了别外境
2. **第六识**（意识）——综合认识，分别思维
3. **第七识**（末那识）——深层执着，恒审思量
4. **第八识**（阿赖耶识）——根本识，含藏种子

## 📚 学习内容

### 核心概念（8个）

#### 前五识（5个）

- [x] [眼识](./前五识/眼识.md) - 依眼根了别色境
- [x] [耳识](./前五识/耳识.md) - 依耳根了别声境
- [x] [鼻识](./前五识/鼻识.md) - 依鼻根了别香境
- [x] [舌识](./前五识/舌识.md) - 依舌根了别味境
- [x] [身识](./前五识/身识.md) - 依身根了别触境

**前五识共同特点**:
- 各依一根，各缘一境
- 现量了别（直接认知，不加分别）
- 与外境直接接触
- 需要意识配合才能产生完整认知

#### 第六识（1个）

- [x] [意识](./第六识/意识.md) - 依意根了别法境

**意识特点**:
- 功能最广，能缘一切法
- 包括五俱意识和独头意识
- 有分别作用，善恶由此而生
- 修行的主要着力点

#### 第七识（1个）

- [x] [末那识](./第七识/末那识.md) - 恒审思量，执阿赖耶为我

**末那识特点**:
- 恒常执我（我执的根源）
- 四烦恼常相随（我痴、我见、我慢、我爱）
- 连接前六识与第八识
- 修行中最难突破的一关

#### 第八识（1个）

- [x] [阿赖耶识](./第八识/阿赖耶识.md) - 含藏一切种子的根本识

**阿赖耶识特点**:
- 一切种子识（含藏万法种子）
- 异熟识（因果异熟的承载者）
- 无覆无记（本身无善恶）
- 如大海，前七识如波浪
