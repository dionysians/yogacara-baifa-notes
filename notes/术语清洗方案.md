## 一、背景与动机

2026-05-16 讨论中识别到 CLAUDE.md 的中英混杂 register 通过会话 prime 闭环回流到笔记。

**闭环机制**:
```
CLAUDE.md 含大量英文术语 → 每次会话被 prime → 模型整理笔记时延续混杂 register
→ 写入笔记 → 下次会话又被 prime → ……
```

**三类风险**(讨论中识别):

1. **三层学术诚实标注的视觉边界模糊** — CLAUDE.md 已明文要求"经典 / 应用映射 / 自主推论"三层区分。英文术语密集渗入对经典原文的注释段后,经典层与假说层在视觉上失去清晰分界。
2. **假说封闭性风险被英文 jargon 放大** — 已是用户画像中识别的对治点(对治点 #2)。英文 jargon 把假说包装成"研究术语"register,新材料更倾向被翻译成 jargon 而不是挑战 jargon。"看穿者我相"等末那 hijack 路径(路径风险 #3)在英文术语下风险更高。
3. **时间衰减后可读性下降** — 利根者属"深熏频疏"模式,笔记会在数月后回读。中文术语自承重(熟悉概念瞬间激活),英文术语需重新建立 binding,损失可读性。

**反向利益**(中文化的额外收益):
- 中文佛教术语 + 中文哲学术语的 register 自带"被讨论过千年/几十年的公共概念"重量
- 强化 CLAUDE.md "经典 > 假说"原则的视觉表达
- 直接对治用户画像中的"看穿者我相"路径风险

### 步骤 2:CLAUDE.md 全量中文化 ⏸(待人工执行)

**范围**:仅 `CLAUDE.md` 本身,共 394 行;不动其中链接到的 `notes/实修/修行者画像.md`、`notes/教学操作核/*.md` 等。

**执行原则**:
1. 按映射表机械替换 A/B/C/D 区英文词
2. F 区项目(版本号、引用编号、字母编号、文件路径)不动
3. 保留所有结构:章节、表格、链表项、链接、emoji 标记(🔴 🟡 🟢 ⚠ ✅ 等)
4. 保留所有 markdown 格式:粗体、斜体、引用块、代码块
5. 不改变任何语义、不重排段落、不增删信息

**预期改动密度**:约 200+ 处英文替换,主要集中在:
- "用户学习画像 / 修行者基础状况"小节(英文密度最高)
- "各心所事件层操作核"小节(英文密度次高)
- "跨阶段回填清单"小节(中等密度)

**潜在边角处理**:
- 假说名(如"假说-15-anchor二阶二维")中的英文 — 文件名不动(避免破坏链接),但 CLAUDE.md 表格里"anchor 二阶+二维"可译"锚二阶+二维"
- "操作核"段落中的 D-/D+ 等 state 编号 — F 区已规定保留
- 引用块内的修行者自陈原文 — 原文照引,不译

**验证方法**:
- `git diff CLAUDE.md` 检视
- `grep -E "[a-zA-Z]{4,}" CLAUDE.md` 在清洗后应只剩 F 区允许项(版本号、文件路径、AI/LLM 等)

### 步骤 3:全笔记扫描与对照 ⏸(待人工执行)

**目的**:
1. 暴露映射表未覆盖的新英文词
2. 评估存量笔记的清洗优先级(不强制立即追溯)

**执行方式**:

```bash
# 提取所有笔记中的英文词频
find notes -name "*.md" -not -path "*/历史/*" | \
  xargs cat 2>/dev/null | \
  grep -oE "\b[a-zA-Z][a-zA-Z\-]{2,}\b" | \
  tr '[:upper:]' '[:lower:]' | \
  sort | uniq -c | sort -rn > /tmp/notes-english-freq.txt

# 与映射表对照,识别未覆盖词
# (逐项 review 后追加到映射表"增补记录"小节)
```

**处理策略**:
- 映射表未覆盖的新词 → 追加到映射表"增补记录"小节,补充推荐译法
- 存量笔记 → **不强制立即追溯清洗**,采用"自然 edit 时顺手转化"策略(避免一次性大规模 commit 造成的语义校验负担)
- 单独的整篇旧笔记如要清洗,按映射表逐条替换 + git diff 检视即可

## 三、本项目原则总结

### 强制原则
1. **经典原文段落及紧邻注释 = 英文零区**(强制)
2. **A 区骨干名词采用 canonical 译法,不允许同义切换**(避免概念漂移)
3. **F 区项目保留不译**(版本号、引用编号、字母编号、文件路径等)

### 优先级
- **映射表 > 个别笔记历史用法**:冲突时以映射表为准
- **经典 > 假说**:CLAUDE.md 既有原则,清洗过程中不变

### 不动项(确保不破坏)
- 所有 markdown 链接的 URL / 文件路径(包括含英文的假说文件名)
- 章节标题的锚点(若有 markdown 锚链接)
- 引用块内的原文引用(经典文字 / 修行者自陈)
- 图标 emoji 与表格结构
