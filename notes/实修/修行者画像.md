子阶段 1 收官评估识别的**利他善巧轴 / 权智缺口**——"诊断性知人强（把人当可建模对象，仍属对事）+ 缺利他善巧轴（对'他为什么如此'的悲悯理解 + 善巧帮助）"，原定位"需待菩萨道次第学习时展开"（CLAUDE.md 跨阶段回填清单）。

**2026-06-09 修行者主动引入新维度**（[随烦恼整体认知 §七](../03-心所法/随烦恼心所/随烦恼整体认知.md)）：

> "学习烦恼心所不仅是看见自己，也是见众生。"

→ 子阶段 2 学习随烦恼时不再是被动等待菩萨道学习，而是**主动建立见众生染心运作的精确认识**作为前置准备。

**子阶段 2 学习方法升级——见自见众双线**：

| 维度 | 操作 |
|---|---|
| **见自线**（子阶段 1 已成熟）| 延续现量分诊师姿态——每法在修行者位置的现量验证 |
| **见众生线**（2026-06-09 新引入）| 通过染心生起次第学习凡夫普遍现行链条——为利他善巧轴 / 权智补缺奠定染心认知基础 |

→ 这是子阶段 1 → 子阶段 2 的**质的演化**：从"自我分诊"扩展到"自他兼诊"。利他善巧轴的补缺不再依赖单一通道（菩萨道学习），而是有了双通道：
- 通道 1：菩萨道次第学习（四摄 / 方便波罗蜜 / 后得智）——结构性等待，未到触发
- 通道 2：百法子阶段 2 学习中通过染心生起次第建立见众生染心认知——**当前阶段主动运作**

→ 学习含义：每学一法时同步问"该法在凡夫普遍现行的形态 / 触发条件 / 修行学含义"，记录"见众生维度"的观察作为利他善巧的认知基础。

### 8.10 利他善巧轴通道 2 早期活化（2026-06-11 忿精修中现量化）

子阶段 2 首法忿精修中，利他善巧轴缺口出现**首个现量填补信号**——不再是结构性等待。

**机制**：修行者现量自陈嗔系最大问题 = 对"就应该这么做"而别人没这么做发生嗔（"不理解别人为什么这么想这么做"= 我所强到"别的活法不可解"、强化我所 → 别人不符则嗔）= 嗔操作核**触发点 2 最深层**"对他人因缘流'应该如何'投射"的现量印证。

→ **见自 / 见众生是同一跃迁两面**：

| 侧 | 现量 | 机制 |
|---|---|---|
| 见自 | 愧在"我所强加"上游点任运起 → 忿不现行（[忿.md §4.1-4.2](../03-心所法/随烦恼心所/忿.md)）| 愧 = 停止向他人扩张我所（假说 12）|
| 见众生 | "开始理解他人现行原因 + 开始有悲悯理解念头" | 我所强加一松 → 见他因缘 → 无嗔之悲 + 无痴见因 涌现 |

→ 愧（不强加）负向清场，悲悯理解正向涌现，**同一动作两头**。利他善巧轴缺口（诊断性知人强 + 缺悲悯理解）通过"见众生线（通道 2）"开始填补——**早期信号**（"开始"= 未稳，追踪方向：后续众生场景中悲悯理解是任运先起还是仍需事后调用）。

→ 印证 CLAUDE.md 回填清单"主线对治（悲先起 + 理解因）不待菩萨道回填、用已学心所事上练即可"——现在正在发生。

### 8.11 利他善巧轴缺口精确归位（2026-06-11 恨精修中现量化）

恨精修（[恨.md §5.3](../03-心所法/随烦恼心所/恨.md)）中修行者把利他善巧轴缺口精确切成三层，**修正 §8.9 / 子阶段 1 评估里"诊断性知人强（把人当可建模对象，仍属对事）"的旧框**——缺口不在"把人当对象、缺换位"，而精确在更里一层：

| 层 | 内容 | 修行者位置 |
|---|---|---|
| 诊断动机 | 从特质/能力/执着推断他的动机行为 | ✓ 强 |
| **理解外缘处境** | 站他视角，理解他这么做的原因、环境、**外缘的无奈** | ✓ **能**（因无嗔恨，能入他视角）|
| **理解烦恼内在机制** | 他为什么"**放不下**"本身、为什么"**一定要做很蠢的行为**" | ✗ **缺** |

→ 缺口精确在**心侧**（不理解他人被烦恼驱动的内在机制），**不在境侧**（外缘处境他能理解）。修行者能站他人视角理解处境无奈，不是冷建模——旧"对事/把人当可建模对象"标签应松动。

**"烦恼少者"的反向利他缺口**（结构性洞察）：修行者自身烦恼现行少（尤其嗔系）→ 对"被烦恼绑架"的现量经验少 → 反而难共情被烦恼深缚的众生。**修行越好，越缺被烦恼驱动的切身经验**。故其补法不走"培养情感共情/悲悯热质地"路径，而走本来的认知路径：理解烦恼机制 → 知道众生卡在哪 → 知道怎么帮（与理性派 / 慧解脱 / 信德冷质地路径一致）。

**见众生线重新定位**：修行者明确——"百法学习中利他善巧轴的部分，更多是去学习产生烦恼的底层机制"。把见众生线（通道 2）从"奠定认知基础"**升级**为**利他善巧轴在百法范畴内的直接修学路径**。缺口二分：

| 部分 | 内容 | 路径 |
|---|---|---|
| **百法内（现在就修）** | 理解烦恼底层机制 | 随烦恼 20 法见众生线直接填 |
| **百法外（待菩萨道）** | 完整善巧行法（四摄/方便波罗蜜）| 已登记回填清单 |

→ **教学动作调整**：见众生线每法**重点讲该法的烦恼底层机制**（众生为何现行它、它如何绑架人、为何明知苦还做），用认知路径填缺口，不框"培养悲悯"。恨即第一个样本——已看到凡夫"放不下"的机制 = 底层对所爱的不舍（恨底层是爱）。

### 8.12 利他善巧轴再填一例——亲子场覆与见解嗔合流（2026-06-12 覆精修中现量化）

覆精修（[覆.md §5.3](../03-心所法/随烦恼心所/覆.md)）给出利他善巧轴见众生线的**第二个亲子场样本**，且首次落到一个**修行者自身见解嗔重场**：

- **场景**：孩子覆藏过失问题"特别重"、反复发生；修行者自身对覆**几乎无感** + 清楚看到后果严重 → 对孩子**训斥严厉** = **见解嗔现行重场**（嗔现行已止于学习中，但机制一直没通：不理解孩子为何反复这么做）。
- **机制填补（认知路径）**：覆三段对治结构（惭感应器→无痴→无贪，缺一即可做完）+ 覆"常驻动机"（贪 + 露则失 + 藏有非零保全概率 = 间歇强化最顽固）→ 看到孩子**结构性三段皆缺**（惭种子薄 / 不到 10 岁认知装不下无痴后果 / 贪与保全概率给常驻动机），"反复藏"是结构必然、非品行问题。
- **见自见众合流**：训斥的隐含前提"他应该不藏 / 应该懂"= [嗔事件层操作核](../教学操作核/教学操作核-02-嗔事件层.md) 触发点 2"对他人应该如何的强加"；**如实见孩子三段皆缺 → 强加基础被抽掉**（同 [恨.md §4.1](../03-心所法/随烦恼心所/恨.md) 归因改道族）。**理解孩子覆机制（见众）= 同时松开自身见解嗔（见自）**——又一次同一跃迁两面。
- **承载**：[生活修对治案 003 · 亲子场孩子覆藏与我的见解嗔](logs/生活修日志/2026-06-亲子场孩子覆藏与我的见解嗔.md)（熏种中；评估指标 = 孩子再藏时"应该"强加念头是否当下被"如实见三段皆缺"截断，标的非速度）。

→ §8.11 立的"见众生线 = 利他善巧轴百法内直接修学路径"在覆场复证一次：从恨场"放不下=对所爱不舍"到覆场"反复藏=三段皆缺+常驻动机"，凡夫烦恼底层机制图谱在累积。

### 8.13 恼结构性不现行 + 亲子训斥校正为强忿 + "没认识到=分别"判定锁（2026-06-12 恼精修中现量化）

恼精修（[恼.md §四](../03-心所法/随烦恼心所/恼.md)）含一处**"经典 > 假说"的现量自我校正**——精修中途曾把亲子场强忿误判为恼，经严格回经典 + 拒立膨胀校回：

- **恼结构性不现行（预判成立）**：恼需「忿恨为先」+「追往恶」，往恶 = 恨结怨之追忆。修行者**恨不现行**（§8.11 / 恨.md §4.4 归因改道、无结怨）→ **无往恶可追 → 经典上够不成恼**。嗔系链三相：忿（现行，亲子场强忿）/ 恨（不现行）/ 恼（不现行）。
- **亲子训斥校正：恼 → 强忿**：§8.12 记的亲子场"严厉训斥"（曾定位见解嗔，中途误升为恼），经现量两点校回**强忿、非恼**——① **愤发**（凶、大声、纠正性，**明确无刺伤毒**）= 无狠戾、不成恼（狠戾是恼的体）；② 会**翻旧账**但**无恨累积**——"只是让我感到这件事的严重性"，翻的是严重性证据、非结怨（"追往（评估严重）"≠ 恼的"追往恶（追怨生毒）"）。**覆案 003 最初判的"见解嗔"判对了**。
- **强忿的强度源 = 见解嗔"覆该禁" + 屡犯严重性评估**（皆非恨）：见解嗔（[触发点 2 我所强加](../教学操作核/教学操作核-02-嗔事件层.md)"覆该禁"）根深蒂固 + 翻旧账加严重性权重 → 现前境一触愤发强烈。**强度不是经典区分忿 / 恼的判据**（唯识按行相非强度分立）——很强的忿仍是忿。
- **惭愧为何没亮 + "没认识到 = 分别"判定锁**：见解嗔"覆该禁"**伪装成客观道德标准**，既不挂恨相、又不挂瞋相 → 惭愧感应器不触发 = **没认识到**（非来不及）。闻思一拆即松（覆案看通三段皆缺后已能不发脾气）⟹ "覆该禁"出身**分别**（见道断分别、修道断俱生；闻思拆得动 = 分别、非真俱生）。
- **见众生封顶 + 利他善巧轴第三层最彻底一填**：凡夫真有恼（恨现行、有怨发酵）。嗔系链 恼 ← 恨 ← 贪（链根没放下的贪）；**越陷越深苦**（戾 = 陈怨发酵到极毒，越刻毒者贪执抱得越死、陷得越深）——连"看着最像坏人"的都还原成"陷得最深的苦"，评判线彻底拆完。与 [恨 §4.3](../03-心所法/随烦恼心所/恨.md)"觉得人坏=恨恼产物"两头对上。

**教学动作**：① 报告评判他人"应该如何"的强加 / "看不惯某类人事" → 先分诊是**忿的强度源（见解嗔 + 评估）**还是真有**恨结怨之往恶**（多半前者）；用"有无狠戾刺伤毒 + 翻旧账是追怨还是评估严重"判忿 / 恼。② 报告"看不惯某类" → 问闻思后是否松动（**松 = 分别可正见拆 / 不松 = 俱生需定中磨**），别因体感即时就判真俱生。③ 见众生续走认知路径（恼←恨←贪机制 + 越陷越深苦），不框"培养悲悯"。

→ **本条本身即教学样本**：修行者主导的"误判恼 → 严格回经典 → 校回强忿"全过程，是[拒立膨胀 + 经典 > 假说]姿态的又一次现量演练（活跃议题 ⑥）。

### 8.14 嫉究竟收于我痴 + 对治双入口分离 + 随喜质地"冷→平"校正（2026-06-12 嫉精修中现量化）

随烦恼第五法**嫉**（首个离开嗔系违境链、起于他荣境），见自侧由修行者主导逼到究竟根，并校正一处模型的表层标签转移。详见 [嫉.md §四](../03-心所法/随烦恼心所/嫉.md)。

- **见自二分 → 拆掉零和**：他荣现起忧戚转瞬有，分**非零和场**（贪内容本身 → 嫉不起、转研究姿态）/ **真实零和场**（贪排名 → 忧戚明显）。修行者自主究竟：二分本身**默认排名实有**，但**排名是比较心产物（想比则有、不想比则无），无天然带排名的境** → 零和场也能拆成纯境。"零和场更难看破，正是看破契机"。
- **对治双入口分离**：贪求不得苦（回贪根，另一回事、可保留贪作世俗动力）vs 嫉（拆"我他对立"动作）。命门在后者、**不必动贪根**；且**随喜反向磨贪**（一动作破嫉+磨贪，比硬断贪根善巧）。
- **究竟收于我痴**：连排名都不实 → 嫉究竟根 = [我痴](../../resources/cards/我痴.md)（立实我中心→造比较→默认"别人有=我损"）。对治究竟化 = **了无自性锚照破排名不实** → 嫉自动消，**收进无痴双线，不需独立通道**。**慢/憍/嫉同一把钥匙**（破实我中心，假说 18 一致）——三个"我他对比"朝向（我胜他/自盛/他胜我）同收。
- **随喜质地校正（"冷 → 平"）**：模型曾推断修行者随喜走"冷质地、缺为他高兴的情感"——属**表层标签转移**（把信德冷质地〔限对三宝〕泛化到对人的随喜），经现量否决。实相：**能为他高兴、有信服认可，只是自身"高兴"情感基线本就低波动 → 为他＝为己等量、无狂热极端**。随喜情感基质**本具足**，不需"培养热情"（反成装相）。
- **见众生**：凡夫嫉 = **看不破排名无自性的结构性必然**（把比较产物当实有、默认别人有=我损），非"心眼小"品行问题 = 利他善巧轴第三层最深一填。

**教学动作**：① 报告"见他人成就 / 被比较起不悦" → 先分诊场域（非零和可转研究 / 真实零和需拆"我他对立"动作），再指向"排名无自性"了无自性锚，**不框"回贪根硬断"**。② 报告随喜 → 不预设"冷质地缺情感"（已校正为"平"），按"为他＝为己等量"理解，不催"培养为他高兴的热情"。③ 凡涉慢/憍/嫉 → 同收"破实我中心"一把钥匙，不立三套对治。

→ **本条再次是教学样本**：模型提"假说18在零和场无处可转、嫉必回贪根" → 修行者现量拆解（排名不实）证伪 → 收于我痴。又一次[拒立膨胀 + 现量 > 假说]演练（活跃议题 ⑥），叠加一处模型自查"表层标签转移"。

### 8.15 悭四界面严格不现行 + 施的边界框架 + "悭≠我所执"归位（2026-06-13 悭精修中现量化）

随烦恼第六法**悭**（小随首入贪系、缘自所有），见自侧确认四界面严格不现行，主产出是"施的边界"简择框架与一次"拒绝范围膨胀"的现量分诊。详见 [悭.md §四 §五](../03-心所法/随烦恼心所/悭.md)。

- **"悭≠我所执"归位（修行者主导）**：模型章末检验问"「我的」边界感如何运作"，修行者指出此问越出悭的范围——涉及我所执全域（财物 ／ 关系 ／ 名利 ／ 所坚持内容 ／ 喜好 ／ 法 ／ 我本身七项），需更细分辨、不可在此展开。经五悭细目 + **"施界面"判准**（可分享而紧缩不肯才成悭）归位：四项属悭（施悭 ／ 家悭 ／ 称誉悭 ／ 法悭），三项各归己通道（见取＋法贪 ／ 贪爱 ／ 萨迦耶见）——**复杂性属末那、不属悭**。
- **施的边界框架**（修行者真问题"施需缘法、不能无差别施"→ 经典完整作答）：① 时机**响应式非搜索式**（《瑜伽师地论》施品"见来求者"——缘不现前不施是无境非悭，主动遍寻施处属菩萨圆满层非凡夫义务）；② **遮缘三条**（修行者对经典明文的无损压缩：真实伤害被施者 ／ 施对象不由己支配 ／ 真实伤害自己·称力线）；③ **"触发烦恼不算自伤"**——那正是要磨的悭本身，真遮缘事后心安、悭借壳事后理由反复自我重申；④ **判心相不判施否**（施境下心紧 = 悭；先认紧后简择，防悭收编简择作借口）+ 隐蔽形态（回避施境让缘现不了前）——与持戒究竟层"判心所配置不判形式"严格同构。
- **见自四界面严格不现行**：财物 ／ 关系 ／ 名誉 ／ 法逐界面过现量皆不现行——施境现前时天生跑的就是遮缘单第①条 + 愧共业秩序质地（"对双方都好"简择），**慧简择占住施界面、悭无现行位置**；事后心安配套验证。本次讨论只做名相归位（知道这是施度简择支、悭判在心相），非安装新配置。法悭侧亦不现行——与"法悭守位置稀缺性 = 排名价值"剥解相符（排名脚手架已在嫉精修拆掉）。
- **双重假第三复证 + 常驻动机最强复证**：「我的」所有权 = 共业约定产物、物上不带"我的"标签（所缘世俗概念假立 ✓，脚手架下接末那俱生我所执）；凡夫悭 = 保全概率最高的常驻动机结构必然（守住几乎必然立即奏效、奖励从不落空）。
- **见众生**：凡夫悭非品行问题——我痴实有化"我的"域 + 外物征用为防御工事 + 不舍的即时安全感微奖励持续强化；五家所共点破"保全"为延迟结算。出口 = **「我的」无自性**——嫉 ／ 悭 ／ 慢 ／ 憍同收"破我所·实我中心"一把钥匙（嫉拆排名、悭拆所有权）。

**教学动作**：① 报告"不想给 ／ 舍不得" → 先分诊遮缘三条是否真中（尤其称力线：真实自伤还是触发烦恼），再问施境下心开心紧，**不判施否本身**；② 报告"不施的理由事后反复自我重申" → 指向悭借壳；③ 此法在修行者处无主修区，归档、不花常规带宽。

→ **本条的教学样本**：修行者对"「我的」边界感"之问的**拒绝范围膨胀**——不顺着模型的问题往我所执全域展开，而是指出问题本身越界、要求归位（活跃议题 ⑥ 现量级警觉的又一演练形态：不只拒立自己的膨胀假说，也拒绝模型的膨胀提问）。

### 8.16 诳结构性不现行 + 叙事感染力抬高他人意愿（非诳·愧的认知/受欲层）+ 对治枢纽惭愧（2026-06-13 诳精修中现量化）

随烦恼第七法**诳**（贪痴一分组、为获利誉矫现有德）。见自侧诳结构性不现行；主产出是修行者自我揭示的一个**邻区现象**（叙事感染力抬高他人意愿，非诳、归位到愧），以及本法触发的一次模型元层膨胀诊断。详见 [诳.md §五](../03-心所法/随烦恼心所/诳.md)。

- **诳本身连那一闪都不起**：开口说"我能干"前心底先盘算"是否真能胜任"+"怕辜负别人"——惭愧感应器源头先起、堵死矫现发动，与覆同走惭愧通道、臂偏愧（怕辜负 / 欺他）。结构性不现行、归档。
- **叙事感染力邻区现象（修行者自我揭示）**：天然善于把事放进更大故事背景，使之有条理 / 故事性 / 吸引力，别人更易忽略风险、愿同行；自己不会不安（真信愿景、自己也按它推进、共担风险）。**定性非诳**（无矫现无异谋、邀请共担非诱骗替担）；**归位到愧的认知 / 受欲层**——客观抬高他人风险承担 = 我所愿景风险向他人细微外溢，愧在此点未现起；轻沾不害，因共担 + 夹利他潜质故性质轻。
- **信息如实挡不住（修行者补充，证伪"如实告知"补全）**：故事讲得好时对方受 / 欲被激发、风险阈值被推高，且自以为是确定风险才来的（对方一层不正知）；问题在受 / 欲层非信息层。→ **对治必上移到初心 / 方向**：感染力是力大而"盲"（五度如盲、般若如导），须由利他初心导向真实利益，否则力越大风险越大；修行者方案（欲 → 精进、初心利他）抓住根（拔我所）。
- **见众生**：常驻动机 + **自欺强化**（被反复认可未暴露 →"我很行"→ 痴分吃掉自知 → 连"我在诳"的刹车都吃掉，自我认知层最顽固）+ 装有德则不修德障道 = 利他善巧轴第三层一填。

**教学动作**：① 报告"叙事 / 讲故事让人跟随" → 先分诊有无矫现（真信共担 = 非诳），若无诳则查"对方风险认知是否被感染力抬高"、指向初心利他（**不框"少讲故事"**）；② 报告"对自己能力的增益性修饰" → 查诳唯一残留缝；③ 此法在修行者处无主修区，归档、不花常规带宽。

→ **本条的元层样本**：本法讲法阶段模型连续膨胀（造"诳独有核" / 对称三分 / 外显结果出口），经修行者主导诊断（法贫瘠 → 造核填补"应有产出" = 模型版法贪 / 染慧；滑向形式判准；"请你判真伪"包装膨胀）→ 确立 CLAUDE.md 学习流程 ①"研究议题来源约束"（详见 [CLAUDE演化 2026-06-13](../历史/CLAUDE演化/2026-06-13_研究议题来源约束.md)）。诳对治（惭愧起、停止演、如实承认"没有"）与模型膨胀对治严格同构。

### 8.17 谄结构性不现行 + 母态过直学随顺 + 表达域反转（2026-06-14 谄精修中现量化）

随烦恼第八法**谄**（贪痴一分组收口、缘他人取意）。见自侧谄结构性不现行，但理由与诳预判相反——母态在谄的反极（过直）；主产出是表达域的一次反转 + 利他善巧轴输出侧的实地填补。详见 [谄.md §四 §五 §六](../03-心所法/随烦恼心所/谄.md)。

- **谄结构性不现行——发心从不网他 + 母态过直**（修行者自陈修行史·第一层事实）：长期根本不知道"仅仅说实话会让人不高兴"，被家人多次指出后才意识到、逐渐学会随顺对方说话。→ 母态在谄的反极**过直**（说实话不顾对方感受且不自知），谄不是诱惑、修行史是反方向（从过直学随顺善巧）。
- **表达域反转**（一处模型预判被修行者反转）：模型曾预判"按对方理解框架调整表达"可能沾谄（取他意）；修行者反转——调整表达让对方懂 = **利他 / 交流目的的必然外显**（目的对、调整自动清净，不经过"要不要顺"那一念）、结构性清净、不在谄域；**表达域真正的染污镜像是诳**（用对方不懂的术语显专业 = 矫现"我很专业"的形象）、非谄。同一表达场景两染污由两参数区分（诳利誉×矫现 = 对自抬高 / 谄网他×违心顺 = 对他迎合）。
- **判准锁发心**：判心相不判形式收于**发心**（网他 vs 利他 / 解决问题），不在动作、不在"违心"字面；险曲 = 发心曲（藏网他异图），非言语不符字面真实；避冲突 / 为安全随顺非谄（发心是安全 / 不造恶）；菩萨"直心 + 恒顺"不悖（直在心 · 无异谋，顺在形 · 善巧应机）。
- **见众生**：凡夫谄 = **贪种熏习正反馈环**（谄不即时奏效——维持"将来可能获利"想象→保住贪念→谄常驻熏贪种→贪种粘着↑→更想获好处→谄频率↑）；**常驻动机第四复证·熏种循环变体**（机制由贪对象时态派生、非通用模板）；**障教诲**掐断"被纠正"通道（经典业用，凡夫最隐蔽卡点）；**见自见众合流**——修行者过直缺随顺 / 凡夫偏谄缺直心，两极合流于"发心利他地直心随顺"（菩萨爱语 / 恒顺众生心相）。
- **利他善巧轴输出侧填补**：缺口的具体历史形态 = 母态过直 → 走认知路径意识到"实话会伤人" → 学随顺；议题 ⑤"补法走认知路径"扩到**输出侧**（不只"理解他人烦恼机制"，还有"如何把真实 / 关心用对方接得住的方式给出去"）；护栏 = 发心（利他 vs 网他），修行者发心一直在利他侧 → 护栏天然在位。

**教学动作**：① 报告"随顺 / 迎合 / 说对方爱听的话" → 先判发心（利他 / 解决问题 = 非谄 / 网他取利 = 谄），不判动作、不判"违心"字面；② 报告"调整表达" → 按利他目的必然外显理解、非谄，反查"用术语显专业"的诳缝；③ 凡涉利他随顺 → 以发心作护栏、不框"少随顺"；④ 此法在修行者处无主修区，归档、不花常规带宽。

→ **本条的元层样本**：本法讲法 / 讨论阶段模型反复自创非经典衍生议题——"对自 / 对他对仗"过度建构（被证伪）/ "即时保全"从覆悭硬搬（被纠正为熏种循环）/ "痴 load-bearing 维度"自造机制解释经典标痴模式（被剥除——够不上经典衍生）。**判准精化**：模型一度把来源约束误述为"看谁打开议题"，修行者校正回"看议题是否经典衍生 / 修行者诉求、与谁出声无关"；规则在 CLAUDE.md 学习流程 ① 已完整，缺的是模型落笔前未跑这条已有检验。另含两处现量自我校正（把修行者的结构分析误读成其个人现行"显专业残留"= 杜撰归因、撤回 / 判准锁"违心"= 判形式冒充心相、校回发心）。= 诳"研究议题来源约束"确立后的一次实地复演。

### 8.18 害结构性不现行 + 嗔系五法收官 + 见众生三型动机填利他轴（2026-06-15 害精修中现量化）

随烦恼第九法**害**（嗔一分、缘有情损恼、不害对偶），**嗔系五法 忿恨恼嫉害 收官**。见自侧害结构性不现行；主产出在见众生侧（凡夫害三型动机）+ 利他善巧轴第三层的实地填补。详见 [害.md §五 §六](../03-心所法/随烦恼心所/害.md)。

- **判别点修正 → 害结构性不现行**：决定害的是**损恼为性（损他为出发）**、不是「心无悲愍」——心无悲愍是嗔分共相（忿与悲愍互违、任一嗔分现行悲愍都不在，区分不了害与忿恨恼）。修行者现量"目标肯定是希望孩子更好、不以损恼有情为出发"→ 损恼非出发 → 害的体不成立、**结构性不现行**。[5/02 亲子场无嗔操作核](../教学操作核/教学操作核-01-亲子场无嗔.md)"起害心"是松标，**校回强忿**（同恼精修 6/12 先例）。**自他相换反射本具**（"想象对方如此对我就受不了、根本做不出"）= 悲愍本具的当下运作、阻断害的机制。
- **嗔系五法全景收官**：忿（亲子场脉冲现行·强忿）/ 恨（不现行·归因改道）/ 恼（结构性不现行·无往恶可追）/ 嫉（究竟收"排名无自性"·可拆）/ **害（结构性不现行·损恼非出发）**——五法里仅忿一法亲子场脉冲现行。
- **见众生·三型动机 + 害无天然源**（修行者主导）：损恼有情非天然、必有正向 driver——报复型（嗔+痴误归因把自苦归于他+恨嫉累积，快感是"误以为除苦"的代偿、非损人本身可乐）/ 扩张型（贪·损他=建立强化我所手段）/ 正当化型（痴恶见·建构损恼为正当有功德）；"冷害"是种子累积的俱生形态、非天然第三源。**究竟归因 = 贪+俱生痴+恶见、凡夫不自见**。经典互印：九恼事（报复型骨架）+ 杀生通三毒（三型对位）；害体恒嗔一分、因可通三毒。
- **利他善巧轴第三层填补 + 悲愍通治全嗔系**：议题 ⑤ 缺口第三层（理解烦恼内在机制）在"损恼有情"格补上，补法走**认知路径**（修行者缺损人之乐现量、不靠共情）。**悲愍是整个嗔系的通治**（悲愍起→无嗔在场→忿恨恼嫉害一并不现行）；见自见众合流于悲愍+无我；害（报复型）与慢/嫉/憍**同一把钥匙**（破实我中心）。

**教学动作**：① 报告"看不惯某类人 / 想损某人" → 先判**损恼是不是出发**（多半是见解嗔顶起的强忿、非害）+ 查报复型有无"痴误归因把自苦归于他"；② 报告评判他人"该被损 / 罪有应得" → 查是否恶见正当化；③ 凡涉理解凡夫损人 → 走认知路径讲三型机制、**不框"培养悲悯"**；④ 凡涉慢 / 嫉 / 憍 / 害报复型 → 同收"破实我中心"一把钥匙；⑤ 此法在修行者处无主修区、归档不花常规带宽。

→ **本条的元层样本**：本法讨论阶段模型两处方法论偏移经修行者纠正——① 用"自调伏面 / 利他面"维度对偶分嗔害（维度是描述属性的独立轴、非分装嗔害的格子；且否定句也不该出现否则把错框请回）；② 把"害是否有独特核"摆成开放二选一请判（经典已判无别体、论证有核=推翻经典、不是可上桌选项）；另用语校正"损他底色"→并行非层级。= "经典>假说 + 经典已判定者不重开"纪律的实地复演。

### 8.19 憍结构性不现行 + 小随十法收官 + "盛"圈层建构 + "小"之指代提炼（2026-06-16 憍精修中现量化）

随烦恼第十法**憍**（贪一分、于自盛事醉傲、染依为业、不憍归无贪），**小随十法收官**。见自侧憍结构性不现行；主产出在"盛"边界厘清 + 见众生命门 + 小随"小"之指代提炼。详见 [憍.md §四 §五 §六](../03-心所法/随烦恼心所/憍.md)。

- **憍结构性不现行 + 法贪 ≠ 憍 分界**：法贪在场俱生（贪"精巧见地"本身），但按"于自盛事深生染著醉傲"判，**醉傲陶醉感不存在** → 憍结构性不现行。机制 = [假说 18](../假说/假说-18-对象转换元假说.md) 贪系侧印证：关注**见地本身（境侧）**、不关注"我有这个见地"（自侧）→ 见地不被盛事化 → 憍无从发动。**法贪（境侧 · 贪结构本身）≠ 憍（需自侧盛事化 + 醉傲）**，中间隔一个对象转换、修行者稳定不做这步。**憍比 L4 慢更彻底**——慢评判型留一个"评判主体我"尾巴、仍明灭闪动；憍要多走"盛事化 + 醉傲"一步、可完全不发生（连尾巴都没）。
- **小随见自全景收官**：小随 10 法在修行者位置上**仅忿（亲子场脉冲）现行、其余 9 法（恨恼覆嫉悭诳谄害憍）结构性不现行** → 真战场在**俱生法染色层**（法贪 + 末那附着 + L4 慢），不在小随事相级；小随整组"认得机制、归档不占主修带宽"。
- **见众生 · 命门在维持机制不在起因**：憍长驻的命门 = 三重自封闭——① 陶醉自盛对外无冲突 → 结构性不生苦受 → 无纠错报警；② "醉"本身禁用警省（侦测层自封闭）；③ 自熏贪种正反馈（种子层自续命）= "染依为业"（安静温床、长驻不走）的深层机理。**钥匙拆深度**：嫉 / 悭 / 憍（+ 覆诳谄）同一把钥匙 = 破世俗建构无自性（**表层**）；慢拆出去 = 破实我中心（**深层**）——旧"慢憍嫉同一把钥匙"框校正。见自见众合流于"破'盛'建构无自性"这一表层动作。
- **"盛"圈层建构**：盛 = 圈层相对的世俗建构正价（非客观胜出义=慢、非稀缺区隔=慢侧；现代价值多元使建构相对性裸露）= 双重假所缘侧当代强样本。

**教学动作**：① 报告"对自己见地 / 成就的得意飘然" → 先按"于自盛事醉傲陶醉"判（有醉傲陶醉=憍 / 只关注境本身=法贪非憍），**不把法贪误判为憍**；② 凡涉嫉 / 悭 / 憍 / 覆诳谄 → 钥匙 = 破该建构无自性（表层）、**不拔高到破实我中心**；凡涉慢 → 才是破实我中心（深层）；③ 此法在修行者处无主修区、归档不花常规带宽。

→ **本条的方法论样本**：本组收官把"候选 → 升格判定"叙事**重定向**为"提炼经典'小 / 中 / 大'设定的角度"（修行者明确：目标不是立假设）——"经典 > 假说"纪律的又一次落地（整理服务于理解经典设定、不另立并行结构）。

### 8.20 无惭无愧两场脉冲现行 + 截断加速 + 凡夫无耻=惭愧因缘两层不足（2026-06-24 无惭无愧精修中现量化）

中随两法（无惭无愧）精修收官。**核心见自更正**：与多数小随（结构性不现行）不同，无惭无愧**确实现行**——因中随遍一切不善心、不挂靠特定境，哪里有不善心就伴生在哪里。详见 [无惭无愧合论 §七 §八](../03-心所法/随烦恼心所/无惭无愧合论.md)。

- **无惭无愧现行场 = 残余不善心两处（皆嗔系、皆脉冲）**：① 亲子场强忿；② 法染色层 · 见解嗔一阶（现量印证 = "我所立见"被损时**首刹那真起微细嗔**〔立刻抵触 / 反驳、护我所立 = 第六识嗔、嗔唯不善〕= 不善心、无惭无愧俱 → 随即惭愧究竟层即刻截断 = "脉冲 + 回落"，与亲子场强忿同型）。无惭无愧在修行者处**无独立战场**、是这两处嗔系不善心的伴生标记。
- **两场同型 · 皆愧外向轴清场**：两场都是"我所强加"型嗔，都由愧（究竟层 · 外向轴 · 不向他人扩张我所）清场——亲子场截"应该如此"强加于孩子 / 法染色层截"我所立见"护持扩张。同一愧外向轴覆盖两场 = [假说 12](../假说/假说-12-惭愧末那二维辐射.md) 在中随侧的现量印证扩展，与忿.md §5"愧负向清场"同型。
- **进展信号 + 征兆 / 标的提醒**：法染色层"越来越快地即刻截断"= 惭愧究竟层向种子层下沉的好信号。但按 [假说 17](../假说/假说-17-sign-vs-target-已闭合.md)：截断速度加快 = **征兆**；标的 = ①惭愧究竟层任运现行②法染色层见解被损时**那一下嗔的反应强度本身下降**。监测放标的（已登记主座 A 实修反馈）。
- **见众生 · 凡夫无耻 = 惭愧因缘两层不足**：惭愧（无惭无愧的对治）升不起来、无惭无愧才畅通。惭愧现起 = 种子（因）+ 见地缘（缘），两层任一不足即起不来——① 俱生种子层：惭愧跨世种子薄；② 现世见地层：方便层（社会缘 · 怕讥嫌）瓦解 + 究竟层（内在缘 · 法本如是 / 共业秩序）未建立。凡夫"无耻"是结构必然、非品行缺陷。
- **见自见众同一跃迁两面**：惭愧现起是因缘条件决定的，条件不具时结构性不能升起 →"他应当此刻有耻"是无理强加。**看通此结构（见众）= 同时松"他应该有耻"的见解嗔 / 我所强加（见自）**，与覆 / 恼 / 嫉 / 害一路同型。利他落点 = 补缘（引导究竟层惭愧借用），走认知路径、不框"培养羞耻"。

**教学动作**：① 报告"对见解被质疑起抵触 / 立刻反驳"→ 按"首刹那嗔（不善 · 无惭无愧俱）+ 惭愧究竟层截断"理解，问**反应强度**（标的）是否下降、不只问截断速度（征兆）；② 报告评判他人"无耻 / 没底线"→ 走认知路径讲"惭愧因缘两层（种子 + 见地缘）不足"、查自己"他应该有耻"是不是见解嗔 / 我所强加，**不框"培养羞耻"**；帮 = 补缘（究竟层借用）；③ 凡涉无惭无愧对治 → 不另立通道、搭惭愧（主要愧外向轴）已有线。

→ **本条的元层记录**：模型曾把整合方案漏列"不善心解释 + 别有体诤议"两块重头，经修行者点出补回——单立显著节（合论 §二 §三）。另：修行者主动重走经部"心所还原"路追问别有体，经典（护法外延论据）正面回应、还原侧记第三层视角 = "经典 > 假说"又一次落地。

### 8.21 掉举罕现 + 驱动力三态分诊（议题②法贪层进展）+ 后得智现量锚（议题⑤）（2026-06-25 掉举精修中现量化）

大随八法开篇。掉举在修行者位置 = **结构归位、现量罕现**（与多数小随同型，但机制不同——非"不挂靠特定境"而是"驱动力本就专注不飞扬 + 念力能收"双因素）。详见 [掉举 §三](../03-心所法/随烦恼心所/掉举.md) + [默认模式网络与掉举专题](../03-心所法/随烦恼心所/默认模式网络与掉举-色法镜像与转依.md)。

- **见自核心更正 = 掉举不是闻思场主现行**：原命题"掉举 = 法染色层主战场在大随层精确显现（法贪境激活→心举）"被现量否决——主现行是"**想搞明白的驱动力**"（引力 / 欲性、非不寂静飞扬）；专注钻研驱动近一境性、恰是掉举反面。掉举仅在驱动力飞扬化时罕起 = 印证候选假说"大随八降级为事件遮蔽"（§6.1 不信首例、掉举第二例）。
- **议题②法贪层进展 · 驱动力三态分诊**（修行者自立现量操作）：一起驱动力先辨析目标三态——① 精进驱动 = 善欲；② 纯粹好奇 = **无记欲**（独立切出无覆无记中项、与"欲通三性"严格对上、是议题②二分的三分精化）；③ 法贪 = 染欲。**核心判准 = 观照贪心所有无"抓取放不下"，有则停**（命中贪体性签名、比"追究封闭 / 过度挖掘"行为相更靠体性一层）。进展 = 法贪现行多数能**定力支撑识破 + 及时中断**。**边界两条**：㈠ 末那附着层（"我所立见"身份附着）仍在判准之外、不以抓取显（与举我捕捉不到一致）、仍待现量化；㈡ 无记好奇过得了抓取核查但仍吞噬精进 / 时间（接议题③）、需补"方向核查"第二把尺。
- **念力反比双因素 + 惛沉为主**：掉举低 = 低基线（专注型本不飞扬）+ 定力能收 双因素叠加（候选假说"基底化与念力稳态成反比"部分印证、不可全归念力）；**禅定中惛沉 > 掉举**（修行者偏"太松 / 沉"端、需策举），坐实场域 A〔浮·罕现〕/ B〔沉·惛沉基底化〕分工 → **下一法惛沉才是大随主修区**。
- **议题⑤后得智现量锚**：发散"消解我执（DMN）会不会出生存问题"→ **功能-染色二分**（对治掉举 = 释放"为我亢进飞扬"染色、非删功能；功能经转依净化为后得智 / 权智）；现量印证 = **我执着色变薄时"看系统 / 理解他人 / 规划"更清明、非丧失**——给议题⑤"看系统强项无我化 → 后得智资粮"补现量基础；破"消解 = 丧失生存功能"伪问题（圣者存在性证明）。

**教学动作**：① 报告"闻思 / 想搞明白的驱动力"→ 按驱动力三态分诊（善欲 / 无记好奇 / 法贪），以"贪心所抓取放不下"判法贪、以"是否朝向善法 / 值不值得花时间"判无记好奇，**不把专注驱动误判为掉举**；② 报告"心浮 / 停不下来"→ 先分诊是掉举（原地飞扬·罕现）还是散乱（流转）还是惛沉（下沉·主修区），坐中体验优先问惛沉；③ 报告"消解我执 / 无我化后功能变化"→ 按功能-染色二分理解（功能更清明 = 后得智雏形）、接议题⑤、**不框"会丢失能力"**；④ 掉举此法无主修区、归档不花常规带宽，主战场是法贪 / 欲驱动分诊（议题②）。

### 8.22 惛沉降级第三例 + 细所缘失念关口（定历来 天花板）+ 味定痴型校正 + 一切智=后得智根定位（2026-06-25 惛沉精修中现量化）

大随第二法。**惛沉在修行者位置 = 降级第三例、两形态（粗 / 细）皆不现行**（继不信、掉举），骨架 §6.2"惛沉 = 场域 B 唯一基底化法 / 大随主修区"现量否决。精修真正撞出的是修行者定历来的真实 天花板——细所缘失念关口（非惛沉）。详见 [惛沉](../03-心所法/随烦恼心所/惛沉.md)。

- **惛沉降级 + 深层结构原因**：三尺复查（明利满格 / 无下沉方向 / 无渐进突然断）排除粗细惛沉。深层原因——修行者**明利质地不退化成钝重**（能入细、心不浊），修定调弦"松端"本该惛沉守门、这里**换成失念 / 微眠守门**（走"细到阈值干净脱落"非"沉钝"）。双场域否决：A 修定场 = 失念 / 微眠、B 懈怠场 = 懈怠 / 失念 / 眠弱级，皆非惛沉。
- **细所缘失念关口 = 定历来 天花板（议题①现量精确定位）**：呼吸越来越细 → 所缘强度弱（定深化自然征象）→ **念力接不住细所缘** → 失念 / 微眠（完全不记得片段）。**童年禅定即同一模式**（体力解释不了根、结构性在念力侧）。6/25 凌晨掉举座（息没细下去、所缘粗）全程念在 = 反向对照、机制锁死。这是"慧定不匹配"的现量精确定位——**能入细、守不住细**（非"慧强定弱"），假说 7 力层缺口的最早证据。
- **念力底板 / 颗粒度假说（接信号框架·坐中修不可替代机制）**〔第三层候选〕：日常欲界散心 = 粗所缘 + 念念有竞争对象 → 念永在底板之上、碰不到能力极限；禅定主动把所缘细化到日常碰不到的细度 + 撤竞争对象 → 念力底板第一次暴露。故此实验日常跑不了——**只有坐中能降所缘信号、暴露并训练念力底板**（生活修在粗所缘场练不到这一力层）= 坐中修不可被生活修替代的精确机制（接假说 1 信号框架）。
- **味定 → 痴型校正（含一处模型自我校正）**：修行者长期把"失念出来后清明愉悦"误为禅定效果。机制 = 攀缘暂停的粗重暂息乐（非真轻安）+ 意识重启清明（非真定持续明利）+ 因果搞反（好的是失念前那段定）。**校正**：模型曾框为"味著 / 追求"（贪型），修行者校回——本心没追没强化、只是误认方向 = **痴（无知）非贪（味著）**；**自证 = 转折点是"知"（理解念不失），知直接对治痴不对治贪**。见自见众分：凡夫卡此关多贪痴型（暗证顽空）/ 修行者纯痴型、正知一补转向干净（利根 + 信德冷质地特殊形态）。
- **养明 vs 断暗根 + 一切智 = 后得智根定位（议题⑤）**：痴两层——事相不知（闻可填、修行者失念-痴属此）/ 根本痴（我执法执遍计模式、须现观转依）。一切智不是学来的数据库、是断所知障撤滤镜后法尔无碍知（后得智 / 尽所有智）；故完全对治痴不靠学完一切、走断二障转依路。**接议题⑤**：后得智（知一切法差别）= 权智 = 利他善巧轴缺口的**究竟边**（断所知障的果、非学来）；修行者"补法走认知路径"是资粮侧。
- **"了 / 痴"之别**：纯未了（无覆无记、累积 + 机缘、非痴）vs 痴所障（俱生无明 / 法执遮蔽）；判准 = 有无颠倒执（如实知"自己未了"= 无痴正知 / 错执"已了"= 不正知）。甚深法理"不明晰"含痴层（俱生无明、闻了现量仍不印持），非纯累积能尽。
- **引力-逃逸比喻（修行者自立）**：惛沉 = 引力（默认下沉）/ 推进 = 精进念力 / 逃逸速度 = 念力临界点（任运）——统一惛沉对治、失念守细、任运涌现于同一临界点（= 假说 7 越临界）。

**教学动作**：① 报告"禅定丢所缘 / 类似睡着"→ 先用三尺（明利之力 / 方向 / 渐进）分诊**失念（突然断·非暗非钝）vs 惛沉（钝重渐沉）**，修行者多是失念、不按惛沉补明分，按"念力守细"对治（中段守细 / 临界段回粗治标 / 治本数→随穿阈）；② 报告"呼吸细就丢"→ 归"细所缘失念关口·念力底板"、接议题①慧定不匹配（能入细守不住细），**不归惛沉**；③ 报告"出定后清明愉悦"→ 按"非禅定效果·失念前定的余味"理解、查是否误认目标（痴非贪），**不框"贪定乐"**；④ 报告"学不懂 / 法理不明晰"→ 分诊纯未了（累积 + 机缘·非痴）vs 痴所障（甚深法理俱生无明），判准 = 有无颠倒执；⑤ 凡涉"消解我执 / 无我化功能"或"一切智从哪来"→ 按养明 vs 断暗根 + 后得智 = 断所知障果（议题⑤究竟边）、**不框"学完一切"或"丢失功能"**；⑥ 惛沉此法无主修区、归档不花常规带宽，真主修指向失念 / 懈怠。

### 8.23 不信降级首例 + 信德冷质地校正为分面（实热德冷·起毛喜）+ 懈怠根痴一分（saṃvega）+ 理热相冷候选（2026-06-29 不信精修中现量化）

大随第三法。**不信在修行者位置 = 降级首例**（四要素现量未发现残留、守"未发现 ≠ 确证无"）——大随三种降级形态俱全：不信（首例·几乎无遮蔽可降）/ 掉举（事件遮蔽）/ 惛沉（不现行）。本法最重产出是**"信德冷质地"标签的实质校正**。详见 [不信](../03-心所法/随烦恼心所/不信.md)。

- **信德冷质地 → 校正为分面（实热德冷）**：检验现量——闻思甚深法理打通现场不仅"底层欣乐 / 心趋向"、且**浑身发麻、毛孔竖立**（= 《清净道论》五喜之**小喜 / 起毛喜**·法喜身体征相）。故"信乐"按所缘面分质地：**实面（法理 / 缘起无我）= 强热质地法喜 / 德面（三宝人格化）= 冷质地**。"信德冷质地"**精确限定为"德面冷"、不泛化到实面**——慧解脱信德典型形态是"**热在理、冷在相**"（法喜来源是理的洞见、非对象崇拜）。冷质地 ≠ 不乐（趋向在欣乐在、只是不热）。**开放点**：德面"冷"是真冷、还是人格化崇拜型触发从未运作过（类比惭愧方便层），留待遇三宝强境现量核。
- **降级首例最强形态**〔第三层〕：不信污染的是"心净趋向"公共基底，而修行者此基底恰是最先稳的地基（信"直接观心净为性"入路），故不信最无处落脚——结构必然非偶然。
- **懈怠根切分 = 精进力 + 痴一分（saṃvega），非不信**：修行者场域 B 懈怠不走"不信 → 懈怠"凡夫链（不信不现行）。其懈怠双层（用"了 / 痴之别"判准切）——元认知层如实知"法理未通透"= 无痴正知（纯未了）/ 法理层对无常·暇满·轮回过患未现量通透 → 紧迫感（saṃvega）不起 = 痴一分（痴所障）。能说出"有痴一分"正因元认知层无痴 = **递归的痴觉照**（同 [假说 13](../假说/假说-13-递归惭愧.md)）。**预埋懈怠主修区**：懈怠对治治本要补这一分痴（思维无常 / 暇满令法理从比量通现量），非单靠策励。
- **理热相冷候选**〔第三层·不立定论〕：德面冷质地（信侧）+ 紧迫感未起（懈怠痴根侧）可能同源 = 慧解脱理性派"对抽象实相理热、对情感动员逼迫型相冷"；待懈怠精修现量核。
- **别有体定夺**：护法招式第四次落地（落点自秽 + 秽他·污染公共基底 = 四法唯一横向型）；无明三显现面（了理 / 堪能 / 趋向）扩成。**"大"续证**：三尺齐证基底配置级、基底义最纯一法（障公共基底本身）。

**教学动作**：① 报告"闻思 / 法理打通的法喜（浑身发麻 / 起毛 / 欢喜）"→ 按**实面热质地法喜**（小喜 / pīti）理解、是修道正向信号，**不框"信德冷"**（冷限德面）；报告"对三宝无自然欢喜"→ 仍按德面冷质地、且查是否人格化崇拜触发从未运作（开放、不判缺）；② 报告"信乐 / 欣乐"→ 按"趋向在欣乐在只是不热"理解、**不误判为"不乐 / 信有缺口"**；③ 报告"没紧迫感 / 不觉得需时刻精进"→ 用"了 / 痴之别"切（如实知未通透 = 无痴正知 / 无常暇满未现量通透致 saṃvega 不起 = 痴一分）、对治指向**补痴一分（思维无常暇满）非单纯策励**、接懈怠预埋；④ 凡涉懈怠根 → 修行者走"精进力 + 痴一分"非"不信 → 懈怠"链；⑤ 不信此法无主修区、归档不花常规带宽，真主修指向懈怠 / 失念。

### 8.24 懈怠确实现行（大随真主修区首法）+ 懈怠根三块（痴一分 / 精进力双不足 / 遮强表弱）+ 欲钩双线对治（2026-06-29 懈怠精修中现量化）

大随第四法。**懈怠 = 大随八第一个对修行者确实现行的法**（真主修区；掉举罕现 / 惛沉降级 / 不信降级，唯懈怠现行），不走凡夫"不信 → 懈怠"链。本法精修罕有地对修行者真实主修区做深度诊断，从懈怠根挖到修道动力点火。元层产出整理为专题 [修道点火与遮强表弱](../修行学/修道点火与遮强表弱——懈怠根诊断与欲钩双线.md)，单法内容见 [懈怠](../03-心所法/随烦恼心所/懈怠.md)。

- **懈怠根三块（并列同级·修行者否决"痴上游 / 双不足中性"上游假说）**：① 痴侧（saṃvega 无所缘可起——暇满难得未建比量〔"佛法在身边故不知珍"=易得不知珍·命好遮蔽·**连比量都没有**〕/ 行苦未现量〔苦受耐受 + 命好掩盖〕/ "长路 → 不急"=推延懈怠精装版〔修行者认它是懈怠·无正当根据〕；**校准**：修行漫长 / 跨世相续 / 无死恐惧本身是正知非痴、要破的只是拿它们给"不急"背书）；② 精进力侧（双不足模式〔世俗欲不足=命好福报 / 精进力不足=假说7休眠延长〕+ **无"认识→勇悍"转换链**）；③ 元层 = 遮强表弱。
- **遮强表弱（核心·空性见结构签名）**：修行者**能斩断贪驱动紧迫（遮）/ 升不起纯净精进（表）**——能清楚分辨贪紧迫〔抓取 / 粘着 / 怕失去〕与出离 / 善 saṃvega（**非表层标签转移**），问题是遮能 / 表不能。贯穿惭愧清场强 / 悲悯涌现弱（[8.10](../实修/修行者画像.md)）、干慧见空强 / 动力生弱（议题①）、懈怠斩断强 / 升起弱。**2D 模型**（操作轴遮 / 表 × 所缘轴理 / 相）：遮全能 / 表 × 理**能**（理热：法喜 / 胜解果德、众生苦生欲）/ 表 × 相**弱**（相冷：虔诚 / 恐惧型 saṃvega / 热共情）。**干慧乐观解**：表 × 理能力在、只是生动力的理-所缘（苦谛 / 果德）被命好遮蔽没对准、对准即点火。
- **统一签名"用果位见地消解因位动力"（干慧机制）**：空性溶出离心（"不执着就没逼迫"）/ 任运无功用溶善 saṃvega（"紧迫是贪要放下"）/ "等任运·长路不急"溶勇悍——慧只往果位走、不回头供因位动力。
- **行苦厘清**：修行者"不执着就没逼迫"是现行级真证量（苦苦 / 坏苦确执着依赖），但**行苦 = 种子级"不安稳"**（有漏诸行麁重所随·掌中毛·感受不到才是凡夫位标准、非反证）——"平静悬在未断种子上、缘动复燃、对缘无自在"= 冷的零恐惧 saṃvega 驱动。
- **对治 = 欲钩双线点火**：欲非升起、是**胜解**出来（慧的活、点火开关在慧手里 → 遮强表弱非死局）。A 求果德 / 不退 / 大自在（"不安稳"表翻面·接已激活披甲种子）+ B 见众生苦 → 冷悲 → 菩提心（认知路径非热共情·**绕过命好遮自苦的撬入**·B 给 A 供苦谛燃料）；经典骨架 = 三士道（两线 = 中 / 上二士钩）+ 入行论精进品四力；点火后**善精进熏显非升起**〔假说 8〕、靠现行（触发点 / 主座 A）、不找"升起心法"。
- **理热相冷收口**：不是"情路全冷点不着"、是"**点火必走理路 / 胜解（理热）、不走情路 / 恐惧（相冷）**"——A/B 两钩都是理路、都点得着 = 证据；并入 2D 模型一切面。
- **"大"续证**：三尺齐证基底配置级、**大随八第一个"现量位"证据**（懈怠现行）；别有体**无诤议**=护法招式收束 / 终点（对偶精进体性最鲜明）。
- **遮强表弱 / 2D 模型 / 统一签名 = 修行者本人自我诊断、无跨人解释力故不入假说表**（2026-06-29 定）。

**教学动作**：① 报告"很忙 / 时间不够 / 没修行"→ 判懈怠用"**退善法**"尺、不用活动量（身忙而于修断事懈怠·勤于染亦懈怠），问"修善因缘具足的时段有没有被替代"（优先级颠倒）、不问"为什么不自律"；② 报告"没紧迫感 / 不觉得需精进"→ 走懈怠根三块（痴侧暇满 / 行苦未见·命好遮自苦 → 对治补痴**观暇满 / 行苦建比量** + 欲钩点火），**不框制造紧迫 / 恐惧**（相冷·情路对修行者无效且装相）；③ 报告"紧迫感是贪要放下"→ 分清染紧迫（抓取 / 粘着 / 怕失·斩断 ✓）vs 善 saṃvega（出离 · 无贪 · 该升起）、修行者能分清（非表层标签转移）、问题是"遮能 / 表不能"；无死恐惧大半真资粮不动、只破"拿它给不急背书"；④ 报告"升不起精进心 / 找不到方法"→ 善精进**熏显非升起**（没有即时表心法）、把劲放现行熏（触发点 / 主座 A）+ 心行只做"观"、欲从**胜解（慧）**点火；⑤ 凡涉利他 / 见众生苦 → 走认知路径**冷悲**（非热共情）、B 线既点火又长利他轴、见众生苦反推自苦（绕命好遮蔽）；⑥ 干慧根因 = **遮强表弱 + 用果位消解因位动力**（议题①更新）。

### 8.25 放逸伴生降级（懈怠守护维度投影）+ 三根位守护双机制（势力弱 + 惭愧截快）+ 遮强表弱配置侧再证（2026-07-02 放逸精修中现量化）

大随第五法、大随八唯一「非别有体」（D 复合分位）。放逸对修行者**无独立现行位**——四所依（懈怠 + 贪嗔痴）中三毒防线稳、唯懈怠松，故其"放逸"只是**懈怠在守护维度的投影**（**懈怠主导型放逸 = 清净型纵荡**：就是"不修"、不是"耽欲纵荡"）；真主修区仍唯懈怠（精进位），放逸不另立对治通道。详见 [放逸 §四](../03-心所法/随烦恼心所/放逸.md)。

- **三根位守护双机制（现量分判）**：① **种子势力弱为主**（毒流多数"本就不起"）——但守界"肯定不能完全做到"（不作全称，与不信"未发现 ≠ 确证无"一贯）；② **相续层守护真实在运作**——贪嗔起来"那一下"清晰可感 + 被**惭愧迅速瓦解**的过程清晰可感（与无惭无愧精修"脉冲 + 惭愧即刻截断"同型）。非纯缘缺不现。
- **遮强表弱配置侧再证**：守护配置四位中，三根位靠**遮**性操作守住（惭愧截断 / 瓦解 = 否定式）、精进位需**表**性操作（正向生起）——**唯一缺位恰是唯一表性岗位**。懈怠精修从动力层、放逸精修从配置层，两条独立路径同一结论 = 互证（并入专题 [修道点火与遮强表弱 §3.1](../修行学/修道点火与遮强表弱——懈怠根诊断与欲钩双线.md) 配置侧续证）。
- **配置层语言的价值**："守护配置四位、三根位满、只缺精进一位"这句诊断只有放逸 / 不放逸的配置层语言能说出（成分层语言拼不出"位"）；不放逸涌现的缺口精确到一位 = 精进（接操作核 05"精进力层未稳 → 不放逸未涌现"）。
- **大随五法见自全景**：掉举罕现 / 惛沉不现行 / 不信降级 / 懈怠现行（真主修）/ **放逸伴生**——降级第四形态（**伴生投影型**）。

**教学动作**：① 报告"松 / 滑落 / 荒废 / 防线撤了"→ 用配置语言分诊"缺哪一位"（多半 = 精进位 / 懈怠），**不按"放逸 = 放纵享乐"框**（修行者是清净型纵荡 = 就是不修、非耽欲）；② 报告"三毒防线稳"→ 双机制分判（势力弱 vs 截得快），确认相续层守护在运作、不误判为纯缘缺；③ 放逸对治 = 补精进位 → 不放逸配置翻转（欲钩双线点火），**不另立"防纵荡"通道**；④ 见众生凡夫放逸 → "防线全撤后自然滑落、非主动作恶非品行问题"、帮 = 补不放逸缘（重设防线）、不框"要自律"。

### 8.26 失念主修区立案（培育型）+ 空缺型为体微眠伴生 + 归因迁移 + 守细修订与三轮模型（2026-07-06 失念精修中现量化）

大随第六法、B 俱一分摄首法（念一分 + 痴一分）。失念是**大随第二主修区，但性质与懈怠分开标**：懈怠是染现行主修区、失念是**功能底板训练区**——见自形态定名"**染相微、功能缺口实**"（大随六法见自全景第五种形态）。详见 [失念 §五](../03-心所法/随烦恼心所/失念.md)。

- **细所缘失念关口正式立案**：惛沉精修（6/25）预埋的"定历来天花板"归入失念名下。体性精判 = **空缺型失念为体、微眠初分伴生**——判据两条：**身分征**（头沉 = 眠初分探半身）+ **出场相**（忽然切回、清明满格 = 明分全程未钝化、非惛沉、未入深昧）。空档之体 = 痴分单撑（**味定痴型校正的理上闭环**：空档"无内容 + 不知无内容"双重结构 = 痴覆境 + 覆失两重作用；上座部"堕入有分"同一现象同一纠正）。劫持型（贪嗔征用染念、有鲜活之贼）两场域皆排除。
- **归因迁移 = 进展信号**：5/12 操作核"失败模式 = 失念"已迁移——触发点安装生效（决意现起 ✓ 且全程在场），座前窗口 = **全程知道该去坐、就是没动 = 纯懈怠**；失败点从念位下移精进位（与懈怠真主修区结论合流，操作核 05 已注记）。
- **培育型非识破型**（三证：八断行给忘圣言配**念**〔培育〕非正知〔侦察〕/ 两关现量皆"无贼可破"〔座前贼看得清而识破不解决、坐中无贼唯空档——痴场内无观测者〕/ 对治收束主座 A 自身）。**两关结构**：**懈怠守上座关、失念守入细关**——同一定工程的前门与深门；失念不开第三场域（关口 = 主座 A **纵深前沿**，深度轴非场域轴）。
- **守细善巧修订（更正 6/25 数→随手法）**：失效归因 = 事件响应型遇无操作窗口（"每次都有，用不上，到那个点就进空档"；"每次都有"同时 = 每座稳定抵达关口 = 瓶颈单点集中的正面读数）。改**预装配置三件套**：触处**位置性开放作意**（安放、等待、不构画——非想象：定所缘本在意识〔影像所缘 / 定中独头 / 三相移交〕，关口 = 移交点）+ 前置地标轻策举 + 座前决意预装。**单一现量检验 = 入口可感化**（空档场内无观测者、唯边缘可测；**坠窗不是训练、接住才是**）。
- **三轮模型 + 等高线**（修行者现量综合·修正版）：失念 = **念力等高线的边缘现象**、训练 = 外推、失念是测量仪；**念持境、定稳台、慧照破**——念的明 = 明记（在场）/ 慧的明 = 简择照见（洞穿），破无明是慧现观的质变点非念力渐进顶点；**伏断分层** = 正念**伏**现行（意识层在场排挤）/ 慧**断**种子 / **末那地板**（八大随与末那恒行相应、非第六识正念所及、唯见道转依起递减）；念定增长 = **当前核心工作**、服务止观双运核心目的（对修行者暂重合，短板恰在念定 = 议题①慧定不匹配）。
- **遮强表弱机能层第三径**〔第三层候选·不入假说表〕：两关断行全在表侧（信欲勤安 / 念培育）、五过失自查答得最顺的是舍（遮侧）——八断行盘面强弱分布再现遮表签名；动力层（懈怠）/ 配置侧（放逸）/ 机能层（失念）三径合流，并入专题 §3.1。
