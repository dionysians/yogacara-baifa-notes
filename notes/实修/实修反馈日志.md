## 监测原则（持续应用）

### 真定 vs 惛沉的辨识

睡前禅定的主要风险是惛沉伪装成定。每次实修后须自查：

| 真定的特征 | 惛沉的特征（需警惕）|
|---|---|
| **念主动持守所缘，agency 在场** | **念被动松脱，不受控滑入，agency 失守** |
| 念清晰，所缘明 | 念模糊，半睡半醒 |
| 出定后第二天能清晰回忆定境 | 出定后回忆模糊 |
| "刻印感" / 五识收摄但心明 | 沉沉欲睡 / 心暗 |
| 中断后快速返回 | 中断后难以返回，更想睡 |

> **关键判别（2026-04-30 增补）**：**"自然过渡"不是真定的充分信号**——真定是连续细微化的自然，惛沉是平滑滑入暗钝的自然，二者都无 jerk。决定性的判别问句是："**那段时间我是否还在'守'所缘？**"——能答"在"即真定，答"不知道/失守"即惛沉/睡眠。

### 三个不要

1. **不立刻提速** — 单次表现好不是跳级理由
2. **不固化自我形象** — "我是个能 5 分钟入深定的人"是末那变形
3. **不为现量体验兴奋** — 单次出现不能定义稳态，需反复验证

### 真正值得追踪的指标

不是"今天定多深"，是**连续天数**。每次反馈关注：

- 是否保持每日不断
- 不同时段（如周末早晨、午后）的差异（偶尔对照）
- 外缘干扰是否在适应中减少
- 惛沉信号是否出现

### 30 min 阈值的 strategic 定位（重要——不是 path 失败）

- **A 主座**：30 min unit + **绝不 forcing pain** = ✅ 当前 unit 设计合理
- **B 双盘训练座**：专门做 Layer 3 / 4 渐进 exposure = 当前的 Layer 3 训练通道
- **C 柔软度**：辅助 Layer 1 / 2

→ A 主座**不需要 push 延长到 40 min**——这违反 5/2 三轨 partition 原则（A 主座绝不 forcing）。Layer 3 训练应通过 B 轨道完成，让阈值**自然上升**而非强行延长 A。

"尝试 2 次再次进入定境 → 无法成功 → 退出起身"这层应答的精确机制非常 healthy：

### 双盘训练的多层机制 framing

修行者主动 push 的 mechanism question："既然痛是缺血导致，为什么长期练习能久坐？"——答案是**多层 adaptive 同步发生**：

```
长期双盘训练
   ↓
Layer 1（关节柔软度）→ 极限位置不再"挤"，机械压迫减少
Layer 2（软组织适应）→ 肌肉对血管压迫减少
Layer 3（血管层）→ 侧支循环发展，缺血代偿
Layer 4（神经感觉）→ 痛觉感受器 desensitization + 中枢处理改变
Layer 5（姿势 efficiency）→ 找到最优 weight distribution / alignment
   ↓
同样姿势的 net 痛感大幅下降 → 可长时双盘
```

**training design implication**：
- Layer 1-2：直接靠**轨道 C**（柔软度训练）
- Layer 3-4：靠**轨道 B**（双盘训练座的渐进 exposure）
- Layer 5：在**轨道 B** 中觉察 alignment 微调

三轨协同 = 同时 work 多层，比单纯"sit through"更高效。

### 轨道 B 的安受苦忍精确定位

双盘训练座中 pain 不是修行的副产品，是**核心所缘**：

| 心所 | 在轨道 B 中的运作 |
|---|---|
| **念** | 清晰跟随痛的现量变化（生起、强度、波动、cycle） |
| **不嗔（无嗔）** | 不烦躁、不抗拒 |
| **不退（精进）** | 不立刻调整姿势、不立刻结束座 |
| **慧（观）** | 观察苦受的无常 / 苦 / 无我 = 修谛察法忍 |

ceiling 判准：可以 sit through（修忍辱），但**不损根**——结束后能正常走路、不持续数日疼痛。

### 不要走的方向（明确警惕）

- ❌ "为消业故意延长极痛"——把消业做成贪的对象，反向喂我相
- ❌ "我必须忍下去坚持 30 分钟"——用力 framing
- ❌ 把双盘做成主座的 forcing 内容——破坏定的连续性
- ❌ 把"练好双盘"设为修行 milestone——已驳的迂回路径

### 起步期定位（更新）

- 主座层：经 4/27、4/28 后有间隔，5/2 是**重新接续座**，节奏需 re-establish
- 三轨 plan：从 5/2 后开始实施
- 第 1-2 周：B 轨道做 1-2 次 monitor 座，观察自身 pain pattern；C 轨道每日实施
- 第 3 周后：根据 monitor 数据决定 B 轨道时长 unit（不依赖外部"30 分钟周期"教条）

### 待观察

- 自身 pain pattern 的 empirically 验证（cycle 是否存在 / 在哪个时长附近）
- C 轨道实施 2-3 周后髋关节 ROM 是否有明显变化（可作为 Layer 1-2 进展信号）
- 主座（A）频次能否稳定 re-establish
