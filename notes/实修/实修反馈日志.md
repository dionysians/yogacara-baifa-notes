## 监测原则（持续应用）

### 真定 vs 惛沉的辨识

睡前禅定的主要风险是惛沉伪装成定。每次实修后须自查：

| 真定的特征 | 惛沉的特征（需警惕）|
|---|---|
| **念主动持守所缘，能动性 在场** | **念被动松脱，不受控滑入，能动性 失守** |
| 念清晰，所缘明 | 念模糊，半睡半醒 |
| 出定后第二天能清晰回忆定境 | 出定后回忆模糊 |
| "刻印感" / 五识收摄但心明 | 沉沉欲睡 / 心暗 |
| 中断后快速返回 | 中断后难以返回，更想睡 |

> **关键判别（2026-04-30 增补）**：**"自然过渡"不是真定的充分信号**——真定是连续细微化的自然，惛沉是平滑滑入暗钝的自然，二者都无 jerk。决定性的判别问句是："**那段时间我是否还在'守'所缘？**"——能答"在"即真定，答"不知道/失守"即惛沉/睡眠。

### 三个不要

1. **不立刻提速** — 单次表现好不是跳级理由
2. **不固化自我形象** — "我是个能 5 分钟入深定的人"是末那变形
3. **不为现量体验兴奋** — 单次出现不能定义稳态，需反复验证

### 真正值得追踪的指标

不是"今天定多深"，是**连续天数**。每次反馈关注：

- 是否保持每日不断
- 不同时段（如周末早晨、午后）的差异（偶尔对照）
- 外缘干扰是否在适应中减少
- 惛沉信号是否出现

**坐姿**：单盘  
**触发 序列**：家人睡下 → 停下手中活 → 直接禅定

### 数据

- **触发 触发**：✅ 有效触发。家人睡下后，能停止手中正在做的事，直接进入禅定。
- **主要障碍**：身受打断。快结束时腿部酸胀达到阈值后退出。
- **行舍 / 征兆-标的 监测**：✅ 未出现“想坐得更好 / 更久 / 更稳”的微细追求感。
- **新增疑点**：坐中数息一段时间后，会进入类似“睡着”的状态；从该状态出来时没有明显“醒来”的感觉，会自然衔接回数息，但该状态中意识似乎消失，无法继续以数息为所缘。

### 正面 signal 1：触发 设计 三次验证通过

5/13、5/14 后，5/15 再次完成 触发 执行：

```
家人睡下 → 停止手中活 → 入座
```

这说明 5/12 不放逸学习中确定的 触发 设计 已不只是单次成功，而是开始呈现**可重复性**。本次未经过洗澡环节，仍能直接入座，表示“家人睡下”这个 触发 本身对念所缘切换有效。

**实修意义**：当前不放逸起步点仍然健康——重点继续放在连续天数与 触发 稳定性，不把单次深浅作为评价中心。

### 正面 signal 2：征兆 / 标的 分判已内化

修行者明确反馈：

> “完全理解需要通过精进的方式熏种子，更好 / 更久 / 更稳是行动的结果，而不是行动的目的。”

这与 [假说 17：征兆 vs 标的](../假说/假说-17-sign-vs-target.md) 在行舍场的预演严格对应：

| 层 | 内容 |
|---|---|
| **标的** | 持续执行、以精进熏种子 |
| **征兆** | 更好 / 更久 / 更稳 |
| **健康分判** | 不追逐 征兆，只重复 标的 |

→ 这是 5/14 “行舍 ↔ 征兆 / 标的 分判”预演后的直接现量延续。当前没有出现“我要更深 / 我要更久 / 我要更稳”的掉举型修行者相。

### 新疑点：所缘失守型“类睡眠”状态

**现量描述**：

- 所缘为数息；
- 数息一段时间后进入类似“睡着”的状态；
- 该状态中意识似乎消失，无法继续以数息为所缘；
- 从该状态出来时没有明显“醒来”感；
- 出来后能自然衔接回数息。

### 初步判别：实修处理上先按惛沉 / 浅睡边界处理

根据本日志“真定 vs 惛沉”监测原则，关键不在“出来时有没有醒来感”，而在：

> **那段时间是否仍在守所缘？**

本次反馈的关键句是“**无法再所缘数息的状态**”。因此，从实修操作角度看，此状态应先判为：

> **念失守 + 明记断片，偏惛沉 / 浅睡边界，不计作真定。**

但仍需保留细分空间：它未必是粗重睡眠，因为出状态时没有强烈“醒来”感，且能自然续接数息；更可能是睡前时段中常见的**细惛沉 / 微睡眠 / 明记中断**混合状态。

### 与真定的边界

| 项 | 本次状态 | 初步判读 |
|---|---|---|
| 所缘是否持续 | 中间无法数息 | 念失守 |
| 明记是否清楚 | 状态中意识似乎消失 | 明记断片 |
| 出状态是否剧烈 | 无明显“醒来”感 | 不足以判定真定 |
| 能否自然续接 | 能续接数息 | 表示滑入 / 滑出平滑，但不是充分正信号 |

→ “自然衔接”不是定的充分证据。真定的自然是**所缘连续细微化**；惛沉 / 浅睡的自然是**平滑滑入暗钝**。本次重点观察对象就是二者的分界。

### 下一次坐中的观测任务

若再次出现该状态，不需要紧张，也不要追求“弄清它是什么境界”。只做 4 个微观察：

1. **入状态前**：数息是否开始模糊、漏数、自动化？
2. **状态中**：是否有任何微细“知道自己在坐 / 知道呼吸在”的明记？
3. **出状态后**：能否回忆失守前最后一个清楚的数？
4. **身体信号**：头部是否微垂、身体是否塌、呼吸是否变粗或变睡眠化？

### 操作建议

下一次如果发现数息开始滑入“黑掉 / 断片”：

- 先轻轻提直脊柱；
- 数息改为更清楚的 1-10 轮计数；
- 必要时微睁眼，保持一点光线；
- 做 2-3 次略深呼吸后回到自然呼吸；
- 若仍反复断片，提前结束也可以，不把“坐满”当 标的。

**关键原则**：这不是失败，是睡前禅定阶段很正常的边界数据。当前 标的 仍是连续执行 + 保持所缘明记；“是否进入某种特殊状态”不是目标。

### 当前定位

- **触发 设计**：✅ 三次验证，开始稳定。
- **A 主座时长**：37 分钟，仍处于可接受范围；腿部酸胀作为自然结束信号。
- **行舍监测**：✅ 征兆 / 标的 分判清楚，未追逐“更好 / 更久 / 更稳”。
- **新增 监测**：睡前坐中出现所缘失守型类睡眠状态；后续重点分辨细惛沉 / 浅睡与真定边界。

### 双盘训练的多层机制 框定

修行者主动 深挖 的 机制 question："既然痛是缺血导致，为什么长期练习能久坐？"——答案是**多层 adaptive 同步发生**：

```
长期双盘训练
   ↓
Layer 1（关节柔软度）→ 极限位置不再"挤"，机械压迫减少
Layer 2（软组织适应）→ 肌肉对血管压迫减少
Layer 3（血管层）→ 侧支循环发展，缺血代偿
Layer 4（神经感觉）→ 痛觉感受器 desensitization + 中枢处理改变
Layer 5（姿势 efficiency）→ 找到最优 weight distribution / alignment
   ↓
同样姿势的 net 痛感大幅下降 → 可长时双盘
```

**training 设计 implication**：
- 层 1-2：直接靠**轨道 C**（柔软度训练）
- 层 3-4：靠**轨道 B**（双盘训练座的渐进 exposure）
- 层 5：在**轨道 B** 中觉察 alignment 微调

三轨协同 = 同时 work 多层，比单纯"sit through"更高效。

### 轨道 B 的安受苦忍精确定位

双盘训练座中 疼痛 不是修行的副产品，是**核心所缘**：

| 心所 | 在轨道 B 中的运作 |
|---|---|
| **念** | 清晰跟随痛的现量变化（生起、强度、波动、cycle） |
| **不嗔（无嗔）** | 不烦躁、不抗拒 |
| **不退（精进）** | 不立刻调整姿势、不立刻结束座 |
| **慧（观）** | 观察苦受的无常 / 苦 / 无我 = 修谛察法忍 |

上限 判准：可以 sit through（修忍辱），但**不损根**——结束后能正常走路、不持续数日疼痛。
