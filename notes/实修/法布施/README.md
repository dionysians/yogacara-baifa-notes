## 经典锚

法布施是三施之一：
- **财施** = 以财物利益他人
- **法布施** = 以佛法利益他人（经典中视为三施中最殊胜者，因其能令他人究竟离苦）
- **无畏施** = 令他人远离恐惧

法布施不同于一般的"教学"——涉及对方根器的辨认、契机契理、不染自利、与受者的因缘等多重因素。

## 当代结构性挑战

法布施在当代面临的核心挑战，与本项目其他领域观察到的"方便层瓦解"是同源的——传统法布施的方便层（寺院结构 / 师徒传承 / 较纯净的闻法环境）正在瓦解，而新方便层尚未形成。

详见 [假说 14 · 2026-05-23 闻法增上缘场验证节](../../假说/假说-14-方便层瓦解普遍性.md)：
- 闻法缘爆炸但正邪混杂——筛选瓶颈从"缘的稀缺"迁移到"缘的筛选"
- 善根种子的筛选功能被放大
- 有种子者与无种子者的差距拉大
- 闻慧与修慧的落差加大（世智辩聪难风险上升）
- 末法特征对应

这意味着：**当代法布施不能简单复制传统模式，需要在新方便层上重新设计**——这是本文件夹未来要承载的核心工作。
