## 2026-06-03 凌晨：上座几息后"不需用念支持"的自如感——念从力压转向轻持（无功用早期 taste）

**时段** 01:57—02:44（47 分钟）/ **所缘** 数息 / **坐姿** 单盘 / **触发** 延续（日日连续第 8 天）

### 数据
- 日日连续第 8 天（5/27→5/28→5/29→5/30→5/31→6/1→6/2→6/3）
- **新现量（修行者自陈）**：上座几个呼吸后即感**很轻松、很自如**，"**好像不再需要用念来支持了**"——修行者形容"如果要形容就是任运"，但带**"好像 / 如果要形容"的试探框定**，未坐实。
- **清明全程保持**：期间清明状态仍有起伏，但**全程数息不断**（未丢数）。
- **杂念变多**（之前很少）：修行者**自判为正常现象**——之前念推动禅定力量重、其他念头不易进；现在念变轻，念头易波动，但**闪过的念头本身很容易清除，稍微控制就消失**。
- **时间感模糊维持**：下座后才发现已 47 分钟。

### 关键判读

**核心信号 = 念从「有功用·力压」转向「无功用·轻持」的早期 taste。**

修行者"杂念变多但易清"的自判，**机制上成立且是关键现量**：

| | 之前 | 6/3 |
|---|---|---|
| 念的质地 | 有功用——用力推动 / 力压杂念 | 无功用早期——轻持，不再力压 |
| 杂念 | 难入（被力压挡住） | 易入，但**闪即清、稍控即消** |
| 守所缘 | 守得住（力守） | **仍守得住**（数息不断、轻守） |

杂念变多**不是失念/散乱**——散乱的判准是**失守所缘**，而此处数息全程不断、守得住，只是从"力守"变"轻守"。所以杂念变多恰是**念力放下用力鞭策**的现量侧写，不是退步。〔第二层框架映射〕

〔第二层框架映射·按 [行舍操作核](../../../教学操作核/教学操作核-06-行舍.md) 三相轴精确分诊，**不给"我到任运了"整体标签**〕：

| 三相 | 6/3 状态 |
|---|---|
| **平等**（振幅轴 / 住分） | 🟡 部分——清明全程在但**有起伏**，延续 6/1「明记呼吸仍瞬断」；基质未完全稳 |
| **正直**（方向轴） | 🟡 部分稳态——无征兆/标的错位痕迹（修行者试探语 + 客观自判，未推进感劫持）|
| **无功用住**（用力后位） | 🟡 **早期 taste 浮现**——"不需用念支持 / 自如"是其味道 |

操作核明示：**无功用住应在平等稳定后才涌现**。此处平等基质未圆满（清明仍起伏、6/1 明记仍瞬断）即出现自如感，故**严格框定 = 单座无功用早期味道，非"无功用住后位达成 / 我已任运"**。修行者"好像 / 如果要形容"的试探语本身 = **健康框定**——未坐实"我已得任运"，自动避开了行舍者相劫持（操作核核心揭示 4：利根者最易把"正直/部分显现"升级为"行舍整体显现"）。

**守所缘判准**（操作核核心揭示 5）：数息全程不断 = **在守** = 倾向性活跃 = **行舍方向**（能动性在场），不是受舍+惛沉的"被动平静"。这条判准确认 6/3 的自如是真朝行舍方向，而非惛沉伪装。

**标的≠征兆**（行舍正直一相 / 假说 17 闭合）：自如、轻松是**征兆**，定承载力稳定才是**标的**——不据单座自如提速、不固化"我能任运了"形象。

〔第三层·推论〕三条线可能在 6/3 交汇，单座不足判别：
1. **轻安线**——"很轻松"含《成唯识论》"远离粗重，调畅身心"侧面，接 5/29「禅定变轻、变丝滑」；
2. **念力层线**——"不需用念支持"= 念力从「用力鞭策」转向「任运稳态」，接不放逸力层成熟（CLAUDE.md 不放逸操作核：不放逸涌现 = 念力稳态化 + 精进力层不被违缘倾动）；
3. **行舍无功用线**——如上。
三线是否同一机制不同侧面，待样本判别。

〔第三层·推论〕**待复现验证的张力**：操作核序列为「平等稳定 → 正直稳定 → 无功用住涌现」线性结构，而 6/3 平等基质未圆满即现无功用味道。两种可能——① 这是**座中暂态 taste**（最可能），非稳态倾向，下座即散；② 序列非严格线性。需后续观察：自如感是否复现、平等基质（清明不起伏 / 明记不瞬断）是否随之跟上。

### 监测原则对照
- **真定 vs 惛沉**：✅ **守所缘判准确认行舍方向**——数息全程不断 = 在守 = 能动性在场，自如非惛沉伪装。杂念变多易清 = 轻守非失守。
- **三个不要**：✅ 修行者用"好像 / 如果要形容"试探语、主动给杂念变多一个客观机制解释，**未夸大为"我入任运/得定了"**——三个不要（不提速 / 不固化形象 / 不为现量兴奋）全守住，且自带健康框定。
- **连续天数（真正指标）**：✅ 第 8 天，5/27 起连续段持续加厚。
- **时长**：47 分钟自然结束（时间感失落），不追求——接 5/28「自然结束 47 分钟」模式。

### 学术诚实标注
- 第一层（现量）：上座几息后很轻松自如 / "好像不需用念支持" / 清明全程在但有起伏、数息不断 / 杂念变多但易清稍控即消 / 时间感模糊 47 分钟。
- 第二层（框架映射）：念从有功用力压→无功用轻持、杂念变多=轻守非失守的现量侧写、行舍三相轴分诊（平等部分 / 正直部分 / 无功用住早期 taste）、守所缘判准定行舍方向、标的≠征兆。
- 第三层（推论）：轻安/念力层/行舍无功用三线交汇待判别；平等未圆满即现无功用味道是座中暂态还是序列非线性，待复现验证。
- **框定说明**：核心信号严格框定为「单座无功用早期 taste，非后位涌现达成」——避免把单座自如升级为"我已得任运"（行舍者相劫持入口）。修行者试探语 + 客观自判已自带此健康框定，本条记录顺其框定不拔高。

## 2026-06-01 凌晨：数息计数穿过明记瞬断——拉回知道数到第几（不再从头数）

**时段** 01:56—02:36（40 分钟）/ **所缘** 数息 / **坐姿** 单盘 / **触发** 延续

> **本条经 6/1 当日修行者澄清后修正**：初记误写为"明记不再断片 / 断片消失"。修行者澄清——他**无法分辨"明记没断"**，明记仍有起伏、有时一瞬丢掉所缘；真正的区别是**拉回时明确知道数到第几息**。据此重写如下，"明记不断"表述已收回。

### 数据
- 日日连续第 6 天（5/27→5/28→5/29→5/30→5/31→6/1）
- **回答 5/30 留下的监测小问号**（心情不稳上座是真定还是惛沉）：修行者现量厘清——**既不是真定，也不完全是惛沉**，当前处于「三段式数息**明分不足 / 细惛沉边界**」阶段；实际状态**并没有变差**。
- **新现量（澄清版）**：三段式数息过程中，深静阶段**滑入趋势**出现时——
  - **明记呼吸所缘仍有起伏，有时一瞬就丢掉所缘**（此点未变）；
  - **之前**：丢掉所缘会**连数息数一起丢失**，拉回后需**从头数**；
  - **今天**：虽然依然滑入、仍有瞬断，但**没有再丢失息数**，拉回时**明确知道数到第几**、不用从头数。

### 关键判读

**核心信号 = 念对"数到第几"的记持，穿过了明记的瞬断**（不是"明记不再断"）。

修行者的澄清把信号定位到了比初记更精细、也更可靠的一层——两层记持分开看：

| 层 | 内容 | 6/1 状态 |
|---|---|---|
| **明记当下所缘** | 对"这一口呼吸"的明记（明分） | **仍瞬断**——有时一瞬丢掉所缘 |
| **念对序列位置的记持** | "我数到第几了" | **穿过瞬断保住**——拉回知道第几 |

变的是**下层**：念对计数序列位置的记持，独立于当下呼吸明记而存活，穿过了明记的瞬断。**不是**上层明记本身不断了。

〔第二层框架映射〕这给「真定 vs 惛沉」一个比"守所缘 / 不守所缘"二分更精细的**瞬断深浅判准**：

- **数也丢、从头数**（旧模式）= 瞬断深到**连念的记持都被冲掉** = 沉入细惛沉的标志（surface 时不知身在何处）。
- **数不丢、知道第几**（今天）= **浅的明记闪断**，念的背景记持未被冲掉 = **没有真的沉下去**。

所以方向上仍是远离惛沉，但**精确表述 = "瞬断变浅 / 念记持未随明记一起断"，而非"明记不再断"**。这也呼应数息所缘的设计本意——"数"给念一个离散抓手，其记持可独立于当下呼吸明记而存活；今天的进展 = **这个抓手抓住了**。〔关联不放逸根层机制「念心所在时间域持续在场」：[教学操作核-05 不放逸](../../../教学操作核/教学操作核-05-不放逸.md)；但严格说今天稳的是念记持层，明记当下所缘层仍有瞬断〕

〔第三层·推论〕细惛沉（惛沉随烦恼微细现行）**仍在**拉，瞬断仍发生，堪任性未到真定；今天的变化是**瞬断的深度变浅**（深到冲掉计数 → 浅到只闪断明记、计数存活）。这是**边界态的内部进步**，不是跨过边界进入真定。待后续样本验证：瞬断深度是否随累积继续变浅、滑入趋势本身是否减弱。
