## 一、实修文件夹的位置与分层

**位置**：`notes/实修/` 与 `01-准备阶段/` 至 `06-无为法/` **同级**——实修不属于任何一个百法范畴，是跨越百法的独立维度。

**目录树**：
```
notes/实修/
├── README.md                       ← 极简索引（仅目录与指针）
├── 修行全景框架.md                  ← 本文档（稳定 framework）
├── 修行者画像.md                    ← 修行者稳定状态（基础状况、早年经历、信三支等）
├── 当前修行内容.md                  ← 当前正在执行的修行计划（动态更新）
├── 实修反馈日志.md                  ← 每次实修后的反馈记录
├── 基础篇/
│   ├── 禅定实修指南.md              ← 止修完整体系（九住心、六力四作意、止观双运等）
│   └── 观的修习路径.md              ← 待撰写（后期）
└── 心所专修/
    ├── 信的修习路径.md              ← 首份心所专修（2026-04-25，未验证）
    └── ...（随学习进度增补）
```

**分层依据**：
- **基础篇 = 止 / 观**：通用平台，所有具体心所修都建在其上
- **心所专修**：特定心所的所缘与操作设计，依赖基础篇

**百法笔记 vs 实修文档的分工**：
- 百法笔记（如 `善心所/信.md`）承载：经典定义、义理讨论、跨概念比较
- 实修文档（如 `心所专修/信的修习路径.md`）承载：具体坐法、所缘设计、实修反馈
- 通过 `📎 实修指针` 相互链接

## 二、修行三层架构

```
┌──────────────────────────────────────────────────┐
│  第一层：闻思层                                    │
│  ──────────────────────────────────────────────  │
│  内容：百法学习（本项目）+ 其他经论阅读              │
│  作用：提供"见"——修行的方向感和结构               │
└──────────────────────────────────────────────────┘
                      ↓（见地下沉为所缘）
┌──────────────────────────────────────────────────┐
│  第二层：坐中修                                    │
│  ──────────────────────────────────────────────  │
│  内容：                                            │
│  - 止（每次前段）：呼吸为所缘，建立定力平台          │
│  - 善心所基态修（目前：信）：在稳定定态中承载        │
│  - 观（后期）：止观双运，待定基稳固后引入            │
│  结构：定 + 某善心所，同一次坐中完成                │
│  作用：正式时间中熏种，提供"任运基态"             │
└──────────────────────────────────────────────────┘
                      ↓（基态渗透到生活）
┌──────────────────────────────────────────────────┐
│  第三层：生活修                                    │
│  ──────────────────────────────────────────────  │
│  内容：                                            │
│  - 察觉（遍行心所现起、烦恼升起）                    │
│  - 对治（烦恼现前时调用信的消融）                    │
│  - 事上磨（亲子教育 = 末那识对治场）                │
│  作用：熏种 + 现量验证                             │
└──────────────────────────────────────────────────┘
                      ↑
          （三层互相回流，不是单向）
```

### 三层互相回流的机制

- **闻思 → 坐中**：闻思所得的"见"下沉为坐中的所缘
- **坐中 → 生活**：坐中熏下的任运基态渗透到生活
- **生活 → 闻思**：生活中的现量体验反过来深化闻思的理解
- **生活 → 坐中**：生活中积累的观察为坐中所缘提供实感
- **坐中 → 闻思**：定中的清晰让闻思的内容更易"照见"

### 与经典框架的对应

| 经典框架 | 对应本全景 |
|---|---|
| **三慧**：闻慧 / 思慧 / 修慧 | 闻思层（闻+思）/ 坐中修（修） |
| **三学**：戒 / 定 / 慧 | 生活修含戒 / 坐中定 / 闻思+坐中观=慧 |
| **闻思修** | 一一对应 |
| **止观双运** | 坐中修的内部结构 |
| **福慧二资粮** | 生活修（福）/ 闻思+坐中（慧） |

> **学术诚实标注**：三层架构的 framing 属第三层（自主构建的个性化全景），但每一层与经典结构同构。

## 三、坐中修的单次结构

**坐中修的单次结构 = 定 + 某善心所，合在同一次坐中**，不是分开两次坐。

```
一次坐中修（30-40 分钟）
│
├─ 前段（15-20 min）：建立定的平台
│   └─ 详见 基础篇/禅定实修指南.md
│      （九住心、呼吸所缘、数息/随息等）
│
├─ 中段（10-15 min）：承载某善心所
│   └─ 详见 心所专修/ 下对应文档
│      （信 / 精进 / 慈 ... 的具体所缘与操作）
│
└─ 后段（3-5 min）：回向收摄
```

**定是通用平台**，各心所专修文档不重复定的建立过程，直接引用 `基础篇/禅定实修指南.md`。心所专修文档只描述中段（该心所特定的所缘、操作、体感、期望）。

## 四、实修文档的演化节奏

### 触发规则

- **学习到一个新心所时**：如该心所有明确修法，在 `心所专修/` 增加对应路径文档
- **实修 2-4 周后**：路径文档从"🟡 未验证"转向"🟢 已验证调整版"，精华回流到对应百法笔记
- **阶段整合时**：检查全景是否需要调整（如加入"观的修习路径"、调整三层权重）
- **修行者状态变化时**：更新 [修行者画像](修行者画像.md)
- **当前修行计划变化时**：覆盖更新 [当前修行内容.md](当前修行内容.md)

### 一般原则

- 实修反馈记录在 [实修反馈日志](实修反馈日志.md) 内（按日期累积，最新在前）
- `当前修行内容.md` 是动态文档，反映**此时此刻在修什么**，随学习推进覆盖更新
- 路径文档保持相对稳定，仅在"定稿标志"达成时做版本升级
