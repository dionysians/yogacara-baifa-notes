## ⚡ 起步胜解（2026-04-26 已补齐——核心前提）

之前迟迟未真正起步的根因不是"缺乏精进"，而是**对实修价值的细颗粒胜解未稳**——具体表现为误以为"实修禅定 = 大块时间 + 双盘起步"，由此设计了"先做胯部训练等准备好"的迂回。

经百法学习中"种子生现行 → 信慧正反馈"的机制理解，胜解已三层补齐：

1. **任何方式的"定"都是有价值的**，都可以立刻开始——不需等双盘 / 大块时间
2. **实修对闻思修过程有正反馈**，可加速佛法学习——修与学不是先后关系，是双轨并行加速
3. **"种子生现行"机制可反向作用于身体**——修行本身在塑身体（异熟果 / 增上果），不需"等身体准备好再修"

**操作含义**：散盘 / 半跏 / 椅子端坐皆可起步，关键是**频率连续**而非姿势完美。

详见相关讨论：[精进.md](../03-心所法/善心所/精进.md) §三、[熏习机制与"用力"观](../03-心所法/善心所/熏习机制与"用力"观.md)

### 主所缘：水清珠观

基于《成唯识论》水清珠比喻——珠入浊水则浊物自沉、水自清。

**循环结构**（10-15 分钟 中段内反复进行）：
1. 建立 形象：清净透亮的珠 + 心如浊水
2. 观净化过程：珠入水 → 浊自沉 → 水自清 → 珠安住
3. 安住于"水清、珠安住"的稳定状态（形象 可淡化，保留心的清净质地）

**关键原则**：
- 不追求 形象 清晰度——模糊若有若无即可
- 真正保持的是**心净的质地**，不是 形象 本身
- 形象 若散，重新提；心净感若散，也重新提

### A 主座当前微调：三段式数息——从"暗静"转向"明静"（2026-05-16 加入）

> **触发背景**：5/15 A 主座反馈中，修行者确认：呼吸变细、心安静后，会逐渐滑入一个舒服、安静、出后清明的状态，但该状态中**清明 / 明记丢失**，无法继续守数息所缘。经讨论，当前不再继续判别其是否为"真定"或"睡眠"，实修处理上直接作为**明分不足 / 细惛沉边界**来对治。

**当前目标**：

> 不是防止心安静，而是让"呼吸变细、心安静"之后，清明不掉线。

也就是从"暗静"转向"明静"：**静而不暗，明而不躁**。

#### 三段式数息

| 阶段 | 操作 | 目标 |
|---|---|---|
| **前段：正常数息** | 从 1 数到 10；丢了回 1；不追求细、不追求稳 | 降低粗散，建立连续性 |
| **中段：安静出现时，加明分锚点** | 一旦呼吸变细、心明显安静，轻轻加入："清楚知道第几息" | 不只知道呼吸，还保持"第几息"的明记结构 |
| **临界段：滑入趋势出现时，微提明分** | 若数字开始模糊、呼吸舒服但第几息不稳、有沉进去的吸引力：微提脊柱、微睁眼、做 1 次略深呼吸，再回到清楚数息 | 防止安静滑成断片，不把舒服暗静当目标 |

**关键规则**：

- 宁可数息清楚而不深，不要安静舒服但断片
- 若能在安静后保持 5-10 息清楚，即为本座有效数据点
- 不连续调整；连续调整易转成掉举
- 不把"是否进入舒服状态"作为目标，只看清明是否持续

**与行舍学习的连接**：

此方案是行舍在当前阶段的操作版——不是主动追求"无功用住"，而是在坐中防止两边偏失：

| 偏失 | 表现 | 当前对治 |
|---|---|---|
| 掉举偏 | 想坐得更好 / 更久 / 更稳，把 征兆 当 标的 | 继续以连续执行 + 清楚数息为 标的 |
| 惛沉偏 | 安静后明记变弱、数息断片 | 三段式数息，安静时补明分 |

### 三段式数息的日常延伸 — 明记训练(2026-05-17 加入)

> **修行学定位**:**禅定场对治滑入暗静 + 日常场对治基态退失 = 同一念心所(明记)训练在两场域的同步运作 = 行舍"平等"振幅轴训练的双场域展开**。修行者 2026-05-17 在惛沉讨论中现量自识此串联,把"日常基态正念"从"独立新建任务"修正为"禅定主轨的日常延伸"。

#### 同构机制

|---|---|---|---|
| **禅定中** | 入静后滑入暗静 / 失念断片 | 念力不足维持明分 | 用念力把心拉回(三段式数息)|

#### 与童年念正知种子势力的关系

修行者童年修行底色三层之一:**小学时善知识引导的基态正念**(详见 [修行者画像 §二](修行者画像.md))。当前修行任务 = **激活已有种子势力,缩小其现行的缘需求**(从"借强外缘激活" → "无外缘也能自起"),不是从零新建。

#### 修行命题(核心路径)

> 通过反复觉察"明记失守 → 提起明记"的双相运作,让念正知种子势力被熏到**任运现行**的厚度 — 这就是常态(看破 → 熏种 → 常态三步循环 — 详见 [CLAUDE.md 修行路径自我认识 2026-05-17 扩展](../../CLAUDE.md))。

#### 操作方法(三条核心)

1. **觉察"明记失守"的瞬间** — 这个觉察本身就是基态正念的现行。不试图"消除无精打采",只是觉察。
2. **接入当下整体觉察** — 身体 + 周围环境 + 心识状态整体放进觉察(童年课堂模式的闲时复刻:"找到并维持念头,身体 + 课堂 + 老师讲课整体放进去")。
3. **染心所现起即识破** — 任何贪 / 嗔 / 懈怠 / 散乱 / 拖延倾向现起时,觉察本身完成识破。

#### 操作原则

- **不"做"基态,只"恢复明记"** — 任何"我要进入基态"的念头都是反向用力
- **失念 → 提起 → 再失念 → 再提起,反复 = 修行** — 反复就是熏种,不评判
- **不维持** — 真正的基态是任运的,试图维持就是用力

#### 唯一现量检验

> **明记的自然度** — 从"刻意提起" → "自然提起"

不设其他指标(失念点缩小 / 识破速度等都是次要 — 修行者倾向单一核心检验)。

### 2026-05-20 调整：B 轨推迟启动 + C 轨升级为前置主线

> **触发**：修行者参考开胯 / 上双盘教程后发现——当前双盘虽能上，但**是硬掰上去的**（开胯不到位、非髋关节外旋打开后的标准动作），这种姿势对膝盖和脚踝有损伤风险。经讨论确认此判断成立，调整三轨方案。

**调整核心**：

| 轨 | 调整 |
|---|---|
| **A 主座** | 不变——主修，不受任何 gating |
| **B 双盘训练座** | **推迟启动**，前置 gated——不再是"逾期缺口"，是正确的 sequencing 决定 |
| **C 柔软度** | **升级为当前阶段身体工程主线**（性质仍是因缘工程、不是修行；升级的是它在 sequencing 中的位置）|

**为什么对——两种疼痛只有一种是 B 轨的合法所缘**：

B 轨把疼痛当安受苦忍 / 层 3-4 渐进 exposure 的所缘。但双盘里的疼痛是两种性质完全不同的东西：

| 疼痛类型 | 来源 | 性质 | 是不是 B 轨所缘 |
|---|---|---|---|
| 缺血酸麻型 | 血流受限（层 3 血管层）| 可逆、不损伤组织 | ✅ 安受苦忍的正确所缘 |
| 关节扭转型 | 膝 / 踝硬掰承受了本应由髋关节外旋承担的旋转 | 结构损伤、可能不可逆 | ❌ 损根信号 |

膝盖是铰链关节、本不该旋转，开胯不到位就把扭力压到膝关节线和踝关节。**这种疼痛 sit through 不是忍辱波罗蜜，是损根**——正是经典中道反对的"极端苦行（损根）"。且硬掰姿势下 **5 标记的标记 3 慧简择失效**——"身体真到限，还是心想停"中的"限"成了损伤阈值而非循环阈值，无法在污染信号上做如实简择。所以 B 轨在硬掰姿势下根本无法干净运作。

**B 轨启动判准（gate）**：能以"旋转来自髋关节外旋、膝与踝不承受扭力"的姿势上双盘。自测点——上双盘时膝关节内侧 / 踝关节有无锐痛或"被拧"感；膝盖能否较自然落下而非高高翘起靠硬撑。注意 gate 是**"不损根"不是"完美标准"**——主要靠开胯、关节无锐痛的双盘即可启动 B 轨，不必杂志级标准（否则 gate 会变成无限期推迟）。

**进度自测**：每 1-2 周轻轻 test 一次上双盘姿势（只是上、感受，不久坐），作开胯进度的现量检验。从"硬掰"过渡到"自然"即 gate 达成。

**真实目标 reframe**：C 轨的真实目标是**开胯（色法因缘条件）**，不是"能双盘"。双盘是开胯到位后的下游自然结果；若长期开胯有限，**单盘 + 良好开胯**的久坐姿势也是 valid 的长期姿势。

**与 §0 起步胜解不冲突**：§起步胜解 说"实修不必等双盘 / 大块时间"——那是针对**主修**（A 轨定 / 闻思 / 生活），依然成立、A 轨继续。本调整只 gate **B 轨**（一条辅助身体训练轨），不 gate 主修。主修不等双盘（起步胜解成立）+ B 轨等开胯（本调整，因 B 轨结构上就是双盘训练）——两者不矛盾。

**watch-point**：推迟 B 轨 ≠ 身体训练这条线静默。C 轨必须真正主动推进（开胯不会自己发生）；同时不让"等开胯"喂养进展焦虑或借口——开胯是几个月尺度的慢工程，慢是正常的，不构成"修行没到位"。

**学术诚实标注**：
- 第一层（经典）：中道反对损根性苦行；安受苦忍是忍辱波罗蜜三相之一
- 第二层（框架应用映射）："缺血酸麻型 vs 关节扭转型"二分是把经典"损根 / 不损根"对应到现代生物力学
- 第三层（推论）："B 轨结构性依赖双盘依赖开胯""硬掰姿势下标记 3 慧简择失效"是基于框架的推理

### 为什么三轨而不是单一双盘训练——多层机制

身体长期能 sit through 双盘是 **5 层 adaptive 同步发生**，不是单点突破：

```
长期双盘训练
   ↓
Layer 1（关节柔软度）→ 极限位置不再"挤"，机械压迫减少
Layer 2（软组织适应）→ 肌肉对血管压迫减少
Layer 3（血管层）→ 侧支循环发展，缺血代偿
Layer 4（神经感觉）→ 痛觉感受器 desensitization + 中枢处理改变
Layer 5（姿势 efficiency）→ 找到最优 weight distribution / alignment
   ↓
同样姿势的 net 痛感大幅下降 → 可长时双盘
```

**Training 设计**：
- 层 1-2：直接靠**轨道 C**（柔软度训练）
- 层 3-4：靠**轨道 B**（双盘座的渐进 exposure）
- 层 5：在**轨道 B** 中觉察 alignment 微调

三轨协同 = 同时 work 多层，比单纯 sit through 高效。

**修行者 5/12 不放逸学习确定 触发 设计**（详见 [不放逸.md §七](../03-心所法/善心所/不放逸.md)）：

> **家人（特别是孩子）睡下 → 立刻入座 → 最高优先级 → 必须完成再做别的**

**设计 精确机制**（三层协同一次解决——确定时间 + 确定模式 + 提高优先级）：

| 元素 | 精确位置 | 解决的层 |
|---|---|---|
| **"家人睡下"作为外部 触发** | 念心所被外部事件强 调用，不依赖内部"想起来" | 确定时间 |
| **"立刻开始"** | 不给"开始别的事"留窗口——堵失念漂移入口 | 确定模式 |
| **"最高优先级"** | 胜解层落地为具体时段排序 | 提高优先级 |
| **"必须完成再做别的"** | 完成性约束——形成"完成动作即通行证" | 频次保证 |

**设计 的隐含 affordance**（修行者 5/12）：

- **天然无紧急事务**（家人睡下时刻的私人时间）→ "立刻"是绝对的，**无需边界条件 / 特殊 case**
- **天然安静**（外缘条件成熟）→ 入座环境无需额外建设
- **天然每日触发**（家人作息规律）→ 频率结构性保证

**与不放逸建立的精确连接**：

修行者 5/12 不放逸学习 揭示——失败模式是**失念**（不是末那 / 不是第六识决定）：意识层有"要做"的决定，但"投入之前正在进行中的事情后不自觉把修行时间挤占了"。触发 设计 是在 触发 点直接**中断 flow** + **切换念所缘**——精进 + 三善根 + 念在 时间域 持续在场的具体场景实证。

→ 这层 设计 同时是**不放逸建立的具体修行操作核**——不放逸（守护面 / 运作机制层）通过 触发 让精进 + 三善根 + 念在事件流中持续在场。详见 [不放逸.md §七](../03-心所法/善心所/不放逸.md)。

### "完成动作即通行证"原则

起步期**不求质量只求 frequency**：
- 完成动作本身就是当天通行证
- 哪怕 15 分钟纯止也算
- 状态不好不勉强长坐，但**不能不坐**

详细见 [信的修习路径 · 七、退失重建](心所专修/信的修习路径.md#七退失重建针对此修行者的具体设计)。

**重建锚点**：信能现量证据（最有力）+ 冷质地震撼回忆 + 唯识自洽性把握。

| 字段 | 记录内容 | 用途 |
|---|---|---|

```markdown
## YYYY-MM-DD

- 一句总结：
```

### 三个不要
