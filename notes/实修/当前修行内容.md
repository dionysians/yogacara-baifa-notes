## ⚡ 起步胜解（2026-04-26 已补齐——核心前提）

之前迟迟未真正起步的根因不是"缺乏精进"，而是**对实修价值的细颗粒胜解未稳**——具体表现为误以为"实修禅定 = 大块时间 + 双盘起步"，由此设计了"先做胯部训练等准备好"的迂回。

经百法学习中"种子生现行 → 信慧正反馈"的机制理解，胜解已三层补齐：

1. **任何方式的"定"都是有价值的**，都可以立刻开始——不需等双盘 / 大块时间
2. **实修对闻思修过程有正反馈**，可加速佛法学习——修与学不是先后关系，是双轨并行加速
3. **"种子生现行"机制可反向作用于身体**——修行本身在塑身体（异熟果 / 增上果），不需"等身体准备好再修"

**操作含义**：散盘 / 半跏 / 椅子端坐皆可起步，关键是**频率连续**而非姿势完美。

详见相关讨论：[精进.md](../03-心所法/善心所/精进.md) §三、[熏习机制与"用力"观](../03-心所法/善心所/熏习机制与"用力"观.md)

## 二、当前坐中修焦点

### 结构：定 + 信 合修

**单次 30-40 分钟坐中，合修一次**：
- **前段（15-20 min）**：建立定的平台 — 按 [基础篇/禅定实修指南](基础篇/禅定实修指南.md)，呼吸为所缘
- **中段（10-15 min）**：信的所缘安立 — 按 [心所专修/信的修习路径](心所专修/信的修习路径.md)
- **后段（3-5 min）**：回向收摄 — 详见下文"回向"

### 当前善心所焦点

**信**（首个善心所专修）

**入路**：**直接观"心净为性"本身**——不从三面（实/德/能）迂回进入，避开信德路径的情感卡点

### 主所缘：水清珠观

基于《成唯识论》水清珠比喻——珠入浊水则浊物自沉、水自清。

**循环结构**（10-15 min 中段内反复进行）：
1. 建立 image：清净透亮的珠 + 心如浊水
2. 观净化过程：珠入水 → 浊自沉 → 水自清 → 珠安住
3. 安住于"水清、珠安住"的稳定状态（image 可淡化，保留心的清净质地）

**关键原则**：
- 不追求 image 清晰度——模糊若有若无即可
- 真正保持的是**心净的质地**，不是 image 本身
- image 若散，重新提；心净感若散，也重新提

### Verbal backup（应急引子）

若某次坐中 image 提不起来，用下句引子唤起质地后再转回 image：
- A：*"烦恼有生则有灭，心有染则有净"*
- B：*"此心本具清净的可能，当下即可觉照"*
- C：*"烦恼可以止息"*

### 起步期两阶段安排

**阶段 B1（前 3-5 天）：纯止暖身**
- 全程用呼吸所缘，不加水清珠观
- 时长 20-30 min 即可
- 目的：让心重新适应正式坐中，观想能力稍后起

**阶段 B2（第 4-6 天起）：加入水清珠观**
- 阶段一（15-20 min 建平台）+ 阶段二（10-15 min 水清珠观）+ 阶段三（3-5 min 收摄）
- 时长回到 30-40 min
- 切换判据：阶段一能稳定达到"不再需要念拉回"的状态

### 起步期目标（2026-04-26 按精进学习成果细化）

- **连续性 > 时长**：每日不断，盯频率不盯时长——15-20 分钟也算
- **不评判质量**：起步 2-3 周内不评判"今天坐得好不好"，只记录"今天有没有坐"
- **观察任运信号**：第 3-4 周开始留意"自己就坐下去了"现象——这是种子重新越过临界点的标志
- **任运基态**：建立"正式时间中心处于信的分位"的惯性
- **不追求感受**：前两周不要求任何体验

### A 主座当前微调：三段式数息——从"暗静"转向"明静"（2026-05-16 加入）

> **触发背景**：5/15 A 主座反馈中，修行者确认：呼吸变细、心安静后，会逐渐滑入一个舒服、安静、出后清明的状态，但该状态中**清明 / 明记丢失**，无法继续守数息所缘。经讨论，当前不再继续判别其是否为"真定"或"睡眠"，实修处理上直接作为**明分不足 / 细惛沉边界**来对治。

**当前目标**：

> 不是防止心安静，而是让"呼吸变细、心安静"之后，清明不掉线。

也就是从"暗静"转向"明静"：**静而不暗，明而不躁**。

#### 三段式数息

| 阶段 | 操作 | 目标 |
|---|---|---|
| **前段：正常数息** | 从 1 数到 10；丢了回 1；不追求细、不追求稳 | 降低粗散，建立连续性 |
| **中段：安静出现时，加明分锚点** | 一旦呼吸变细、心明显安静，轻轻加入："清楚知道第几息" | 不只知道呼吸，还保持"第几息"的明记结构 |
| **临界段：滑入趋势出现时，微提明分** | 若数字开始模糊、呼吸舒服但第几息不稳、有沉进去的吸引力：微提脊柱、微睁眼、做 1 次略深呼吸，再回到清楚数息 | 防止安静滑成断片，不把舒服暗静当目标 |

**关键规则**：

- 宁可数息清楚而不深，不要安静舒服但断片
- 若能在安静后保持 5-10 息清楚，即为本座有效数据点
- 不连续调整；连续调整易转成掉举
- 不把"是否进入舒服状态"作为目标，只看清明是否持续

**与行舍学习的连接**：

此方案是行舍在当前阶段的操作版——不是主动追求"无功用住"，而是在坐中防止两边偏失：

| 偏失 | 表现 | 当前对治 |
|---|---|---|
| 掉举偏 | 想坐得更好 / 更久 / 更稳，把 sign 当 target | 继续以连续执行 + 清楚数息为 target |
| 惛沉偏 | 安静后明记变弱、数息断片 | 三段式数息，安静时补明分 |

### 用力觉察（关键卫生学原则）

按 [熏习机制与"用力"观](../03-心所法/善心所/熏习机制与"用力"观.md) §四，用力过猛实为掉举伪装的精进，且会反向熏种：

## 三、双盘训练（独立轨道）

> **触发日期**：2026-05-02——主座单盘 30+ 分钟首次出现身体支撑层 forcing 结束后讨论确立
> **partition 原则**：与主座（A 轨道）严格分开——所缘不同、目的不同、不互相干扰

### 三轨 partition

| 轨道 | 内容 | 时段 | 坐姿 | pain 处理 |
|---|---|---|---|---|
| **A 主座（定 / 观息）** | 数息 / 水清珠观 + 信（§二） | 当前睡前节奏，每日 30-40 min | **单 / 散盘**——绝不被打断 | 不 forcing pain |
| **B 双盘训练座** | 安受苦忍 + 身体训练，**pain 本身即所缘** | 独立时段，每周 3-4 次 | 双盘 | sit through，10 min 起渐增 |
| **C 胯 / 膝 / 踝柔软度** | 蹲、坐角式、蝴蝶式、踝绕转 | 每日 10-15 min | — | 因缘工程，非修行 |

### 为什么三轨而不是单一双盘训练——多层机制

身体长期能 sit through 双盘是 **5 层 adaptive 同步发生**，不是单点突破：

```
长期双盘训练
   ↓
Layer 1（关节柔软度）→ 极限位置不再"挤"，机械压迫减少
Layer 2（软组织适应）→ 肌肉对血管压迫减少
Layer 3（血管层）→ 侧支循环发展，缺血代偿
Layer 4（神经感觉）→ 痛觉感受器 desensitization + 中枢处理改变
Layer 5（姿势 efficiency）→ 找到最优 weight distribution / alignment
   ↓
同样姿势的 net 痛感大幅下降 → 可长时双盘
```

**Training design**：
- Layer 1-2：直接靠**轨道 C**（柔软度训练）
- Layer 3-4：靠**轨道 B**（双盘座的渐进 exposure）
- Layer 5：在**轨道 B** 中觉察 alignment 微调

三轨协同 = 同时 work 多层，比单纯 sit through 高效。

### 轨道 B：双盘训练座的内部结构

> **2026-05-02 reframe**（无嗔学习主线 5 后）：之前定位"安受苦忍训练 + 身体训练"——精确化后，因修行者天生具备**安受苦忍 stable base**（详见 [修行者画像 §七](修行者画像.md) 跨世种子证据 + [无嗔.md §十三.4](../03-心所法/善心所/无嗔.md)），轨道 B 的功能层级调整：
>
> - **主功能**：定的训练（在身识苦受场上的定中持守 / 所缘专一）+ 身体训练（Layer 3-5 渐进 exposure）
> - **次要 / 稳态延伸**：安受苦忍——已 stable，无需"建立"，是新所缘上的 extension
>
> 这与**假说 7"激活休眠种子 ≠ 从零累积"**严格同构。
>
> **2026-05-07 进一步精确化**（轻安学习 Q1-Q2 后）：在假说 15 v3（二阶 + 二维 anchor 结构）下，轨道 B 的精确定位 = **重建 phenomenal anchor（轻安 anchor）的 substrate capacity** = **直接对接 path 风险 #1 干慧风险的精确对治通道**。修行者 5/7 自我诊断"心所配置已经能达标，但是禅定功夫不够"——条件 1（心所配置 ready）已稳，条件 2（定 capacity 稳定）是当前唯一缺口；轨道 A + B + C 三轨协同 = 定 capacity 重建主轨。详见 [轻安.md §八 §九](../03-心所法/善心所/轻安.md)。

**所缘**：苦受本身（pain itself）——**不是数息**，与主座所缘完全不同。

**心所配置（reframe 后）**：

| 心所 | 运作 | 重要性 |
|---|---|---|
| **定** | 苦受为所缘，心识专一不被打断 | **主功能** |
| **念** | 清晰跟随痛的现量变化（生起、强度、波动、cycle） | 主功能 |
| **不嗔（无嗔）** | 不烦躁、不抗拒（安受苦忍 stable，自然现行） | 稳态延伸 |
| **不退（精进）** | 不立刻调整姿势、不立刻结束座 | 主功能 |
| **慧（观）** | 观察苦受的无常 / 苦 / 无我 = 修谛察法忍 | 高阶——闻思已通，定中持守 |

**ceiling 判准**：可以 sit through（修忍辱），但**不损根**——结束后能正常走路、不持续数日疼痛。

**起座判准（reframe 后）**：起座**不是失败**——失败是"起座时心带嗔"，不失败是"起座时心带无嗔"（如实评估身体已到极限，不勉强继续以致反向熏种）。

### 5 markers checklist（pain 中堪任是否被拉下的现量判准，2026-05-07 加入）

**核心区分**：苦受现行 ≠ 堪任 lost——两个独立心识事件，可同时（普通人）也可分离（轻安 anchor 在场时）。

| # | 检查项 | 在场表现 | 不在场表现 |
|---|---|---|---|
| 1 | **念力**：能否 hold 原来的所缘（呼吸 / 身体扫描点）| pain 在 + 仍能觉知所缘（pain 是背景 / 一部分）| 注意力被 pain 完全占据，所缘 lost |
| 2 | **观察分离**：是"pain 在升起"还是"我 = pain"| "pain 在升起 / pain 是一个现象" frame 在场 | 全身心 fused 进 pain，无观察距离 |
| 3 | **慧的简择**：起座决定的 anchor | 慧判断"已到 ROM 真实极限 / 继续会损伤"→ 起座 = 善决择 | "受不了了想逃"→ 起座 = 嗔 escape |
| 4 | **嗔的不现行**：对身体 / pain / 训练有没有起厌 | 无嗔（修行者 Layer 1 已 stable，应在场）| 起 frustration / "为什么我这么差" |
| 5 | **起座后即时心识**：调畅恢复速度 | 起座后 1-2 分钟内调畅复位 | 余波留 5+ 分钟，烦躁 / 自责 / 失望 |

**5/7 现量自报（10 min 起座）**：marker 1/2/4/5 全在场；marker 3 不明确（"忍耐极限"无明确慧判定）。"忍耐极限"在唯识层精确位置 = **忍心所（安受苦忍）饱和点**——是健康状态，不是 marker 失败。

### 起座最小慧简择（2026-05-07 加入，hedge marker 3）

虽 marker 3 当前不在场不是失败，但有一层 risk 需 hedge——长期没有慧 anchor 参与起座决定，末那有可能在 ε 时间内悄悄把"忍达极限"前移（escape 漂移）。

**操作建议**（极简，不复杂化训练）：起座决定的瞬间做一句话简择——

> **"这是身体真到限，还是心想停？"**

不需展开分析，一句即可。最小慧介入贴在 marker 3 上，既保留双盘 B 的修忍 / 修定主功能，又防末那做 escape 漂移。与假说 17（sign vs target 区分）在双盘场的精确应用一致。

### 不要走的方向（明确警惕）

- ❌ "为消业故意延长极痛"——把消业做成贪的对象，反向喂我相
- ❌ "我必须忍下去坚持 X 分钟"——用力 framing，可能反向熏种

- ❌ 把"30 分钟一周期"做成 fixed unit——民间传统而非经典，empirically 验证自己

## 五、起步关键 — 解决"实修未内化为日常常态"

修行者自陈核心 gap：**意图与行动的差距**——闻思层面已稳定，生活察觉已稳定，唯独正式坐中修尚未建立日常习惯。

### AI partition 原则（核心机制）

```
今天没坐 → 今天不开始 AI 探索
今天坐了 → 今天可以自由探索 AI
```

把已有的 AI 拉力反向 enforce 实修——不靠"修行紧迫感"（那是浮的），靠真实的 AI 拉力。

### 时间锚点（外部 cue 触发器）—— 2026-05-12 已定案

**修行者 5/12 不放逸学习确定 trigger design**（详见 [不放逸.md §七](../03-心所法/善心所/不放逸.md)）：

> **家人（特别是孩子）睡下 → 立刻入座 → 最高优先级 → 必须完成再做别的**

**design 精确机制**（三层协同一次解决——确定时间 + 确定模式 + 提高优先级）：

| 元素 | 精确位置 | 解决的层 |
|---|---|---|
| **"家人睡下"作为外部 trigger** | 念心所被外部事件强 invoke，不依赖内部"想起来" | 确定时间 |
| **"立刻开始"** | 不给"开始别的事"留窗口——堵失念漂移入口 | 确定模式 |
| **"最高优先级"** | 胜解层落地为具体时段排序 | 提高优先级 |
| **"必须完成再做别的"** | 完成性约束——形成"完成动作即通行证" | 频次保证 |

**design 的隐含 affordance**（修行者 5/12 reveal）：

- **天然无紧急事务**（家人睡下时刻的私人时间）→ "立刻"是绝对的，**无需边界条件 / special case**
- **天然安静**（外缘条件成熟）→ 入座环境无需额外建设
- **天然每日触发**（家人作息规律）→ 频率结构性保证

**与不放逸建立的精确连接**：

修行者 5/12 不放逸学习 reveal——失败模式是**失念**（不是末那 / 不是第六识决定）：意识层有"要做"的决定，但"投入之前正在进行中的事情后不自觉把修行时间挤占了"。trigger design 是在 trigger 点直接**中断 flow** + **切换念所缘**——精进 + 三善根 + 念在 time domain 持续在场的具体场景实证。

→ 这层 design 同时是**不放逸建立的具体修行操作核**——不放逸（守护面 / 运作机制层）通过 trigger 让精进 + 三善根 + 念在事件流中持续在场。详见 [不放逸.md §七](../03-心所法/善心所/不放逸.md)。

### "完成动作即通行证"原则

起步期**不求质量只求 frequency**：
- 完成动作本身就是当天通行证
- 哪怕 15 分钟纯止也算
- 状态不好不勉强长坐，但**不能不坐**

### 退失重建预案

详细见 [信的修习路径 · 七、退失重建](心所专修/信的修习路径.md#七退失重建针对此修行者的具体设计)。

**主要风险**：AI 探索吞噬时间（高）+ 智识贪散乱（中）。
**重建锚点**：信能现量证据（最有力）+ 冷质地震撼回忆 + 唯识自洽性把握。

### 每次实修日志记录说明（2026-05-16 起）

详细记录仍写入 [实修反馈日志](实修反馈日志.md)。起步期不求长篇，优先保持以下字段稳定：

| 字段 | 记录内容 | 用途 |
|---|---|---|
| **基础信息** | 日期 / 时段 / 时长 / 坐姿 / 所缘 | 保留可比较数据 |
| **trigger** | 家人睡下后是否停止手中活；是否直接入座或进入固定序列（如洗澡 → 入座）| 监测不放逸 trigger 是否稳定 |
| **主障碍** | 身受、出汗、散乱、掉举、惛沉 / 明记断片等 | 区分外缘问题、身体问题、心所问题 |
| **三段式数息结果** | 安静后是否出现滑入暗静趋势；是否及时提明分；提明分后能否保持 5-10 息清楚 | 当前 A 主座最核心数据 |
| **sign / target 监测** | 是否出现想坐得更好 / 更久 / 更稳 / 想确认境界的微细追求 | 防细掉举与修行者相 |
| **结束方式** | 自然到时、腿部酸胀到限、惛沉明显而提前结束等 | 判断 A 主座边界是否健康 |
| **一句总结** | 本座最主要的数据点 | 便于后续阶段回看趋势 |

**最简记录模板**：

```markdown
## YYYY-MM-DD
- 时段 / 时长 / 坐姿 / 所缘：
- trigger：
- 主障碍：
- 三段式数息：安静后是否滑入暗静？是否提明分？能否保持 5-10 息清楚？
- sign / target：是否追逐更好 / 更久 / 更稳？
- 结束方式：
- 一句总结：
```

### 三个不要

1. **不立刻提速**——单次表现好不是跳级理由
2. **不固化自我形象**——"我是个能 5 分钟入深定的人"是末那变形
3. **不为现量体验兴奋**——单次出现不能定义稳态，需反复验证
