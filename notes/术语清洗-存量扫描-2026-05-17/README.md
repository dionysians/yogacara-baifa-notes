## 关键工具用法

### 机械清洗脚本

按映射表 v4 对一个或多个 .md 文件做替换。保护 markdown 链接 / 代码块 / F 区允许项。

```bash
# 清洗单个文件
python3 notes/术语清洗-存量扫描-2026-05-17/机械清洗脚本.py path/to/file.md

# 批量清洗
python3 notes/术语清洗-存量扫描-2026-05-17/机械清洗脚本.py file1.md file2.md ...
```

⚠ **脚本会原地修改文件**。建议清洗前 commit 一次或用 `git diff` 检视改动。

### 扫描脚本

重新扫描所有笔记的英文分布:

```bash
python3 notes/术语清洗-存量扫描-2026-05-17/扫描脚本.py
# 输出会落到 /tmp/notes_eng_*.tsv,可再 cp 到这里覆盖
```

### 常用查询命令

```bash
cd notes/术语清洗-存量扫描-2026-05-17

# TOP 30 密度文件(可读格式)
column -ts $'\t' 按文件统计.tsv | head -31

# TOP 50 全局词频
head -51 全局词频.tsv | column -ts $'\t'

# 找映射表 v4 还未覆盖的新词(频次 >= 10)
awk -F'\t' 'NR>1 && $2 >= 10' 全局词频.tsv
```
