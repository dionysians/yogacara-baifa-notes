## 📖 原文与出处

### 《百法明门论》原文

> 第三色法，略有十一种：一眼，二耳，三鼻，四舌，五身，六色，七声，八香，九味，十触，十一法处所摄色。

### 《成唯识论》卷一

> 眼等五根，非显色等能发识故。《瑜伽》等说：净色为根。

### 《瑜伽师地论》卷一

> 眼谓四大种所造，眼识所依净色。

### 《五蕴论》

> 云何眼根？谓以色为境，净色为性。

## 💬 定义

**眼根**是视觉认知的能力基础，是眼识生起的依止（所依）。唯识学中的"眼根"不是指肉眼这个器官（浮尘根），而是指依附于肉眼之上、能够感光辨色的微细净色（胜义根）。

打个比方：肉眼（浮尘根）像摄像头的外壳，而眼根（胜义根）是其中的感光元件——真正让"看"成为可能的，是感光元件而非外壳。外壳坏了不一定看不见（比如眼球表面有伤但视力正常），感光元件坏了才真正看不见（视神经损伤导致失明）。

眼根是四大种所造的"净色"——"净"不是道德上的纯净，而是指质地清净、微细透明，不同于粗显的肉体组织。

---

## 🎯 核心特征

1. **净色为性**: 眼根的体性是"净色"，一种微细、清净、有透明质地的物质，不同于肉眼可见的粗色。类似于现代说的视神经系统的感光功能
2. **以色为境**: 眼根专门缘色境（颜色、形状、明暗等视觉对象），这是它与其他四根的本质区别
3. **四大种所造**: 眼根是地水火风四大种所造的色法，属于物质范畴，但非常微细
4. **眼识所依**: 眼根是眼识生起的增上缘（所依根）。没有眼根，眼识无法生起——如同没有收音天线，就接收不到信号
5. **浮尘根与胜义根之别**:
   - 浮尘根：肉眼（扶尘根），外在可见的器官，起保护和扶助作用
   - 胜义根：真正的眼根，微细净色，不可肉眼见，是发识之本
6. **识所变现**: 在唯识学中，眼根不是心外实有的物质，而是阿赖耶识中眼根种子变现出来的相分

## 🔄 眼根在认知过程中的角色

```
眼根（增上缘）
  +
色境（所缘缘）     →  眼识生起  →  触  →  受、想、思...
  +
作意（等无间缘）
  +
阿赖耶识（因缘/种子）
```

眼根在"四缘生识"中充当**增上缘**——不是直接产生识，而是提供识生起的必要条件。就像电视需要天线（根）接收信号（境），加上电力（种子），才能显现画面（识）。

### 根境相对

| 根 | 境 | 识 |
|---|---|---|
| **眼根** | **色境** | **眼识** |
| 耳根 | 声境 | 耳识 |
| 鼻根 | 香境 | 鼻识 |
| 舌根 | 味境 | 舌识 |
| 身根 | 触境 | 身识 |

五根五境一一对应，形成五组认知通道。眼根只能缘色不能缘声，耳根只能缘声不能缘色——这叫"根境相对"。

## 🌟 日常实例

1. **近视戴眼镜**: 镜片改善的是浮尘根的条件（光线折射），让胜义根（眼的净色功能）能更好地发挥作用。近视是浮尘根有缺陷，但胜义根未必坏
2. **视神经受损导致失明**: 浮尘根（眼球）完好，但胜义根（感光功能）损坏——此时色境再好、再亮，也无法产生眼识。说明发识的关键在胜义根
3. **闭眼仍能"看到"光**: 闭上眼，浮尘根被遮蔽，但强光下仍能感知到光线——说明净色有其独立于外壳的感知能力
4. **梦中"看到"景象**: 梦中无外在色境，也无浮尘根的参与，但意识可以变现类似的视觉体验——这说明"看"的根本在识而非根，根只是增上缘

## 📝 浮尘根与胜义根

这是色法学习中的核心概念：

| | 浮尘根 | 胜义根 |
|---|---|---|
| 别名 | 扶尘根、扶根 | 净色根、正根 |
| 性质 | 粗显、可见 | 微细、净色 |
| 功能 | 保护、扶助 | 发识之本 |
| 比喻 | 灯罩 | 灯芯 |
| 损坏后果 | 不一定失明 | 必定失明 |
| 唯识地位 | 相分中的粗色 | 相分中的净色 |

窥基大师在《百法明门论解》中强调，百法所说的"根"指的是胜义根，因为只有胜义根才是发识的真正依止。

## 🧘 唯识学意义

### "识所变现"的理解

眼根在唯识学中不是独立存在的物质实体，而是：
- 阿赖耶识中"眼根种子"（根身种子）变现的**相分**
- 属于"内变根身"的范畴——第八识变现根身以为自己的"器具"
- 因此眼根本质上是识的一部分，不是心外独立的物质

这与日常的直觉相反：我们通常认为眼睛是客观存在的肉体器官。唯识学说，你所认为的"客观的眼睛"，其实是第八识变现出来的、让你"以为是客观的"相状。

---

## 💡 学习心得

- 理解浮尘根与胜义根的区别，是理解五根的第一步。核心要点：百法说的"根"是胜义根/净色
- 眼根是"增上缘"而非"因缘"——它不生产识，它只提供条件。真正产生识的是阿赖耶识中的种子
- "四大种所造"这个说法值得玩味：即使是净色，也不离地水火风，仍然是色法。但在唯识学中，色法本身也是识所变现
