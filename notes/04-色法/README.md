## 📖 阶段概述

色法是百法五位中的第三位，共11法。"色"在佛学中指物质现象，包括一切有质碍（占有空间、互相障碍）的存在。

百法论中色法列第三位，排在心法、心所法之后，因为唯识学认为色法是"识所变现"——物质世界并非独立于心识之外，而是心识活动的相分（所呈现的相状）。

色法11法分为三组：
1. **五根** — 眼、耳、鼻、舌、身（感官能力）
2. **五境** — 色、声、香、味、触（感官对象）
3. **法处所摄色** — 不属于五根五境，但仍归于色法的特殊类别

理解色法，是深入"万法唯识"核心义理的重要一步。

## 📚 学习内容

### 核心概念 (11个)

#### 五根 (5个)

感官能力，是心识认知外境的增上缘。注意：唯识学中的"根"不是指肉体器官（浮尘根），而是指感官的认知能力（胜义根）。

- [x] [眼根](./五根/眼根.md) - 视觉能力，缘色境
- [x] [耳根](./五根/耳根.md) - 听觉能力，缘声境
- [x] [鼻根](./五根/鼻根.md) - 嗅觉能力，缘香境
- [x] [舌根](./五根/舌根.md) - 味觉能力，缘味境
- [x] [身根](./五根/身根.md) - 触觉能力，缘触境

#### 五境 (5个)

感官所认知的对象（所缘境），是五识生起的所缘缘。

- [x] [色境](./五境/色境.md) - 视觉对象（颜色、形状等）
- [x] [声境](./五境/声境.md) - 听觉对象（声音）
- [x] [香境](./五境/香境.md) - 嗅觉对象（气味）
- [x] [味境](./五境/味境.md) - 味觉对象（味道）
- [x] [触境](./五境/触境.md) - 触觉对象（冷热、软硬等）

#### 法处所摄色 (1法，含5种细分)

不归属于五根五境，但仍属色法范畴的特殊色法。这是色法中最需要深入理解的部分。

- [x] [法处所摄色](./法处所摄色/法处所摄色.md) - 总论
  - 极略色（极微）— 分析物质到极限的概念
  - 极迥色（极远处的色）— 极远或极细难以辨别的色
  - 受所引色（无表色/戒体）— 受戒所引发的色法 ⭐重点
  - 遍计所起色（纯想象的色）— 意识虚构的色
  - 定自在所生色（禅定中变现的色）— 定力所现的色

## 🔑 重点与难点

### 重点
1. **根境相对关系** — 五根与五境如何一一对应，构成认识的基础
2. **受所引色** — 戒体的唯识学解释，连接色法与修行
3. **色法的唯识性质** — 色法是识所变现，非心外实有

### 难点
1. **浮尘根与胜义根的区别** — 肉体器官 vs 认知能力
2. **法处所摄色** — 五种特殊色法的理解
3. **色法"非实有"的理解** — 如何在承认物质现象的同时理解其唯识性
