# 术语映射表 — 英 → 中

> **创建日期**:2026-05-16
> **用途**:CLAUDE.md 全量中文化 + 笔记 retroactive 翻译的 canonical 参考
> **状态**:v4 已确认(E 区 9 项决策 + 增补记录 20 项新词 = 步骤 3 第一波)
>
> **背景**:2026-05-16 讨论中识别到 CLAUDE.md 的中英混杂 register 通过会话 prime 闭环回流到笔记,产生三类风险:① 经典 / 注释 / 假说三层学术诚实标注的视觉边界模糊;② 假说封闭性风险被英文 jargon 放大("看穿者我相"在英文术语下更易包装为"研究术语");③ 时间衰减后可读性下降(中文术语自承重 vs 英文术语需重新 binding)。本表是清洗工程的 canonical 参考。

---

## 使用原则

1. **经典原文段落及紧邻注释** = 英文零区(强制)
2. **A 区骨干名词**采用 canonical 译法,不允许同义切换(避免概念漂移)
3. **B 区过程动词、C 区修饰词**按表翻译,无争议
4. **D 区复合术语**由 A 区导出,保持结构对应
5. **F 区项目**保留不译(版本号、引用编号、纯英文记号等)
6. **表中未列项**:在步骤 3 全笔记扫描中暴露后追加到"增补记录"小节
7. **优先级**:本表 > 个别笔记历史用法。冲突时以本表为准,旧笔记自然 edit 时顺手转化,不强制立即追溯清洗

## E. 已确认的多译法决策(2026-05-16 用户确认)

下表是有多个合理译法的项的最终决策。A/B/C/D 区已同步更新。

| 英文 | 最终决策 | 备选(未采) | 说明 |
|---|---|---|---|
| frame anchor / phenomenal anchor | **见地锚 / 身心锚** | 框架锚 / 现象锚 | 接地气,贴 phenomenal 在笔记中实际指身心系统层的语义 |
| manifest | **显现** | 现行 | 避免与唯识 strict"种子→现行"含义打架 |
| evidence | **证据** | 印证 / 证据双 register | 用户决策:统一"证据",不分 register |
| capacity | **承载力** | 容量 | "基质承载力"读起来对 |
| shift | **跃迁** | 跃迁 / 转变双 register | 用户决策:统一"跃迁",不分 register |
| trigger | **触发**(动) / **触发点**(名) | 触发器 | 标准中文动名分用 |
| frame(裸用) | **见地** | 框架 / 视角 | 与 frame anchor=见地锚 canonical 一致;CLAUDE.md 语料仅 1 处裸用,无 register 分歧 |
| framing | **框定** | 表述 / 表述方式 | 动作感强(取景/框定),与 formulation(静态结果感)严格分用,避免双词撞译 |
| formulation | **表述** | 拟法 / 表述方式 | 静态结果感,几乎全部出现在 `anchor formulation` 固定短语,作为已成型的 anchor 命题形式 |

## F. 保留不译

- **版本号**:v3、v2、v3+(及类似 versioning 标记)

## 边角不易归类的待确认项

- `hijack` / `flow-trap` / `sink` / `gap` / `escape` 等心理学/系统论借词:中文都能译,但隐喻力度可能损失。当前推荐译法已入表,但允许在具体语境保留英文(如"AI 注意力 sink"如保留英文也接受)
- `phenomenology / phenomenology 报告`:推荐"现象学报告",但在严格哲学语境之外可考虑"现量观察报告"等替代
- 经典原文中本来就有的梵文术语注释(如"vitarka / vicāra"):保留梵文,不在本表覆盖范围
