# 世亲菩萨（Vasubandhu）

> **创建日期**: 2025-01-03
> **学习主题**: 世亲菩萨的生平、著作与佛学贡献
> **所属阶段**: 阶段一 - 准备与概览

## 📋 本节学习目标

- 了解世亲菩萨的生平和思想转变

## 一、生平简介

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| **梵文名** | Vasubandhu（婆薮槃豆） |
| **中文名** | 世亲（又译天亲） |
| **时代** | 约公元4-5世纪（320-400年，另有316-396年等说法） |
| **出生地** | 北印度犍陀罗国布路沙布罗城（今巴基斯坦白沙瓦） |
| **家庭** | 婆罗门种姓，三兄弟皆出家 |
| **称号** | "千部论主" |

[^1]

### 1.2 家庭背景

世亲菩萨出身于北印度的婆罗门家庭，家中三兄弟都出家修行：

```
家庭成员

父亲：婆罗门（侨尸迦）
    │
    ├─ 长子：无著（Asaṅga）
    │        母亲：第一妻
    │        → 大乘瑜伽行派创立者
    │
    ├─ 次子：世亲（Vasubandhu）
    │        母亲：第二妻
    │        → "千部论主"，唯识学集大成者
    │
    └─ 三子：比邻持跋婆（Viriñcivatsa）
             母亲：第二妻
             → 小乘学者
```

> **注**：无著与世亲虽是同父异母的兄弟，但感情深厚。无著后来引导世亲从小乘转入大乘，是佛教史上的重要事件。[^2]

### 1.3 生平历程

世亲菩萨的一生可分为三个阶段：

#### 第一阶段：小乘学习时期

| 时期 | 内容 |
|------|------|
| **出家** | 在迦湿弥罗国（今克什米尔）出家 |
| **宗派** | 说一切有部（Sarvāstivāda） |
| **学习** | 精研有部阿毗达磨，深通三藏 |
| **著作** | 《阿毗达磨俱舍论》（小乘最高成就） |

**《俱舍论》的地位**：

- 全称：《阿毗达磨俱舍论》
- 性质：对说一切有部阿毗达磨的精要总结
- 评价：被称为"聪明论"，小乘佛学的最高峰
- 影响：至今仍是学习部派佛教的必读论典[^3]

#### 第二阶段：转入大乘

**转变的背景**：

据传记记载，世亲菩萨曾不信大乘，甚至诽谤大乘佛法。其兄无著菩萨为引导他转入大乘，采取了巧妙的方法：

> **传说**：无著菩萨称病，请世亲来探望。世亲到后，无著为他宣说大乘教法。世亲听后，深感惭愧，认识到自己诽谤大乘的过失，想要割舌谢罪。无著劝他："你曾以舌头诽谤大乘，现在就用这同一条舌头来赞叹大乘、弘扬大乘。"[^4]

**转变后的著作**：

世亲转入大乘后，著述了大量唯识学论典，成为大乘唯识学的集大成者。

#### 第三阶段：大乘弘扬时期

| 活动 | 内容 |
|------|------|
| **著述** | 著作等身，涵盖唯识学各个方面 |
| **弘法** | 在印度各地弘扬大乘教法 |
| **教育** | 培养了众多弟子 |
| **影响** | 对后世唯识学发展产生深远影响 |

### 1.4 "千部论主"的由来

世亲菩萨被称为"千部论主"（或"千部论师"），意指他著作极多：

- **传说**：小乘论典500部，大乘论典500部，合计千部
- **实际**：这是夸张的说法，用以表彰其著述丰富
- **意义**：反映了世亲菩萨在佛教思想史上的重要地位[^5]

## 二、主要著作

### 2.1 著作分类

世亲菩萨的著作可分为两大类：

```
世亲菩萨著作

小乘时期
├─ 《阿毗达磨俱舍论》⭐ 小乘代表作
├─ 《俱舍论本颂》
└─ 其他小乘论著

大乘时期
├─ 唯识学核心论典
│   ├─ 《唯识二十论》⭐ 破斥外难
│   ├─ 《唯识三十颂》⭐ 唯识精华
│   └─ 《百法明门论》⭐ 唯识入门（本次学习对象）
│
├─ 经论注释
│   ├─ 《十地经论》
│   ├─ 《无量寿经优婆提舍愿生偈》（往生论）
│   ├─ 《金刚般若波罗蜜经论》
│   ├─ 《妙法莲华经论》
│   └─ 《涅槃经论》等
│
└─ 其他论著
    ├─ 《大乘五蕴论》
    ├─ 《大乘成业论》
    └─ 其他
```

### 2.2 小乘时期代表作

#### 《阿毗达磨俱舍论》

| 项目 | 内容 |
|------|------|
| **全称** | 阿毗达磨俱舍论（Abhidharmakośa-bhāṣya） |
| **卷数** | 30卷（玄奘译） |
| **性质** | 对说一切有部阿毗达磨的总结和批判 |
| **内容** | 包括界品、根品、世间品、业品、随眠品、贤圣品、智品、定品、破我品 |
| **地位** | 小乘佛学的巅峰之作，"聪明论" |

**特点**：

1. **系统性**：完整总结有部的法相分析
2. **批判性**：站在经量部立场批评有部
3. **分析性**：对75法的详细分析[^6]

> **与百法的关系**：《俱舍论》分析75法（有为法72 + 无为法3），《百法明门论》分析百法（有为法94 + 无为法6）。百法论是大乘唯识学的法相分析，与《俱舍论》的小乘法相有继承也有发展。

### 2.3 大乘唯识核心论典

#### 《唯识二十论》

| 项目 | 内容 |
|------|------|
| **梵文** | Viṃśatikā-vijñaptimātratā-siddhi |
| **卷数** | 1卷 |
| **译者** | 玄奘法师 |
| **性质** | 论证性论典 |
| **目的** | 破斥外道、小乘对"唯识无境"的疑难 |

**核心内容**：

通过二十个偈颂（加长行解释），回答对唯识学的七大疑难：

1. 如果唯有识无外境，为什么有处所的决定？
2. 如果唯有识无外境，为什么有时间的决定？
3. 如果唯有识无外境，为什么有相续的决定？
4. 如果唯有识无外境，为什么能起作用？
5. 如何解释梦与觉的区别？
6. 如何解释地狱的情况？
7. 如何解释他心的问题？

**论证特点**：

- 以梦境为喻：梦中有境，觉后知其为识所变
- 以共业为据：众生共业所感，故有共同经验
- 严密的逻辑论证，体现因明学素养[^7]

#### 《唯识三十颂》

| 项目 | 内容 |
|------|------|
| **梵文** | Triṃśikā-vijñaptimātratā |
| **卷数** | 仅30颂（偈颂体） |
| **译者** | 玄奘法师 |
| **性质** | 唯识学的纲要性著作 |
| **地位** | 唯识学最核心的论典之一 |

**结构**：

```
《唯识三十颂》结构

第1-24颂：唯识相（识的相状）
    ├─ 第1-2颂：总说"假说我法，有种种相"
    ├─ 第3-4颂：阿赖耶识（第八识）
    ├─ 第5-7颂：末那识（第七识）
    ├─ 第8-16颂：前六识
    └─ 第17-24颂：心所、三性、唯识义

第25-29颂：唯识性（识的真实性）
    └─ 三自性、三无性、真如

第30颂：唯识位（修证阶位）
    └─ 资粮位、加行位、见道位、修道位、究竟位
```

**重要性**：

- 世亲菩萨圆寂前的最后著作，未及作注
- 后来十大论师分别为之作注
- 玄奘法师将十家注释糅合为《成唯识论》[^8]

#### 《大乘百法明门论》

| 项目 | 内容 |
|------|------|
| **梵文** | Mahāyāna-śatadharmā-prakāśamukha-śāstra |
| **卷数** | 1卷 |
| **字数** | 约600字 |
| **译者** | 玄奘法师 |
| **性质** | 唯识入门论典 |
| **地位** | 学习唯识学的第一步 |

（详见下文"《百法明门论》的写作背景"）

### 2.4 经论注释

世亲菩萨还为多部大乘经典作注：

| 注释 | 所注经典 | 说明 |
|------|----------|------|
| **《十地经论》** | 《华严经·十地品》 | 详说菩萨十地，是"地论宗"的依据 |
| **《无量寿经优婆提舍愿生偈》** | 《无量寿经》 | 又名"往生论"，净土宗依据之一 |
| **《金刚般若波罗蜜经论》** | 《金刚经》 | 对《金刚经》的注释 |
| **《妙法莲华经论》** | 《法华经》 | 对《法华经》的注释 |

[^9]

## 三、在佛教史上的地位

### 3.1 思想史地位

世亲菩萨在佛教思想史上具有独特的地位：

#### 贯通小乘与大乘

```
世亲菩萨的思想贡献

小乘方面
└─ 《俱舍论》：小乘阿毗达磨的最高成就
    └─ 总结75法的法相分析
    └─ 为大乘法相学奠定基础

大乘方面
└─ 唯识学的系统化
    ├─ 将100法的分类精确化
    ├─ 以简洁偈颂概括复杂义理
    └─ 提供唯识学的入门途径
```

#### 唯识学的集大成者

- **继承**：继承无著菩萨的唯识学
- **发展**：使唯识学更加系统化、精确化
- **简化**：将复杂的义理以偈颂形式呈现
- **传承**：培养弟子，使唯识学传承下去

### 3.2 对后世的影响

#### 对印度佛教的影响

- 十大论师皆为其《唯识三十颂》作注
- 护法、安慧等形成不同学派
- 那烂陀寺成为唯识学研究中心[^10]

#### 对中国佛教的影响

| 方面 | 影响 |
|------|------|
| **地论宗** | 基于《十地经论》形成 |
| **摄论宗** | 间接影响（真谛译无著《摄大乘论》） |
| **唯识宗** | 玄奘法师专程求取其论典，建立唯识宗 |
| **净土宗** | 《往生论》成为净土宗依据之一 |

#### 对其他地区的影响

- **西藏**：唯识学是藏传佛教五大论之一
- **朝鲜、日本**：唯识学随中国传入

### 3.3 "两个世亲"问题

学术界曾有"两个世亲"的争论：

| 观点 | 内容 |
|------|------|
| **两个世亲说** | 认为小乘著作（《俱舍论》）和大乘著作（唯识论典）是两个不同的人 |
| **一个世亲说** | 传统观点，认为同一人前后转变 |

**当前主流观点**：

多数学者认为是同一人，理由包括：
1. 传记资料的记载一致
2. 思想的连贯性
3. 学术方法的一致性[^11]

## 四、《百法明门论》的写作背景

### 4.1 论典的性质

| 项目 | 内容 |
|------|------|
| **全称** | 《大乘百法明门论》 |
| **依据** | 《瑜伽师地论·本地分》 |
| **性质** | 唯识学入门论典 |
| **篇幅** | 仅约600字 |
| **结构** | 将一切法归纳为五位百法 |

### 4.2 写作目的

世亲菩萨撰写《百法明门论》的目的：

#### 1. 提供唯识入门

《瑜伽师地论》有100卷，内容庞大，初学者难以入门。《百法明门论》将其精华提炼为600字，便于初学。

```
从繁到简

《瑜伽师地论》
    │ 100卷，内容庞大
    ↓ 提炼精华
《百法明门论》
    │ 约600字，提纲挈领
    ↓ 作用
唯识入门的阶梯
```

#### 2. 建立法相框架

通过五位百法的分类，建立一切法的系统框架：

| 位 | 法数 | 内容 |
|------|------|------|
| 心法 | 8 | 八识心王 |
| 心所法 | 51 | 心理活动 |
| 色法 | 11 | 物质现象 |
| 心不相应行法 | 24 | 非心非色 |
| 无为法 | 6 | 真理 |
| **合计** | **100** | |

#### 3. 指归"无我"

论典的最终目的是指向"一切法无我"：

> **论文**："如世尊言：一切法无我。何等一切法？云何为无我？一切法者，略有五种……"[^12]

- 通过详细分析一切法的构成
- 看清没有独立、恒常的"我"
- 最终证悟"人无我"、"法无我"

### 4.3 读者对象

《百法明门论》的预期读者：

1. **初学唯识者**：作为入门读物
2. **已有基础者**：作为复习纲要
3. **修行者**：作为观察心识的指南

### 4.4 论典特点

| 特点 | 说明 |
|------|------|
| **简洁** | 仅600字，便于记诵 |
| **系统** | 五位分类，条理分明 |
| **完整** | 包含唯识学基本框架 |
| **指归明确** | 以"无我"为宗旨 |
| **便于实修** | 可用于观察心念 |

### 4.5 与其他论典的关系

```
《百法明门论》的定位

《瑜伽师地论》（100卷）
    │ 母论，根本论典
    ↓
《百法明门论》（600字）
    │ 入门论典，法相分类
    │
《唯识三十颂》（30颂）
    │ 纲要论典，唯识原理
    ↓
《成唯识论》（10卷）
    │ 集大成论典
    ↓
学通唯识
```

## 五、总结

### 5.1 世亲菩萨的主要贡献

1. **小乘集大成**：《俱舍论》是小乘阿毗达磨的最高成就
2. **唯识学发展**：将唯识学系统化、精确化
3. **入门论典**：《百法明门论》为后人提供学习入门
4. **经论注释**：为多部大乘经典作注，便于理解

### 5.2 学习《百法明门论》的意义

| 意义 | 说明 |
|------|------|
| **入门阶梯** | 学习唯识学的第一步 |
| **框架建立** | 掌握一切法的分类体系 |
| **修行指南** | 学会观察自己的心念 |
| **无我证悟** | 最终目标是证悟"无我" |

### 5.3 关键记忆点

- **世亲菩萨**：约公元4-5世纪，"千部论主"
- **从小乘到大乘**：在无著菩萨引导下转入大乘
- **核心著作**：《俱舍论》《唯识二十论》《唯识三十颂》《百法明门论》
- **百法论**：唯识入门，约600字，五位百法，以"无我"为宗
