# 唯识学的历史发展

> **创建日期**: 2025-01-03
> **学习主题**: 唯识学从印度到中国的发展历程
> **所属阶段**: 阶段一 - 准备与概览

## 📋 本节学习目标

- 了解唯识学在印度的起源和发展
- 掌握印度唯识学的主要发展阶段和代表人物

## 一、唯识学的起源

### 1.1 唯识学的名称

**唯识学**有多个名称，各有侧重：

| 名称 | 梵文 | 含义 | 侧重点 |
|------|------|------|--------|
| **唯识学** | Vijñaptimātratā | 万法唯识 | 核心义理 |
| **瑜伽行派** | Yogācāra | 修行瑜伽的行者 | 修行实践 |
| **法相宗** | Dharmalakṣaṇa | 诸法的相状 | 法相分析 |
| **有宗** | 对应"空宗" | 相对于中观空宗 | 学派对比 |

> **说明**：这些名称指的是同一学派的不同方面。"唯识"强调义理，"瑜伽行"强调实践，"法相"强调分析方法。[^1]

### 1.2 唯识学的思想渊源

唯识学不是凭空产生的，而是有其深厚的思想渊源：

#### 经典依据

1. **般若经典**
   - 虽然般若经典以说"空"为主，但也包含心识的论述
   - 如《般若经》中说"心外无境"的思想[^2]

2. **《解深密经》**
   - 唯识学最直接的经典依据
   - 明确提出阿赖耶识、三自性等核心概念[^3]

3. **《楞伽经》**
   - 详说八识、五法、三自性、二无我
   - 融合唯识与如来藏思想[^4]

4. **《华严经·十地品》**
   - "三界唯心，万法唯识"的思想
   - 世亲菩萨曾专门作《十地经论》阐释[^5]

#### 部派佛教的贡献

唯识学也吸收了部派佛教的心理分析成果：

| 部派 | 贡献 | 与唯识的关系 |
|------|------|--------------|
| **说一切有部** | 详细的法相分析（75法） | 百法的基础 |
| **经量部** | 种子说的萌芽 | 阿赖耶识种子论 |
| **大众部** | 根本识的思想 | 第八识的先驱 |

> **关键理解**：唯识学是对早期佛教心理分析的继承和发展，将分析推进到更深更广的层次。

## 二、印度唯识学的发展

### 2.1 发展阶段概览

```
印度唯识学发展

第一期：奠基期（约3-4世纪）
    └─ 弥勒菩萨、无著菩萨
        ↓
第二期：发展期（约4-5世纪）
    └─ 世亲菩萨
        ↓
第三期：分化期（约5-7世纪）
    └─ 护法、安慧、难陀、净月等十大论师
        ↓
后期：传播期（7世纪以后）
    └─ 戒贤、智光等 → 传入中国、西藏
```

### 2.2 第一期：奠基期

#### 弥勒菩萨（Maitreya）

| 项目 | 内容 |
|------|------|
| **身份** | 未来佛，现居兜率天 |
| **时代** | 传说约公元3-4世纪显现 |
| **地位** | 唯识学的开创者 |
| **传承** | 无著菩萨亲承其教 |

**主要著作**（"弥勒五论"）：

1. **《瑜伽师地论》**：100卷，唯识根本论典
2. **《大乘庄严经论》**：菩萨道的庄严
3. **《辨中边论》**：辨析中道与边见
4. **《分别瑜伽论》**：修行瑜伽的论述（未传入中国）
5. **《金刚般若论》**：《金刚经》的注释[^6]

> **传说**：无著菩萨经过多年精进修行，上升兜率天亲见弥勒菩萨，听闻唯识教法，后返回人间弘扬。这一传说反映了唯识学起源的神圣性。[^7]

#### 无著菩萨（Asaṅga）

| 项目 | 内容 |
|------|------|
| **时代** | 约公元4世纪（310-390年） |
| **出生地** | 北印度犍陀罗国（今巴基斯坦白沙瓦一带） |
| **身份** | 世亲菩萨之兄 |
| **地位** | 唯识学的实际奠基人 |

**生平要点**：

1. 初学小乘有部，后转入大乘
2. 上兜率天亲承弥勒教法
3. 返回人间，建立唯识学体系
4. 后来引导其弟世亲转入大乘[^8]

**主要著作**：

| 著作 | 性质 | 重要性 |
|------|------|--------|
| **《摄大乘论》** | 唯识学系统纲要 | ⭐⭐⭐⭐⭐ |
| **《显扬圣教论》** | 瑜伽论纲要 | ⭐⭐⭐⭐ |
| **《大乘阿毗达磨集论》** | 阿毗达磨的大乘化 | ⭐⭐⭐⭐ |
| **《六门教授习定论》** | 修定方法 | ⭐⭐⭐ |

**《摄大乘论》的重要性**：

这是无著菩萨最重要的著作，以"十殊胜"的框架系统阐述唯识学：

```
《摄大乘论》十殊胜

1. 所知依殊胜 → 阿赖耶识
2. 所知相殊胜 → 三自性
3. 入所知相殊胜 → 唯识观修行
4. 彼入因果殊胜 → 六波罗蜜
5. 彼因果修差别殊胜 → 菩萨十地
6. 增上戒学殊胜 → 戒学
7. 增上心学殊胜 → 定学
8. 增上慧学殊胜 → 慧学
9. 彼果断殊胜 → 无住涅槃
10. 彼果智殊胜 → 三身四智
```

[^9]

### 2.3 第二期：发展期

#### 世亲菩萨（Vasubandhu）

> **说明**：世亲菩萨的详细内容将在下一节《世亲菩萨》中专门阐述。

| 项目 | 内容 |
|------|------|
| **时代** | 约公元4-5世纪（320-400年或更晚） |
| **身份** | 无著菩萨之弟 |
| **地位** | "千部论主"，唯识学的集大成者 |
| **转变** | 从小乘说一切有部转入大乘唯识 |

**主要贡献**：

1. 将唯识学系统化、精确化
2. 著作涵盖唯识学各个方面
3. 以简洁的偈颂形式概括复杂义理
4. 培养了众多弟子，传承唯识学

**核心著作**：

- **《唯识二十论》**：破斥外道、小乘对唯识的疑难
- **《唯识三十颂》**：唯识学的精华总结
- **《百法明门论》**：唯识入门论典（本次学习对象）[^10]

### 2.4 第三期：分化期

世亲菩萨之后，唯识学在印度继续发展，出现了不同的解释系统。

#### 十大论师

为解释世亲菩萨的《唯识三十颂》，后世有十位论师分别作注，形成不同的学派：

| 论师 | 时代（约） | 学派特点 | 代表观点 |
|------|------------|----------|----------|
| **护法**（Dharmapāla） | 6世纪 | 正统派 | 四分说（相分、见分、自证分、证自证分） |
| **安慧**（Sthiramati） | 6世纪 | 无相派 | 一分说（唯有自证分） |
| **难陀**（Nanda） | 5-6世纪 | 有相派 | 二分说（见分、相分） |
| **净月**（Śuddhacandra） | 6世纪 | 折中派 | 二分说 |
| **火辨**（Citrabhānu） | 6世纪 | — | — |
| **德慧**（Guṇamati） | 5-6世纪 | — | — |
| **亲胜**（Bandhuśrī） | 6世纪 | 折中派 | 三分说 |
| **欢喜**（Nandā） | 6世纪 | — | — |
| **智月**（Jñānacandra） | 6世纪 | — | — |
| **胜友**（Viśeṣamitra） | 6世纪 | — | — |

[^11]

#### 主要分歧：识的"分"的问题

十大论师的主要分歧在于：心识在认识活动中有几个"分"（层面）？

```
识的"分"的不同观点

一分说（安慧）：
    只有自证分，见分、相分都是遍计所执

二分说（难陀、净月）：
    见分 ← 能认识的作用
    相分 ← 所认识的影像

三分说（亲胜）：
    见分、相分 + 自证分（证知见分的作用）

四分说（护法）：
    见分、相分、自证分 + 证自证分
    （自证分与证自证分互证）
```

> **玄奘法师的取舍**：玄奘法师在翻译《成唯识论》时，以护法的四分说为主，同时参考其他论师的观点。这是中国唯识宗的主流见解。[^12]

### 2.5 后期：传播期

#### 那烂陀寺

唯识学的传承中心是印度的**那烂陀寺**（Nālandā）：

| 项目 | 内容 |
|------|------|
| **位置** | 中印度摩揭陀国（今印度比哈尔邦） |
| **性质** | 世界上最早的大学之一 |
| **规模** | 鼎盛时期有上万名僧人 |
| **重要性** | 唯识学的研究和传播中心 |
| **玄奘所学** | 玄奘法师曾在此学习五年 |

#### 重要传承者

| 论师 | 时代 | 贡献 |
|------|------|------|
| **戒贤**（Śīlabhadra） | 约529-645年 | 那烂陀寺主持，护法弟子，玄奘法师的老师 |
| **智光**（Jñānaprabha） | 7世纪 | 中观与唯识融合的尝试 |

[^13]

## 三、唯识学传入中国

### 3.1 早期传译

唯识学传入中国经历了几个阶段：

#### 第一阶段：零星传译（4-5世纪）

| 译者 | 时代 | 译作 | 说明 |
|------|------|------|------|
| 鸠摩罗什 | 后秦（4-5世纪） | 部分唯识相关经论 | 以中观为主，兼及唯识 |
| 求那跋陀罗 | 刘宋（5世纪） | 《楞伽经》等 | 唯识经典的早期翻译 |
| 菩提流支 | 北魏（6世纪） | 《十地经论》等 | 世亲著作的翻译 |
| 勒那摩提 | 北魏（6世纪） | 《十地经论》等 | 与菩提流支合译 |

#### 地论宗的形成

基于《十地经论》的翻译，在北方形成了"地论宗"：

- **南道派**：以慧光为代表
- **北道派**：以道宠为代表

两派对阿赖耶识的性质有不同理解，这一争论后来被玄奘法师的唯识学所统一。[^14]

#### 第二阶段：真谛的翻译（6世纪）

| 项目 | 内容 |
|------|------|
| **译者** | 真谛（Paramārtha，499-569年） |
| **来自** | 西印度优禅尼国 |
| **主要译作** | 《摄大乘论》《俱舍论》《唯识论》等 |
| **影响** | 形成"摄论宗" |

真谛的翻译使中国佛教界第一次系统接触唯识学，但由于翻译的局限和理解的偏差，仍有不完整之处。[^15]

### 3.2 玄奘法师的贡献

> **说明**：玄奘法师的详细内容将在《玄奘法师》一节专门阐述。

玄奘法师（602-664年）的西行求法和翻译事业，标志着中国唯识学的正式建立：

**历史意义**：

1. **亲赴印度**：历时17年，遍访印度各地
2. **师承正统**：在那烂陀寺从戒贤学习唯识
3. **系统翻译**：翻译唯识经论75部、1335卷
4. **糅译创新**：将十大论师的注释糅合为《成唯识论》[^16]

### 3.3 中国唯识宗的建立

#### 法相唯识宗

玄奘法师及其弟子窥基建立了中国的**法相唯识宗**（简称"唯识宗"或"法相宗"）：

| 项目 | 内容 |
|------|------|
| **开创者** | 玄奘法师 |
| **实际建立者** | 窥基大师（632-682年） |
| **祖庭** | 大慈恩寺（今西安） |
| **别称** | 慈恩宗 |
| **核心论典** | 《成唯识论》《百法明门论》等 |

#### 窥基大师

| 项目 | 内容 |
|------|------|
| **生卒** | 632-682年 |
| **身份** | 玄奘法师的主要弟子 |
| **称号** | "百本疏主"（著作等身） |
| **贡献** | 系统注疏唯识论典，建立唯识宗学说体系 |

**主要著作**：

- 《成唯识论述记》：《成唯识论》的权威注释
- 《大乘百法明门论疏》：《百法明门论》的详细解说
- 《瑜伽师地论略纂》：《瑜伽师地论》的摘要
- 《因明入正理论疏》：因明学的重要注释[^17]

#### 唯识宗的传承

```
唯识宗传承

玄奘法师（开创）
    │
    ├─ 窥基大师（实际建立者）
    │       │
    │       └─ 慧沼（675-744年）
    │              │
    │              └─ 智周（668-723年）
    │
    ├─ 普光
    │
    └─ 圆测（新罗，613-696年）
            │
            └─ 传入新罗（韩国）
```

[^18]

### 3.4 唯识宗在中国的兴衰

#### 唐代的鼎盛

唐代是唯识宗最兴盛的时期：

- 得到皇室支持（玄奘法师深受唐太宗、高宗器重）
- 大慈恩寺成为译经和学术中心
- 培养了大量唯识学人才
- 影响传播到朝鲜、日本[^19]

#### 唐末以后的衰落

会昌法难（845年）后，唯识宗逐渐衰落：

**衰落原因**：

1. **义理繁复**：唯识学义理精深，学习门槛高
2. **缺乏实修**：偏重学术研究，与禅宗、净土宗的简易相比不够"接地气"
3. **典籍散失**：多次法难导致典籍流失
4. **传承断裂**：缺乏杰出传承者

#### 近代的复兴

清末民初，唯识学迎来复兴：

| 人物 | 贡献 |
|------|------|
| **杨仁山**（1837-1911年） | 从日本找回唯识典籍，创办金陵刻经处 |
| **欧阳竟无**（1871-1943年） | 创办支那内学院，培养唯识学人才 |
| **太虚大师**（1890-1947年） | 弘扬唯识学，推动佛教现代化 |
| **吕澂**（1896-1989年） | 唯识学研究的重要学者 |

[^20]

## 四、唯识学的当代意义

### 4.1 与现代心理学的对话

唯识学对心识的详细分析，与现代心理学有许多对话空间：

| 唯识概念 | 可能的现代对应 |
|----------|----------------|
| 八识 | 意识的不同层次 |
| 心所法 | 心理活动的分类 |
| 种子 | 潜意识、记忆 |
| 熏习 | 习惯的形成 |
| 末那识 | 自我意识的根源 |

> **注意**：这只是粗略的比较，唯识学有其独特的修行目的和理论框架，不能简单等同于现代心理学。

### 4.2 修行的意义

唯识学不只是学术理论，更是修行的指导：

1. **认识心识的运作**：了解烦恼是如何产生的
2. **转识成智**：将染污的心识转化为清净的智慧
3. **达到无我**：通过分析，证悟"人无我"、"法无我"

## 五、总结

### 5.1 时间线

```
唯识学发展时间线

约3-4世纪
    └─ 弥勒菩萨说法（传说）
    └─ 无著菩萨奠基

约4-5世纪
    └─ 世亲菩萨集大成

5-7世纪
    └─ 十大论师分化发展

6世纪
    └─ 真谛译经（中国）

7世纪
    └─ 玄奘法师西行、译经
    └─ 窥基建立唯识宗

8-9世纪
    └─ 会昌法难，唯识宗衰落

19-20世纪
    └─ 唯识学复兴
```

### 5.2 关键理解

1. **唯识学是大乘佛教的重要学派**：与中观学派并称大乘两大思想体系

2. **唯识学有系统的传承**：弥勒→无著→世亲→十大论师→戒贤→玄奘→窥基

3. **唯识学既是学术也是修行**：不只是分析心识，更是为了"转识成智"

4. **中国唯识宗的建立归功于玄奘法师**：他的翻译使中国得到完整、正确的唯识学

5. **百法明门论是唯识入门**：学习唯识学，从《百法明门论》开始

[^9]: 《摄大乘论》的十殊胜框架，是无著菩萨对唯识学的系统阐述。见《大正藏》第31册。

[^10]: 世亲菩萨著作的记载，见《婆薮槃豆法师传》及各论典的序跋。

[^11]: 十大论师的名单，见《成唯识论》的传统记载。各论师的具体观点见窥基《成唯识论述记》。

[^12]: 护法四分说成为中国唯识宗主流，见《成唯识论》及窥基注疏。

[^13]: 那烂陀寺的情况，见玄奘《大唐西域记》卷九。戒贤为玄奘法师之师，见《大慈恩寺三藏法师传》。

[^14]: 地论宗的形成，见《续高僧传》等。南北二道的分歧主要在阿赖耶识是否为清净心。

[^15]: 真谛的翻译，见《续高僧传》卷一。摄论宗的形成源于其《摄大乘论》的翻译。

[^16]: 玄奘法师的贡献，见《大慈恩寺三藏法师传》。《成唯识论》糅译十家之说，以护法为主。

[^17]: 窥基大师的著作和贡献，见《宋高僧传》卷四。其著作多收于《大正藏》第43、44册。

[^18]: 唯识宗的传承，见《宋高僧传》等。圆测是新罗人，其学说传入朝鲜。

[^19]: 唐代唯识宗的兴盛，见《大慈恩寺三藏法师传》及相关史料。

[^20]: 近代唯识学复兴，见欧阳竟无《支那内学院院训释》、太虚大师《法相唯识学》等著作。
