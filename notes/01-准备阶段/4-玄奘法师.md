## 一、生平简介

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| **俗名** | 陈祎（yī） |
| **法名** | 玄奘 |
| **尊称** | 三藏法师、唐三藏 |
| **生卒** | 602-664年（唐代） |
| **籍贯** | 洛州缑氏县（今河南偃师） |
| **家世** | 书香门第，祖上世代为官 |

[^1]

### 1.2 早年经历

```
玄奘法师早年历程

602年
└─ 出生于洛州缑氏县

约611年（10岁左右）
└─ 随兄长长捷法师入洛阳净土寺

612年（13岁）
└─ 破格剃度出家（时规定需年满27岁）
└─ 开始学习佛法

618-622年
└─ 随兄在四川学习《涅槃经》《摄大乘论》等

622-627年
└─ 游历各地，遍访名师
└─ 发现各家说法不一，疑难重重
└─ 决心西行求法
```

### 1.3 学佛的疑难与西行动机

玄奘法师在国内学习佛法时，发现几个重要问题：

| 问题 | 表现 | 解决方法 |
|------|------|----------|
| **译本不完整** | 许多经论只有部分翻译 | 需求取完整原典 |
| **翻译有歧义** | 不同译者译法不同，义理混乱 | 需从梵文原典确定 |
| **宗派争议** | 地论宗、摄论宗对阿赖耶识理解不同 | 需求取权威解释 |
| **缺乏师承** | 无法确定哪种理解正确 | 需亲赴印度从正统学习 |

> **玄奘法师的决心**："既遍谒众师，备餐其说，详考其理，各擅宗途，验之圣典，亦隐显有异，莫知适从。乃誓游西方，以问所惑。"[^2]

## 二、西行求法

### 2.1 行程概览

| 项目 | 内容 |
|------|------|
| **出发** | 贞观三年（629年）从长安出发 |
| **历时** | 约17年（627/629-645年） |
| **行程** | 约5万里 |
| **途经国家** | 110多国 |
| **返回** | 贞观十九年（645年）回到长安 |

### 2.2 西行路线

```
西行路线概要

长安 → 凉州（甘肃武威）→ 瓜州（甘肃敦煌附近）
    │
    ↓ 偷渡玉门关（未获朝廷批准）
    │
莫贺延碛（大戈壁）→ 高昌国（今新疆吐鲁番）
    │
    ↓ 高昌王供养，结为兄弟
    │
屈支国（龟兹）→ 凌山（天山）→ 碎叶城（今吉尔吉斯斯坦）
    │
    ↓ 穿越中亚
    │
迦毕试国（今阿富汗）→ 那揭罗曷国 → 犍陀罗国
    │
    ↓ 进入印度
    │
中印度：那烂陀寺（学习5年）→ 遍游印度各地
    │
    ↓ 学成返回
    │
原路返回 → 于阗（今新疆和田）→ 长安（645年）
```

[^3]

### 2.3 重要事件

#### 偷渡玉门关

- 当时朝廷禁止私自出境
- 玄奘法师未获批准，偷渡出关
- 途中几乎被边关守将射杀
- 凭借坚定信念，最终脱险[^4]

#### 莫贺延碛的考验

- 800里大戈壁，无水无人烟
- 不慎打翻水囊，几乎渴死
- 走了四天五夜
- 靠老马识途找到水源[^5]

#### 高昌王的供养

| 项目 | 内容 |
|------|------|
| **高昌王** | 麴文泰 |
| **供养** | 黄金百两、银钱三万、绫帛法服 |
| **护送** | 派人护送，并致书沿途各国 |
| **约定** | 归国时在高昌讲法三年 |
| **结局** | 玄奘归国时高昌已被唐朝攻灭，麴文泰已死 |

[^6]

### 2.4 那烂陀寺的学习

#### 那烂陀寺简介

| 项目 | 内容 |
|------|------|
| **位置** | 中印度摩揭陀国（今印度比哈尔邦） |
| **性质** | 世界上最早的大学之一 |
| **规模** | 鼎盛时期有僧众上万 |
| **地位** | 印度佛教的最高学府 |

#### 从戒贤学习

| 项目 | 内容 |
|------|------|
| **老师** | 戒贤（Śīlabhadra），当时已106岁 |
| **身份** | 那烂陀寺主持，护法的弟子 |
| **学习时间** | 5年 |
| **学习内容** | 《瑜伽师地论》等唯识论典 |

**戒贤与玄奘的因缘**：

> **传说**：戒贤曾患重病，痛苦欲绝，想要绝食而死。梦中文殊菩萨告诉他："三年后，大唐国有一沙门来此学习，你要等待他，传授唯识正法。"戒贤因此坚持下来，三年后玄奘法师果然到达。[^7]

#### 学习成就

玄奘法师在那烂陀寺的成就：

1. **精通唯识**：系统学习唯识学，成为顶尖学者
2. **遍学诸宗**：学习因明、声明、中观等
3. **受到尊崇**：被尊为"大乘天"、"解脱天"
4. **参加辩论**：在曲女城法会上立论18天，无人能破

#### 曲女城法会

| 项目 | 内容 |
|------|------|
| **时间** | 约642年 |
| **地点** | 曲女城（戒日王首都） |
| **召集者** | 戒日王 |
| **参加者** | 印度18国国王、各派学者数千人 |
| **玄奘所立论题** | "真唯识量"（唯识的核心论证） |
| **结果** | 18天无人能破，被尊为"大乘天" |

[^8]

## 三、翻译事业

### 3.1 翻译概况

玄奘法师归国后，主要从事译经工作：

| 项目 | 内容 |
|------|------|
| **翻译时间** | 645-664年（约19年） |
| **翻译地点** | 长安大慈恩寺、玉华宫等 |
| **翻译经论** | 75部、1335卷 |
| **翻译团队** | 组织大规模译场，分工明确 |

### 3.2 翻译特点

玄奘法师的翻译被称为"新译"，与之前的"旧译"有明显区别：

| 方面 | 旧译 | 新译（玄奘） |
|------|------|--------------|
| **准确性** | 有时意译过度 | 力求忠实原文 |
| **术语** | 译法不统一 | 统一术语翻译 |
| **完整性** | 多有节略 | 完整翻译 |
| **音译标准** | 各有不同 | 建立规范 |

#### "五不翻"原则

玄奘法师确立了"五不翻"的翻译原则，这五种情况保留梵文音译：

| 类型 | 含义 | 例子 |
|------|------|------|
| **秘密故不翻** | 咒语等秘密语 | 陀罗尼（dhāraṇī） |
| **多义故不翻** | 一词有多义 | 薄伽梵（bhagavat，含六义） |
| **此方无故不翻** | 中国没有的事物 | 阎浮树（jambu） |
| **顺古故不翻** | 已有约定俗成的音译 | 阿耨多罗三藐三菩提 |
| **生善故不翻** | 音译更能生起恭敬 | 般若（prajñā） |

[^9]

### 3.4 糅译《成唯识论》

玄奘法师最重要的翻译创新是糅译《成唯识论》：

**背景**：

世亲菩萨《唯识三十颂》后，十大论师分别作注。各家观点不同，难以统一学习。

**糅译过程**：

```
《唯识三十颂》（世亲）
    │
    ├─ 护法注
    ├─ 安慧注
    ├─ 难陀注
    ├─ 净月注
    ├─ 火辨注
    ├─ 德慧注
    ├─ 亲胜注
    ├─ 欢喜注
    ├─ 智月注
    └─ 胜友注
        │
        ↓ 玄奘法师糅译
        │
《成唯识论》（10卷）
    └─ 以护法为主，参考其他九家
```

**弟子窥基的请求**：

最初玄奘法师打算将十家分别翻译。弟子窥基请求将诸家糅合为一论，以便学习。玄奘法师采纳了这一建议。[^10]

## 四、对唯识学传入中国的贡献

### 4.1 传入正统唯识学

玄奘法师之前，中国虽有唯识学的翻译，但存在问题：

| 问题 | 表现 |
|------|------|
| **不完整** | 许多论典未翻译 |
| **不准确** | 真谛译本有偏差 |
| **有争议** | 地论宗、摄论宗观点不同 |
| **无定论** | 无法确定哪种理解正确 |

**玄奘法师的贡献**：

1. **亲承正统**：从那烂陀寺戒贤（护法弟子）学习
2. **完整翻译**：翻译唯识学的核心经论
3. **统一观点**：以护法系统为主
4. **建立宗派**：与弟子窥基建立法相唯识宗

### 4.2 法相唯识宗的建立

| 项目 | 内容 |
|------|------|
| **创立者** | 玄奘法师（实际建立者：窥基大师） |
| **祖庭** | 大慈恩寺（今西安） |
| **别称** | 慈恩宗、法相宗 |
| **核心典籍** | 《成唯识论》《百法明门论》等 |
| **传承** | 玄奘→窥基→慧沼→智周 |

### 4.3 培养人才

玄奘法师培养了众多弟子：

| 弟子 | 贡献 |
|------|------|
| **窥基**（632-682年） | 建立唯识宗学说体系，"百本疏主" |
| **圆测**（613-696年） | 新罗人，唯识学传入朝鲜 |
| **普光** | 著《俱舍论记》 |
| **法宝** | 著《俱舍论疏》 |

### 4.4 历史意义

玄奘法师对中国佛教的贡献：

1. **完善经藏**：翻译75部1335卷经论
2. **建立宗派**：法相唯识宗成为八宗之一
3. **文化交流**：促进中印文化交流
4. **翻译典范**：确立翻译原则和方法
5. **精神典范**：求法精神成为后世楷模

## 五、翻译《百法明门论》的意义

### 5.1 翻译背景

| 项目 | 内容 |
|------|------|
| **翻译时间** | 约645年后 |
| **翻译地点** | 长安 |
| **篇幅** | 仅1卷，约600字 |
| **重要性** | 唯识学入门必读 |

### 5.2 《百法明门论》在唯识宗的地位

```
唯识宗的核心典籍

《成唯识论》
    │ 唯识学的集大成
    │ 详说唯识原理
    │
《百法明门论》
    │ 唯识学的入门
    │ 法相分类纲要
    │
《唯识三十颂》
    │ 唯识学的精华
    │
合称"唯识三论"或"法相三论"
```

### 5.3 翻译的特点

玄奘法师翻译《百法明门论》的特点：

| 特点 | 说明 |
|------|------|
| **忠实原文** | 保持世亲菩萨的原意 |
| **术语统一** | 与其他唯识论典术语一致 |
| **简洁流畅** | 便于读诵和记忆 |
| **配套注释** | 弟子窥基作《百法明门论疏》 |

### 5.4 对后世的影响

1. **入门必读**：成为学习唯识学的第一本书
2. **背诵纲要**：因篇幅短小，可以背诵
3. **实修指南**：用于观察心念的分类
4. **持续流传**：至今仍是唯识学入门首选

## 六、玄奘法师的精神遗产

### 6.1 求法精神

玄奘法师的求法精神成为后世楷模：

| 精神 | 表现 |
|------|------|
| **坚定信念** | 虽未获批准，仍坚持西行 |
| **不畏艰险** | 穿越沙漠、雪山，九死一生 |
| **精进学习** | 在那烂陀寺刻苦学习5年 |
| **谦虚求教** | 遍访印度各地高僧 |
| **回报众生** | 归国后专心译经，不慕荣利 |

### 6.2 著作

除翻译外，玄奘法师还有著作：

| 著作 | 内容 |
|------|------|
| **《大唐西域记》** | 记录西行见闻，12卷 |
| 其他 | 多为译经序跋 |

**《大唐西域记》的价值**：

- 记录了7世纪印度、中亚的地理、历史、宗教
- 成为研究古代中亚和印度的重要史料
- 对考古学有重大贡献（如发现那烂陀寺遗址）[^11]

### 6.3 社会影响

玄奘法师的故事在中国家喻户晓：

| 影响 | 表现 |
|------|------|
| **文学作品** | 《西游记》以其为原型 |
| **民间传说** | "唐僧取经"的故事广为流传 |
| **精神象征** | 代表求知、坚韧、无畏的精神 |
| **文化交流** | 成为中印文化交流的象征 |
