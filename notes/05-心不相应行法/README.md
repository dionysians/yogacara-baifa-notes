## 📖 阶段概述

心不相应行法，是百法中的第四位。所谓"心不相应"，指这些法既不是心法（八识），也不是心所法（51种心理活动），更不是色法（物质现象），而是依据心、心所、色三者的分位差别而**假立**的法。

"行"指有为法中的行蕴，这24法属于行蕴所摄但不与心法相应，故名"心不相应行法"。

这些法涵盖了生命、语言、时间、空间、关系等抽象概念，虽然日常生活中我们习以为常，但唯识学揭示它们的本质——都是"分位假立"，并非独立实有。
