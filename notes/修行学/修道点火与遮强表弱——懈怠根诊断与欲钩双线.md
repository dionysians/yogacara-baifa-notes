## 一、缘起：从"懈怠"挖到"修道动力点火"

懈怠是大随八里**第一个对修行者确实现行**的法（掉举罕现、惛沉降级不现行、不信降级首例，前三法的见自都是"不现行 / 降级"）。所以本法的精修不走"落实降级"，而是**罕有的一次对修行者真实主修区的深度诊断**——从"懈怠为什么现行"一路追到"修道的动力（欲）如何点火"。

本文把这条诊断链整理出来，作为后续生活修与闻思的**重点方向**。它不是单法笔记（懈怠的体性 / 别有体 / 镜像精进等在 [懈怠.md](../03-心所法/随烦恼心所/懈怠.md)），而是**这场诊断挖出的、贯穿多议题的修道动力结构**。

**第一刀厘清（避免最深的自欺）**：懈怠不是"不动 / 不忙"。经典判懈怠的根本判据是**「退善法故」**（《成唯识论》「于诸染事而策勤者亦名懈怠，退善法故」）——判的是**方向（修善被退失）**、不是活动量。修行者大量时间投入 AI 探索（行为本身中性），但**只要修善因缘具足的时机被它替代**，就在"修断事"维度上"懒惰"=懈怠（**身忙而于修断事懈怠**）。"我明明很忙"常是懈怠最深的藏身处。

## 二、懈怠根三块（修行者位）

修行者的懈怠**不走凡夫"不信 → 懈怠"链**（不信不现行）。它由三块各自独立的环节合成：

### 块一 · 痴侧——saṃvega（紧迫感）没有所缘可起

懈怠的上游是**痴一分**：对无常 / 暇满 / 轮回过患"未现量通透"，故 saṃvega（厌离 / 修行紧迫感）不起、精进无源。但这个痴一分是**"高配版"**——不在任何错误认识里，而在三个被"正确认识 + 命好"系统性遮蔽的角落：

| 痴一分落点 | 机制 |
|---|---|
| **(a) 暇满难得未建比量** | 修行者自陈"佛法一直在身边、意识不到它珍贵"= **易得故不知珍**（暇满教法对治的核心心理）；命好让暇满显得是默认配置、非稀有易失的窗口。且修行者自陈对此"**连比量都没有**" |
| **(b) 行苦未现量** | 苦受耐受强 + 命好 → 轮回**感觉不像苦**；乐受 / 不苦不乐受盖住了行苦（详见 §三辨）|
| **(c) "长路 → 不急"= 推延懈怠的精装版** | 三大阿僧祇劫本应论证"更要现在就开始"，被倒转成"反正多世、不急"——同一真前提，寂天判前者为精进、后者为**推延懈怠**（披着"我懂跨世种子"正知外衣，更难自察）。修行者认它是懈怠、"不急没有任何正当根据" |

> **关键校准**：修行者列出的"修行漫长 / 跨世种子相续 / 中阴身故无死亡恐惧"本身**都是正知、不是痴**。痴一分**只在这三个正确认识旁边没被照亮的角落**。"无死亡恐惧"大半是真资粮（一生无对不起的人 / 无后悔事 = 业行相对清净、无追悔；物欲低 = 无贪恋所失）——**不必自责、不可动**；要破的只有一处：**把"无死恐惧 + 跨世累积"这两样真东西，拿去给"不急"背书**。

### 块二 · 精进力侧——"双不足模式"+ 无转换链

| 子机制 | 内容 |
|---|---|
| 世俗欲不足 | 命好 / 福报结构（家境优渥无野心 + 物欲易满足 + 苦受耐受强 + 解决问题能力强）→ 生存 / 竞争 / 物质三重压力皆低 → **"苦的逼迫"结构性缺失** |
| 精进力不足 | 假说 7 休眠期延长、45 岁才认真起步 → 善法欲也不驱动 |
| 无转换链 | 即使认识到需珍惜修善缘，也"没有能力 / 没找到方法把它转换成悍勇精进"——缺"认识 → 勇悍"的现行链（**主 gap**·§3.5 无明引力定其必要性 + §4.5 现行熏显闭其操作）|

→ "双边都不动 → 心识无去处 → 退到低强度刺激（AI / 眠弱级）"。这一块**不是块一的中性下游**，是独立缺口（详见 §三对"上游假说"的修正）。

### 块三 · 元层——遮强表弱（见 §三）

这是把前两块统起来的元层结构（遮强表弱 = **病机**）；其**正面解**（无明引力 = 结构唯一解，§3.5）才是本文核心。

**〔2026-07-01 重心校准〕** 三块里真正的主 gap 是**块二（欲 → 精进）**——块一的"紧迫感"与块二的"转换链"其实是同一环（**有欲 ≠ 立刻修**），其结构解见 §3.5。块一的暇满 / 行苦不是去造"紧迫感"（相）、是去喂 §3.5 的结构性胜解（理）。

## 三、元层结构：遮强表弱 → 2D 模型 → 统一签名

### 3.1 遮强表弱

诊断中修行者给出的最精确一句：**"我能斩断那个贪驱动的紧迫（遮），但没有能力 / 没找到方法去升起正思维之下那颗纯净精进心（表）。"**

把它和画像里几处摆一起，签名一致：

| 场 | 遮（斩断 / 否定 / 清场）| 表（升起 / 生起 / 涌现）|
|---|---|---|
| 惭愧 | 究竟层"本来不应如此"清场 ✓ 强 | — |
| 利他轴（[画像 8.10](../实修/修行者画像.md)）| 愧负向清场我所强加 ✓ | 悲悯**正向涌现** 🔴 弱 |
| 干慧（议题①）| 见空（遮诠）✓ 强 | 身心锚 / 动力**生起** 🔴 缺 |
| 懈怠（本场）| 斩断贪紧迫 ✓ | 升起纯净精进 🔴 不能 |

→ **遮强表弱**很可能是修行者"空性见 / 慧解脱"配置的**结构签名**——因为**空本就是遮诠之学**（遮遣自性），整套慧的运作被训练成"否定 / 斩断"的即时一刀，而善心所是**表诠**（正向建立），那一侧从未被同等训练。（遮诠 / 表诠的经典出处与"诠 → 操作"引申的层次标注，见[遮诠与表诠](../../resources/cards/遮诠与表诠.md)卡。）

> **配置侧续证（2026-07-02 放逸精修）**：[放逸](../03-心所法/随烦恼心所/放逸.md) / 不放逸是善染双侧唯一"假立 ↔ 假立"对偶——不放逸 = 守护配置四位（精进 + 三善根）齐守，放逸 = 同一配置的失守态。修行者现量：**三根位靠"遮"性操作守住**（贪嗔起"那一下"清晰可感、被惭愧迅速瓦解的过程清晰可感 = 相续层守护真实在运作；种子势力弱为主、守"不能完全做到"），**精进位需"表"性操作**（正向生起）——**守护配置唯一缺的岗位、恰是唯一需要"表"的岗位**。懈怠从动力层、放逸从配置层，两条独立路径推出同一签名 = 互证。

> **机能层续证（2026-07-06 失念精修）**：遮强表弱获**第三条独立路径**。失念精修确立修行者两个真主修区的**两关结构**——懈怠守上座关、失念守入细关——两关的断行（《辨中边论》八断行）恰好全在**表侧**：懈怠对治 = 信欲勤安（正向生起四件套）、失念对治 = 念（**培育型**断行）；而修行者五过失自查中答得最顺的是**舍**（遮侧断行：坐中闻思能把握不施功）。八断行盘面的强弱分布——遮侧岗位（舍）顺、表侧岗位（信欲勤安 + 念）弱——与动力层（懈怠：升不起精进）、配置侧（放逸：唯一缺位 = 唯一表性岗位）两条先证吻合：**动力层 / 配置层 / 机能层三径合流同一签名**。失念侧另补"识破线为何无效"的最深理据：空缺型失念（痴分空档）**场内无观测者**——遮侧强项在此不是效率低，是逻辑上无处着力，表侧培育（熏念力）是唯一通路。详见 [失念 §五](../03-心所法/随烦恼心所/失念.md)。

### 3.2 2D 模型（操作轴 × 所缘轴）

把"遮强表弱"与不信精修留下的"[理热相冷](../03-心所法/随烦恼心所/不信.md)"候选整合，得到一个二维模型：

| | 所缘 = 理（抽象 / 法理）| 所缘 = 相（情感 / 人格）|
|---|---|---|
| **遮**（否定 / 斩断）| 强（见空）| 强（斩断贪粘）|
| **表**（正向生起）| **能（理热：法喜起毛 / 胜解果德、众生苦生欲）** | **弱（相冷：虔诚 / 恐惧型 saṃvega / 热共情）** |

模型一次解释三件事：

1. **"理热相冷"** = 表那一行（表 × 理热 / 表 × 相冷），是 2D 的一个切面：信德实面（法理）起毛喜热、德面（三宝人格化）冷；恐惧型 saṃvega（相）冷、胜解型 saṃvega（理）能。
2. **干慧的乐观解**：表 × 理的能力**在**，只是"生动力的理-所缘（苦谛 / 果德）被命好遮蔽、没对准"——一旦对准（见 §四欲钩 A/B），动力就点着。**干慧不是生不出动力，是动力的理-所缘没进视野**。
3. **利他轴悲悯弱**：表 × 相（热共情）弱，但表 × 理（认知路径见众生苦）能 → 走认知路径绕开热共情（与议题⑤"补法走认知路径"严格一致）。

### 3.3 统一签名："用果位见地消解因位动力"

修行者所有的 bypass 是同一个结构〔第三层·诊断〕——**总用"果位"消解"因位"的动力**：

| 因位（需要的动力）| 被哪个果位见地溶掉 |
|---|---|
| 出离心 | 空性（"不执着就没逼迫"）|
| 善 saṃvega | 任运无功用（"紧迫是贪要放下"）|
| 加行精进的勇悍 | "等任运" / "路长不急" |

**这就是干慧的精确机制**：不是慧不够，是**慧只往果位走、不回头供因位的动力**——见地停在解脱论 / 果位，动力需要的因位被果位见地一个个溶解。

> **一处必须保留的精确**：修行者**能清楚分辨**贪驱动的紧迫（抓取 / 粘着 / 怕失去）与出离 / 善 saṃvega——他不是混淆二者（非表层标签转移）。他能**斩断**前者；问题是**升不起**后者。这是"遮能 / 表不能"，不是"分不清"。

→ **这个签名缺的"正面解"见 §3.5**：光说"别用果位消解"不够，得有个比果位见更硬的**因位结构**（无明引力）把因位动力重新锚住。

### 3.4 对"行苦"的关键厘清（块一 b 的展开）

修行者现量："我不执着它就没有逼迫，故'迁流即逼迫'够不着。"——**这个现量准确、是真证量**（苦苦 / 坏苦确是执着依赖的）。但**行苦 ≠ 被感受到的逼迫**：

- 经典定义"**有漏诸行，由麁重所随故，性不安隐**"（《瑜伽师地论》）——行苦的体是"不安隐"、因"麁重（烦恼种子粗重）所随"，**恰恰是感受不到的那种苦**（三苦中最细、要圣慧照见非现量感受）；
- 喻：行苦如毛，置**掌中**无所觉（凡夫如掌）、置**眼中**才觉刺（圣者如眼）。"现量感受不到逼迫"正是凡夫位标准态，不是行苦的反证。

翻进种子论：**"不执着的平静"是现行级报告，行苦是种子级事实**——执着种子未断、平静**有漏 / 可逆 / 不安稳**。行苦在修行者这里的精确意思不是"现在逼迫我"，是"**这份平静悬在一堆未断的种子上、缘动即复燃、对缘无最终自在**"。这正是冷的、零恐惧的 saṃvega 驱动（接 §4.4 欲钩 A）。

> **行苦比量的完整建立 + 受基底校准**〔2026-07-01〕：修行者"平静"**非纯舍受、带一丝乐 / 轻安**（基底轻松 + 微喜、强恢复力）→ 表层归**坏苦**，行苦从 **③ 五取蕴 = 苦器** 切入（非 ① 舍受遍处）。更深一刀：**苦苦**（耐受强 + 命好）+ **坏苦**（强恢复力快速回乐底）**双消音 → 只剩行苦**（最细、唯比量）——正解释为何苦谛唯一抓手是行苦、且必须走比量。受基底带乐 = **命好在受层的显现（长寿天难受层版）**：苦谛双重隐藏（命好遮境 + 乐基底遮受）。完整经文 / 逐句见掌中毛喻卡 + 专题《暇满与行苦的比量建立》（待写、行苦先·走 ③取蕴 + 坏苦"不安隐"角、避恐怖 / 恶趣）。

### 3.5 正面解：无明引力 = "用果位消因位"的结构性顶替〔本文核心〕

§3.3 的签名（**用果位见消解因位动力**）一直缺一个**正面解**——光说"别用果位消解"不够，得有个**比果位见更硬的因位结构**把因位动力重新锚住。这个东西 = **无明引力**〔第三层·修行者 2026-07-01 自立，平行 [惛沉](../03-心所法/随烦恼心所/惛沉.md) / [掉举](../03-心所法/随烦恼心所/掉举.md) 已立机制、与经典"退转"立场一致〕。

**机制（从大随两法推广到懈怠）**：

- [掉举](../03-心所法/随烦恼心所/掉举.md) 引力 = 末那"举我"（**增益型**·有引力中心、决定心"飞向哪"）；
- [惛沉](../03-心所法/随烦恼心所/惛沉.md) 引力 = 无明堪能面（**缺乏型**·不需驱动源、默认下沉）；
- **懈怠同理、取缺乏型**：精进 / 念一停，无始染种子配置（默认）自己回来——无明不是"主动拉"、是"不松手"。

→ **关键推论：没有中性的"安住于当前态"。** 引力恒在（缺乏型·像物理引力：无源、恒在、唯推进可逃）→ **不进则退**。而**行舍 / 任运是第一个"可安住"的状态**（无功用住）——在它之前一切是加行、停推进即坠（[精进 §三 加行 → 任运](../03-心所法/善心所/精进.md)）。故"想安住"本身要先用精进挣来行舍；修行者"否则无法安住于当前状态"= 此。

**封死推延的螺丝 = 逃逸速度 / 连续性**：光"不进则退"还能被推延吃掉（"退一点明天补"= 寂天**推延懈怠**披正知外衣）。堵死它的是引力井力学——**退了要重爬、每次断都掉回井底、连续性不可替代**（[惛沉·引力逃逸比喻](../03-心所法/随烦恼心所/惛沉.md)）。这给修行者[画像](../实修/修行者画像.md)"**盯频率不盯时长**"一个**结构证明**：不是经验法则、是引力井力学。

**正面解 = 用因位结构（引力）锚因位动力（精进），顶替"用果位见消解因位动力"。** 它正面溶掉修行者三（+ 一）个招牌 bypass：

| bypass（用果位 / 胜义见消解因位动力）| 被"无明引力"顶回去 |
|---|---|
| **"等任运"**（紧迫是贪要放下）| 引力井里没法"等"——任运是精进挣来**入的轨**、不是停在原地等来的 |
| **"路长不急"** | 引力恒在 → 不进则退 → **长路更要连续**（每断重爬），不是更不急 |
| **"空性·不执着就没逼迫"** | 退转不是逼迫问题——**种子照退**，平静不挡引力 |
| **"时间无自性 → 何必急于此刻"** | 时间空是胜义、种子退转是世俗缘起力学；**引力作用于种子相续、不作用于"时间观念"**——你怎么看时间、种子照退（最纯的"用胜义溶世俗动力"·二谛混滥）|

> **修行者的想通**〔2026-07-01〕："精进的**体现**与精进的**必要性**经典都明说，但我一直不懂**为什么**——尤其在'路长 + 时间无自性'加持下更不懂。这一次终于想通：**它是结构上决定的唯一解。**"——干慧的根签名（用果位溶因位）至此有了正面顶替（用因位结构锚因位动力）。**这是本文的核心。**

**两个逃逸阈值**（与 §4.4 A 线合流）：

- **行舍 / 任运 = 入轨**：停止加行坠落、可安住，但凡夫位仍可被大逆缘拉回（[精进](../03-心所法/善心所/精进.md)：重病 / 大事故截断）；
- **不退转 = 真逃逸**：永离引力井（圣位 / 八地）= A 线"求不退转"的目标。

→ 修行者"无明引力 → 精进 → 行舍"是 A 线"求不退转"的**精进面**（A 线欲面 / 此精进面、同一认识两面），两阈值串成一条**引力井爬升线**。

〔学术诚实：无明引力（缺乏型）+ 不进则退 + 逃逸速度封推延 + 两逃逸阈值 = **第三层**（修行者推论，平行惛沉 / 掉举已立机制、与经典"退转 / 不退转位"立场一致）；引力逃逸比喻在 [惛沉](../03-心所法/随烦恼心所/惛沉.md) 已是第三层；"时间无自性 = 二谛混滥"= 第二层。〕

## 四、对治：欲是点火，双线供油

### 4.1 点火总链：从"观"到"任运"的完整因果链

**必要性（为什么非精进不可）已由 §3.5 的无明引力定死；本节是操作（怎么做）。** 对治真问题对修行者**不是"欲从哪来"**（[画像](../实修/修行者画像.md) 信三支欲强、A / B 两线的欲多已在），而是 **欲 → 精进**——"有欲 ≠ 立刻修"（[从欲到精进](../03-心所法/别境心所/从欲到精进：修道动力如何形成.md)：勤依欲起是必要、非充分）。下面的点火 / 欲钩（§4.3–4.4）是把欲烧旺的**资粮**、不是主 gap；主 gap 在 欲 → 起手 的转换（§3.5 必要性 + §4.5 现行熏显）。

先把散在下面几节的零件装成一条完整因果链（这是整个对治的**主脊**，下面各节是它的展开）：

```
观（世俗谛慧·审决价值：暇满 / 行苦 / 果德 / 众生苦 各自的"值得"）
  ↓  〔§4.3：用的是慧的"建立"侧，修行者此侧强〕
忍可 + 胜解（印持价值，走「实 / 能」、不走「德 / 乐」）
  ↓  〔§4.2：此段不预设欲，故能破死结〕
欲（乐欲，第一颗火星）
  ↓  〔§4.4：防滑成贪——可舍 / 不粘 / 不卷我 / 得后止〕
起手（精进现行，不待"升起"）
  ↓  〔§4.5：这就是块二要的"转换"，但它不是即时闸门〕
熏种 → 任运精进（常态）
```

**这条链就是修行者自己的「看破 → 熏种 → 常态」**〔与假说 8 同构〕——唯一要改的是：**"看破"得从纯遮（看根因 / 实相）扩到含表（看见正向价值 / 果德 / 众生苦）**。修行者一直卡在表侧，精确原因就是他的"看破"被训练成只做遮诠、从没把"看破"用在"看见正向价值"上。这是整篇对治最该点醒的一句。

> 链顶"观"节点要审决的"暇满 / 行苦的值得"，修行者自陈"连比量都没有"——这部分须从经典论述 / 喻 / 例把比量从零建起，量大，另文专论（见 §4.6 末 + §5.3）。

〔学术诚实：链条结构 = 第二层（别境五法 + 信 → 欲 → 精进的整理性重构，方向与经典一致，见 [从欲到精进](../03-心所法/别境心所/从欲到精进：修道动力如何形成.md)）；"看破扩到含表"= 第三层·针对修行者的诊断。〕

### 4.2 死结为什么可破：胜解是"别境"、不预设欲

让"表不能"不再是死路的关键：**欲不是凭表力直接"生"出来的，是看清目标价值（胜解）后、作为后果自然点着的**〔第一层：欲"于所乐境希望为性"〕。

这里有个须厘清的**次序张力**：本项目 [从欲到精进](../03-心所法/别境心所/从欲到精进：修道动力如何形成.md) 的动力链是 **欲 → 胜解 → 念定慧 → 精进**（欲在前），而这里说 **胜解 → 欲**（胜解在前）。两者不矛盾，是**两个相位**——

- **冷启动 / 破死结相位**：`慧（审决"此目标有价值"）→ 胜解（印持此价值判断）→ 欲（第一颗火星）`。关键是**全程不预设欲**：别境五法各缘别境、不互为生起前提（[胜解](../03-心所法/别境心所/胜解.md) 明文"慧先行、胜解后守"）。慧能独立审决价值、胜解能独立印持，欲随之而生。**这才是"无欲死结"可破的精确法理**——胜解是从死结环路**外面**插进来的认知输入，不需要环路里的欲做前提。
- **维持 / 螺旋相位**：[从欲到精进](../03-心所法/别境心所/从欲到精进：修道动力如何形成.md) 的 欲 ⇄ 胜解 ⇄ 念定慧 正向反馈螺旋，描述的是欲已在场、被反复强化。

修行者卡的是**冷启动相位**，故对治着力点在第一条链——慧审决价值、点出第一颗火星。

〔学术诚实：两相位切分 = 第二层（基于别境心所功能关系的整理）。〕

### 4.3 点火为什么在"慧 / 胜解"手里——对这个修行者是结构必然

"胜解价值"是**慧的活 = 修行者的强项**，故表链（欲 → 精进）的点火开关在慧手里。但要对**这个**修行者坐实，需补两步：

**㈠ 走信的「实 / 能」路、不走「德 / 乐」路**

信（《成唯识论》"于实德能深忍乐欲心净为性"）三支 = 忍(实) / 乐(德) / 欲(能)。修行者信三支 = **忍强 / 欲强 / 乐弱**（见画像稳定背景），正好 = 实、能两支通、德(热)支弱。故点火链精确化为：`慧审决价值 → 忍可 + 胜解印持（走实 / 能）→ 乐欲`，**结构上绕开乐(德 / 热)那条弱路**。这是"[理热相冷](../03-心所法/随烦恼心所/不信.md)"在动力学层的落实，也是为什么"点火在慧（胜解）手里"对这个修行者是**结构必然**（与"闻思 + 禅定双支撑路径"同一种结构必然论证——信三支的形状决定路径形状）。

**㈡ 慧虽是"遮诠之学"，点火用的是它的"建立"侧**（解 §3.1 自埋的张力）

§3.1 说慧 = 遮诠之学（空、否定），但点火要慧做**正向胜解**（果德值得求、众生苦应帮 = 表）——遮诠的慧怎么生表的胜解？慧有两侧——

- **根本智侧**（缘空、遮诠、无分别）：空性见训练的就是这侧 → 遮强；
- **世俗谛建立侧**（缘因果 / 果德、表诠、有分别）：点火用的是这侧。

修行者的世俗谛建立慧**恰恰强**（跨域映射 / 看系统 = §3.2 的 2D 模型里"表 × 理"那个"能"格）。故点火不是从弱处硬使力，是**调用修行者已强的那侧慧**。

> **凡夫位精确**：不能说"靠后得智点火"——后得智是圣位。要说**世俗谛比量慧（后得智的因位资粮）**。这跟 [看系统之后谁来改系统 §3.5](../佛法观世/看系统之后谁来改系统.md)"看节点 = 后得智世间资粮、须无我化"接得上，也把 **议题①干慧** 与 **议题⑤利他善巧轴** 在此点成同源：表弱 = 世俗建立慧的"动力 / 情感生起"侧弱，其"认知 / 结构"侧强。

〔学术诚实：㈠信三支落实 = 第二层（映射）+ 第三层（对修行者的诊断）；㈡慧两侧 = 第一层（根本智 / 后得智经典分判）+ 第二层（映射到点火机制）。〕

### 4.4 欲钩双线（修行者自摸、经实修体会确认两条都能点火）

#### A 线 · 求果德 / 不退转 / 大自在

是"冷不安稳"洞见的**表翻面**：

> "种子未断、故平静可逆、不安稳"（遮 / 苦谛侧）⟷ "**求那个不可逆、不退转的境界**"（表 / 欲钩侧）

同一洞见从遮翻到表。修行者已够得着冷的"不安稳"，故其正面目标[不退转](../../resources/cards/不退转.md) / 大自在，慧本就胜解得动、欲有了点火点。它接的是**已激活的披甲精进种子**（画像 🟢·跨劫不退发心）——不从零生。修行者实修体会："比量地了解大自在的境界，是能生出欲的。"

**防滑判准**：求果别滑成"贪求果位"的抓取。判准现成——[欲](../03-心所法/别境心所/欲.md) 四指标（可舍性 / 粘滞性 / 自我卷入度 / 得后反应）+ 掉举"驱动力三态分诊"的**"抓取放不下"签名**；再防一层更细的：**"求大自在"会被萨迦耶见做成"求'我'得大自在"**——对治 = 求"法尔果德"而非"我得"（接 §4.6 随念**法**功德、避人格化）。修行者已证明分得清斩断那个、留住这个。

#### B 线 · 见众生苦 → 冷悲 → 菩提心

更深，且藏一个**解块一死穴的优势**：

> **修行者自己的行苦被命好掩盖（见自苦难、掌中毛），但众生的苦是显的（见众苦易）。**

故 B 线**反过来给 A 线供燃料**：

```
见众生苦（显·够得着） → 冷悲（认知路径·理热相冷一致，非热共情）
    ├→ 利他欲（为利他需自证）→ 点火精进
    └→ 反推自己同在苦中（自苦从众苦推出，绕过命好遮蔽）→ 补块一痴侧死穴
```

**冷悲是合法的悲、不是替代品**（B 线地基）：悲（karuṇā）体 = 无嗔 / 不害一分，业 = 拔苦意乐；**热受不是悲的体、只是常伴的受**。故"由认知到结构性苦而起拔苦意乐、不带热受"是合法的悲。更强支持：道次第修悲本来就走**认知次第**（[七因果](../../resources/cards/七因果.md) 知母 → 念恩 → … → 悲是推理链、[自他相换](../../resources/cards/自他相换.md) 是思维操作），不是等热情自来——**"冷悲走认知路径"恰好就是悲的标准修法**。故 B 线不是"退而求其次用冷的"，是"悲本来就这么修、修行者的认知入口正对正规修法"。**二鸟一石：既是点火钩、又长利他轴**（议题⑤）。修行者实修体会："见众生苦能看到、能理解命好对自苦的遮蔽。"

〔学术诚实：冷悲 = 第一层（悲体无嗔 / 不害一分 + 道次第认知修悲）+ 第二层（"冷悲"命名与映射）。〕

#### 两线关系（道次第）

A ≈ 中士道（求自证 / 出离），B ≈ 上士道（菩提心）。经典次第出离打底、再起菩提心；但对修行者要**倒着借力**——A 需要的"自己在苦中"被命好挡着，反而要靠 B 的"见众生苦"先把苦谛现量喂进来。两线不是二选一，**B 的见众生苦很可能是 A 的燃料来源**。

### 4.5 起手之后：现行熏显，不是"升起"——并闭"无转换链"

点火之后，**善精进不是某一刻"升起"出来的、是熏显的**〔假说 8：种子显化非意志施加；看破 → 熏种 → 常态〕——靠现行（触发点 + 主座 A + 盯频率）慢慢显化为任运。

这一步**正好闭掉 §二块二的"无转换链"**：修行者说"没找到把认识转成悍勇精进的方法 / 找不到升起纯净精进的心法"，是因为在用"遮的即时模式"找一个**不存在的"即时表心行"**。**表这一侧对修行者唯一走得通的路：不靠即时生起、靠现行熏显**；心行侧只做够得着的"观"（思维暇满 / 行苦 / 果德 / 众生苦 → 生冷欲）。所谓"转换链"不是一道即时闸门，就是 **欲 → 起手 → 熏 → 任运** 这条慢链本身。

### 4.6 经典骨架（深挖时的结构，非新内容）

- **三士道 = 欲钩总架构**：修行者自摸的两条钩，正是经典[三士道](../../resources/cards/三士道.md)的中、上二士欲钩（冷的恰好是最底下情感恐惧型的下士钩）。
- **寂天《入菩萨行论》精进品 = 起 / 续精进最完整专论**：断三懈怠（推延 / 耽劣 / 自轻）+ 集四力——**信解力**（观功德过患生胜解欲 = 点火机制本身）、坚毅力、**欢喜力**（于善如童子游戏不知足 = 续火）、放舍力。
- **每条线的具体经典修法**：A 线随念**法**功德（涅槃 / 法身德·走理侧、避人格化德面冷）+ [不退转](../../resources/cards/不退转.md)（十住毗婆沙论易行品 / 现观庄严论果德）；B 线[七因果](../../resources/cards/七因果.md) + [自他相换](../../resources/cards/自他相换.md)。
- **边界**：七因果 / 自他相换 / 随念 / 不退转易行**不在《百法》范畴**、属道次第 / 菩萨道经典，系统深挖待相应阶段（与利他善巧轴回填触发一致）。现阶段先用认知路径起头。
- **无现量处的比量燃料（暇满 / 行苦）另文专论**：§4.1 链顶"观"要审决的"暇满 / 行苦的值得"，修行者自陈"连比量都没有"——须从经典论述 / 喻 / 例把比量从零建起。**分工**：专题文档《暇满与行苦的比量建立》（材料清单 + 关键比量点、结构 / 诊断侧，待写、行苦先）+ **四张喻卡**（盲龟喻 / 爪上土喻 / 掌中毛喻 / 暇满难得·**完整经文 + 逐句比量讲解**，待建）。
