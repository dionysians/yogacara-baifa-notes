## 〇、这篇是什么：在"无现量"处把比量从零建起

暇满 / 行苦对修行者特殊——和"比量沉现量"那类问题**方向相反**：一般问题是比量已有、缺把它沉成现量；这两个是**现量结构性缺席**（命好的人从无"稀缺 / 逼迫"的现量），得**先把比量从零搭起**。

经典对此早有技术 = **喻（盲龟 / 爪上土 / 掌中毛）= 比量代现量的脚手架**：盲龟喻不给你稀缺的现量，它给你一个够鲜活、能在现量缺位时顶上去运作的比量影像。

**功能定位**（接 [修道点火](修道点火与遮强表弱——懈怠根诊断与欲钩双线.md)）：本文是该文 §4.1 链顶"观"节点的弹药库。**但不是去造"紧迫感"（相型·修行者做不了），是喂 §3.5 的结构性胜解（理型）**——义大 → A 线果德侧 / 行苦不安隐 → §3.5"不进则退"的苦谛根据 / 难得 → "别浪费窗口"。取**理 / 义大 / 不安隐角**、避**恐怖 / 恶趣角**（接该文 §4.3 信走实能）。

**行苦先**：行苦离修行者已有现量（该文 §3.4）只差一层窗户纸、比量沉得最快；暇满（长寿天难领衔）随后，是更纯的"无现量从零建比量"范本。

## 一、行苦的比量建立（已讲 + 确认 2026-07-01）

### 1.1 三苦遍三受：定位修行者落在哪

〔第一层·《瑜伽师地论》《俱舍论》〕一切有漏苦按"借哪种受显"分三层（[三苦](../../resources/cards/三苦.md)）：苦受 → **苦苦** / 乐受 → **坏苦** / 不苦不乐受 → **行苦**；且**行苦通一切有漏行**（《俱舍》三受皆具行苦性）。

**关键比量点①**：修行者"带一丝乐 / 轻安"的基底 → 表层落**坏苦**域；但行苦在那点乐底下也照在。修行者 [§3.4 现量](修道点火与遮强表弱——懈怠根诊断与欲钩双线.md) 证的是"苦苦 / 坏苦此刻不现"，**不等于"行苦不在"**——三层不同苦层，证量只盖前两层。

### 1.2 行苦的体 = 五取蕴苦器（③·修行者入口）

〔第一层·《瑜伽》"有漏诸行由麁重所随故性不安隐" + 八苦之五取蕴苦〕行苦不是某苦受，是**有漏取蕴本身不安隐**——取蕴 = **苦器**（盛苦的所依）；八苦末项"五取蕴苦"即把一切苦收摄为"仅仅拥有取蕴就是苦的所依"。

**关键比量点②**（命门一句）：修行者乐基底 = **"苦器上暂时无浪"**——浪没起 ≠ 不是苦器。接 §3.4：缘动即复燃、对缘无最终自在 = **不安隐**。**这"不安隐"= 无明引力的苦谛侧表述**（[修道点火 §3.5](修道点火与遮强表弱——懈怠根诊断与欲钩双线.md)）：取蕴不安隐 = 平静可退 = 引力恒在。**行苦与 §3.5 是同一件事两面**（苦谛面 / 力学面）。

### 1.3 为什么现量够不着 = 掌中毛喻（②·详 [掌中毛喻卡](../../resources/cards/掌中毛喻.md)）

〔第一层·行苦定义《瑜伽》+ 譬喻（道次第 / 阿毗达磨传承·原始出处待考）〕毛置掌不觉、置眼即痛；凡夫如掌（行苦置之不觉）、圣者如眼（即觉即厌）。

**关键比量点③**："现量感受不到逼迫" **= 凡夫位标准态、不是行苦反证**——不是看一个不存在的东西，是站在掌位看一个要眼位才显的东西。把修行者历来的"够不着"从**困惑**转成**经典预言的标准态**。

### 1.4 收口：双消音 → 只剩行苦，且恢复力够不着它

- **苦苦**（耐受强 + 命好）消音 + **坏苦**（强恢复力快回乐底）消音 → **只剩行苦**。
- **关键比量点④**（最锋利·修行者现量 2026-07-01 确认）：强恢复力是**受层**的本事（在"受"上抚平苦苦 / 坏苦）；**行苦根本不在受层**（在取蕴 / 所依层）。**故修行者最大资粮（恢复力）恰好够不着行苦**——能消音前两苦、唯独碰不掉行苦，反把它单独曝为唯一苦谛抓手。身心配置把别的路都关了、只留这一扇门，而这扇门一句话（取蕴不安隐）就推开 = 这块对修行者"很快"的原因。

### 1.5 功能定位

行苦比量 = 喂 §3.5 结构性胜解（理），**非造紧迫**。收益：① A 线苦谛侧燃料齐（[§4.4](修道点火与遮强表弱——懈怠根诊断与欲钩双线.md)"冷不安稳 → 求不退转"那半有根）；② §3.5"不进则退"有苦谛根据（退到哪 = 退回取蕴不安隐的有漏轮转）。

## 二、暇满的比量建立（材料清单 + 关键比量点）

### 2.1 自性：把"珍贵"还原成可清点的条件

〔第一层·八无暇 = [八难](../../resources/cards/八难.md)；十圆满 = 《瑜伽·声闻地》（详 [暇满难得卡](../../resources/cards/暇满难得.md)）〕暇满 = 离八无暇（有暇）+ 十圆满。十圆满 = 五自圆满（人 / 生中土 / 诸根具 / 不堕边业 / 于正法处净信）+ 五他圆满（佛降世 / 说正法 / 教法住世 / 法住随转 / 他具悲愍）。

**关键比量点⑤**：把笼统的"珍贵"**还原成 18 个可清点条件**（八无暇 + 十圆满）——建比量第一招 **化笼统为可数**，让"难得"从感叹变成可逐条核验的结构。

### 2.2 长寿天难 = 命好的经典正名〔压轴〕

〔第一层·[八难](../../resources/cards/八难.md)〕八无暇之"长寿天难"明文：天人福报极大、寿命极长、一切舒适有序 → **反不生出离心、无缘闻法** =「福报本身可能成为障碍」。

**关键比量点⑥**：修行者命好 = **人间淡影长寿天难**——舒适有序、压力皆低，正是出离心起不来那个结构（接 [修道点火 §二块一 / §3.4](修道点火与遮强表弱——懈怠根诊断与欲钩双线.md)）。「福报即障」走**理（结构反转）**、不走恐惧 → 对修行者最钩得动。**护栏**：命好的真资粮（无死恐惧 = 业清净）**不动、不自责**，只破"拿它给'不急'背书"——暇满教法对治"易得故不知珍"，不是否定福报。

### 2.3 义大：这窗口能办不可替代的大事

〔第一层·三士道义·《广论》暇满〕此暇满身能办增上生 / 决定胜 / 乃至一生成佛，"较如意宝尤为难得"。

**关键比量点⑦**：义大走"**求**"（表 / A 线果德侧）——讲"这窗口能办那件不可替代的大事"，**不讲"失去多可怕"**（堕恶趣恐吓走相、对修行者冷）。

### 2.4 难得：纯现量缺位、全靠比量（三门 + 喻）

〔第一层·《广论》难得三门〕

- **因门**：暇满身须净戒为本 + 施等助善 + 净愿回向为因；众生多造恶、鲜修此因 → 因稀 → 果（暇满身）稀。
- **数量门**：恶趣众生如大地土、善趣如爪上尘（[爪上土喻卡](../../resources/cards/爪上土喻.md)·《杂阿含经》佛擎爪甲土）。
- **喻门**：[盲龟值轭](../../resources/cards/盲龟喻.md)（百年一浮的盲龟颈恰穿入风飘木轭孔·《杂阿含经》卷十五 / 《入菩萨行论》/ 龙树《亲友书》）；连"修福之念"都闪电级稀有（《入菩萨行论》浓云闪电喻）。

**关键比量点⑧**：现量无"稀缺"（命好者从没经验过稀缺）→ **难得全靠比量**；**喻 = 比量代现量的技术**——盲龟 / 爪上土用一个鲜活影像顶替缺失的现量。

### 2.5 功能定位

义大 → A 线果德侧（求）；难得 → "**别浪费这窗口**" = §3.5"不进则退"的另一面（窗口有限 + 引力恒在·窗口期一过即坠回无暇）。同行苦——喂结构性胜解、非造紧迫。

## 三、选材校准（接 [修道点火 §4.3](修道点火与遮强表弱——懈怠根诊断与欲钩双线.md)）

道次第 saṃvega 引擎两类、**对修行者不等效**：

- **恐怖型**（三恶趣苦 / 死亡恐怖）走"相 / 恐惧"→ 修行者恐惧型 saṃvega 相冷、收效弱；
- **理胜解型**（暇满义大 / 行苦不安隐 / 长寿天难"福报即障"反转 / 果德殊胜）走"理 / 胜解"→ 修行者能。

故搭比量**有意识偏理侧**：暇满取**义大角**（不取堕恶趣恐吓）、行苦取**不安隐角**（不取苦受逼迫）、八难取**长寿天难结构反转**（不取地狱描写）。两半合起来喂 A 线胜解内容（暇满义大 → 果德侧 / 行苦不安隐 → 苦谛侧）。

## 四、学术诚实三层标注

**第一层（经典）**：三苦遍三受（《瑜伽》《俱舍》）；行苦"有漏诸行由麁重所随故性不安隐"（《瑜伽》）；五取蕴苦（八苦·阿含）；八无暇 / 十圆满（《瑜伽·声闻地》《广论》卷二）；难得三门 + 盲龟（《杂阿含》卷十五 / 入行论 / 亲友书）/ 爪上土（《杂阿含》）；长寿天难（阿含 / 大智度论 / 瑜伽）。

**第二层（框架映射）**："喻 = 比量代现量的技术"；"长寿天难 = 修行者命好的经典正名"；选材偏理避相、与信三支配置对接；难得 = §3.5"不进则退"的窗口侧；眼掌毛譬喻原始出处待考、以行苦定义为经文锚。

**第三层（自主推论 · 修行者位诊断）**："双消音 → 只剩行苦 / 强恢复力够不着行苦"（关键比量点④·修行者现量 2026-07-01 确认）；"乐受基底 = 命好在受层的显现（长寿天难受层版）"。
