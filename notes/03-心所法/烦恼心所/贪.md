## 一、经典定位

### [《成唯识论》](../../../resources/cards/《成唯识论》.md)卷六原文

> 云何为贪？于**有、有具**，**染著**为性，能障无贪，**生苦**为业。谓由**爱**力，取蕴生故。

### 四槽位

| 槽位 | 贪 |
|---|---|
| [所缘](../../../resources/cards/所缘.md) | [有](../../../resources/cards/三有.md)（三有 = 欲有、色有、无色有，即三界果报）+ 有具（三有之因 = 惑、业、资具） |
| [体性](../../../resources/cards/体性.md) | 染著 |
| 对治 | [无贪](../善心所/无贪.md) |
| [业用](../../../resources/cards/业用.md) | 能障无贪 + 生苦为业 |

补文"谓由爱力，取蕴生故"明确把贪与[十二缘起](../../../resources/cards/十二缘起.md)的"爱"接通。

### 与无贪严格对偶

贪的所缘"有、有具"与[无贪](../善心所/无贪.md)"于有有具无著为性"完全同一——差别仅在心识对所缘的取向（**染著 vs 无著**）。

### 梵文

- **rāga**：词根 rañj = 染色、着色。本义是心被对象"染上颜色"——不只是想要，是心的色调被对象改变
- **lobha**：贪欲，偏"抓取"的动作义
- [《成唯识论》](../../../resources/cards/《成唯识论》.md)"染著"二字恰好把两面合在一起：rāga 的"染"（渗透）+ lobha 的"著"（抓取）

### 与嗔的严格平行

| | 贪 | 嗔 |
|---|---|---|
| 所缘 | 有、有具（果 + 因） | 苦、苦具（果 + 因） |
| 体性 | 染著 | 憎恚 |
| 方向 | 顺境 → 抓取 | 逆境 → 拒斥 |

经典安立本身就是**严格平行**——同构的所缘结构（果 + 因双层），对反的体性。这直接坐实[三毒整体认知](三毒整体认知.md)骨架"贪嗔 = [我所]双向扩张"不只是诠释，经典定义的结构本身就是这样的。

### 贪与欲（[别境](../../../resources/cards/别有自性.md)）的辨别

| | 欲（别境心所） | 贪（烦恼心所） |
|---|---|---|
| 体性 | 希望（于所乐境希望为性） | 染著 |
| 通[三性](../../../resources/cards/三性.md) | 是（善法欲 / 染欲 / 无记） | 否（永远是染） |
| 关键差异 | 希望 = 指向对象但**不改变心的色调** | 染著 = 心被对象的颜色**渗透** |

善法欲指向修行但心不被"我要修行"这个内容染色；贪也可能指向修行，但心被"我要修行"染了色——分判在心所配置中有没有"我所"渗透。

## 二、"染著为性"精确机制

### "染"与"著"——两步复合

"染著"不是一个笼统的"执取"，拆开是两个动作的复合：

**染**（rāga 本义 = 染色）：心识被所缘的品质**渗透**——心不只认知到对象，心**取了对象的颜色**。

**著**（lobha 本义 = 抓取）：渗透之后**拔不出来**——心反复返回所缘，不愿离开。

→ 染是空间维度（所缘的颜色渗入心识），著是时间维度（心识持续变形不恢复）。两者合起来 = "染著"的完整运作。

结构性对比——与[痴](痴.md)的"迷暗"根本不同：

| | 痴 | 贪 |
|---|---|---|
| 体性性质 | 缺失性（明的缺失） | 积极性（心被主动渗透） |
| 现象特征 | **无**（缺失没有现象） | **有**（"想要的张力"可被觉察） |
| 修行学含义 | 照见痴 = 无痴现行（识别即对治） | 识别贪 ≠ 贪消退（识别和对治是两步） |

### 触→受→贪——精确转折点

**受（乐受）≠ 贪。** 这是经典中极其清晰、修行学中极其关键的分判。

受（遍行心所之一）只是心对所缘品质的自然感应，本身无善恶。**贪是受之后的第二步**——心对乐受的"味"抓住不放。

```
触（根 + 境 + 识 三缘和合）
  ↓
受（乐受升起）  ← 到这里不是贪
  ↓
关键分叉——

  路甲（无贪在场）：受完即过。心知道"好"，不染色、不黏住、继续走

  路乙（贪现行）：心对"好"的味抓住 → 染 → 著 → 我所扩张启动
```

**[不正作意](../../../resources/cards/不正作意.md)是路乙的触发。** 心识在[痴](痴.md)的背景下对所缘做出[四颠倒](../../../resources/cards/四颠倒.md)——四种系统性误读，让贪有了立足处。

### [四颠倒](../../../resources/cards/四颠倒.md)——痴在贪机制中的具体运作

| 颠倒 | 实相 | 误读 | 对贪的支撑 |
|---|---|---|---|
| 以无常为**常** | 此乐受是缘起的、刹那变灭的 | "这个好是持久的、可保留的" | 贪才有抓住的理由 |
| 以苦为**乐** | 依赖外缘的快乐本质是苦（坏苦） | "这真的是快乐" | 贪才有追求的动机 |
| 以不净为**净** | 所缘是因缘和合、非纯净独立 | "这个对象本身就是好的" | 贪才有染著的对象 |
| 以无我为**我** | 没有一个"我"在享受 | "**我**在听、**我**觉得好" | "我所"扩张才有主体 |

→ 四颠倒是痴在贪的现行中的**具体运作形态**。痴不是笼统的"迷暗"，在贪的机制里，痴精确地表现为这四种对所缘的误读。**四颠倒在先，贪才有立足处。**

→ 四颠倒中**三个直接支撑贪**（常、乐、净），一个支撑所有烦恼（我）。这就是为什么经典四种对治法中三种针对贪：

| 颠倒 | 对治观 | 破什么 |
|---|---|---|
| 常倒 | **无常观** | 破"可保留"→ 贪失去时间抓手 |
| 乐倒 | **苦观** | 破"真快乐"→ 贪失去追求动机 |
| 净倒 | **不净观** | 破"对象本身好"→ 贪失去染著对象 |
| 我倒 | **无我观** | 破"我在享受"→ 我所扩张失去主体 |

→ 贪的"营养来源"比嗔广——四颠倒中三个直接喂贪，嗔主要靠"苦倒"（对实际非苦缘亦起憎恚）。

**修行者现量印证**：常倒最典型——听到好听的音乐时，"好听"的体验需要心境、认知、耳识状态、音响条件全部到位，是缘起的、刹那变灭的。但常倒让心把"拥有录音"当作"保留体验"——这是痴构造的因果叙事的最具体例子（详见 §三）。

### 染著对心的三个效果

**效果一：心的"色调"改变。** 心不再中性地认知世界，而是戴着所缘的颜色看世界——心的中性认知功能被贪特定化。

**效果二："我所"边界移动。** 所缘的品质从"外面的东西"变成"我的东西"——染著扩张性在单次现行中的微观形态。每一次染著，"我所"的版图多一块领地。

**效果三：种子层加固。** 每一次完整的触→受→染→著循环，都在[阿赖耶识]里熏入贪的种子。种子越厚，下次遇到类似所缘时贪越容易现行——正反馈循环。这就是"上瘾"的精确种子机制。

## 三、"有有具"与染著扩张性

### "有具"双层所缘的递归性

"有具"（三有之因）包含三类：

| 类 | 含义 | 举例 |
|---|---|---|
| **惑** | 烦恼心所本身 | 对精巧知识的染著（贪）+ 不觉察此染著（痴） |
| **业** | 在惑驱动下实际做出的身口意行为 | 花时间搜索、整理、构建管理系统 |
| **资具** | 支撑存在的物质和条件 | 收藏品、管理工具、知识库 |

贪不只贪果报本身（有），还贪这三类因的全部或部分——贪驱动的兴奋（惑）、贪行为本身的过程（业）、贪物质条件（资具）。**"有具"的双层让贪有递归结构**：

```
层一（贪有）：享受体验
     ↓
层二（贪有具）：囤积、收集
     ↓
层三（贪有具的有具）：管理方法、系统构建
     ↓
层四……
```

每一层新的所缘经历同样的触→受→四颠倒→染→著循环，成为新的"有"，再生出它自己的"有具"。

### 修正："因果叙事 + 扩张性"双层机制

讨论中确立的精确描述——贪有具的递归有**两层同时在运作**的机制：

**层一（贪自身的扩张性 — 更根本）：** 染著本身具有扩张性——心被所缘"染了色"之后，这个颜色会向相邻所缘自动渗透。不需因果推理，只靠"相关"就蔓延。**"爱屋及乌"**是经典例证：爱一人→爱其居所→爱屋上之乌鸦。这里没有因果叙事（乌鸦不是爱人的因），有的是染著的颜色向相邻所缘自动渗透——rāga（染色）的本义在此最为精确。

**层二（痴给扩张提供轨道）：** 痴构造因果叙事（"拥有多 = 体验好"），贪沿着叙事执取。因果叙事是痴的贡献——它给贪的扩张加速、定向。

→ 层一是贪的**本性**（不需痴就能运作），层二是痴**给贪加速定向**。两者协同，但层一更根本。这也解释了为什么单独破痴（想通了道理）不能完全止住贪——层一的扩张性不走因果叙事通道，破不干净；必须贪的**种子势力本身**减弱，扩张才收敛。

**同时**，"有具"在经典层是存在论描述（三有之因确实**是**惑、业、资具），但凡夫在贪有具时并不**知道**自己在贪惑、业、资具——凡夫体验到的是"我在追求完善"。经典讲的是存在论（有具**是**什么），修行者体验的是现象学（贪有具时心识**在做什么**）。两层同时成立，两层之间的落差正是痴。

### 染著扩张性与[十二缘起](../../../resources/cards/十二缘起.md)"爱→取"

"染著的扩张性"不只是第三层推论——十二缘起的**爱→[取](../../../resources/cards/取.md)**本身就是对此扩张性的经典表述：

```
爱（初起染著）→ 取（染著扩张——四方向）→ 有（扩张后的存在态）
                    ├ 欲取（向感官方向扩张）
                    ├ 见取（向知见方向扩张）
                    ├ 戒禁取（向仪式/方法方向扩张）
                    └ 我语取（向自我叙事方向扩张）
```

[取](../../../resources/cards/取.md)的四类就是染著扩张性在经典中的精确展开——扩张不只朝一个方向，而是同时向感官、知见、方法、自我叙事四个方向蔓延。

### "生苦为业"——苦的完整谱系

"生苦为业"不是道德评判，是机制描述。贪现行时苦的谱系：

| 阶段 | 苦 |
|---|---|
| 未得 | 没得到的苦（求不得苦） |
| 追求中 | 方法不完善、方案不够精巧的不满——紧张和不自在 |
| 达成时 | 结果不如预期的不满 |
| 达成后 | 满足感（暂时的贪消退——但此满足**本身是下一轮贪的种子**） |

→ "满足感"不是苦的对立面，是苦的**驱动器**：正因为有过满足，心识才构造"再来一次会更好"的叙事——新一轮递归启动。整个谱系的底层机制就是十二缘起的**受→爱→取→有→生→老死**。

## 四、贪遍三界与断除次第

### 三界分布

嗔只在欲界（色界、无色界没有逆缘），**贪是三毒中唯一遍三界的**：

| | 欲贪 | 色贪 | 无色贪 |
|---|---|---|---|
| 界 | 欲界 | 色界 | 无色界 |
| 所缘 | 五欲 | 禅定中的乐受、轻安、明净 | 空无边处 / 识无边处 / 无所有处 / 非想非非想处 |
| 粗细 | 粗显 | 微细 | 极微细 |

三界贪**不是三种不同的贪**——体性都是"染著"，变的只是所缘从粗到细。深度禅修者放下五欲但对禅定境染著 = 贪的所缘从粗境换成细境，运作机制完全一样。

**与修行者路径的连接**：种子势力中"对结构精巧的天然喜好"，在未来禅定深入时有可能以另一形态现行——对定境本身的精巧、深度、结构的染著。体性相同（染著），所缘更细（从"知识的精巧结构"到"定境的精巧体验"）。

### [五下分结](../../../resources/cards/五下分结.md)与[五上分结](../../../resources/cards/五上分结.md)——断除次第

| 分类 | 内容 | 断位 |
|---|---|---|
| **五下分结** | 身见、疑、戒禁取、**欲贪**、嗔 | 三果（不还）断尽 |
| **五上分结** | **色贪**、**无色贪**、慢、掉举、无明 | 四果（阿罗汉）断尽 |

关键结构：

1. **欲贪先断，色贪无色贪后断**——粗先去、细后去
2. **色贪、无色贪与无明在同一组**——是**最后断的烦恼**
3. 三果不还圣者已断尽欲贪和嗔，**仍有色贪和无色贪**

→ **所缘越细，贪越难断**——不是因为细贪"更强"，而是**越难被照见**。

### [分别起](../../../resources/cards/分别起.md)与[俱生](../../../resources/cards/俱生.md)——现行机制差异

| | 分别起贪 | 俱生贪 |
|---|---|---|
| **现行依什么缘** | 概念框架（邪教、邪思惟、后天推理） | 种子力本身，不需概念支撑 |
| **识层** | 只在第六识 | 第六识 + **末那**（[我爱]） |
| **举例** | "构建知识体系是有价值的"→ 贪知识体系 | 婴儿抓奶、天然被精巧事物吸引 |
| **断位** | **[见道](../../../resources/cards/见道.md)断** | **[修道](../../../resources/cards/修道.md)渐断** |

**关键精确化**：分别起与俱生的区别**不在形成时间**（与生俱来 vs 后天），在**现行机制**：

- 分别起依赖**概念框架**才能现行 → [见道](../../../resources/cards/见道.md)的根本无分别智**摧毁概念框架** → 现行失去缘 → 种子断
- 俱生**不依赖概念框架**，种子力到了就自动现行 → 见道摧毁不了它的现行条件 → 需[修道](../../../resources/cards/修道.md)反复修习渐弱种子势力

→ 见道断分别起不是"从此不新增"，是**直接断种子**（概念基础设施没了，种子永远没有现行的缘）。俱生在见道后仍会自动现行，只能靠修道渐弱。

## 五、现行形态——识层分布与末那我爱

### 贪在各识层

| 识层 | 贪的形态 | 节奏 | 粗细 |
|---|---|---|---|
| **前五识** | 触境即起的初始染著 | 间或 | 最粗 |
| **第六识** | 主要显现场——相应贪 + 独起贪 | 间或 | 粗到中 |
| **末那识** | **我爱**（末那四烦恼之一） | **恒时不断** | **微细恒底** |
| 第八识 | 无（第八识只与遍行五相应） | — | — |

### 与痴三分的关键不对称

| | 痴 | 贪 |
|---|---|---|
| **恒行层** | 恒行不共无明——**独行**（不与贪嗔俱起） | 我爱——**俱起**（与我痴、我见、我慢四者恒时俱起） |
| **第六识层** | 相应 + 独行不共 | 相应 + 独起 |
| **"总依"地位** | ✓（一切杂染所依） | ✗ |

**最关键的不对称在恒行层**：痴在末那可以**独行**；贪在末那**必须与我痴、我见、我慢四者俱起**。

→ **末那的贪（我爱）必须以痴（我痴）为前提——没有"不如实知我"的暗，就不会有"对我的染著"。反过来不成立——痴可以在没有贪的情况下独立运行。** 这是"痴为根、贪为枝"在最深的末那结构层的精确落实——不是比喻，是心所配置的结构事实。

### 末那四烦恼的逻辑依赖——从贪侧看

[痴.md §三](痴.md) 已做落位表。从贪侧反过来看：

```
我痴（迷暗——不知无我）
  ↓ 认知暗提供基础
我见（萨迦耶见——执五蕴为实我）
  ↓ 有了"我"的形象
我爱（对此"我"的珍爱/染著）← 贪在末那的精确形态
  ↓ 爱"我"则举"我"
我慢（对此"我"的高举）
```

四者**恒时俱起**，箭头表示**逻辑依赖**而非时间序列——"爱我"必然蕴含"我与别人不同/我比别人好/我喜欢的最好"（我慢），因为爱了就要举。

→ 我爱在四者中**承上启下**：承接我痴 + 我见提供的"我"形象，把认知层的"执我"转化为情感层的"爱我"；在爱的基础上自然长出我慢。

→ **我爱是"我所扩张"的源头**——先有对"我"的珍爱，才有把外物纳入"我的"版图的冲动。所有"这是我的"递归链条，最底层驱动是末那我爱。

### §七 在贪侧的闭合

[痴.md §三](痴.md) 已从痴侧闭合末那四烦恼。贪侧：

- **我爱 = 贪在末那的精确形态** ✓
- 我爱的所缘 = 第八识见分（被末那执为"我"） → 贪的最深所缘不是外物，是"自我"
- 我爱 = 恒行贪，是凡夫位一切贪的深层结构性根据
- 三毒中"贪通末那"精确表述：贪在末那 = 我爱（对自我的染著）

→ 与[三毒整体认知 §七](三毒整体认知.md)"痴贪通末那、嗔不通"完全一致，贪侧现已精确落位。

## 六、现量识别

### 贪 vs 痴：识别路径根本差异

| | 痴 | 贪 |
|---|---|---|
| 体性 | 缺失性 | 积极性 |
| 现象特征 | 无 | 有（"想要的张力"等） |
| 识别 = 对治？ | **是**（照见痴 = 无痴现行 = 同一件事） | **否**（识别贪 ≠ 贪消退——两步） |

最后一行是贪识别的关键特殊性：**可以清清楚楚知道"我在贪"，但贪仍然在**。贪是积极性的力量，不会因为被看见就消失。

→ 贪的现量识别只是**对治的入口**，不是对治本身。识别之后还需无贪的正面力量介入。

### 五层光谱

**层一（粗显）——"想要的张力"：** 身体层可觉察的拉力/紧张。心被所缘拉着走，注意力不由自主回去。[无贪.md §九](../善心所/无贪.md)"欲罢不能"触发精确命中此层。

**层二（中等）——"不想停/还要更多"：** 不是明显拉力，是心在所缘上流连不走，或"已经有了但觉得不够"。识别判准："**现在能不能自在停下？**"——能停心不挂念 = 不是贪；能停心还挂着 = 著在运作；不想停 = 染著都在。此层最容易跟善法欲混淆。

**层三（微细）——"我所感/持有感"：** 不是"想要"也不是"不想停"，是底色性的"这是我的"——没有动作，只有态度。识别判准："**这个东西突然消失，心会不会动？**"——微动（一丝不安/失落）= 我所感在运作。此层需主动扫描，不会自己浮出来。

**层四（精微）——方法贪/修行贪：** 贪的所缘从外物转向修行过程/方法/见地。识别判准：修行/学习的满足感里有没有"**我做到了/我理解了/我的体系**"的味道——有则贪在运作。与路径风险 #3（看穿 vs 绕过）直接连接。

**层五（极微细）——末那我爱（恒行底色）：** 凡夫位几乎不可直接觉察。与痴的恒行不共无明在同一层级，只能在"我"形象偶尔表面化的瞬间间接逼近。止观双运的般若现观才是对治通道。

```
层一（粗显）：  "想要的张力"    ← 欲罢不能触发    → 易觉察
层二（中等）：  "不想停/还要更多" ← 能否自在停下    → 需主动问
层三（微细）：  "我所感/持有感"  ← 消失测试       → 需主动扫描
层四（精微）：  "方法贪/修行贪"  ← 满足感有无我味  → 需警觉
层五（极微细）：末那我爱         ← 间接逼近       → 凡夫位不可操作
```

→ 层一到层三 = 事件层可操作范围。层四 = 闻思层可操作（学术诚实/谦实态度即对治）。层五 = 留给止观双运。

## 七、十二缘起中的贪——两个关键节点

### 受→爱：当下干预点

十二支中，贪（= [爱](../../../resources/cards/爱.md)）精确卡在**受之后**：

```
受 → 【爱(= 贪)】→ 取 → 有 → 生 → 老死
```

受本身不生苦——受之后心识对受**做什么**才决定走向。受之后无贪在场（不染著），链条断；受之后贪现行，链条接上取→有→轮回。**贪是受转为轮回动力的转折点。**

### 无明 + 爱：两个关键节点

讨论中的修行者观察：十二缘起有**两个关键节点**（无明 + 爱），中间环节更像"自动进行"。这个直觉与经典的惑/业/苦三分严格对应。

### 惑·业·苦三分

| 类 | 十二支 | 性质 |
|---|---|---|
| **惑** | 无明、爱、取 | 烦恼——驱动力 |
| **业** | 行、有 | 造作——被惑驱动的行为 |
| **苦** | 识、名色、六入、触、受、生、老死 | 果报——自动展开 |

**惑只有三支**，其中爱和取本质上是同一贪在两个时点的展开（爱 = 初起染著；取 = 染著增长为追逐执取）。→ 真正的惑的核心 = **无明 + 爱（贪）**，恰是修行者观察的"两个关键节点"。

**"苦"类**（识→名色→六入→触→受 / 生→老死）= 过去因的果报自动展开，**不待作意**——身体已在、六根已长、触境已发生。这解释了"自动进行"的体感。

→ 干预点精确在两个节点：

```
【过去】无明 → 行                ← 惑 + 业（已种之因）
                 ↓
【现在】识 → 名色 → 六入 → 触 → 受   ← 苦（果报自动展开）
                                    ↓
          【爱 → 取】→ 有          ← 惑 + 业（现在种新因）← 当下干预点
                 ↓
【未来】生 → 老死                ← 苦（将自动展开）
```

### 与痴三层对治的结构映射

| 干预点 | 十二缘起位置 | 对应[痴.md §六](痴.md)三层 |
|---|---|---|
| **受→爱** | 现世惑的起点 | 层一（事件层——识破相应俱起的贪/痴） |
| 闻思深挖因果 | 惑的认知基础 | 层二（闻思——破独行不共的因果迷暗） |
| **无明** | 整条链的根 | 层三（止观双运——对治恒行不共无明） |

→ 层二在两者之间做功——把"痴构造的因果叙事"逐渐替换为"如实见缘起"，让受→爱的干预越来越精准，同时为无明的根本对治累积见地。

## 十、关键概念

- **染著为性**：贪的体性——染（心被所缘渗透色调）+ 著（渗透后拔不出），是积极性力量（vs 痴的缺失性）
- **有、有具**：双层所缘——果报 + 因（惑、业、资具）；有具有递归性，靠染著扩张性 + 痴的因果叙事双层驱动
- **染著扩张性**：贪的本性特征——染著向相邻所缘自动渗透（"爱屋及乌"），对接十二缘起爱→取
- **受 ≠ 贪**：乐受是遍行层的中性感应，贪是受之后心对"味"的抓取——转折点靠四颠倒（不正作意）
- **[四颠倒](../../../resources/cards/四颠倒.md)**：常/乐/净/我——痴在贪机制中的具体运作，四颠倒中三个直接支撑贪
- **贪遍三界**：欲贪/色贪/无色贪——体性不变、所缘从粗到细；所缘越细越难断
- **[分别起](../../../resources/cards/分别起.md) vs [俱生](../../../resources/cards/俱生.md)**：差异在现行机制（依概念框架 vs 种子力自动），不在形成时间
- **末那我爱**：贪在末那的精确形态——以我痴为前提、承上启下、是一切"我所扩张"的源头
- **四烦恼逻辑依赖**：我痴→我见→我爱→我慢——恒时俱起但有逻辑依赖方向
- **识别 ≠ 对治**：贪有现象特征可直接觉察，但觉察不等于消退（vs 痴的识别=对治）
- **十二缘起双节点**：无明（根）+ 爱（转折点）——修行干预的两个关键位置
