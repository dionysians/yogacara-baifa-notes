## 引言

本文是烦恼心所阶段第一个子组——三毒（贪、嗔、痴）——的**整体骨架**。它不是三个单法的深入笔记，而是先打通三者的整体结构，为随后精修单法（痴 → 贪 → 嗔）提供共同坐标。

方法上镜像 [三善根整体认知](../善心所/三善根整体认知.md)：善心所阶段已验证"先打通跨心所骨架、再精修单法"有效。三毒与三善根严格对偶（贪对无贪、嗔对无嗔、痴对无痴），骨架也从这一对偶切入。

本骨架由 2026-05-21 的开篇讨论确立，含三根梁：**主梁（存在论地位）+ 结构梁（痴为暗根、其上生出两支）+ 一条对治推论**。

## 一、经典定位：三毒即三不善根

《成唯识论》卷六立贪、嗔、痴为根本烦恼，且三者并称**三不善根**——一切不善法以此三者为根。这与善心所之首的三善根（无贪、无嗔、无痴）严格对偶：经文以"对治三毒"立三善根之体性（无贪"对治贪著"、无嗔"对治嗔恚"、无痴"对治愚痴"）。

但"对偶"只是骨架的入口。三毒与三善根**不是简单的镜像**——真正的骨架内容在不对称处（见第五节）。

---

## 二、骨架主梁：三毒的存在论地位

三毒（及一切烦恼）与三善根（及一切善法）之间，有一条决定性的不对称：

> **烦恼是凡夫心现行的默认态；善需作意、需熏习，且初期不坚。**

俱生烦恼任运现起、不待作意；善心所要靠作意安立、靠反复熏习才能现行，起步阶段还容易退失。二者地位不对等。

**为什么这是骨架的主梁**：唯识修行的根本目标是**转依**——转舍杂染依、转得清净依（转识成智）。转依的前提认知就是"现在的默认态是杂染，修行是逆转它"。如果善与烦恼是势均力敌的相持，就既无"转"的必要、也无"转"的方向。

这条不对称正是**修行之所以必要、之所以是"逆流"的结构根据**。它把 [学习方法论](烦恼心所学习方法论.md) 第二节"为看破装备分辨力、指向对治"进一步钉死为：**对治是逆默认态的、需持续用功的、有方向的（从染默认 → 净）——不是中立的裁判**。

学三毒，首先要把这条放在最前：不是"客观研究三种心理现象"，而是认识"这三者是当前心识的默认底色，修行要逆转它"。

## 三、骨架结构梁：痴为暗根，其上生出两支

### 一、痴与恶见之辨——先厘清一个最易混的点

三毒里的"痴"，**不等于"我相"**。这一点必须先厘清，否则整个骨架会被压扁。

《成唯识论》卷六：

- 痴："于诸理事**迷暗**为性……**一切杂染所依**为业。谓由无明起疑、邪见、贪等。"
- 恶见："于诸谛理**颠倒推度，染慧**为性。"

经典自己就把两者分在两个不同方向：

| 对照项 | 痴（无明） | 恶见 |
|---|---|---|
| 性质 | **迷暗**——明的缺失 | **颠倒推度**——积极的错误认知建构 |
| 方向 | 缺失方向（暗） | 建构方向（错） |$$
| 与我相的关系 | **不能看破我相** | **基于我相形成的错误认知** |
| 与慧的关系 | 慧所依之明阙如 | 染慧（慧无无痴时的颠倒形态） |

所以：**痴不是我相，痴是"我相未被照破"的暗**；而**我相作为积极的颠倒见，是"恶见"**（其中萨迦耶见即我我所见）——恶见是第六个根本烦恼，不在三毒之内。

无痴则是"看破我相"——明。痴与无痴是一对"明 / 暗"关系：无痴是看破（明），痴是不看破（暗）。

### 二、经典背书：痴"一切杂染所依"——痴为根

《成唯识论》明文：痴"一切杂染所依为业……由无明起疑、邪见、贪等"。即：痴（无明）是疑、恶见、贪等一切杂染的所依。

这正面坐实"痴为根"，也回答了一个旧争议——"无明为根"还是"我见为根"？本项目以唯识为基，《成唯识论》框架内痴是"一切杂染所依"，取**痴为根**；"我见为根"是其他部派的安立。

### 三、修正后的三毒核心结构

由上两节，三毒的整体结构是：

> **三毒 = 痴（不看破我相的"暗"，一切杂染所依）+ 我所的双向扩张（贪 = 顺境抓取 / 嗔 = 逆境拒斥）。**

```
                    痴
        （无明 / 迷暗 / 不看破我相）
          一切杂染所依 —— 暗、根
                    │
        ┌───────────┴───────────┐
        ▼                       ▼
      恶见                    贪 ／ 嗔
  我相之上的颠倒认知建构      我所的双向扩张
  （染慧）                  贪 ＝ 顺境抓取
  〔第六根本烦恼，          嗔 ＝ 逆境拒斥
   不在三毒之内〕          〔三毒中的两支〕
```

痴是暗、是根；在"我相未被照破"这个暗之上，长出两个方向：

- **认知方向**：基于未照破的我相，做出颠倒的认知建构 = 恶见（不在三毒内，是另一根本烦恼）。
- **驱动方向**：我相驱动"我所"向外扩张——遇顺境则抓取染著（贪），遇逆境则拒斥憎恚（嗔）。贪嗔是三毒中的两支。

贪与嗔共一个底层（我所扩张），方向相反（抓 / 拒）；它们的对治面无贪、无嗔则同归于"不被境牵"。

### 四、与假说 16 的连接

恶见 = 染慧 = "慧无无痴"。可以这样看：痴（暗）+ 慧（推度力）→ 恶见（颠倒推度）；无痴（明）+ 慧 → 正慧（看破我相）。痴与恶见之辨与 [假说 16（慧无痴俱起分判）](../../假说/假说-16-慧无痴俱起分判.md) 严密一致。

## 四、对治推论：无痴（看破我相）是釜底抽薪的根本对治

既然痴 = 暗、是一切杂染所依，三毒的根本对治就不是逐个去压贪、压嗔，而是：

> **无痴（看破我相 / 明）= 釜底抽薪。**

我相一旦被照破，"我所向外扩张"失去根据，贪、嗔自然减损；基于我相的恶见也失去地基。这与本项目的修行路径（看破优先）、与"看破 → 熏种 → 常态"三步循环的第一步严格同构。

这不否定对贪、嗔本身的事件层对治（那属各单法笔记），但确立了**总方向**：三毒的总对治在"明"、在无痴。

> **连接修行者童年双锚**："所有错都是无知造成的" = 痴是根、恶见与贪嗔皆其果；"了无自性" = 无痴看破我相。痴与恶见之辨，正是这条童年双锚的精确法相表述——童年是现量地"认得"，闻思在此为它配上法相坐标。

## 五、与三善根的关系：镜像确认，不对称才是骨架

三毒与三善根的镜像是显然的（名字对偶、"能障"明文、同居"根"位、体性正对）。但镜像不构成骨架。开篇讨论检视了若干不对称候选，结论：

- **存在论地位的不对称**（烦恼是默认态 / 善需培养）→ **保留为骨架主梁**（第二节）。
- **内部结构的不对称**（三毒有"暗根"痴居层级之首；贪嗔方向相反而无贪无嗔同向）→ 其有效内容**并入结构梁**（第三节）：贪嗔共底层而方向相反，这一点已在核心结构中；至于"方向相反 / 同向"本身，只是"善必平等收敛、烦恼必散乱发散"这一行舍层已知真理的实例，不另立骨架梁。
- **增殖性的不对称**（根本烦恼派生二十随烦恼，善无"随善"展开）→ 结构上支持主梁（染污不仅是默认态、还自我增殖），但其展开属随烦恼阶段，此处只暂记。

## 七、末那四烦恼与烦恼分布全景

末那识恒与四烦恼相应：我痴、我见、**我慢**、我爱（此处的"爱"即贪）。**四者中没有嗔**——末那唯内执自我、不缘违逆之境，故不起嗔。

这意味着：三毒中"痴、贪"通到末那根部，而"嗔"只现行于第六识 / 前五识层。**三毒不是同一识层的三个法**。慢虽不在三毒内，但作为末那四烦恼之一（[慢.md §四](慢.md)）加入后让全景完整。

### 痴侧已闭合（2026-05-25 [痴.md §三 §七](痴.md)）

末那我痴 = **恒行不共无明**——独行（不与贪嗔俱起）、恒时现行、是一切杂染所依的最深结构性根据。

### 贪侧已闭合（2026-05-27 [贪.md §五](贪.md)）

末那我爱 = 贪在末那的精确形态——以我痴为前提、与我痴 / 我见 / 我慢恒时俱起、承接认知层"执我"转为情感层"爱我"、是一切"我所扩张"的源头。

### 嗔侧已闭合（2026-05-29 [嗔.md §三](嗔.md)）

末那四烦恼无嗔的精确机制：

- **末那的所缘 = 自内我（第八识见分被执为"我"）**——结构上是"摄受所缘"，不是"逆境"
- **嗔需推拒"对方"**——末那的所缘就是"我"自身，无对方可推拒
- → **嗔与末那的所缘结构在体性层不兼容**

嗔在两个不同层面（识层 / 界层）失去现行条件是**同一结构机制**——嗔需要"逆境"作所缘，而末那的所缘（自内我）和色界以上的所缘（细乐境）都不是逆境。

→ 末那对"我"的态度结构上只有摄受 / 爱护（我爱）+ 高举（我慢）+ 颠倒（我见）+ 迷暗（我痴），**没有任何推拒**——嗔不可能现行。

### 慢侧接入（2026-06-01 [慢.md §四](慢.md)）

慢虽不在三毒内，但作为五钝使（贪嗔痴慢疑）第四法 + 末那四烦恼之一，其分布与痴贪同质：

- **慢通末那**——末那"我慢"是末那四烦恼之一，与我痴 / 我见 / 我爱恒俱
- **慢通三界**——色界禅境对比 + 无色界定境对比，慢仍可起（自抬不依外境）
- **慢三果断俱生**——与嗔同位次（但俱生层位深于嗔浅于贪）
- **我慢的独特功能**：末那四烦恼中**唯一带方向性的烦恼**——给"我"赋予上下方向（自抬），其他三者构建存在 / 暗背景 / 爱乐

### 四数据点闭合后的全景

四烦恼在末那 / 通界 / 通识 / 体性方向的完整分布：

| | 痴 | 贪 | **慢** | 嗔 |
|---|---|---|---|---|
| **通末那** | ✓（我痴 = 恒行不共无明）| ✓（我爱）| ✓ **（我慢）** | ✗ |
| **通三界** | ✓ | ✓（色贪 / 无色贪）| ✓ **（色无色慢 = B 组纵向慢）** | ✗（唯欲界）|
| **通六七识** | ✓ | ✓ | ✓ | 通六（不通七）|
| **恒行** | ✓ | ✓ | ✓ | ✗ |
| **体性方向** | 蔽暗 | **摄受** | **自抬** | **推拒** |
| **全部断尽位** | 四果 | 四果 | 三果 | 三果 |

**升级框定**：

> **摄受 + 自抬 + 蔽暗 三类烦恼**：通末那 + 通三界 + 通六七识 ← **末那本层主烦恼**（以"我"为操作对象）
> **推拒类烦恼**（嗔独）：不通末那 + 唯欲界 + 通六识 ← **结构性边缘烦恼**（以外境为操作对象）

**四数据点一致**——结构稳定。慢的加入让该结构从"三毒 + 一外烦恼"升级为**完整的烦恼分布机制**：

> **末那所缘性质（恒缘自内我 / 非逆境）决定烦恼分布。**
>
> 所有"以我为操作对象"的烦恼（不论暗背景 / 摄受 / 自抬）都通末那 + 通三界 + 通六七识；
> 所有"以外境为操作对象"的烦恼（推拒外境）都不通末那 + 唯欲界 + 通六识。

→ 三毒**不是同层三法**，加入慢后**四烦恼内部分两类**：**末那本层三烦恼（痴贪慢）+ 边缘一烦恼（嗔）**。

四烦恼分布细节详见各单法笔记 §三 / §四 章节：[痴.md](痴.md) / [贪.md](贪.md) / [嗔.md](嗔.md) / [慢.md](慢.md)。

## 八、学术诚实标注

- **第一层（经典）**：三毒即三不善根；痴"于诸理事迷暗为性、一切杂染所依为业、由无明起疑邪见贪等"；恶见"颠倒推度、染慧为性"；贪"于有有具染著为性"、嗔"于苦苦具憎恚为性"（《成唯识论》卷六）。痴为根，在《成唯识论》框架内有明文依据。
- **第二层（框架应用映射）**：把三毒结构对接"看破 → 熏种 → 常态"三步循环；"主梁 / 结构梁"是骨架式表述；"暗根 → 两支"的分支图是基于经典"一切杂染所依"做的结构化整理。
- **第三层（自主推论）**："贪嗔 = 我所双向扩张"是项目末那框架的诠释（与三善根整体认知、假说 12 一致）——经典明文只说贪"染著"、嗔"憎恚"于境，"我所扩张"是我们的诠释。第六、七节的假说连接与末那四烦恼推论均待后续验证。
