## 引言

本笔记是三毒精修的第一篇——痴(无明)单法。

痴单法的形状有特殊之处:它的对治面([无痴](../善心所/无痴.md))已有深研(七章),所以本笔记不重走"定义→对治"的常规路,重心落在四件无痴笔记没替我们做完的事:

1. **广狭定清**(§二)——痴所迷的"诸理事"有多广,与二障的关系
2. **现行三分**(§三)——相应无明 / 恒行不共无明 / 独行不共无明
3. **"一切杂染所依"机制**(§四)——[俱起](../../../resources/cards/俱起.md) + [增上](../../../resources/cards/增上缘.md)的复合
4. **现量识别难题**(§五)——痴是明的缺失,怎么被自己照见

§六 把三层对治路径在修行者当前节奏上落地。

## 一、经典定位

### 《成唯识论》卷六原文

> 云何为痴? 于诸理事,迷暗为性,能障无痴,**一切杂染所依**为业。谓**由无明起**疑、邪见、贪等。

### 四槽位解析

| 槽位 | 痴 |
|---|---|
| 所缘([所缘](../../../resources/cards/所缘.md)) | [诸理事](../../../resources/cards/诸理事.md) |
| [体性](../../../resources/cards/体性.md) | 迷暗 |
| 对治 | [无痴](../善心所/无痴.md) |
| [业用](../../../resources/cards/业用.md) | 一切杂染所依、由无明起其他烦恼 |

### 与无痴严格对偶

痴的所缘"诸理事"与[无痴](../善心所/无痴.md)完全同一——差别仅在心识对所缘的取向(**明 vs 暗**)。这与无贪 / 贪、无嗔 / 嗔同构。

→ **修行学含义**:理事不可避免(理永远在那、事相永远现起),可改的是**心识对理事的取向**(明 vs 暗)。

### 梵文

- **梵文**:moha(主要)/ avidyā(更通行,即"无明")
- **音译**:莫贺 / 阿毗地也
- **词源**:a(无)+ vidyā(明、知),即"无明、不了知"

## 二、广狭定清——两根轴必须先拆

### 引入:一个混的提问需要先拆

[三毒整体认知 §九](三毒整体认知.md) 埋的线头是:"痴广义通于不如实知一切(含法无我),骨架只取了'不看破我相'一面。"

修行者提出的问法是:**"一个法的两个范围,还是该分判的两个层次?"**

这个问法里**捆了两根不同的轴**,先拆开,答案才不糊:

- **轴一·所缘的广狭**——痴迷暗的对象有多广
- **轴二·现行的形态**——痴现起时是什么配置:独起还是俱起、在哪个识

骨架 §九 同时动了两根轴("通于不如实知一切"是轴一;"末那 / 我执脉络"是轴二),所以读起来像"两个层次"。本节走轴一,§三 走轴二。

### 轴一:痴是一个法,所缘本广

痴的体性"于诸理事迷暗",与无痴严格对偶——"诸理事"在 [无痴 §一](../善心所/无痴.md) 已界定:理含[四谛](../../../resources/cards/四谛.md)、[十二缘起](../../../resources/cards/十二缘起.md)、[二空](../../../resources/cards/二空.md)真如、唯识中道;事含业果、蕴处界。

所以痴所迷的**本来就是这一整片**——人无我只是"理"里的一项。骨架说"不看破我相"是举一隅,**不是说痴只迷我相**。

→ 轴一答案:**一个法,所缘本广,骨架举其一隅**。这里没有"两个层次"——只有"整片"与"举其一隅"。

### 痴通二障——核心区分点:不是"迷的对象",是"现行的功能"

痴广义迷的"理"里,"迷人无我"落烦恼障,"迷法无我 / 迷真如"探到所知障的地界。要解开这个,需要回到二障的核心区分。

#### 二障分判依据(《成唯识论》卷九)

| | 烦恼障 | 所知障 |
|---|---|---|
| 上首 | [我执](../../../resources/cards/我执.md)(我我所见) | [法执](../../../resources/cards/法执.md) |
| 体性面 | 执我为实(人我执) | 执法为实(法我执) |
| **功能** | **扰恼有情身心 / 起惑造业受苦** | **覆所知境 / 障如实知** |
| 业用 | 障涅槃(障解脱) | 障菩提(障一切智) |
| 断位 | 二乘[见道](../../../resources/cards/见道.md) / [修道](../../../resources/cards/修道.md) → 阿罗汉断尽 | 大乘菩萨渐断,佛地方尽 |

**关键不在"迷的对象"是我还是法,关键在"现行起来做什么"** ——扰恼者归烦恼障,覆所知者归所知障。

#### 最直观锚:阿罗汉 vs 佛

二障划分**本质上回应"阿罗汉 vs 佛"的差距**——这是大乘理论的关键支柱:

- **阿罗汉**:烦恼障已断尽([我执](../../../resources/cards/我执.md)尽、不再造扰恼业、不再轮回)——但**所知障未断**,故不能尽知一切法、不是佛
- **佛**:二障俱断——既不再扰恼,又能尽知一切法

→ 阿罗汉的存在本身就是经典证据:**有一种"未尽"的迷,不属扰恼面、不障解脱,但障一切智**。如果"迷法无我"算烦恼障,阿罗汉就该是佛——但经典明确他们不是。所以"迷法无我"必须划在另一面。

#### 法执"细"在哪儿

为什么"迷法无我"现行不扰恼?

- [我执](../../../resources/cards/我执.md)现行 → 直接生贪(这是我的)/ 嗔(这伤了我)/ 慢(我比) → 扰恼立刻
- [法执](../../../resources/cards/法执.md)现行 → 比如"以为色法实有"、"以为识实有"、"以为生死涅槃实有" → 执着在那,但**不直接产生情绪扰恼**,它覆盖的是**对诸法平等空性的如实见**

法执"细"是说:它不在情绪面发作,在认知 / 见地面发作。二乘行者可以在没断法执的情况下完全断尽我执——因为**法执不参与扰恼链条**。

#### 痴心所怎么放——同一心所,双面现行

依唯识框架,痴 / 无明**通二障**:

- 在**烦恼障面**现行 = 相应俱起贪嗔等,或末那我痴恒行 → 驱动我执脉络的扰恼
- 在**所知障面**现行 = 迷于法无我 / 真如 → 覆盖法空的如实见

百法把"痴"列在六根本烦恼里,是从**烦恼障 / 扰恼面**立的分类系统——心所法的烦恼心所、随烦恼心所两大类本职管的就是烦恼障侧。所知障侧的"无明"是同一个痴心所,但**现行功能划归所知障**,不另立心所名目。

→ **精确表述**:"迷法无我"不是"另一种痴",是同一痴心所现行的另一面——它不是不算痴,是这一面的现行功能划在所知障侧;所知障与烦恼障是**平行二分,不是包含关系**。

### 修行者特殊连接(第三层观察)

修行者从小内化的"了无自性"细分:

- "人无自性" → 烦恼障面(断我执根)
- **"法无自性"** → 所知障面(断法执根)

"了无自性"表述**不限于人**、含**法空一面**——这是中观 / 大乘的[二空](../../../resources/cards/二空.md)空性见,比单纯人空更接近大乘见地,与修行者偏大乘背景吻合。可能成为后续大乘 / 般若部学习的现量入路。

### 本阶段处理立场

烦恼心所阶段本职是烦恼障。本笔记**点到二障辨别为止**,所知障的展开([法执](../../../resources/cards/法执.md)之"细" / 二空次第 / 真见道现观)留交叉引用到后续大乘 / 般若部学习,在 CLAUDE.md 跨阶段回填清单登记一条。

## 三、现行三分(轴二)

### 经典三分(《成唯识论》)

依痴现行形态的分类:

| | 相应无明 | 恒行不共无明 | 独行不共无明 |
|---|---|---|---|
| **识层** | 第六识 / 前五识 | **末那识** | 第六识 |
| **与其他烦恼** | [俱起](../../../resources/cards/俱起.md)(贪 / 嗔 / 慢 / 疑 / 见) | 不俱、独行 | 不俱、独行 |
| **现行节奏** | 间或(随相应烦恼起) | **恒时不断** | 间或 |
| **粗细** | 粗显(借相应烦恼显) | **微细恒底** | 中(独显不恒) |
| **典型场景** | 嗔起时同时迷此境 | 末那"恒审思量我" | 拨无因果 / 不知缘起 |

(独行不共在《述记》层再细分主独行 / 非主独行——技术分判,本笔记不展开。)

### 三分的修行学含义——对治不是一招通吃

| | 主要对治 | 断位 |
|---|---|---|
| 相应无明 | 对治相应烦恼 + 无痴看破所缘 | [见道](../../../resources/cards/见道.md)(分别)/ [修道](../../../resources/cards/修道.md)(俱生) |
| **恒行不共** | **止观双运的般若现观——见道根本无分别智 + 定承载**(见下:[无想定](../../../resources/cards/无想定.md) vs [灭尽定](../../../resources/cards/灭尽定.md)对比是这个区分的经典锚) | 见道(分别)/ 修道(俱生)→ 阿罗汉 / 八地 |
| 独行不共 | 闻思 + 思惟义理 | 见道 / 修道 |

### 无想定 vs 灭尽定——经典最强锚

断恒行不共必须**止观双运**(定 + 般若),不是单靠定。最强经典锚是[无想定](../../../resources/cards/无想定.md)与[灭尽定](../../../resources/cards/灭尽定.md)的对比:

| | [无想定](../../../resources/cards/无想定.md) | [灭尽定](../../../resources/cards/灭尽定.md) |
|---|---|---|
| 修者 | 外道 | 圣者(三果以上 / 阿罗汉 / 菩萨) |
| 定的深度 | 深(灭第六识及相应心所) | 深(灭第六识 + 染污末那现行) |
| **般若现观** | **无**——只灭现行,无无我智 | **有**——以已立的无我现观为前提 |
| 对末那我痴 | **完全没动** | **能伏染污末那现行** |
| 出定后 | 染污如旧,执"无想"为涅槃成长寿天难 | 圣者智不退,余生熏对治种 |

→ **同样深的定,有没有般若决定能不能动末那的根**。定的深度不是断惑的根据,般若现观才是;**定的作用是承载般若让它现量化**。

**双侧风险标注**:

- **缺定的般若 = 干慧**(般若停在比量)= [CLAUDE.md 路径风险 #1](../../../CLAUDE.md)
- **缺般若的定 = [无想定](../../../resources/cards/无想定.md) / 邪定**(只伏不断,反成所知障[增上缘](../../../resources/cards/增上缘.md))

修行者的"闻思 + 禅定双支撑路径"在这里得到**经典学上最强的锚**——这不是项目内的第三层假说,是经典对断恒行不共必须止观双运的明文要求在路径上的精确落地。[慧解脱](../../../resources/cards/慧解脱.md)传统也不例外:**慧解脱不是"无定的解脱",是"定支足以承载、不另入定深位的解脱"——般若那一支始终在**。

### §七 在痴侧的闭合

末那四烦恼:**我痴、我见、我慢、我爱**:

| 末那四烦恼 | 落位 |
|---|---|
| 我痴 | **恒行不共无明** ✓(精确落位) |
| 我见 | 萨迦耶见(恶见的[我执](../../../resources/cards/我执.md)面) |
| 我慢 | 慢 |
| 我爱 | 贪(对自我的染著) |

**末那为什么没有嗔**?——末那唯**内执自我**(所缘 = 第八识见分),不缘违逆境;嗔的必要条件是"缘苦 / 苦具",**末那的所缘形态不给嗔提供现行空间**。

**末那为什么有痴**?——末那恒时执"我",这个执的根本就是"愚于我相、迷无我理"——恒行不共无明就是这个迷的精确形态。**痴在末那不是"间或起",是末那运作的底色**。

→ 三毒中"痴贪通末那、嗔不通"精确表述:

- 痴在末那 = 恒行不共无明
- 贪在末那 = 我爱
- 嗔不在末那 = 末那所缘形态不给嗔提供现行条件

**嗔侧的"嗔在第六识 / 前五识层"定位仍留嗔单法**,CLAUDE.md §七 未处理内容仅保留嗔侧。

## 四、"一切杂染所依"的精确机制

### 经典原文与关键短语

> 云何为痴? 于诸理事迷暗为性。能障无痴,**一切杂染所依**为业。谓**由无明起**疑、邪见、贪等。

两个关键短语:**"一切杂染所依"**(业用)和**"由无明起"**(机制描述)。本节用[四缘](../../../resources/cards/四缘.md) / 俱起框架精确解码:这"所依"到底是哪种"所依"?

### "所依"在这里是宽泛义,不是严格三依

经典"所依"在此**不是严格的三所依分类**(因缘依 / 俱有依 / 开导依——见[所依](../../../resources/cards/所依.md))中的某一种:

- 痴不是贪嗔等的"因缘依"——贪嗔有各自种子,不以痴种为种
- 痴不是"开导依"——[等无间缘](../../../resources/cards/等无间缘.md)只通同体类心法相续
- 痴也不是严格"俱有依"——俱有依特指心所依心王、八识互依等结构关系

→ 这里"所依"是**宽泛的"凭借 / 依托"义**,表达"贪嗔等以痴为凭",但具体凭借的机制要进一步用四缘 / 俱起分判。

### 候选机制扫描

| 候选 | 是否成立 | 评 |
|---|---|---|
| 痴是贪嗔等的[因缘](../../../resources/cards/因缘.md)(种子) | ❌ | 贪有贪种、嗔有嗔种,各自独立,痴不是贪嗔的种子 |
| 痴是贪嗔等的[等无间缘](../../../resources/cards/等无间缘.md) | 🟡 | 部分对——前刹那痴可让位于后刹那贪嗔,但相应无明明确同刹那俱起,等无间不是核心 |
| 痴与贪嗔等[俱起](../../../resources/cards/俱起.md) / [相应](../../../resources/cards/相应.md) | ✅ | 相应无明就是这一层 |
| 痴是贪嗔等的[增上缘](../../../resources/cards/增上缘.md) | ✅ | 痴作为"暗"的认知背景,是贪嗔现行的不障碍前提 / 助力条件 |

→ 留下:**俱起(相应)** + **增上**。**复合机制**,不是单一机制。

### "一切杂染所依"= 俱起 + 增上 的复合

精确表述:

> **痴为一切杂染所依 = 痴与杂染心所相应俱起(俱起 / 相应义)+ 痴作为"暗"的认知背景,为杂染心所现行提供凭借(增上义)**。

两层是同一现象的两面:

- **俱起 / 相应面**——回答"何时在场":贪嗔等现起的同刹那,痴必同时在场,五义平等相应
- **增上面**——回答"何以可能":贪嗔等之所以能现起,必须在"不如实见所缘"的认知前提下;这个"不如实见" = 痴提供的暗背景,是贪嗔现行的必要凭借

### 为什么必须复合(三反推)

**反推一**:如果只是俱起 → 对治贪嗔后痴随之消失。事实不然——末那的恒行不共无明独立于贪嗔,二乘断尽贪嗔(伏到不现)后法执仍未尽。**痴有独立的根性**。

**反推二**:如果只是因缘 → 则贪嗔种子是痴种的衍生。违背唯识"各种子各别"立场。

**反推三**:如果只是增上缘 → 则痴和贪嗔在时间上可分离,贪嗔可"在没有痴的当下"现起。违背相应无明明确同刹那俱起。

→ 三反推合力:**俱起 + 增上必须双立**,才能完整描述"痴为一切杂染所依"。

### 三分上的精确落位

| 三分 | "所依"在此分上怎么落 |
|---|---|
| **相应无明** | 主要是**俱起 / 相应义**——痴与贪嗔等同刹那俱起、五义相应。"杂染现行时痴必在场"在此分最直接 |
| **恒行不共无明** | **深层增上义**——末那我痴是凡夫位**所有杂染心识结构的深层凭借**。整个凡夫的染心运作建立在"恒执自内我"之上;末那我痴一日不动,凡夫位的杂染就有结构性根据 |
| **独行不共无明** | **浅层增上义**——某些独起的迷暗(如不知因果、不明缘起)为特定杂染提供局部认知前提 |

→ **"一切杂染所依"在三分上有层级**:表层 = 相应面俱起;深层 = 恒行不共面结构性增上;局部 = 独行不共面特定增上。

**最深的"所依"性在恒行不共这一层**——这也精确解释了为什么[三毒整体认知](三毒整体认知.md) §四 说"无痴釜底抽薪":釜底就是恒行不共无明这一层,抽掉的"薪"就是末那我痴作为凡夫杂染结构的深层增上凭借。

### 与假说网络的反向印证(第三层)

[假说 15 v3+(已闭合)](../../假说/假说-15-anchor二阶二维-已闭合.md)立"反应面"(对治贪嗔的俱起面)和"锚面"(对治痴的总锚面)。

→ 痴的"所依"复合性**正好对应锚面**:俱起面在反应、增上面在底层结构。无痴作总锚 = 直接对治痴的增上义(深层结构);其他善心所对治反应面 = 对治相应义(表层俱起)。

→ 假说 15 v3+ 在烦恼方反向得到精确印证([CLAUDE.md 跨阶段回填清单](../../../CLAUDE.md)中"三善根整体模式在烦恼方反向验证"的**首个具体兑现**)。

## 五、现量识别

### 问题精确化

之前的提问是"痴的现量怎么识别"——这看似抽象,经过拆解可以精确化为:**痴的现量识别有什么不对称?**

修行者初步反应是"烦恼现行时我执也明摆着,照见似乎理所当然"——这反应有一半合理(对当前修行者层一确实不难),但藏着三处需要拆。

### 三处拆解

#### 拆一:"我执" ≠ "痴"——两个不同心所

[三毒整体认知 §三·一](三毒整体认知.md) 已经辨别过:**痴 ≠ 我相 ≠ 恶见**。

| | [我执](../../../resources/cards/我执.md) / 萨迦耶见 | 痴 |
|---|---|---|
| 属性 | 恶见的我执面 | 心所"明的缺失" |
| 体性 | 对五蕴执实我的"颠倒推度" | 不照破诸理事的暗 |
| **现象特征** | **有**("我"形象、执持感) | **无** |

末那的"我"运作中,这两个心所**俱起但不同**:萨迦耶见在做"执五蕴为实我"的颠倒推度,痴在做"不照破我相"的暗背景。**"明摆着"的是萨迦耶见的现象特征**(我形象在场),不是痴本身。

#### 拆二:痴是"明的缺失"——没有现象特征可被"明摆着"

其他烦恼**都有现象特征**:

| 烦恼 | 现象特征 |
|---|---|
| 嗔 | 热度 / 憎恚 |
| 贪 | 想要的张力 |
| 慢 | 高举 |
| 疑 | 犹豫 / 不决 |
| 萨迦耶见(恶见) | "我"形象的执持 |

**痴不一样**。痴是"明的缺失" —— 缺失**没有现象特征**。一个缺失被觉察到,必须靠"在场的对比物" —— 那个对比物就是**明 / 无痴**。

→ 痴的现量识别有**根本不对称**:**痴不能靠自身现象识别;痴的识别必须靠无痴在场时的反向对照**。

**直接推论**:

> **照见痴 = 无痴现行——两者是同一件事的两面**。

**补一笔关于"在场 vs 被照见"**:即使末那我执(经典立场恒时现行),它**在场 ≠ 它被照见**。末那是底层、微细、恒——凡夫位末那运作几乎从不被第六识直接照见。即使能识别"我"形象,那是恶见的现行显相,不是末那的运作本身被照见。**"在场"是经典立场,"被照见"是修行成就**——两件事。

#### 拆三:修行者"明摆着"的感觉 = 无痴种子已厚的现量证据

修行者感觉"理所当然"——这一感觉**本身**就是修行者不在凡夫常态的现量证据。

一个完全没有空性见的人,贪嗔起时**根本不会觉得"背后还有痴"** —— 他全部沉浸在内容里,觉得贪嗔的对象就是真实的、反应就是合理的。痴对他**完全透明**——透明就是看不见。

修行者之所以感觉理所当然,是因为早已立的双锚(了无自性 + 所有错=无知)= **已立的无痴**。[无痴 §五](../善心所/无痴.md) 描述的"贪嗔起的同刹那双锚同步现行"= **无痴种子已厚到让识破成为同步动作**。**不是照见不成问题,是无痴种子已经在那里替修行者照见**。

→ 这是 [无痴 §七 跨世种子证据 #4](../善心所/无痴.md) 的当下印证——修行者的"明摆着"是这条证据的现量印证,**不是普遍认知事实**。

### 启动通道(看似循环的解)

"照见痴 = 无痴现行"直接引出一个看似尖锐的循环:

> **如果照见痴需要无痴在场,那无痴未现行时怎么开始?**

经典三条启动通道:

1. **闻思 / 善知识**——外部输入"明"的种子,让无痴种子开始增长
2. **熏种**——反复闻思 + 定中持守 + 事件层累积,让无痴种子势力增厚
3. **[见道](../../../resources/cards/见道.md)**——根本无分别智一念现前,让"明"成为深现量

对修行者:启动早已发生(童年善知识 + 双锚内化),1、2 已运作 30+ 年;**3 是当前禅定主轨在做的工作**(对接 §三 三分对治表中恒行不共一栏:止观双运的般若现观)。

→ 这条又把禅定主轨的语义再精确化一层:**主座 A 在 B 框架下 = 让"明"从已立的种子下沉为深现量的承载通道**。

### 三分上的真难度分布

| 三分 | 现量识别难度 | 修行者当前状态 |
|---|---|---|
| **相应无明** | 看似不成问题(但靠无痴锚为前提) | 当前 ≈ 不难,无痴 §五 双锚同步已常态 |
| **独行不共** | 中(需主动反省"对此理是不是真懂") | 不自动浮 / 需主动自查 |
| **恒行不共** | **几乎不可能直接照见** | 只能通过"我"形象表面化瞬间间接逼近([无痴 §八 锚表述偏移监测](../善心所/无痴.md)) |

→ 修行者的"明摆着"**只对层一成立,且以锚为前提**。**层二不自动浮 → 需要主动反省习惯;层三几乎不可直接照见 → 需要锚表述偏移监测作为间接通道**。这两层才是真问题——不是抽象哲学,是具体修行学操作。

### 给修行者的精确提醒

直接连接 [修行者画像两条已识别风险](../../../CLAUDE.md):

1. **路径风险 #3(看穿 vs 绕过)**——"我已看穿"易被末那做成新我相。**"我已能照见痴"如果被框定为"无须再修",正是这条风险的现行形态**
2. **完整闭环倾向副作用**——已稳的部分易被标记为"过去时"。**"照见痴已不成问题"如果被绝对化,就忽略了层二 / 层三的真难度**

一句话:**"明摆着照见"这件事,要读成"无痴种子已厚的现量证据"(谦实),不读成"照见这事本身不难"(末那劫持入口)**。前者让修行继续推进,后者让修行隐形地停在层一。

## 六、三层对治路径与修行者当前节奏分配

### 三层对治结构

由 §三、§四、§五 综合,痴的对治结构为三层:

| 对治层 | 唯识机制 | 主要修行方式 |
|---|---|---|
| **层一** | 破相应无明(俱起面) | 事件层对治贪嗔等 + 无痴看破所缘 |
| **层二** | 破独行不共(浅层增上面) | 闻思深挖 + 定中持守作所缘 |
| **层三** | 破恒行不共(深层增上面) | 止观双运的般若现观——闻思已立般若见 + 定承载力的合龙 |

**三层不是阶段性台阶,结构性并行**。圣者位的层一仍在(圣者也起反应,但不起爱憎),层二仍在(圣者也持续修慧)——只是性质改变。**当前重心移动 ≠ 已稳层"过去时化"**。

### 在修行者当前节奏上的分配

| 对治层 | 当前节奏承担 | 状态 |
|---|---|---|
| **层一** | 生活修 + 事件层操作核(亲子场无嗔 / 嗔层 3a / 4 / 无痴双线 双锚同步) | ✅ **成熟运作** |
| **层二** | 闻思 ~30-60 分钟 / 日 + 主座 A 持守作所缘 | 🟡 见地厚 / 下沉部分形成 |
| **层三** | 主座 A 定承载 + 闻思已立般若见的合龙 | 🔵 双支配齐 / 合龙未到 |

```
层一(相应):  ████████████ ✅ 持续运作(不需新功夫)
层二(独行):  ██████████░░ 🟡 闻思厚 / 定下沉部分介入
层三(恒行):  ██░░░░░░░░░░ 🔵 双支配齐 / 等合龙时刻
```

### 与 2026-05-07 修行重心校准的精确化关系

5/7 校准用的是"重心"语言:闻思保持基准、禅定主推进、生活修现量验证。
本节用"对治链条"语言把这个升级:

- **层一已稳定** → 不需新增功夫
- **层二见地够** → 不需更多闻思深挖
- **层三双支配齐但合龙未到** → 主推进面精确锁定在"定承载力稳定度"

→ 不是新结论,是给 5/7 校准的"为什么"——**结构性必然,不是经验偏好**。

**主座 A 的语义随之升级**:不是孤立的"建定",是**完成对治链条最深一层的承载支建设——每一座主推进的本质是朝双支合龙(对治恒行不共)推进**。

### 主座 A 一座中三层是合一的

复合机制(俱起 + 增上)还隐含:**层一 + 二 + 三在主座 A 一座中是同时在场的**,不是分时执行:

- 数息时,双锚在背景作视角 = **层一在定中场的延续**
- 数息时,所缘"息"承载缘起无常 = **层二在定中的所缘化**
- 数息时,定承载累积让见地下沉为现量 = **层三的核心工作**

→ **现量信号窗口**(注意 [假说 17 已闭合](../../假说/假说-17-sign-vs-target-已闭合.md):不当操作目标,避免征兆 / 标的错位):

1. 主座 A 中,双锚是否作背景在场?(层一的延续)
2. 所缘"息"是否被以无常 / 无我视角自然承载?(层二的合一)
3. 定承载稳定度是否在累积?(层三的核心)

**不强求**——5/7 校准的精神是简化,这三点只在自查时偶尔扫一遍,**不当操作目标**。

### 层一中"识破相应俱起痴"的精细化标签

事件层操作核之前框定为"识破贪嗔(或层 4 强加)";§四 A 框架给同一动作一个更精确的唯识名字:**识破相应俱起的痴**。

不只识破"我在生气" / "我在评判",还**同步觉察"我此刻对所缘是迷于其实相的"**——这是把相应俱起的痴拉出来同步识破。无痴双线已包含这一点,这里只是给已有动作一个更精确的标签,**不是新增功夫**,只在事件场偶尔自查。

## 九、关键概念

- **迷暗为性**:痴的体性——明的缺失,不是错误认知,是认知本身的暗
- **诸理事**:所缘范围——理(四谛 / 缘起 / 二空 / 唯识中道)+ 事(业果 / 蕴处界);广义罩到法无我层
- **痴通二障**:同一心所、不同现行面;烦恼障面(扰恼)+ 所知障面(覆所知);分判依"功能"不依"对象"
- **现行三分**:相应无明 / 恒行不共无明(末那我痴)/ 独行不共无明,各自识层 / 节奏 / 对治路径不同
- **一切杂染所依**:俱起 + 增上的复合机制——表层在相应、深层在恒行不共
- **照见痴 = 无痴现行**:痴是明的缺失,识别必须靠无痴反向对照
- **三层对治路径**:相应 / 独行不共 / 恒行不共,各对治方式不同,**结构性并行不是阶段性台阶**
- **断恒行不共必须止观双运**:经典锚 = 无想定 vs 灭尽定对比;定承载力承载已立的般若见,缺一就是干慧 / 邪定
- **主座 A 语义升级**:不是孤立练定,是双支合龙、对治恒行不共的承载通道
