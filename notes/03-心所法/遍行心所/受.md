## 📖 原文与出处

### 《百法明门论》原文

> 一遍行五者：一作意，二触，三受，四想，五思。

### 《成唯识论》卷三

> 受谓领纳顺违俱非境相为性，起爱为业，能起合离非二欲故。

### 《瑜伽师地论》卷三

> 受者，谓领纳，是心之差别。

---

## 💬 定义

**受**是心识领纳（体验）所缘境时产生的苦、乐、舍（不苦不乐）的感受。它不是情绪（情绪属于更复杂的心所），而是最基本、最原始的**感受色调**——每一念心识活动都自带一个"感受标签"：舒服、不舒服、或中性。

打个比方：如果心识是一台相机，触是按下快门，那受就是照片自带的**色温**——每张照片必然有色温（暖、冷、中性），不可能没有。同样，每一念心识必然带有受——苦、乐、舍三者必居其一。

受是五遍行中唯一直接关联到"苦乐"的心所，也是十二因缘中从认知转向烦恼的关键枢纽。

---

## 🎯 核心特征

1. **领纳为性**: 受的本质是"领纳"——体验、承受所缘境带来的感受。不是分析判断，而是直接的感受体验
2. **三受分类**: 苦受（不适感）、乐受（适意感）、舍受（不苦不乐的中性感）。一切受不出这三类
3. **起爱为业**: 受的功能是引发爱（渴望）——乐受引起合爱（想要接近、拥有），苦受引起离爱（想要远离、排斥），舍受引起非二爱（不关心，但潜在地维持着执着）
4. **遍行性**: 八识都有受。从最粗的五识感官感受，到最细的阿赖耶识的极微细舍受，每一念心识必有受
5. **因触而生**: 受依触而起——根境识三和合（触），然后才有苦乐的体验。触是受的直接依止
6. **非情绪**: 受是最原始的感受色调，不是愤怒、喜悦、悲伤等复杂情绪。情绪是受加上其他心所（如嗔、贪等）共同作用的结果

## 🔍 为什么受是独立心所

**【第一层 + 第三层：以下论证基于经典定义（受是遍行、爱是烦恼心所），推理过程是我们的分析】**

受的运作方式与分别依的模式识别相似——都是由种子习气驱动的自动反应。那为什么受需要被单独列为一个心所？

### 受不能并入爱

最直接的回答：**受是遍行，爱不是。**（《成唯识论》明确将受列为遍行心所，贪列为烦恼心所）

| 场景 | 有受吗 | 有爱吗 |
|---|---|---|
| 阿赖耶识的运作 | 有（舍受） | 没有（阿赖耶识只有5个遍行，无烦恼心所） |
| 阿罗汉的日常感知 | 有（触冷知冷、触热知热） | 没有（烦恼已断尽） |
| 四禅定中 | 有（舍受） | 没有（定中烦恼暂伏） |
| 你平静地看着桌上的杯子 | 有（舍受） | 没有（对杯子无贪无嗔） |

受可以独立于爱而存在。一个遍一切心的法不可能是一个非遍行的法的附属属性。

### 受不能并入触

**【第一层：以下体性定义来自《成唯识论》】**

触也是遍行，范围一样大，但功能定义不同：
- **触**的体性：令心心所触境——使认知**接通**（是/否）
- **受**的体性：领纳顺违俱非境相——产生**苦乐舍体验**（三种色调）

触回答"接通了没有"，受回答"接通之后的体验色调是什么"。逻辑上可以设想一个只有触而没有受的系统——它接触到了对象、了别了对象，但对这个接触没有任何苦乐体验。

### 受描述的是不可还原的维度

**【第三层：自主推理，经典未以"不可还原"这个角度论述受的独立性】**

受之所以被单独列出，不是因为它的运作方式特殊（它确实像模式识别一样自动），而是因为**苦乐舍这个体验色调是一个独立的心理维度**——不等于"识别出了什么"（触/想的事），也不等于"想要/不想要"（爱/贪的事），而且它遍一切心。

## 🔄 受的详细分类

### 基本三分法

| 受 | 梵文 | 定义 | 特征 |
|---|---|---|---|
| **苦受** | Duḥkha-vedanā | 领纳违逆境相 | 不适、难受、想远离 |
| **乐受** | Sukha-vedanā | 领纳顺适境相 | 舒适、愉悦、想靠近 |
| **舍受** | Upekṣā-vedanā | 领纳非顺非违境相 | 中性、不苦不乐 |

**【第三层：以下推理基于受的遍行性和舍受定义，经典未直接论述"零信号状态即舍受"】** 前五识的"零信号状态"——舌识尝"淡"、耳识听"寂静"、眼识见"黑暗"——都是舍受的实例。没有顺境（乐受的条件）也没有违境（苦受的条件），领纳的是"非顺非违境相"。这些状态下识仍在运作、触仍成立，因此受必然在。详见 [舌识 — 零信号状态](../../02-心法/前五识/舌识.md#淡是一种味吗低信号状态与识的显露)。

### 五受分法（更精细）

| 受 | 身/心 | 说明 |
|---|---|---|
| **苦受** | 身 | 身体层面的不适（如疼痛） |
| **乐受** | 身 | 身体层面的舒适（如温暖适度） |
| **忧受** | 心 | 心理层面的不适（如忧愁烦闷） |
| **喜受** | 心 | 心理层面的适意（如欢喜快乐） |
| **舍受** | 身心 | 身心层面的中性感受 |

五受进一步区分了**身受**（前五识对应的感受）和**心受**（第六意识对应的感受）：
- 前五识只有苦受、乐受、舍受（身体感受，较粗）
- 第六意识有忧受、喜受、舍受（心理感受，可以很细微）
- 第七、八识主要是舍受（详见下节）

### 第七、八识的舍受

#### 末那识为什么是舍受

**【第一层 + 第三层：末那识唯舍受为经典定论；以下用因果理门解释"为什么"是我们的推理】**

从五遍行的因果理门来理解：

```
作意 → 触 → 受 → 想 → 思
```

末那识的触是末那识与第八识见分的接触。在受的逻辑阶段，末那识只是在领纳这个接触的体验色调——第八识见分本身是"非顺非违"的中性对象，所以受必然是**舍受**。"执第八识见分为我"的判断属于**想**（取相——取"我"之相）和**思**（造作——执取"我"的意志推动），在逻辑上后于受。受的内容由所缘境的性质直接决定，不受后续判断的影响。

**【第二层：以下"对比经验"的类比是基于唯识框架的映射】** 普通人无法觉知末那识的舍受——不是因为它不存在，而是因为末那识的"这是我"从无始以来一刻不停，你没有"有我执 vs 无我执"的对比经验，所以根本不知道它在运作。就像从来感觉不到空气压力——不是因为它不存在，而是因为它从来没有消失过。经典中说只有见道位（初地菩萨）以上，末那识我执暂时被破，才能觉知到它之前一直在做什么。

#### 阿赖耶识为什么是舍受

**【第一层：经典依据】** 《成唯识论》卷三："此识行相极不可知，……唯是舍受。"

阿赖耶识的所缘是种子、根身、器界。它的触——阿赖耶识与这些对象的接触——极其微细。受同样极其微细，唯舍受，道理与末那识相同：所缘境本身是中性的（种子的含藏、根身的执持没有顺违之分）。

普通人无法觉知阿赖耶识的舍受。末那识虽以第八识见分为所缘，但这不是"觉知"阿赖耶识，而是**误认**它为"我"——末那识不知道那是阿赖耶识的见分，只是执为自我。

## 🔄 受在认知过程中的位置

```
作意（警觉、引导注意）
  ↓
触（根境识三和，建立接触）
  ↓
受（领纳苦乐舍感受）  ← 感受的"自动标签"
  ↓
想（取相、形成概念）
  ↓
思（意志推动，造作）
```

### 受与触的关系

触是三和合的接触，受是接触后的体验。有触必有受——心识接触到对象的那一刻，苦乐感受**同时**升起。

但要注意：虽然说"因触而生受"，五遍行实际上是**同时俱起**的。"因触生受"是逻辑上的因果关系（没有接触就没有感受），不是时间上的先后。

### 受与爱的关系（十二因缘）

十二因缘：**触→受→爱→取→有→生→老死**

受是从"认知"转向"烦恼"的关键转接点：
- 触只是中性的接触
- 受产生苦乐，本身也还是"体验"层面
- 受之后**默认**引发爱——乐受引起贪爱（想要更多），苦受引起排斥（想要远离）
- 从爱开始，进入执取（取）→积聚业力（有）→轮回（生）→苦（老死）

### 受→爱的"自动"不是必然

**【第一层 + 第三层：受是遍行、爱是烦恼心所为经典依据；"两种自动"的区分框架是我们的分析】**

受→爱看起来是"自动"的，但这里的"自动"是**习气驱动的默认反应**，不是逻辑上不可阻挡的必然：

| | 真正不可阻挡的自动 | 习气驱动的自动 |
|---|---|---|
| 例子 | 触→受（遍行→遍行） | 受→爱（遍行→烦恼心所） |
| 性质 | 只要有心识活动，必然发生 | 因为种子习气太强，**默认**发生 |
| 能否打断 | 不能 | 能，但需要训练 |

受→爱之所以能被打断，根本原因是：**受是遍行心所，爱（贪）是烦恼心所——爱的生起需要条件，其中一个条件就是不如理作意。**

```
触 → 受（必然发生，无法阻挡）
         ↓
    此刻的作意是什么品质？
         ↓                    ↓
    不如理作意               如理作意
    （默认习气）             （训练出来的）
         ↓                    ↓
    爱生起（贪/嗔跟上）      爱不生起（觉知受，不跟随）
```

修行不是改变受（那不可能），而是训练作意的品质——从不如理作意变为如理作意，使得受生起时不自动引发爱。详见 [作意.md 正念状态中的作意](./作意.md#正念状态中的作意)。

### 二箭喻：身识的苦受 vs 意识的忧受

**【第一层：经典依据】**

《杂阿含经》有"二箭喻"：身受一箭（苦受），心又受第二箭（忧受）。凡夫受二箭，修行者只受一箭。

以痛感为例，同一个痛觉场景有两层受同时发生：

| | 身识的受 | 意识的受 |
|---|---|---|
| **类型** | 苦受（身体层面） | 忧受（心理层面） |
| **内容** | 纯粹的痛感信号 | "好疼"、"为什么是我"、"什么时候才好" |
| **能否通过修行消除** | 不能——身根触违逆境，苦受必生 | 能——这正是觉照的着力点 |
| **末那识的角色** | 末那识恒执"我的身体"，使身体损伤的境必然是违逆境 | 末那识的"我执"将苦受放大为"我在受苦" |

第一箭（身识苦受）是遍行，阿罗汉也疼，拦不住。第二箭（意识忧受）是意识在苦受基础上通过不如理作意生成的额外痛苦——修行截断的就是这第二箭。观照痛感的修行，就是身识苦受照常发生，意识以如理作意觉照，不生成忧受。

## 🌟 日常实例

1. **喝到一口好茶**：舌根触味境，舌识生起——随即一个"乐受"自动升起（舒适愉悦感）。注意：这个乐受不是"这茶真好"（那是想和思），而是更原始的"啊，舒服"
2. **牙疼**：身根触触境（疼痛刺激），身识生起——苦受自动升起。你还没来得及想"我牙疼了"，那个不适感已经在了
3. **刷短视频的无聊感**：看着一条接一条的视频，没有特别愉悦也没有不适——舍受。但这个舍受中潜藏着微细的不满足，驱使你继续刷下去
4. **回忆尴尬往事时的身体反应**：想到过去的尴尬经历，忽然心里一紧——这是意识层面的忧受。没有任何外部刺激，纯粹的心理感受

## 📝 受蕴——五蕴之一

受在佛教中极为重要，是**五蕴**（色、受、想、行、识）之一，单独作为一蕴。为什么感受重要到和"色"（一切物质）、"识"（一切认知）并列？

因为受是轮回的**驱动引擎**——众生之所以造业、轮回，根本动力就是"趋乐避苦"。而趋乐避苦的基础就是受。佛说"一切有情皆依食住"，其中"触食"就和受密切相关。

## 🧘 修行意义

### 受念处——四念处之二

四念处（身、受、心、法）中，**受念处**是专门观察感受的修行：

- 觉知当下的受是苦受、乐受还是舍受
- 观察受的**无常性**——乐受不会永久持续，苦受也不会。受是刹那变化的
- 观察受的**非我性**——受是因缘和合自动生起的，不是"我"在选择感受什么
- 在受与爱之间保持觉知间隔——感受到了，但不自动跟随贪爱或排斥

### 修行中的"舍受"陷阱

舍受看似安全（不苦不乐），但它潜藏着**无明**——不清不楚、浑浑噩噩的状态。很多人禅修中追求"什么感觉都没有"的状态，以为那是定境，其实可能只是沉浸在舍受中的昏沉。真正的定中有**明觉**，不是感受的消失。

### 四禅与受的关系

| 禅定 | 受 | 说明 |
|---|---|---|
| 初禅 | 喜受 + 乐受 | 离开欲界烦恼，身心轻安喜乐 |
| 二禅 | 喜受 + 乐受 | 内等净，定中喜乐更深 |
| 三禅 | 乐受 | 离喜，住于妙乐（三禅乐为最） |
| 四禅 | 舍受 | 舍念清净，不苦不乐 |

四禅是**舍受**——但这个舍受不是昏沉的"没感觉"，而是极清明的中性。四禅舍受是修观（毗婆舍那）的最佳基础。

### 苦谛与三受：三苦

**【第一层：经典依据】**

苦谛（四圣谛之一）的"苦"比三受的"苦受"范围大得多——苦谛覆盖全部三种受：

| 三苦 | 梵文 | 对应的受 | 含义 |
|---|---|---|---|
| **苦苦** | duḥkha-duḥkhatā | 苦受 | 苦受本身就是苦——疼痛、不适，直接的苦 |
| **坏苦** | vipariṇāma-duḥkhatā | 乐受 | 乐受的本质也是苦——因为它无常，会坏灭，乐消失时产生苦 |
| **行苦** | saṃskāra-duḥkhatā | 舍受 | 舍受也是苦——因为它是有为法、刹那生灭、受制于因缘，本身就不圆满 |

乐受之所以是苦（坏苦），不是因为乐的当下不舒服，而是因为：无常（乐受必然消失，消失时产生失落）、我执（末那识把乐受执为"我的快乐"，产生贪著）、不圆满（再大的乐受也无法真正满足，因为它是有为法、依赖条件）。

苦谛不是在说"一切都是痛苦的感受"，而是在说**一切有为法的受——无论苦乐舍——都不是究竟的安乐**。

### 涅槃与受

**【第一层：经典依据】**

唯识学说四种涅槃，受的情况各不相同：

| 四种涅槃 | 说明 | 有受吗 |
|---|---|---|
| **本来自性清净涅槃** | 一切法本来具有的清净本性 | 不涉及受（法性，非事件非状态） |
| **有余依涅槃** | 烦恼已断但肉身还在（阿罗汉在世） | 有——身体还在，前五识运作，受还在 |
| **无余依涅槃** | 肉身也灭，五蕴全部止息 | 无——识止息，受也止息 |
| **无住处涅槃** | 佛的涅槃——不住生死也不住涅槃 | 有——但性质不同（示现） |

#### 有余依涅槃：第一箭在，第二箭断

**【第一层 + 第三层：有余依为经典概念，以下与二箭喻的结合是我们的分析】**

阿罗汉的身体是**过去业力的果报**（业报身）——无始以来我执和业力已经造好的"机器"，其疼痛/愉悦机制写在了阿赖耶识的种子里。转依时末那识的我执消除了，但身体是过去业力的产物还在运作。所以：

- 前五识仍有苦受/乐受（第一箭——身体的疼痛机制是硬件层面的，不需要当下我执驱动）
- 意识不再生成忧受（第二箭断了——没有我执把受变成"我的苦""我的乐"，受→爱链条从根源断掉）

等身体寿命到了、五蕴散了——从有余依进入无余依涅槃，苦受乐受才彻底没有。

**对二箭喻中"我执与苦受"关系的修正**：之前说"末那识恒执'我的身体'，使身体损伤的境必然是违逆境"——更精确的说法是：我执不是每一刻实时制造苦受，而是我执**通过无始以来的业力**塑造了身体结构，使身体"被设计成"会对损伤产生苦受。消除当下的我执消除的是第二箭，第一箭是过去业力的果报。

#### 佛的化身与菩萨：示现而非果报

**【第一层：经典依据】**

佛的化身不是业报身，而是通过愿力和成所作智**主动变现**的。经典记载佛也有背痛、被石头割伤脚，但唯识传统理解为**示现**——佛显现出与众生相同的身体反应，是为了让众生能亲近、被教化，不是因为过去业力不得不承受。

| | 阿罗汉的身体 | 佛的化身 |
|---|---|---|
| **来源** | 过去业力的果报（业报身） | 愿力主动变现（非业报身） |
| **苦受** | 真实的苦受——身体疼痛机制还在 | 示现——显示苦的样子，非业力所感 |

菩萨的情况分层：凡夫菩萨仍是业报身（与普通人相同）；初地至七地开始转依但未圆满；八地以上无功用行，接近佛的化身状态。

**【第三层：自主推理】** "有受无受"的问题对佛来说可能不是恰当的框架——佛的化身超出了"业报驱动的五蕴"范畴，用五蕴框架去问"佛有没有受"，可能像用牛顿力学描述量子现象一样，框架本身不完全适用。

## 💡 学习心得

- 受的"自动性"最令人警醒——我们无法选择不感受。每一念都带着苦乐标签，而每个标签都在悄悄驱动后续的贪爱或排斥。修行不是消除受，而是在受升起时保持觉知、不被牵着走
- 区分"受"和"情绪"很重要。愤怒不是受，而是苦受+嗔+作意+思等多个心所的复合。受是最原始的一层，好比情绪的"原材料"
- 舍受的"隐患"是个很有趣的洞见——看似安全无害的中性感受，其实可能掩盖着深层的无明
- 受→爱的"自动"是习气默认，不是逻辑必然——爱的生起需要不如理作意作为条件，改变作意品质就能截断链条
- 受之所以是独立心所，不是因为运作方式特殊，而是因为苦乐舍是一个不可还原的心理维度，且遍一切心（不能并入爱，因为爱不是遍行）
- 二箭喻是理解受的修行意义的关键——身识苦受（第一箭）拦不住，意识忧受（第二箭）可以通过如理作意截断
- 我执不是实时制造每一个苦受，而是通过无始业力塑造了身体的苦乐机制——消除当下我执断的是第二箭，第一箭是过去业力果报
- 涅槃与受的关系因涅槃类型而异——有余依仍有受，无余依无受，佛的化身是示现而非果报
