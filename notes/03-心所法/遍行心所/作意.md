# 作意

> **类别**: 心所法 > 遍行心所

> **梵文**: Manaskāra
> **学习日期**: 2026-03-05

---

## 📖 原文与出处

### 《百法明门论》原文

> 一遍行五者：一作意，二触，三受，四想，五思。

### 《成唯识论》卷三

> 作意谓能警心为性，于所缘境引心为业。

### 《瑜伽师地论》卷三

> 作意者，谓心回转，是心之差别。

---

## 💬 定义

**作意**是心识的警觉和引导作用——当心识从沉睡或散乱状态被唤起，转向特定对象时，这个"唤醒并引导"的功能就是作意。

用现代语言来说，作意就是**注意力的启动**。不是注意力本身的持续聚焦（那是别境心所的"定"），而是注意力被激活、被牵引到某个方向的那个起始动作。

比喻：心识像一个昏睡的门卫，作意是把他叫醒并指向来客方向的那声"喂，有人来了！"。门卫醒来（心被警觉），转头看向来客（心被引向所缘境）——这就是作意的完整功能。

---

## 🎯 核心特征

1. **警心为性**: 作意的本质是"警觉"心识——让心从不活跃状态变为活跃状态，或从关注A转向关注B。就像闹钟叫醒你一样，作意叫醒心识
2. **引心为业**: 作意的功能是把心引向特定的所缘境。不只是泛泛地"醒了"，而是有方向性地"醒来看这个"
3. **遍行性**: 八识都有作意。每一念心识的生起，都有作意在起作用——哪怕是最微细的阿赖耶识
4. **先导作用**: 在逻辑功能上，作意是认知链条的第一环——先有警觉和引导，才有接触（触）、感受（受）等后续活动
5. **不等于"故意"**: 作意不需要主观刻意。你走路时突然听到巨响而转头，这个自动的注意力转向也是作意——是心识层面自发的警觉引导，不是"我决定去注意"

---

## 🔄 作意的两层含义

### 第一层：警心——唤醒

心识从"未活动"到"活动"的转变。好比你打盹时被声音惊醒——心从昏沉变为警觉。

### 第二层：引心——引导

心识被引向特定对象。不只是泛泛醒来，而是朝特定方向看去。好比你不只是被惊醒，而且注意力立刻转向了声音来的方向。

这两层在一念之中**同时完成**——警觉和引导不是两个步骤，而是一个作用的两个面。

## 🔄 作意在认知过程中的位置

```
作意（警觉心识，引向所缘境）  ← 认知的"点火器"
  ↓
触（根境识三和，建立接触）
  ↓
受（产生苦乐舍感受）
  ↓
想（取相、形成概念）
  ↓
思（意志推动，造作）
```

### 作意与触的对读

| | 作意 (Manaskāra) | 触 (Sparśa) |
|---|---|---|
| **《成唯识论》** | 作意谓能警心为性，于所缘境引心为业 | 触谓三和，分别变异，令心心所触境为性，受想思等所依为业 |
| **体性** | "警心" — 使心警觉 | 令心心所"触境" — 使认知接通 |
| **业用** | "引心" — 把心引向所缘境 | 受想思等所依 — 后续心所的基础 |
| **功能比喻** | "启动和指向" | "到达和接通" |

两者同时俱起，但功能不同：作意偏重启动和引导，触偏重连接和接触。排列上作意在前、触在后，是因果理门的逻辑先后，不是时间先后（详见 [触.md 相关章节](./触.md#触与作意对读)）。

### 多识并行：每个识各有自己的作意

**【第一层：经典依据】** 《成唯识论》卷七："此触等五，各各别有。"每一个识都有自己独立的作意——不是八识共用一个作意。

| 识 | 它自己的作意 |
|---|---|
| 阿赖耶识 | 警觉阿赖耶，维持根身器界的执持 |
| 末那识 | 警觉末那，引向第八识见分 |
| 眼识 | 警觉眼识，引向色境 |
| 意识 | 警觉意识，引向法境 |

我们日常感觉"只有一个注意力"，是因为末那识恒常执第八识见分为"我"，把多识并行的活动统合成了"一个我的体验"。

### 意识的作意与分别依的独立性

**【第三层：自主推理，与唯识框架一致但经典未明确如此表述】**

意识是前五识的"分别依"（眼识九缘之一），但意识的**作意**和意识的**分别依功能**是两回事：

- **意识的作意**：只在意识主动缘法境时发动（思考、概念化、判断）
- **意识的分别依**：意识"在线"时自然提供的系统级支持，不需要意识的作意参与

这解释了"视而不见"的精确机制：不是"眼识的作意缺失"，而是**意识作为分别依没有向眼识方向配合**，导致眼识缺了分别依这个缘，眼识整个不生起。

这也解释了正念状态：意识的作意不发动（不缘任何法境、不追逐念头），但分别依功能完整运作——前五识全部得到清晰支持。

→ 详见 [深度问答：分别依与作意的独立性](./分别依与作意的独立性.md)

### 作意与眼识九缘的关系

在眼识的九缘中，**作意**是九缘之一。眼识的生起需要作意作为增上缘——即使眼根完好、色境在前、光线充足，如果作意不起，眼识也不会真正生起。注意这里的作意是**眼识自己的作意**，不是意识的作意。

## 🌟 日常实例

1. **上课走神被叫名字**：老师叫你名字的声音引起作意——你的心从走神状态被"唤醒"并"引向"老师说话的内容。作意就是这个"一激灵"的瞬间
2. **深夜听到异常声响**：正在睡觉或放松时，突然的声响让心识警觉并转向声源方向。你还不知道是什么声音（那是后续的受、想），但心已经被唤醒并指向了——这就是作意
3. **刷手机时被标题吸引**：滑动屏幕时，某个标题让你停下来——作意引导注意力转向这条内容。这个引导往往是自动发生的，不需要"我决定看这个"
4. **禅修中的妄念升起**：你在专注呼吸，突然想到明天要开会——作意引导心识从呼吸转向了"开会"这个法境。修行中的"觉知妄念"，本质上也是一个新的作意——心从妄念被重新引向"觉知"

### 容易混淆的概念

| 概念 | 类别 | 区别 |
|---|---|---|
| **作意** | 遍行心所 | 注意力的**启动和引导**，每一念都有，自动发生 |
| **欲** | 别境心所 | 对境的**希求**，"想要"，不一定每念都有 |
| **定** | 别境心所 | 注意力的**持续聚焦**，"专注在一个点上"不散 |
| **精进** | 善心所 | 朝善的方向**持续努力**，有善恶价值判断 |

作意 → 欲 → 定：作意是"看向那边"，欲是"想要它"，定是"盯着它不放"。三者层次递进。

## 🔍 各识作意的层次对比

每个识有自己独立的作意，但其特征截然不同：

**【第二层：基于唯识框架的类推】**

| 识 | 作意的特征 | 类比 |
|---|---|---|
| **阿赖耶识** | 恒常、极微细、不可知、完全自动 | 心脏跳动——从来感觉不到它在"决定"跳，但一刻不停 |
| **末那识** | 恒常、微细、自动，比阿赖耶识粗一点 | 呼吸——大部分时候自动运作，偶尔能隐约觉察 |
| **意识** | 可间断、较粗、有可塑性 | 走路——可以自动走，也可以刻意调整步伐方向 |
| **前五识** | 随缘生起、被动、依赖分别依 | 被按下的按钮——外缘来了才响应 |

### 阿赖耶识的作意

**【第一层：经典依据】**

《成唯识论》卷三说阿赖耶识的所缘是"不可知执受、处、了"：

- **执受** — 种子和有根身（维持身体不坏）
- **处** — 器界（外部世界的呈现）
- **了** — 对以上对象的了别（极其微细，不可知）

同卷又说："此识行相极不可知，……触等亦尔。"阿赖耶识的作意、触、受、想、思全部极其微细，细到**不可知**——永远无法通过内省觉察到它们。

阿赖耶识的作意指向它的两个核心功能：

| 功能 | 作意的角色 |
|---|---|
| **含藏**：接纳、保持一切种子 | 使阿赖耶识持续"警觉"于种子的受熏和保持——新种子进来要接纳，旧种子不能丢失 |
| **变现**：种子成熟时现行为根身器界 | 使阿赖耶识持续"引向"根身器界的执持和呈现——身体每一刹那都在被维持，世界每一刹那都在被变现 |

### 阿赖耶识作意的特殊性

**【第三层：自主推理】**

阿赖耶识的作意揭示了一个重要的认识：**最基础的作意只是"使这个识保持运作"，不涉及方向选择。**

我们讨论意识的作意时，总在讨论"指向哪个法境"、"如理还是不如理"——好像作意本质上是一个"选择"。但阿赖耶识的作意没有选择、没有方向切换、没有如理不如理之分。它的整套遍行都处于最"中性"的基态：受只有**舍受**（不苦不乐），想极其微细，思不造善恶业——只维持运转，不做任何评判或选择。

这说明"警心引心"在不同层次的识中有不同的表现形态：越深层的识，作意越接近纯粹的"维持运转"；越表层的识，作意越带有方向性和选择性。

## 🧘 修行意义

### 如理作意与不如理作意

唯识学特别区分两种作意：

- **如理作意**（yoniśo manaskāra）：引导心识朝向正确的方向——如实观察事物的无常、苦、无我。修行的起点就是培养如理作意
- **不如理作意**（ayoniśo manaskāra）：引导心识朝向错误的方向——执着于常、乐、我、净。烦恼的根源之一就是不如理作意

**关键洞见**：我们不能直接控制受（苦乐感受自动生起），不能直接控制想（概念自动浮现），但可以在一定程度上**引导作意**——选择把注意力引向哪里。这是修行着力的关键点。

### 禅修中的作意

禅修的核心训练之一就是训练作意：
- **止（奢摩他）**: 训练作意持续引导心识回到一个对象（如呼吸），不让它随着妄念飘走
- **观（毗婆舍那）**: 训练作意依次扫描身心现象，如实观察

每次在禅修中发现自己走神并把注意力拉回来，就是重新发起一个正确的作意。

### 正念状态中的作意

**【第一层 + 第三层】**

正念状态下，意识的作意并非"不发动"（作意是遍行心所，不可能不发动），而是安住于**如理作意**。散心位与正念位的区别在于作意的品质：

| | 散心位 | 正念位 |
|---|---|---|
| 意识的作意 | 发动，**不如理** — 追逐念头链 | 发动，**如理** — 安住于正确的觉照 |
| 独头意识 | 高度活跃，不断生成念头链 | 安静，不生成念头链 |
| 对前五识的分别依支持 | 被不如理作意驱动的独头活动挤占 | 不被挤占，充分释放，前五识都得到清晰支持 |
| 体验 | 感官模糊、心不在焉 | 感官清晰、鲜活、当下感强 |

如理作意是正念的**必要前提**（经典链条：如理作意 → 正念生起 → 正定成就），正念是如理作意的**持续化**——由别境心所"念"来保障持续性。修行成熟后，如理作意内化为默认模式，正念自然持续，达到善心所"行舍"的**无功用住**状态。

修行训练的核心变量：不只是作意的**方向**（指向哪个法境），更是作意的**品质**（如理 vs 不如理）。

## 💡 学习心得

- 作意的"自动性"很关键——它不是"故意去注意"，而是心识自发的警觉引导。这意味着我们大部分时间的注意力方向是被习气（种子）自动引导的，不是我们"选择"的
- 理解了作意，就理解了为什么刷手机那么容易上瘾——APP 的推送和算法在不断制造刺激，触发作意，引导你的注意力。修行的价值在于夺回作意的主动权
- "如理作意"的教义说明，虽然作意有自动性，但通过训练可以改变它的默认方向——这就是修行的意义
- 每个识有自己独立的作意——我们感觉"只有一个注意力"是末那识的统合作用造成的错觉
- 意识的作意和分别依功能可以独立运作——这是理解正念状态的关键。修行训练的不只是作意的方向，更是作意的模式（追逐 vs 开放觉知）
- 修行中主要训练的是**第六意识的作意**，因为前五识的作意被动，第七、八识的作意不受主观控制，只有意识的作意有较大可塑性

## 🤔 待深入问题

1. - [x] 作意在《百法》中排遍行心所第一位，但《成唯识论》的五遍行次序是"作意、触、受、想、思"——这个排列是否暗示了逻辑先后？→ **已解决**：窥基《百法明门论疏》明确指出这是"因果理门"的逻辑先后，不是时间先后
2. - [x] 阿赖耶识的作意是怎样的？→ **已解决**：阿赖耶识的作意指向它的两个核心功能——**含藏**（接纳保持一切种子）和**变现**（种子现行为根身器界）。其特征是恒常、极微细、不可知（《成唯识论》："此识行相极不可知"）、完全自动，无如理/不如理之分。这提示我们：最基础的作意只是"使识保持运作"，不涉及方向选择。阿赖耶识的整套遍行（受唯舍受、想极微细、思不造善恶）都处于最中性的基态
3. - [x] "如理作意"和"正念"（sammā-sati）的关系是什么？→ **已解决**：不是同一概念，而是不同层次的心所协同。如理作意（遍行·作意的品质）是每一念的方向选择；正念（别境·念的正确运用）是在如理作意基础上的持续明记不忘。经典链条：如理作意→正念→正定。如理作意是正念的**必要前提**，正念是如理作意的**持续化**。修行成熟后如理作意内化为默认模式，正念自然持续，达到行舍的"无功用住"。详见"正念状态中的作意"章节及 [分别依与作意的独立性](./分别依与作意的独立性.md) 第五节
4. - [x] 意识的分别依功能是否有"容量限制"？→ **已解决**：不是"容量限制"的问题，而是不如理作意驱动独头活动会挤占分别依，如理作意安住时分别依自然释放。详见 [分别依与作意的独立性](./分别依与作意的独立性.md) 第五节
