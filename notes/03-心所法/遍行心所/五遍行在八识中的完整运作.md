# 深度问答：五遍行在八识中的完整运作

> **相关心所**: 作意、触、受、想、思（全部五遍行）
> **讨论日期**: 2026-04-16
> **核心问题**: 八识各自的五遍行具体是什么？五遍行的五分法为什么是必要的？
> **学术诚实标注**: 本文包含第一层（经典依据）、第二层（框架类推）和第三层（自主推理）内容，已分别标注

---

## 一、八识五遍行全景

**【第一层：经典依据】** 《成唯识论》卷七："此触等五，各各别有。"每个识拥有自己独立的一套五遍行。

### 阿赖耶识

| 遍行 | 内容 | 特征 |
|---|---|---|
| **作意** | 警觉阿赖耶识，维持含藏和变现的运转 | 恒常、极微细、不可知、无如理/不如理之分 |
| **触** | 阿赖耶识与种子、根身、器界的接触 | 极微细，不可知 |
| **受** | 舍受——所缘境（种子、根身、器界）是中性的 | 无苦乐波动 |
| **想** | 对种子的最基本区分功能——不同种子不能混淆 | 不形成任何概念名言 |
| **思** | 维持含藏和变现运转的最小推动力 | 不造善恶业，唯无记 |

> 整套遍行处于最"中性"的基态——只维持运转，无判断、无选择、无善恶。

### 末那识

| 遍行 | 内容 | 特征 |
|---|---|---|
| **作意** | 警觉末那，引向第八识见分 | 恒常、自动、不受主观控制 |
| **触** | 末那识与第八识见分的接通 | 恒常不断 |
| **受** | 舍受——第八识见分是中性所缘，受在逻辑上先于判断 | 无苦乐波动 |
| **想** | 取"我"之相——从第八识见分中摄取"自我"表象 | 我执的概念基础 |
| **思** | 执取"我"的意志推动——驱使末那识持续抓住"这是我" | 我执的动力来源，有覆无记 |

> 想提供了"我"的概念内容，思提供了抓住"我"的意志力量。两者配合 = 我执的完整机制。

### 前五识（以眼识为例）

| 遍行 | 内容 | 特征 |
|---|---|---|
| **作意** | 警觉眼识，引向色境 | 被动、随缘生起、依赖分别依 |
| **触** | 眼根-色境-眼识三和 | 现量，了别自相 |
| **受** | 苦受/乐受/舍受——取决于色境对身体的顺违性质 | 身受（非心受） |
| **想** | 取自相——摄取颜色、形状、明暗等感官特征 | 极基础的特征提取，不形成概念名言 |
| **思** | 极微弱的造作——善恶随意识，参与新种子品质的标记 | 以无记为主 |

> 前五识的五遍行都很"薄"——只做最基本的感知工作，概念化和行动决策留给意识。

其余四识类推：耳识（耳根-声境）、鼻识（鼻根-香境）、舌识（舌根-味境）、身识（身根-触境）。

### 意识

| 遍行 | 内容 | 特征 |
|---|---|---|
| **作意** | 警觉意识，引向法境；可如理/不如理 | **唯一有高可塑性的作意**，修行的主要着力点 |
| **触** | 意根（末那识）-法境-意识三和 | 可缘一切法：概念、回忆、想象、推理 |
| **受** | 忧受/喜受/舍受——心受，可以非常细微 | 范围最广，包括对抽象事物的感受 |
| **想** | 取共相——归类、命名、抽象概念化 | **最活跃的想**，一切名言概念由此建立 |
| **思** | 善/恶/无记的完整造作——审虑思→决定思→动发思 | **"思即是业"的主要承担者**，三业之源 |

> 意识的五遍行全部处于"最大功率"——51个心所全部可以在意识中生起。

## 二、遍行的梯度：从深层到表层

**【第二层：基于唯识框架的类推】**

```
阿赖耶识：作意(维持) 触(微细) 受(舍) 想(微细) 思(无记)  ← 基态
    ↓
末那识：  作意(恒常) 触(恒常) 受(舍) 想(取我相) 思(执我) ← 我执
    ↓
前五识：  作意(被动) 触(现量) 受(苦乐舍) 想(取自相) 思(微弱) ← 感知
    ↓
意识：    作意(可塑) 触(广缘) 受(忧喜舍) 想(取共相) 思(造业) ← 全功率
```

越深层的识，遍行越均匀、越中性、越自动；越表层的识，遍行越丰富、越有差异、越有可塑性。

## 三、五遍行的五分法为什么是必要的

### 逻辑必要条件

**【第一层：经典依据】**

唯识学坚持五遍行遍一切心，因为这五个功能是任何心识运作的逻辑必要条件：

1. 没有**作意**，识无法被激活
2. 没有**触**，识无法接触所缘
3. 没有**受**，识无法有任何体验色调
4. 没有**想**，识无法对所缘有任何区分
5. 没有**思**，识无法有任何运作的推动力

### 种子论层面的必要性：果侧与因侧

**【第三层：自主推理，与唯识种子论框架一致但经典未做此映射】**

五遍行的五分法可以映射到种子运作的两个同时过程上：

```
每一刹那同时发生：

果（种子生现行）              因（现行熏种子）
  作意 — 识被激活               想 — 区分了什么特征
  触 — 接通所缘                 思 — 以什么品质回应
  受 — 体验色调                  → 决定新种子的内容和品质
```

**果侧**（作意、触、受）：种子成熟，识被激活，接触对象，产生体验。这是种子变现为当下经验的过程。果侧不是"被动接收"——种子变现会根据识缘境的不同条件产生不同的结果（参见 [唯识与物理学 — 观察者效应](../../02-心法/唯识与物理学-种子因果的世界模型.md#观察者效应识缘境即造业)）。

**因侧**（想、思）：当下经验产生新种子。想决定新种子的**内容**（区分了什么特征），思决定新种子的**品质**（善/恶/无记）。

这个映射给了五分法远比"逻辑必要条件"更深的意义：

- **前五识的思为什么必要**：即使前五识的思很薄、善恶随意识，但它仍然参与了"新种子的品质标记"——没有思，这一刹那的体验就无法以任何品质被写回种子库
- **阿赖耶识的想为什么必要**：阿赖耶识含藏种子时需要对种子有最基本的区分——不同的种子不能混为一谈。没有想，种子库就是一团无差别的混沌

### 各识遍行的可区分度

**【第三层：自主推理】**

| 识 | 五遍行的可区分度 | 说明 |
|---|---|---|
| **意识** | 高 | 五个功能清清楚楚，各有明确不同的内容 |
| **前五识** | 中 | 作意、触、受比较清楚，想和思已经很薄 |
| **末那识** | 中 | 受单调（唯舍受），但想（取我相）和思（执我）有明确内容 |
| **阿赖耶识** | 低 | 五个遍行全部"极不可知"，功能上几乎不可区分 |

遍行的"遍一切心"是一个逻辑框架的断言——在意识层面有清晰的经验对应，在阿赖耶识层面更多是逻辑分析的结果而非可观察的事实。《成唯识论》自己也承认阿赖耶识的行相"极不可知"。

## 四、修行的着力点

修行着力于意识——因为只有意识的遍行有足够的可塑性：

- **作意**：从不如理转为如理
- **受**：觉照受而不随转（受念处）
- **想**：从颠倒想转为如实想
- **思**：从恶思/杂染思转为善思/无漏思

但修行最终影响的是深层——通过改变意识层面的种子（因侧：想和思不断熏习新种子），逐渐改变末那识的我执（想不再取"我"相，思不再执取"我"），最终转依。
