## 💬 定义

**思**是心识的意志造作功能——驱使心识朝向善、恶或无记的方向去行动。当心接触对象（触）、产生感受（受）、形成概念（想）之后，思负责**推动**心识采取行动、做出决定。

如果说前四个遍行（作意、触、受、想）是认知阶段，那思就是**行动阶段**的核心——它是从"知道了"到"做点什么"的驱动力。

佛陀说"思即是业"——这是极关键的教义。业（karma）不是外在的行为本身，而是推动行为的**意志力量**。杀生的"业"不在于刀砍下去的动作，而在于推动这个动作的那个"思"（意志决定）。

---

## 🎯 核心特征

1. **令心造作为性**: 思的本质是驱使心去"造作"——采取行动、做出选择、执行决定。"造作"不限于身体行为，一念心中的取舍决断也是造作
2. **于善品等役心为业**: 思的功能是驱使心朝向善、恶或无记的方向。思像是心的"司令官"——收到情报（受、想提供的信息）后，下达命令，调动心所去执行
3. **思即是业**: 这是思在整个佛教教义中最核心的地位。三业（身业、口业、意业）的本质都是思——身体的行为由思驱动（身业），语言由思驱动（口业），心中的意志决断本身就是思（意业）
4. **遍行性**: 八识都有思。从最粗的身口造作，到最细的阿赖耶识的极微细运行，都有思的推动力
5. **三性分类**: 思可以是善的（善思）、恶的（恶思）、无记的（无记思）。思的善恶性质直接决定了业的善恶性质

## 🔄 思的三层结构

《成唯识论》将思细分为三个层次：

### 1. 审虑思（审查思考）

对所缘境进行审查权衡——"这件事该不该做？怎么做？"

这是决定前的**思考阶段**，相当于参谋在出主意。

### 2. 决定思（做出决定）

审虑之后做出决断——"好，就这么做。"

这是**决策阶段**，相当于司令官拍板。

### 3. 动发思（付诸行动）

决定之后驱使身口去行动——说话、动作。

这是**执行阶段**，相当于下达命令后士兵去执行。

三层递进的关系：

```
审虑思：考虑权衡 → "要不要帮他？"
  ↓
决定思：做出判断 → "好，帮他。"
  ↓
动发思：付诸行动 → 伸手去帮
```

**注意**：这三层在一念中可以极快完成，也可以拉长为一个漫长的决策过程。"想了很久才决定辞职"——审虑思持续了很久；"冲动之下打了人"——审虑思极短甚至几乎跳过，直接到动发思。

## 🔄 思在认知过程中的位置

```
作意（警觉、引导注意）
  ↓
触（根境识三和，建立接触）
  ↓
受（领纳苦乐舍感受）
  ↓
想（取像、形成概念）
  ↓
思（意志造作，推动行动）  ← 从"认知"到"行动"的转折点
```

思是五遍行的最后一个，在逻辑功能上处于"收尾"位置——汇集了前四个遍行提供的信息（注意力的指向、接触的建立、感受的体验、概念的形成），然后做出"下一步怎么做"的决定并推动执行。

## 🔍 思与想的对读

| | **思** (Cetanā) | **想** (Saṃjñā) |
|---|---|---|
| **《成唯识论》** | 思谓令心造作为性，于善品等役心为业 | 想谓于境取像为性，施设种种名言为业 |
| **体性** | 造作 — 驱使心去行动、选择 | 取像 — 摄取特征，形成表象 |
| **业用** | 役心于善品等 — 驱使心朝善恶方向运转 | 施设名言 — 建立概念、分类、命名 |
| **回答的问题** | "怎么办" | "这是什么" |
| **五蕴对应** | 行蕴的核心 | 想蕴（单独一蕴） |

想提供认知内容（是什么），思提供行动方向（做什么）。两者独立变化——同一个想可以引发不同的思，同一个思可以基于不同的想。

### 思在种子论中的角色：因侧——决定新种子的品质

**【第三层：自主推理，与唯识种子论一致但经典未做此映射】**

五遍行映射到种子运作的两个同时过程上：作意、触、受属于**果侧**（种子生现行），想、思属于**因侧**（现行熏种子）。思在因侧的角色是**决定新种子的品质**——这一刹那以什么善恶品质回应，决定了新种子是善种子、恶种子还是无记种子。这正是"思即是业"在种子论层面的精确含义。

→ 详见 [五遍行在八识中的完整运作](./五遍行在八识中的完整运作.md)

### 各识的思

| 识 | 思的层次 | 说明 |
|---|---|---|
| **阿赖耶识** | 维持含藏和变现运转的最小推动力 | 极微细，不造善恶，唯无记 |
| **末那识** | 执取"我"的意志推动 | 驱使末那识持续抓住"这是我"——我执的动力来源，有覆无记 |
| **前五识** | 极微弱的造作，善恶随意识 | 参与新种子品质标记，但自身以无记为主 |
| **意识** | 善/恶/无记的完整造作 | 审虑思→决定思→动发思，"思即是业"的主要承担者 |

末那识的想和思配合构成我执的完整机制：想提供"我"的概念内容，思提供抓住"我"的意志力量。修行中破我执，既要破想（认清"我"是概念建构），也要破思（松开抓取的力量）。

## 📝 思与业——核心关系

### 业的分类（以思为核心）

| 分类 | 说明 | 思的角色 |
|---|---|---|
| **意业** | 心中的意志决断 | 思本身就是意业 |
| **身业** | 身体的行为 | 思驱动身体行动（动发思→身表业） |
| **口业** | 语言的表达 | 思驱动语言表达（动发思→语表业） |

### 善思、恶思、无记思

| 思的性质 | 业的性质 | 结果 |
|---|---|---|
| **善思** | 善业 | 感乐果（如布施助人的意志） |
| **恶思** | 恶业 | 感苦果（如杀盗淫的意志） |
| **无记思** | 无记业 | 不感善恶果（如无意识的日常动作） |

### 无记思的作用：习气与习惯

无记思不感善恶果报，但它熏习的种子有重要作用——**形成习气和习惯模式**。

你每天走同一条路上班——不善不恶，无记思。但这个无记思反复熏习，种子越来越强，下次走到路口你"自动"就往那个方向走了。这就是习惯。无记种子的作用不是感果报，而是**塑造后续行为的默认模式**：

| 无记思的反复熏习 | 形成的习气 |
|---|---|
| 每天走同一条路 | 路线习惯——自动转向 |
| 反复练习某个动作 | 身体记忆——不需要意识参与 |
| 长期使用某种语言 | 语言习惯——脱口而出 |
| 长期接触某种审美 | 审美偏好——自动取舍 |
| 长期刷短视频 | 注意力涣散的习气 |

无记习气虽不直接造善恶业，但它**间接影响关键时刻思的善恶方向**。比如长期刷短视频（无记思）形成注意力涣散的习气，在需要专注修行时就成了障碍——不是因为刷视频本身是恶业，而是无记习气塑造的默认模式妨碍了善思的生起。

这也说明修行不只是"止恶行善"——大量无记习气需要被觉察和调整，因为它们是善恶思的"土壤"。

### 思与业力的关系

思造业的过程：
1. 心接触境 → 产生感受和概念
2. 思发起意志 → 审虑、决定
3. 思驱动行动 → 身口造作
4. 造作完成 → 业的**种子**回熏到阿赖耶识
5. 种子储存 → 遇缘成熟 → 感受果报

思是整个因果链条的**发动者**——没有思的推动，就没有业的积累，就没有果报的成熟。

## 🌟 日常实例

1. **看到路边有垃圾**：触（看到），受（轻微不适），想（取"垃圾"相）——然后思开始运作：审虑思（"要不要捡？"），决定思（"算了，赶时间"或"捡起来吧"），动发思（走过去或继续走）。你的选择和行动，就是思在造业
2. **收到挑衅的消息**：触，受（苦受/怒），想（"这人在攻击我"）——思的运作：审虑思（"要回怼吗？"），决定思（"忍住"或"怼回去"），动发思（打字回复或放下手机）。善思还是恶思，就在这一念之间
3. **超市排队时有人插队**：全过程中思的三层都在运作——你在审虑（考虑是否说something），决定（开口或不开口），然后行动。整个过程可能在几秒内完成
4. **长期计划——决定考研**：审虑思持续了很长时间（反复权衡），决定思在某个时刻成立（"我决定了"），动发思开始长期执行（每天复习）。这说明思不只是瞬间的，也可以是持续的意志力量

```

触:   "接触上了"

想:   "这是什么"（取像命名）
思:   "怎么办"  （意志造作）→ 造业
```

### 容易混淆的概念

| 概念 | 类别 | 区别 |
|---|---|---|
| **思**（遍行心所） | 心所法 | 意志的造作推动，每念都有，是"业"的本质 |
| **欲**（别境心所） | 心所法 | 对境的**希求**，"想要"，侧重愿望，不一定付诸行动 |
| **精进**（善心所） | 心所法 | 朝善的方向**勤奋努力**，是善的持续意志 |
| **胜解**（别境心所） | 心所法 | 对事物的**确定理解**，"确认这样"，侧重认知确定 |

思 = "去做"（造作推动）。欲 = "想要"（希求）。精进 = "坚持做善的"（持续的善意志）。

## 🔍 思与其他心所的关系：引擎与方向

思是"令心造作"——告诉你**心在造作**这个事实。但它不告诉你以什么方式造作、朝什么方向造作。这由伴随的其他心所决定：

```
思（造作）+ 信 + 精进 + 惭 + 愧  → 善思
思（造作）+ 贪                    → 恶思（贪的方向）
思（造作）+ 嗔                    → 恶思（嗔的方向）
思（造作）+ 贪 + 慢                → 恶思（又贪又傲）
```

**思是引擎，其他心所决定引擎往哪开、载了什么货。**

### 为什么不把其他心所并入思

其他心所不能合并进思，原因和受不能并入爱一样——**独立变化**：

- 思是遍行（每念都有），贪不是（有时有有时没有）
- 贪可以在没有嗔的时候单独出现，嗔也可以在没有贪的时候单独出现
- 同样是善思，伴随的心所组合不同，业的品质完全不同

| 场景 | 思 | 伴随的心所 | 业的品质 |
|---|---|---|---|
| 布施时心怀惭愧 | 善思 | 信 + 无贪 + 惭 + 愧 | 纯善业 |
| 布施时带着自豪 | 杂染思 | 无贪 + 慢 | 夹杂烦恼的业 |

外在行为一样（都在布施），思都在造作，但伴随心所不同，业的品质完全不同。

### 修行的精密诊断

把心所拆开的意义在于修行中的精密诊断——你观察到"心在造作"（思），还需要进一步识别是哪些心所在驱动，才能对症下药：无贪对治贪，无嗔对治嗔，不害对治害。如果所有心所合并进思，修行就只剩"有造作/没造作"的粗判断，失去所有诊断精度。

**一句话：思是"心在造作"的事实，其他心所是"以什么方式造作"的细节。事实和细节必须分开记录，否则无法诊断也无法对治。**

### 思与行蕴

五蕴中的行蕴以思为主将，但行蕴还包含其余49个心所（除受、想外）和24个心不相应行法，共73法。"行"的核心含义是"造作"，与思的定义"令心造作"对应。其他心所和心不相应行法也归入行蕴，因为它们都参与了有为法的运作，但思是其中的核心驱动力。详见 [README — 五蕴与百法的对应](../README.md#五蕴与百法的对应)。

## 🧘 修行意义

### 思是修行的核心着力点

修行的本质就是**转变思的方向**：
- 从恶思转为善思（持戒）
- 从散乱的思转为集中的思（修定）
- 从有漏思转为无漏思（修慧）

菩萨道的核心——发菩提心——就是一个极强大的善思：决定为一切众生求无上正觉。这个思的力量，可以引导无量劫的修行方向。

### 意业最重——思的责任

佛教特别强调意业（思本身）的重要性：

> 身口意三业，意业为最重。

为什么？因为身业和口业都是思驱动的结果。控制了思，就控制了一切业的源头。反过来，即使身口没有行动，但心中的恶思（如恶意的嗔恨念头）已经在造恶业了——只是比身口造的业相对轻微。

### 戒律与思

持戒的本质不是压制行为，而是**训练思**：
- **律仪戒**（止恶）: 训练思在恶的方向上"刹车"——审虑思觉察到恶倾向，决定思选择不做
- **摄善法戒**（行善）: 训练思主动朝善的方向造作——审虑思发现善的机会，决定思推动去做
- **饶益有情戒**（利他）: 训练思以利益众生为首要考量

## 💡 学习心得

- "思即是业"这四个字是理解佛教因果观的钥匙。业不在外面，不在行为本身，而在推动行为的意志中。同样的行为（如杀一只蚊子），恶思驱动的是恶业，无心的是无记业
- 思的三层结构（审虑→决定→动发）解释了为什么"三思而后行"那么重要——拉长审虑思的过程，给决定思更充分的信息，避免冲动的动发思造下后悔的业
- 五遍行走到"思"，整个认知→行动的链条就完整了：注意到→接触→感受→认知→行动。这个链条每时每刻都在运作，构成了我们全部的心理生活
