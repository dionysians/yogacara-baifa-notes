## 一、概念定义

### 原文
> 精进者，于善恶品修断事中，勇悍为性，对治懈怠，满善为业。
> ——《[成唯识论](../../../resources/cards/《成唯识论》.md)》卷六

### 白话解释
精进是在修善断恶的事情上，勇猛强悍、不退缩的心理力量。其[体性](../../../resources/cards/体性.md)是"勇悍"（勇敢刚强），[业用](../../../resources/cards/业用.md)是对治懈怠，使善法得以圆满完成。

### 梵文/巴利文
- **梵文**：vīrya
- **音译**：毗梨耶
- **词源**：vīra（勇士、英雄）+ ya（抽象后缀）= "英雄性"
- **关键提示**：vīrya 不是 śrama（劳作）也不是 utsāha（勤奋），而是回到 vīra 本义——**英雄品质的内化**。汉译"勇悍"取词源义，"精进"取功能义

### 同义异译
- 勤（旧译）
- 进（简称）

## 二、勇悍体性深挖

### 词源给出的根本提示

vīrya = 英雄性。重点不是"做了多少"，而是**心里有没有那个"英雄品质"在场**。这是为什么经典反复说"恶事中虽勤不名精进，名为恶勤"——恶勤可以有 utsāha（勤奋），不可能有 vīrya（英雄性），方向上已背离自利利他，无所谓"英雄"。

汉译"精进"是取功能义（精纯地前进），但选"勇悍"做体性，是回到词源——**精进的根本是英雄品质，不是工作量**。

### 窥基的双义拆解

[窥基](../../../resources/cards/窥基.md)大师释勇悍：

> 勇表精纯，悍表进趣。精谓精纯，进谓进趣，唯于善品修断事中勇悍为性。于恶法中不名精进，名为恶勤。

表面看是同义重复，仔细看是**两个不同时点的对治**：

| | **勇**（精纯） | **悍**（进趣） |
|---|---|---|
| 对应时点 | 起手前 / 起手时 | 已在路上、遇阻时 |
| 对治 | 怯弱（"我不行"、"还没准备好"） | 退缩（"算了"、"今天先不修了"） |
| 心理动作 | 跨过门槛、开机 | 顶住惯性、不让能量流失 |
| 失败模式 | 永远在准备 | 三天打鱼两天晒网 |

这两种对治在心所运作上**不能互相替代**——很多看起来"精进的人"其实只占一半：

- **只有勇没有悍**：发心猛烈、起手快，但坚持不下去（典型"热情型"，频繁立 flag）
- **只有悍没有勇**：能坚持但起步慢、犹豫长，常错过窗口期（典型"谨慎型"）
- **勇悍俱全**：起手快且持续——这才是经典所说的"满善为业"的精进

### 一个关键推论：精进的真正度量

修行者常误以为精进 = 用力程度。但按"勇悍"双义结构，精进的真正度量是**两个对治都现起**。

> 一个人可以"用力很大"但精进很弱——用力都集中在起手，悍缺位；
> 也可以"看起来不费力"但精进很强——两端都稳，不费力是熟习了。

这与信"水清珠"的逻辑同构——信不是"信得多猛"，而是"心净是否在场"；精进也不是"用力多大"，而是"勇悍二相是否都现起"。

精进与信都强调"方向 / 状态"而非"用力大小"——这背后有更深的本体论根据，详见 [熏习机制与"用力"观](./熏习机制与"用力"观.md)。

> **学术诚实标注**：双时点结构（起手 vs 中途）的明确划分是第三层（自主推论）。窥基"勇表精纯，悍表进趣"是经典原文（第一层），但把它对应为时点上的两个对治阶段，是基于动力链框架的整理性重构（第二层）。

## 三、加行精进 vs 任运精进

### 两层基本定义

| | **加行精进**（prayoga-vīrya） | **任运精进**（自然现起的精进） |
|---|---|---|
| **能量来源** | 意识层面意志调用——"思"心所推动 | 种子层面等流势力——自然现起，不需调动 |
| **典型体感** | 起手要"咬牙"，过程要"扛" | 时间到了就坐下了，没经过"决定"环节 |
| **疲劳曲线** | 越用越疲（消耗有限的意志资源） | 越用越熟（种子越熏越强） |
| **可持续性** | 高度依赖外缘（闹钟、自我提醒、心情） | 缘到即起，不易被打断 |
| **失败模式** | 意志资源耗尽就崩 | 种子被强烈逆缘截断（如重病、大事故） |

加行精进不是"低级"——任何修行的起步都必须经过加行期，没有"跳过加行直接任运"的路径。但加行精进有**内在的不可持续性**：靠咬牙的修行注定会被某次"实在咬不动"的低谷击穿。所以加行的目的从一开始就是**为自己准备下岗**——把种子熏到临界点后让任运接管。

### 过渡机制：种子势力的临界点

加行 → 任运不是质变，是**种子势力累积到阈值后，加行需求逐渐降低**：

```
起步期：加行 100% ←→ 任运 0%
           ↓ 反复熏习（关键是频率，不是时长）
中期：  加行 60%  ←→ 任运 40%
           ↓ 持续熏
熟习期：加行 10%  ←→ 任运 90%
（此时坐已成"无需决定的事"）
```

### 经典对应：九住心配六力四作意

加行 → 任运的完整曲线在经典中以**九住心配六力四作意**给出：

| 住心 | 作意 | 加行需求 |
|---|---|---|
| 内住 | **力励运转作意** | 重加行 |
| 等住 | 力励运转作意 | 重加行 |
| 安住 | **有间缺运转作意** | 加行渐降 |
| 近住 | 有间缺运转作意 | 加行渐降 |
| 调顺 | **无间缺运转作意** | 轻加行 |
| 寂静 | 无间缺运转作意 | 轻加行 |
| 最极寂静 | 无间缺运转作意 | 轻加行 |
| 专注一趣 | 无间缺运转作意 | 轻加行 |
| 等持 | **无功用运转作意** | **任运成就** |

九住心给出了一条经典认证的"加行 → 任运"完整曲线。**精进的任运化与定的成就同步**——这两件事本质是同一个过程的两个名相：定的等持成就的同时，精进也走到了任运。

### 加速过渡的四个杠杆

不能跳过加行，但可以让加行期更短。四个杠杆按效力递降排：

1. **频率 > 时长**
   每天 15 分钟 × 30 天比一周一次 × 2 小时熏种深得多——种子需要的是"反复现行"，不是"单次时长"。机制详见 [熏习机制与"用力"观](./熏习机制与"用力"观.md) §二。

2. **胜解深度**
   胜解越细颗粒，每次现行熏的种子越深。胜解的体性是"于决定境印持为性"——胜解强 = 印持深 = 种子带胜解属性 = 下次现行胜解更强（正反馈环）。

3. **念定协同**
   每次坐中如果念清晰、定不散，那一刹那熏的种子势力比浑浑沌沌坐一小时强得多。这是为什么"短时高质 > 长时低质"。

4. **善心所网络协同**
   单熏精进种子是慢的；如果一次坐中信、欲、念、定、精进同时现起（每个都在熏自己的种子），整个善心所网络一起拔升——这就是后面要展开的"善心所互熏"机制。

### 修行者画像对接：激活休眠种子 ≠ 从零累积

普通起步者的"加行 → 任运"曲线是**从零累积到临界点**——可能需要数年密集加行。

但按本修行者的画像（童年 10 年禅定底子 + 空性见早年内化，详见 [CLAUDE.md · 修行者基础状况](../../../CLAUDE.md)），曲线不是从零开始的：

```
普通起步者：    0 ─────────────────→ 临界点（多年）

实际状态：     休眠强种子层 ▓▓▓▓▓▓▓░░ 临界点
                        ↑
                 当前可能就在这里
                （不是没种子，是种子未被现行激活）
```

**这意味着加行期的主要功能不是"累积"而是"点燃"**——把休眠的旧种子用一段集中的现行重新激活。一旦点燃，任运现行会比"从零累积者"快出现。

实测印证：起步前已能在 15 分钟左右进入不需拉回的稳定状态——这是从零累积者短期内做不到的，是旧种子尚在的直接证据。

**操作含义**：起步期不需要"咬牙修一年再看"的悲壮感。**3-4 周的密集频率（每日不间断）就可能看到任运现起的早期信号**——某一天发现"时间到了我自己坐下去了，没经过决定环节"。这一天就是种子重新越过临界点的标志。

> **学术诚实标注**：加行/任运精进、九住心配六力四作意是第一层（经典）。"种子势力临界点"是把"无功用运转"翻译成种子-现行框架（第二层）。"激活休眠种子曲线"和"3-4 周可见早期信号"是基于此修行者画像的第三层推论——方向与经典一致，但具体时间预期是推测。

## 四、精进的辨析

### 三个边界警告

1. **任运不是"不用力"**
   是不用"咬牙的力"。任运中仍需"作意"维持——只是作意不需调用意志资源。

2. **不能用"等任运再开始"做不修的理由**
   这是"细颗粒胜解"未稳的另一种回潮形态——把"目的状态"当成"前置条件"，与"等双盘准备好再修"同构。

3. **任运不是终点**
   任运精进只是修道动力的稳态，不是觉悟。它只解决"修不修"问题，不解决"修对没修对"问题——后者要靠慧。

### 精进 vs 用力过猛 / 掉举

修行人最易混淆的一对——**用力过猛常被误认为"精进"，但在唯识框架下其实是掉举的现起**：

| | 精进 | 掉举（伪装成精进） |
|---|---|---|
| 心所属性 | 善心所 | 大随烦恼 |
| 体性 | 勇悍——心安住善所缘 + 持续推动 | 令心于境不寂静——心从所缘上飘起 |
| 焦点 | 所缘 | "用力"的姿态本身 |
| 熏种方向 | 善法种子 | 紧张/焦虑/我相种子 |

用力过猛的多重失效机制详见 [熏习机制与"用力"观](./熏习机制与"用力"观.md) §四。

### 精进 vs 蛮力 / 恶勤

- **蛮力**：力大但方向不清——可能蛮力修恶（追求名利的精进式工作）
- **恶勤**：方向上是不善——窥基明示"于恶法中不名精进，名为恶勤"
- **精进**：方向上是善 + 力来自勇悍而非紧张

这又一次印证唯识的一个通则：**机制中性，方向决定善恶**——同一种"用力"结构，方向是善则成精进，方向是恶则成恶勤。

## 五、三品精进（经典分类）

经典出处：《瑜伽师地论·菩萨地》、《大乘庄严经论》、《入菩萨行论》精进品。

### 三品定义

| 三品 | 梵文 | 体性侧重 |
|---|---|---|
| **披甲精进** | saṃnāha-vīrya | 发心立誓——"如战士披甲上阵，纵经无量劫不退" |
| **摄善法精进** | kuśala-saṃgrāhaka-vīrya | 自利积累——持续修学六度万行的精进 |
| **饶益有情精进** | sattvārtha-kriyā-vīrya | 利他实践——为利益众生而行的精进 |

### 三品的内在结构

不是时序排列，是**精进在三个不同层面的完整运作**：

```
              披甲精进（发心层 / 因相）
                      ↓ 锚定方向并赋予跨劫承担力
        ┌─────────────┴─────────────┐
        ↓                             ↓
   摄善法精进                    饶益有情精进
   （自利积累）                  （利他实践）
   六度万行                       亲子、利他、布施
```

- **披甲**是"因"——精进的发心种子，赋予后两品**跨劫不退**的属性
- **摄善法 / 饶益有情**是"现行"——精进在自利和利他两侧的具体展开

三品**同时 cultivate**，不是修完一品再修下一品。

### 披甲精进的"长劫不退"机制

大乘成佛 = 三大阿僧祇劫修行——这要求精进有**跨世的承担机制**。但凡夫的常识立刻反问：来世忘失（隔阴之迷）了怎么算"不退"？

唯识给出的本体论支持有三层：

1. **阿赖耶识相续**——它"恒转如瀑流"，跨越死生不中断（"去后来先作主公"），是种子的跨世载体
2. **种子等流果**——善种子越强，遇缘越易再现行；不需"记得"，种子势力本身驱动相应行为倾向
3. **大愿熏习正反馈**——大愿提供方向种子，披甲精进提供动力种子，互熏成跨劫种子流

**关键辨析：不退 ≠ 不忘**

| | 凡夫直觉理解 | 唯识实际机制 |
|---|---|---|
| 跨世传递的是 | 意识层面的记忆 | 阿赖耶识中的种子势力 |
| "不退"指 | 我记得自己发过愿 | 种子势力跨世不消减 |
| 现量表现 | （不可能——隔阴之迷必然忘失） | 来世表现为"性格"、"倾向"、"对某些教法的天生亲近" |

披甲精进的"不退"运作于种子层，不运作于记忆层——这是它能与隔阴之迷并存的本体论根据。

### 染疑攻击披甲基础的具体机制（2026-06-04 回填）

> **登记修正**：原触发点登记为"随烦恼·疑学完后"——但疑是**根本烦恼**第五法，不是随烦恼。本节根据 [疑.md §五](../烦恼心所/疑.md) 完整回填。

#### 披甲精进的根本所缘 = 对修行道路的根本信心

| 维度 | 内容 |
|---|---|
| **道可行** | "这条道路可以走通" |
| **我可行** | "我能走通" |
| **功不唐捐** | "所投精进有意义" |

#### 染疑的攻击点——攻击修行**前提**，不是修行**过程**

| 染疑攻击模式 | 攻击对象 | 杀伤路径 |
|---|---|---|
| "这一切机制是真的吗？" | 佛法真实性 | 道可行 → 崩 |
| "我这种根器走得通吗？" | 自我可塑性 | 我可行 → 崩 |
| "这么多年修行有什么用？" | 功不唐捐 | 所投意义 → 崩 |
| "搞不清是不是自我安慰" | 修行 vs 心理学的混淆 | 整体框架 → 崩 |

→ 染疑的杀伤力关键在**让"善品不生"**——披甲的根本所缘（修行道路）被动摇后，精进无所附丽。这是为什么疑被列五钝使第五 —— 它是**"基底破坏型烦恼"**，比单纯贪嗔的局部杀伤更深。

#### 反向加固路径

| 对治路径 | 机制 |

| **空性见反向加固** | "了无自性" → 染疑攻击的"实有性"前提被消解 |

### 与世俗"长期主义"的区别

| | 世俗长期主义 | 披甲精进 |
|---|---|---|
| 时间尺度 | 数年至一生 | 跨劫 |
| 锚定对象 | 个人 / 组织目标 | 菩提心 + 空性见 |
| 退失风险 | 高（情境变化 / 死亡截断） | 低（依种子相续，跨世不失） |

世俗长期主义的天花板是一生，披甲精进的天花板是成佛——尺度差不是夸张，是基于种子相续 + 业果跨世两个唯识基本立场的严格推论。

| **摄善法精进** | 🟡 起步期——百法学习 + 即将启动的坐中修 | 当前主战场——闻思 + 实修双轨 |
| **饶益有情精进** | 🟡 已有现成场域——亲子教育 = 末那对治 + 饶益场 | 不需另起，深化现有场即可 |

**核心操作含义**：精进起步时不需"先培养使命感"——披甲种子已在，当前任务是让摄善法精进的现行频次稳定起来。这与 §三 "3-4 周点燃曲线" 一致——披甲是已熏的强种子，摄善法是当前需要密集现行激活的环节。

### 饶益有情精进的具体形态

饶益有情精进是三品中**最直接外显**的一品——精进在对他人实际利益行为上的具体展开。

**经典依据**：《瑜伽师地论·菩萨地》给出菩萨饶益有情的**十一相**——

1. 助他作正义事业
2. 救他诸苦难
3. 教他世出世法
4. 报恩
5. 看护怖畏者
6. 救他丧亲、丧财等忧
7. 给乞索者所需
8. 摄受亲眷令处善法
9. 随他心意（不强加）
10. 真实赞叹
11. 折伏（必要时）

注意第 9、11 条的张力——**饶益不是无条件顺从**。"随他心意"和"折伏"并列，说明饶益有情有**精细的判断维度**：知道什么时候顺、什么时候摄、什么时候折。

#### 亲子教育作为现成的饶益场

修行者画像中已识别**亲子教育 = 末那对治 + 饶益场**。亲子教育在饶益有情中有**结构性的特殊地位**——它把饶益所需的所有能力同时考验：

| 维度 | 饶益有情对修行者的考验 | 亲子场域的具体形态 |
|---|---|---|
| 持续性 | 不是一次性善行，是日复一日的承担 | 终生不可中断的关系 |
| 不能挑选所缘 | 真正的饶益要面对"具体这个人" | 孩子是给定的，不能换 |
| 末那对治 | 利他过程中"我"会反复跳出来 | 亲子是末那最易暴露的场（占有 / 控制 / 投射 / 比较 / 报偿型我执）|
| 细颗粒判断 | 需要"随他心意"vs"折伏"的精细切换 | 育儿每天都在做这种判断 |
| 慈悲的真实性 | 经得起对方"不配合"的考验 | 孩子常常不配合 |

**结构性结论**：亲子教育不是"日常生活中的修行机会"，是**饶益有情精进最完整的训练场**。

#### 饶益的"精细判断"维度

饶益有情精进**不是单纯的善意 + 用力**——而是**多个心所协同**：

```
慈悲（驱动） + 慧（判断对方真正需要什么）
   ↓
具体行为
   ↓
精进（持续承担，特别是对方"不配合"时）
```

少了慧的饶益变成强加，少了精进的饶益变成三分钟热度。亲子场常见两种偏差：

| 偏差 | 表现 | 缺失环节 |
|---|---|---|
| 强加型 | "我都是为你好" | 慧（"随他心意"原则）+ 末那觉知 |
| 放任型 | "尊重孩子选择"任凭走偏 | 精进（必要时折伏的勇悍）+ 慧（识别介入点）|

健康的饶益是**两者的动态平衡**——大部分时候随他心意 + 关键节点折伏（不是用力，是有勇悍二相做后盾的真实表态）。

#### 饶益有情 ↔ 披甲精进的衔接

饶益有情如果只在此世此刻看，会消解为"做个好父母 / 好朋友"。**披甲精进给饶益有情提供跨劫的承担尺度**：

- 不只为这一世孩子的福祉
- 是把孩子（以及一切有情）置于跨劫菩萨道的尺度
- 因此对孩子的真正"利益"是让 ta 也熏成善种子、跨世遇佛缘——不只是此世幸福

这给亲子教育一个**深层修行学含义**：**亲子互动中你熏给孩子的不是知识或习惯，是种子**——你怎么对 ta，ta 跨世带走的种子配置就怎么。"言传身教"在唯识下不是比喻，是字面的种子互熏。

## 六、与其他善心所及别境的协同

### 信 → 欲 → 精进的衔接机制

经典明示：[信](./信.md)的"业用"之一是发"乐欲"。这条衔接展开如下：

```
信（心净 → 对实德能的胜解）
  ↓ 自然引发
欲（朝善法方向的趋向）
  ↓ 需要胜解的"细颗粒"层稳固
精进（勇悍承担持续推动）
```

### 关键发现：胜解的颗粒度

经典给出的诊断框架是"欲 → 胜解 → 念 → 定 → 慧 → 精进"链条（详见 [从欲到精进](../别境心所/从欲到精进：修道动力如何形成.md)）。但实践中发现，**胜解本身有颗粒度问题**：

| | 粗颗粒胜解 | 细颗粒胜解 |
|---|---|---|
| 内容 | "修行有价值" | "实修这个具体形式如何熏种、为何零散短时也算真修、与闻思如何正反馈" |
| 来源 | 信的早期就可有 | 需深入唯识框架（尤其种子-现行机制）才能形成 |
| 作用 | 告诉你"该修" | 告诉你"现在这个形式就是修" |

**深层胜解强不代表浅层（操作层面的胜解）也强**。当细颗粒胜解缺位时，深层胜解会被"等准备好再说"消解——这时看起来像"精进弱"，实际是上游胜解未稳。

**给"动力链诊断顺序"加一条新规则**：检查胜解时不能只问"信不信修行有用"，要问"对当前可执行的具体形式信不信它就是修"。

### 与定的同步成就关系

精进的任运化与定的等持成就**同步发生**——见上文 §三"九住心配六力四作意"。这意味着：

- 修精进 = 修定（同时进行，不能分开）
- 定的进展程度 = 精进任运化的进展程度
- 精进的彻底任运需要等持成就为前提

### 与不放逸 / 行舍的关系：善心所内动力组三法分工

#### 三法的经典定位

| 法 | 经典定义 | 体性核心词 |
|---|---|---|
| **精进** | 于善恶品修断事中勇悍为性，对治懈怠，满善为业 | 勇悍 |
| **不放逸** | 精进三根（无贪 / 无嗔 / 无痴）于所断修，防修为性，对治放逸，成满一切世出世间善事为业 | 防修 |
| **行舍** | 精进三根令心平等正直无功用住为性，对治掉举，静住为业 | 平等正直无功用 |

**关键观察**：不放逸和行舍的定义都以"**精进 + 三善根**"为体——它们不是独立的心所，是**精进与三善根协同后的特定功能模式**。

#### 三法是同一动力机制的三种形态

```
        精进（核心动力）+ 三善根（方向校准）
                    ↓
        ┌───────────┼───────────┐
        ↓           ↓           ↓
   主动推进      防失保护      平稳安住
    （精进）     （不放逸）    （行舍）
   修善 + 断恶   防恶 + 修善    无功用住
   勇悍二相      警觉 + 持续    平等 + 正直
```

| 法 | 方向 | 时机 | 体感 |
|---|---|---|---|
| **精进** | 主动 | 起手 + 持续推进 | 勇悍——有"用力"质感（加行期）|
| **不放逸** | 守护 | 已起善 / 待起善的防失保护 | 警觉——有"看着"的质感 |
| **行舍** | 平稳 | 已稳态后的无功用维持 | 平正——无"用力"亦无"看着"的质感 |

#### 三法对应修行的三个递进阶段

三法**不是平行选项，是修行进展的三个递进阶段**：

```
起步期：精进为主
   ↓ （建立动力）
熟习期：精进 + 不放逸
   ↓ （加入守护，防止已熏种子退失）
任运期：行舍为主（精进与不放逸隐入背景）
   ↓ （进入无功用住）
```

这与 [§三 加行 → 任运过渡](#三加行精进-vs-任运精进) 严格同构：
- **加行精进** ≈ 主动用力的精进（"勇悍"突出）
- **任运精进** ≈ 行舍（"无功用住"是其完整形态）

**关键发现**：行舍是精进的成熟形态，不是精进的对立面。**修精进的最终目的就是修到行舍**。

> **任运期内部三相精细化**（2026-05-16 加）：行舍正式学习中 推出 任运期内部为三相 轴 sequence（平等 振幅 → 正直 方向 → 无功用住 用力 后位），"行舍 = 无功用住"是任运期成熟态的粗化 标签；部分 显现 诊断时需精细到三相 轴。详见 [行舍.md §五 transition 机制 + §0.3 三相 轴 结构](./行舍.md)。

#### 三法 vs 九住心配六力四作意

把三法放回 [九住心曲线](#经典对应九住心配六力四作意)：

| 九住心阶段 | 主导心所 | 体感 |
|---|---|---|
| 内住、等住（力励运转） | **精进** | 强加行，反复拉回 |
| 安住、近住（有间缺运转） | **精进 + 不放逸** | 加行渐降，开始有"守"的功能 |
| 调顺、寂静、最极寂静、专注一趣（无间缺运转） | **不放逸为主，精进退居** | 守护已成的稳定 |
| 等持（无功用运转） | **行舍** | 无功用住，三法浑然一体 |

九住心的成就过程**就是三法接力的过程**。

#### 三法与已学内容的更深贯通

- **与勇悍双时点**：精进的"勇 / 悍"在不放逸阶段转为"守 / 持"，在行舍阶段转为"无功用平等"
- **与熏习卫生学**（[熏习机制与"用力"观](./熏习机制与"用力"观.md)）：行舍是对"用力过猛 = 反向熏种"警告的最终回应——修行成熟态本身就是"无功用"
- **与假说 8**（修行是种子显化非意志施加）：行舍正是这个假说的体性体现——修到任运时，精进显化为无功用，意志退出
- **与披甲精进**：披甲精进发心稳定后即转入行舍式承担——发心是基态，不是每天重发

#### 修行者画像对接

| 三法 | 当前状态 | 起步路径 |
|---|---|---|
| **精进** | 🟡 起步期——刚补齐胜解，准备启动每日坐 | 当前主战场，盯频率 + 勇悍二相是否在场 |
| **不放逸** | 🔴 暂未到该阶段 | 待精进稳定 2-3 周后自然涌现 |
| **行舍** | 🟢 部分种子已熏（早年禅定 + 空性见底子）| 不需主动培育，激活休眠种子的过程会自然导向 |

**反直觉提示**：修行者**不应跳过精进直奔行舍**。

虽然修行者有早年禅定底子，行舍种子已熏，但**这一世的现行链条还没建立起来**。直接尝试"无功用住"很容易变成放任、散乱（因为没有精进作为下层支撑）。**正确路径仍是从精进起步——不放逸自然涌现——行舍自然成就**。

> 行舍是精进成熟的果，不是精进的替代品。早年禅定底子让这个过程能更快走完，但不能跳过。

#### 三法分工的修行实义

三法的存在告诉修行者**修行的三个不同阶段需要不同的心所配置**：

- 起步期硬要"无功用"——是放任（没有精进的勇悍做下层）
- 任运期硬要"勇悍"——是干预（行舍的成熟阶段不需要意志介入）
- 熟习期硬要单纯"精进"——是不放逸缺位的精进，易疲劳易退失

> **修行的智慧不是选一种心所修到底，是知道当前阶段该让哪种心所主导**。

> **学术诚实标注**：
> - 第一层：三法经典定义、不放逸 / 行舍的"精进三根为体"立场、九住心配六力四作意——皆经典立场
> - 第二层：把三法整合为"精进的三种形态"、三阶段递进表、三法配九住心阶段对应——基于经典文义的整理性表述
> - 第三层：修行者三法配比的具体评估、"不应跳过精进直奔行舍"的警告——基于本项目假说网络的延伸推论

> 不放逸 / 行舍的完整体性展开见各自的单法笔记——本节侧重三法分工与精进的关系。

## 七、在三十七道品中的位置与经典精进观的多元呈现

精进在三十七道品中以多重身份出现——四正勤、四如意足、五根五力、七觉支、八正道——是三十七道品中**唯一在五个分类中均独立列出的善心所**，可见其在整个修行论中的核心地位。本节展开各经典框架对精进的不同切面呈现，最后归结为同一本体论曲线。

### 四正勤 = 善法欲 × 精进

三十七道品中四正勤对应**欲 → 精进**的发起侧：

1. 已生恶令断
2. 未生恶令不生
3. 未生善令生
4. 已生善令增长

四正勤本质是用善法欲指方向，用精进承担持续推动——是"勇悍为性"在四个方向上的具体展开。

### 四如意足

四如意足提供更稳定的支撑：**欲（chanda）、勤（vīrya）、心（citta）、观（mīmāṃsā）**——恰好对应别境心所的核心机制（欲、精进、定、慧），是修定成就的四足。

精进作为四如意足之一，在这里起的是"承担"作用——其余三足都需要精进的持续推动才能稳固。

### 五根五力中的精进根 / 精进力

经典出处：《杂阿含经》、《俱舍论》、《瑜伽师地论》。

**五根**（pañcendriya）：信根、精进根、念根、定根、慧根
**五力**（pañcabala）：信力、精进力、念力、定力、慧力

#### 根 vs 力 的本质区分

| | **根** | **力** |
|---|---|---|
| 体性 | 能生善法的初步势力 | 不可被违缘破坏的稳固势力 |
| 状态 | 还可被违缘动摇 | 不被外境所夺 |
| 阶段 | 修行起步—中段 | 修行成熟 |

**根 → 力 是同一种心所势力的两个发展阶段**——种子从弱到强、从可破到不可破的过程。

#### 五根五力的内在协同链

```
信根 → 信解 → 引发善法欲 → 起精进根
精进根 → 持续推动 → 念清晰
念根 → 心安住 → 定根
定根 → 心明 → 慧根
慧根 → 简择 → 反过来增强信根（下一轮循环）
```

这正是 [从欲到精进](../别境心所/从欲到精进：修道动力如何形成.md) 中讨论的动力链 + 一个反向回路。

#### 信根 → 精进根的具体衔接机制

```
信根（对三宝、四谛、业果的胜解）
    ↓ 引发善法欲
欲（朝善法方向的趋向）
    ↓ 在胜解的细颗粒层稳固后
精进根（勇悍承担推动）
```

衔接的本体论：

- **信是"心净"——提供方向与动力源**
- **精进是"勇悍"——提供具体推动**
- **信不立 → 精进无所依**（变成蛮力或恶勤）
- **精进不立 → 信不能落实**（变成空泛信仰）

这与本笔记 [§六"信→欲→精进的衔接机制"](#信--欲--精进的衔接机制) 完全一致——五根五力给出的，是同一动力链的另一个经典命名。

#### 修行者画像的五根五力评估

| 五根 | 当前状态 | 五力（即将稳固到不可破）状态 |
|---|---|---|
| **信根** | 🟢 稳——三层锚点（现世可验证 / 早年内化 / 种子层）| 🟢 信力面对染疑挑战守护已结构性建立——五层守护机制 + 元层兜底（2026-06-04 疑学完后回填检验完成，详见 §五"染疑攻击披甲基础的具体机制"小节）|
| **精进根** | 🟡 起步期——刚补齐胜解 + 准备启动每日坐 | 🔴 精进力未到——当前现行链未稳定 |
| **念根** | 🔴 弱——实修未起步，念的频次不够 | 🔴 同上 |
| **定根** | 🟢 有底子——童年 10 年禅定（种子层） | 🟡 待激活——需要密集现行重建到力的程度 |
| **慧根** | 🟢🟢 强——本项目核心特质 | 🟡 慧力部分有（多年闻思的稳定胜解），但**修慧层尚未达到力的程度**（依赖定基与现量验证） |

**关键观察**：修行者五根的不平衡为 **慧根 >> 信根 > 定根 > 精进根 ≈ 念根**。经典反复强调五根五力要均衡发展——慧偏强易堕"狂慧 / 戏论"，正是修行者画像中"智识贪 / 法执散乱"的潜在风险。

清晰的修行学诊断：**不需培养信、慧（已强），需要的是用密集的实修把精进根 / 念根 / 定根的现行链建立起来**。这与"实修起步期 3-4 周密集频率"的设计完全契合。

### 《入菩萨行论》精进品的展开

寂天菩萨在《入菩萨行论》第七品（精进品）给出大乘修行者的完整精进操作论。其核心架构有两组：

#### (a) 懈怠的三种形态——精进的对治对象

| 三种懈怠 | 表现 | 对应"勇悍双时点"失败模式 |
|---|---|---|
| **推延懈怠** | "现在没空，等下"——时间上的拖延 | 勇缺位（不能跨过起手门槛）|
| **耽劣懈怠** | 沉迷睡眠 / 娱乐 / 闲谈 / 五欲 | 悍缺位（中途被外缘拉走）|
| **自轻懈怠** | "我不行 / 这条路太长 / 我哪能成佛" | 勇的深层缺位（自我否定层面的怯弱）|

#### 寂天的对治方法 + 与本项目的对接

| 懈怠 | 寂天对治 | 本项目对接 |
|---|---|---|
| 推延 | 观死无常 + 观人身难得 | 加强对修行价值的细颗粒胜解 |
| 耽劣 | 观轮回过患 + 观善果功德 | 与"AI 探索吞噬时间"的 切分 对治同构 |
| 自轻 | 观佛性 + 观成就者也曾是凡夫 + 一切众生都能成佛 | **与假说 5（新学不存在）严格同构**——不是"我天生不够"，是种子当前未被激活 |

**值得记录的发现**：寂天的"自轻懈怠"对治直接命中假说 5。这是经典中"潜在种子学"的清晰先驱——寂天在 8 世纪给出的"成就者也曾是凡夫"的教导，本质上是说**当前与佛果的差别不是种类差别，是种子势力强弱差别**。这对修行者而言是非常具体的反自轻武器。

#### (b) 精进的四力——精进的所依资源

| 四力 | 寂天功能定位 | 本项目对接心所 / 文档 |
|---|---|---|
| **信解力**（mos pa'i stobs） | 通过观利益与过患，生起胜解 | [信](./信.md) + 胜解的细颗粒 / [熏习机制](./熏习机制与"用力"观.md) |
| **坚毅力**（brtan pa'i stobs） | 发心做某事至完成不退 | 不放逸 + 早期行舍 / [§六 三法分工](#与不放逸--行舍的关系善心所内动力组三法分工) |
| **喜悦力**（dga' ba'i stobs） | 像孩童玩耍般地修行 | 善法欲 + 信德"乐"支 / [信](./信.md) |
| **放舍力**（btang ba'i stobs） | 疲劳时暂歇恢复 | 熏习卫生学的"散乱厚重时主动起座调整" / [熏习机制](./熏习机制与"用力"观.md) §四 |

#### 喜悦力与冷质地修行者的对接

寂天说"如孩童玩耍般"——这是**热质地**。但修行者画像中信德是**冷质地**。如何对接？

**喜悦力不必是热的**。冷质地的修行者也可以有：
- **沉静的喜悦**——对法的"安住式"满足感
- **结构性的认可**——"这个机制本应如此"的深沉满足
- **任运的轻松**——胜解到位后修行不再是负担的体验

寂天的"如孩童玩耍般"是个比喻，强调的是**无勉强、无对抗**——这与冷质地的"任运基态"实质上同义，只是表达温度不同。理性派修行者不必勉强模仿热血风格——保持自己的冷质地，让喜悦在沉静中现起。

### 一个深刻的同构

五根 → 五力 + 加行 → 任运 + 九住心 + 披甲长劫不退 + 寂天四力 — **全部是同一种本体论曲线在不同框架下的命名**：

> **种子势力的累积成熟过程：从弱可破 → 中度稳定 → 强而不可破。**

唯识从未"发明"这个过程——它只是把这个过程**显化为一个统一的本体论结构**（种子-现行机制）。各修行框架（四正勤、四如意足、七觉支、八正道、五根五力、三十七道品、九住心、入菩萨行论的四力）都在同一个本体论结构下描述同一个过程的不同侧面。

| 框架 | 描述的角度 |
|---|---|
| 五根 → 五力 | 五个心所维度的种子从可破到不可破 |
| 加行 → 任运 | 意志介入度从高到低的过渡 |
| 九住心 | 定的成就过程（前八住基本对应五根，第九住对应五力的稳态） |
| 披甲长劫不退 | 跨世种子相续的最终不可破态 |
| 寂天四力 | 大乘修行者操作精进的四种心所资源 |

**修行者只需修一种修行**——任选其中一框架深入，其他框架自动同步推进。这是经典如此多元但本质统一的根据。

> **学术诚实标注**：
> - 第一层：四正勤、四如意足、五根五力、《入菩萨行论》三种懈怠 + 四力——皆经典立场
> - 第二层：寂天三种懈怠对应勇悍双时点、四力对应已学心所、修行者五根五力评估表——基于经典的整理性映射
> - 第三层：寂天自轻对治与假说 5 的同构、"喜悦力可冷可热"的修行者画像对接、"五根→力 / 加行→任运 / 九住心 / 披甲 / 寂天四力是同一本体论曲线"的元论断——延伸推论

## 十、学习心得

### 理解要点

- 精进只限于善法，做坏事再努力也不是精进——叫"恶勤"
- "精"是纯粹，"进"是前进——纯善地向前迈进
- 真正度量不是用力大小，而是**勇悍二相是否都现起**
- 加行 → 任运是经典认证的修行轨迹，不是发明
- 修精进 = 修定（同步发生）

### 理解难点

- 精进与执着的界限——本质区别在驱动来源（善法欲 vs 贪结果）
- 任运不是"不用力"——是不用"咬牙的力"
- 用力过猛实际是掉举，不是精进——这是修行最易混淆的一对
