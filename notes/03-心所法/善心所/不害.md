## 一、概念定义

### 原文

**[《成唯识论》](../../../resources/cards/《成唯识论》.md)卷六**(完整版):

> 云何不害?于诸有情不为损恼,无嗔为性。能对治害,悲愍为业。**谓即无嗔于有情所不为损恼,假名不害。此无别体,由无嗔故,于有情所不为损恼,假立此名**。

### 白话解释

不害是对一切有情众生不去损害、恼乱。**它的[体性](../../../resources/cards/体性.md)就是无嗔本身,不是独立的心所体** — 无嗔在"对有情这一特定[所缘](../../../resources/cards/所缘.md)"上的功能展开,经典上"假立"(借用一个名字单独称呼)为"不害"。能对治害(随烦恼),以悲愍众生为[业用](../../../resources/cards/业用.md)。

**"假立无别体"的精确含义**:不害在现行时是真实可观察的功能,但**没有独立于无嗔之外的体性**。类比:火能照、能熟物、能取暖,"取暖"是火的功能之一,可以独立命名为"暖",但暖没有独立于火的体性。不害对无嗔的关系同此。

### 梵文/巴利文
- **梵文**: ahiṃsā
- **音译**: 阿醯爀娑
- **词源**: a（无、非）+ hiṃsā（伤害），意为不伤害

---

## 二、详细说明

### 核心特征
1. **体性 = 无嗔**:不是新的、独立的心所体性
2. **行相 = 于有情不损恼**:无嗔在"对有情这一特定所缘"上的功能展开
3. **业用 = 悲愍**:见众生苦而心不忍
4. **假立无别体**:经典明文"此无别体,由无嗔故...假立此名"

### 作用与功能

**业用"悲愍"的两层结构**:

| 面向 | 含义 |
|---|---|
| **消极面**(不损恼)| 不对任何众生造成身心的损害和恼乱(避免造作)|
| **积极面**(悲愍)| 见众生苦而心不忍(主动的不忍伤害)|

→ 二者协同 → 进一步可发展为**大悲心**。但不害本身只是悲心的**基础**,不等于悲心(更不等于大悲) — 后者属于行为造作 + 慧的复合,远超不害一法的范围。

### 与无嗔的精确分工(核心理解)

| 项 | 无嗔 | 不害 |
|---|---|---|
| **所缘** | 苦 + 苦具(广义,含逆境/苦境/损己之人事)| **专缘有情** |
| **对治** | 嗔(根本烦恼)| 害(随烦恼)|
| **业用** | 不恼(不起忿恚)+ 乐善行 | **悲愍**(积极不忍其苦)|
| **方向** | **自己面对苦境不起忿** | **对他人不去损恼 + 不忍其苦** |
| **体性** | 善心所根本体(三善根之一)| **假立,无别体** |

→ 一个粗略表述:**无嗔是体,不害是用** — 无嗔在"于有情这条所缘上"的展开就是不害。

### 生起条件
- 无嗔心所的生起(作为体性前提)
- 对众生苦难的感知(所缘条件)
- 同理心的培养
- 认识到一切众生皆有[佛性](../../../resources/cards/佛性.md)

## 三、与其他概念的关系

### 上位概念

### 下位概念

### 相关概念
- **相似概念**: 无嗔（不害是无嗔的一分，但侧重点不同）
- **对立概念**: 害（随烦恼心所）
- **协同概念**: 无嗔（不害依无嗔而立）、慈悲（不害是悲的基础）

### 关系图示

**与无嗔的展开关系**:
```
无嗔（于苦苦具无恚）
  ├→ 对治嗔恚（对自己面对逆境的反应）
  └→ 不害（对他人不损恼）
       ↓
    悲愍为业 → 大悲心(更上位,需慧合)
```

**与"害"的镜像对应结构**(关键经典立场):

```
嗔(根本烦恼) ←—对治—→ 无嗔(根本善)
   ↓ 一分                  ↓ 一分
害(随烦恼)  ←—对治—→ 不害(假立善)
```

→ 经典上之所以一定要把不害单独列出,**部分原因在于:要与"害"作为随烦恼的独立位置对应**(随烦恼里嗔系展开为忿、恨、恼、嫉、害等多条,善法侧也要有对应的对治细分)。更深的理由(为何独立列入 11 善心所)见 §四 修行学定位。

## 四、修行学定位:为何独立列入 11 善心所

经典明文承认不害是无嗔一分 + 假立无别体(《成唯识论》卷六:"此无别体,由无嗔故...假立此名"),但仍要独立列入 11 善心所。原因有三层,层层递进。

### 1. 与"害"的对偶完整性(浅层)

随烦恼中嗔系展开五项:**忿 / 恨 / 恼 / 嫉 / 害**。其中"害"是"于有情损恼为性" — 专门针对"对他人造成损害"。经典在善法侧需要对偶位置专门对治"害"。

→ 但这层只解释"为什么要有对治结构",**还没解释为何不能合并到无嗔下**(无嗔已对治嗔了)。需要更深一层。

### 2. 大乘 — 利他面的独立位置(核心)

11 善心所有一个隐含的功能分区结构(基于 [惭愧合论 §二](./惭愧合论.md) 与已学心所累积分判):

| 面向 | 善心所 |
|---|---|
| 信仰 / 锚定 | 信 |
| **守护面**(断恶 + 修善 + 双线接合)| 惭 / 愧(断恶线刹车)+ 精进(修善线动力)+ 不放逸(双线接合) |
| 反应面([三善根](../../../resources/cards/三善根.md))| 无贪 / 无嗔 / 无痴 |
| 任运面 | 轻安 / 行舍 |
| **利他面** | **不害** |

**关键论证**:

- 无嗔的主战场 = "自己面对苦境不起忿恚" = **自调伏面**
- 不害的主战场 = "对有情不损恼 + 悲愍其苦" = **利他面**
- 二者修行学方向不同 — 一个内向调伏,一个外向饶益

→ **不害是 11 善心所中唯一**"专缘有情、专为利他"的心所。如果没有不害,11 善心所中**没有专门面向众生的位置** — 这与大乘的根本方向(菩提心 / 慈悲愿 / 利他)严重不符。

→ 经典即使明知不害是无嗔一分、假立无别体,**仍要把它独立列出**,因为大乘修行学必须把利他面作为独立位置识别。**这是 [假说 15 v3+ 已闭合](../../假说/假说-15-anchor二阶二维-已闭合.md) 第五层(利他面)的精确经典依据,且为 5/18 闭合的最后验证心所**。

### 3. 唯识学方法论根本:分类按修行学操作价值,不按体性独立性(最深层)

修行者 2026-05-18 提示的关键论证 — 这层把"为何独立"从"经典原则"上升到**唯识学方法论根本**。

在 [唯识与物理学—种子因果的世界模型 § 两门学科的精确性](../../02-心法/唯识与物理学-种子因果的世界模型.md) 中已建立的立场:

| | 物理学 | **唯识学** |
|---|---|---|
| 目标 | 预测物质世界的行为 | **理解心识运作,指导修行,实现解脱** |
| 精确性标准 | 定量预测与实验数据的吻合度 | **修行方法的可操作性、阶段判定的明确性** |
| 在对方领域的表现 | 无法指导修行 | 无法计算物理参数 |

**直接推论**:

在唯识学的目标(理解心识 + 指导修行 + 实现解脱)框架下,**心所的分类必然以修行学操作价值为标准,而不是以"体性是否独立"为标准**。

- "体性是否独立"是**形而上学维度**的精确性标准 — 这不是唯识学的精确性维度
- "**修行学操作价值**"才是唯识学的精确性维度 — 不害在此维度上完全独立(利他面的修行学操作有独特性 + 大悲心基础)

→ 经典"假立无别体 + 仍独立列入"看似矛盾,实际上反映的是**唯识学按修行学维度分类的内在逻辑** — 在修行学维度上,功能独特性比体性独立性更根本。

**这层论证同时解释了 11 善心所中所有假立心所的独立位置**:
- 不放逸(精进 + 三善根假立)— 守护面双线接合的修行学操作价值
- 行舍(精进 + 三善根假立)— 任运面的修行学操作价值
- 不害(无嗔假立)— 利他面的修行学操作价值

三者均"假立无别体",但都独立列入 — **正是唯识学方法论按修行学维度分类的内在逻辑的具体体现**。

### 修行学含义

**不害的独立位置反过来定义了 11 善心所的完整功能结构** — 一个完整的善心所配置必须**同时具备**:

- 信仰 / 锚定面(信)
- 守护面(惭/愧 + 精进 + 不放逸)
- 反应面(无贪/无嗔/无痴)
- 任运面(轻安/行舍)
- **利他面(不害)**

→ **缺不害 = 没有利他面 = 不能成立大乘善心所配置**。

这是不害作为"大悲心基础"的精确机制 — 不是说不害本身就是大悲心,而是**没有不害就无从建立大悲心,因为善心所配置中没有利他面的种子可供累积**。

## 五、修行入路:方便层瓦解 + 究竟层两层结构

不害的修行入路验证了 [假说 14(方便层瓦解普遍性)](../../假说/假说-14-方便层瓦解普遍性.md) 在 11 善心所完整覆盖的最后一法——但其究竟层论证比其他善心所更深,触及大乘菩提心的根本逻辑。

### 1. 方便层瓦解(简化版)

经典中不害(以及与之协同的悲心 / 慈心)的方便层入路有六条主要候选:

| 类别 | 方便层入路 | 经典出处 |
|---|---|---|
| 情感共感型 | 七因果教授(知母 → 念恩 → 报恩 → 慈 → 悲)| [《菩提道次第广论》](../../../resources/cards/《菩提道次第广论》.md)|
| | 自他相换 | [《入菩萨行论》](../../../resources/cards/《入菩萨行论》.md)|
| | 同情共感 / 将心比心 | 阿含 / 部派 |
| 果报驱动型 | 果报恐惧 / 业报论 | 阿含 / 律部 / 业报经典 |
| 身份规范型 | 宗教身份(佛弟子 / 受戒者) | 律部 / 戒律传承 |
| 文化伦理型 | 文化伦理(普世人道 / 印度 ahiṃsā 传统)| 印度 ahiṃsā 文化 / 跨文化伦理 |

**修行者 2026-05-18 判断**:

> 前五条基于修行 / 宗教认同前置条件,不在当代未具[空性](../../../resources/cards/空性.md)见者的讨论范畴内;第六条文化伦理型在**法律约束内基本仍有共识,法律约束外大多数情况已缺乏共识**——与惭愧方便层瓦解情况严格同构。

→ 假说 14 在不害上验证通过(标准范本,无新例外)。详见 [假说 14](../../假说/假说-14-方便层瓦解普遍性.md)。

### 2. 究竟层第一层:慈悲作为大乘根本必然方向

**修行者准备阶段已建立的洞察**(2026-05-18 接入主线 3):

> "在修行路上(菩萨行),'缘起性空',我们在路上经历的事都需要'缘起'。如果缘起的出发点不是'慈悲',那就必然是处于'[我执](../../../resources/cards/我执.md)'的状态,因为缘起的念头区分了'我'和'众生',这就是为什么大乘的究竟必须是悲智双运。"

(出处:[六度详解和深度问答 §为什么大乘必须悲智双运](../../01-准备阶段/六度详解和深度问答.md))

**精确化的论证结构**:

```
任何缘起 →  
  要么落入我执方向(强化"我" / 我所扩张)
  要么落入非我执方向(=消融"我"的方向 = 慈悲方向)

  ↑ 这两个方向是结构对偶,不是"主动选择"
  ↑ 非我执方向必然指向慈悲(无第三选项)
```

**[见道](../../../resources/cards/见道.md)前后都成立,机制不同**:

| 阶位 | 机制 |
|---|---|
| 见道前(凡夫 / 加行 / 修道位)| 修慈悲 = **主动**避开我执 → 通过修来消融我执 |
| 见道后(已[转依](../../../resources/cards/转依.md))| 我执已断 → 慈悲方向**任运现行**(不再需要"修") |

→ 不是"二选一选择慈悲",是**避开我执方向的必然结果**;不是"我们选择慈悲作为修行方法",是**大乘修行的结构必然位置**。

### 3. 大乘路径的整体逻辑(修行者深化洞察)

> "在'我'的对立面修,到最后'我'消失的时候'众生'也消失了。"

这层洞察精确指出大乘修行的根本逻辑结构:

```
凡夫位:                              见道后:                    究竟位:
有"我-众生"分别 →  通过修慈悲消融我执 → "我-众生"分别消失 → 无缘大悲任运
   (有相缘慈悲)                     (转依平等性智)          (无对象的慈悲)
```

**经典对应**:

| 经典立场 | 出处 |
|---|---|
| **[无缘大悲](../../../resources/cards/无缘大悲.md)** | [《大智度论》](../../../resources/cards/《大智度论》.md):"佛大悲于一切众生,从前际、后际、现在际,无...无缘大悲" |
| **[平等性智](../../../resources/cards/平等性智.md)** | 《成唯识论》:见道后末那转为平等性智 = "于自他无差别" |
| **自利利他不二** | [《维摩诘经》](../../../resources/cards/《维摩诘经》.md):究竟位无能利所利之分 |
| **法华一乘** | 一切众生终成佛 |

→ 不害不只是 11 善心所中的"利他面",**是大乘消融我执路径在事件层的具体显现**。

### 4. 佛性内在结构必然孕育让有情解脱(本体论根据)

> "本该如此(佛性)必然孕育着让有情解脱的特性。"

```
佛性 = 心识本来清净的可能(消融我执的方向)
   ↓
消融我执 = 不再有"我"对"众生"的对立
   ↓
→ 佛性必然导向"让一切有情同得解脱"的方向
   = 大乘菩提心的本质 = 不害 / 慈悲 / 大悲的根本所依
```

**经典对应**:
- **众生本具佛性**([《华严经》](../../../resources/cards/《华严经》.md)):"一切众生皆具如来智慧德相"
- **[如来藏](../../../resources/cards/如来藏.md) + 大乘菩提心**:佛性本身就是让一切有情解脱的方向
- **法华一乘**:一切众生终成佛 = 佛性必然导向解脱的展开

→ 这层论证给了大乘菩提心 + 不害的**本体论根据** — 不是经典选择,是佛性内在结构的必然展开。

### 5. 究竟层第二层:不强加作为运作护持机制

凡夫位 / 加行位 / 修道位的慈悲依"我-众生"有相缘,易夹带"我在慈悲"我相 / 我所扩张到众生 — 需要护持机制防止退转。

**护持机制 = 不强加**(不向他人扩张我所):
- 防止"我这么爱你你必须……"(慈的外形 + 我所扩张内核 = 隐性害)
- 防止"我都是为了你好"(悲的外形 + 我所投射内核 = 隐性害)
- 防止"我帮你你应感恩"(施恩 + 我慢内核 = 隐性害)

**详细鉴别点**:见 [无嗔 §七 §7.5](./无嗔.md) "经典识别的'披慈悲衣的隐性害'"。

**与已建立框架的接入**:
- 与 [愧的"不强加"](./惭愧合论.md) 严格同构
- 与 [惭愧合论 §七 末那二维辐射对治](./惭愧合论.md) 严格同构 — 不害 = 末那"我所"对外辐射在利他场的对治
- 与 [假说 12(惭愧末那二维辐射)](../../假说/假说-12-惭愧末那二维辐射.md) 接通
- **运作判准**:真无相缘 / 三轮体空(详见 [无嗔 §七 §7.2-§7.4](./无嗔.md) + [三轮体空概念卡](../../../resources/cards/三轮体空.md))

### 6. 修行学含义

修不害的修行学本质(关键修正):

| 错误理解 | 正确理解 |
|---|---|
| 不害 = 修"对众生好"(有相缘) | 不害 = 修"对治我执"在事件层的具体显现 |
| "我去帮助众生" → 易被末那做成"我是慈悲者"我相 | "在事件层不损恼有情" = 不让我执扩张到伤害有情 |
| 伦理性的不伤害 | **消融我执的修行核心通道之一** |

→ 长期累积 → 我执减弱 → 慈悲范围自然扩大 → 直至无缘大悲。

→ 这层修行学含义把不害从"伦理性的不伤害"提升到**大乘消融我执路径的核心通道**。

### 7. 与已学善心所究竟层入路的同构 + 不害的特殊地位

| 心所 | 究竟层入路 | 末那对治轴 |
|---|---|---|
| 惭 | 本来不应如此(法本如是) | 内向:不固化身份相 |
| 愧 | 敬共业秩序 / 不强加 | 外向:不扩张我所 |
| 无贪 | 不黏着 | 不抓取所缘 |
| 无嗔 | 不忿恚 / 真无相缘 | 不投射我所到苦境 |
| **不害** | **慈悲(根本必然) + 不强加(护持)** | **外向:不扩张我所到利他场** |

→ 11 善心所的究竟层入路在结构上同构 — 都基于"无相 + 不强加"的同一原则在不同心所面的具体显现。

**不害的特殊地位**(2026-05-18 主线 1 + 主线 3 共同立稳):
- 其他善心所的究竟层入路:**修行学操作意义上的方法**
- **不害的究竟层(慈悲方向)**:**大乘修行的结构必然位置 + 佛性内在结构必然展开**

→ 不害不是 11 善心所中"可选的一法",是**大乘根本方向(消融我执 + 佛性展开)的事件层具体显现** — 缺不害则大乘修行的核心通道未建立。

## 六、实例与观察

1. 起责备孩子的脉冲瞬间识破"应该如何"是末那对孩子因缘流的我所扩张——同时升起对孩子因缘流的悲愍 = 不害补偿
2. 说话时注意不用让对方因缘流增加负担的措辞——细颗粒不损恼(B 类)
3. 工作场景中拒绝合作时,识破对方因缘流的独立性,以"对此事的不接受"代替"对此人的拒绝"——不强加的事件层显现

**共业场(对治外向轴扩张)**:

4. 看到他人观点与自己不同时,识破"我应让对方改变"的脉冲——不向他人因缘流扩张我所
5. 公共空间中举止保持不破坏共业秩序——愧 × 不害协同(详见 [愧.md §七](./愧.md))
6. 表达调控:根据对方理解框架调整表达,不强加究竟层框定于凡夫层听众——B 类细颗粒不害(认知层延伸)

**利他面(慈悲根本方向)**:

7. 看到流浪动物受苦,心生不忍,想要帮助——悲愍体性的直接显现
8. 路上避让虫蚁——传统不害例(但需注意不陷入耆那式外相执着,详见 §九 ahiṃsā 比较)
9. 在能力范围内做利他行而不夹带"我是行善者"形象——真无相缘 + 三轮体空(详见 [无嗔.md §七](./无嗔.md))

## 八、学习心得

### 关键洞察

1. **不害不是 11 善心所中"可选的一法",是大乘根本方向的事件层具体显现**——经典立其独立位是为了把大乘"避开我执方向 = 趋向慈悲"这一根本逻辑在心所配置层显化(详见 §四 + §五.3)。

2. **不害的判准在体性,不在外相**——"严厉的行为相 = 违不害" 是初学最大误读。同一外行为相,心所配置不同,业相截然不同。四种组合表(§九)给出精确分判。

3. **究竟层两层结构:慈悲(根本必然) + 不强加(运作护持)**——慈悲是结构必然性(在"我"对立面修的必然结果,见道前后都成立),不强加是事件层运作护持(末那外向轴的具体对治工具)。

4. **"佛性内在结构必然孕育让有情解脱"**(修行者本体论根据洞察)——这条让不害的修行学含义从"应该对众生好"升级为"佛性自身的内在展开"。本来如此,不需另立。

5. **方便层瓦解的标准范本**——耆那式 ahiṃsā 外相严守在当代瓦解,不害成为另一个"借用究竟层 = 当代常规起步路径"的善心所(假说 14 第六例验证)。

6. **凡夫位最大陷阱:伪方便善巧 = 嗔的合理化**(已识破常态化)——经典允许的"严厉"是菩萨位真无嗔,凡夫位"我有理由"多半是嗔的伪装。事件当下四问可作自检。

7. **不害与惭 / 愧的协同结构**:
   - 与惭(亲子场)= 同一空性见在断恶面 / 利他面的双显现
   - 与愧(共业场)= 共享末那外向轴对治原则,大乘利他面双驱动(刹车 + 引擎)

### 修行学含义

- **慈悲不是修出来的,是避开我执方向的自然结果**——不需要"努力慈悲",只需要不抓"我",慈悲方向自然显现
- **修不害 = 修对治末那扩张** = 事件层每次"应该如何"脉冲识破——与惭愧 / 无嗔 / 无痴 / 不放逸 / 行舍诸善心所的修行入路同构
- **凡夫位起步路径**:借用究竟层框定,真实现行累积胜解种子(假说 14 + 假说 11),不通过方便层(已瓦解)

### 与已学心所对照中的特殊性

不害是 11 善心所中**唯一专门面向"利他面"的心所**——其他 10 善心所或对治自心烦恼(无贪/无嗔/无痴/惭/愧/精进/不放逸/轻安/行舍)或确立修行方向(信),不害是唯一明确把"对外面向有情"作为独立面的善心所。这一独立性正是大乘根本方向的事件层落地点。

详见 [§五.7 与已学善心所究竟层入路的同构 + 不害的特殊地位](#7-与已学善心所究竟层入路的同构--不害的特殊地位)。

## 九、疑问与探索

### 已解决

#### 疑问 1 + 2 同源结构:外行为相强硬时,是否违不害?

"为正义而进行的惩罚是否违反不害" + "不害与菩萨的方便善巧如何调和" 实为**同一问题的两面**——表面问"外行为相强硬时是否违不害",实质问"不害的判准在外相还是心地"。

**核心判准:不害判准在体性,不在外相**

不害体性 = 无嗔一分 + 悲愍业用——判准是**事件当下心所配置**,不是外行为强硬与否。

**四种组合表**:

| 心所配置 | 外行为 | 是否违不害 |
|---|---|---|
| 嗔 + 无悲愍 | 严厉 | **违不害**(典型违) |
| 嗔 + 自我合理化"为他好" | 严厉 | **违不害(伪方便善巧——最危险)** |
| 无嗔 + 悲愍 + 智抉择 | 严厉(必要时) | **不违不害**(真方便善巧) |
| 无嗔 + 悲愍 | 不行动(放任) | **可能违不害**(该止恶不止,反让有情造更深业) |

**经典立场**:

- **《瑜伽师地论》卷四十一(菩萨地)**:菩萨持戒 / 开遮原则——心地无嗔、纯为利他、智慧抉择,可以呈现强硬外相
- **大悲商主本生**:杀短矛贼以救 500 商人 + 截断短矛贼造五无间业——经典明文菩萨可以呈现"杀"的外行为相但不违慈悲不害(内心配置真为悲愍 + 智抉择)
- **国王 / 父母断恶**:经典允许,前提是无嗔 + 为对方业果着想

**修行者实操判准**(事件当下四问):

1. 此刻是否有嗔的脉冲?(微细识别)
2. 行为停止后,是否有"出了一口气"的快感?(有 = 嗔伪装态)
3. 行为是否真为对方业果 / 共业秩序?还是为我所扩张?
4. 是否真在用智慧抉择该不该如此 / 力度多大?还是被嗔推着走?

**凡夫位最大陷阱:伪方便善巧 = 嗔的合理化**

凡夫位最常见的违不害形态不是直接的严厉行为,而是**用"我是为他好" / "这是必要的纠正" 包装嗔的现行**。经典允许的"严厉"是菩萨位见地下的真无嗔,不是凡夫位"我有理由所以可以"。

修行者本人在亲子场已识别此陷阱并能常态化看穿(详见 [无嗔.md §十](./无嗔.md) + [教学操作核 01 亲子场无嗔](../../教学操作核/教学操作核-01-亲子场无嗔.md))——核心识破 = "看穿'应该如何'是末那对孩子因缘流的'我所'扩张"。同一识破延伸到惩罚 / 方便善巧场域,机制完全一致。

> **学术诚实标注**:四种组合表是基于唯识"心所配置 → 业相"的精确化(第二层框架映射);"伪方便善巧 = 嗔的合理化作为凡夫位最大陷阱"是第三层推论,但与修行者亲子场现量识破同构。经典明文不害判准在心地不在外相(瑜伽菩萨地 + 大悲商主本生)。

#### 印度 ahiṃsā 传统与佛教不害的异同

**同名不同体——佛教究竟 / 印度耆那为代表的传统 ahiṃsā 偏方便**。

| 维度 | 印度 ahiṃsā 传统(以耆那教为代表) | 佛教不害 |
|---|---|---|
| **判准** | **外相严守**——以"是否造成实际损害"为根本判 | **心地判准**——以心所配置(有无嗔 / 悲愍)为根本判 |
| **典型表现** | 极端外相戒律:出家者扫地恐踩虫 / 戴口罩防误吸微生物 / 不食根菜(挖出杀植) | 不规定外相,看心地是否真无嗔 + 悲愍。可严厉(菩萨方便) / 可不行动 |
| **本体论根据** | 灵魂(jīva)实有 + 业(karma)作物质实体附着——任何外相损害都会染污灵魂 | 一切法缘起无自性 + 业种依心识熏成——外相损害若无嗔无悲愍配置同时现行,业种性质截然不同 |
| **修行学定位** | **方便层**——以外相严守作"应然"锚点(类似惭愧方便层"怕讥嫌") | **究竟层**——直接以心地为锚(类似惭愧究竟层"本来不应如此") |
| **极致表现** | 耆那教苦行至禁食而死(sallekhanā)——彻底切断造业可能 | 菩萨方便示现忿怒相 / 大悲商主杀短矛贼——心地真无嗔则外相自由 |

**两层差别的根本来源**:

1. **业论不同**:耆那"业作实体附着"必然导出外相严守(实体被外行为决定);佛教"业种依心识熏成"必然导出心地判准(心识配置决定业种性质)
2. **空性见的有无**:耆那灵魂实有 → 必须保护此实有不被业污染;佛教缘起无自性 → 关键不在外相而在心识缘起本身
3. **菩萨道的有无**:耆那个人解脱(jīva 解脱)→ 严守外相是单一最优路径;佛教菩萨道需要在染净世间行利他 → 必须有"心地真无嗔则外相可严"的开放空间

**修行学含义**:

- 不要把佛教不害误读为耆那式 ahiṃsā——这会让修行者陷入对外相的过度执着(如"我不能起任何强硬行为否则违不害")
- 但也不要因此过早借用"心地判准"放松外相——凡夫位心地容易被末那做成"我有理由"的伪究竟层
- **修行者本人的位置**:空性见已结构性内化,心地判准可直接运作;但伪方便善巧风险仍在(已识破并常态化)

> **学术诚实标注**:此处"耆那为代表的传统 ahiṃsā 偏方便"是基于"判准在外相 = 方便层 / 判准在心地 = 究竟层"的二阶结构(本项目第三层推论,假说 11 + 假说 14)对印度传统的归类。这一归类反映了佛教内部视角,不代表耆那教自身的自我定位(耆那教视严守外相为究竟法,非方便)。两个传统的本体论根据不同(灵魂实有 vs 缘起无自性),故同名"ahiṃsā"实非同体。

#### [四无量心](../../../resources/cards/四无量心.md)中"悲"与不害的关系

详见 [§五.3 大乘路径的整体逻辑 + §五.5 究竟层第二层:不强加](#五修行入路方便层瓦解--究竟层两层结构) 已实质覆盖:不害 = 慈悲(根本必然方向) + 不强加(运作护持) 在事件层的具体显现;四无量心中"悲"是不害的体性根,不害是悲在事件层的具体运作显现。
