## 一、经典定位与"善之根"的本体论地位

### 1. 经典出处

《成唯识论》卷六：

> 云何无贪？于有有具无著为性，对治贪著作善为业。
> 云何无嗔？于苦苦具无恚为性，对治嗔恚作善为业。
> 云何无痴？于诸理事明解为性，对治愚痴作善为业。

三者作为一组并列于善心所之首，且经文明确以"对治三毒"立体性——这是 11 善心所中唯一与三毒（贪嗔痴根本烦恼）严格对偶的一组。

### 2. "根"的精确含义：A + B + C 统一

为什么是这三个被称为"善之根"，而不是"轻安/惭愧/精进"等其他重要善心所？三个角度统一在"**对治末那我执**"这个核心：

**A. 因果之根（无我前提）**
三善根本质上是**末那"我执 + 我所执"运作的事件级反向对治**——
- 无贪：对治"可意境 → 我所扩张去抓取"
- 无嗔：对治"不可意境 → 我所扩张去抗拒"
- 无痴：对治"所缘 见地 → 末那以我相 强加 颠倒认取"

→ 三善根是**所有善法不被末那 劫持 的"无我"前提**——没有三善根作底盘，其他善心所现行时会被末那做成"染 + 我相"的形态：
- 慧无无痴 = 染慧 / 邪见 / 看穿者我相（[假说 16](../../../CLAUDE.md#跨阶段回填清单)）
- 信无三善根 = 染信（"我有正法善知识"我相驱动）
- 精进无三善根 = 染精进（"我修行进步快"我相驱动）
- 惭愧无三善根 = 染惭愧（"我有道德判断力"我相驱动）
- 慈悲无三善根 = 染慈悲（"我在爱他"我相驱动；详见 [无嗔.md §七](无嗔.md)）

→ 这是它们作"根"的最深含义：**所有善法是否能不被我相 劫持 的前提条件**，不只是某些善法的线性因果上游。

**B. 对偶之根（结构必然性）**
根本烦恼是三毒——三毒不是任意三个烦恼，是末那"我执 + 我所执"的三种 显现（爱→贪、憎→嗔、迷暗→痴）。所以根本对治也必然是**结构对偶**的三个，不能多也不能少。其他烦恼（嫉、慢、疑、忿、恨等）都从三毒衍生，对应的善对治位次更下游。

**C. 通遍之根（遍行性）**
凡善心起必有三善根之全部或部分现行（详见 §五 俱起规则）——否则不是真正的善心，是带我相的假善心。这与遍行心所之于一切心相对应，但限于善心。

### 3. 三个角度统一收敛

A + B + C 都收敛在**对治末那我执**这个核心：
- B 决定为什么必须是这三个（结构必然性）
- C 决定它们必须遍及一切善心（否则非真善）
- A 决定它们对其他善法起的作用（无我前提）

→ 三善根 = **末那运作的事件级反向对治结构**，是经典从修行学角度对"如何不被末那 劫持"的精确建模。

### 4. 学术诚实标注

| 内容 | 层次 |
|---|---|
| 经文（《成唯识论》卷六）| 第一层（经典）|
| "对治三毒"立体性 | 第一层（经典）|
| A + B + C 三角度统一 | 第二层（基于经典框架的整理性重构）|
| 把"我相 劫持 假善法"作为 A 的精确含义 | 第三层（与假说 16 同构的推论）|

### 5. 烦恼方反向验证精确化（2026-05-29 三毒精修学完后）

三毒精修（[痴.md](../烦恼心所/痴.md) / [贪.md](../烦恼心所/贪.md) / [嗔.md](../烦恼心所/嗔.md)）完成后，本节 A 立场（三善根作为末那运作对治）与 B 立场（三毒 = 末那三显现）经反向验证，**结构整体成立但需两处精确化**：

**精确化 1 — A 立场：对治范围在三毒间不对称**

| 善心所 | 经典依据的对治范围 |
|---|---|
| 无痴 | 末那本层（对治我痴 = 恒行不共无明）+ 末那对外扩张（第六识 / 前五识层痴）|
| 无贪 | 末那本层（对治我爱 = 末那相应贪）+ 末那对外扩张（第六识 / 前五识层贪）|
| **无嗔** | **仅对治末那对外扩张的逆境反应**（经典明文：末那四烦恼无嗔——无嗔在末那本层无可对治）|

→ 三善根对治"末那运作"成立，但**对治范围在三毒间结构性不对称**：痴贪贯通末那本层 + 对外，嗔仅对外。这与三毒断位（嗔三果断 vs 痴贪四果断）严格契合，是同一不对称的两面。

**精确化 2 — B 立场：嗔侧表述修订**

原 §一·2B + §二表述"三毒 = 末那'我执 + 我所执'的三种显现（爱→贪、憎→嗔、迷暗→痴）"在嗔侧与经典明文冲突——嗔不通末那（《成唯识论》卷六明文）。

修订后表述：

> **三毒 = 末那"我执 + 我所执"运作的三种染显现，其中**：
> - **痴贪 = 末那本层 + 末那对外**双重显现（我痴恒行 / 我爱恒行作末那本层；同时通过第六识 / 前五识相应起向外显现）
> - **嗔 = 仅末那对外**的逆境反应（末那本层结构上不容嗔——所缘是自内我非逆境，与 §一·2B"末那扩张方向"的对外面严格对应；末那本层无嗔可显现）

这个修订保留原立场核心（三毒都是末那运作的染显现，非任意三烦恼），但纠正了"三毒在末那层对称显现"的过度推论。

**深层结构发现 — 末那所缘性质决定不对称的根本原因**

末那恒缘自内我（第八识见分被执为"我"）。对"我"自身：

- **摄受性烦恼**（爱 / 慢 / 见 / 痴）→ 可在末那本层（自我执取的内在展开）
- **推拒性烦恼**（嗔）→ 结构上不可在末那（推拒自我 = 末那的自我执取自相矛盾）

→ 这与 [假说 12 惭愧末那二维辐射](../../假说/假说-12-惭愧末那二维辐射.md)"我（内向凝聚）/ 我所（外向扩张）"双轴**精确对应**：内向轴的烦恼可在末那本层（贪痴），外向轴的烦恼必在末那之外（嗔）。三毒在末那的不对称 = 末那双轴辐射框架在烦恼方的反向印证。

详见 [三毒整体认知 §七](../烦恼心所/三毒整体认知.md) 三侧闭合总结。

## 二、与三毒的逐项对偶

| 三毒（根本烦恼）| 末那扩张方向 | 对偶善根 | 对治方向 |
|---|---|---|---|
| 贪 | 可意境 → 我所要去抓取 | 无贪 | 不黏不抓 |
| 嗔 | 不可意境 → 我所抗去抗拒 | 无嗔 | 不嗔不害 |
| 痴 | 所缘 见地 → 末那以我相 强加 颠倒认取 | 无痴 | 于诸理事明解 |

**精确对偶关系**：
- 贪与无贪：所缘同（可意境），心识取向反（黏着 vs 不著）
- 嗔与无嗔：所缘同（不可意境），心识取向反（嗔恚 vs 慈和）
- 痴与无痴：所缘同（诸理事），认取方式反（迷暗颠倒 vs 明解如实）

**三毒不是三个并列烦恼，是末那运作的三个 显现**（爱、憎、迷暗）——这是为什么根本对治必须三个，不能多也不能少。

详细对偶分析见各心所笔记：[无贪.md §二](无贪.md)、[无嗔.md §二](无嗔.md)、[无痴.md §二](无痴.md)。

## 三、三善根的三层分工：断恶 / 修善 / 见地

> **重要**：本节的三层分工与 §四 假说 15 v3 的"反应面 vs 锚 面"是**正交关系**，不是同一维度。
> - §三 三层分工 = 三善根（统一作为整体）在他善心所运作时起的**三种作用维度**
> - §四 v3 = 三善根**之间的内部结构**（无贪/无嗔在反应面 + 无痴在 锚 面）

### 1. 断恶层（事件 反应式）

**作用**：三毒现起时，三善根作为直接对治阻断（让其不熏新种子，不形成等流相续）。

**特征**：
- 是 反应式 的——境现起 → 三毒可能现起 → 三善根现行让其消解
- 是事件级的，不是常态运作
- 对应假说 17 的 征兆 层（事件级可观察）

**典型操作**：
- 反应式嗔现起 → 即时识破 → 无嗔现行（[无嗔.md 层 3a](无嗔.md)）
- 贪境现起 → 看穿"可意"是末那 强加 → 无贪现行
- 痴根驱使下的颠倒认取现起 → 锚 升起识破 → 无痴现行

### 2. 修善层（配置 standing）

**作用**：三善根作为底盘配置，让其他善法（信、精进、惭愧、轻安、不放逸等）能起且不被末那 劫持。

**特征**：
- 是 proactive 的——三善根稳态运作 → 其他善法依此起
- 是常态配置层，不限于事件触发
- 对应假说 17 的配置层（other 善法运作的底盘）

**典型显现**：
- 闻思 深挖 通透不被"看穿者我相"劫持（无痴 锚 在场）
- 慈悲行起不被"我在爱他"我相 劫持（无嗔 锚 在场，详见 [无嗔.md §七](无嗔.md)）
- 精进现行不被"我修行进步快"我相 劫持（三善根 锚 在场）

### 3. 见地层（锚 显现）

**作用**：三善根现行 = 无我见地的事件级显现。

**特征**：
- 三善根现行**就是**与无我空性见的事件级 contact
- 在一阶反应面：无贪 = 不被我所贪扩张、无嗔 = 不被我所抗扩张
- 在二阶 锚 面：无痴 = 不被我相迷暗（直接的 见地 层无我）
- 这层是**转依方向的事件级运作**

**典型形态**：
- State D 双 锚 同步（[无痴.md §五](无痴.md)）
- 修行者童年内化的"了无自性"+"所有错=无知造成的"双 锚表述
- 在这层运作的三善根本身就是无我的事件级运作，不是"为了通向无我"的工具

### 4. 三层是嵌套结构，不是独立分工

**嵌套关系**：
- 断恶层是反应面的事件级显现（征兆 层）
- 修善层是配置层的稳态运作（configuration 层）
- 见地层是 锚 层的最深运作（标的 层）

**修行学含义**：
- 三善根的修行不是"三层各自分别修"，是**同一组心所在不同层的展开**
- 起步：从断恶层开始（事件 反应式 让三毒不熏）
- 深化：到修善层稳态化（让其他善法不被 劫持）
- 究竟：在见地层与无我空性见 contact（这就是**[转依](../../../resources/cards/转依.md)方向**）

→ 三层都是同一组三善根的现行，深化方向是从 反应式 → standing → 锚 显现。

## 四、结构关系：假说 15 v3 二阶 + 二维 锚 视角

> **正交维度**：本节的二阶+二维结构是三善根**之间**的内部结构，与 §三 的三层分工是不同维度。

### 1. v3 总览

```
                  ┌─ 可意境 ──→ 贪 ←── 无贪
一阶（反应面）:                                    
                  └─ 不可意境 → 嗔 ←── 无嗔
                         
                  ┌─ frame dimension（见地层）
                  │   ── 无痴 anchor（贯遍所有境的 frame 方向）
二阶（anchor 面）:│
                  └─ phenomenal dimension（身心层）
                      ── 轻安 anchor（贯遍所有现行的身心堪任度）
```

### 2. 三善根的位置

- **无贪**：一阶反应面，对治可意境的染反应
- **无嗔**：一阶反应面，对治不可意境的染反应
- **无痴**：二阶 锚 面 见地 维度，作所有境的 见地 方向 锚
- **轻安**（不属三善根但在 v3 中互补）：二阶 锚 面 身心 维度，作身心堪任度 锚

### 3. 经典支持

- 痴 = 一切杂染所依（《成唯识论》卷六）
- 贪起必痴俱、嗔起必痴俱
- → 痴遍贯贪嗔起处 → 无痴作 锚 贯遍所有善心运作（与三善根之 §五 俱起规则一致）

## 五、协同与互摄机制

### 1. 俱起规则：B 立场（部分俱起，不对称）

**结论**：
- **无痴必随无贪 / 无嗔俱起**——因为 v3 中无痴是 见地锚，贯遍所有善心运作（与"痴遍贪嗔起处"对偶严格）
- **无贪 / 无嗔之间不必俱起**——反应面对应不同境性质（可意境无贪现行时不可意境的无嗔不需同时起）

**经典依据状态**：烦恼方"贪起必痴俱、嗔起必痴俱"是经典明文；善法方对偶论述本项目暂未找到等同明确的经文。在没有经典明确反驳和现量证据推翻之前，本项目以 B 作为当前认定立场。

### 2. 为什么 B 而不是 A 或 C

**B vs A（严格俱起说）**：
- 反应面（无贪/无嗔）按境分工，可意与不可意境本来就不同时主导现起
- A 的"任一现行必带其他二者"在反应面没有结构必然性

**B vs C（不必俱起说）**：
- 假说 16 严格暗示无痴必随其他善心所俱起作 见地锚——否则慧+无痴不俱起即染慧
- 类比扩展：无贪+无痴不俱起 = 染无贪（"我已放下"我相）；无嗔+无痴不俱起 = 染无嗔（"我不会发火"我相）
- C 假定无痴可以独立离开反应面运作，但 v3 二阶结构里 锚 面恰是为反应面提供 锚 而存在的

### 3. 修行学含义（B 立场）

**缺无痴的"无贪 / 无嗔"现行 = 染对治**：
- 反应面看似到位但被末那 劫持 为"我能放下 / 我能不嗔"我相
- 这是利根者特别需要警惕的形态——反应快 + 见地 不稳 = 染对治高 看似可信

**修行重点不是"练无贪练无嗔"，是练无痴 锚 让其稳定贯穿所有善法运作**：
- 与修行者 5/3 双线 框定 一致：
  - 线 1（烦恼种子势力弱化）= 三毒种子无新熏 + 缘缺自然衰减
  - 线 2（无痴 锚 加强）= 闻思 深挖 通透 + 定中持守 锚 作所缘
- 线 2 不只对无痴学习有效——对**所有善心所**的运作都是底盘建设

| 内容 | 层次 |
|---|---|
| 经典烦恼方俱起规则（贪起必痴俱、嗔起必痴俱）| 第一层（经典）|
| 善法方 B 立场（无痴必随无贪/无嗔；无贪/无嗔不必俱起）| 第三层（基于假说 15 v3 + 假说 16 的与经典框架一致的推论）|
| "染无贪 / 染无嗔"现象 | 第三层（与"染慧"对偶的推论）|

### 6. 烦恼方反向验证升级（2026-05-29 三毒精修学完后）

三毒精修完成后，B 立场（无痴必随无贪/无嗔俱起；无贪/无嗔之间不必俱起）与"染对治"机制经反向验证，**获得强经典支持**：

**B 立场的烦恼方反向印证**：

| 立场 | 烦恼方经典依据 | 反向支持力度 |
|---|---|---|
| 无贪 / 无嗔现行必有无痴俱起 | **贪起必痴俱、嗔起必痴俱**（[贪.md §四 §五](../烦恼心所/贪.md)、[嗔.md §六](../烦恼心所/嗔.md) 分别起 / 俱生分析；《成唯识论》卷六明文）| ✅ **强**——直接对偶 |
| 无贪 / 无嗔之间不必俱起 | 贪嗔不必互相俱起（结构必然——同一时点不可能同时缘可意境又缘不可意境）| ✅ **强**——结构必然 |

→ §五·1 原"善法方对偶论述本项目暂未找到等同明确的经文"的状态，可升级为"**经烦恼方'贪起必痴俱、嗔起必痴俱'严格对偶反向印证**"。B 立场的两半分别有强支持。

**"染对治"= "染慧"的结构同构（与假说 16 的明确接口）**

经典烦恼方无"染对治"对偶概念（烦恼本身就是染，不存在"染染对治"），但有结构对应：

| 善方 | 烦恼方对偶 |
|---|---|
| **染对治**（无贪 / 无嗔现行但缺无痴 = "我能放下 / 我能不嗔"我相）| **染慧**（慧现行但缺无痴 = 颠倒推度 / 邪见，即恶见心所体性）|
| 缺无痴 → 反应面退化为带我相 | 缺无痴 → 慧退化为颠倒推度 |

→ "染对治"在烦恼方的精确对偶是**染慧**（[恶见心所](../烦恼心所/) 的体性 = 颠倒推度，《成唯识论》卷六）——这正是 [假说 16 慧无痴俱起分判](../../假说/假说-16-慧无痴俱起分判.md) 的核心。

→ 这给"染对治"理论一个**经典锚定**：染对治不是孤立的项目级假说，是与经典"染慧"机制严格同构的结构。这升级了 §五·3 修行学含义的可信度——不只是基于假说 15 v3 + 假说 16 的推论，**有烦恼方经典明文支持的结构同构**。

### 5. 锚 作为 v3 通用判别基准（5/14 不放逸学习 推导）

5/14 不放逸学习中，修行者 深挖 给出 v3 框架 一个**重要的内在 推导**：

> "不放逸的三善根同时升起对治的就是'心所配置不当时该行为的染性变形'……不会产生过度泛化问题——因为在三善根现行的状态下应该断的恶是很清晰的。"

这层 推导 让 v3 框架 内在自洽性 步 up——**锚 面不仅是体性 锚，还是所有反应面 / 守护面 / 任运面的判别基准**：

```
anchor 面（无痴 / 轻安）  ←──── 提供判别基准
   ↓
反应面（无贪 / 无嗔）     ←── 染对治 in 反应面（事件层）
守护面（不放逸）          ←── 染对治 in 守护面（time domain）
任运面（行舍——5/14 预演）  ←── 染对治 in 任运面（state domain）
```

**与本节 B 立场的严格内在一致**：

- B 立场（无痴必随俱起）= 锚 缺位时反应面对治都退化为染对治
- 锚 作判别基准 = 锚 在场状态下所有 显现 面的染对治判定**自然清晰**

→ B 立场的 双 表述：**锚 在场 → 所有 显现 面健康 + 边界自然辨别**；**锚 缺位 → 所有 显现 面退化为染对治 + 边界泛化风险或预先 cataloging 风险**。

**与已学心所的结构性对偶**（详见 [不放逸.md §六](不放逸.md)）：

| 善心所 | "恶"判别 锚 | 判别机制 |
|---|---|---|
| 愧（究竟层 / 广读）| 缘起共业观 | 行为对共业网的影响 |
| 不放逸 | 三善根（无贪 / 无嗔 / 无痴）| 行为的染性变形 |
| 惭（究竟层）| "本来不应如此"（法本如是）| 行为对法性的偏离 |

→ 三者结构性统一——**所有善心所对治的"恶"边界都不是预先列表，是 锚 在场状态下的自然辨别**。

## 六、修行者跨世种子 模式（证据 #1-#5 整合）

修行者在三善根 + 信能 + 惭 + 轻安 上**整体重启**而非线性累积——5 条 证据 跨四面（嗔 / 痴 / 轻安 + 信能 / 惭）共同支持 [假说 7](../../../CLAUDE.md#跨阶段回填清单)（激活休眠种子 ≠ 从零累积）。

### 2. 整体重启 模式 的精确含义

修行者**多面同时 稳态** 不是巧合，是跨世修行积累在多面同时显现的**整体重启 模式**：
- 不是单点（如某个心所）激活
- 是**一整套 基准 配置**激活
- 三善根 + 信能 + 惭 + 轻安 的 锚 系统多面同时到位

→ 与从零起步者的修行轨迹结构性不同：
- 从零起步：累积式（线性厚化）
- 整体重启：激活式（多面 自发 复位）

### 3. 修行重心 校准（5/7）

修行者 5/7 自我诊断："**心所配置已经能达标，但是禅定功夫不够**"——这一精确诊断在假说 15 v3 下结构清晰：

→ **当前 瓶颈 不在三善根本身**（已 稳态），在 身心锚 的定 承载力 重建。修行重心结构性 校准：

## 七、当代方便层瓦解的跨三善根整体 模式（假说 14 整合）

### 1. 整体 模式：制造 / 奖励 / 颠倒 见地 三层递进

| 三善根 | 古代方便瓦解 | 工业化反向核心 |
|---|---|---|
| **无贪** | 少欲知足社会共业 | **工业化精准制造贪境**（消费 / 算法）|
| **无嗔** | 怕讥嫌 / 共业秩序惩罚 / 嗔为恶根伦理 | **工业化奖励嗔现行**（流量 / 极化）+ 部分伦理反向（嗔为正义）|
| **无痴** | 善知识 / 经教 / 共学 / 经教权威 | **权威崩塌**（信息多元化的结构性结果）+ 工业化奖励 superficial / 个人体验优先 / AI 染慧 vector |

**三层递进**：
- 无贪 = **制造现行**（不让你不黏）
- 无嗔 = **奖励现行**（让你乐于黏 + 嗔为正义）
- 无痴 = **颠倒 见地 本身**（让你以为自己在见地上，实际 见地 已被反向）

→ **痴的方便层瓦解最深**——前两者是反应面被工业化攻击，痴是 见地 本身被反向，修行者甚至难以察觉自己 见地 已被染。这与 §五 B 立场（无痴是所有善法的 锚 前提）一致——锚 缺位时，反应面对治也都是带我相的假对治。

### 2. 痴 / 无痴 上的精确化（5/7 推导）

**古代方便层**（依共业秩序运作的 见地锚 路径）：

5. 以经教为权威的社会共业——古人对佛法权威的天然接受

**当代瓦解**：

| 古代方便 | 当代瓦解形态 | 工业化反向 |
|---|---|---|

- → **真正的 erosion vector = 信息多元化的结构性结果**：任何权威 候选 都成了"多个 candidates 中的一个"，结构上 weakened，与个人是否批判性思维**无关**

## 八、路径 修行学含义

### 1. 三善根的修行不是"三个独立修"

**核心**：三善根是同一组对治末那运作的整体结构，不是三个独立项目。

- 修行重点不是"练无贪练无嗔练无痴"，而是**让对治末那的整体结构稳定运作**
- 缺无痴的反应面对治 = 染对治（带我相的假对治）
- 缺反应面的 锚 单独运作 = 见地不下沉到事件层

### 2. 修行序

**深化**：让 锚 稳态化贯穿所有善法运作
- 闻思 深挖 通透（深入诸理事）+ 定中持守 锚 作所缘
- 让 锚 不只在事件触发时升起，在定中作背景持续运作（State D- → D+）

**究竟**：与无我空性见的事件级 contact 深化
- 见地层运作 + 反应面运作 + 修善配置层运作三层同步
- 这就是[转依](../../../resources/cards/转依.md)方向的事件级展开
