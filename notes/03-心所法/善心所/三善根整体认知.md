## 一、经典定位与"善之根"的本体论地位

### 1. 经典出处

《成唯识论》卷六：

> 云何无贪？于有有具无著为性，对治贪著作善为业。
> 云何无嗔？于苦苦具无恚为性，对治嗔恚作善为业。
> 云何无痴？于诸理事明解为性，对治愚痴作善为业。

三者作为一组并列于善心所之首，且经文明确以"对治三毒"立体性——这是 11 善心所中唯一与三毒（贪嗔痴根本烦恼）严格对偶的一组。

### 2. "根"的精确含义：A + B + C 统一

为什么是这三个被称为"善之根"，而不是"轻安/惭愧/精进"等其他重要善心所？三个角度统一在"**对治末那我执**"这个核心：

**A. 因果之根（无我前提）**
三善根本质上是**末那"我执 + 我所执"运作的事件级反向对治**——
- 无贪：对治"可意境 → 我所扩张去抓取"
- 无嗔：对治"不可意境 → 我所扩张去抗拒"
- 无痴：对治"所缘 frame → 末那以我相 imposing 颠倒认取"

→ 三善根是**所有善法不被末那 hijack 的"无我"前提**——没有三善根作底盘，其他善心所现行时会被末那做成"染 + 我相"的形态：
- 慧无无痴 = 染慧 / 邪见 / 看穿者我相（[假说 16](../../../CLAUDE.md#跨阶段回填清单)）
- 信无三善根 = 染信（"我有正法善知识"我相驱动）
- 精进无三善根 = 染精进（"我修行进步快"我相驱动）
- 惭愧无三善根 = 染惭愧（"我有道德判断力"我相驱动）
- 慈悲无三善根 = 染慈悲（"我在爱他"我相驱动；详见 [无嗔.md §七](无嗔.md)）

→ 这是它们作"根"的最深含义：**所有善法是否能不被我相 hijack 的前提条件**，不只是某些善法的线性因果上游。

**B. 对偶之根（结构必然性）**
根本烦恼是三毒——三毒不是任意三个烦恼，是末那"我执 + 我所执"的三种 manifest（爱→贪、憎→嗔、迷暗→痴）。所以根本对治也必然是**结构对偶**的三个，不能多也不能少。其他烦恼（嫉、慢、疑、忿、恨等）都从三毒衍生，对应的善对治位次更下游。

**C. 通遍之根（遍行性）**
凡善心起必有三善根之全部或部分现行（详见 §五 俱起规则）——否则不是真正的善心，是带我相的假善心。这与遍行心所之于一切心相对应，但限于善心。

### 3. 三个角度统一收敛

A + B + C 都收敛在**对治末那我执**这个核心：
- B 决定为什么必须是这三个（结构必然性）
- C 决定它们必须遍及一切善心（否则非真善）
- A 决定它们对其他善法起的作用（无我前提）

→ 三善根 = **末那运作的事件级反向对治结构**，是经典从修行学角度对"如何不被末那 hijack"的精确建模。

### 4. 学术诚实标注

| 内容 | 层次 |
|---|---|
| 经文（《成唯识论》卷六）| 第一层（经典）|
| "对治三毒"立体性 | 第一层（经典）|
| A + B + C 三角度统一 | 第二层（基于经典框架的整理性重构）|
| 把"我相 hijack 假善法"作为 A 的精确含义 | 第三层（与假说 16 同构的推论）|

## 二、与三毒的逐项对偶

| 三毒（根本烦恼）| 末那扩张方向 | 对偶善根 | 对治方向 |
|---|---|---|---|
| 贪 | 可意境 → 我所要去抓取 | 无贪 | 不黏不抓 |
| 嗔 | 不可意境 → 我所抗去抗拒 | 无嗔 | 不嗔不害 |
| 痴 | 所缘 frame → 末那以我相 imposing 颠倒认取 | 无痴 | 于诸理事明解 |

**精确对偶关系**：
- 贪与无贪：所缘同（可意境），心识取向反（黏着 vs 不著）
- 嗔与无嗔：所缘同（不可意境），心识取向反（嗔恚 vs 慈和）
- 痴与无痴：所缘同（诸理事），认取方式反（迷暗颠倒 vs 明解如实）

**三毒不是三个并列烦恼，是末那运作的三个 manifest**（爱、憎、迷暗）——这是为什么根本对治必须三个，不能多也不能少。

详细对偶分析见各心所笔记：[无贪.md §二](无贪.md)、[无嗔.md §二](无嗔.md)、[无痴.md §二](无痴.md)。

## 三、三善根的三层分工：断恶 / 修善 / 见地

> **重要**：本节的三层分工与 §四 假说 15 v3 的"反应面 vs anchor 面"是**正交关系**，不是同一维度。
> - §三 三层分工 = 三善根（统一作为整体）在他善心所运作时起的**三种作用维度**
> - §四 v3 = 三善根**之间的内部结构**（无贪/无嗔在反应面 + 无痴在 anchor 面）

### 1. 断恶层（事件 reactive）

**作用**：三毒现起时，三善根作为直接对治阻断（让其不熏新种子，不形成等流相续）。

**特征**：
- 是 reactive 的——境现起 → 三毒可能现起 → 三善根现行让其消解
- 是事件级的，不是常态运作
- 对应假说 17 的 sign 层（事件级可观察）

**典型操作**：
- 反应式嗔现起 → 即时识破 → 无嗔现行（[无嗔.md Layer 3a](无嗔.md)）
- 贪境现起 → 看穿"可意"是末那 imposing → 无贪现行
- 痴根驱使下的颠倒认取现起 → anchor 升起识破 → 无痴现行

### 2. 修善层（配置 standing）

**作用**：三善根作为底盘配置，让其他善法（信、精进、惭愧、轻安、不放逸等）能起且不被末那 hijack。

**特征**：
- 是 proactive 的——三善根稳态运作 → 其他善法依此起
- 是常态配置层，不限于事件触发
- 对应假说 17 的配置层（other 善法运作的底盘）

**典型显现**：
- 闻思 push 通透不被"看穿者我相"hijack（无痴 anchor 在场）
- 慈悲行起不被"我在爱他"我相 hijack（无嗔 anchor 在场，详见 [无嗔.md §七](无嗔.md)）
- 精进现行不被"我修行进步快"我相 hijack（三善根 anchor 在场）

### 3. 见地层（anchor manifest）

**作用**：三善根现行 = 无我见地的事件级显现。

**特征**：
- 三善根现行**就是**与无我空性见的事件级 contact
- 在一阶反应面：无贪 = 不被我所贪扩张、无嗔 = 不被我所抗扩张
- 在二阶 anchor 面：无痴 = 不被我相迷暗（直接的 frame 层无我）
- 这层是**转依方向的事件级运作**

**典型形态**：
- State D 双 anchor 同步（[无痴.md §五](无痴.md)）
- 修行者童年内化的"了无自性"+"所有错=无知造成的"双 anchor formulation
- 在这层运作的三善根本身就是无我的事件级运作，不是"为了通向无我"的工具

### 4. 三层是嵌套结构，不是独立分工

**嵌套关系**：
- 断恶层是反应面的事件级显现（sign 层）
- 修善层是配置层的稳态运作（configuration 层）
- 见地层是 anchor 层的最深运作（target 层）

**修行学含义**：
- 三善根的修行不是"三层各自分别修"，是**同一组心所在不同层的展开**
- 起步：从断恶层开始（事件 reactive 让三毒不熏）
- 深化：到修善层稳态化（让其他善法不被 hijack）
- 究竟：在见地层与无我空性见 contact（这就是**[转依](../../../resources/cards/转依.md)方向**）

→ 三层都是同一组三善根的现行，深化方向是从 reactive → standing → anchor manifest。

## 五、协同与互摄机制

### 1. 俱起规则：B 立场（部分俱起，不对称）

**结论**：
- **无痴必随无贪 / 无嗔俱起**——因为 v3 中无痴是 frame anchor，贯遍所有善心运作（与"痴遍贪嗔起处"对偶严格）
- **无贪 / 无嗔之间不必俱起**——反应面对应不同境性质（可意境无贪现行时不可意境的无嗔不需同时起）

**经典依据状态**：烦恼方"贪起必痴俱、嗔起必痴俱"是经典明文；善法方对偶论述本项目暂未找到等同明确的经文。在没有经典明确反驳和现量证据推翻之前，本项目以 B 作为当前认定立场。

### 2. 为什么 B 而不是 A 或 C

**B vs A（严格俱起说）**：
- 反应面（无贪/无嗔）按境分工，可意与不可意境本来就不同时主导现起
- A 的"任一现行必带其他二者"在反应面没有结构必然性

**B vs C（不必俱起说）**：
- 假说 16 严格暗示无痴必随其他善心所俱起作 frame anchor——否则慧+无痴不俱起即染慧
- 类比扩展：无贪+无痴不俱起 = 染无贪（"我已放下"我相）；无嗔+无痴不俱起 = 染无嗔（"我不会发火"我相）
- C 假定无痴可以独立离开反应面运作，但 v3 二阶结构里 anchor 面恰是为反应面提供 anchor 而存在的

### 3. 修行学含义（B 立场）

**缺无痴的"无贪 / 无嗔"现行 = 染对治**：
- 反应面看似到位但被末那 hijack 为"我能放下 / 我能不嗔"我相
- 这是利根者特别需要警惕的形态——反应快 + frame 不稳 = 染对治高 plausible

**修行重点不是"练无贪练无嗔"，是练无痴 anchor 让其稳定贯穿所有善法运作**：
- 与修行者 5/3 双线 framing 一致：
  - 线 1（烦恼种子势力弱化）= 三毒种子无新熏 + 缘缺自然衰减
  - 线 2（无痴 anchor 加强）= 闻思 push 通透 + 定中持守 anchor 作所缘
- 线 2 不只对无痴学习有效——对**所有善心所**的运作都是底盘建设

### 4. 学术诚实标注

| 内容 | 层次 |
|---|---|
| 经典烦恼方俱起规则（贪起必痴俱、嗔起必痴俱）| 第一层（经典）|
| 善法方 B 立场（无痴必随无贪/无嗔；无贪/无嗔不必俱起）| 第三层（基于假说 15 v3 + 假说 16 的与经典框架一致的推论）|
| "染无贪 / 染无嗔"现象 | 第三层（与"染慧"对偶的推论）|

## 六、修行者跨世种子 pattern（evidence #1-#5 整合）

修行者在三善根 + 信能 + 惭 + 轻安 上**整体重启**而非线性累积——5 条 evidence 跨四面（嗔 / 痴 / 轻安 + 信能 / 惭）共同支持 [假说 7](../../../CLAUDE.md#跨阶段回填清单)（激活休眠种子 ≠ 从零累积）。

### 1. 跨善心所证据 5 条整体图

| Evidence | 心所 / 面 | 内容 |
|---|---|---|
| #1 | 无嗔 | 安受苦忍 stable base（病痛 / 身体不适不起嗔）|
| #2 | 无嗔 | 不参与奖励嗔场域（围观 / 极化 / 网暴聚集天然抗拒）|
| #3 | 无嗔（深层）| Layer 4 imposing 看穿（"之前无法忍受场景突然能接受"）|
| #4 | 无痴 | 童年善知识 transmission "所有错=无知造成的" 即时 stick + 30+ 年持续运作 + State D 双 anchor 同步 |
| #5 | 轻安（+ 三善根整体）| 心所配置达 真正轻安现起 threshold + 30 岁前 spontaneous + 童年 ceiling 45 min 时间感失落 |

### 2. 整体重启 pattern 的精确含义

修行者**多面同时 stable** 不是巧合，是跨世修行积累在多面同时显现的**整体重启 pattern**：
- 不是单点（如某个心所）激活
- 是**一整套 baseline 配置**激活
- 三善根 + 信能 + 惭 + 轻安 的 anchor 系统多面同时到位

→ 与从零起步者的修行轨迹结构性不同：
- 从零起步：累积式（线性厚化）
- 整体重启：激活式（多面 spontaneous restoration）

### 3. 修行重心 calibration（5/7 reveal）

修行者 5/7 自我诊断："**心所配置已经能达标，但是禅定功夫不够**"——这一精确诊断在假说 15 v3 下结构清晰：

| 条件 | 内容 | 修行者状态 |
|---|---|---|
| 条件 1：心所配置 ready | anchor 系统（frame + phenomenal）+ 反应面三善根 | ✅ 达标 |
| 条件 2：定 capacity 稳定 | 别境定的 stable 持续 + 入色界定支稳定建立 | 🟡 重启中 |

→ **当前 bottleneck 不在三善根本身**（已 stable），在 phenomenal anchor 的定 capacity 重建。修行重心结构性 calibration：
- 闻思：保持 baseline，不再 push 主推进（三善根已 stable）
- **禅定：主推进线**（重建 phenomenal anchor 的 substrate capacity）
- 生活修：现量验证

## 七、当代方便层瓦解的跨三善根整体 pattern（假说 14 整合）

### 1. 整体 pattern：制造 / 奖励 / 颠倒 frame 三层递进

| 三善根 | 古代方便瓦解 | 工业化反向核心 |
|---|---|---|
| **无贪** | 少欲知足社会共业 | **工业化精准制造贪境**（消费 / 算法）|
| **无嗔** | 怕讥嫌 / 共业秩序惩罚 / 嗔为恶根伦理 | **工业化奖励嗔现行**（流量 / 极化）+ 部分伦理反向（嗔为正义）|
| **无痴** | 善知识 / 经教 / 共学 / 经教权威 | **权威崩塌**（信息多元化的结构性结果）+ 工业化奖励 superficial / 个人体验优先 / AI 染慧 vector |

**三层递进**：
- 无贪 = **制造现行**（不让你不黏）
- 无嗔 = **奖励现行**（让你乐于黏 + 嗔为正义）
- 无痴 = **颠倒 frame 本身**（让你以为自己在见地上，实际 frame 已被反向）

→ **痴的方便层瓦解最深**——前两者是反应面被工业化攻击，痴是 frame 本身被反向，修行者甚至难以察觉自己 frame 已被染。这与 §五 B 立场（无痴是所有善法的 anchor 前提）一致——anchor 缺位时，反应面对治也都是带我相的假对治。

### 2. 痴 / 无痴 上的精确化（5/7 derivation）

**古代方便层**（依共业秩序运作的 frame anchor 路径）：
1. 善知识 transmission 链——师承直接给 frame
2. 经典学习路径完整——稳定的闻所成慧渠道
3. 共学场域——讲经 / 论辩 / 参学讨论
4. 寺院结构提供的认知秩序——frame 不被多元信息打散
5. 以经教为权威的社会共业——古人对佛法权威的天然接受

**当代瓦解**：

| 古代方便 | 当代瓦解形态 | 工业化反向 |
|---|---|---|
| 善知识 transmission | 真伪难辨 / 多门多派自己选 | — |
| 经典完整学习 | 信息碎片化（podcast / 短视频 / 文章片段）| 流量奖励"10分钟搞懂X"扁平化叙事 |
| 共学场域 | 寺院衰 / 居士分散 | — |
| frame 稳定结构 | 多元世界观日常涌入 | 算法奖励内容混杂消费 |
| 经教权威 | **权威崩塌**（结构性，非个人思维方式问题）| "我自己体验最真实"反向消解经典见地优先性 |
| —— | —— | AI 让"plausible 但 frame 可能颠倒的见地"极易获得（[假说 16](../../../CLAUDE.md#跨阶段回填清单) 染慧形态的工业化载体）|

**关于"权威崩塌"的精确归因**（重要修正）：
- 不是"批判性思维 / 独立思考"被习气化为"质疑一切包括经典"——批判性思维 properly applied 与经典权威 compatible
- 批判性思维**本身**得出的就是"以经典为准"——经典 prior probability 远高于个人推论（贝叶斯）
- 我们整个项目的"经典 > 假说"准则正是批判性思维的合理运用，不是其反面
- 假说 14 自身也是合理批判（识别经典框架在不同社会条件下的适用边界，不是否认经典）
- → **真正的 erosion vector = 信息多元化的结构性结果**：任何权威 candidate 都成了"多个 candidates 中的一个"，structurally weakened，与个人是否批判性思维**无关**

## 八、path 修行学含义

### 1. 三善根的修行不是"三个独立修"

**核心**：三善根是同一组对治末那运作的整体结构，不是三个独立项目。

- 修行重点不是"练无贪练无嗔练无痴"，而是**让对治末那的整体结构稳定运作**
- 缺无痴的反应面对治 = 染对治（带我相的假对治）
- 缺反应面的 anchor 单独运作 = 见地不下沉到事件层

### 2. 修行序

**起步**：从能直接 reactive 的层入手
- 修行者 path：无嗔 Layer 4 imposing 看穿（[无嗔.md §十二](无嗔.md)）+ 无贪境 partition（[无贪.md §九](无贪.md)）+ 无痴双 anchor 已 stable（[无痴.md §五](无痴.md)）

**深化**：让 anchor 稳态化贯穿所有善法运作
- 闻思 push 通透（深入诸理事）+ 定中持守 anchor 作所缘
- 让 anchor 不只在事件触发时升起，在定中作背景持续运作（State D- → D+）

**究竟**：与无我空性见的事件级 contact 深化
- 见地层运作 + 反应面运作 + 修善配置层运作三层同步
- 这就是[转依](../../../resources/cards/转依.md)方向的事件级展开

### 3. 修行者 specific 操作核

修行者三善根面已 stable（evidence #1-#4 + 整体 pattern），但 phenomenal anchor 定 capacity 重启中——**修行重心 calibration**：

| 维度 | 内容 | 当前权重 |
|---|---|---|
| 闻思 | 三善根 anchor 已稳，保持 baseline | 🟢 baseline |
| **禅定** | **phenomenal anchor 重建（主座 A + 双盘 B + 柔软度 C）** | 🔴 **主推进** |
| 生活修 | 现量验证 + 事件层三善根 reactive | 🟢 持续 |

详见 [当前修行内容.md §三](../../实修/当前修行内容.md)。

### 4. 监测信号

**anchor formulation drift（path 风险 #3 跨善心所变形）**：
- 无痴场：出现"我已看穿无知 / 我已了无自性 / 我能让双 anchor 同步"= 看穿者我相
- 无贪场：出现"我已放下 / 我能不黏"= 放下者我相
- 无嗔场：出现"我能不发火 / 我有慈悲心"= 慈悲者我相

→ 任一 actor-status 表述出现 = anchor 被末那 hijack 为我相，应立即递归识破（[假说 13](../../../CLAUDE.md#跨阶段回填清单) 递归惭愧机制）。
