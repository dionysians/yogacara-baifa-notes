## 0. 5/14 预演框架（待行舍正式学习时整合）

5/14 不放逸学习中，修行者 push 引出行舍的两层关键预演——为后续行舍正式学习预设 framework。

### 0.1 修行者比喻：行舍的体性精确化

> "修行比喻成开向目标的车——**不放逸是始终在开**；**任运开车的过程中的自如驾驶，是不被路上的各种情况影响，同时也不因为追求速度导致行驶不稳**。"

这层比喻给出行舍的两个核心 manifest 含义：

| 含义 | 唯识精确位置 |
|---|---|
| "不被路上各种情况影响" | motion quality 不被外缘扭曲——心识 quality 的稳态 |
| "不因为追求速度导致行驶不稳" | **不把推进感 lift 为成就感**——不"追求速度"作为修行进展信号 |

→ 行舍 = state domain（每个当下的运作质量）的 **anchor**，与不放逸（time domain 持续性）正交。

### 0.2 v3 framework：任运面 vs 守护面的 dimension 独立判定

| 维度 | 不放逸（守护面）| 行舍（任运面）|
|---|---|---|
| 答的是什么问题 | "还在开吗？"（motion continuity）| "开得自如吗？"（motion quality）|
| 对应 manifest 层 | time domain | state domain |
| 失败模式 | 停下来 = 放逸 / 懈怠 | 行驶不稳 = 掉举 |
| 对治反面性质 | "不用力 / 纵荡" | "过用力 / 紧张" |

两个反面性质对偶但不同层——放逸是 motion 中断（量），掉举是 motion quality 扭曲（质）。**(b) 任运面独立维度成立**（修行者 5/14 confirm）。

详见 [不放逸.md §四 5/14 v3 framework 五层 manifest 预演完整化](./不放逸.md)。

### 0.3 行舍 ↔ 假说 17（sign vs target 区分）严格对应——新发现

修行者 5/14 比喻最深的一层是"**不因为追求速度导致行驶不稳**"——这层精确指向**掉举的本质机制**：

| 现象 | 唯识精确位置 |
|---|---|
| "追求速度" | 把 sign（更快 / 更深 / 更稳的可观察现象）lift 为 target |
| "行驶不稳" | sign / target 错位导致的心识过度活动 = 掉举 |

→ **行舍的精确机制 candidate（5/14 预演）= sign / target 不错位 + 心识自然运作不被"我要更快 / 更深 / 更稳"hijack**

这层 derivation 让**假说 17（sign vs target 区分）在行舍场获得体性层面最严格的对应**——之前假说 17 在无痴 / 轻安场是"伴随观察方法论"，在行舍场直接就是体性核心。

**意外含义（待行舍学习时验证）**：行舍作为善心所的体性，可能就是**对治"用力推进作为修行进展信号"误识**的心所。掉举不只是简单的"心识浮躁"，是"把推进感升级为成就感"导致的心识失稳。

**对"不应跳过精进直奔行舍"警告的精确化**：跳过精进直奔行舍 = 把"无功用"作为 target = 已经在 sign/target 错位 = 反而违反行舍体性。

> **学术诚实标注（第三层）**：行舍 ↔ 假说 17 严格对应是 5/14 修行者比喻引出的自主推论，属第三层。窥基"令心平等正直无功用住"是经典立场；"平等正直 = sign/target 不错位"是基于假说 17 的内在 derivation，待行舍正式学习时校准。

## 一、概念定义

### 原文
> 行舍者，精进三根，令心平等、正直、无功用住为性，对治掉举，静住为业。

### 白话解释
行舍是依靠精进和三善根（无贪、无嗔、无痴），使心达到平等（不偏高偏低）、正直（不歪曲）、无功用（自然而然、不需刻意用力）的安住状态。它能对治掉举，使心安静地住于善法。注意"行舍"与"受舍"（舍受，不苦不乐受）不同。

### 梵文/巴利文
- **梵文**: upekṣā
- **音译**: 优毕叉
- **词源**: upa（近）+ īkṣ（观），意为平等地观照

---

## 二、详细说明

### 核心特征
1. **心平等**：心不偏高（掉举）也不偏低（惛沉），保持中道
2. **心正直**：心不歪曲、不虚伪，正直而住
3. **无功用住**：到达自然而然的状态，不需要刻意努力
4. **假立非实**：与不放逸一样，依精进三根假立，无独立体性

### 作用与功能
- 对治掉举（随烦恼心所）
- 使心安静住于善法
- 是禅定深化的关键——心达到平等正直的境界
- 体现修行的成熟状态

### 生起条件
- 精进和三善根已经成熟
- 通过不放逸的修习使善法稳固
- 禅定修习达到一定程度
- 惛沉和掉举都已调伏

```

          ↓

三种舍的区别：
- 受舍：不苦不乐（受蕴）
- 行舍：心平等正直（行蕴）
- 无量舍：对众生平等（四无量心之一）
```

## 六、学习心得

### 理解要点
- 行舍与不放逸的关系：先不放逸（初期刻意修善），然后行舍（善法自然成熟）

- 行舍也是假立的，依精进三根而有
- 注意区分三种"舍"：受舍、行舍、无量舍
