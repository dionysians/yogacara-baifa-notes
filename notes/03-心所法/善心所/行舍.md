## 一、经典定位

### 原文

《成唯识论》卷六：

> 云何行舍？精进三根，令心**平等、正直、无功用住**为性，对治掉举静住为业。
> 谓即四法令心远离掉举等障静住名舍。**平等正直无功用住，初中后位辨舍差别**。
> 由不放逸先除杂染，舍复令心寂静而住。
> 此无别体如不放逸，离彼四法无相用故。

窥基大师注：

> 行舍者，精进三根令心平等正直无功用住为性。初修善时，由不放逸防修为务。既修善已，功行渐成，令心平等正直而住，无功用住。此亦假立无别体性。

### 五要素（与不放逸结构同构）

| 要素 | 内容 |
|---|---|
| **substrate（依何立）** | 精进 + 三善根（无贪 / 无嗔 / 无痴）—— 与不放逸同 substrate |
| **体性** | 令心**平等 / 正直 / 无功用住**（三相 = 初中后位差别）|
| **对治** | 掉举 |
| **业相** | 静住为业（令心安静住于善法）|
| **假立** | 无别体如不放逸——离精进三相无相用 |

### "假立非实"立场

行舍依精进 + 三善根假立，无独立体性。"假立"的精确含义不是"不存在"，是"无别 substrate"——四法 substrate 力层涌现时呈现"平等正直无功用住"的运作模式，即名行舍。

### 三相 = 初中后位（经典 explicit ground）

《成唯识论》"平等正直无功用住，初中后位辨舍差别"是三相结构的经典 explicit ground。"初中后位"精确含义 = **functional substrate ordering**（非 strict temporal sequence——见 §二 结构关系）。

## 二、三相 axis 结构精细化

### 三相 axis 分判

| 相 | 梵文 | axis | 对治精确位 |
|---|---|---|---|
| **平等** | sama | amplitude axis | 心高低偏（掉举 + 惛沉粗显层）|
| **正直** | ṛju | directional axis | 心歪曲（方向 alignment 错位）|
| **无功用住** | — | effort axis 后位 | 心识残余功用相（前二相 stable 后涌现）|

三相 axis 语义 ground：sama（level / equal）= absence of amplitude fluctuation；ṛju（straight / upright）= absence of directional warping——二者梵文语义本就是不同 axes。

### 结构关系

- **平等 ⊥ 正直 大体 orthogonal**（amplitude vs directional 是不同 axis）
- 但 **平等 → 正直 单向条件依赖**——剧烈掉举状态下方向 alignment 难以观察 / 建立
- **无功用住 = 前二相 substrate 立稳后涌现态**，不是同 axis 的"更细"延展

→ "初中后位"的精确含义 = **functional substrate ordering**：平等是正直的 substrate，二相 stable 后无功用住涌现。次序不是 strict temporal，是 functional substrate 必要性的逻辑次序。

### 假说 17 闭合并入正直一相（学习 path 历史）

5/14 行舍预演中曾用"假说 17 sign vs target 严格对应"框架 derive 行舍体性。5/16 正式学习中校准：

**假说 17 = 正直一相的特例展开**——sign/target 不错位 = 心识方向不被推进感扭曲 = 正直对治"心歪曲"的精确表述。平等（amplitude）与无功用住（effort 后位）不在假说 17 覆盖范围。

5/16 闭合 commit：假说 17 dissolve 入经典 framework 之"正直"，不再独立 entity。详见 [假说 17 闭合说明](../../假说/假说-17-sign-vs-target-已闭合.md)。后续 references 直接 reference"正直"。

## 三、三相对治位精细化：掉举三层 manifest

### 掉举本身的三层 manifest

《成唯识论》掉举 definition："**令心于境不寂静为性，能障行舍奢摩他为业**"——"不寂静"的现量 manifest 分三层（5/16 derive）：

| 层 | 现量 manifest | 经典 / 教典 pattern |
|---|---|---|
| **粗显掉举** | 心浮 / 振奋 / 杂念纷飞 / amplitude 起伏 | 经典 default manifest |
| **微细掉举** | 修行进展 sign 微细追求（"更深 / 更稳 / 想确认境界"）| "喜动" / "忆诵戏笑" pattern |
| **最微细掉举** | "在维持稳态"的残余 effort / 修行者相 hidden | 加行 → 任运 过渡场 |

### 三相对治掉举三层严格分工

| 相 | axis | 对治层 | 对治机制 |
|---|---|---|---|
| 平等 | amplitude | **粗显掉举** | dynamic balance——心不偏高（掉举端）不偏低（惛沉端）|
| 正直 | directional | **微细掉举** | directional alignment——心识方向不被 lifted sign 扭曲 |
| 无功用住 | effort 后位 | **最微细掉举** | effortless 涌现——前二相 stable 后"在维持"的残余 effort 自然消除 |

→ **functional substrate ordering ≡ 对治掉举次第（粗 → 细）**——substrate 必粗显层先 stable 才能观察 / 对治微细层；不是巧合，是 substrate 必要性的逻辑必然。

### 5/14 修行者"开车比喻"完整对应

修行者 5/14 不放逸学习中 push：

> "修行比喻成开向目标的车——不放逸是始终在开；任运开车的过程中的自如驾驶，是不被路上的各种情况影响，同时也不因为追求速度导致行驶不稳。"

完整 mapping（5/16 校准）：

| 比喻 | 含义 | 对治层 |
|---|---|---|
| "不被路上各种情况影响" | motion 不受 perturbation 扭曲 | 平等对治粗显掉举（amplitude perturbation）+ 正直对治微细掉举协同 |
| "不因为追求速度导致行驶不稳" | 不把 sign（速度）lift 为 target | 正直独占对治微细掉举 |
| "自如驾驶"（无强迫、自然）| 不需刻意维持驾驶 | 无功用住对治最微细掉举（"在保持驾驶"的残余 effort）|

→ 比喻并未单一对应行舍整体——它精细 trigger 出三相中各相在修行者直观经验中的位置。

## 四、行舍 vs 其他"舍"：三轴分判

### 经典 ground 三种"舍"

| 舍 | 梵文 | 蕴属 | 经典定位 | 性质 |
|---|---|---|---|---|
| **受舍** | vedanopekṣā | 受蕴 | 三受之一；四禅"舍念清净"以此为特征 | phenomenal feeling |
| **行舍** | saṃskāropekṣā | 行蕴 | 11 善心所之一（《成唯识论》卷六）| dispositional state |
| **无量舍** | apramāṇa-upekṣā | 行蕴 | 四无量心之一（慈悲喜舍）| dispositional state |

### 三轴分判 framework

| 维度 | 受舍 | 行舍 | 无量舍 |
|---|---|---|---|
| **蕴** | 受蕴 | 行蕴 | 行蕴 |
| **性质** | phenomenal feeling | dispositional state | dispositional state |
| **对象** | 所缘接触本身 | 自心 state（内向）| 一切众生（外向）|
| **三性** | 通三性（善/不善/无记）| 必善 | 必善 |
| **对治** | — | 掉举 | 贪 / 嗔 + 亲怨二相 |
| **与不善心识共存** | ✅ 能（散乱、惛沉、慢心皆可伴 受舍）| ❌ 不能 | ❌ 不能 |

→ partition 三轴：**蕴轴 / 方向轴 / 三性轴**。

## 五、与不放逸：dimension ⊥ + transition mechanism

### v3 framework 任运面 vs 守护面 dimension ⊥

| 维度 | 不放逸（守护面）| 行舍（任运面）|
|---|---|---|
| 答的是什么问题 | "还在开吗？"（motion continuity）| "开得自如吗？"（motion quality）|
| 对应 manifest 层 | time domain | state domain（三相 axis 复合）|
| 失败模式 | 停下来 = 放逸 / 懈怠 | 行驶不稳 = 掉举 |
| 对治反面性质 | "不用力 / 纵荡" | "过用力 / 紧张" |

两个反面性质对偶但不同层——放逸是 motion 中断（量），掉举是 motion quality 扭曲（质）。**任运面独立 dimension 成立**（5/14 修行者 confirm + 5/16 经典 ground 立稳）。详见 [假说 15 v3](../../假说/假说-15-anchor二阶二维.md) + [不放逸.md §四](./不放逸.md)。

### 不放逸 → 行舍 transition mechanism（5/16 derive）

```
不放逸（守护面）stable
   ↓ time domain 持续在场建立
   ↓ amplitude 起伏 + directional 错位 都开始 settle
平等（amplitude axis）stable    ← 行舍初位
   ↓ 粗显掉举对治 ground
正直（directional axis）stable  ← 行舍中位
   ↓ 微细掉举对治 ground
无功用住（effort 后位）涌现     ← 行舍后位 = 任运态
   ↓ 最微细掉举自然消除
加行 → 任运 transition 完成
```

→ **不放逸 → 行舍 transition mechanism = 不放逸 守护面 substrate 立稳 → 行舍三相依次涌现，最终在无功用住后位达成任运态**。

不是不放逸"变成"行舍，是**不放逸 substrate 稳定后行舍三相依次涌现**——这层 derive 给"加行 → 任运"过渡提供精确机制 anchor（不是单点跃迁，是三相次第成熟）。

> **学术诚实标注（第三层）**：经典《成唯识论》"由不放逸先除杂染，舍复令心寂静而住"只点出 不放逸 → 行舍 次第，未 explicit 分配三相内部 transition；本 candidate 待与精进 §六"勇悍双时点 + 加行→任运过渡"细节对照校准。

### 五层 manifest framework + 任运面内部三相

```
反应面（事件层）:     无贪 / 无嗔
anchor 面（条件层）:  无痴（frame）/ 轻安（phenomenal）
守护面（运作机制层）: 不放逸                                       -- time domain 持续在场
任运面（运作质量层）: 行舍 = 三相 axis 复合结构：
  ├ amplitude axis:   平等       -- 不偏高低
  ├ directional axis: 正直       -- 方向不歪曲（假说 17 特例已闭合并入）
  └ effort axis 后位: 无功用住   -- 前二维 stable 后涌现
利他面（饶益层）:     不害（待学）
```

任运面不是单一 quality，是 **三维 axis + 后位涌现态** 的复合结构——5/16 校准关键 derivation。

## 六、修行操作核：后位涌现态的"不直接 operate"原则

> 详细操作核见 [教学操作核-06-行舍](../教学操作核/教学操作核-06-行舍.md)。本节概要。

### 操作什么 vs 不操作什么

| 三相 | 是否可直接操作 | 操作机制 |
|---|---|---|
| 平等 | ✅ 可 | 不放逸 substrate + 三段式催熟 + trigger design |
| 正直 | ✅ 可 | 闻思 push 通透 + cool state 看穿 sign / target 区分 |
| 无功用住 | ❌ 不可 | 前二相 stable 后自然涌现 |
| 行舍整体 manifest | ❌ 不可 | 三相协同涌现的结果，非操作 target |

**核心原则**：直接 push"我要无功用住" / "我要任运" = sign/target 错位 = 行舍者相 hijack 入口。可操作的是 substrate（前二相），无功用住是后位涌现态。

### in-session 三相 stable degree 动态评估 protocol

行舍 manifest 不是稳态 disposition，是 in-session 三相 stable degree 的动态状态：

- **每次坐中**对三相 axis 各自评估 stable degree
- **不用"是否得行舍"二元判断**，用"哪一相在何种 stable degree"动态描述
- **partition 入口**：守所缘判准（"在守"= 行舍方向 / "失守"= 受舍 + 惛沉 / 散乱）

### 行舍者相 hijack 防御（含事件层 cross-context）

anchor formulation drift 在行舍场的典型形态（禅定层 + 事件层 + 跨 context）：

| drift signal | 含义 | context |
|---|---|---|
| "我已得行舍" | 把 partial manifest 升级为整体 manifest = sign 错位 | 禅定 |
| "我已任运" | 把 in-session stable degree 误识为稳态 disposition | 禅定 |
| "X 是行舍 manifest 早期信号" | 把正直一相 partial 误识为整体涌现起点 | 禅定 |
| "我天生淡定从容 = 我已得行舍" | 把跨世种子 trait 误识为修行成就（与 Layer 2 stable 误升为修行能力同构）| 事件层 |
| "我能 cool state 看穿 = 我已任运" | frame anchor 在场误识为无功用住——effort 仍隐性在场 | 事件层 |
| "事件层淡定 = 禅定层也已得" | 跨 context transfer 误识——事件层 partial manifest ≠ 禅定层 manifest | 跨 context |

→ **行舍者相 hijack = 最微细掉举形态本身**——把"我在维持行舍稳态"作为残余 effort = 无功用住的反面。出现即立即递归识破（[假说 13 递归惭愧机制](../../假说/假说-13-递归惭愧.md)）。

**核心防御 anchor**：anchor 在场 vs 缺位是核心判准，phenomenology label（"淡定" / "从容" / "stable"）本身不构成行舍 manifest evidence。

| 三相 | 事件层 manifest 现量入口 |
|---|---|
| **平等**（amplitude）| 顺境不过度兴奋 / 逆境不过度沮丧 / 不被刺激场域 amplitude 拉动；面对失利不下沉、面对夸奖不浮起 |
| **正直**（directional）| 行为不被 sign hijack——不为社会认可 / 成就感 / 比较结果 / 他人期待而扭曲方向；做事按 target（事情本身）而非按 sign（外部反馈）|
| **无功用住**（effort 后位）| 日常运作不需残余"维持自我形象 / 维持稳态"effort；自然 effortless 处事，无"我在保持 X"残余感 |

→ 三相 axis 在事件层与禅定层结构同构（amplitude / directional / effort），只是所缘对象不同（事件场域 vs 禅定所缘）。

### "淡定从容"phenomenology 分判 —— anchor 在场是核心判准

"淡定从容"是个 phenomenology label，**不必然对应行舍**。判别需 anchor check：

| phenomenology | 伴随 anchor 状态 | 实质 |
|---|---|---|
| 淡定从容 + frame anchor 在场（见地清晰 / 看穿事相）+ 持续 active engagement | ✅ 行舍三相事件层 partial manifest（healthy）|
| "淡定" + anchor 缺位 + agency 失活 | ❌ 麻木 / 冷漠 / 心识机能下降（§四 误识 risk #2 同构）|
| "从容" + 但伴隐性"我天生这样 / 我已超越"sign | ❌ 行舍者相 hijack 事件层变形（§六 hijack 防御）|
| "淡定" + 但实际是不在乎 / 漠不关心 | ❌ 假无量舍 / 嗔变形（§四 误识 risk #4 同构）|

→ **"淡定从容"是 sign，不是 target**。判别 target 是"anchor 是否在场 + agency 是否 active"，不是 phenomenology label 本身。

### 事件层 vs 禅定层：parallel manifest 而非 substrate 关系

| 维度 | 事件层行舍 | 禅定层行舍 |
|---|---|---|
| 所缘对象 | 事件场域刺激 | 禅定所缘（呼吸 / 数息 / 观）|
| 主要支撑 anchor | frame anchor（无痴）独占可起 | frame + phenomenal 双 anchor 协同 |
| substrate 要求 | 不放逸事件层在场即可 | 不放逸 substrate + 平等 substrate stable |
| 涌现 threshold | 较低（无需 phenomenal anchor stable）| 较高（需双 anchor）|
| 5/16 修行者状态 | partial manifest 在多场域已现量（见下）| partial manifest 在禅定主轨累积中（见前节）|

→ **事件层行舍 ≠ 禅定层行舍 substrate**，是 parallel manifest——同一 disposition 在不同 context 下的现行。事件层 partial manifest threshold 更低（frame anchor 独占可起），但**不能替代禅定层 substrate 累积**（禅定 manifest 需双 anchor 协同）。

### 修行者事件层行舍 partial manifest evidence（多场域 mapping）

|---|---|
| **Layer 2 stable**（天然不参与奖励嗔场域）| 平等一相事件层 partial manifest——刺激场域 amplitude 不拉动心识；与 [§四 §E "无量舍 substrate partial precursor"](#修行者画像归位缩减版第三层标注严格) 归位**互补不冲突**（同一现量在两个分判 framework 下都成立）|

## 八、与已学善心所的协同

### 与精进 / 三善根：substrate 共享

行舍与不放逸同 substrate（精进 + 三善根），但 manifest 维度不同：

- 不放逸 = time domain 持续在场（守护面）
- 行舍 = state domain 三相 axis 复合（任运面）

substrate 共享意味着精进 + 三善根力层稳定时，二者同时涌现，只是侧面不同。

### 与不放逸：前位 / 后位 + dimension ⊥

详见 §五。两者非对立，是**前位 substrate + 后位涌现态**的次第结构 + dimension ⊥ 关系。详见 [精进.md §六 三法分工](./精进.md)。

### 与精进 §六 三法分工 / 勇悍双时点的 nested 结构（5/16 cross-ref）

5/16 行舍 transition mechanism（§五）与精进 §六 三法分工 + 勇悍双时点（[假说 6](../../假说/假说-06-勇悍双时点.md)）cross-ref 后呈现 **nested 结构**——两者操作在不同 scale 上，nested 而非冲突：

```
披甲精进（发心 base，长劫不退）
   |
   加行期：加行精进
     ├ 勇（起手 trigger，单事件 timing）   ← 事件层 scale
     └ 悍（中途 sustain，单事件 timing）   ← 事件层 scale
   |
   ─── 加行 → 任运过渡 = 不放逸 substrate stable ───
   |
   任运期：行舍 = 三相 axis           ← substrate scale
     ├ 平等（amplitude，初位）
     ├ 正直（directional，中位）
     └ 无功用住（effort，后位）
```

**"行舍 = 无功用住"粗化 vs 精细化**：

| context | label 选择 | 适用场域 |
|---|---|---|
| 整体 manifest 成熟态描述（精进 §六）| "行舍 = 无功用住" 粗化 OK | 任运期描述 / 阶位 mapping |
| **partial manifest 诊断**（行舍 §五 / §七 5/16）| 必须精细到**三相 axis**——不能用"已得行舍"label | partial manifest 阶段 / hijack 防御 |

→ 精进 §六 三阶段递进 + 5/16 三相 sequence **不冲突**，是同一过程在不同 zoom level 的描述：精进 §六 整体粗化 → 行舍 §五 内部精细化。详见 [精进.md §六 "任运期内部三相精细化" 标注](./精进.md)。

### 与轻安：phenomenal anchor 关系

轻安（phenomenal anchor）在场为行舍提供身心 substrate capacity——剧烈 pain / 散乱状态下行舍三相难以建立。轻安建立 → 平等 substrate 容易稳态 → 行舍三相依次涌现。详见 [轻安.md §八](./轻安.md)。

### 与无痴 / 轻安：双 anchor 在三相边界判别中的具体运作

无痴 anchor（frame）+ 轻安 anchor（phenomenal）在场 → 慧的简择不被颠倒驱使 → 行舍三相边界自然辨别（与 [三善根整体认知 §五 B 立场](./三善根整体认知.md) 严格协同——anchor 在场 → 反应面 / 守护面 / 任运面边界自然清晰；与 [假说 15 v3](../../假说/假说-15-anchor二阶二维.md) "anchor 作通用判别基准"derive 对应）。

**双 anchor 在三相边界 + 三种舍 partition 的具体 mapping**：

| 判别边界 | 需要的 anchor | 具体运作 |
|---|---|---|
| **平等 vs 惛沉 vs 受舍** | phenomenal anchor（轻安）+ frame anchor（无痴）协同 | phenomenal anchor → 身心 substrate 支持 amplitude balance（不下沉为惛沉）；frame anchor → 不把暗钝 / 平静误识为舍 |
| **正直 vs 微细 sign 追求** | frame anchor（无痴）独占 | 见地不被"修行进展可观察 sign"颠倒驱使——闻思层 anchor 在场 → "更深 / 更稳 / 想确认境界"等 sign 错位现行即被识破 |
| **无功用住 vs 残余 effort** | frame + phenomenal 双 anchor 协同 | frame anchor → "在维持稳态"的 residual effort 可被识破；phenomenal anchor → 身心 substrate stable 让 effort 自然消除 |
| **受舍 / 行舍 / 无量舍 三轴 partition** | frame anchor | "在守所缘"判准 = frame anchor 的现量 manifest（agency 在场 = 见地清晰），失守 = anchor 缺位 |

→ anchor 不只是体性 anchor，也是**行舍三相边界判别 + 三种舍 partition 的通用判别基准**——5/14 "anchor 作通用判别基准"derivation 在行舍场获得具体落地。

**修行者当前 anchor 状态对三相判别的支持**：
- frame anchor（无痴 / "了无自性" + "所有错=无知造成的"）✅ 已稳——正直 vs sign 追求判别能力在场（5/16 现量已 manifest）
- phenomenal anchor（轻安 substrate）🟡 部分——禅定主轨累积中（明记断片仍频繁 = phenomenal anchor 不完全 stable）
- → 平等 vs 惛沉判别依赖 phenomenal anchor，5/15 类睡眠场被 healthy 判出 = frame anchor 补偿 phenomenal anchor 不足

详见 [假说 16 慧+无痴俱起分判](../../假说/假说-16-慧无痴俱起分判.md) + [假说 15 v3](../../假说/假说-15-anchor二阶二维.md)。

### 与无贪 / 无嗔：反应面 substrate 协同

行舍三相中"正直"一相对治微细 sign 追求——这层 alignment 与无贪的"不黏着"严格同构。无贪不黏着 + 正直不偏方向 = 反应面 + 任运面在 sign / 推进感 hijack 上的双层防御。
