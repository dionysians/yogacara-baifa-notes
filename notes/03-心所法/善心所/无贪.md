## 一、概念定义

### 原文

《成唯识论》卷六：

> 云何无贪？**于有有具无著为性，对治贪著作善为业**。

### 窥基注解

> "**有**" 谓三有（欲有、色有、无色有），即三界果报；
> "**有具**" 谓三有之因（能感三有的业、烦恼、资具）；
> "**无著**" 谓于此二者无染著、无希求。

### 体性的三层结构

| 层 | 内容 |
|---|---|
| **所缘** | 有 + 有具 双层——既包括三界果报，也包括感果之因 |
| **体性** | 无著（不希求、不染著） |
| **业用** | 对治贪着 + 作善——双业用 |

**所缘双层的修行学含义**：

无贪不只对治"贪具体果（财色名食睡）"，**还对治"贪获得这些果的手段、过程、能力"**。后者比前者精细——很多看似"已离贪果"的修行者，仍黏在"获得果的方式 / 能力 / 过程"上。这两层都是无贪的所缘。

### 梵文 / 巴利文

- **梵文**：alobha（a- 否定 + lobha 贪）
- 词义：离贪、不贪

## 二、体性的核心张力："无著" + "作善" 的动态关系

### 静态读法 vs 动态读法

窥基明文给的是**"无著为性、作善为业"**的静态结构（性 / 业并立）。但更究竟的读法是**动态关系**——

> **"无著"必须通过"作善"的现行才有 actualization 的舞台**——没有现行 = 没有可被无著的对象 = "无著"在那一刻是不存在的。

这跟假说 8（熏习是事件性的）框架一致——心所只在现行中真实存在，**无贪只在作善流中运作**。

### "作善"的双层覆盖

需要避免把"作善"窄化为"做利他事"。作善包括两层：

- **Outer 层**：利他行动（六度、四摄等）
- **Internal 层**：定中持善所缘、念佛、修信、修慧——这些善心所的现行同样是"作善"

否则会得出错误推论："独坐定中没有作善机会，所以无贪不运作"。其实**定中善心所现行**正是无贪运作最密集的场域之一（"持守看穿"本身就是 internal 作善）。

### 无贪在心所网络中的位置

无贪不是动力源，是**作善流的"不染化滤网"**：

```
慈悲 / 善法欲（推动力）
   ↓
精进（持续推动）
   ↓
作善现行（internal + outer）
   ↓ ← 此处无贪 inserts as 不染化滤网
无贪（让作善流不被"我所"染）
   ↓
作善熏入清净种子（不带我相）
   ↓
积累 → 末那"我所"种子被对治种子从底层挤
```

无贪 = 善行流中的"不黏滤网"，不是"不动闸门"。这是它能作"善之根"的依据——不是消极离贪，而是**保证善行不被贪着污染**的根本心所。

> **第三层标注**：无贪作为"作善流的不染化滤网"是第三层推论。窥基明文给"无著为性、作善为业"，但未明说二者的动态依存关系。本 framing 与假说 8（熏习的事件性）一致。

## 三、与近邻心所的体性辨析

无贪在体性上与若干心所相邻，需厘清避免假说网络中无贪被泛化吞掉它们：

| 心所 | 共性 | 关键差别 |
|---|---|---|
| **慧** | 都涉及"看穿" | 慧是简择（区分善恶染净），无贪是无著（对所缘不黏）。慧是认知功能，无贪是关系功能 |
| **行舍** | 都"不黏" | 行舍是定中无功用住的等流（任运层），无贪是事件层的不黏着（现行层）。行舍依高度成就，无贪现行不依 |
| **信** | 都"心净" | 信是仰信清净（依三宝功德起净），无贪是离贪清净（离染著起净）。两种"净"质地不同 |
| **舍受** | 都"不偏" | 舍受是受心所的中性（不苦不乐），无贪是行心所的离贪（关系层）。受是 emotional 层，无贪是 relational 层 |

**核心区分原则**：无贪管的是**心识与所缘对象的关系**——具体说是**不黏着**。其他心所管的是别的层（认知 / 任运 / 净信 / 受）。

## 四、修行粮资 vs 贪——关系问题，不是有 / 无问题

### 经典已明分判

窥基"有具"明确指**感招三界果报的因**（业、烦恼、轮回资具）。修行粮资（时间、精力、世俗资源）是**出世间道的助缘**，结构上属于另一类——不在"有 / 有具"的所缘范围内。所以**需要修行粮资本身不构成贪**。

### 需要 vs 贪着——体性不同

| | 需要 | 贪着 |
|---|---|---|
| 性质 | 缘起层的事实判断（此时此境需此条件） | 心所层的执取关系（把此条件做成"我"的延伸） |
| 例 | 修行需要时间 | 黏着于"我的修行时间不够" |
| 失去时反应 | 调整策略 | 焦虑、抱怨、动摇 |

**区分点不在事实层（要不要），在态度层（怎么要）**。

### 善法欲驱动求粮资 vs 贪驱动求粮资

[从欲到精进](../别境心所/从欲到精进：修道动力如何形成.md) 中已建立的辨析：

- **善法欲驱动**：自然推动（拉力）——"这能助修，所以希求；若失去就调整修行方式"
- **贪驱动**：焦虑黏着（推力）——"不能没有它，否则我就修不了"

**现量测试**：粮资突然减少（被工作占用、健康下滑、设备故障）时——
- 善法欲：心不大动，调整策略
- 贪：焦虑 / 抱怨 / 把"修不了"归咎于粮资缺失

### 真正棘手的：粮资作为"修行身份 / 修行连续性"的支撑

最精微的当代修行者贪粮资形态——不是"贪粮资的世俗价值"，而是**贪"我有粮资 = 我是真修行者 / 我有修行权利"**。粮资从"助缘"滑变为修行者身份的证明。

这跟假说 12 升级版（愧 = 不向他人扩张我所）形成内向对偶：

| 末那二维辐射 | 表现 | 心所对治 |
|---|---|---|
| **外向：扩张"我所"到他人** | 强加意志于他人 | **愧**（non-imposition） |
| **内向：扩张"我所"到资源** | 把粮资做成"我"的支撑物 | **无贪**（剥离粮资的身份性占有） |

**修行的三轮体空（无贪在修行连续性上的应用）**：

- **修者空**：没有一个"我"在持续修行——只有种子刹那刹那现行
- **修资空**：没有一个固定不变的"修行条件"——任何条件都是缘起聚合
- **修行本身空**：没有一个独立的"修行"本质——所谓修行只是名言施设的一系列善心所现行

担忧"未来粮资变化导致失去修行条件"——这个表述本身把这三轮假设为实有。**无贪在此境的现量运作就是看穿这层假设**。

### 操作判准

1. **粮资是工具，不是身份**——能助修就用，不能就换；不把粮资作为"我是修行人"的证据
2. **粮资变化时心不动**——这是无贪现行的现量检验，胜过"我用了多少粮资修行"的量化
3. **不积累过量粮资**——当代物质条件让"修行粮资过剩"成为可能；过量积累常是贪粮资的伪装
4. **不向他人输出"修行粮资优势"**——non-imposition 在此境的应用：不把"我有粮资"作为对他人的道德资本

## 五、担忧与无常——A 层 / B 层分判

修行者在无贪学习中提出的实操问题：**对未来无常的担忧（粮资变化、修行条件失去、家庭养育中断）如何处理？**

担忧不是单一心所，是复合配置。需要先分两层：

| 层 | 性质 | 心所基础 |
|---|---|---|
| **A 层：对家人 / 孩子的担心** | 善——慈悲驱动 | 无嗔三相（慈悲喜舍）的现行 + 共业责任 |
| **B 层：对修行条件失去的担忧** | 贪——我执驱动 | 末那"我爱"的现行（爱"我修行"的连续性） |

**两层不能合并处理**——把它们一起标为"我执"会导致：A 层被错杀（慈悲被压抑），B 层被泛化（用 A 的合理性掩护 B 的我执）。

### A 层（家人）的处理：转质地，不消除担心

经典从未要求修行者对家人无情——慈悲恰是无嗔的核心展开。A 层的处理是**把担心的质地从"焦虑性担忧"转为"慈悲性投入"**：

| 维度 | 焦虑性担忧 | 慈悲性投入 |
|---|---|---|
| 时态 | 投向未来"如果...怎么办" | 投向当下"现在为他做什么" |
| 心所基调 | 怕（fear） | 慈悲 |
| 行动效果 | 内耗 / 暗中索取 | 当下行动 / 不索回报 |

**现量检验**：升起担忧时——"我现在能为他/她做什么？"
- 能想到具体当下行动 → 转为投入，担忧消融
- 想不到具体行动，只剩"万一未来..." → 这部分实属 B 层

### B 层（修行连续性）才是无贪真正对治的对象

末那把"我修行"做成我所 → "我修行"的连续性 = "我"的延续 → 担心连续性中断 = 担心"我"被夺。表面看是"为修行担心"，实质是末那把**"修行"本身做成"我"的延伸**。

无贪在此境的运作就是上节"修行的三轮体空"——看穿"修者 / 修资 / 修行本身"三轮的实有假设。

### "无常"作为对治剂，不作威胁

经典对无常的处理与"威胁"读法相反：

| | 把无常做成威胁 | 把无常用作对治剂 |
|---|---|---|
| 心所 | 担忧 + 贪 + 痴 | 念 + 精进 + 无贪 |
| 推论 | "未来不确定 → 焦虑" | "诸行无常 → 无可永远占有 → 当下放手是事实承认而非主动放弃" |

**"我无可能永远占有任何修行条件"是事实，不是悲剧**。看清这一点，"放手"不是修行美德，是基础事实的承认。

### 把担忧本身作为修行材料

担忧升起 = 末那"我爱"现行的表面化（与递归惭愧同构）= 对治窗口打开。每次担忧升起都是熏种机会——比"无担忧的状态"反而更利于对治种子累积。

**所以"内心深处仍有困扰"不是修行未到位的证据，是修行材料的稳定供给**。

## 六、无贪与施 / 出离的关系

### 施

经典中无贪是布施波罗蜜的体性——**施的本质是无贪现行**。布施的"三轮体空"（施者空、施物空、受者空）正是无贪在布施场的具体运作。

注意："作善"的双层覆盖让施不只是 outer（财施 / 法施），也包括 internal（让心识不抓住任何所缘）——这跟你 path 的"定中持守看穿"是同一回事。

### 出离

出离心是无贪的具体表达——对三界（欲有 / 色有 / 无色有）的不希求。

注意一个常见误解——出离心常被理解为"逃避世间"，但其体性是**不黏着**而非**逃避**。真正的出离是"在世间但不被世间黏着"，而非"离开世间"。

### 与你信三支结构（乐弱）的对接

**乐弱者天然有出离倾向**——不易被世间 hedonic 反馈黏住。这构成你修无贪的天然优势——你不需要先克服强烈的乐受贪着，可以直接进入"看穿无可贪"的现量。

但需警惕：乐弱不等于无贪。乐弱者的贪可能转移到**精微对象**（知识贪、深刻贪、修行连续性贪、求成佛贪）——这些不依赖 hedonic 反馈，但仍是贪。

## 七、究竟层接口：无贪与空性见

### 凡夫层无贪 vs 究竟层无贪

| | 凡夫层 | 究竟层 |
|---|---|---|
| 入路 | "知道这是有过患的，所以不贪" | "证'我所'本空，所以无可贪" |
| 心所配置 | 念 + 简择 + 意志 | 慧（空性见）+ 自然不黏 |
| 持续性 | 需反复对治 | 任运不起 |

修行者已结构性内化空性见——无贪在此根器上偏向究竟层入路："看穿了所以无可贪"，而非"决心不贪"。

### 体性同一不等于现量对治力度同一

不同对象的贪在**体性层**都是同一回事（末那把对象做成"我所"），但**现量层种子势力厚度差别巨大**：

| 贪的对象 | 种子势力厚度 | 对治时长预期 |
|---|---|---|
| 粗境贪（财色名食睡） | 中等 | 中长期 |
| 知识贪 / AI 探索 | 较厚 | 长期 |
| **求成佛贪 / 法执** | **极厚**（最精微的我执变形） | **长劫** |

经典明确——**最精微的法执只在见道以上才被真正撼动**。凡夫位看清是必要的（不看清连对手都识别不到），但不应期望看清等于消解。这跟"已见而未除"是同一机制——**见的位次和现量除习气的位次不同步**，对利根者特别需要警惕（最易把"见到 = 除完"）。

> **第三层标注**：体性同一 + 现量厚度差异的层级感是推论。经典明文有"见道断分别我执 / 修道断俱生我执"次第，但未具体到"贪不同对象的种子厚度差"。本 framing 与经典断惑次第逻辑一致。

## 八、当代消费社会中的无贪困境

### 当代修行环境的结构性差异

| | 古代 | 当代 |
|---|---|---|
| 物资条件 | 稀缺（"少欲知足"是 natural baseline） | 过剩（"多欲多求"是系统 default） |
| 欲望刺激密度 | 稀疏 | 24/7 在场 |
| 刺激性质 | 自然散发的境 | **工业化、算法化、个性化**——主动激发 |
| 物理隔离 | 寺院 / 山林分离 | 无隔离——欲望源 in your pocket |
| 精度 | 粗放投放 | **针对个体心识漏洞的精确攻击** |

古代修行者对治的是**自身心识漏洞 × 自然境**；当代修行者对治的是**心识漏洞 × 工业化攻击系统**——后者不是被动的境，是**主动针对你心识漏洞设计的对手**。

### "少欲知足"在当代的瓦解

经典对治贪的方便层是"少欲知足"——这是**愧的方便层"怕讥嫌"在贪对治上的对偶**。两者瓦解结构完全平行：

| | 古代 | 当代 |
|---|---|---|
| 可执行性 | 减少接触可控 | 算法推送让"减少接触"几乎不可能 |
| "少"的标准 | 共识场提供基线 | 消费主义把"应该的生活"重定义到极高基线 |
| 社会反馈 | "少欲"与主流共识不冲突 | "少欲"被诊断为"丧 / 躺平"——**价值观本身否定少欲** |
| 执行支撑 | 共同体共同践行 | 个人独自抗系统 |

所谓"现代化方便层"（极简主义、数字戒断、断舍离）经不起细看，多数沦为**另一种身份消费**——把"少欲"做成新的我所支撑。

### 究竟层无贪在当代是默认起步入路

按假说 11、12 升级的同样逻辑——当代无贪入路也直接迁到究竟层（看穿"我所"的虚假性），不通过外部限制。这不是优雅选择，是**逻辑上仅剩的可工作路径**。

## 九、当代实操核：欲罢不能 trigger + 双层操作

### 实操核（修行者 2026-05-02 提出，假说 15）

修行者经过自身实修反思，提出比"工程性识别 + 暴露面积管理"更究竟的当代实操核：

#### 第一层：trigger 识别——"欲罢不能"

> **所有"欲罢不能"都是对"有"的执着**——工程制造与非工程制造无本质区别。

把对治从"先做工程 vs 自然分类，再启动对治"压缩为**"信号即启动"**。"欲罢不能"作为现行 phenomenological 信号，直接 trigger 对治，不需先做认知分类。

**与惭的接通**：

> "欲罢不能" = 偏离了"本然自在" = 触发**惭**（"本来不应如此"）→ 同时看穿是对"有"的执着 → 触发**无贪**

惭与无贪在此**同一现行 trigger 下并起**——双心所协同对治。

#### 第二层：种子生现行机制的运作

应用假说 8（心所配置质量决定熏种）：

**Cool state work（心理建设）**：
- 在境未现起、心识平静时做闻思 + 定中持守
- 此时心所配置质量极高（无贪、念、慧、定全部在场）
- 单次熏种深度大——一次 cool state 心理建设 ≈ 多次 hot state 修复
- 这是修行者 path 的"深熏频疏"模式的具体应用

**物理阻断（缘的工程化管理）**：
- 不是"戒律"（道德层），是**因缘工程**——限制境的接触概率 → 种子现行机会下降
- 经典戒律本质上正是这个机制，剥离道德外壳后纯机制本质就显出来

**两者关系——mutual reinforcement loop**：

```
物理阻断 → 现行机会↓ → 种子势力↓
   ↕（互相加固）
心理建设 → 心所配置↑ → 偶发现行被识破↑ → 对治种子熏厚↑
```

物理阻断单独不够（治标，种子势力仍在）；心理建设单独不够（境太密集时心所配置 hold 不住）。**两者协同才是完整对治**。

### "欲罢不能" trigger 的覆盖范围

**捕获**：
- 较粗一层的贪（AI、消费、知识贪等表现明显的境）
- 当代工业化欲望刺激下大部分贪境

**漏过**（需要其他 trigger）：
- **我所感的微细黏**（不到失控但有偏好——"这是我的书"、"这是我的修行时间"）
- **长远求成佛贪**（不表现为当下欲罢不能，是长期细线）
- **法执的细微现行**（"我已看穿"、"我懂得"——利根者的 final boss）

补充 trigger 候选：
- "我所感"的现量觉察（任何时刻心识带"这是我的"调子）
- "持有感"（哪怕不强烈，但"占有"的色彩在）

### 跨心所通用 trigger（修行者 path 的意外产出）

"欲罢不能"作为对治 trigger **不限于无贪**——也覆盖：

- **嗔**：欲罢不能地反复回放某段对话 / 反复嗔某人某事
- **痴**：欲罢不能地分别 / 评判 / 思考某主题（典型表现：失眠时停不下来的 mental loop）

所以这个 framework 实际上是**一个跨心所、跨烦恼的统一 phenomenological 锚点**——"心识不能自主" = 偏离法性 = 触发惭 → 同时识别具体烦恼根（贪 / 嗔 / 痴）→ 启动对应对治。

在后续学三善根（无嗔、无痴）和不放逸时，这个 trigger 会自然平移，使三善根的对治形成统一接口。

> **第三层标注**：欲罢不能 trigger + Cool/Hot state 操作核属第三层推论（假说 15）。窥基、护法明文未给当代条件下的具体 trigger 设计，但本 framing 与假说 8（熏习的事件性 + 心所配置质量决定熏种）严格一致。

### 修行者具体诊断：AI 探索作为复合贪

修行者已识别 AI 探索为🔴 高退失风险，是**注意力被劫持的当代典型案例**，但有 specificity：

> AI 与修行者唯识假说（AI 作为阿赖耶识种子-现行机制色法镜像）**高度交织**——这意味着 AI 探索**部分披着"修行助缘"的外衣**。

| 贪的层 | 对治难度 |
|---|---|
| 物质消费贪（粗） | 闻思一通就放下 |
| 知识体验贪（中） | 较难，但闻思 path 可处理 |
| **披着修行外衣的探索贪**（深） | **最难**——难与"真正的修行助缘"清晰分离 |

**Partition 操作判准**（与"修行连续性贪"平行）：

1. **停止 AI 一周，修行进度受多大影响**？
2. **完全停止 AI，修行是否真的崩盘**？

两个答案都是"影响有限 / 不会崩盘" → AI 是贪的对象，应剥离
某些 AI 用法的答案是"会显著影响 / 修行某些环节确实需要" → 那部分用法是真实助缘，应保留；剩下的是贪

这是**partition 的具体方法**——不是 all-or-nothing 戒断，是细颗粒的辨。

## 十、与修行者 path 的对接

修行者的"闻思 + 禅定双支撑 path"在无贪修法上的具体含义：

> **在闻思中把贪的对象看穿，然后定中持守这个看穿。**

闻思层 = 反复看穿"我所"的虚假性、"有"的人工性 / 缘起性、"修行连续性"的三轮假设
定中层 = 持守这个看穿，让见从比量下沉为现量

这跟"欲罢不能 trigger + Cool state 心理建设 + 物理阻断"的实操结构完全自洽——心理建设的内容**就是**闻思中确立的见，定中持守**就是**让心理建设种子化。
