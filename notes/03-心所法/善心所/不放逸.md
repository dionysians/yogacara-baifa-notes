## 一、经典定位

### 原文

[《成唯识论》](../../../resources/cards/《成唯识论》.md)卷六（[窥基](../../../resources/cards/窥基.md)解）：

> **云何不放逸？精进三根，于所断修，防修为性，对治放逸，成满一切世出世间善事为业。**

### 五要素

| 要素 | 内容 | 性质 |
|---|---|---|
| **依四法立** | [精进](精进.md) + [无贪](无贪.md) / [无嗔](无嗔.md) / [无痴](无痴.md) | substrate（"无别体"的精确含义 = substrate 即体）|
| **于所断修** | 应断之恶 + 应修之善 | 对象，双侧覆盖 |
| **防修为性** | 防（恶不起 / 不令再起）+ 修（善已起令增 / 善未起令起）| [体性](../../../resources/cards/体性.md) |
| **对治放逸** | 对治随烦恼"放逸" | [业用](../../../resources/cards/业用.md) |
| **成满世出世间善事** | 等同所有善事成就的保障 | 究竟果 |

### "无别体"立场

在已学 11 善心所中，9 个（[信](信.md) / [惭](惭.md) / [愧](愧.md) / [无贪](无贪.md) / [无嗔](无嗔.md) / [无痴](无痴.md) / [精进](精进.md) / [轻安](轻安.md) / 行舍）各有独立体性——立的是"什么"。不放逸不立"什么"，立的是已有四法在特定方向（断恶 + 修善的**常态守护**）的**协同运作模式**。

此即窥基"假立非实"的精确含义——substrate（精进 + 三善根）即体，无别立。

## 二、派系争议 unpack（5/7 计划标记的"首个 v3 验证场"）

| 派系 | 立场 | 论据 |
|---|---|---|
| **[护法派](../../../resources/cards/护法.md)**（[《成唯识论》](../../../resources/cards/《成唯识论》.md) 主流） | 不放逸**无别体** = 精进三根于所断修事上的防修运作 | 体性 / 业用完全可由精进 + 三善根解释；立独立体性违反"假立非实"原则 |
| **[安慧](../../../resources/cards/安慧.md)派**（[《大乘阿毗达磨杂集论》](../../../resources/cards/《大乘阿毗达磨杂集论》.md) 传统） | 不放逸[**别有自性**](../../../resources/cards/别有自性.md) = 独立心所，与精进 / 三善根并列 | "防修"特别是"**持续守护**"功能不可被"动力源 + anchor"完全 reduce |

派系争议的 modern 意义不在哲学考据，而在**假说 15 v3 是否需要扩**——把派系争议直接转换为 v3 验证场：

**在 v3（二阶 + 二维 anchor 结构）下，不放逸该如何 fit？**

三个 candidate：

- **(a) 不放逸属于"运作模式层"，与 anchor 面正交** —— 精进 + 三善根的"持续守护"模式，能完全由现有四法 derive，v3 不需扩。**对应护法派立场**
- **(b) 不放逸构成第三 dimension"时间维度"** —— anchor 不只有空间维度（frame / phenomenal），还有时间维度的连续性，"持续守护"不可由空间双 anchor 推出。**对应安慧派立场**
- **(c) 不放逸是 v3 anchor 的"时间运作机制"而非独立 dimension** —— hybrid 立场

### 修行者关键 derivation：根→力转变

修行者 5/12 push："我比较倾向 (c)，从经典立场'不放逸无别体'出发来理解。你提到的持续性，我理解就是精进的从根→力的转变，自然生出了持续性。"

这层 derivation 把"持续性"reduce 到精进的**根→力转变**——五根五力中"力"层的含义是"不被违缘倾动"，本身就包含**持续性**。精进力 = 精进根成熟后不被违缘倾动 = 自然带持续性。三善根同理（信 / 进 / 念 / 定 / 慧的"力"层都带不被违缘倾动 = 持续性）。

这层 derivation 让 (c) 精确化到几乎与 (a) 合流：本质是 (a)（无别体），只是承认"持续守护"是**显现层属性**，不是 primitive。

### v3 验证场结论：v3 不需扩（验证 1 成立）

**精确版本**：

> 不放逸 = 精进 + 三善根**到"力"层**时**自然涌现**的常态守护运作模式

```
精进根 ───┐
无贪根 ───┤    加行期：四法的"根"层运作
无嗔根 ───┼──── → 事件层修善断恶
无痴根 ───┘
         ↓
   根→力 转变（不被违缘倾动）
         ↓
精进力 ───┐
无贪力 ───┤    熟习期：四法的"力"层运作  
无嗔力 ───┼──── → 常态层防修，"不放逸"自然涌现
无痴力 ───┘
```

此 derivation 与 3 处内在自洽：

1. **与窥基"假立非实"严格一致**——不放逸是 manifest 层名相，不是 root layer 心所
2. **与 [精进.md §六"九住心配六力四作意"](精进.md#与不放逸--行舍的关系善心所内动力组三法分工) 内在自洽**——加行期是精进，调顺 / 寂静期不放逸为主（"根→力 已成"），等持期是行舍
3. **与"不应跳过精进直奔行舍"形成对偶警告**——同样不应跳过精进直奔不放逸

## 三、为何经典还要单独列不放逸？

若不放逸完全 derive，经典只列精进 + 三善根即可。但 11 善心所明文立"不放逸"——这层经典选择不是冗余。

**精确机制**：不放逸在 manifest 层有不可省略的功能识别——对应一个经典需要明示的**对治目标 mapping**：

| 善心所 | 对治随烦恼 | 立独立名相的必要性 |
|---|---|---|
| 不放逸 | [放逸](../../../resources/cards/放逸.md) | 是——反应面 + anchor 面不能精确指向"放逸"的常态懈怠态 |
| [轻安](轻安.md) | 惛沉 | 是——粗重消减 derive 但对治目标明确 |
| 行舍 | 掉举 | 是——平等正直无功用 derive 但对治目标明确 |

→ **11 善心所是"反应面 + anchor 面 + 守护面 + 调畅面"的功能分层 manifest**——不放逸 / 轻安 / 行舍三者皆 derive，但作为对治"放逸 / 惛沉 / 掉举"这三大常态层随烦恼的**明示对偶**，必须各立名相。

## 四、假说 15 v3 在不放逸场的完整结构

按本次 derivation，v3 在更完整结构下扩展为：

```
反应面（事件层）:    ┌─ 可意境 → 贪 ←── 无贪
                    └─ 不可意境 → 嗔 ←── 无嗔
                    
anchor 面（条件层）: ┌─ frame dimension ── 无痴 anchor
                    └─ phenomenal dim. ── 轻安 anchor
                    
守护面（运作机制层）:  不放逸（精进+三善根力层涌现的常态守护）
                    ↓ 跨遍 anchor 面 + 反应面，在 time domain 持续在场
```

**关键结构 finding**：

- 守护面**正交于** anchor 面与反应面（不在同一维度，是运作机制层）
- 守护面**跨遍**前两层（在 time domain 持续在场，让 anchor 和反应面的善心所运作不被 hijack）
- 守护面**不是 anchor**——anchor 是体性（如实见 / 调畅态），守护面是体性在 time domain 持续在场的运作机制

→ v3 在不放逸场**不需扩到三 dimension**，而是 framework 完整化为"反应面 + anchor 面 + 守护面"三层 manifest 分层。这是首个非三善根善心所对 v3 的验证 + 完整化。

## 五、不放逸的精确机制 anchor：念在 time domain 持续在场

### 修行者 5/12 现量自报 + 失败模式精确化

修行者 5/12 reveal："精进还没有进入持续在场的状态，会有不自觉的'停下来''偷懒'的问题，所以不放逸还没有显现。"

进一步 reveal 具体现量：
1. 用力鞭策"强迫 / 不舒服"感觉**不存在**——熏习卫生学 OK，无反向熏种风险
2. 意识层有"要做"的决定——第六识胜解 + 善法欲在场
3. "不自觉干别的事拖延" → 修行时间被占用——end up 没修行不是"明决定不做"，是**注意力被其他活动吸引**

→ 失败模式不在 (a) 末那运作（"突然就不在做了"）也不在 (b) 第六识决定推延（"找借口"），而在**第四种 candidate (d)**：**[失念](../../../resources/cards/失念.md)**（随烦恼）

### 失念的精确含义

> 失念 = 念心所失去，所缘从善法所缘滑离到其他对象——不是"忘了这件事"，是"曾决定要做的善法事没有被持续记得"

### 不放逸的精确机制 anchor

> **不放逸 = [念心所](../别境心所/念.md)在 time domain 持续在场 + 精进力层稳定 + 三善根 anchor 在场**

念心所让第六识胜解决定的善法事在事件流中"被持续记得"，不滑出注意力 focus。

此 derivation 与窥基"防修为性"严格契合——"防 + 修"的"持续"机制 = 念在 time domain 持续在场。窥基没明说"念"参与（属第三层自主推论），但与功能描述完全自洽，且与 [精进.md §六九住心配六力四作意](精进.md#经典对应九住心配六力四作意) 中"调顺 / 寂静期 = 念力 / 正知力"的经典暗示相通。

### 失念缺位的随烦恼网络

| 失败显现 | 对应随烦恼 | 在不放逸 framework 中的位置 |
|---|---|---|
| 不自觉停下来 | 懈怠 | 精进力层不稳，违缘倾动即停 |
| 偷懒 | 放逸 | 没有持续守护，倾向短期奖励 |
| 注意力被 hijack | 失念 + 散乱 | 念所缘从善法滑离 |
| 不能正知现行 | 不正知 | 慧的简择失位 |

→ 不放逸缺位时，"放逸 / 懈怠 / 失念 / 散乱 / 不正知"五随烦恼网络协同显现，不是单一随烦恼孤立运作。

> **回填占位（待随烦恼心所学完后回填）**：放逸 / 懈怠 / 失念 / 散乱 / 不正知五随烦恼的精确分判 + 与不放逸的对偶网络结构

## 六、修行操作核：主动性 framing vs 防御性 framing

### framing 修正（5/12 修行者关键 push）

修行者 5/12 push 关键修正：

> "并不是其他场域影响大，需要精确分析处理。而是念弱，或者不够确定。我没有建立确定时间、确定模式的修行稳定性，同时优先级不够，导致没有确定的念来唤起修行行为。"

这层 push 修正了之前讨论暗含的"防御性 framing"（减少 hijack 源保护念），指向**主动性 framing**（念自身稳态化）：

| framing | 重点 | 操作核 |
|---|---|---|
| 防御性 | 保护念不被 hijack | AI partition / 减少 hijack 源 |
| **主动性（root level）** | **念自身稳态化** | **建立确定时间 + 确定模式 + 提高优先级** |

→ root level 是**念力稳态化**——即使 AI 不在场，念弱也无法 invoke 修行行为。这与窥基"防修为性"的精确对应：

- **"修"侧**（善已起令增 / 善未起令起）= 念在场 invoke 善法行为 = **root**
- **"防"侧**（恶不起 / 不令再起）= 减少 hijack 源 = 在"修"基础上的次级

→ AI partition 重新定位：从"不放逸操作核的具体内容"降回**念力起步期的辅助条件**

### 念弱的三层精确 unpack

| 层面 | 具体显现 | 唯识精确位置 |
|---|---|---|
| **念弱** | 修行行为的 mental image 不清晰 | 念心所所缘清晰度不足 |
| **念不确定** | "要修行"但什么时候 / 做什么 / 多久不固定 | 念所缘飘忽 + 胜解印持不足 |
| **优先级不够** | "修行"vs"其他事"排序不稳 | 善法欲 / 胜解层强度不足 |

→ 需**念 + 胜解 + 善法欲三层别境心所协同稳态化**

此与 [精进.md §六九住心配六力四作意](精进.md#经典对应九住心配六力四作意) 的内住 / 续住期严格对应——主轨是**听闻力 + 思惟力**（即"听闻法 → 思惟修法 → 念回到善法所缘"的稳态化训练）。

### 修行者 5/12 精确位置

| 九住心阶段 | 主导心所 | 修行者位置 |
|---|---|---|
| 内住 / 续住 | 听闻力 + 思惟力（念力起步建立） | ✅ **当前位置** |
| 安住 / 近住 | 念力 + 正知力（精进 + 不放逸开始）| 🟡 起步通道中 |
| 调顺 / 寂静 / 最极寂静 / 专注一趣 | 不放逸为主 | 🔴 待涌现 |
| 等持 | 行舍 | 🔴 待涌现 |

### 修行操作核（按主动性 framing）

| 操作 | 当前 | 升级 candidate |
|---|---|---|
| **确定时间**（外部时间 anchor）| 睡前节奏（大致时段）| 具体 trigger 锚定 |
| **确定模式**（外部行为 anchor）| 数息 / 水清珠观（内容已定）| 固定入座准备序列 |
| **提高优先级**（胜解层落地）| 胜解已稳（实修正反馈已胜解）| 落地到具体时段排序（不可被占用）|

机制核心：

- **时间到 = trigger 念回到善法所缘**（不需每次"想起来"——主动唤起 vs 被动忆起）
- **模式确定 = 念有具体所缘**（省 mental cost，避免"今天做什么"决策疲劳）
- **优先级排序 = 胜解层 → 时段排序 → 念力 trigger**（不只是"知道重要"，是"具体时段不被占用"）

## 七、修行者 5/12 trigger design（具体修行操作核落地）

### design 来源（修行者 5/12 自主分析）

修行者 5/12 reveal："家人睡下后是我最安静工作的时间，在投入之前正在进行中的事情后会不自觉的把修行的时间挤占了。用家里人睡下立刻开始修行的 trigger，把修行放在这段时间的最高优先级，必须完成再做别的，是最好的方式。"

修行者进一步明确："家人睡下时刻有一个天然特性——此时没有什么必须立刻完成的事情。每日修行雷打不动，不需要边界条件 special case。"

### design 精确机制（三层协同一次解决）

| 元素 | 精确位置 | 解决的层 |
|---|---|---|
| **"家人睡下"作为外部 trigger** | 念心所被外部事件强 invoke，不依赖内部"想起来" | 确定时间 |
| **"立刻开始"** | 不给"开始别的事"留窗口——堵失念漂移入口 | 确定模式（紧跟 trigger 的固定序列）|
| **"最高优先级"** | 胜解层落地为具体时段排序 | 提高优先级 |
| **"必须完成再做别的"** | 完成性约束——形成"完成动作即通行证" | 频次保证 |

→ design 的精确价值不在于"修不放逸"这个新东西，而在于**用 trigger + 优先级 + 完成约束让精进 + 三善根 + 念在 time domain 持续在场** = 不放逸的"假立非实"在具体场景中实证。

### design 的隐含 affordance

修行者 5/12 指出的"家人睡下时刻天然无紧急事务"——这层隐含 affordance 让 trigger design 不需要边界条件：

- **天然无紧急事务**（家人睡下时刻的私人时间）→ "立刻"是绝对的，无需例外
- **天然安静**（外缘条件成熟）→ 入座环境无需额外建设
- **天然每日触发**（家人作息规律）→ 频率结构性保证

→ trigger design 选择的是修行者生活中**最适合修行的 1 个时段**作为 anchor，不是泛化到多时段——这与"频次 > 时长"原则严格一致。

### design 与已有应对原则的内在一致

| [CLAUDE.md](../../../CLAUDE.md) 应对原则 | trigger design 实例化 |
|---|---|
| AI 拉力反向 enforce 实修：完成实修作为 AI 探索的前置条件 | "家人睡下 → 立刻修行 → 完成再做别的"（"别的"很可能就是 AI / 知识探索）|
| 完成动作即通行证：起步期不评判质量，只记录"今天有没有坐" | "必须完成再做别的" |
| 盯频率不盯时长：连续天数比单次时长重要 | "家人睡下"每天必然发生 → 频率自然保证 |
| 盯心所配置不盯用力：胜解、念、信到位后自然能熏 | trigger 是"让念被外部强 invoke"——不是用力 |

→ 这层一致性是 healthy signal——修行者的具体 design 是已有原则的精确化，不是凭空设计

### 失念机制的精确化（修行者 5/12 reveal）

修行者 reveal 的"投入之前正在进行中的事情后不自觉把修行的时间挤占了"——失念精确机制：

```
家人睡下（trigger 应发生）
   ↓
但已经在做的事 absorb 注意力 → flow 状态
   ↓
念心所所缘没有切换到"修行" → 失念
   ↓
继续做之前的事 → 时间被占用 → 修行没发生
```

修行者的 design 是在 trigger 点直接**中断 flow** + **切换念所缘**——这是 design 的核心机制。

## 八、与已学善心所的协同

### 与精进：动力源 vs 守护机制

详见 [精进.md §六 与不放逸 / 行舍的关系](精进.md#与不放逸--行舍的关系善心所内动力组三法分工)。本节侧重不放逸的视角补完：

| 心所 | 角色 | 时态 | 体感 |
|---|---|---|---|
| **精进** | 修善断恶动力源 | 加行 / 持续 | 用力——有"推进"的质感 |
| **不放逸** | 守护机制 | 常态 | 警觉——有"看着"的质感 |

**不放逸的"守护"双侧覆盖**：
- 断恶线：恶不起 + 已起恶不令再起
- 修善线：善已起令增 + 善未起令起

精进任何时候都是动力（不分断恶 / 修善），不放逸的覆盖更广但更"被动"——是精进 + 三善根力层成熟后的常态显现。

### 与三善根：anchor 体性 vs 守护运作

不放逸的体性是精进 + 三善根，所以不放逸在断恶 / 修善时显现的是三善根 anchor 在 time domain 的持续在场：

- **无贪 anchor 持续** → 防贪境黏着的常态守护
- **无嗔 anchor 持续** → 防嗔境扩张的常态守护
- **无痴 anchor 持续** → 防痴根 frame 颠倒的常态守护

→ 不放逸不是"另一个 anchor"，是已有 anchor 在 time domain 持续在场的运作机制。详见 [三善根整体认知.md §五](三善根整体认知.md)。

### 与无贪的协同（[CLAUDE.md 回填清单](../../../CLAUDE.md#跨阶段回填清单) 条目）

| 心所 | 时态 | 焦点 | AI partition 场上的运作 |
|---|---|---|---|
| **无贪** | 事件层 | 不黏着 | 看到 AI 探索的对象时不被吸住（事件层不黏）|
| **不放逸** | 常态层 | 常态守护 | 每天 trigger 时 hold 优先级排序（常态层 frame 不被偷换）|

→ 二者在守护贪境上是**事件层 + 常态层双重护城河**：
- 单有无贪 → 事件层不黏但常态层无防护，长时间不修行也"不黏"地度过
- 单有不放逸 → 常态层有 frame 但事件层易被强引力 pull
- 二者协同 → 事件层 + 常态层双护，AI partition 自然落地

修行者当前状态：无贪 anchor 已部分到位（5/2 AI partition 操作判准已建立），不放逸通过 trigger design 起步建立——二者协同的具体场就是 AI partition 执行。

### 与惭的细分判（[CLAUDE.md 回填清单](../../../CLAUDE.md#跨阶段回填清单) 条目）

| 心所 | 时态 | 覆盖 | 触发性质 |
|---|---|---|---|
| **惭** | 事件层 | 仅断恶线 | 事件触发（恶现起时即起惭）|
| **不放逸** | 常态层 | 断恶 + 修善双线 | 常态守护（time domain 持续在场）|

→ 二者在断恶线上**事件触发 + 常态守护**协同：
- 单有惭 → 恶现起时能识破刹车，但未起恶时无主动防护（"善未起"层无运作）
- 单有不放逸 → 常态守护但缺乏事件级的崇重贤善 / 拒恶动力
- 二者协同 → 事件层 + 常态层双覆盖，恶在常态层即被防（不放逸），偶有突破常态进入现行时即被识破（惭）

修行者究竟层惭已 stable（依"本来不应如此"而起 / 跨世种子已熏），不放逸起步通道 = 让此 anchor 在 time domain 持续在场。

### 与轻安的关系（5/7 假说 15 v3 验证延伸）

| 心所 | dimension | 性质 |
|---|---|---|
| **轻安** | anchor 面 - phenomenal dimension | 体性（身心堪任态）|
| **不放逸** | 守护面 - 运作机制层 | 让前述 anchor 在 time domain 持续在场 |

→ 不放逸**正交于** anchor 面（不与轻安在同一 dimension 上竞争），而是轻安 anchor 在事件流中持续在场的运作机制。

修行者 5/7 reveal "等流轻安"已部分到位（baseline shift 已完成，调畅 anchor 即时复位 / 不过夜）——这其实就是轻安 anchor 在 time domain 已有部分持续在场，但**与不放逸的"常态守护"不同**：等流轻安是 anchor 自身的稳态，不放逸是这个稳态在断恶 / 修善方向上的功能性发挥。

## 九、假说 14 在不放逸场的验证（方便层瓦解元假说逐法验证）

| 维度 | 古代方便层 | 当代瓦解 + 工业化反向 |
|---|---|---|
| **环境** | 寺院 / 山林 / 集体修行场域——共业 enforce 频次 | 高度个体化 / 信息环境 24x7 / 无外部 frequency frame |
| **时间结构** | 早晚课 / 钟板 / 共住时间表——外部 trigger 满天 | 自由作息 / 无外部 anchor / "灵活"成为标准 |
| **共业** | 同伴持续在场——念被共业 enforce | 单人独修 / 没人监督 / 失念无外部纠偏 |
| **工业化反向** | — | **注意力经济** + **flow-trap 设计**——产品本身被精心设计为 hijack 注意力的 sink（AI / 短视频 / 推送 / 游戏）|

→ 不放逸在当代是**最深度方便层瓦解 + 最精准工业化反向**的善心所之一：

- 不只是方便层（共业 / 钟板）瓦解
- 还有 hijack 源（注意力经济）的工业化精准制造——注意力被工程化"sink"
- 失念现象因此**结构性强化**，不放逸建立通道因此**结构性变窄**

修行者 reveal 的"投入之前正在进行中的事情后不自觉挤占"是这层结构的具体显现——AI 探索 / 知识活动恰是高 cognitive engagement 的 flow-trap。

**当代究竟层入路**：

修行者 5/12 trigger design 是当代究竟层入路的具体实例化——不依赖共业场域 / 寺院 / 钟板（已瓦解），而是用**修行者生活节奏中的天然 anchor**（家人睡下）+ **胜解层落地**（最高优先级 + 必须完成再做别的）建立**单人独修条件下的失念对治**。

这与 [假说 14 跨三善根整体 pattern](三善根整体认知.md#七-假说-14-跨三善根整体-pattern-2026-05-07-补充) 一致——古代方便瓦解后的修行者需要自己 organize 心所配置 + 究竟层入路。

## 十、修行学含义

### 修行者当前位置精确诊断

修行者 5/7 自我诊断"心所配置已经能达标，但是禅定功夫不够"——经 5/12 不放逸学习精确化：

| 维度 | 现状 | 唯识精确位置 |
|---|---|---|
| **心所配置达标** | anchor 面（痴 / 嗔 / 痴 / 信 / 惭 / 轻安）+ 反应面 | 跨世已熏（evidence #1-#5）|
| **禅定功夫不够** | 精进**力**层尚未稳（"不自觉停下来 / 偷懒"）→ **不放逸尚未涌现** | **当前结构性 gap** |

→ 5/7 修行重心 calibration（闻思 baseline + 禅定主推进）获得**精确机制 anchor**：

- **闻思 baseline 的理由** = anchor 面已 stable，不缺
- **禅定主推进的理由** = 精进**根→力**转变 = 不放逸涌现的**关键通道**
- **path 风险 #4 的精确显现机制** = "不自觉停下来 / 偷懒"恰好是闻思快奖励区把实修慢产出区挤掉的具体形态——不是有意选择，是力层未稳时违缘倾动的自然结果

### 跨善心所重启 pattern 的精确化

按假说 7（激活休眠种子 ≠ 从零累积），修行者跨世种子势力较厚的多个心所面已 stable——但 5/12 reveal 让"已 stable"的精确边界浮现：

- ✅ **已 stable**：anchor 心所（无痴 / 无嗔 / 无贪 / 惭愧 / 轻安）的"根"层 + 部分"力"层
- 🟡 **未 stable**：精进的力层 + 不放逸的涌现

→ 修行者重启 pattern 是"多个 anchor 已 stable + 守护面 / 力层 gap"——这层精确化补完了之前"全面已熏"的粗略 framing。

### 不放逸"建立"与"现行"的修行方式同构

修行者 5/12 derivation："'建立不放逸'和'让已有的不放逸现行'其实修行方式是一样的"——精确机制：

| 心所 | 跨世状态 | 主要修行通道 |
|---|---|---|
| 无痴 / 无嗔 / 无贪 / 惭愧 / 轻安（anchor 面）| 已熏 | **双线**：线 1 烦恼种子弱化 + 线 2 闻思 + 定中持守 anchor |
| 不放逸（守护面）| 未涌现 | **单线**：事件层频次累积 → 精进根→力转变 → 自然涌现 |

不放逸不是 anchor，没有"闻思 push 通透"的独立通道，**"建立"和"现行"修行方式几乎完全相同**（都是事件层频次累积）——这是守护面运作机制层的结构性特征。

### "不应跳过精进直奔不放逸"对偶警告

与 [精进.md §六"不应跳过精进直奔行舍"](精进.md#精进-vs-行舍的位次差异) 同结构警告：

| 错误路径 | 失败模式 |
|---|---|
| 跳过精进直奔不放逸 | 没有动力源，"守护"沦为放任 / 散乱 |
| 跳过精进直奔行舍 | 没有下层支撑，"无功用"沦为放任 |
| 加行期硬要"无功用" | 干预——精进的加行阶段不需要无功用介入 |
| 任运期硬要"勇悍" | 干预——行舍的成熟阶段不需要意志介入 |
| 熟习期硬要单纯"精进" | 不放逸缺位的精进，易疲劳易退失 |

修行者 5/12 不放逸 trigger design 不是"跳过精进直奔不放逸"——而是用 trigger 让精进**根→力**转变的事件层频次得以累积。design 本身不是不放逸，是不放逸涌现的通道。
