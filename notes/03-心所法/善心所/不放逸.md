## 一、经典定位

### 原文

[《成唯识论》](../../../resources/cards/《成唯识论》.md)卷六（[窥基](../../../resources/cards/窥基.md)解）：

> **云何不放逸？精进三根，于所断修，防修为性，对治放逸，成满一切世出世间善事为业。**

### 五要素

| 要素 | 内容 | 性质 |
|---|---|---|
| **依四法立** | [精进](精进.md) + [无贪](无贪.md) / [无嗔](无嗔.md) / [无痴](无痴.md) | 根基（"无别体"的精确含义 = 根基 即体）|
| **于所断修** | 应断之恶 + 应修之善 | 对象，双侧覆盖 |
| **防修为性** | 防（恶不起 / 不令再起）+ 修（善已起令增 / 善未起令起）| [体性](../../../resources/cards/体性.md) |
| **对治放逸** | 对治随烦恼"放逸" | [业用](../../../resources/cards/业用.md) |
| **成满世出世间善事** | 等同所有善事成就的保障 | 究竟果 |

### "无别体"立场

在已学 11 善心所中，9 个（[信](信.md) / [惭](惭.md) / [愧](愧.md) / [无贪](无贪.md) / [无嗔](无嗔.md) / [无痴](无痴.md) / [精进](精进.md) / [轻安](轻安.md) / 行舍）各有独立体性——立的是"什么"。不放逸不立"什么"，立的是已有四法在特定方向（断恶 + 修善的**常态守护**）的**协同运作模式**。

此即窥基"假立非实"的精确含义——根基（精进 + 三善根）即体，无别立。

## 二、派系争议 拆解（5/7 计划标记的"首个 v3 验证场"）

| 派系 | 立场 | 论据 |
|---|---|---|
| **[护法派](../../../resources/cards/护法.md)**（[《成唯识论》](../../../resources/cards/《成唯识论》.md) 主流） | 不放逸**无别体** = 精进三根于所断修事上的防修运作 | 体性 / 业用完全可由精进 + 三善根解释；立独立体性违反"假立非实"原则 |
| **[安慧](../../../resources/cards/安慧.md)派**（[《大乘阿毗达磨杂集论》](../../../resources/cards/《大乘阿毗达磨杂集论》.md) 传统） | 不放逸[**别有自性**](../../../resources/cards/别有自性.md) = 独立心所，与精进 / 三善根并列 | "防修"特别是"**持续守护**"功能不可被"动力源 + 锚"完全 归约 |

派系争议的 modern 意义不在哲学考据，而在**假说 15 v3 是否需要扩**——把派系争议直接转换为 v3 验证场：

**在 v3（二阶 + 二维 锚 结构）下，不放逸该如何 嵌合？**

三个 候选：

- **(a) 不放逸属于"运作模式层"，与 锚 面正交** —— 精进 + 三善根的"持续守护"模式，能完全由现有四法 推出，v3 不需扩。**对应护法派立场**
- **(b) 不放逸构成第三 维度"时间维度"** —— 锚 不只有空间维度（见地 / 身心），还有时间维度的连续性，"持续守护"不可由空间双 锚 推出。**对应安慧派立场**
- **(c) 不放逸是 v3 锚 的"时间运作机制"而非独立 维度** —— 混合 立场

### 修行者关键 推导：根→力转变

修行者 5/12 深挖："我比较倾向 (c)，从经典立场'不放逸无别体'出发来理解。你提到的持续性，我理解就是精进的从根→力的转变，自然生出了持续性。"

这层 推导 把"持续性"归约 到精进的**根→力转变**——五根五力中"力"层的含义是"不被违缘倾动"，本身就包含**持续性**。精进力 = 精进根成熟后不被违缘倾动 = 自然带持续性。三善根同理（信 / 进 / 念 / 定 / 慧的"力"层都带不被违缘倾动 = 持续性）。

这层 推导 让 (c) 精确化到几乎与 (a) 合流：本质是 (a)（无别体），只是承认"持续守护"是**显现层属性**，不是 primitive。

### v3 验证场结论：v3 不需扩（验证 1 成立）

**精确版本**：

> 不放逸 = 精进 + 三善根**到"力"层**时**自然涌现**的常态守护运作模式

```
精进根 ───┐
无贪根 ───┤    加行期：四法的"根"层运作
无嗔根 ───┼──── → 事件层修善断恶
无痴根 ───┘
         ↓
   根→力 转变（不被违缘倾动）
         ↓
精进力 ───┐
无贪力 ───┤    熟习期：四法的"力"层运作  
无嗔力 ───┼──── → 常态层防修，"不放逸"自然涌现
无痴力 ───┘
```

此 推导 与 3 处内在自洽：

1. **与窥基"假立非实"严格一致**——不放逸是 显现 层名相，不是 根 层 心所
2. **与 [精进.md §六"九住心配六力四作意"](精进.md#与不放逸--行舍的关系善心所内动力组三法分工) 内在自洽**——加行期是精进，调顺 / 寂静期不放逸为主（"根→力 已成"），等持期是行舍
3. **与"不应跳过精进直奔行舍"形成对偶警告**——同样不应跳过精进直奔不放逸

## 三、为何经典还要单独列不放逸？

若不放逸完全 推出，经典只列精进 + 三善根即可。但 11 善心所明文立"不放逸"——这层经典选择不是冗余。

**精确机制**：不放逸在 显现 层有不可省略的功能识别——对应一个经典需要明示的**对治目标 映射**：

| 善心所 | 对治随烦恼 | 立独立名相的必要性 |
|---|---|---|
| 不放逸 | [放逸](../../../resources/cards/放逸.md) | 是——反应面 + 锚 面不能精确指向"放逸"的常态懈怠态 |
| [轻安](轻安.md) | 惛沉 | 是——粗重消减 推出 但对治目标明确 |
| 行舍 | 掉举 | 是——平等正直无功用 推出 但对治目标明确 |

→ **11 善心所是"反应面 + 锚 面 + 守护面 + 调畅面"的功能分层 显现**——不放逸 / 轻安 / 行舍三者皆 推出，但作为对治"放逸 / 惛沉 / 掉举"这三大常态层随烦恼的**明示对偶**，必须各立名相。

## 四、假说 15 v3 在不放逸场的完整结构

按本次 推导，v3 在更完整结构下扩展为：

```
反应面（事件层）:    ┌─ 可意境 → 贪 ←── 无贪
                    └─ 不可意境 → 嗔 ←── 无嗔
                    
anchor 面（条件层）: ┌─ frame dimension ── 无痴 anchor
                    └─ phenomenal dim. ── 轻安 anchor
                    
守护面（运作机制层）:  不放逸（精进+三善根力层涌现的常态守护）
                    ↓ 跨遍 anchor 面 + 反应面，在 time domain 持续在场
```

**关键结构 finding**：

- 守护面**正交于** 锚 面与反应面（不在同一维度，是运作机制层）
- 守护面**跨遍**前两层（在 时间域 持续在场，让 锚 和反应面的善心所运作不被 劫持）
- 守护面**不是 锚**——锚 是体性（如实见 / 调畅态），守护面是体性在 时间域 持续在场的运作机制

→ v3 在不放逸场**不需扩到三 维度**，而是 框架 完整化为"反应面 + 锚 面 + 守护面"三层 显现 分层。这是首个非三善根善心所对 v3 的验证 + 完整化。

### 5/14 v3 框架 五层 显现 预演完整化（待行舍 / 不害学完后定稿）

修行者 5/14 深挖 行舍 ↔ 假说 17 严格对应（详见 [行舍.md §0 5/14 预演框架](行舍.md)）后，v3 框架 在 11 善心所完整学完后的结构预演扩展为**五层 显现 分层**：

```
反应面（事件层）:     无贪 / 无嗔            -- 对治染反应
anchor 面（条件层）:  无痴（frame）/ 轻安（phenomenal）  -- 提供见地 / 调畅 anchor
守护面（运作机制层）: 不放逸                 -- time domain 持续在场
任运面（运作质量层）: 行舍                   -- state domain 不被 sign/target 错位扭曲
利他面（饶益层）:     不害（待学）            -- 无嗔的特化展开
```

**守护面 vs 任运面的 维度 独立判定**（基于修行者 5/14 比喻 + 假说 17 对应）：

| 维度 | 不放逸（守护面）| 行舍（任运面）|
|---|---|---|
| 答的是什么问题 | "还在开吗？"（运动连续性）| "开得自如吗？"（运动质量）|
| 对应 显现 层 | **时间域**（时间持续性）| **状态域**（每个当下的运作质量）|
| 失败模式 | 停下来 = 放逸 / 懈怠 | 行驶不稳 = 掉举 |
| 外缘扰动应答 | 不被外缘**中断** | 不被外缘**扭曲动作** |

修行者 5/14 比喻原文：

> "修行比喻成开向目标的车——不放逸是始终在开；任运开车的过程中的自如驾驶，是不被路上的各种情况影响，同时也不因为追求速度导致行驶不稳。"

→ 两个反面性质对偶但 显现 层不同：放逸是 运动 中断（量），掉举是 运动质量 扭曲（质）。

> **学术诚实标注（第三层）**：五层 显现 框架 是 v3 在不放逸 / 行舍学习中的扩展性预演，待行舍 / 不害正式学完后定稿。当前结构性证据较充分但仍属第三层自主推论。

## 五、不放逸的精确机制 锚：念在 时间域 持续在场

### 修行者 5/12 现量自报 + 失败模式精确化

修行者 5/12："精进还没有进入持续在场的状态，会有不自觉的'停下来''偷懒'的问题，所以不放逸还没有显现。"

进一步 揭示 具体现量：
1. 用力鞭策"强迫 / 不舒服"感觉**不存在**——熏习卫生学 OK，无反向熏种风险
2. 意识层有"要做"的决定——第六识胜解 + 善法欲在场
3. "不自觉干别的事拖延" → 修行时间被占用——end up 没修行不是"明决定不做"，是**注意力被其他活动吸引**

→ 失败模式不在 (a) 末那运作（"突然就不在做了"）也不在 (b) 第六识决定推延（"找借口"），而在**第四种 候选 (d)**：**[失念](../../../resources/cards/失念.md)**（随烦恼）

### 失念的精确含义

> 失念 = 念心所失去，所缘从善法所缘滑离到其他对象——不是"忘了这件事"，是"曾决定要做的善法事没有被持续记得"

### 不放逸的精确机制 锚

> **不放逸 = [念心所](../别境心所/念.md)在 时间域 持续在场 + 精进力层稳定 + 三善根 锚 在场**

念心所让第六识胜解决定的善法事在事件流中"被持续记得"，不滑出注意力 focus。

此 推导 与窥基"防修为性"严格契合——"防 + 修"的"持续"机制 = 念在 时间域 持续在场。窥基没明说"念"参与（属第三层自主推论），但与功能描述完全自洽，且与 [精进.md §六九住心配六力四作意](精进.md#经典对应九住心配六力四作意) 中"调顺 / 寂静期 = 念力 / 正知力"的经典暗示相通。

### 失念缺位的随烦恼网络

| 失败显现 | 对应随烦恼 | 在不放逸 框架 中的位置 |
|---|---|---|
| 不自觉停下来 | 懈怠 | 精进力层不稳，违缘倾动即停 |
| 偷懒 | 放逸 | 没有持续守护，倾向短期奖励 |
| 注意力被 劫持 | 失念 + 散乱 | 念所缘从善法滑离 |
| 不能正知现行 | 不正知 | 慧的简择失位 |

→ 不放逸缺位时，"放逸 / 懈怠 / 失念 / 散乱 / 不正知"五随烦恼网络协同显现，不是单一随烦恼孤立运作。

> **回填占位（待随烦恼心所学完后回填）**：放逸 / 懈怠 / 失念 / 散乱 / 不正知五随烦恼的精确分判 + 与不放逸的对偶网络结构

## 六、修行操作核：主动性 框定 vs 防御性 框定

### 框定 修正（5/12 修行者关键 深挖）

修行者 5/12 深挖 关键修正：

> "并不是其他场域影响大，需要精确分析处理。而是念弱，或者不够确定。我没有建立确定时间、确定模式的修行稳定性，同时优先级不够，导致没有确定的念来唤起修行行为。"

这层 深挖 修正了之前讨论暗含的"防御性 框定"（减少 劫持 源保护念），指向**主动性 框定**（念自身稳态化）：

| 框定 | 重点 | 操作核 |
|---|---|---|
| 防御性 | 保护念不被 劫持 | AI 切分 / 减少 劫持 源 |
| **主动性（根 层级）** | **念自身稳态化** | **建立确定时间 + 确定模式 + 提高优先级** |

→ 根 层级 是**念力稳态化**——即使 AI 不在场，念弱也无法 调用 修行行为。这与窥基"防修为性"的精确对应：

- **"修"侧**（善已起令增 / 善未起令起）= 念在场 调用 善法行为 = **根**
- **"防"侧**（恶不起 / 不令再起）= 减少 劫持 源 = 在"修"基础上的次级

→ AI 切分 重新定位：从"不放逸操作核的具体内容"降回**念力起步期的辅助条件**

### 所断 / 所修边界的判别工具（5/14 修行者 深挖）

窥基定义"于所断修，防修为性"中"应断之恶 / 应修之善"的边界判定，依**三善根 锚 在场状态**而非预先 cataloging。修行者 5/14 深挖：

> "不放逸的三善根同时升起对治的就是'心所配置不当时该行为的染性变形'。这跟愧 §四 广读（究竟层）的'世间作为缘起共业场的事实'类似。不会产生过度泛化问题——因为在三善根现行的状态下应该断的恶是很清晰的。"

**边界判定的精确机制**：

| 候选 | 立场 | 风险 |
|---|---|---|
| 保守 框定 | 所断只限经典明文的"恶" | 漏掉具体生活场景细节 |
| 过度泛化 框定 | 所断 = 任何对修行不利的事 | 末那滋生压抑 / 反向熏种 |
| **(γ) 锚 作判别基准**（采纳）| 同一行为在不同心所配置下性质不同——三善根 锚 在场时染性变形自然清晰 | 不存在边界泛化风险——锚 本身就是边界 |

→ "所断"在不放逸场的精确含义 = **心所配置不当时该行为的染性变形**，不是行为本身。

### v3 框架 内在一致性发现：锚 作为通用判别基准（5/14）

这层 推导 让 v3 框架 内在自洽性 步 up——**锚 面不仅是体性 锚，还是所有反应面 / 守护面 / 任运面的判别基准**：

```
anchor 面（无痴 / 轻安）  ←──── 提供判别基准
   ↓
反应面（无贪 / 无嗔）     ←── 染对治 in 反应面（事件层）
守护面（不放逸）          ←── 染对治 in 守护面（time domain）
任运面（行舍）            ←── 染对治 in 任运面（state domain）
```

没有 锚 面在场，三个 显现 面都退化为染对治（"我能放下 / 我不发火 / 我能不放逸 / 我能任运"我相）——与 [三善根整体认知 §五 B 立场](三善根整体认知.md)（无痴必随俱起）完全一致。

**与已学心所的结构性对偶**：

| 善心所 | "恶"判别 锚 | 判别机制 |
|---|---|---|
| 愧（究竟层 / 广读）| 缘起共业观 | 行为对共业网的影响 |
| 不放逸 | 三善根（无贪 / 无嗔 / 无痴）| 行为的染性变形 |
| 惭（究竟层）| "本来不应如此"（法本如是）| 行为对法性的偏离 |

→ 三者结构性统一——**所有善心所对治的"恶"边界都不是预先列表，是 锚 在场状态下的自然辨别**。

> **学术诚实标注（第三层）**："锚 作为 v3 通用判别基准"是 5/14 修行者 深挖 后的内在 推导。窥基定义"所断 / 所修"未明说"由 锚 判别"，但与"假立非实"立场内在一致（依四法立——精进 + 三善根本身就包含 锚 心所）。

### 念弱的三层精确 拆解

| 层面 | 具体显现 | 唯识精确位置 |
|---|---|---|
| **念弱** | 修行行为的 mental 形象 不清晰 | 念心所所缘清晰度不足 |
| **念不确定** | "要修行"但什么时候 / 做什么 / 多久不固定 | 念所缘飘忽 + 胜解印持不足 |
| **优先级不够** | "修行"vs"其他事"排序不稳 | 善法欲 / 胜解层强度不足 |

→ 需**念 + 胜解 + 善法欲三层别境心所协同稳态化**

此与 [精进.md §六九住心配六力四作意](精进.md#经典对应九住心配六力四作意) 的内住 / 续住期严格对应——主轨是**听闻力 + 思惟力**（即"听闻法 → 思惟修法 → 念回到善法所缘"的稳态化训练）。

### 修行者 5/12 精确位置

| 九住心阶段 | 主导心所 | 修行者位置 |
|---|---|---|

### 修行操作核（按主动性 框定）

| 操作 | 当前 | 升级 候选 |
|---|---|---|
| **确定时间**（外部时间 锚）| 睡前节奏（大致时段）| 具体 触发 锚定 |

- **优先级排序 = 胜解层 → 时段排序 → 念力 触发**（不只是"知道重要"，是"具体时段不被占用"）

## 七、修行者 5/12 触发 设计（具体修行操作核落地）

### 设计 来源（修行者 5/12 自主分析）

修行者 5/12："家人睡下后是我最安静工作的时间，在投入之前正在进行中的事情后会不自觉的把修行的时间挤占了。用家里人睡下立刻开始修行的 触发，把修行放在这段时间的最高优先级，必须完成再做别的，是最好的方式。"

修行者进一步明确："家人睡下时刻有一个天然特性——此时没有什么必须立刻完成的事情。每日修行雷打不动，不需要边界条件 特殊 case。"

### 设计 精确机制（三层协同一次解决）

| 元素 | 精确位置 | 解决的层 |
|---|---|---|
| **"家人睡下"作为外部 触发** | 念心所被外部事件强 调用，不依赖内部"想起来" | 确定时间 |
| **"立刻开始"** | 不给"开始别的事"留窗口——堵失念漂移入口 | 确定模式（紧跟 触发 的固定序列）|
| **"最高优先级"** | 胜解层落地为具体时段排序 | 提高优先级 |
| **"必须完成再做别的"** | 完成性约束——形成"完成动作即通行证" | 频次保证 |

→ 设计 的精确价值不在于"修不放逸"这个新东西，而在于**用 触发 + 优先级 + 完成约束让精进 + 三善根 + 念在 时间域 持续在场** = 不放逸的"假立非实"在具体场景中实证。

### 设计 的隐含 affordance

修行者 5/12 指出的"家人睡下时刻天然无紧急事务"——这层隐含 affordance 让 触发 设计 不需要边界条件：

- **天然无紧急事务**（家人睡下时刻的私人时间）→ "立刻"是绝对的，无需例外
- **天然安静**（外缘条件成熟）→ 入座环境无需额外建设
- **天然每日触发**（家人作息规律）→ 频率结构性保证

→ 触发 设计 选择的是修行者生活中**最适合修行的 1 个时段**作为 锚，不是泛化到多时段——这与"频次 > 时长"原则严格一致。

### 设计 与已有应对原则的内在一致

| [CLAUDE.md](../../../CLAUDE.md) 应对原则 | 触发 设计 实例化 |
|---|---|
| AI 拉力反向 强制 实修：完成实修作为 AI 探索的前置条件 | "家人睡下 → 立刻修行 → 完成再做别的"（"别的"很可能就是 AI / 知识探索）|
| 完成动作即通行证：起步期不评判质量，只记录"今天有没有坐" | "必须完成再做别的" |
| 盯频率不盯时长：连续天数比单次时长重要 | "家人睡下"每天必然发生 → 频率自然保证 |
| 盯心所配置不盯用力：胜解、念、信到位后自然能熏 | 触发 是"让念被外部强 调用"——不是用力 |

→ 这层一致性是 健康 signal——修行者的具体 设计 是已有原则的精确化，不是凭空设计

### 失念机制的精确化（修行者 5/12）

修行者 揭示 的"投入之前正在进行中的事情后不自觉把修行的时间挤占了"——失念精确机制：

```
家人睡下（trigger 应发生）
   ↓
但已经在做的事 absorb 注意力 → flow 状态
   ↓
念心所所缘没有切换到"修行" → 失念
   ↓
继续做之前的事 → 时间被占用 → 修行没发生
```

修行者的 设计 是在 触发 点直接**中断 flow** + **切换念所缘**——这是 设计 的核心机制。

## 八、与已学善心所的协同

### 与精进：动力源 vs 守护机制

详见 [精进.md §六 与不放逸 / 行舍的关系](精进.md#与不放逸--行舍的关系善心所内动力组三法分工)。本节侧重不放逸的视角补完：

| 心所 | 角色 | 时态 | 体感 |
|---|---|---|---|
| **精进** | 修善断恶动力源 | 加行 / 持续 | 用力——有"推进"的质感 |
| **不放逸** | 守护机制 | 常态 | 警觉——有"看着"的质感 |

**不放逸的"守护"双侧覆盖**：
- 断恶线：恶不起 + 已起恶不令再起
- 修善线：善已起令增 + 善未起令起

精进任何时候都是动力（不分断恶 / 修善），不放逸的覆盖更广但更"被动"——是精进 + 三善根力层成熟后的常态显现。

### 与三善根：锚 体性 vs 守护运作

不放逸的体性是精进 + 三善根，所以不放逸在断恶 / 修善时显现的是三善根 锚 在 时间域 的持续在场：

- **无贪 锚 持续** → 防贪境黏着的常态守护
- **无嗔 锚 持续** → 防嗔境扩张的常态守护
- **无痴 锚 持续** → 防痴根 见地 颠倒的常态守护

→ 不放逸不是"另一个 锚"，是已有 锚 在 时间域 持续在场的运作机制。详见 [三善根整体认知.md §五](三善根整体认知.md)。

### 与无贪的协同（[CLAUDE.md 回填清单](../../../CLAUDE.md#跨阶段回填清单) 条目）

| 心所 | 时态 | 焦点 | AI 切分 场上的运作 |
|---|---|---|---|
| **无贪** | 事件层 | 不黏着 | 看到 AI 探索的对象时不被吸住（事件层不黏）|
| **不放逸** | 常态层 | 常态守护 | 每天 触发 时 成立 优先级排序（常态层 见地 不被偷换）|

→ 二者在守护贪境上是**事件层 + 常态层双重护城河**：
- 单有无贪 → 事件层不黏但常态层无防护，长时间不修行也"不黏"地度过
- 单有不放逸 → 常态层有 见地 但事件层易被强引力 pull
- 二者协同 → 事件层 + 常态层双护，AI 切分 自然落地

修行者当前状态：无贪 锚 已部分到位（5/2 AI 切分 操作判准已建立），不放逸通过 触发 设计 起步建立——二者协同的具体场就是 AI 切分 执行。

### 与惭的细分判（[CLAUDE.md 回填清单](../../../CLAUDE.md#跨阶段回填清单) 条目）

| 心所 | 时态 | 覆盖 | 触发性质 |
|---|---|---|---|
| **惭** | 事件层 | 仅断恶线 | 事件触发（恶现起时即起惭）|
| **不放逸** | 常态层 | 断恶 + 修善双线 | 常态守护（时间域 持续在场）|

→ 二者在断恶线上**事件触发 + 常态守护**协同：
- 单有惭 → 恶现起时能识破刹车，但未起恶时无主动防护（"善未起"层无运作）
- 单有不放逸 → 常态守护但缺乏事件级的崇重贤善 / 拒恶动力
- 二者协同 → 事件层 + 常态层双覆盖，恶在常态层即被防（不放逸），偶有突破常态进入现行时即被识破（惭）

修行者究竟层惭已 稳态（依"本来不应如此"而起 / 跨世种子已熏），不放逸起步通道 = 让此 锚 在 时间域 持续在场。

### 与披甲精进的协同（5/14 三层精进结构）

[精进.md §五 披甲精进](精进.md) 与不放逸的协同结构在 5/14 学习中精确化为**三层精进结构**：

| 层 | 内容 | 时态 |
|---|---|---|
| **披甲精进** | 长劫不退的发心稳定 | 发心面（恒常）|
| **加行精进** | 事件层"勇 + 悍"动力推进 | 事件层（活跃）|
| **不放逸** | 三善根 + 精进力层涌现的常态守护 | 常态层（standing）|

→ **协同结构**：披甲发心稳定 → 加行事件层动力推进 → 不放逸常态守护让动力不被违缘倾动

**关键 finding**：**披甲精进稳定 = 不放逸涌现的前提之一**——若披甲发心未稳，加行精进易被违缘倾动（"今天不修了 / 这条 路径 走不通"），不放逸无法在 时间域 持续在场。

修行者当前协同状态：

| 层 | 状态 | 现量 证据 |
|---|---|---|
| 披甲精进 | ✅ 种子已激活 | 跨世佛缘 / 修行粮资充足 / 时间可用度高（详见 [跨世佛缘与八难对治](跨世佛缘与八难对治.md)）|
| 加行精进 | 🟡 起步中 | 5/13-5/14 触发 落地 + 三轨 plan 执行 |
| 不放逸 | 🔴 待涌现 | 5/12 自诊 力层未稳 |

修行者披甲精进种子已激活 → 不放逸涌现的"上游条件"已满足，当前 瓶颈 在加行事件层频次累积让精进根→力转变。

### AI 切分 在不放逸场的精确位置（5/14 推导）

修行者画像 保持 风险 #1（AI 探索吞噬时间）在三层精进结构下的精确位置：

```
披甲精进种子已激活 → "修行这件事不退"作为发心稳态 (OK)
                            ↓
              事件层每天可能被 AI 吞噬时间
                            ↓
       加行精进事件层频次不稳 → 不放逸力层涌现通道被 hijack
                            ↓
              trigger design 直接对治这层 ← 5/12 reveal
                            ↓
       让加行事件层频次结构性保证 → 不放逸涌现的事件层 substrate 累积
```

→ **AI 探索 保持 风险 #1 在不放逸场的精确位置 = 加行精进事件层频次的最大 劫持 源**。触发 设计 不是简单的"时间管理"，是精确针对"AI 劫持 加行精进事件层"的对治通道。

修行者 5/12 自主 框定 修正（"根 层级 是念力稳态化，不是 劫持 源管理"）让 AI 切分 从"防御性 框定"重新定位为"念力起步期的辅助条件"，但**在三层精进结构下，AI 切分 仍然有精确价值** —— 不是 根 层级（根 是念力稳态化 + 加行频次累积），而是**减少加行频次被 劫持 的源头**。

→ AI 切分 的精确角色：**辅助加行精进事件层频次稳定 → 间接支持不放逸涌现**。不是 根 但仍是 enabling 条件。

### 与轻安的关系（5/7 假说 15 v3 验证延伸）

| 心所 | 维度 | 性质 |
|---|---|---|
| **轻安** | 锚 面 - 身心 维度 | 体性（身心堪任态）|
| **不放逸** | 守护面 - 运作机制层 | 让前述 锚 在 时间域 持续在场 |

→ 不放逸**正交于** 锚 面（不与轻安在同一 维度 上竞争），而是轻安 锚 在事件流中持续在场的运作机制。

修行者 5/7 "等流轻安"已部分到位（基准 跃迁 已完成，调畅 锚 即时复位 / 不过夜）——这其实就是轻安 锚 在 时间域 已有部分持续在场，但**与不放逸的"常态守护"不同**：等流轻安是 锚 自身的稳态，不放逸是这个稳态在断恶 / 修善方向上的功能性发挥。

## 十、修行学含义

### 修行者当前位置精确诊断

修行者 5/7 自我诊断"心所配置已经能达标，但是禅定功夫不够"——经 5/12 不放逸学习精确化：

| 维度 | 现状 | 唯识精确位置 |
|---|---|---|
| **心所配置达标** | 锚 面（痴 / 嗔 / 痴 / 信 / 惭 / 轻安）+ 反应面 | 跨世已熏（证据 #1-#5）|
| **禅定功夫不够** | 精进**力**层尚未稳（"不自觉停下来 / 偷懒"）→ **不放逸尚未涌现** | **当前结构性 缺口** |

→ 5/7 修行重心 校准（闻思 基准 + 禅定主推进）获得**精确机制 锚**：

- **闻思 基准 的理由** = 锚 面已 稳态，不缺
- **禅定主推进的理由** = 精进**根→力**转变 = 不放逸涌现的**关键通道**
- **路径 风险 #4 的精确显现机制** = "不自觉停下来 / 偷懒"恰好是闻思快奖励区把实修慢产出区挤掉的具体形态——不是有意选择，是力层未稳时违缘倾动的自然结果

### 跨善心所重启 模式 的精确化

按假说 7（激活休眠种子 ≠ 从零累积），修行者跨世种子势力较厚的多个心所面已 稳态——但 5/12 让"已 稳态"的精确边界浮现：

- ✅ **已 稳态**：锚 心所（无痴 / 无嗔 / 无贪 / 惭愧 / 轻安）的"根"层 + 部分"力"层
- 🟡 **未 稳态**：精进的力层 + 不放逸的涌现

→ 修行者重启 模式 是"多个 锚 已 稳态 + 守护面 / 力层 缺口"——这层精确化补完了之前"全面已熏"的粗略 框定。

### 不放逸"建立"与"现行"的修行方式同构

修行者 5/12 推导："'建立不放逸'和'让已有的不放逸现行'其实修行方式是一样的"——精确机制：

| 心所 | 跨世状态 | 主要修行通道 |
|---|---|---|
| 无痴 / 无嗔 / 无贪 / 惭愧 / 轻安（锚 面）| 已熏 | **双线**：线 1 烦恼种子弱化 + 线 2 闻思 + 定中持守 锚 |
| 不放逸（守护面）| 未涌现 | **单线**：事件层频次累积 → 精进根→力转变 → 自然涌现 |

不放逸不是 锚，没有"闻思 深挖 通透"的独立通道，**"建立"和"现行"修行方式几乎完全相同**（都是事件层频次累积）——这是守护面运作机制层的结构性特征。

### "不应跳过精进直奔不放逸"对偶警告

与 [精进.md §六"不应跳过精进直奔行舍"](精进.md#精进-vs-行舍的位次差异) 同结构警告：

| 错误路径 | 失败模式 |
|---|---|
| 跳过精进直奔不放逸 | 没有动力源，"守护"沦为放任 / 散乱 |
| 跳过精进直奔行舍 | 没有下层支撑，"无功用"沦为放任 |
| 加行期硬要"无功用" | 干预——精进的加行阶段不需要无功用介入 |
| 任运期硬要"勇悍" | 干预——行舍的成熟阶段不需要意志介入 |
| 熟习期硬要单纯"精进" | 不放逸缺位的精进，易疲劳易退失 |

修行者 5/12 不放逸 触发 设计 不是"跳过精进直奔不放逸"——而是用 触发 让精进**根→力**转变的事件层频次得以累积。设计 本身不是不放逸，是不放逸涌现的通道。

### 5/14 修行者关键 自我修正：征兆 / 标的 分判（假说 17 在元方法论层应用）

修行者 5/14 主动 深挖："**这（时间预期 候选）没有什么区别，不影响实际操作的任何内容，还是只要反复通过行为熏精进的种子即可。**"

这层 自我修正 是**假说 17（征兆 vs 标的 区分）在 元-discussion 层面的现量印证**：

| 层 | 内容 | 性质 |
|---|---|---|
| 时间预期 (候选 1/2/3) | 可观察预期 | **征兆** |
| 行为熏精进种子（事件层频次累积）| 修行实际通道 | **标的** |
| "选哪个 候选" | 修行者元层决定 | 把 征兆 拔高 为 标的 = 错位 |

→ 修行者主动识别 征兆 / 标的 错位并 自我修正——之前假说 17 是教学者引导的元方法论，5/14 由修行者主动应用 = 显现 已在场。

### 时间预期 候选 2 确认 + "启动容易 vs 持续动力稳定"分判

**候选 选择**（修行者 5/14 确认）：**候选 2（部分激活 + 部分累积）**——跨世已有部分精进力种子，但需 reactivation + build；1-2 周可见早期信号 + 1-2 月 显现 稳态。

**"启动容易 vs 持续动力稳定"精确分判**（修行者 5/14）：

| 维度 | 现状 | 唯识层位置 |
|---|---|---|
| **启动容易** | 触发 落地稳定，触发信号立刻让念唤起 | 九住心**内住 / 续住**：听闻力 + 思惟力——已到位 |
| **持续动力稳定** | 实修的稳定动力尚未确认 | 九住心**安住 / 近住**：念力 / 正知力——当前 缺口 |

→ 修行者**精确在内住 / 续住 → 安住 / 近住的过渡期**，与 5/12 自诊 "精进根已起步 + 力层未稳"完全一致。

**Target 明确**：反复通过行为熏精进种子。时间预期作为 征兆 监测，不作为 标的 深挖。

### 监测信号（参考假说 7 + 假说 17）

**正面 signals**：
- 触发 时刻"自动"切换念所缘（不需 用力 决定）

- 修行外时段也开始出现"念回到善法所缘"的现量觉察（无外引）

**warning signals**：
- 用力鞭策"不舒服 / 强迫感"出现（熏习卫生学违反）
- "我已经能不放逸了"的自我形象浮现 = **修行者相 / 不放逸者相**（锚表述偏移 的不放逸场变形——与 [无痴.md §八](无痴.md) "看穿者我相" / [轻安.md §七](轻安.md) "修行者相 / 解脱者相"同构）
- 单纯 深挖 速度（"我能更快入座"）= 征兆 / 标的 错位（假说 17）

> **新增 锚表述偏移 监测项**：不放逸场的"我已经能不放逸了 / 我是个能 成立 修行优先级的人"自我形象——已纳入 [跨阶段回填清单](../../../CLAUDE.md#跨阶段回填清单) 锚表述偏移 监测
