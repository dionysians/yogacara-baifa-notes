> **开始日期**: 2026-03-05
> **预计时长**: 4-6周
> **当前状态**: 进行中

## 📖 阶段概述

心所法是百法中数量最多的一类（51法），指与心王（八识）相应的心理活动。心所有法依心王而起，与心王同时运行，是对心理活动更细致的分析和分类。

"心所"全称"心所有法"，意为"心所拥有的法"，即属于心的作用。每一个心所都有四义：
1. **恒依心起** — 永远依赖心王才能生起
2. **与心相应** — 与心王同时活动
3. **系属于心** — 从属于心王
4. **与心同缘** — 与心王缘同一对象

理解心所法，就是理解我们内心世界的全部心理现象。

### 心所的本质

心所不是独立存在的东西，而是**心王运作时附带的具体心理功能**。离开心王，心所就不存在——"触"永远是"某个识的触"，"受"永远是"某个识的受"。五十一个心所是对心理功能的分类体系，但在实际运作中，每个识的每个心所都是那个识自己的、独立的（《成唯识论》卷七："此触等五，各各别有"）。

### 八识与心所的配置

并非每个识都有全部51个心所。《成唯识论》对八识各自配多少心所有明确说明：

| 识 | 心所数量 | 具体配置 |
|---|---|---|
| **阿赖耶识** | 5个 | 仅遍行五：作意、触、受、想、思 |
| **末那识** | 18个 | 遍行5 + 别境1（慧）+ 烦恼4（贪、痴、慢、我见）+ 大随烦恼8 |
| **前五识** | 34个 | 遍行5 + 别境5 + 善11 + 中随2 + 大随8 + 根本烦恼3（贪、嗔、痴） |
| **意识** | 51个 | 全部都可以生起 |

- **阿赖耶识最少**（仅5个遍行）——只做最基础的含藏和变现，不做判断、不起烦恼、不生善念
- **意识最多**（全部51个）——心理活动最丰富的识，善恶烦恼都在意识层面展开
- **末那识有烦恼**（贪、痴、慢、我见）——恒常执"我"本身就是烦恼活动
- **前五识没有小随烦恼**（忿、恨等）——小随烦恼需要概念化的分别，前五识做不到

### 为什么遍行心所排第一

遍行心所是唯一**横贯八识**的心所——遍一切心、遍一切时、遍一切处。无论哪个识运作，五个遍行必然全部俱起。它们是理解整个心所体系的基础，因此排在第一位学习。

### 五蕴与百法的对应

五蕴（pañca-skandha）是佛教对一切有为法的另一种分类方式——按**对轮回的功能**分类，与百法按**法的性质**分类互补：

| 蕴 | 含义 | 对应百法 |
|---|---|---|
| **色蕴** | 一切物质/物理现象 | 色法（11法） |
| **受蕴** | 感受 | 受（1个心所，单独成蕴） |
| **想蕴** | 取像/概念形成 | 想（1个心所，单独成蕴） |
| **行蕴** | 造作/意志活动 | 思 + 其余49个心所 + 心不相应行法24法（共73法） |
| **识蕴** | 了别/认知 | 心法（八识） |

```
百法（94有为法 + 6无为法 = 100法）：
  心法(8) + 心所法(51) + 色法(11) + 心不相应行法(24) + 无为法(6)

五蕴（只含94有为法）：
  色蕴(11) + 受蕴(1) + 想蕴(1) + 行蕴(73) + 识蕴(8)
```

**受和想各只有一个心所却各自单独成蕴**——说明它们对理解轮回太重要了：受是轮回的驱动引擎（起爱为业），想是"我"的建构者（颠倒想）。行蕴以**思**为主将——"行"的核心含义就是"造作"，与思的定义"令心造作"完美对应。百法更适合做精密的心理分析，五蕴更适合修行中的观照（"五蕴皆空"）。

## 📚 学习内容

### 核心概念 (51个)

#### 遍行心所 (5个) — 最基础的心理活动

> 每一刹那的心识活动都伴随这五个心所，遍一切心、遍一切时、遍一切处。

- [ ] [触](./遍行心所/触.md) — 根、境、识三者和合
- [ ] [作意](./遍行心所/作意.md) — 引心趣境，使心警觉
- [ ] [受](./遍行心所/受.md) — 领纳顺违等境相
- [ ] [想](./遍行心所/想.md) — 取像施设，安立名言
- [ ] [思](./遍行心所/思.md) — 令心造作，推动行为

#### 别境心所 (5个) — 特定条件下生起的心理活动

> 各别缘境而起，不一定同时生起。

- [ ] [欲](./别境心所/欲.md) — 对所乐境的希望
- [ ] [胜解](./别境心所/胜解.md) — 对所认定事物的坚定理解
- [ ] [念](./别境心所/念.md) — 对曾习境的明记不忘
- [ ] [定](./别境心所/定.md) — 令心专注一境
- [ ] [慧](./别境心所/慧.md) — 对所观境的简择判断

#### 善心所 (11个) — 修行要培养的善良心理

> 善的心理品质，修行中需要培养和增长。

- [ ] [信](./善心所/信.md) — 对三宝、因果等的信心
- [ ] [精进](./善心所/精进.md) — 勇猛修善、断恶
- [ ] [惭](./善心所/惭.md) — 自省而羞耻
- [ ] [愧](./善心所/愧.md) — 对人而惭愧
- [ ] [无贪](./善心所/无贪.md) — 于三有及三有因无执着
- [ ] [无嗔](./善心所/无嗔.md) — 于苦及苦因不生恚恨
- [ ] [无痴](./善心所/无痴.md) — 于事理明解
- [ ] [轻安](./善心所/轻安.md) — 身心调畅安适
- [ ] [不放逸](./善心所/不放逸.md) — 依无贪等防修为性
- [ ] [行舍](./善心所/行舍.md) — 心平等正直无功用住
- [ ] [不害](./善心所/不害.md) — 于诸有情不为损恼

#### 烦恼心所 (6个) — 修行要对治的根本烦恼

> 六根本烦恼，是一切烦恼的根源，障碍修行解脱。

- [ ] [贪](./烦恼心所/贪.md) — 于有有具染着为性
- [ ] [嗔](./烦恼心所/嗔.md) — 于苦苦具憎恚为性
- [ ] [痴](./烦恼心所/痴.md) — 于诸理事迷暗为性（又名"无明"）
- [ ] [慢](./烦恼心所/慢.md) — 恃己于他高举为性
- [ ] [疑](./烦恼心所/疑.md) — 于诸谛理犹豫为性
- [ ] [恶见](./烦恼心所/恶见.md) — 于诸谛理颠倒推求（含身见、边见、邪见、见取见、戒禁取见）

#### 随烦恼心所 (20个) — 从根本烦恼衍生的烦恼

> 随根本烦恼而起，分为小随烦恼(10)、中随烦恼(2)、大随烦恼(8)。

**小随烦恼 (10个)** — 各别而起，行相粗猛

- [ ] [忿](./随烦恼心所/忿.md) — 依对现前不饶益境，愤发为性
- [ ] [恨](./随烦恼心所/恨.md) — 由忿为先，怀恶不舍
- [ ] [覆](./随烦恼心所/覆.md) — 于自作罪，恐失利誉，隐藏为性
- [ ] [恼](./随烦恼心所/恼.md) — 忿恨为先，追触暴热
- [ ] [嫉](./随烦恼心所/嫉.md) — 殉自名利，不耐他荣
- [ ] [悭](./随烦恼心所/悭.md) — 耽著财法，不能惠舍
- [ ] [诳](./随烦恼心所/诳.md) — 为获利誉，矫现有德
- [ ] [谄](./随烦恼心所/谄.md) — 为罔他故，矫设异仪
- [ ] [害](./随烦恼心所/害.md) — 于诸有情，心无悲愍，损恼为性
- [ ] [憍](./随烦恼心所/憍.md) — 于自盛事，深生染著，醉傲为性

**中随烦恼 (2个)** — 遍不善心

- [ ] [无惭](./随烦恼心所/无惭.md) — 不顾自法，轻拒贤善
- [ ] [无愧](./随烦恼心所/无愧.md) — 不顾世间，崇重暴恶

**大随烦恼 (8个)** — 遍染污心

- [ ] [掉举](./随烦恼心所/掉举.md) — 令心于境不寂静
- [ ] [惛沉](./随烦恼心所/惛沉.md) — 令心于境无堪任
- [ ] [不信](./随烦恼心所/不信.md) — 于实德能不忍乐欲
- [ ] [懈怠](./随烦恼心所/懈怠.md) — 于善恶品修断事中，懒惰为性
- [ ] [放逸](./随烦恼心所/放逸.md) — 于染净品不能防修
- [ ] [失念](./随烦恼心所/失念.md) — 于诸所缘不能明记
- [ ] [散乱](./随烦恼心所/散乱.md) — 于诸所缘令心流荡
- [ ] [不正知](./随烦恼心所/不正知.md) — 于所观境谬解为性

#### 不定心所 (4个) — 善恶不定的心理活动

> 非善非恶，随缘而善恶不定。

- [ ] [悔](./不定心所/悔.md) — 恶作，于已作业追悔为性
- [ ] [眠](./不定心所/眠.md) — 令身不自在，昧略为性
- [ ] [寻](./不定心所/寻.md) — 令心匆遽，于意言境粗转为性
- [ ] [伺](./不定心所/伺.md) — 令心匆遽，于意言境细转为性

## 🗺️ 学习顺序

> **节奏建议**：每次讨论聚焦2-3个心所，重点理解经典定义和彼此关系，不求快。

### 第一阶段：遍行心所（5法）— 地基

**触 → 作意 → 受 → 想 → 思**

遍行心所"遍一切心、遍一切时、遍一切处"，是每一刹那心识活动的标配。不理解遍行，后面所有心所都缺少运作框架。这五个之间有内在的认知流程顺序：触是连接，作意是警觉，受是感受，想是概念化，思是意志推动。

### 第二阶段：别境心所（5法）— 条件分化

**欲 → 胜解 → 念 → 定 → 慧**

别境心所"各别缘境"而起，与遍行形成对比——遍行是必然有，别境是条件具备才有。这五个也是修行中反复提到的核心能力（尤其念、定、慧），先学它们能为后面理解善/烦恼心所打下基础。

### 第三阶段：烦恼心所（6法）— 认识病根

**贪 → 嗔 → 痴 → 慢 → 疑 → 恶见**

在善心所之前先学烦恼。原因：善心所中的无贪、无嗔、无痴是直接对治烦恼的，先认识"病"，再学"药"会更有体感。六根本烦恼是一切心理问题的源头，痴（无明）尤为核心。

### 第四阶段：善心所（11法）— 修行的药方

**信 → 精进 → 惭 → 愧 → 无贪 → 无嗔 → 无痴 → 轻安 → 不放逸 → 行舍 → 不害**

有了对烦恼的认识，再学善心所就能理解每一个善法是如何对治相应烦恼的。善法之间也有层次：信是基础，三善根（无贪无嗔无痴）是核心，不放逸和行舍是综合运用。

### 第五阶段：随烦恼心所（20法）— 烦恼的枝末

按小→中→大的顺序：

- **小随烦恼**（10）：忿→恨→覆→恼→嫉→悭→诳→谄→害→憍
- **中随烦恼**（2）：无惭→无愧
- **大随烦恼**（8）：掉举→惛沉→不信→懈怠→放逸→失念→散乱→不正知

小随是具体的、行相粗猛的烦恼，容易在日常中辨认；中随遍一切不善心；大随遍一切染污心。从具体到普遍，理解会更自然。

### 第六阶段：不定心所（4法）— 收尾

**悔 → 眠 → 寻 → 伺**

不定心所善恶随缘，性质独特，放在最后学习时可以与前面所有心所形成对照。

## 📝 讨论范例

> 以下是一次讨论的范例，展示每次聚焦2-3个心所时的讨论方式。

### 范例：第一次讨论 — 触与作意

#### 1. 经典定义对读

先把两个心所的经典定义放在一起：

| | 触 | 作意 |
|---|---|---|
| **《成唯识论》** | 触谓三和，分别变异，令心心所触境为性，受想思等所依为业 | 作意谓能警心为性，于所缘境引心为业 |
| **体性** | 令心心所接触到所缘境 | 使心警觉、注意 |
| **业用** | 作为受、想、思等的依止 | 将心引向所缘境 |

#### 2. 关系辨析：谁先谁后？

讨论核心问题：触和作意在认知过程中的先后关系。

- **论典依据**：《成唯识论》说五遍行"此中触等亦各一故"，五个同时俱起，严格说没有时间先后
- **逻辑顺序**：但从功能上可以分析——作意是"引心趣境"（把心引向对象），触是"三和"（根境识和合），似乎作意在前（先警觉），触在后（才接触）
- **待深入问题**：如果五遍行同时俱起，"先后"只是逻辑分析而非时间顺序？这个"同时"如何理解？

#### 3. 日常观察练习

用一个具体场景把两个概念落地：

> **场景**：你正在看书，突然听到门铃响。
>
> - **作意**：心从书本"转向"门铃声——这个警觉、注意力转移的瞬间就是作意的作用
> - **触**：耳根、声境、耳识三者和合——你的听觉真正"接触到"了门铃声
> - **观察要点**：注意"心被牵引过去"（作意）和"真正听到了"（触）之间微妙的区别

- 更新 `触.md` 和 `作意.md` 中的相关章节
