## 💬 定义

**定**（三摩地，Samādhi）是使心专注于所观察的对象、不散乱的心理作用。"定"不是昏沉或空白，而是心高度清明地安住在一个对象上——既不散乱跑掉，也不昏暗模糊。

打个比方：定就像一盏不被风吹动的灯。在无风的房间里，灯火稳定不摇晃，照亮的范围清清楚楚。心也一样——当定力具足时，心不被外境的"风"吹得东倒西歪，能够稳定地、持续地照亮（了知）所缘境。

定是别境心所，只在面对"所观境"（选定的观察对象）时才生起。日常散乱中虽然心也在运作，但没有真正的定。

---

## 🎯 核心特征

1. **于所观境令心专注不散为性**: 定的体性是让心专注于所观的对象，不散乱到其他地方。关键词是"专注"和"不散"
2. **智依为业**: 定的功能是作为智慧（般若）的依止。心不散乱时，才能产生深度的观察和洞见。"定能发慧"就是这个道理
3. **别境性**: 只在特定条件下（面对所观境、心具备专注力时）才生起。不是八识恒有
4. **通三性**: 定本身中性。专注于善法是善定（如修四禅八定），专注于恶念是恶定（如专心谋害他人），专注于无记事是无记定。详细展开（染定的精确化 / 与散乱的关系 / 染分对偶结构）见下文「定的通三性与"染分对偶"」
5. **心一境性**: 定的另一个名称。"心"安住于"一"个"境"，这个状态就是定
6. **非独指禅定**: 百法中的"定"（别境心所）是广义的心专注作用，不限于打坐入定。日常专注地读书、专注地听课，也有定心所在运作

## 🔄 定在戒定慧三学中的位置

### 三学的修行链条

```
戒（持戒清净，减少散乱的外缘）
  ↓
念（对所缘境明记不忘）
  ↓
定（心专注一境，不散乱）
  ↓
慧（在定中生起深度洞察，如实了知）
  ↓
解脱（以慧断惑，证得涅槃）
```

定在这条链上承上启下：**由戒生定，由定发慧**。

### 定的层次

定不是只有一个"定"或不定的二元状态，而是有深浅层次：

| 层次 | 名称 | 说明 |
|---|---|---|
| 日常 | 散心中的专注 | 读书、做事时的短暂专注，也有定心所 |
| 欲界定 | 欲界散地定 | 较为稳定但尚未进入禅定 |
| 未到地定 | 近分定 | 接近初禅但未正式进入 |
| 初禅 | 色界初禅 | 离生喜乐，有寻有伺 |
| 静虑中间 | 中间静虑 | **无寻唯伺**——初二禅之间别出的一档定地，修之感大梵果 |
| 二禅 | 色界二禅 | 定生喜乐，无寻无伺 |
| 三禅 | 色界三禅 | 离喜妙乐 |
| 四禅 | 色界四禅 | 舍念清净 |
| 四空定 | 无色界四定 | 空无边处至非想非非想处 |

所有这些层次中的"定"，本质上都是同一个别境心所——只是强度和深度不同。

### 定在念定慧链条中的位置（2026-04-22）

> 本节是对"念→定→慧"整体骨架的定位；完整展开见专题文档 [念定慧的内在链条：从比量到现量](./念定慧的内在链条：从比量到现量.md)。

#### 稳压器 / 电源比喻：定不生慧

关于"定智依为业"最常见的误读是把它理解成"定生出慧"。经本轮讨论厘清，更准确的表述是：

> **定不是发电机，定是稳压器。** 真正的电（慧）来自闻思修。但没有稳压器，电压不稳，灯泡要么不亮，要么烧掉。

用唯识因果论精确表达：

| 关系 | 含义 | 对应 |
|---|---|---|
| **亲因** | 直接产生某法的种子 | 慧的亲因是**慧心所种子**，由闻思修熏成 |
| **所依 / 增上缘** | 让某法得以现行的平台 | **定是慧的所依**——"定智依为业" |

#### 外道四禅八定为何不解脱

在这个框架下，外道不解脱的原因并非"定不能生慧"，而是：

**外道阿赖耶识里没有正见的种子可以被定调出来。**

外道修定 = 有稳压器、有灯泡，但**插头插错了电源**——连的是"常见 / 断见 / 梵我"的种子。定再深，简择出来的也是"我是梵""灵魂永恒"这类邪见的深化。定在这里反而成了邪见的**加固器**——与定心所通三性一致。

佛陀的突破不在于定比外道深（佛陀已修到非想非非想处），而在于他带着"缘起""无我"的思慧种子进入定中，在第四禅中以这些种子为所缘简择，才证得解脱慧。

#### 伏惑 vs 断惑：定与慧的分工

这里要精确区分经典的两个范畴：

- **定的功能**：暂时**伏**烦恼（压住现行，种子仍在）
- **慧的功能**：彻底**断**烦恼（直照种子，根本灭除）

对修行者来说这意味着：

- **散心位**：我执以粗猛方式现行（贪嗔慢随时起），慧被它们不断打断、扭曲
- **定中**：粗分我执被伏住（不现行），末那识的俱生我执仍在相续，但暂时不骚扰意识
- **定中慧起观**：意识带着正见种子简择，才能反照到末那识的我执运作
- **见道一刹那**：慧真正照穿俱生我执，种子被断

**关键**：定伏的是"现行我执"，慧断的是"种子我执"。定再深也只是把烦恼按下，真正拔根必须靠慧。

#### 定对慧的真实贡献："滤波"让现相显露

对慧而言，定的最关键贡献是**让心相的真实运作从噪声中独立显露**：

- 散心位八识俱起、五十一心所杂然并现，我执混在噪声里看不出独立轮廓 → 慧只能以比量标记它"在那里"
- 定位粗分散乱伏住 → 俱生我执在相续中成为显著运作 → 慧简择的对象不再是概念，而是现相 → 现量产生

这就是思慧跃迁为修慧的机制。详见专题文档中的"滤波机制详解"章节。

### 定与散乱的对比

| | 定（别境心所） | 散乱（随烦恼心所） |
|---|---|---|
| 心的状态 | 专注一境 | 东散西荡 |
| 认知品质 | 清明、深入 | 浮浅、杂乱 |
| 后续效果 | 为慧提供基础 | 使心无法深入 |
| 修行意义 | 三学核心之一 | 修行最大障碍之一 |

## 🌟 日常实例

1. **全神贯注读书**: 读到入迷时，外面的声音都听不见了——这就是定心所在强力运作。虽然不是禅定，但同一个心所在起作用
2. **运动员的"心流"状态**: 篮球运动员在关键时刻进入"zone"——外界仿佛慢动作，自己的动作异常清晰流畅。这是高度的定配合身体技能的表现
3. **打坐时的昏沉**: 坐在那里闭着眼，但心模模糊糊的——这**不是**定。定的特征是清明和专注，昏沉只是另一种散乱
4. **刷手机时的"专注"**: 刷短视频两小时——虽然看起来很"专注"，但心不断在新内容间跳转。这更接近散乱而非真正的定。真正的定是心安住于一个对象

## 📝 定的两种修法

### 止（奢摩他，Śamatha）

止是专门培养定力的修法。选一个所缘境（如呼吸、佛号、光明等），反复将心安住于此：

```
选定所缘（如呼吸）
  ↓
以念持守（明记所缘不忘）
  ↓
心散乱时，以作意拉回
  ↓
反复训练
  ↓
定力逐渐增强（从欲界定到色界定）
```

### 止观双运

单纯的定没有解脱力——外道也能修到四禅八定。佛法强调止观双运：

- **止**（定）：让心安住不动
- **观**（慧）：在安住中如实观察

止提供稳定的平台，观在平台上工作。只有止没有观，像一潭死水；只有观没有止，像风中的烛火。

### 九住心

培养定力的九个阶段：

1. 内住 - 把心拉回所缘
2. 等住 - 持续安住
3. 安住 - 散乱时快速回来
4. 近住 - 心更加靠近所缘
5. 调顺 - 克服粗分散乱
6. 寂静 - 克服细分散乱
7. 最极寂静 - 微细散乱也能觉察
8. 专注一趣 - 不间断地专注
9. 等持 - 任运自然地安住

九住心就是定心所从弱到强的渐进过程。

## 🧘 修行意义

1. **"由定发慧"是核心原理**: 没有定的慧是浮浅的理解，有定的慧是直接的洞察（现量）。理论上知道"无常"和亲证"无常"，差别就在定力
2. **日常生活中也要修定**: 不只是打坐时才修定。做任何事都全神贯注、不散乱，就是在培养定心所的力量
3. **定的障碍**: 掉举（心太活跃）和昏沉（心太暗淡）是定的两大障碍。修定就是在掉举和昏沉之间找到那个清明而专注的中道

## 💡 学习心得

- 百法中的"定"（别境心所）比通常理解的"打坐入定"要宽泛得多。专注做任何事时都有定在运作——这让"修定"变得日常化、可操作化
- "智依为业"说明定不是目的，而是手段——定是为了生慧，慧是为了解脱。执著于定境本身反而成了障碍
- 现代人最缺的可能就是定——信息过载、注意力碎片化，定心所长期处于虚弱状态。从唯识角度看，这意味着慧也很难深入

## 🧩 别境"定"与禅定的关系（2026-04-22）

> 本节解答第一个待深入问题：别境心所的"定"和"禅定"（四禅八定）如何对应？

### 通与别的关系（不是并列）

两者不是"一类定 vs 另一类定"（并列关系），而是：

> **别境心所的"定"是**心一境性**这一心所层面的普遍功能；四禅八定是这个心所在特殊因缘（修止 + 特定所依身 + 特定心所配置）下形成的**稳定等持**。两者是"同一个心所在不同条件下的现行形态"，是**通与别**的关系。**

所以"禅定是定心所的特殊形态"这一直觉方向对，但"特殊"二字的展开比一般理解复杂。

### 禅定次第是三维同时渐进

禅定深入不只是"所缘细微化"单一维度，而是三个维度**同时变化**：

| 维度 | 具体变化 |
|---|---|
| **A. 所缘的细微化** | 粗色（呼吸、佛相）→ 精细色法 → 色法舍弃 → 无色所缘 |
| **B. 心所配置的精炼化** | 伴随定同时现行的心所越来越少（喜、乐、寻、伺依次脱落） |
| **C. 所依身的脱落** | 欲界身 → 色界心身 → 无色界心（完全脱离色法依附） |

### 完整次第结构表

| 定位 | 所缘（A） | 心所配置（B） | 所依（C） |
|---|---|---|---|
| 欲界散心定 | 粗色对象，易转移 | 所有心所杂然并现 | 欲界身 |
| 初禅 | 专注所缘（粗可转向细） | **寻、伺、喜、乐、心一境性**（五支） | 色界初禅天相应 |
| 静虑中间 | 同上而更寂 | **先舍寻，唯余伺**——寻伺不是同时脱落 | 大梵天相应 |
| 二禅 | 所缘稳定，不需推寻 | **伺亦舍**，留喜、乐、心一境性 | 色界二禅天相应 |
| 三禅 | 所缘更内向 | **舍喜**，留乐、心一境性 | 色界三禅天相应 |
| 四禅 | 纯粹内定相 | **舍乐**，唯舍念清净 + 心一境性 | 色界四禅天相应 |
| 空无边处 | 缘"虚空无边" | 色想舍弃 | 无色界，完全脱色法 |
| 识无边处 | 缘"识无边" | 空想舍弃 | 无色界 |
| 无所有处 | 缘"无所有" | 识想舍弃 | 无色界 |
| 非想非非想处 | 极微细相 | 想极微弱 | 无色界，最深世间定 |

三维同时发生。单独看所缘细微化（A 列）解释不了为什么二禅比初禅"深"——真正的深在 B 列（寻伺脱落，定不再需要主动推寻）。

> **2026-07-28 校正（不定四法收官）**：原表把寻伺作一并脱落处理，缺"静虑中间"一档，已补入。《瑜伽师地论》卷四明说欲界及初静虑"**除静虑中间**"为有寻有伺地，静虑中间若定若生为无寻唯伺地，第二静虑以上方为无寻无伺地——**寻先舍、伺后舍，中间别有一地**。另须留意两点：① 三地依寻伺**有染离染**而立，"不由不现行故"，坐中一时无寻伺不能据以判地；② 心所精炼的是**处理动作**而非简择本身，慧一路到底——依第二静虑以上诸静虑仍能发无漏慧断惑。详见[伺 §五 / §六](../不定心所/伺.md)。

### "心所脱落"才是深入的主线

这里有一个重要原理，与 [念定慧的内在链条：从比量到现量](./念定慧的内在链条：从比量到现量.md) 中"定 = 稳压器 / 滤波器"一致：

- **所缘细微化是结果，不是原因**
- 真正让定"更深"的，是**同时现行的心所越来越少**，心境中的"噪声"越来越低
- 噪声低了，原本被噪声掩盖的更细微所缘才能成为主导
- 所以：**心所配置精炼 → 滤波效果增强 → 更细微的所缘成为可能**

四禅八定的层层深入，本质就是**滤波精度逐级提升**——每一层都关掉一些心所的现行。这是"由定发慧"能够落实的基础：只有噪声低到一定程度，慧简择的对象才能从"概念标记"（比量）跃迁为"现相直照"（现量）。

### 至关重要的边界：禅定深 ≠ 解脱

非想非非想处是**世间最深的定**——所缘极微细、心所极简、所依完全脱色。按单维度理解它应该最接近解脱。但实际上：

> **四禅八定最深的非想非非想处，仍是凡夫境界。外道修到此处一样不解脱。**

原因在于：

- 定再深也只是**伏惑**（压住现行我执），不断种子我执
- 没有正见的定，像外道走到非想非非想后就卡住——**定力无法替代慧力**
- 要解脱必须在定中起慧观照末那识的俱生我执

### 双轴观：量轴 vs 质轴

这一立场带出一个关键的区分：

- **四禅八定的深浅维度**：所缘细微 + 心所精炼 + 所依脱色（**定的量轴**）
- **灭尽定所在的维度**：定中起慧 → 末那识染污部分止息（**定慧的质轴**）

**"深度"有两个正交的轴**：

| 轴 | 刻度 | 代表 |
|---|---|---|
| **量轴**（世间定） | 所缘细微、心所少、所依脱色 | 四禅八定（凡夫外道皆可入） |
| **质轴**（出世间修） | 定中起慧、伏染到见慧断染 | 灭尽定（仅圣者可入） |

灭尽定**不是"比非想非非想处更深的定"**——它是**另一个方向**的成就。它用的是定 + 慧，而不仅是定。这也是为什么灭尽定只有圣者能入，而四禅八定凡夫外道皆可入。

这一双轴框架也为下一题（无想定 vs 灭尽定中定心所的运作）提供了定位：

- **无想定** = 在第四禅之后、**仅凭定力**压住心心所的短路径 → 走的是**量轴**的异常分支
- **灭尽定** = **定 + 慧**使末那识染污部分止息 → 走的是**质轴**

两者在这张双轴图上位置泾渭分明。

### 回到基本立论

"禅定是一类特殊的定，随着禅定的逐渐深入，定安住的对象就越细微"的精确版本：

> **禅定是别境"定"心所在"修止 + 特定所依 + 特定心所配置"三因缘下形成的稳定等持。四禅八定的逐级深入同时发生在三个维度：所缘细微化、心所配置精炼化、所依身逐级脱色。其中"心所精炼"是主线，所缘细微化是结果而非原因。但四禅八定再深仍属世间凡夫境界；真正超越需要另一个正交维度——定中起慧（如灭尽定）。**

> **学术诚实标注**：
> - 第一层：四禅八定的所缘、支数、心所配置、所依界地——均见《俱舍论》《瑜伽师地论》《大毗婆沙论》等；"定"通三性通诸界、"禅"特指色界四禅的语词区分——见经典；四禅八定不解脱、灭尽定是圣者之境——经典立场。
> - 第二层：把"心所精炼是主线、所缘细微化是结果"作为禅定深入的因果表达、连回"定是滤波器"作为同构解释——基于心所论与定体系的整理性重构。
> - 第三层："禅定深浅是量轴、定慧质轴与之正交"的双轴表述——基于经典"定不解脱、慧方断惑"立场的推论性整合。

## 🧩 无想定、灭尽定中"定心所"的去向（2026-04-22）

> 本节解答第二个待深入问题：无想定和灭尽定中，别境心所的"定"是否还在运作？

### 先守住一条原理：心所依识而起

讨论这个问题必须先回到心所的基本性质：

> **心所是依心王（识）而起的——心所不能脱离识独立运作。哪个识不起，对应的心所就不起。**

按 [03-心所法 README](../README.md) 的心所配属：

- 前五识各有 34 个相应心所
- 第六意识有全部 51 个心所
- 第七末那识有 18 个相应心所
- 第八阿赖耶识**只相应遍行 5 个心所**（作意、触、受、想、思）——**没有定**

**定心所属于"别境"，不属于遍行**——这一差别在两种无心定的讨论中起决定作用。

### 关键判断

> **两种无心定中，定心所本身都不现行。**

理由：别境定心所只在前六识和末那识中相应。两种无心定中前六识全部止息 → 六识相应的所有心所（包括定心所）随之止息。

### 两种无心定的完整对比

| | 无想定 | 灭尽定 |
|---|---|---|
| 入定前 | 第四禅基础上**纯定力**压住意识 | 圣慧伏染后**定慧双运** |
| 入定中前六识状态 | 止息 | 止息 |
| 入定中末那染污 | **仍在运作**（只伏六识，不触末那染污） | **止息**（圣慧伏力延续） |
| 入定中定心所 | **不现行**（随意识止息） | **不现行**（随意识止息） |
| 入定中在运作的 | 阿赖耶识 + 遍行五 + 末那识（染+净） | 阿赖耶识 + 遍行五 + 末那识（仅净分） |
| 凡/圣 | 凡夫外道皆可入 | 仅圣者可入 |

**两个共同点**：

- 两种定中**定心所都不现行**——因心所随识起
- 两种定名里的"定"都是**境界名**（等持境界），不是心所持续运作的指称

**关键差别**在**末那的命运**：

- **无想定**只伏前六识，末那染污依然运作（只是失去了前六识作所缘）——"关屏幕没关机"
- **灭尽定**因有慧伏，末那染污也止——"真正关机"

（详见 [心法阶段总结的"定压慧破"洞见](../../02-心法/stage_summary.md)）

### "灭尽定"里的"定"字不是指心所运作

这里必须澄清一个容易产生的误解：如果定心所都止息了，为什么还叫"灭尽**定**"？

> **"灭尽定"里的"定"指的是一种**等持境界**（samāpatti），不是指"定心所的持续运作"。**

"灭尽"是对整个状态的命名——这个状态**整体上**是一种稳定等至，但构成这个状态的**具体心所运作**恰恰是"大部分止息"。境界的名称和心所的运作是两个层面的事。

类比：你不会说"无想定中想心所在运作"——恰恰相反，无想定里想心所止息了，"无想"就是它的定义。同理灭尽定里前六识全止息、末那染污止息——"灭尽"就是它的定义。

### 末那染污在灭尽定中"继续止息"的机制

一个值得追问的问题：既然定中连慧心所都不现行了，是什么让末那染污持续处于不起状态？

经典的回答不是"有一个心所在持续压制"，而是：

> **入定前以圣者的慧力（无我慧）伏染末那；一旦伏住并跨入灭尽定，整体状态稳定，染污末那无法起现行——这不是靠定中持续的"观照"维持的，而是**入定前加行力的延续 + 前六识止息后染污末那失去触发条件**的共同结果。**

时间线：

```
入定前（加行位）：
  定 + 慧双运
  ↓
  意识中的慧在运作，现量照见末那识染污
  ↓
  末那染污部分被伏
  ↓
进入灭尽定：
  前六识止息（意识→灭，慧心所也随之不现行）
  ↓
  定心所作为别境心所，也随意识止息
  ↓
  末那染污因失去被触发的条件 + 伏力的延续，不起现行
  ↓
定中：
  只剩阿赖耶识 + 遍行五（极微细）+ 末那净分
  没有"能观照的慧"也没有"持续运作的定"
```

**关键一步**：末那染污在定中不起，是因为**入定前已经被伏、且没有任何条件让它在定中起来**——不是定中还有什么东西在"观照"它。

### 见道与灭尽定的区别

把这一点和见道位对比可以看得更清楚：

| | 见道位 | 灭尽定 |
|---|---|---|
| 意识 | 在，慧心所现行 | 不在，慧心所不现行 |
| 对末那染污的作用 | **现量照破、断种子** | 不断种子，仅伏现行（伏力延续） |
| 运作方式 | 主动观行 | 等持稳态（不需做功） |
| 时机 | 加行位末一刹那 | 见道后的特殊等至境 |

所以**见道 ≠ 灭尽定**。见道的那一刹那是主动的慧穿透；灭尽定是充分伏染后达成的稳态。

### 一个更深的原理：稳态不一定需要持续做功

这里藏着一个容易被日常因果思维忽略的原理：**并非一切状态都靠"持续运作"维持**。

日常直觉假设："状态要维持，必须有某个运作在持续"——水要持续加热才能沸腾、灯要持续供电才能亮。

但唯识里存在一类**不需持续做功就能维持的状态**。灭尽定就是其一：它不是靠"持续观照"维持，而是靠**此前的加行 + 所依条件的缺失**让状态自然持续。这更接近"势能稳态"或"惯性"的思路，而不是主动做功。

这也正是为什么它叫"**等持**"（samāpatti）——"等"是平衡、持稳的意思。一旦进入，它自己能维持。

**修行上的隐含含义**：并非一切成就都靠"持续用力"。真正深的成就往往是**先用力建立结构、然后用力本身可以放下，结构自己稳定延续**——这在禅定、在戒律、在见道后的修行次第中是一条共通原理。

### 回到基本立论

这一题的精确回答：

> **无想定和灭尽定中，定心所本身都不现行——因别境心所依前六识而起，六识止息后定心所也随之止息。两种定之命名里的"定"是对整个等持境界的称谓，不是指定心所的持续运作。两者的关键差别不在定心所（都不现行）而在末那的命运——无想定中末那染污仍在，灭尽定中末那染污止息；后者是由入定前的圣慧伏力延续、而非定中持续观照所致。**

> **学术诚实标注**：
> - 第一层：心所依心王而起的基本原理、八识心所配属（阿赖耶识只相应遍行五）、灭尽定中末那染污止息（护法派立场）、无想定中末那染污仍运作、阿赖耶识在二无心定中相续不断——均见《成唯识论》卷三、卷五、卷七。
> - 第二层：把"加行位"和"定中"作为时间轴精细化两种定的机制、"灭尽定中连慧心所也不现行"——基于心所依识而起的原理推出，方向与经典一致。
> - 第三层：把"无想定 = 关屏幕没关机、灭尽定 = 真正关机"作为比喻性定位（见心法阶段总结洞见四）、"稳态不一定需要持续做功"作为一条跨领域的修行原理——基于框架的解释性归纳。

## 🧩 前五识的定：刹那内心一境性（2026-04-22）

> 本节解答第三个待深入问题：前五识是否有定？如果有，是怎样的定？

### 先守住前提：前五识有 34 心所，"定"在其中

按 [03-心所法 README](../README.md)：前五识各有 34 个相应心所，别境五法（欲、胜解、念、定、慧）**都在其内**。

所以经典立场明确：**前五识有定心所**。问题不是"有没有"，而是"是何种形态"。

### 前五识定的精确形态

前五识没有跨刹那的连续性（刹那生灭、不相续），所以它们的定**不可能是"跨时间的持续专注"**——那是意识的工作。

前五识的定表现为：

| 维度 | 内容 |
|---|---|
| **空间维度** | 在当下一刹那中，心所只缘"一境"而不散缘其他境（如眼识此刹那只取这个色，不同时跳到那个色） |
| **锐利度维度** | 所缘境在感官上的清晰度、精细度——定强则现量锐利，定弱则模糊浮浅 |

这与意识的定形成分工：

| 识 | 定的作用 | 时间结构 |
|---|---|---|
| **前五识** | 刹那内空间专一 + 现量锐利度 | 无跨刹那结构（每刹那独立） |
| **第六识** | 跨刹那持续导向同一所缘 | 跨时间连续性由意识承担 |

### "日常专注观察性境" = 前五识定 + 意识定共同作用

日常生活中"我专注地看这朵花"这类经验，其实是两层定的合作：

- **前五识定**：眼识在每一刹那都锐利地、不分散地取这朵花的色相——这是现量的"当下清晰"
- **意识定**：跨刹那持续把"关注的对象"锁定在花上，不跳到别的事——这是"持续不走神"

缺了前者，看也看不清（现量浮浅）；缺了后者，看一眼就跑（没有持续性）。日常所说的"专注"其实是两者的合力。

### 一个关键约束：前五识定不独立现行

前五识必与**五俱意识**俱起——五识现行时意识必同时在。所以"纯粹的前五识定"在现实中**不会独立出现**，一定伴随意识定。

这意味着日常修行中，**身念处、受念处的修法恰好承载在前五识定上**：

- 观呼吸的触感、观身行住坐卧、观受的乐苦——这些所缘本身是前五识的境
- 这些修法本质上是在**训练前五识定的锐利度**，同时由意识定提供跨刹那的连续性
- "活在当下"的现量品质，直接取决于前五识定的强度

### 前五识定与禅定的关系

这里要避免一个误判：禅定主要是**意识层面**的定，不是前五识的定。四禅八定所缘的细微化、心所的精炼化，都发生在意识相续中。

但前五识定对修止也并非不相关：

- **欲界散心**：前五识定弱，锐利度低 → 意识所依的感官输入本身就浮浅 → 修止的起点低
- **修止过程**：随着止力增强，五俱意识对前五识所缘的取舍更精准 → 前五识定也相应提升
- **深定中**：入四禅以上前五识逐渐不起（色界二禅以上无五识现行），所以前五识定此时**不再相关**——深定是纯意识 + 末那的事

### 回到基本立论

这一题的精确回答：

> **前五识有定心所（在 34 心所之内），但其形态是"刹那内的空间专一 + 现量锐利度"，而非跨刹那的持续专注。日常所说的"专注观察"是前五识定（刹那内空间专一 + 锐利度）与意识定（跨刹那持续导向）的合力。前五识定不能独立现行，必与五俱意识俱起；它是身念处、受念处等以根尘触为所缘之修法的直接承载。深定（色界二禅以上）中前五识不起，此时前五识定不再相关，深定是意识 + 末那的事。**

> **学术诚实标注**：
> - 第一层：前五识各相应 34 心所（含别境五）、五识必与五俱意识俱起、色界二禅以上无前五识——均见《成唯识论》、八识心所配属、《瑜伽师地论》。
> - 第二层：把前五识定分解为"空间专一 + 锐利度"两维、与意识定形成"空间/时间"分工——基于前五识刹那性与意识相续性的基本差别所作整理。
> - 第三层：把"身念处 / 受念处承载在前五识定上"作为修行定位、"日常专注 = 两层定合力"作为现象学解释——基于框架一致的推论。

## 🧩 定的通三性与"染分对偶"：染定、散乱的精确归位（2026-06-09）

> 本节是 §核心特征 第 4 条"通三性"的精确展开。**触发**：随烦恼整体认知 §二讨论中，问"为什么大随 8 法中借用别境名（念定慧）的三法（失念 / 散乱 / 不正知）是随烦恼？"的结构性追究。

### 通三性的具体展开

| 三性 | 定的形态 | 例 |
|---|---|---|
| **善定** | 心专注于善法所缘 | 修四禅八定 / 闻思修中的专注 / 正定（八正道之第八）/ 念佛三昧 |
| **染定** | 心被染心所驱动，向染境集中 / 流散 | 专心谋害他人 / 沉迷于贪欲对象的"心一境性" / 邪师外道之邪定 |
| **无记定** | 心专注于无记境 | 工艺操作 / 游戏中的专注 / 一般日常任务中的注意保持 |

→ 关键：**定本身只是"心一境性"的功能，通三性。决定定为善 / 染 / 无记的，是所缘境的性质 + 与之俱起的心所配置。**

### 染定的精确化——两种典型表现

"染定"看似矛盾——既"专注"又"染污"——但精确表述是：

> **染定 = 心被染心所驱动，向染境集中 / 流散的"心一境性"。不是定本身的缺失，而是定向染境的运作。**

它有两种典型表现：

1. **染境集中型**（贪驱动）：心向贪境聚集，专注度可能很高（如沉迷游戏 / 沉迷追求）。表面上"专注"，实质上是定 + 贪 + 痴俱起
2. **染境流散型**（嗔 / 慢 / 痴驱动）：心在多个染境之间流散，难以一境专一（如焦虑下的多线思虑 / 散乱的嗔念）。表面上"散乱"，实质上是定的功能被染心打散

→ 这两种形态正是**散乱**（随烦恼）的体性基础。

### 与散乱（随烦恼）的关系（2026-06-09 经典核对修订）

散乱在《成唯识论》卷六中有**三家立场**：

| 立场 | 安立 | 派系 |
|---|---|---|
| 立场一 | 散乱**痴一分摄** | 瑜伽传（《瑜伽师地论》） |
| 立场二 | 散乱**贪嗔痴一分摄** | 集论传（《大乘阿毗达磨集论》） |
| 立场三 | 散乱**别有自体**——「说三分者是彼等流。如无惭等非即彼摄」 | **《成唯识论》护法最终立场**（本项目沿用） |

护法立场的关键论证：「**若离彼三无别自体，不应别说障三摩地**」——若散乱只是三毒的分位，就不必单立障三摩地的随烦恼。

→ **散乱不是定的染分**——这一立论的经典依据是护法"散乱别有体"立场。散乱与定的关系是**功能性反对**（业用反对，体性不共），非染分对偶：

| 维度 | 定（别境） | 散乱（随烦恼） |
|---|---|---|
| 体性 | 心一境性的功能 | **别有自体**（《成唯识论》护法立场） |
| 通性 | 通三性（善定 / 染定 / 无记定） | 唯染（只在染心位现行） |
| 关系 | "心一境" | "令心流荡"——**业用上正对反**（"能障正定"） |

→ **散乱与定的对偶 = 功能性反对**（体性不共 + 业用反对），不是染分构成。本节初稿（2026-06-09 早间）将散乱归入"染分对偶 = 定的染分 + 痴"是越过经典体性差异，经修行者指出 + 经典核对后修订（详见 §学术诚实标注 自我修正记录）。

### 大随对偶网络的三类结构（2026-06-09 经典核对修订）

大随 8 法的对偶关系不是齐一的"善 ↔ 染"，而是基于体性差异的**三类**：

| 类型 | 安立机制 | 大随例 | 对治路径 |
|---|---|---|---|
| **A. 对称对偶**（善 ↔ 染） | 别立实有染心所，与某善心所体性反对 | 不信 ↔ 信 / 懈怠 ↔ 精进 / 放逸 ↔ 不放逸 / 掉举 ↔ 行舍 / 惛沉 ↔ 轻安 | 建立善心所 = 削弱染（直接对治） |
| **B. 染分对偶**（别境 + 痴 = 染分） | 别境心所（通三性）与痴俱起 = "俱一分摄"形态（《成唯识论》卷六立场三） | 失念 = 念分 + 痴分摄 / 不正知 = 慧分 + 痴分摄 | 对治痴 + 让别境回善分（间接对治） |
| **C. 功能性反对**（别立实有 + 业用反对别境） | 染心所别有自体（与对称对偶同），业用上反对某别境的善功能 | **散乱**（别有体 + "令心流荡"反对定的"心一境"） | 去贪嗔痴根（间接削弱散乱的等流来源）+ 直接修善定（双管对治） |

**B 类的经典明文支持**——《成唯识论》卷六立场三明立"俱一分摄"：
- 失念：「**俱一分摄**——由前二文影略说故」= 念分（"烦恼相应念"）+ 痴分**俱起**
- 不正知：「**俱一分摄**——由前二文影略说故」= 慧分（"烦恼相应慧"）+ 痴分**俱起**

→ "别境 + 痴" 的表述是经典立场三的精确再表述，不是过度具体化。

→ 这与子阶段 1 已闭合的[染慧](../../../resources/cards/染慧.md)概念（假说 16）严格同构：
- **染慧 = 慧 + 痴**（不正知的事件层形态 / 恶见的稳定化形态，子阶段 1 已闭合）
- **染念 = 念 + 痴**（失念的事件层形态，经典立场三平行支持）
- 二者的安立机制都是经典立场三"俱一分摄"的精确再表述——本项目"染慧"概念严格符合经典，"染念"作为平行扩展也有经典支持

**C 类（散乱）的特殊性**——散乱体性别立（不是别境染分），但业用上专门反对定的"心一境"功能，所以仍与定形成对偶关系，但属于"业用反对"而非"染分构成"。这是大随 8 法中独一的特殊归类。

### 修行学含义：对治散乱的精确路径（2026-06-09 经典核对修订）

散乱归入 **C 功能性反对** 后，对治路径**比简单的染分对偶更复杂**——需要双管对治：

| 错误路径 | 问题 |
|---|---|
| "建立定本身就能对治散乱" | 定通三性，建立后仍可能向染境流散——单建立定对染定有效，但对散乱（别有体）需双管 |
| "只对治痴就能消解散乱" | 散乱体性是别有的，不只是痴的分位——去痴削弱散乱的等流来源（间接），散乱"心流荡"自体仍需直接对治 |
| "用意志压住散乱" | 反向熏种（本项目卫生学反复强调）|
| **正确路径（双管）** | **(1) 去贪嗔痴根**（间接削弱散乱的等流来源——散乱"说三分者是彼等流"）**+ (2) 直接修善定**（建立"心一境"功能直接反对"心流荡"）|

→ 这与[无痴](../善心所/无痴.md)双线操作核严格对接（路径 1 = 去痴根），也与子阶段 1 主座 A 三重统一的"扩散无我相到非禅定场域"对接——禅定中"心一境性"在无我相结构中现行 = 善定 + 心一境直接对反散乱（路径 2 = 修善定）。**双管同步**是修行者位置当前的精确对治路径。

### 与"禅定深入主线"的关系

这个结构也对接 §别境"定"与禅定的关系中的"心所精炼是主线"：

- 禅定深入的核心 = 同时现行的染心所越来越少（寻 / 伺 / 喜 / 乐依次脱落 + 痴的现行减损）
- 当染心所减损 → 定回到善分 → 染定 / 散乱无现行基础 → "禅定深"自然出现

→ 所以禅定深入的"心所精炼"主线 = 染分对偶的对治机制在禅定场域的连续展开。"由定发慧"的"定"必须是**善定**——染定再深也只是邪见的加固器（外道四禅八定不解脱的精确机制）。

  - **不正知三家立场**：慧一分摄（"烦恼相应慧"） / 痴一分摄 / **俱一分摄（"由前二文影略说故"）**（卷六）
