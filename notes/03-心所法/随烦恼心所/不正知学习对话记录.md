#### 不正知（asaṃprajanya）· 单法精修 ① 概念讲解（闻）

##### 一、经典定义与四维拆解

《成唯识论》卷六：

> 「云何不正知？**于所观境，谬解为性。能障正知，毁犯所依为业。**谓不正知者，多所毁犯故。」

| 维度 | 内容 |
|---|---|
| **所缘** | **所观境**——用字与前两法都不同：失念「于**诸所缘**」（该持守之境）、散乱「于**诸所缘**」（复数流转），不正知是「**所观**境」——当下应当观察、简择、审视之境。传统注疏的第一现场指向**身语意三业的现行**（见下"正知的经典原型"） |
| **体性** | **谬解**——注意不是"不知"。痴是迷闇（灯暗、无解）；不正知是**有解而解歪**——简择在运作、但简择失真。"谬解是'解'的一种走向"，这正是它必须带慧分的原因：纯痴给不出"谬解"这个行相 |
| **业用** | 双重：① 能障**正知**；② **毁犯所依**——论自注「谓不正知者多所毁犯故」：于自己身语意正在做什么不如实知 → 该止不知止、该行不知行 → **行为层毁犯有隙**。这是大随八唯一直接挂到"戒线"的业用格 |
| **对偶** | **正知**——但正知在百法中**不是独立心所**：唯识判**正知即慧**（观察身语意如法与否的慧用，窥基述记明判）。对偶结构与失念严格平行：失念 ↔ 正念（念之善位）、不正知 ↔ 正知（慧之善位）——散乱精修立的"**正**"前缀标记（别境侧对偶用字）第三次兑现 |

**词源**：asaṃprajanya = a（否定）+ saṃprajanya（正知，sam-pra-jñā"正遍了知"）。与失念 muṣita（被偷）、散乱 vikṣepa（被抛出）两个生动的被动式不同，这个名字是**素面的否定式**——但恰因如此，它比"失念"更直白地把 B 型身份写在名字上："不·正知"，名字借自被染的那个法本身。

**正知的经典原型 = "正知而住"**：《瑜伽师地论》卷二十四立四威仪教授——若往若来、若睹若瞻、若屈若伸、著衣持钵、若食若饮……**正知而住**（大意转述）。正知的原始岗位就是**对自己当下行为的如实了知**；《辨中边论》八断行又给它第二个岗位——③格沉掉的**侦察哨**（失念精修已立：②格配念是培育型、③格配正知是侦察型）。不正知 = 这两个岗位同时失灵：行为层失察 + 座中侦察给假情报。

##### 二、本体归属——B 俱一分摄第二法（三家诤议）

《成唯识论》卷六，结构与失念条完全平行：

> 「有义：不正知，**慧一分摄**，说是烦恼相应慧故。有义：不正知，**痴一分摄**，《瑜伽》说此是痴分故，令知不正，名不正知。有义：不正知，**俱一分摄**，由前二文**影略**说故，论复说此**遍染心**故。」

| 家 | 主张 | 思路 |
|---|---|---|
| 第一家 | 慧一分摄 | 不正知就是**染污慧**——慧与烦恼相应时简择功能失真 |
| 第二家 | 痴一分摄 | 不是慧坏了，是**痴令知不正**——痴覆真相故解得歪 |
| 第三家（护法正义） | **俱一分摄** | 慧一分 + 痴一分俱，影略说 + 遍染心论证 |

护法的遍染心论证与失念同款：**慧是别境、不遍一切心**——昧钝无简择的染心里慧根本不起，若不正知唯是慧分，则彼等染心无不正知，违「遍一切染心」（大随身份）→ 必须痴分补遍（痴遍染心）。反问若唯痴分何以不并入痴？——缘所观境的染心中确有"染慧谬解"的突出行相，**名从行相显处立**。

**判型判准的第二次落地**（失念 §2.3 立、散乱 §2.3 过尺时已预告）：染慧仍是"**简择**"行相——谬解是解的一种走向，功能被劫持而行相保留 → **切片切得出来 → B 型** ✓。至此判准三格全兑现：念（B 切片）/ 慧（B 切片）/ 定（切不出 → C 别体）。

**俱舍对照**：《俱舍论》大烦恼地法六不含不正知；会通《品类足论》"十大烦恼地法"时，世亲明判失念、心乱、不正知即**大地法念、定、慧之染污位**、已摄不重立（大意转述）——有部亲口说"**不正知者即染污慧**"。B 型两法在有部处遭遇**同一判摄**（染位不别立），唯识侧则同样"立名不立体"——B 型同构至此双侧完整。

##### 三、与相邻法辨异

| 对比 | 区别 |
|---|---|
| **不正知 vs 痴** | 痴 = 迷闇（无解、灯暗）；不正知 = 谬解（有解而歪——灯亮着、照出来的像是失真的）。不正知必带痴分（痴覆真相才解得歪），但不即是痴（有慧分行相） |
| **不正知 vs 失念** | 失念 = 锚没持住（念位、所缘脱手——"**没看着**"）；不正知 = 观察在场但失真（慧位、分判歪——"**看错了**"） |
| **不正知 vs 散乱** | 散乱 = 心不住境（流荡）；不正知 = 心可在境上、但解歪。且散乱业用格「恶慧所依，**谓散乱者发恶慧故**」——散乱发的"恶慧"正是不正知的慧分（烦恼相应慧）：**接力棒交接写在文面上** |
| **不正知 vs 恶见** | 两者**都是染慧**——慧的染位有两个被立名的切片：恶见「于诸**谛理**颠倒**推度**」（见解层、推求成执、种子级固化、根本烦恼）；不正知「于**所观境谬解**」（现行层、观察失真、未成执、大随）。骨架 §6.3 修行者自立的三阶段（染慧刹那级 → 不正知多刹那累积 → 恶见种子级）正卡在这两个经典切片之间，本次精修须做经典对接检验 |

**四环链收口位**：放逸「增恶损善所依」→ 失念「散乱所依」→ 散乱「恶慧所依」→ **不正知「毁犯所依」**。不正知是链的**末环与出口**——前三环都在心内（配置、锚、流荡），到不正知这一环，塌陷**穿出心识、落到身语行为层**（毁犯）。两条障道线（失念 §4.5）在此收口：失念 → 散乱 = 障定线 / 不正知 → 毁犯 = 障戒线。

##### 四、见众生普遍现行形态

凡夫不正知同样不是事件、是默认态——**行为层的"自动驾驶"**：

- **于所作不知所作**：吃饭不知在吃、走路不知在走、刷手机不知已刷一小时——四威仪全程无正知而住，行为在跑、观察者缺席（与失念全程版共生：没人持锚、也没人查岗）；
- **自我行为叙事失真**：做的是 A、以为自己在做 B——事后合理化把谬解固化成叙事（"我这是关心你"覆盖着控制、"我在放松"覆盖着放逸），谬解层层熏习即滑向恶见（三阶段的凡夫全程演示）；
- **毁犯不自知**：伤人不觉、越界不觉（"我说话就这样"）——毁犯所依的字面兑现：凡夫的毁犯多数不是明知故犯，是**犯时根本不知在犯**。

### 助手 · 2026-07-15 12:44:50

好问题——"四环链"（全名**所依接力四环**）是散乱精修（2026-07-15，[散乱 §5.1](./散乱.md)）落定的一个读法，收官前值得把它的概念地基说清。

##### 一、文面事实（第一层）

大随八的**后四法**，定义的业用格全部以同一个句式收尾——「**……所依为业**」：

| 法 | 业用格原文（《成唯识论》卷六） | "所依"指向 |
|---|---|---|
| 放逸 | 「障不放逸，**增恶损善所依**为业」 | 一切染品滋长（总闸义，不点名） |
| 失念 | 「能障正念，**散乱所依**为业。谓失念者，心散乱故」 | **点名散乱** |
| 散乱 | 「能障正定，**恶慧所依**为业。谓散乱者，发恶慧故」 | **点名恶慧**——而"恶慧"（烦恼相应慧）正是不正知的慧分之体 |
| 不正知 | 「能障正知，**毁犯所依**为业。谓不正知者，多所毁犯故」 | **毁犯**（身语行为层）——链的出口 |

"所依为业"的意思是：这个法的业用，就是**充当某个下游东西的地基 / 温床**。四个"所依"读下来恰好首尾相衔：中间两环（失念→散乱、散乱→恶慧）是经典**指名道姓**写的；首环放逸是泛指（总闸义）；末环毁犯不再指向某个心所、而是穿出心识落到行为。

##### 二、"链"的读法（第二层整理，须两条界定）

**界定一：经典没有说"链"**。四个定义各自独立成条，"这是一条接力级联"是我们对**文句排布**的整理——但排布本身是原文自带的（四条业用格同款语法 + 两处点名交接），所以它比纯自主推论硬、比经典明立软，散乱精修记为"有直接文句排布支撑的整理"。

**界定二：它是机制依存链，不是时序链**（失念 §4.2 先立、散乱精修沿用）。四法全部遍染心——**每一个染心刹那，四者同时在场**，不存在"先放逸、过一会儿失念、再过一会儿散乱"的时间顺序。链描述的是同一刹那染心的**四个深度切面**、层层为下一层供地基：

```
放逸（配置层：守护总闸撤）
  → 失念（所缘层：锚点无人守、脱手）
    → 散乱（现行层：脱手后流荡无阻——链上第一个"看得见"的环节）
      → 不正知（分判层：流荡中简择必失真）
        → 毁犯（行为层出口：谬解落成身语犯）
```

"依存"的确切含义：守护不撤，锚不会无人守；锚不脱手，流荡无隙可入；心不流荡，分判不至于潦草失真；分判不失真，毁犯无从发生。**上游是下游的可能性条件**，不是下游的时间前件。

##### 三、两个配套件

- **窗口公式**（散乱精修产出）：链的"失念→散乱"一环有现量差分支撑——**散乱窗口宽度 = 失念持续时长**（凡夫失念是默认态→窗口无限宽；修行者座中失念是点状空档 + 干净切回→散乱无窗口可用；懈怠日念力欠供→窗口变宽）。这把链从结构描述升级为有现量证据的机制。
- **与"五随网络"的关系**：回填清单那条"五随烦恼网络"是**五**法（懈怠、放逸、失念、散乱、不正知），四环链是其中**带"所依为业"句式的四法**构成的骨干；懈怠的业用格不是"所依"句式（「能障精进，**增染**为业」），它从更上游进链——放逸定义「由**懈怠**及贪嗔痴，不能防修」亲自把懈怠写成放逸的成分。所以全网络 = **懈怠（动力层断供）→ 四环链（配置→锚→流荡→谬解→毁犯）**。收官联动㈠"五随网络全分判"要做的正是把这两截焊成一张完整网络图、回填不放逸 §五。

一句话收束：**四环链 = 经典用四个连续的"所依为业"业用格，在定义内部写好的一条染心塌陷级联（同刹那四切面、机制依存非时序）；不正知是它的末环——塌陷从心内穿出、落到行为层毁犯的那个出口。**

这个概念澄清后，主线四（毁犯所依与四环收口）就是把这条链的末环补完 + 焊上懈怠做全网络分判。主线设计可以继续确认或调整。

#### 主线一 · 行相精析与正知原型

##### 1.1 "所观境"——三法所缘用字对比与第一现场

大随后三法（别境侧三法）的所缘用字，经典各有讲究：

| 法 | 所缘用字 | 用字的重心 |
|---|---|---|
| 失念 | 「于**诸所缘**」 | 该持守之境（《大乘五蕴论》补"于诸善法"——持守侧） |
| 散乱 | 「于**诸所缘**」 | **复数本身**是体性一部分（流转侧） |
| 不正知 | 「于**所观境**」 | "所观" = 应当被观察、审视、简择之境 |

"所观境"具体指什么，《杂集论》给了直接答案：

> 「不正知者，烦恼相应慧为体，由此慧故，**起不正知身语心行**，毁所依为业。」（大意转述）

——**身、语、心（意）三业的现行**。不正知的第一现场不是抽象的认知错误，是**对自己当下正在做什么、说什么、想什么的观察失真**。这与失念（锚）、散乱（流荡）都不同：那两法的战场在所缘侧，不正知的战场在**对自身现行的监察侧**。

##### 1.2 谬解三态——"看错了"与"没看着"的精确切分

"谬解为性"这两个字里藏着不正知的全部行相特征。把观察状态切成三态：

| 态 | 结构 | 归属 |
|---|---|---|
| **正知** | 观察者在岗 + 报告如实 | 慧之善位 |
| **不知** | **观察者缺席**（无解） | 痴覆 / 失念空档侧（"没看着"） |
| **谬解** | **观察者在岗 + 报告失真**（有解而歪） | **不正知**（"看错了"） |

两个要点：

**㈠ 谬解必须"有解"**。纯痴是迷闇——灯暗、无解，给不出"谬解"这个行相；谬解是"解"的一种走向——灯亮着、照出来的像是失真的。这在行相层就预告了本体归属：不正知不能唯痴分摄（主线二展开）。

**㈡ 谬解自带"自信为知"的元层特征**〔第二层整理〕。恰因为有一个"解"在场，心识以为自己已经知道，**不会再去查**——假情报比无情报更险：无情报者知道自己盲，假情报者以为自己明。「多所毁犯」的机制正在此：行动总是基于"解"发动，解歪则行歪，而歪的当下无自觉。这与失念处痴的"覆失"（把失藏起来）同构——不正知处痴藏起来的是"解歪了"这件事本身。

##### 1.3 正知即慧——对偶方不是独立心所 + "正"前缀第三次兑现

百法中**没有"正知"这个心所**。窥基述记判：正知以**慧**为体——是慧用于"观察身语意现行如法与否"的那一用。对偶结构与失念严格平行：

```
正念（念之善位）↔ 失念（念之染位切片 + 痴分）
正知（慧之善位）↔ 不正知（慧之染位切片 + 痴分）
```

散乱精修立的"**正**"前缀标记（别境侧对偶用字：论文给别境侧三法的业用格全带"正"字、善侧对偶无前缀）至此**三格全部兑现**——失念「能障**正念**」、散乱「能障**正定**」、不正知「能障**正知**」。前缀的功能一以贯之：念定慧通三性，染方障的只是其**善位**，论文用一个字把这层切分写进了字面。

##### 1.4 正知的经典原型——"正知而住"与双岗位

正知的原始岗位在《瑜伽师地论》卷二十四"**正知而住**"教授（大意转述）：若往若来、若睹若瞻、若屈若伸、著衣持钵、若食若饮、若行住坐卧、若语若默、乃至解劳睡眠——**一切威仪现行中如实了知自己正在做什么**。声闻地资粮组里它与"密护根门"相邻并立——正知是律仪的贴身守护者。

合上《辨中边论》八断行，正知在经典中有**两个岗位**：

| 岗位 | 教证 | 监察对象 | 失守后果 |
|---|---|---|---|
| **戒门岗位** | 正知而住（《瑜伽》卷二十四） | **外**——身语意行为现行 | 于所作不如实知 → **毁犯有隙**（不正知业用格的直接兑现） |
| **定门岗位** | 八断行③格沉掉配正知（《辨中边论》） | **内**——定境中沉掉起没 | 侦察哨给假情报 → 沉掉起而不觉 → ④格"不作行"连锁失守（侦察不报、对治不发） |

两个岗位是**同一个慧用**：于当下现行如实监察——对象一外一内而已。不正知 = 监察官在岗但报告失真，两个岗位同时失灵。

**两线收口**：失念精修立的"②格配念 = 培育型 / ③格配正知 = 侦察型"分判，至此双法双线闭合——**培育线**（念，失念障之）+ **侦察线**（正知，不正知障之），恰是 B 型两法各障一线。经典把"持住"与"查岗"分成两个法、配两个断行，大随八用两个 B 型法各废其一。

> 不正知：「于**所观境**，**谬解**为性。能障正知，**毁犯所依**为业。」（体 = 烦恼相应**慧** + 痴分）

**两者都是染慧**——经典自己把慧的染位切成两片、分驻两处：

| | 恶见 | 不正知 |
|---|---|---|
| 所缘 | 诸**谛理**（真理层命题——世界是常是断、有我无我、何为因果） | **所观境**（现行层——当下身语心行） |
| 行相 | **颠倒推度**（审虑推求、构造见解、印持成执） | **谬解**（监察失真 / 失检放行） |
| 业用 | 障善见、招苦 | 障正知、毁犯所依 |
| 谱系位置 | **根本烦恼**（五见开列） | **大随**（俱一分摄） |

同为染慧，为何一个升根本、一个居随？分判的尺不在体、在**能生力**：根本烦恼的"本"义 = 能生其他烦恼。恶见成执之后是**烦恼的发生器**——见取生斗诤、萨迦耶见生贪嗔慢、戒禁取生无义苦行，《成唯识论》判见为多惑所依；不正知只是监察失真，**不自生诸惑、只开毁犯之门**（所依义——供地基、不供动力）。一句话：**推度成执者为本，失察放行者为随。**

##### 3.2 三阶段的经典对接〔骨架 §6.3 你自立的分诊、本节检验其经典地基〕

你在骨架预演立的三阶段——染慧（刹那级一次染分判）→ 不正知（多刹那级带染认知）→ 恶见（种子级已成内容）——经典侧的对接结果：

**㈠ 骨架材料齐备**：对象层级递升（所观境 → 谛理）、行相强度递升（谬解 → 推度执）、谱系位置递升（随 → 根本）——三条文面梯度都指向同一个方向，三阶段不是外加的，是把经典自带的梯度读成了发生学。

**㈡ "累积"与"遍染心"的张力，用散乱精修的**体 / 用两层**化解：不正知之**体**（监察失真一分）遍每一染心刹那——这是"遍染心"的成立层；其**用**（成形的谬解叙事——"我在做的是 B"这类持续性错误自我认知）**显于相续**——这是你说"多刹那级累积"的层。与掉散"体遍刹那、用显相续"完全同构：单刹那谁也累积不出叙事，但每刹那都有失真一分在供材料。

**㈢ 两个边界标记**（三阶段"非连续谱、有明确边界"的边界正身）：

- **阶段 1 → 2**：**相续化**——从一次染分判到一条被维持的叙事（解疑不共刹那在此起作用：每个刹那的解都排掉怀疑，叙事就无阻力地续下去）；
- **阶段 2 → 3**：**成执化**——推度 + 印持进场（"可辩护、逢缘必起、被质疑时护"——从"一直这么以为"变成"就是这样"）。

**㈣ 俱生分边界**〔诚实标注〕：这套发生学严格说是**分别起恶见**的发生学（今生邪教邪思惟熏成——三阶段可观察地走完）。俱生恶见（俱生萨迦耶见、边见）无始已成，今生看不到它的三阶段——只能说"结构相同、时间轴在无始"，而"无始"处发生学本身悬置。三阶段的适用域需加此限定。

##### 3.3 双轨完成图——恶见间接对应的最终精确化

骨架 §3.4 立"恶见 ↔ 不正知 + 失念（完全成立 + 重要精化）"，§6.4 你自立"**路径全程失念，最终才滑入恶见**"（失念 = 全程基底缺位、不在三阶段内）。本次精修补上另一条轨：**无检型不正知**（该分辨未分辨、直接放过）与失念是**同款的缺位型使能条件**——

```
内容线（演化什么）：染慧 → 谬解叙事（不正知之用） → 恶见（成执）
双轨线（凭什么能一路滑过去）：
  轨一 · 失念——不持（正念缺位：没人把心锚在如实境上）
  轨二 · 无检型不正知——不查（正知缺位：没人抽查这条叙事）
```

**两个 B 型法恰好供出两条轨**：念的染位断"持"、慧的染位断"查"——持查双缺，三阶段就在无摩擦的轨道上滑到底。恶见的间接对应至此完整：**不正知供内容（谬解叙事是恶见的前身）+ 失念与无检型供轨道（缺位使演化无阻）**。这也回答了为什么经典把这两法安排成大随里仅有的 B 型对子——它们是染心认知演化的两条基础设施。
