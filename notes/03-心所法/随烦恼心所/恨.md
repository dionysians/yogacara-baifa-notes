## 一、经典概念（闻）

### 定义原文

[《成唯识论》](../../../resources/cards/《成唯识论》.md)卷六：

> 云何为恨？**由忿为先**，**怀恶不舍**，**结怨**为性。能障**不恨**，**热恼**为业。谓结恨者不能含忍，**恒**热恼故。此亦**瞋恚一分**为体，离瞋无别恨相用故。

（梵语 upanāha。）

### 体性拆解

| 项 | 内容 | 与忿的关键差别 |
|---|---|---|
| **所缘** | 过去违境**内化储存**的怨——境不需现前 | 忿缘**现前**违境；恨缘内存表象 |
| **体性** | 怀恶不舍、**结怨**——把怨收结储存 | 忿是**发出**（动态外向）；恨是**收结储存**（静态内向）|
| **业用** | 能障不恨；**热恼**——"不能含忍，**恒**热恼" | 忿业用是执杖暴恶身表业（对外）；恨业用是**持续自我煎熬**（对内、恒续）|
| **所障** | 不恨（无瞋在"含忍"上的分位）| — |
| **本体** | 瞋一分，离瞋无别相用 → **E 分位假立** | 与忿同类——皆瞋的分位别名 |

### 三个"恨独有"的锚点

1. **"由忿为先"——生起次第经典明文**：恨不独立起境，**以忿为前提**。这是骨架 §七 生起次第链"忿→恨"的经典锚（恼"忿恨为先"同理）。恨是嗔系链上**第一个有"前法依赖"明文**的法。

2. **"怀恶不舍"的静态储存相**：忿恨恼 = **一股瞋换相位**（发出 / **收结不舍** / 追触暴热狠戾）。恨独占**"不舍"**槽位 = 把忿的势力从"发出态"转为"储存态"。储存可长期不外显但势力未消，是**等流熏厚瞋种**的关键环节（[五果](../../../resources/cards/五果.md)·等流果）。

3. **"恒热恼"的自苦性**：恨的业用方向**对内**——"不能含忍，恒热恼"，区别于忿/恼的对外暴发。修行学上最值得标注的一点：**恨的主要受害者是自己**（持续内在煎熬），而非所恨的对象。

## 二、与相邻法的辨异（嗔系五小随同属瞋一分）

分界**都不靠外显**，在所缘相位 + 行相 + 质地（详表见 [忿.md §二](./忿.md)）：

- **恨 / 忿**：动态发出（忿）/ 静态储存（恨）；现前境（忿）/ 内化怨（恨）；时序忿先恨后（"由忿为先"）。
- **恨 / [恼](./恼.md)**：恨独有**"不舍"**（储存态）；恼独有**"狠戾"**（恨后再遇追触而暴发的狠戾，"忿恨为先，追触暴热"）。恨是静态库存，恼是库存被再次激活的暴发。
- **恨 / [嫉](./嫉.md)**：所缘不同——嫉缘**他荣境**（不耐他人荣盛），恨缘**违境内化的怨**。嫉"另起"，不在忿恨恼现前违境链上。

## 三、主线 1：分位机制 + 嗔系链位置

### 3.1 恨 = 嗔的"怀怨储存分位"，在链中是"忿后沉淀点"

恨无别体（E 类分位假立），在忿恨恼链中把忿的势力做了一次**相变**：

```
忿（现前境 · 脉冲式发出）
   │  忿后不放、反复缘那个"违境内化表象"
   ↓
怀恶不舍 → 结怨 = 恨（储存式怀持）
```

**两种相态的修行学差别**（恨单列的真正理由）：

| | 忿（发出态） | 恨（储存态） |
|---|---|---|
| 时间结构 | 脉冲式——发完即过 | 持续式——结着不散 |
| 自然衰减 | 有（境过、势力自衰）| 无（不主动舍就一直在）|
| 对瞋种熏习 | 单次现行熏一次 | **反复"怀"= 反复缘内化怨境 = 反复现行**，等流熏厚更深 |

→ 恨虽"离瞋无别恨相用"（无别体），但业用结构与忿不同——忿靠境过自衰，**恨无自然衰减机制，必须主动"舍"才能解**。对治入口因此与忿不同（忿是"不发"，恨是"舍已结之怨"）。

### 3.2 现量精化：静态储存相 = 微观脉冲串（修行者自主立）

修行者现量戳穿"静态/持续"的宏观表象——**所谓"持续在场"，微观上是反复触发的"主动重新结怨"脉冲串**：

```
境违 → 联想曾经的忿境 → 主动重新结怨 → （境再触）→ 再联想 → 再结怨 …
        ↑__________________________________________↓
                     反复续命的触发循环
```

→ 恨"无自然衰减"的真相**不是有个静物挂着不衰减，而是反复重新结怨在续命**。对治随之精确：**截断"境违→联想忿境→主动不放"触发循环 → 储存态断续命 → 基态自然衰减**。这与忿"不发"、与修行者"忿后即止不入恨"是同一条机制线。

### 3.3 "不舍"的双层结构——现行↔基态种子线（修行者自主立 · 拒立膨胀）

"怀恶不舍"是主动不放还是无法放下？修行者现量把这组**并列二分收敛为一条种子-现行线的两端**：

| 旧框（并列二分，被修正） | 现量分诊 | 对应模型 |
|---|---|---|
| 主动不放 | **现行层**：每次"境违→联想忿境→主动重新结怨"= 触发式脉冲 | 现行 |
| 无法放下 | **基态层**：长期主动触发**熏出来**的随烦恼基态状态 | 熏习 / 种子 |

→ "独立无先后"（当下种子起现行、现行熏种子同时，各自独立令恨滞留）+"无法放下是主动不放熏出来的"（历时基态由现行养成）——二者**不矛盾，恰是种子↔现行的标准结构**（当下双向 + 历时熏成）。

### 3.4 两种恨的所缘二分（触发源贪侧 / 我执侧，恨体仍瞋一分）

| | 触发源 | 损坏对象 |
|---|---|---|
| 恨1 | **贪**粘着的对象被损 → 转移到损坏者 | 所爱境（外物）|
| 恨2 | **我执 / 我的认定**被破 → 联想到伤害者 | "我"本身 |

→ 触发源不同（贪侧 / 我执侧），但**恨体仍是瞋一分**，两条都收敛到同一触发式循环。接驳法染色层：贪粘着或末那"我所"被损，都能点燃嗔系储存。

## 四、见自维度（修行者位置现量分诊）

### 4.1 不是"截断点位"，是归因方向从源头改道

问"对治截在触发循环哪个点"，修行者现量否掉了这个预设——**那条链从源头就不指向恨**：

> 发生以后内心的直接归因是"哪里不对（我哪里做错）"，而不是"别人有问题"。

→ 恨的体性是"怀怨"，需一个**可怨对象（有恶意的他人）**作所缘；童年双锚"**所有错都是无知造成的**"（去行为者，[无痴双线操作核](../../教学操作核/教学操作核-03-无痴双线.md)）把归因从"他有恶意"转成"无知"——**无知不是可怨对象**（是 cause 不是 agent）→ **直接抽掉恨的所缘基础**，势力流向自省找错而非结怨他人。链根本没通向恨，谈不上在哪截断。

→ 与忿精修接续：忿是"愧在我所强加上游截"，恨是"双锚把归因从他人改道到自省"——**同一去行为者机制的两个出口**。

### 4.2 递归惭愧 = 纵向下沉，终点无常无我（[假说 13](../../假说/假说-13-递归惭愧.md) 现量再确认）

自省过程 = 惭愧过程，**可层层往究竟层走**：

> 浅层能解决就在浅层解决；解决不了往深层延展，最终回归诸行无常、诸法无我，直接放下。

修行者澄清一处关键归位：**递归就是纵向下沉本身，不存在"横向递归"**。"发现识别里还掺杂我执 → 对这个更深的点再惭愧"——每递归一层即下沉一层，假说 13"**越递归越无相**"本就刻画此纵向性。故：

- **不立新结构**——这是假说 13 的本来含义，只把**终点（无常无我）明确出来**；
- **够用就停**——不是每次一沉到底，浅层能解决就停，解不掉才往无常无我下沉（与"看破从更细微处开始"同一下沉机制）。

### 4.3 没恨恼 → 不觉得人坏

> "觉得人坏"这件事，很多时候本身就是一种"恨"和"恼"的表现。

→ "他坏"不是中性认知，是**恨/恼染出来的判断**（恨需"认定一个可怨的恶意行为者"，"坏"就是那个认定的标签）。修行者双锚改道、忿后即止不入恨 → 此认定不形成 → "很少觉得谁坏"。

### 4.4 见自侧闭合

恨在修行者位置**结构性不现行**（不记得恨的体验，唯见众生）。机制完整：归因改道（双锚抽掉所缘）+ 自省惭愧递归下沉（解不掉则沉到无常无我直接放下）。学习日志预判"见自快收"成立，产出却厚——给出"归因改道"+"递归下沉终点"两个机制。

## 五、见众生维度

### 5.1 恨的底层是"爱"——看见苦因（修行者现量）

> 凡夫对侵犯/破坏的**我执的爱和不舍**……意识中反复升起对喜爱/不舍内容的**内境** → 联想到导致失去的**外境** → 不受控进入循环。

这把"明知苦还抱着怨"解开了——**抱着的根本不是怨，是怨底下的爱/不舍**：

| 层 | 内容 |
|---|---|
| **表层** | 可怨对象（损坏者 / 违境）= 恨的显相所缘 |
| **底层** | 被损的**所爱**（我执粘着物）= 恨的真正根 |

放下怨 = 等于承认所爱真的失去了，故**不肯放**——恨成了对所爱的最后挂靠。这是**爱憎一体 / 由爱生嗔**的结构（第二层框架映射：爱所缘被夺则嗔起，嗔是爱的背面）。§3.4 的"恨1=贪粘着对象被损"在此收到根上：恨1 的底层就是贪。

### 5.2 见自见众在"无常无我"合流

```
        无常无我
       ╱         ╲
  见自：出口        见众生：缺口
  惭愧下沉到        凡夫不知无我、
  无常无我 → 放下   抱所爱不舍 → 困在恨里
```

**同一个无常无我，修行者是出口、凡夫是缺口**。这给出利他善巧轴方向：帮困在恨里的人，**不是劝他"别恨那个人"**（表层无用——他抱的是底层的爱），而是松动底层"对所爱的不舍"、指向无常无我。能看到凡夫"被爱/不舍困住"而非"他坏"——这就是悲悯（看到苦因），不是评判。

### 5.3 利他善巧轴缺口精确归位（本法关键产出）

修行者把利他善巧轴缺口切成三层，前两层**有**、第三层**缺**：

| 层 | 内容 | 修行者位置 |
|---|---|---|
| 诊断动机 | 从特质/能力/执着推断他的动机行为 | ✓ 强 |
| **理解外缘处境** | 站他视角，理解他这么做的原因、环境、**外缘的无奈** | ✓ **能**（因无嗔恨，能入他视角）|
| **理解烦恼内在机制** | 他为什么"**放不下**"本身、为什么"**一定要做很蠢的行为**" | ✗ **缺** |

→ 缺口精确在**心侧**（不理解他人被烦恼驱动的内在机制），不在**境侧**（外缘处境他能理解）。这比笼统"缺悲悯"精确，也更可操作。

**"烦恼少者"的反向利他缺口**（结构性洞察）：修行者自身烦恼现行少（尤其嗔系）→ 对"被烦恼绑架"的现量经验少 → 反而难共情被烦恼深缚的众生。**修行越好，越缺被烦恼驱动的切身经验**。故其补法不走"培养情感共情/悲悯热质地"路径，而走本来的认知路径：**理解烦恼机制 → 知道众生卡在哪 → 知道怎么帮**（与理性派 / 慧解脱 / 信德冷质地的修行学逻辑一致）。

**见众生线重新定位**：修行者明确——"百法学习中利他善巧轴的部分，更多是去学习产生烦恼的底层机制"。这把见众生线从"奠定认知基础"**升级**为**利他善巧轴在百法范畴内的直接修学路径**。缺口因此二分：

| 部分 | 内容 | 修学路径 |
|---|---|---|
| **百法内（现在就修）** | 理解烦恼底层机制 | **随烦恼 20 法见众生线**直接填 |
| **百法外（待菩萨道）** | 完整善巧行法（四摄/方便波罗蜜）| 已登记回填清单 |

恨即第一个现量样本：已看到凡夫"放不下"的机制 = 底层对所爱的不舍。

## 六、结构关联

- **E 分位假立**：恨 = 瞋在"怀怨储存"分位的假立名，无独立体性。
- **嗔系**：忿恨恼现前违境链的"忿后沉淀点"（"由忿为先"）；嫉 / 害另起。
- **现行↔基态种子线**：恨的"不舍"= 主动不放（现行）+ 无法放下（熏成基态），种子↔现行标准结构；静态储存 = 微观反复结怨脉冲串。
- **子阶段 1 嗔操作核接续**：恨在修行者位置不现行 = 双锚归因改道（去行为者）+ 自省递归惭愧下沉；与忿"愧上游截"是同一去行为者机制两出口。
- **假说网络**：现量再确认假说 13（递归=纵向下沉、终点无常无我）；接驳无痴双线双锚（"所有错=无知"作恨侧出口）。

## 七、学术诚实三层标注

**第一层（经典）**：恨定义原文（由忿为先 / 怀恶不舍 / 结怨 / 不恨 / 恒热恼 / 瞋一分）；"由忿为先"生起次第明文；恨"离瞋无别恨相用"；等流果（五果）。

**第二层（框架应用映射）**：忿恨发出/储存两相态对比；"静态储存=微观脉冲串"的现量整理；"不舍"双层=现行↔基态种子线的模型对应；两种恨所缘二分（贪侧/我执侧）；恨底层是爱=由爱生嗔结构读；见自见众无常无我合流图；利他善巧轴缺口三层切分。

**第三层（自主推论）**：归因方向"从源头改道"（非链上截断）作恨不现行的机制判定；递归=纵向下沉、终点无常无我（修正"横向递归"误读，归为假说 13 本义）；"觉得人坏=恨恼产物"论断；"烦恼少者反向利他缺口"结构性洞察；见众生线=利他善巧轴百法内修学路径的重新定位——均属修行者位置现量分诊产出，状态为"与唯识框架内在一致的现量报告"。
