# 悭

> **类别**：心所法 > 随烦恼心所 > 小随烦恼（经典顺序第六法）
> **五象限归属**：E 分位假立（贪一分）
> **对治通道**：小随通道 → 无贪 → 布施（不悭）；究竟收于「我的」无自性（与嫉"排名无自性"同钥——破我所边界实有）
> **学习日期**：2026-06-13（子阶段 2 · 随烦恼单法精修第六法 · 小随中首入贪系、缘自所有）
> **骨架**：[随烦恼整体认知](./随烦恼整体认知.md)

## 一、经典概念（闻）

### 定义原文

[《成唯识论》](../../../resources/cards/《成唯识论》.md)卷六：

> 云何为悭？**耽著法财**，不能惠施，**秘吝为性**。能障**不悭**，**鄙畜为业**。谓悭吝者，心多鄙涩，畜积财法，不能舍故。此即贪爱一分为体，离贪无别悭相用故。

[窥基](../../../resources/cards/窥基.md)《百法明门论解》：悭者，贪之一分，耽著财法，不能惠施，秘吝为性。（梵语 mātsarya。）

### 体性拆解

| 项 | 内容 | 悭的独有处 |
|---|---|---|
| **所缘** | **自所有的法财**——财悭（钱财、物、身命）+ 法悭（知识、技艺、教法） | 嗔系五法缘他（违我者 / 胜我者），悭**缘自己已得之物**——小随中首个所缘转向"自所有"的法 |
| **体性** | **秘吝**——耽著（贪根）+ 不能惠施（不舍动作）。关键动作 = **在施的界面上不舍** | 根在贪、**相也在贪**——全链同向，不需任何反转（§3.1）|
| **业用** | **鄙畜**——心多鄙涩（心地紧缩、变小）+ 畜积不舍（越攒越不肯散） | 苦的质地不是热恼（无瞋分参与），是**收紧**——与布施时"心开"正相反 |
| **所障** | 障**不悭**（能施 = 无贪在"舍"上的行相） | 与[布施波罗蜜](../../../resources/cards/布施波罗蜜.md)正相违 |
| **本体** | 贪一分（离贪无别相用）→ **E 分位假立** | 贪一分是定说，**无内部体性诤议** |

### 五悭（所缘细目）

[《大毗婆沙论》](../../../resources/cards/《大毗婆沙论》.md)立**五悭**，比《成唯识论》"法财"二摄更细：

| 五悭 | 所守内容 |
|---|---|
| 住处悭 | 居处、地盘不容他共 |
| 家悭 | 独占施主 / 人脉关系，不容他亲近 |
| 施悭 | 利养独得，不容他分 |
| 称誉悭 | 名誉称赞独享，不愿他被赞 / 沾光 |
| 法悭 | 吝惜教法 / 知识技艺，不肯施人 |

### 三个"悭独有"的锚点

1. **三段链无反转——贪系里最"诚实"的随烦恼**：嫉要把顺境（他荣）经我执二次加工成逆境才起瞋相；悭的链条全程同向——贪什么就守什么，耽著直接顺向延伸为秘吝，不需要任何境的翻转（§3.1）。

2. **悭嫉镜像**：嫉憎外（他有 = 我损），悭守内（给出 = 我损）——同一「我所」边界的守卫反应的两面，故经典常并称"悭嫉"（§3.2）。

3. **究竟根是「我的」无自性看不破**：物上不带"我的"标签——所有权是共业约定（法律、习俗、默契）的产物，离开约定网络，"这是我的"无处安放。与嫉的"排名无自性"平行：排名是比较心产物，"我的"是所有权概念产物，皆世俗概念假立；脚手架之下接的才是末那俱生我所执（§6 / §7）。

## 二、与相邻法的辨异

**与[嫉](./嫉.md)（"悭嫉"并称 · 镜像对）**

| | 嫉 | 悭 |
|---|---|---|
| 体 | 瞋一分 | 贪一分 |
| 朝向 | **憎外**——缘他荣，不耐他好 | **守内**——缘自有，不肯施他 |
| 触发判断 | 「他有 = 我损」 | 「给出 = 我损」 |
| 制造判断的脚手架 | **排名**（比较心产物） | **所有权**（"我的"边界） |
| 业用质地 | 忧戚（瞋分刺痛、热恼） | 鄙涩（贪分收紧、变小） |

→ 一守边界的**相对高度**（不许他比我高）、一守边界的**绝对存量**（不许我的减少）；底层同跑一个默认：实有一个"我的"域，域之盈亏即我之盈亏。

**与[贪](../烦恼心所/贪.md)（悭是贪一分，须分清哪一分）**
- 贪 = 于有、有具染著——**求未得**（通缘自他，追求获得）。
- 悭 = 已有不舍——**守已得**（专缘自所有）。
- 一句话：**贪求未得 ／ 悭守已得**——求与守是贪的两个相位，悭只占"守"这一相。

**与[无贪](../善心所/无贪.md)（对治面）**
- 不悭 = 能施 = 无贪在"舍"上的行相，悭的对治直接走无贪 → 布施。

## 三、主线 1：体性机制（三段链无反转 + 镜像 + 财法不对称）

### 3.1 三段链——悭不需要反转

```
耽著法财 ──→ 秘吝 ──→ 鄙畜
(根·贪·已得相位)  (不舍动作)  (心紧缩业用)
```

与嫉对照的干净差异：**嫉有反转点，悭没有**。嫉的"逆"是顺境被我执翻转；悭根在贪、相也在贪——耽著直接顺向延伸为守持。所以悭是贪系里**最"诚实"的随烦恼**：链条全程同向，苦的质地因此不是热恼而是收紧。〔"诚实 / 同向"为第三层结构归纳，经典只立"贪一分"〕

### 3.2 悭嫉镜像——同一「我所」执的两面

嫉把他人之有拉进"与我对比"（守相对高度），悭把已得之物钉进"我的"域（守绝对存量）——都是**「我所」边界的守卫反应**。〔镜像归纳为第三层；与[假说 12 惭愧末那二维辐射](../../假说/假说-12-惭愧末那二维辐射.md)"外向扩张我所"结构一致〕

### 3.3 财悭／法悭——一个结构性不对称

- **财是零和的**：给了就少。财悭的"施则损"判断在物理层为真——它错在把物理损读成"我"损，但存量减少不虚。
- **法是非零和的**：教了不减、灯灯相传。法悭的"施则损"判断**在所缘层就已是假的**——法本身给出去一分不少。

那法悭守的是什么？守的不是法，是**法带来的位置**——师傅地位、竞争优势、"只有我会"的稀缺性。**法悭剥到底守的是排名价值**——它在所缘层借用了嫉的排名脚手架。财悭守存量、法悭守位差；法悭是悭与嫉的**交界处**，其检验口正落在嫉已拆掉的"排名无自性"上。〔此剥解为第三层推论；经典立"法财"二所缘但未做此结构分析〕

## 四、施的边界（本法精修主产出——施的简择框架）

精修中提出的真问题：**施本身需要缘法**——不可能大街撒钱、不可能有求必应倾尽家当、不可能在别人不需要时强行分享知识。"什么时候该施"如何分判？经典对此有完整明文。

### 4.1 施的时机是响应式的，不是搜索式的

[《瑜伽师地论》](../../../resources/cards/《瑜伽师地论》.md)菩萨地施品通篇施行文皆以"**菩萨见来求者**……"开头——施的缘是**境自己来**：来求者现前 ／ 现见之苦现前 ／ 法器之问现前。**不需要一个"何时该施"的判定器走在前面**：缘不现前时不施不是悭，是无境（大街撒钱 = 无缘强造境，且属无慧之施——"五度如盲，般若如导"，[《大智度论》](../../../resources/cards/《大智度论》.md)）；主动遍寻施处是菩萨施度圆满层的事，不是凡夫位 / 在家位的义务。正向地图则有[三福田](../../../resources/cards/三福田.md)（报恩田·父母师长 ／ 功德田·三宝 ／ 贫穷田·贫苦），但那是"施往哪落"的地理，不是时机判定器。

### 4.2 遮缘三条（经典明文的无损压缩）

缘现前后，简择不是开放式权衡，而是**查有没有不施的正当遮缘**。《瑜伽师地论》施品的不应施明文，可无损压缩为三条：

| 遮缘 | 经典明文（归入此条者） |
|---|---|
| **① 真实伤害被施者** | 毒火刀酒猎具不施 ／ 求刀自害者不施 ／ 魔众恼乱而求不施 ／ **非器不说深法**（说之令生谤造罪）／ 为窃法、求过端而来求法者不施 |
| **② 施对象不由自己支配** | 父母不施于人 ／ 妻子奴婢不自愿不施（眷属不强施） |
| **③ 真实伤害自己（称力线）** | 初心菩萨未得堪忍位不强舍身命 ／ 强舍生悔退心反损大行 ／ [《优婆塞戒经》](../../../resources/cards/《优婆塞戒经》.md)**随力随分**——在家位施到力所能及即如法 |

**一条遮缘不中 → 默认就是施（随力）。**

### 4.3 第三条的精度——"触发烦恼"不算伤害自己

遮缘 ③ 是整个判法里最易被悭钻空子的一条缝，精修中立了关键精度：

> **「触发烦恼」不算伤害自己——那正是要磨的悭本身；「真实伤害」才是遮缘。**

两者现场体感都是"我不想给"，区分线是经典的**称力**：超出力分、施后生悔退心、损及生计与修行 = 真实自伤，遮缘成立；力分之内只是心在抽紧不肯 = 悭披着 ③ 的外衣。事后辅助检验〔第三层推论〕：真遮缘的不施过后心安；悭借壳的不施，过后那个理由会被反复自我重申（心在替自己辩护，说明当时就知道不干净）。

### 4.4 完整判法——判心相不判施否（与持戒究竟层同构）

```
境来 → 遮缘三条（伤他 ／ 不由己 ／ 真实自伤·称力线）
     → 无遮缘则随力施
     → 施境下心紧 = 悭（先认紧、后简择——防悭收编简择作借口）
     →（隐蔽形态：回避施境，让缘根本现不了前——紧检验抓不到，需反观"我是否在回避施界面"）
```

悭的体是"秘吝"、业是"心多鄙涩"——**全部判在心相，不判在行相**：慧简择"此缘不合、不施"，心开且缘到位随时能舍 → 不是悭，是施度的简择支（"对双方是否都好"的简择本身属施度，不属悭）；"缘还不到位"出口那一刻心是紧的、且"缘到位"的标准不知不觉越抬越高 → 悭披着慧简择外衣。与持戒判心所配置不判形式、忿恼判行相不判强度严格同构：**悭判心相不判施否**。〔"回避形态"与"标准越抬越高"为第三层推论〕

## 五、见自维度（修行者位置现量分诊）

### 5.1 悭 ≠ 我所执——先归位再分诊

精修中先做了一次边界归位：「我的」边界感本身涉及我所执全域（财物 ／ 关系 ／ 名利 ／ 所坚持内容 ／ 喜好 ／ 法 ／ 我本身），但**悭不等于我所执**——悭只占其中一个窄切片：**我所执 + 贪已得 + 施界面上的不舍动作**三者同时在场。判准一条：**有没有"施的界面"**（可分享而紧缩不肯才成悭）。按此判准 + 五悭细目过七项清单：财物（施悭 ／ 住处悭）、关系（家悭）、名誉（称誉悭）、法（法悭）四项是悭的经典所缘；"所坚持的内容"归见取 + 法贪（法染色层主战场）、"喜好"归贪爱本身（无施界面）、"我本身"归萨迦耶见（俱生身见通道）——复杂性属于末那，不属于悭。

### 5.2 四界面分诊——严格不现行

修行者逐界面过现量：**财物 ／ 关系 ／ 名誉 ／ 法四界面，悭严格不现行**。施境现前时每次运作的是"施出去的东西和被施对象是否合适""引介关系对双方是否都好"的简择，满足条件即施、心不紧，事后心安（"很少处于过后心不安的情况"）。回避形态（第三形态）亦由主动进入施界面并跑简择的运作方式间接排除。

**结构读法**：修行者的天生简择标准正是遮缘单第 ① 条（伤他否）+ 愧的共业秩序质地（"对双方都好" = "如果大家都这样做"的究竟层世俗化操作系统在施界面的运行形态）——**慧简择占住了施界面，悭没有现行位置**。本次讨论没有安装新配置，只是给已在运行的配置做了名相归位（知道这是施度的简择支、知道悭判在心相）。法悭侧预判"待验证"的结果也是不现行——与"法悭守位置稀缺性 = 排名价值"的剥解相符：排名脚手架已在嫉精修中拆掉。

### 5.3 结构归位与现量现行分离（学术诚实）

悭归小随通道、对治面无贪 → 施，是经典体性归位；修行者位置四界面不现行是现量事实；凡夫位贪种仍在，**不现行 ≠ 永断**——此法在修行者处无主修区，归档即可。

## 六、见众生维度

凡夫悭的现行链：

```
我痴(实有化"我的"域：域之盈亏=我之盈亏)
  → 外物被征用为"我"的防御工事（财物=对抗无常恐惧的护城河、存在证明）
  → 每次"不舍"当下兑现即时安全感微奖励（守住了，东西确实还在）
  → 习气被持续正向强化 → 鄙涩畜积
```

**悭是「常驻动机」候选的第二个复证样本，且是最强的一个**：动力 = 贪已得（可守内容）✓；失则损 = 施则存量减 ✓；行有保全概率 = **守住几乎必然立即奏效（保全概率接近必然，比覆的"间歇保全"更高）** ✓。覆的藏匿只有非零概率不被发现，悭的守持每次都立即兑现——这解释了悭在凡夫处为何是最稳定、最不需重新发动的随烦恼之一：**奖励结构几乎从不落空。凡夫悭不是品行问题，是保全概率最高的常驻动机结构必然。**〔常驻动机为第三层候选，此为复证第二例〕

而它的苦与出口，经典早有断语：财为[五家所共](../../../resources/cards/五家所共.md)（王、贼、火、水、恶子）——存量本来守不住，悭者的"保全"只是延迟结算；且拥有越多防御面越大，"鄙涩"之苦正是**被所有物反向占有**——物成了主、人成了守卫。凡夫缺口 = 看不破所有权假立 + 不见五家所共的无常必散；修行者出口照旧是那把钥匙——**「我的」无自性**（与嫉"排名无自性"、慢憍"破实我中心"同钥）。

→ 利他善巧轴第三层（理解烦恼内在机制）在悭上的一填：与"孩子覆藏三段皆缺"（[覆 §5.3](./覆.md)）、"凡夫嫉看不破排名无自性"（[嫉 §五](./嫉.md)）一脉——是机制，不是人品。

## 七、结构关联

- **E 分位假立（贪一分）**：悭 = 一股贪在"自所有不舍"分位的假立名，无独立别体，无体性诤议。
- **小随所缘版图再扩**：忿恨恼缘违境 → 嫉缘他荣境 → **悭缘自所有**——小随的所缘从"违我者"、"胜我者"扩到"我已得"。
- **生起次第**：骨架 §七 凡夫染心链"嫉（他荣现起）→ **悭**（自有被求）"。
- **悭嫉镜像**：守内 ／ 憎外，同一"我所"边界守卫的两面（"悭嫉"并称的结构原因）。
- **双重假复证（第三例）**：体上分位假立（贪一分）✓ + 所缘上世俗概念假立——**「我的」所有权 = 共业约定产物，物上不带"我的"标签** ✓；并补一层精度：脚手架（所有权概念）可拆，其下接末那俱生我所执（比比较心更顽固的质地）。
- **常驻动机复证（第二例 · 最强）**：贪已得 + 施则失 + 守住保全概率接近必然——见 §六。
- **对治收编**：无贪 → 布施正面对治；究竟收于"「我的」无自性"——与嫉收于"排名无自性"同归**破我所 / 实我中心**一把钥匙（[假说 18](../../假说/假说-18-对象转换元假说.md)一致）。
- **施的边界框架**（§四）为本法特有产出：响应式时机 + 遮缘三条 + 称力线 + 判心相不判施否——可迁移到布施波罗蜜后续学习（菩萨道次第阶段）。

## 八、学术诚实三层标注

**第一层（经典）**：悭定义原文（耽著法财 ／ 秘吝为性 ／ 不悭 ／ 鄙畜为业 ／ 心多鄙涩畜积财法）；悭贪一分、离贪无别相用；五悭（《大毗婆沙论》）；《瑜伽师地论》施品不应施明文（毒火刀酒 ／ 求刀自害 ／ 非器不说深法 ／ 眷属不强施 ／ 不强舍身命）；随力随分、应时施（《优婆塞戒经》）；五度如盲般若如导（《大智度论》）；三福田；财为五家所共。

**第二层（框架应用映射）**：三段链无反转图；悭嫉镜像表（守内 ／ 憎外、存量 ／ 高度）；财悭 ／ 法悭零和不对称的整理；遮缘三条对经典明文的无损压缩；"判心相不判施否"与持戒究竟层的同构整理。

**第三层（自主推论）**：
- **「我的」（所有权）是世俗概念假立**（共业约定产物、物上不带"我的"标签）= 修行者现量确认，双重假候选第三复证样本；
- **法悭守位置稀缺性 = 借排名脚手架、是悭嫉交界** = 结构剥解推论；
- **"触发烦恼不算自伤"的称力区分 + 事后心安 ／ 反复自我重申检验** = 讨论产出的实操判准（称力线本身是第一层）；
- **回避施境的隐蔽形态、"缘到位标准越抬越高"** = 推论性补充；
- **凡夫悭 = 保全概率最高的常驻动机结构必然** = 常驻动机候选复证（候选本身待续证）；
- 均属修行者位置现量分诊与结构推论，状态为"与唯识框架内在一致的假说 / 现量报告"。

> **本法一处归位记录**：模型章末检验问"「我的」边界感如何运作"，修行者指出此问实已越出悭的范围、涉及我所执全域（七项清单）、需更细分辨而不可在此展开——经五悭细目 + "施界面"判准归位：四项属悭、三项各归己通道（见取 ／ 贪爱 ／ 萨迦耶见）。复杂性属末那、不属悭——一次"拒绝范围膨胀"的现量分诊演练。
