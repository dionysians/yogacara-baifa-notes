## §一 经典概念（闻）

### 1.1 定义原文

[《成唯识论》](../../../resources/cards/《成唯识论》.md)卷六：

> 「云何为害？**于诸有情，心无悲愍，损恼为性。能障不害，逼迫为业**。谓有害者，逼恼他故。**此亦瞋恚一分为体，离瞋无别害相用故。瞋害别相，准善应说**。」

### 1.2 拆解

| 要素 | 内容 | 解读 |
|---|---|---|
| 所缘 | **于诸有情** | 专缘有情（不缘非情）|
| 体性 | **损恼为性** | 以损害恼乱有情为体；其体性侧显现 = 心无悲愍 |
| 业用 | **逼迫为业** | 令他受逼恼 |
| 障 | **不害**（善心所）| 对治方向 = 悲愍 |
| 本体 | **嗔一分、无别体** | 「离瞋无别害相用故」|

### 1.3 本体归属

- **嗔一分、E 分位假立、无别体**——「此亦瞋恚一分为体，离瞋无别害相用故」。害与[忿](./忿.md) / [恨](./恨.md) / [恼](./恼.md) / [嫉](./嫉.md)同族，皆嗔之一分。**无派系诤议**（嗔系五法体性诸家一致归嗔一分）。
- **生起次第**（骨架 §7.3）：名利场域中诳 → 谄 → **害**（损恼有情）→ 自盛现起 → 憍。但害的位置不是时序链的下一拍（详 §四）。

### 1.4 「准善应说」的正读

经典对"嗔与害如何分别"不展开，只留「瞋害别相，准善应说」四字——**害是嗔一分、无别体，准照[不害](../善心所/不害.md)是[无嗔](../善心所/无嗔.md)一分、无别体的方式来理解**。

[不害](../善心所/不害.md)定义（《成唯识论》卷六）：「于诸有情不为损恼，无嗔为性……此无别体，由无嗔故，于有情所不为损恼，假立此名。」→ 不害 = 无嗔在「缘有情·不损恼」这一所缘+行相上的一分，无别体。

故害 = **嗔在「缘有情·损恼逼迫」这一所缘+行相上的一分，无别体**。是**整体与一分**的关系。

> **一处订正**：讲法初稿曾用"自调伏面 / 利他面"两个"面"去分嗔与害（说嗔属反应面、害属损他面）。此框架被修行者证伪——这两者是描述任一心所属性的两条**独立维度**，不是分装嗔害的两个格子（嗔本身既有自反应面读数、也有损他面读数）；用它们去分别框定嗔害，方法本身就错。「准善应说」的真义只是**一分·无别体**，不含任何维度对偶。本笔记不保留该错误框架。

## §二 与相邻法辨异

| 对比 | 分界 |
|---|---|
| 害 / 嗔 | 嗔（整体）通缘违境（有情、非情皆可）、行相是憎恚；害（嗔之一分）唯缘**有情**、行相是**损恼逼迫**。害 = 嗔缘有情而起损恼那一分被切出单立。〔传统注释另有"嗔能断命、害但损恼"的程度别相，《成唯识论》原文只到「准善应说」、未展开程度，此条属第二层注释，未当经典原文用〕|
| 害 / 忿恨恼嫉 | 忿恨恼嫉的所缘是"某违我 / 胜我之境"（境对我如何）、朝向"我受触"；害的所缘是**有情**、朝向"**我损他**"。害不是忿恨恼时序链上的环节，是另起一支的并行嗔分（详 §四）|
| 害 / 正当严厉 | 判准在体性不在外相——损恼是不是出发 / 体性。外行为强硬而心地无嗔、悲愍、智抉择者非害（详 [不害.md §九](../善心所/不害.md) 四种组合表 + 大悲商主本生）|

## §三 主线 1 · 体性机制（嗔一分 × 发作方式 · 无独特核）

### 3.1 两参数模型正向确认——无剩余

害 = 根本分（**嗔**，经典明标）× 发作方式（**于有情·损恼逼迫·无悲愍**）。可由此完整重构、无剩余——E 分位假立对两参数模型（[谄.md §3.4](./谄.md)）的又一次**顺向确认**。

### 3.2 纲领适用域收紧（修行者纠正一处方法论偏移）

精修中模型曾把"害是否有独特核"摆成读法 A（无剩余）／读法 B（有独特核）的**开放二选一**，请修行者判。被修行者纠正：经典已明文「离瞋无别体」，无别体已是定论——**论证"心无悲愍是独特核"= 推翻经典**，根本不是可上桌的选项。

由此收紧"小随=根本分×发作方式·无独特核"纲领的适用域：

> 「无剩余」判准的**撞验**只对 A / C 类有意义（那里经典未判"无别体"，剩余之有无是真问题）；**E 类经典已直接判无别体，纲领在 E 类只做正向重构确认，不设"有无独特核"的开放二选一**——在 E 类上设此二选一，等于把经典裁决当成待裁。

### 3.3 「心无悲愍」的三层用意 + 状态/书写两层澄清

既然悲愍不在场是**任一嗔分现行的共相**（嗔与无嗔互违，忿恨恼现行悲愍也都不在），经典为何偏在害的定义里把「心无悲愍」挑明？读出三层用意（标好层次）：

- **第一层 · 所缘定位码（经典框架内）**：「悲愍」只对**有情**才谈得上（对非情、对苦具无所谓悲愍）。"心无悲愍"一笔同时**钉死害唯缘有情**这个区别于嗔的坐标。忿恨恼嫉靠"现前违缘 / 怀怨 / 追触 / 他荣"标清所缘；唯独害所缘=有情、行相=损他，最精确的标记就是"心无悲愍"。
- **第二层 · 对偶镜像（经典框架内）**：害**障不害**；不害 = 无嗔 +「悲愍为业」（缘有情）。要让害精确成为"不害之障"，它必须 = 嗔 +「心无悲愍」（缘有情）。"心无悲愍"是把害钉成"不害之障"的镜像标记——不写它，害只是泛泛"嗔到人"；写了它，害才精确对位到不害的悲愍业。
- **第三层 · 对治入口显写（推论，紧贴经典）**：悲愍是整个嗔系的通治（§五 一问）。经典在害这个"有情面终端"显写「心无悲愍」，等于把对治直接标在体性描述里——害的对治不必另寻，就是让**悲愍涌现（修不害）**，而悲愍一起，连带把整条嗔系冲掉。

**状态 / 书写两层澄清**（消"心无悲愍是否独特核"之惑）：

> 作为**现量状态**，心无悲愍是嗔分共相（区分不了害与忿恨恼）；作为**经典的书写选择**，它是钉住"害=向有情损他·不害之障"坐标的定位码 + 显写对治。两者层次不同——三层用意**都不给害加体**（经典紧接说「离瞋无别体」），它是定位码 / 对偶标记 / 对治笔，不是独立核。

→ 真正区分害与其余嗔分的，仍是**损恼为性（损他为出发）**；「心无悲愍」是经典用来钉所缘+对偶+对治的标记笔。这条也回头印证 §3.2：心无悲愍非害的独特识别码。

## §四 主线 2 · 嗔系五法链收口（小阶段性总结）

> 害是小随嗔系最后一法。本章作 **忿恨恼嫉害 五法收官的小阶段性总结**。

### 4.1 五法同为嗔一分——按"根本分×发作方式"各占一坐标

| 法 | 所缘 | 行相（发作方式）| 时位 / 支属 |
|---|---|---|---|
| **忿** | 现前违缘 | 暴怒、发暴恶身表（执仗）| 违境反应时序·当下 |
| **恨** | 已过违缘 | 怀怨结不舍、热恼 | 违境反应时序·忿后蓄积 |
| **恼** | 追忆违缘 | 追触暴热、狠戾（蛆螫）| 违境反应时序·恨后追往 |
| **嫉** | 他荣境 | 不耐、自夺忧戚 | 另起一支（不在时序链）|
| **害** | **有情** | **损恼逼迫·心无悲愍** | **另起一支·非时序（并行，可伴随可独立）** |

五法的差别**不来自"不同的面 / 维度"，只来自"嗔被 narrow 到哪个所缘+行相"**——两参数模型在嗔系的统一显化（根本分=嗔恒不变 × 发作方式各异）。

### 4.2 三种支属关系

- **忿恨恼是同一违境反应的时序三相**：当下暴怒 → 忿后怀怨 → 追忆暴热，所缘是"同一违我之境"的三个时间切片，**这三法之间是真链**。
- **嫉、害各自另起一支**：嫉所缘换成"他荣境"、害所缘换成"有情"，皆不在违境时序链上。
- **害唯一的区别坐标 = 朝向"损他"**（缘有情·我损他）；其余四法朝向"我受触"（境对我如何）。害可与忿 / 恼**俱起**（暴怒时顺手损恼对方），也可**独立**现行——这是普通的心所俱起 / 独起，**不是层级关系**。


### 4.3 修行者位置 · 嗔系五法全景（见自收官）

| 法 | 修行者位置 |
|---|---|
| 忿 | 亲子场脉冲**现行**（强忿；触发点 2 我所强加 + 屡犯严重性评估）|
| 恨 | 不现行（归因改道·无结怨）|
| 恼 | 结构性不现行（无往恶可追）|
| 嫉 | 究竟收"排名无自性"·可拆 |
| **害** | **结构性不现行（损恼非出发，详 §五）** |

→ 嗔系五法里**只有忿一法在亲子场脉冲现行**，其余四法不现行 / 可拆。

## §五 主线 3 · 见自（害结构性不现行）

### 5.1 判别点修正——决定害的是"损恼为性"，不是"心无悲愍"

修行者分诊把害的判别问对了地方。两段拆开：

- **「心无悲愍」段**：忿会盖住 / 冲淡悲愍（悲愍起时愤怒被冲掉），这是**忿与悲愍互违**（嗔分现行则悲愍不俱）。但**盖住悲愍是"忿"干的、不是"害"干的**——任一嗔分现行都盖悲愍，故心无悲愍是**嗔分共相**，区分不了害与忿恨恼，拿它当害的判别点从一开始就抓错。
- **「损恼为性」段（真判别点）**：害的体 = 损恼有情本身就是出发 / 目标。修行者现量："从目标上肯定是希望孩子更好，而不是以损害恼乱有情为出发。"**损恼非出发 → 害的体性根本不成立**。

→ 真正决定害的判别点是**损恼是不是出发 / 体性**，不是悲愍在不在场。这条回头印证 §3.3（心无悲愍是嗔分共相、非害独特识别码）。

### 5.2 害结构性不现行 + 操作核校回

> **害在修行者位置 = 结构性不现行。** 亲子场那一刻是**强忿现行**（忿盖住 / 冲淡悲愍），但**损恼非出发（出发是为孩子好）→ 害分不俱起**。

[亲子场无嗔操作核（5/02）](../../教学操作核/教学操作核-01-亲子场无嗔.md) 那句"起害心后快速识破"中的"起害心"是**松标**，**校回"强忿"**——与 [恼精修（6/12）](./恼.md) "亲子训斥松标为恼 → 校回强忿"同一先例、同一道理（嗔系强度不是判据，唯识按行相分立）。

### 5.3 自他相换反射本具 = 悲愍本具的运作机制

修行者现量："做了有害对方的事，想象对方用同样方式做在自己身上就受不了、根本做不出，怎么能带来快感？"——这个**自他相换反射**是悲愍本具的当下运作，它正是阻断害（损恼非出发）的机制，也解释了为什么修行者缺"损人之乐"的现量（见 §六 利他轴）。

## §六 主线 4 · 见众生 + 利他善巧轴

### 6.1 害的凡夫位三型动机 + "害无天然源"

**强命题（修行者主导 · 法理+现量双支）**：**损恼有情不是天然特性，必有正向 driver**。麻木 ≠ 天生去损恼，所谓"冷害"是种子累积、不是天然。三型动机：

| 型 | 起因（三毒）| 机制 | 愧 |
|---|---|---|---|
| **报复型** | 嗔（+痴误归因 + 恨嫉累积）| **痴把"我的烦恼苦"误归因于某有情** → 损恼他=误以为除苦 / 讨公道 → 嗔得宣泄 + 误以为除苦 = 代偿快感（**非损人本身的快感**）| 事后多有悔（误归因可被拆）|
| **扩张型** | 贪（我所）| 损恼他人 = 建立 / 强化 / 扩张**我所**的手段 | 我所得逞则无悔 |
| **正当化型** | 痴 / 恶见 | 邪见把损恼建构为正当 / 有功德（祭祀杀生、外道见、意识形态 / 制度性"替天行道"）| **无愧**（见未破前刹车不亮）|
| 俱生形态 | — | 以上任一在无始熏习下结成种子、现"似天然"冷害——驱动力 在过去熏习，非当下、非天然 | 似无当下动机 |

> 报复型快感的拆解（修行者命门）：单纯嗔出口解释不了快感；真正的链是**痴误归因（把自苦归于他）→ 损恼他=误以为在"除苦源"→ 那点快感是"以为在解决问题"的代偿**，不是损人本身可乐。修行者缺此现量（自他相换反射本具、损恼做不出），故凡夫害只能走**认知路径**理解，不靠共情损人之乐——与信德冷质地 / 慧解脱路径一致。

### 6.2 经典互印——九恼事 + 杀生通三毒

讨论结果与经典相互印证（修行者确认）：

- **[九恼事](../../../resources/cards/九恼事.md)**（[《集异门足论》](../../../resources/cards/《集异门足论》.md) / [《大毗婆沙论》](../../../resources/cards/《大毗婆沙论》.md)）：嗔害的九种起处 =（他损我 / 损我所爱 / 饶益我所憎）×（过 / 现 / 未）。**正是报复型"痴误归因把损害归于他"的经典骨架**——九处每一处都是"他损我 / 我所"的读取，而那读取本身是痴的颠倒（实无"我"可被损，归底是 [我执](../../../resources/cards/我执.md)）。
- **杀生通三毒**（[《俱舍论》](../../../resources/cards/《俱舍论》.md) 业品）：损害有情（杀业为其极致）**通由三毒起**——由嗔起（报复怨敌）=报复型 / 由贪起（为皮肉、财利、护亲）=扩张型 / 由痴见起（邪见正当化）=正当化型。三型与经典三毒框架精确对位。
- **体因之辨**：害的**体**经典定死=嗔一分（损恼行相即嗔）；但**发起害的因 / 动机**可通三毒（扩张型因是贪、正当化型因是痴见）。体恒嗔一分、因通三毒，不矛盾。

### 6.3 究竟归因 + 利他善巧轴第三层填补

三型往下追，**究竟都归到：凡夫的贪 + 俱生痴 + 以此产生的恶见，而凡夫看不到这一点，才落入害**：

- **俱生痴**——把无我读成"有我被损 / 有我可扩张"（报复型、扩张型的共同颠倒底）；
- **贪**——我所的建立与扩张动力（扩张型直接由它起）；
- **恶见**（贪痴所产）——把损恼建构成正当 / 必要 / 有功德（正当化型由它起）；
- **看不到** = 无明遮蔽：凡夫不见这三者在驱动自己，故害无刹车。

→ **利他善巧轴**（[画像 §⑤](../../实修/修行者画像.md)）缺口第三层（理解烦恼内在机制）在"损恼有情"这格补上了，补法正是**认知路径**（理解这条根因链），不靠共情损人之乐。

### 6.4 见自见众合流 + 悲愍通治全嗔系

**一问产出**：悲愍是无嗔 / 不害的现行相，嗔与无嗔互违——**悲愍真起的那一刻，无嗔在场 → 整个嗔系（忿恨恼嫉害）一并不现行**。故悲愍不只对治害一法，是**整个嗔系的通治**。

**见自见众合流点**：修行者害不现行的入口（自他相换反射本具、损恼非出发、悲愍本具）与凡夫害的缺口（痴误归因 / 贪我所 / 恶见正当化），合流在**悲愍 + 无我**——修行者手里有通治（悲愍冲嗔 + 了无自性破误归因），凡夫缺。**害（报复型）与慢 / 嫉 / 憍同一把钥匙**（破实我中心）；扩张型收于无贪（拆我所）。

## §七 结构关联

### 7.1 双重假复证——所缘侧深化样本

- 体上：嗔一分、E 分位假立、无别体 ✓
- 所缘上：害缘的"此有情=损我者 / 敌 / 可扩张对象"是颠倒建构（无自性）✓，**但这个建构比贪系更深**——贪系（[嫉](./嫉.md)"排名" / [悭](./悭.md)"我的" / [诳](./诳.md)"德相" / [谄](./谄.md)"网住"）挂的是**世俗概念脚手架**；害的核心（报复型）几乎不挂世俗中介，**直接是俱生我执的颠倒读取**（"无我"读成"有我被损"）。
- → 害是双重假**所缘侧从"世俗脚手架"深化到"俱生我执颠倒"的样本**，与悭精修"脚手架下接末那俱生我所执"呼应、但害更直接（脚手架近无）。〔第三层·候选〕

### 7.2 常驻动机不适用——印证其为贪系机制

害**不套常驻动机模型**：报复型是**事件性**（痴误归因触发即发、归因一拆即坍），不"站着不走"；扩张型的损他是**工具性**（服务我所扩张时才用），也非常驻。常驻动机（动力+失则损+保全概率）是贪对象时态派生的**贪系结构**，嗔系害不套——这是该候选作用域的又一次确认（不适用本身是有信息的结果）。

### 7.3 嗔系五法收官

害是小随嗔系最后一法。忿恨恼嫉害五法精修完毕，§四 即作小阶段性总结：五法皆嗔一分、各占"根本分×发作方式"一坐标；忿恨恼是违境反应时序三相、嫉与害各起一支；修行者位置上仅忿（亲子场）脉冲现行。

### 第一层（经典）

- 害定义原文、嗔一分、离瞋无别体、「瞋害别相准善应说」（《成唯识论》卷六）；[窥基](../../../resources/cards/窥基.md)《百法明门论解》"嗔之一分名害"

- 三型动机与经典三毒框架的对位 = 经典框架内的映射
- "嗔能断命 / 害但损恼"程度别相 = 传统注释层（非《成唯识论》原文）

### 第三层（自主推论）

- **「心无悲愍」三层用意（所缘定位码 / 对偶镜像 / 对治显写）+ 状态-书写两层澄清** = 修行者追问"经典为何专写心无悲愍"引出、本笔记整理（第三层用意属推论、紧贴经典）
- **纲领适用域收紧（E 类只正向确认、不设有无核二选一）** = 修行者纠正模型方法论偏移后结晶
- **"害无天然源·必有正向 driver"+ 三型动机（报复 / 扩张 / 正当化）+ 俱生是种子残留** = 修行者主导、法理+现量双支
- **究竟归因 = 贪 + 俱生痴 + 恶见，凡夫不自见** = 修行者收束
- **悲愍通治全嗔系**（悲愍起则整个嗔系不现行）= 嗔与无嗔互违的推论
- **双重假复证（所缘侧深化到俱生我执颠倒）/ 常驻动机不适用（印证贪系机制）** = 已立候选的持续验证
- 害结构性不现行、判别点=损恼为性非心无悲愍、自他相换反射本具 = 修行者现量分诊

### 本法元记录 · 两处方法论偏移自我校正

本法讨论阶段，模型两处偏移经修行者纠正：① 用"自调伏面 / 利他面"维度对偶去分嗔害（§1.4 证伪——维度是描述属性的独立轴、非分装嗔害的格子；且否定句也不该出现、否则把错框请回）；② 把害是否有独特核摆成开放二选一请修行者判（§3.2——经典已判无别体，论证有核=推翻经典，根本不是可上桌选项）。另一处用语校正：把害称"损他底色"（§4.2——并行不蕴含层级，校回并行可俱起 / 独立）。三处皆"经典>假说 + 经典已判定者不重开"纪律的实地复演。
