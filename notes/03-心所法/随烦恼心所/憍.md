## 引言

憍是小随烦恼第十法、贪系第二法，也是**整个小随 10 法的收官**（嗔系 5 + 贪系 2 + 贪痴一分 3 已全过）。本笔记按 [随烦恼整体认知](./随烦恼整体认知.md) §六 §七 确立的姿态（了解→对治 / 现量分诊 / 见自见众双线 / 必问"它是哪个根本烦恼的分位"）展开。

**本次精修两个核心特色**：

1. **"盛"的边界现量厘清**：修行者从"无需他人作镜"反推出憍所缘的精确结构——"盛"= 圈层相对的世俗建构正价（非客观胜出义、非稀缺区隔），把憍送成双重假所缘侧的当代强样本。
2. **小随 10 法收官 · "小"的指代提炼**：以憍收口，把贯穿小随的几条整理（双重假 / 常驻动机 / 两参数 / 看破深度）**归位为"小随之'小'指代什么"的不同角度**——修行者明确重定向：目标不是立假设，是搞清楚经典把随烦恼分小/中/大到底在指什么。

## §一 经典概念

### 1.1 定义原文与拆解

《成唯识论》卷六：

> **「云何为憍？于自盛事深生染著醉傲为性，能障不憍染依为业。谓憍醉者生长一切杂染法故。」**
> **「此亦贪爱一分为体，离贪无别憍相用故。」**

| 拆解项 | 内容 |
|---|---|
| **所缘** | **自盛事**——自己的兴盛之事。唯缘"自"之盛，**不缘他**（这是憍区别于慢的根本处）|
| **体性** | **深生染著 + 醉傲**——对自盛事深深耽著，并起如醉酒般的傲逸陶醉（"醉"状其昏然自得、失警省）|
| **业用** | **染依为业**——"憍醉者生长一切杂染法"，憍是一切杂染法的**依止 / 温床**（非如嗔系"逼迫热恼"直接损境）|
| **本体归属** | **贪爱一分为体，离贪无别**——E 分位假立，**无别体**，无派系诤议 |
| **对偶** | 能障**不憍**。"不憍"非十一善心所之一，归摄于[无贪](../善心所/无贪.md)（憍是贪一分，其对治善即无贪一分）|

### 1.2 七憍——"自盛事"的所缘细目

经论列**七种憍**（《瑜伽师地论》等所列，诸论开合略异，取通行七数），是"自盛事"的具体例举：

无病憍 / 少年（少壮）憍 / 长寿（命）憍 / 族姓憍 / 色力（端正）憍 / 富贵（自在）憍 / 多闻（聪慧）憍。

→ 七憍揭示：凡可被读作"我之盛"者皆可成憍所缘——从最物理的（无病、少壮、色力）到最世俗建构的（族姓、富贵、多闻）。**七憍是举例、非滤网**（不是"够这七格才算"的客观清单）。详见 [七憍](../../../resources/cards/七憍.md)。

### 1.3 本体归属

憍 = **E 分位假立 · 贪系**。在 [随烦恼整体认知](./随烦恼整体认知.md) §三五象限中属 E 类（小随 10 法皆此类），与[悭](./悭.md)并列**贪系 2 法**。无别体、无派系诤议（与嫉害同为"离根本无别相用"）。

## §二 与相邻法辨异 + "盛"的边界

### 2.1 憍 / 慢——最核心辨异

| | [慢](../烦恼心所/慢.md)（根本烦恼 · 别有体） | 憍（随烦恼 · 贪一分无别体） |
|---|---|---|
| 所缘 | **缘他**（恃己**于他**高举，必涉比较）| **缘自**（于**自**盛事染著，不必涉他）|
| 体性方向 | **自抬**（向"我"之位置）| **摄受 / 染著**（向自境陶醉，是贪的方向）|
| 撤对照测试 | 撤对照即消失（A 组横向慢）| **撤对照仍在**（陶醉于自盛本身，不需比较对象）|
| 本体 | 别立实有 | 贪一分 · 无别体 |

> [慢.md §2.2](../烦恼心所/慢.md) 的粗判"去掉对照者，良好感是否仍在？仍在→贪 / 消失→慢"——**憍正是那个"仍在"的贪侧**：对自盛事的醉傲陶醉，无须他人作镜。

### 2.2 憍 / 贪、憍 / 正当自信

- **憍 / 贪**：憍是贪一分，但贪通缘一切顺境（内外境皆可），憍**唯缘"自盛事"且加"醉傲"相**——是贪在"自盛"这一特定所缘上、起傲逸陶醉的分位。
- **憍 / 正当自信**：自信是对能力的如实评估（慧 / 胜解，可无染）；憍是于自盛"深生染著醉傲"（贪 + 昏醉，失如实）。判准在**有无染著醉傲相**，不在"是否肯定自己"。

### 2.3 "盛"的边界——圈层相对的建构正价

修行者从"无需他人作镜"反推："既然憍不照镜子，那是不是'我贪且我有就够了，根本不需要是盛'？"经厘清，结论是**基本一致、一处精度校准**：

**㈠ "盛"不是"胜过他人"（比较 / 客观胜出义）**——那一读法属慢，不属憍。憍不照镜子，故"盛"绝不能是比较义。

**㈡ 但"盛"不能整个清零**——若只剩"我贪且我有"，憍与普通贪自物无法分立。憍多一个**醉傲相**，而"醉"必有可醉之物：不会对自己读作"破烂 / 无所谓"的东西飘飘然。所以"盛"残留的内容 = **所缘被读作"好 / 可恃 / 令我得意"的正价**。

**㈢ 但这个"盛"不是外挂的第四味料，而是醉傲贪自带的形**——不是"我贪 + 我有 +（再核对它是盛）"三步，而是"**醉傲地贪着我有**"这一动作本身就把所缘建构成了"盛"。用两参数讲：贪 × **于自盛事醉傲**——"盛"写在第二个参数里，不是独立的所缘门槛。

**㈣ 现代多元化使"盛"的建构相对性裸露**：古典社会预设价值共识（健康 / 长寿 / 族姓 / 多闻，大家都认好）→ "盛"看似客观；现代价值圈层化 → **同一所缘在 A 圈是盛、在 B 圈是零** → "盛"是**圈层相对的建构**这一点裸露出来了。但要守一条边界：**圈层只供给"好不好"的价值标尺（价值谱系），不进醉傲的当下结构**——一旦"圈里人"进了醉傲现场（"我比圈里其他人更懂"），那已是**慢**、不是憍。

**㈤ "稀缺 / 不是大家都有"归慢侧，不是憍的结构要件**：七憍中**无病憍 / 少年憍**是反例——健康的人、年轻的人都多得很、毫无区隔，可经典明立此二憍。故稀缺非憍要件；"我有他人所无"要先登记"别人没有"= 比较 = **慢的区隔高举**。现实中憍常被稀缺放大（憍 + 慢复合），但那放大器是慢、不是憍自己。

> **校准后的"盛"** = 我贪 + 我有 + 我（或我所认同的圈层标尺）把它读作"好 / 可得意"的正价；删去"客观胜出"与"稀缺区隔"（二者归慢侧）。

## §三 主线 1 · 体性机制

### 3.1 两参数无剩余 · 正向确认

按 [谄.md](./谄.md) 确立、[害.md §3](./害.md) 收紧的两参数纲领：憍 = **贪（经典所标根本分）× 于自盛事醉傲（独特发作方式）**。E 类（经典已判无别体）只做**正向确认无剩余**，不设"有无独特核"的开放二选一。两个边界风险都消解：

| 风险 | 检验 | 判定 |
|---|---|---|
| "傲"偷藏慢的"举我"？| 若"傲"含向"我位置"的高举，憍便有慢剩余 | **无**——经典明文「离贪无别憍相用」；"傲逸"是贪深染自盛到飘然的**陶醉态**，非慢的举我向位置 |
| "醉"之昏要写进痴？| 若昏醉算痴，憍便成贪痴一分 | **不写**——经典标憍为**贪一分**、非贪痴一分；昏醉之"不见过患"是痴**共同底**（恒在背景），按痴分定则"经典不标则不专写" |

→ 憍 = 贪 × 自盛醉傲，**无剩余**。

### 3.2 染依为业——宽口温床

经典原文只说 **「染依为业，谓憍醉者生长一切杂染法故」**——憍是"**生长一切杂染**"的**依 / 温床**，是个**宽口**业用，**没有指定唯一后继**。其机理在"醉"字：

> 醉的本义 = **失警省**。憍醉者心高逸飘然 → 不防恶、不修善 → 一切杂染失闸滋长。

三个后继按离憍远近摆位（皆"生长的杂染"、不冲突）：

| 后继 | 与憍的关系 | 离憍 |
|---|---|---|
| **放逸** | "醉 = 失警省"的最直接失闸门（放逸 = 不防修染净）| 最近（失防）|
| **掉举** | 憍**自体质地最相邻**——醉傲的飘然嚣动即掉举相，且掉举与憍**同是贪一分** | 最近（同质）|
| **散乱** | 经"贪扩张"中介到达的下游——憍醉常态 → 强化贪种 → 攀缘经营更多盛事 → 心流荡多境 | 一步之遥 |

> **第二、三层标注**："醉 = 失警省 → 放逸为最直接失闸门""掉举为自体最相邻"是通途 / 框架解读；"放逸"非经典对憍的专说。"憍→（经贪扩张）→散乱"是修行者提的下游链、与体性一致（第三层）。

### 3.3 自熏贪种——憍是"染依"的真正机理

憍长驻当温床，不靠某个后继，而靠**自体的正反馈常态**：

> 憍是贪一分 → 每次醉傲就**回熏贪种**（尤其"自盛-贪"种 + 末那"我所"）→ 贪种粘着↑ → 更易醉傲 → 自体闭环。

这正是憍为何是"**染依**"（常驻温床 / 基底）而非"逼迫"（一次性事件）的机理——它靠自熏续命、长驻不走，故能作一切杂染的依止。[谄](./谄.md)那条"熏种循环变体"在憍处以**最纯的自熏形态**再现（谄熏种靠"维持将来获利想象"中介，憍直接"醉傲即回熏自盛贪种"、无中介）。

## §四 主线 2 · 小随 10 法收官 · "小"的指代〔专章 · 小阶段性总结〕

### 4.1 重定向——目标不是立假设，是提炼经典"小 / 中 / 大"的指代

贯穿小随的几条整理（双重假 / 常驻动机 / 两参数 / 看破深度），**不是要辩护的假设**。修行者明确重定向本组学习的真出发点：

> 通过整理 10 个小随的特性，**搞清楚经典把随烦恼分"小 / 中 / 大"到底在指什么**。这些整理是提炼"小"之指代的不同**观察角度**，不是自主假说。

→ 故这些内容**主要是第二层（框架整理）、不是第三层（自主假设）**——出发点是理解经典设定、在经典三轴之上作整理性提炼，离经典更近。

### 4.2 两种"看破深度"——"小"指现行级，不指究竟断

收官的关键厘清：**"深度"有两种，不可混**。

| 两种深度 | 指什么 | 害的情况 |
|---|---|---|
| **现行级看破深度**（停现行）| 这个烦恼现行出现时，要多深才能看破、停掉这一次现行 | **浅层**——害现行"损我者→损恼"是粗显事相，现行场拆"损我者"读取 / 拆误归因即坍 |
| **究竟断深度**（断种子）| 要多深才能把它连根断尽 | 深层——俱生颠倒要修道磨（但这是**嗔根**的深度，与所有嗔系共享）|

→ **"小"指的是前者，不指后者**。小随之所以"小"（行相粗、事相级），正因为**它现行出现时就处在浅层**。害的深层俱生颠倒属**究竟断**维度（跟嗔根走），不是衡量"小"的那把尺。

### 4.3 看破深度（现行级）= 表层 = 全体小随通性（含害）

故"看破深度（现行级）= 表层"**覆盖全体 10 小随、含害**——只要小随现行出现，就处在这一浅层、浅层看破即停现行。这同时化解了两条早期张力：既**不需要害的"贪系脚手架 / 嗔系俱生颠倒"两形态**来解释离究竟，也**不靠脚手架厚薄**（该度量被害打破、已弃）。

### 4.4 "小"的指代（提炼自 10 法）

经典三轴（[骨架 §二](./随烦恼整体认知.md)）+ 整理出的修行学侧，**共变、同指一件事**：

| 维度 | "小"的内容 | 来源 |
|---|---|---|
| 行相 | 粗（具体可识别事相）| 经典轴一 |
| 自类 | 各别起 | 经典轴二 |
| 遍染心 | 窄（欲界第六识为主）| 经典轴三 |
| **看破深度（现行级）** | **浅层——现行出现即在表层，浅层看破即停现行** | 整理（修行学侧）|
| **离究竟** | **远（事相级对治，事件场识破即可）** | 看破深度的等价表述 |

→ 统一线索：**小随 = 染心的最表层、最事相的一类**；"看破深度（现行级浅层）"是其表层性的修行学度量，与经典三轴共变。

**三候选在此框下各归其位**（作为"小"的特性角度、非待立假说）：

| 角度 | 解释了"小"的哪一面 |
|---|---|
| **双重假**（所缘是世俗建构无自性）| 为什么浅层看破即可——所缘是表层建构，破建构即停 |
| **常驻动机**（贪系维持机制 · 保全型覆悭诳 / 自熏型谄憍）| 贪系小随为什么虽浅却能长驻（靠自熏 / 保全赖着不走）；作用域限贪系、嗔系不套 |
| **两参数无剩余**（根本分 × 发作方式）| 为什么小随无独立深度——E 类无别体、可由根本分完全重构 |

### 4.5 据此预测中 / 大（待学到时提炼确认）

同一把"看破深度 / 离究竟"尺往下推：

```
小随  → 现行表层、浅层看破即停现行     → 离究竟远（事相级对治）
中随  → 不善心位的结构性标记            → 深一层（善心所对偶级对治）
大随  → 染心基底配置（微细、遍染心）    → 最深（基底配置级对治，主座A/念力/信力）
```

→ **小 / 中 / 大 = 染心由表及里的深浅层次**，看破深度 / 对治深度是贯穿三者的统一尺。"小"已提炼实，**中 / 大待学到时落实**（已挂 CLAUDE.md 当前阶段未处理内容）。

### 4.6 本法元记录——重定向本身的纪律意义

本组收官把"候选 → 升格判定"的叙事，校正为"提炼经典设定的不同角度"。这是"**经典 > 假说**"纪律的又一次落地：**整理的价值在帮助理解经典为何如此设定，不在另立一套与经典并行的结构**。

## §五 主线 3 · 见自

### 5.1 法贪在场、憍结构性不现行

| 项 | 现量结论 |
|---|---|
| **法贪** | 在场、俱生（贪"精巧见地"本身）|
| **憍** | **结构性不现行**——按"于自盛事深生染著醉傲、傲逸陶醉"判，那个**醉傲陶醉感不存在** |
| **机制** | **[假说 18](../../假说/假说-18-对象转换元假说.md)（对象转换）贪系侧印证**：修行者关注**见地本身（境侧）**、不关注"**我有**这个见地"（自侧）→ 见地从不被"盛事化"为"我的盛事"→ 憍的"醉傲于我有"无从发动 |

### 5.2 法贪 ≠ 憍 的分界现量化

法贪缘**境侧**（贪见地本身、想挖更多）/ 憍需把对象转到**自侧**（贪"我有此盛事"+ 醉傲）。修行者有前者、无后者——证明法贪**不自动升级为憍**，中间隔着一个"盛事化 + 醉傲"的对象转换，而修行者稳定地不做这步。

### 5.3 憍不现行比 L4 慢更彻底

二者都被假说 18 的对象转换门控，但深度不同：

- **L4 慢评判型仍在场**（"我评判一下是否已 X"）：评判动作本身**自带一个最低限度的"评判主体我"**，难全撤，故仍 明灭闪动（详见 [慢.md §五](../烦恼心所/慢.md)）；
- **憍要再多走一步**（把"我有"盛事化 + 主动醉傲陶醉），这步**可以完全不发生**——所以憍是干脆缺席、不是 明灭闪动。

→ 慢侧留一个"评判主体"的尾巴，贪系侧（憍）连尾巴都没有。（**第三层**：此不对称是据二者所缘 / 操作差异的推论。）

### 5.4 小随见自全景——仅忿现行

到憍为止，**小随 10 法在修行者位置上仅忿（亲子场脉冲）现行，其余 9 法（恨恼覆嫉悭诳谄害憍）结构性不现行**。这反向印证真战场在**俱生法染色层**（法贪 + 末那附着 + L4 慢），**不在小随事相级**——小随这一整组对修行者而言是"认得机制、归档不占主修带宽"。

## §六 主线 4 · 见众生

### 6.1 命门在维持机制、不在起因——三重自封闭

分析憍"难破、长驻不走"的命门，要看**维持机制、不看起因**（修行者的方法论纠偏）。起因侧（盛实有执 / 末那我所 / 痴）解释憍**为何起**；让憍**长驻**的命门 = 它自身的**三重自封闭结构**：

| 命门 | 机制 | 为什么导致长驻 |
|---|---|---|
| **① 陶醉于自盛本身 → 对外无冲突 → 结构性不生苦受** | 憍纯向自境陶醉，不像嗔推拒损他、不像悭吝啬摩擦 | 没有苦受 = **没有纠错报警信号**。嗔生苦显（灼烧）会自我惊动；憍连苦受都很少生成，宿主毫无警报 |
| **② "醉"本身禁用警省** | 醉的本义就是失警觉——需被察觉的状态恰是禁用察觉的状态 | 自封闭在**侦测层** |
| **③ 自熏自反馈** | 醉傲即回熏自盛贪种（§3.3）| 自封闭在**种子层**，越熏越厚 |

→ 这三条正是"**染依为业**"的深层机理从见众生侧的揭示：一个**不报警（无苦）+ 自麻醉（醉禁警省）+ 自续命（自熏）**的安静烦恼，才会长驻不走地当地基，让别的杂染在它上面生长。吵闹的烦恼（嗔）会烧完自灭；安静自封闭的憍不灭、且当温床。

### 6.2 钥匙——表层破"盛"无自性

慢（我胜他）/ 憍（自盛）/ 嫉（他胜我）三朝向旧框"同收破实我中心一把钥匙"，经修行者校正**要拆深度**：

| 法 | 所缘 | 钥匙 | 深度 |
|---|---|---|---|
| 嫉 | 排名 | 破排名无自性 | **表层（破世俗建构）**|
| 悭 | "我的" | 破所有权无自性 | **表层** |
| **憍** | **"盛"** | **破"盛"无自性（圈层相对建构）** | **表层** |
| [慢](../烦恼心所/慢.md) | 举我向位置 | 破"我"作高举主体 = 破实我中心 | **深层** |

→ 两件事修正：① 嫉 / 悭 / 憍（+ 覆诳谄）**是同一把钥匙的不同应用面**——那把钥匙是「**破世俗建构无自性**」，**不是**「破实我中心」（所缘换：盛 / 我的 / 排名，动作同）；② **慢要拆出去**——慢直接以"我"为操作对象（举我），其钥匙才是真的"破实我中心"（深层）。它们**连通**（建构无自性究竟也 ← 我痴），但对治看破在**不同层**。

### 6.3 见自见众合流

憍的见众生认知路径钥匙 = **帮凡夫看破"盛"无自性（圈层相对建构）**，**不需要先帮他破实我中心**——表层即可的干预（与"小随事相级"一致、利他门槛低）。而修行者的见自出口（不盛事化、关注境本身）**正是这同一把表层钥匙**。见自见众合流于「**破"盛"建构无自性**」这个表层动作。这是利他善巧轴第三层（理解烦恼内在机制）在"自盛醉傲"格的认知路径填补。

## §七 结构关联

### 7.1 双重假复证——贪系世俗脚手架

憍 = 体上贪一分无别体 ✓ + 所缘上世俗概念假立——"盛"= **圈层相对的建构正价**（想读作盛则盛、不读则只是中性自物）✓。与[嫉](./嫉.md)"排名"、[诳](./诳.md)"德相"、[悭](./悭.md)"我的"同族，是双重假所缘侧的**当代强样本**（现代圈层化使建构相对性裸露）。挂载体差异：无病 / 少壮 / 色力挂物理载体，族姓 / 富贵 / 多闻偏纯建构，但"以之为盛而醉傲"这层读取一律假立。

### 7.2 常驻动机——贪系自熏型

憍**适用**常驻动机（贪系结构）：动力（贪自盛）+ 失则损（盛事失则憍失）+ 行——但**不保全**（醉傲不守护盛事），而是**自熏续命**。故憍是常驻动机的**自熏型最纯样本**（与谄熏种循环变体同类、无中介）。印证常驻动机作用域限贪系（嗔系害不套，见 [害.md §7.2](./害.md)）。

### 7.3 小随 10 法收官全景（三系）

| 系 | 法 | 所缘侧形态 | 常驻动机 | 钥匙深度 | 收于 |
|---|---|---|---|---|---|
| 嗔系 5 | 忿恨恼嫉害 | 俱生我执颠倒（脚手架近无）| 不适用（事件 / 工具性）| 表层（现行级）| 无嗔 · 悲愍通治 |
| 贪系 2 | 悭憍 | 世俗概念脚手架（我的 / 盛）| 适用（保全 / 自熏）| 表层（现行级）| 无贪 |
| 贪痴一分 3 | 覆诳谄 | 世俗 / 纯认知建构（罪 / 德相 / 网住）| 适用（保全 / 自熏）| 表层（现行级）| 无贪 + 无痴 |

→ **离究竟轴收束**：早期"小随依脚手架厚→离究竟远"度量被害打破、已弃；正确度量是**看破深度（现行级浅层）= 离究竟远**，覆盖全体小随（含害），即经典"小随事相级对治"（[骨架 §2.5](./随烦恼整体认知.md)）的看破深度读法。

### 第二层（框架整理 / 应用映射）

- **"盛" = 圈层相对的建构正价**（古典价值共识 → 现代圈层相对建构，使"盛"建构性裸露）
- **两参数无剩余正向确认**（贪 × 自盛醉傲；傲≠慢举我 / 醉之昏=痴共同底不专写）
- **染依为业三后继摆位**（放逸最直接失闸 / 掉举自体最近 / 散乱经贪扩张下游）
- **看破深度（现行级）= 离究竟远近**；"小 = 染心最表层事相级"；**三候选 = "小"之指代的角度**；小 / 中 / 大 = 染心深浅层次
- **见众生命门三重自封闭 = 染依为业的深层机理**
- **钥匙拆深度**（建构类小随表层破建构 / 慢深层破我中心，二者连通不同层）

### 第三层（自主推论）

- **稀缺 / 区隔归慢侧、非憍结构要件**（据憍 / 慢体性差异分判）

- **自熏贪种正反馈 = 憍当常驻温床的机理**

- **中 / 大指代的预测**（待学到时确认）
