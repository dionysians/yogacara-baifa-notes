# 失念——念被偷走：别境染位切片与细所缘关口

> **类别**: 心所法 > 随烦恼心所 > 大随烦恼（第六法）
> **梵文**: muṣitasmṛtitā——muṣita 出自动词词根 muṣ（偷、劫），字面义"**念被偷走**"：不是念被删除、被毁坏，是被劫走——而偷的现象学特征恰是发生时不自知、事后清点才发现丢了〔词源第一层，现象学解读第二层〕。
> **经典定义**:《[成唯识论](../../../resources/cards/《成唯识论》.md)》卷六：「云何失念？于诸所缘，不能明记为性。能障正念，散乱所依为业。谓失念者，心散乱故。」
> **本体**: **B 俱一分摄首法**——念一分 + 痴一分（[护法](../../../resources/cards/护法.md)正义）。非别有体、非复合分位，是大随八第三种本体来源。
> **修行者位**: **大随第二主修区（培育型）**——坐中细所缘失念关口在本法正式立案（2026-07-06 精修）。

## 一、定义四维与"明记"拆解

### 1.1 四维

| 维度 | 内容 |
|---|---|
| **所缘** | 诸所缘（当下正缘之境——正念应明记而持守之处）。《大乘五蕴论》作「染污念，于**诸善法**不能明记」——两文合观：不能明记的是**该持守的所缘**（禅修所缘、教诫、决意、戒） |
| **体性** | **不能明记**——念的体性「于曾习境令心明记不忘」的失落 |
| **业用** | 能障正念 + **散乱所依**（先失明记、心才流散——失念是散乱的地基） |
| **本体** | 俱一分摄 = 念一分 + 痴一分（详 §二） |

### 1.2 "明记"三字拆解〔第一层〕

念的定义（《成唯识论》卷五）：「云何为念？于曾习境，令心**明记不忘**为性，**定依**为业。谓**数忆持**曾所受境，令不忘失，能引定故。」

- **记 = 忆持 / 执持**：当下把所缘持在心上、令其对心保持现前。「数忆持」之"数"（频频）显示念是**逐刹那反复持住**的动作——如手握物，不是储存写入。念管"现在持着"，不管"以后调得出"。
- **明 = 分明现前、不昧**：所持之境对心清楚、鲜活；反面是昧（模糊、名存实亡地挂着）。
- **忘 / 失 = 脱手**：「不忘」之忘不是"多年后想不起"，是**当下从手里滑掉**。失念之"失"正是此失。

### 1.3 失念 ≠ 忘事——两种"忘"切分〔第二层·依定义整理〕

| | 检索失败型"忘" | 失念 |
|---|---|---|
| 现象 | 想不起旧名字、学过的内容调不出 | 正持着 / 该现起的所缘**当下脱手** |
| 机制 | 念的种子 / 串习弱（库存不足） | 念的现行被劫或未起（持的中断） |
| 时态 | 过去储存 → 现在调不出 | **当下**进行时 |
| 性质 | 本身无记（功能不足） | 染（染念 + 痴分，遍染心） |

想不起名字不是失念现行，那是念力种子层的弱；失念永远是当下的事——手上有东西，然后没了（或该上手的没上手）。

### 1.4 与正念的完整镜像——业用逐位取反〔第一层，两处皆《成唯识论》明文〕

```
念  ：明记不忘为性 → 【定】依为业    （明记相续 → 心一境性有地基）
失念：不能明记为性 → 【散乱】所依为业（明记断裂 → 流荡有隙）
```

定不另起炉灶，是**明记持续到不动**；所以对偶双方连业用都逐位取反。「散乱**所依**」与放逸「增恶损善**所依**」同款语法：失念不是流荡本身，是使流荡可能的地基——《成唯识论》自注一句收尽：「谓失念者，心散乱故。」

### 1.5 与相邻法辨异

| 对比 | 区别 |
|---|---|
| **失念 vs [惛沉](./惛沉.md)** | 惛沉损"**明**"的质地（灯变暗——心体钝重、渐进钝化）；失念断"**记**"的持续（**灯亮手松**——心可仍明利，所缘突然断）。修行者 6/25 现量精判"松端守门是失念非惛沉"与此同构 |
| **失念 vs 散乱** | 失念 = 当下明记力失（锚脱手）；散乱 = 心转趣异缘（流荡）。行相上失念为散乱所依 |
| **失念 vs [放逸](./放逸.md)** | 放逸 = 守护配置总闸；失念 = 明记单项失守（总闸下游的具体防线） |
| **失念 vs 眠** | 眠 = 心趣昧略、令身不自在（不定心所，**心体状态**改变）；失念 = **持境关系**断（心体可不变）。细所缘处二者交界（§5.3 精判） |

## 二、本体——俱一分摄：三家立场与 B 型谱系

### 2.1 三家立场〔第一层〕

《成唯识论》卷六：「有义：失念，**念一分摄**，说是烦恼相应念故。有义：失念，**痴一分摄**，《瑜伽》说此是痴分故，**痴令念失**，故名失念。有义：失念，**俱一分摄**，由前二文**影略**说故，论复说此**遍染心**故。」

| 家 | 主张 | 文证 | 思路 |
|---|---|---|---|
| 第一家 | 念一分摄 | 《[杂集论](../../../resources/cards/《大乘阿毗达磨杂集论》.md)》「诸烦恼相应念为体」 | 失念就是**染污念**——念与烦恼相应时持境功能被染坏 |
| 第二家 | 痴一分摄 | 《[瑜伽师地论](../../../resources/cards/《瑜伽师地论》.md)》判失念为痴分 | 不是念坏了，是**痴把念挤掉**——「痴令念失」 |
| 第三家（护法正义） | **俱一分摄** | 合观前二文 + 「遍染心」文 | 念一分 + 痴一分俱，合名一个失念 |

护法论证两层：

1. **影略说**（会通文证）：两处论文各举一边、互相省略，合观得全貌——《杂集》说念分时略痴分、《瑜伽》说痴分时略念分，非两家相违。
2. **遍染心故**（实质论证）：

```
念唯缘曾习境（定义所限）
→ 缘非曾习境的染心里，念根本不生起
→ 若失念唯是"念一分"，则那些染心中无失念
→ 违「失念遍一切染心」（大随八身份）
→ 必须痴分补遍（痴遍一切染心）
```

反问若唯痴分，何以立名"失念"、不并入痴？——因缘曾习境的染心中确有**染念现前而于善所缘不能明记**的突出行相，名从行相显处立。两边各取所是。

### 2.2 "一分" = 外延切片〔第二层·结构整理〕

俱一分摄落到逐刹那：

- **缘曾习境的染心**：染念现行（念分）+ 痴（遍染底色）→ 失念 = 两分俱在；
- **缘非曾习境的染心**：念不起，**唯痴分单撑** → 失念仍在场（"不能明记"以"根本没在持"的形态成立）。

"分"字在大随谱系里两义须辨：放逸的"**分位**" = 功能合名（依多法合力配置立一总名）；失念的"**一分**" = **外延切片**（念通三性，从全域切出"与烦恼相应"那一片，加痴一片补遍）。

### 2.3 本体谱系三型完整化〔第二层·谱系整理〕

| 型 | 法 | 结构 | 立体 / 不立体理由 |
|---|---|---|---|
| **A 别有体** | [掉举](./掉举.md)、[惛沉](./惛沉.md)、[不信](./不信.md)、[懈怠](./懈怠.md)、散乱（预告） | 独立自体 | 推究有**剩余行相**（遍染心 + 独立业用，贪分痴分不能尽） |
| **D 复合分位** | [放逸](./放逸.md) | 四法合力配置的总名 | 特性真、体假——可由所依完全重构无剩余 |
| **B 俱一分摄** | **失念**、不正知（预告） | 别境法的染位切片 + 痴分补遍 | 名有必要（行相突出 + 障道岗位明确）、体不必立（两分即尽） |

**B 与 D 的三条区别**：

1. **所依性质**：D 的四所依全是染法（懈怠 + 三毒）；B 是**一正一遍**——主名成分（念）是通三性的别境法，只取其染相应位。
2. **得名方式**：放逸之名不借自任何成分；失念之名**直接借自被染的那个法**——"失·念"，名字本身写着它是谁的染位。
3. **对偶几何**：见 §4.1。

**判型的真判准——行相可否重构为该别境法的染位**（非"对偶对象是谁"）：染念仍是"明记"行相（只是被劫向染境——记仇者明记极好）→ 失念**切片切得出来** → B 型；染定仍是"住一境"行相（缘怨敌一心不乱是染定），散乱的"流荡" = 不住，**是定的缺位反面、不是定的染污位**——从定身上切不出"不住"这一片 → 推究有剩余 → 散乱别有体（届时护法两刀第五次输出"是"）。

### 2.4 俱舍对照——立名不立体〔第一层体系事实 + 第二层叙事〕

《[俱舍论](../../../resources/cards/《俱舍论》.md)》心所表**没有失念这一法**——[大烦恼地法](../../../resources/cards/大烦恼地法.md)六（痴逸怠不信惛掉）不含它：有部体系里念是大地法遍一切心，染心中之念即染污念，**不需另立名字**。第一家"念一分摄"正是有部式思路入唯识。

唯识的处理是**立名而不立体**：名的必要性来自道次第（"障正念"这个岗位必须有专名点出，否则大随八的遍染守护地图缺一格），体的节俭来自推究（两分即尽、无剩余）。与放逸合观，两法从相反方向证成同一元命题——**立名与立体是两件事**：放逸是"有部立了体、唯识拆掉"，失念是"有部连名都不立、唯识立名但拒绝立体"。

## 三、痴的构成作用——"持的动作没起来"为什么归痴

> 本节由修行者提问驱动："空缺型（唯痴分）说'持的动作没起来'——为什么缺席归属痴分？这是痴的什么特性导致的？"

### 3.1 染法不能以纯无为体〔第一层立场〕

问题暗含的预设是"缺席需要一个导致缺席的原因"。经典立场更强：**失念作为染法，不能以纯无为体**——大随八是现行法、有实在业用（散乱所依），纯粹的"念不在场"是无体之无，无体之法当不了任何东西的所依。所以"不能明记"必须由一个**正面在场的法**来构成。俱一分摄的实义：有染念时，染念 + 痴构成它；无念时，**唯痴构成它**。痴不是替缺席记账——**痴是构成者**。

### 3.2 「迷闇为性」的两重作用：覆境 + 覆失〔第一层定义 + 第二层拆解〕

《成唯识论》：「云何为痴？于诸理事**迷闇**为性。能障无痴，**一切杂染所依**为业。」迷闇在失念处的作用两重：

**㈠ 覆境——明记无抓手**。闇的作用方式独特：它不搬走物、**只取消物之现**（灯灭物隐——物未失，现失）。明记的"明"要求境分明现起；痴在场时，念纵有种子也无从起用，因为**没有可持之相**。"持的动作没起来"不是念被压住，是念生起所需的缘（境分明现前）被痴掐掉了一支。

**㈡ 覆失——把瞬间的失变成持续的窗**。痴同时把"没在持"这件事本身藏起来。若无痴，失锚一刹那即自知，正知立刻补位，空档不可能有宽度。「痴令念失」的"令"字着力点在此：**不是痴发动了失，是痴维持了失**。

### 3.3 冲动型 / 遮蔽型——缺失型行相唯遮蔽型能构成〔第二层整理〕

烦恼按作用方式分两型：**冲动型**（贪嗔——给心加矢量、推心去持什么抓什么）与**遮蔽型**（痴——不加内容、只做减法、减掉明）。"空缺"是纯减法行相，冲动型结构上给不出——贪嗔在场时心恰恰**满格持着**什么。由此失念两形态的配方严格分工：

```
劫持型 = 贪嗔（征用者）+ 染念（被征用的持境力）+ 痴（无报警）
空缺型 = 痴（覆境 + 覆失），别无他物——痴的底裸露在外
```

再推一步：大随八所有"缺失面"都由痴供体——放逸四所依恒含痴、不正知痴分、惛沉痴家族、空缺型失念唯痴。**遮蔽型烦恼是一切缺失型染法的通用构成材料**——放逸精修见它作配置底，此处见它裸露成相。

### 3.4 痴场内不可观测——只能边缘测量〔第二层〕

痴的在场方式就是观测者的不在场，"在场即不知"是其定义性结构。所以痴只能**从边缘测量**：入口的相、出口的相、窗的宽度。这在最深处证成 §5.6 的"培育型非识破型"：识破线在空缺型失念处不是效率低，是**逻辑上无处着力——那一段根本没有观测者**。

**上座部对照**〔第二层〕：南传安般传承把此现象描述为**堕入[有分](../../../resources/cards/有分.md)**（bhavaṅga）——息转细后念力接不住，心落回无业处所缘的空白流，特征恰是：无内容、无梦、出场突然、**常被误认为定或证得**；教法上的纠正与修行者的味定痴型校正一字不差——那是不知，不是所得。唯识无有分位概念，对应表述 = 意识落入极暗昧分位而阿赖耶识恒流不断。

## 四、对偶与网络

### 4.1 B 型对偶几何——同一个体的两个相应位〔第二层〕

大随八三种对偶几何：A 型 = **两个别体相障**（惛沉↔轻安、不信↔信、懈怠↔精进）；D 型 = **假立↔假立四对四反占**（放逸↔不放逸）；B 型 = **同一别境法的两个相应位**——同一个别境[念](../别境心所/念.md)，与善法俱起时是正念、与烦恼相应（加痴）时是失念之念分。对偶不跨两个体，在"相应"层内部翻转。这也是失念的对偶方不在善十一的原因：它不是另一个法，是**同一个法的另一位**（骨架 §4.2 基底配置 10↔10 对偶表中唯二挂到别境侧者，另一个是不正知↔慧）。

### 4.2 五随网络第三节点——机制依存链非时序链〔第二层·延续放逸读法〕

```
放逸（配置层：守护总闸撤）→ 失念（所缘层：锚点脱手）→ 散乱（现行层：流荡显相）
```

**这不是时序事件链**——大随八全部遍染心，每个染心刹那三者俱在场。链描述的是**机制依存**：守护撤了，锚才无人守；锚脱手了，流荡才无阻；流荡是最外层显相。三法是同一刹那染心的三个深度切面。（全网络分判待散乱、不正知学后完成——见 CLAUDE.md 回填清单。）

### 4.3 定障沉浮两线的共同汇点〔第二层〕

掉举（震嚣摇锚）与惛沉（明分暗化）从浮沉两个方向逼近同一终点——所缘失守。**失念是定障沉浮两线的共同汇点**：沉线是灯暗到照不住，浮线是震到握不住，汇点都是"手上没了"。

### 4.4 修定五过失八断行——失念的独立席位〔第一层·《辨中边论》〕

《[辨中边论](../../../resources/cards/《辨中边论》.md)·辨修对治品》立[修定五过失、配八断行](../../../resources/cards/修定五过失与八断行.md)：

| # | 过失 | 位置 | 断行（对治） |
|---|---|---|---|
| ① | 懈怠 | 加行前（不欲上座） | 信、欲、勤、轻安（四合一） |
| ② | **忘圣言**（忘失教授所缘 = **失念**） | 正修时 | **念** |
| ③ | 惛沉掉举 | 等持中 | 正知（侦察哨） |
| ④ | 不作行（沉掉起而不对治） | 沉掉现前时 | 思 |
| ⑤ | 作行（已平复仍施功） | 安住后 | 舍 |

三层意义：

1. **失念与沉掉分席**——经典自己把"丢所缘"（②）与"沉浮"（③）列为两个过失、配两个断行。修行者 6/25 现量精判"松端守门是失念非惛沉"与千年前的过失表**结构同构**。
2. **念是失念的专职断行**——对治不假外求：染位问题由本法善位修复，与 B 型本体（失念 = 念的染位切片）完全咬合。且②的断行是**培育型**（念）、③的才是侦察型（正知）——经典自己判定②格是能力问题不是侦察问题（§5.6 用此证）。
3. **五过失表是一张修定时间线**（座前 → 正修 → 等持 → 对治操作），天然是自查网格（§5.1 用此查）。

### 4.5 两条障道线〔第二层观察〕

两个 B 型法分掌两条障道线：**失念 → 散乱障定线**（念的染位断定资粮）/ **不正知 → 毁犯所依障戒线**（慧的染位断律仪守护，根门失察则毁犯有隙）。别境念、慧的两个染位切片，恰好各卡定、戒一门。

## 五、见自——细所缘失念关口正式立案（大随第二主修区·培育型）

### 5.1 五过失自查盘面与②格判读

### 5.4 关口的经典对接——安般业处的固有天花板〔回填条②理论侧〕

**念定义侧**〔第二层·从定义直接推出〕：明记以"境现"为食——念缘曾习境而持之，**所缘越微细，明记的负荷越高**。数息的"数"是给细境挂的粗把手（数字是粗曾习境），随息撤掉把手、直接持细境。所以颗粒度假说（日常粗所缘碰不到底板、唯坐中降所缘能暴露并训练念力底板）不是外加解释，是从念的定义直接长出来的。

**传统文本侧**〔第一层·《[清净道论](../../../resources/cards/《清净道论》.md)》安般章，大意转述〕：觉音明言此业处随修习深入，出入息**转细乃至似不现起**；教诫行者不应因所缘不现而起座，**当于原触处（鼻端）系念以待其复现**；且称安般念业处修习艰难、非念慧羸弱者所能成办。三个要点：

1. **传统自己把"细处难持"标为安般的固有关口**——配了标准教授，不是个人缺陷；
2. 教授方向正是守细（触处待复、不弃座）；
3. 关口由此获得去我化重述：**不是"我定不行"，是恰好一直卡在这个业处最难的标准关口上——它有名有姓有解法**。

### 5.5 移交点——定的所缘本来就在意识〔第一层〕

修行者问："鼻端触点这个位置不是可感对象，难道要将定的所缘放进意识而不是身识吗？"答：**定的所缘从来就在意识，从第一座开始就是**。

1. **归谬**：深定位前五识不现行（定中心识名目即"定中独头意识"）——若定所缘必依身识，定越深所缘越不可能，与事实恰反。
2. **经典正面立义**：《[解深密经](../../../resources/cards/《解深密经》.md)·分别瑜伽品》——慈氏问三摩地所行影像与心异不异，佛答「当言无异。……我说**识所缘，唯识所现故**」。奢摩他缘无分别**影像**、毗钵舍那缘有分别**影像**——定的所缘在定义上就是心所现的影像。此前守息的实际结构：身识逐刹那供料（触的性境材料），**真正持所缘、令明记相续的一直是五俱意识**——身识随境起灭、无自主相续，守不了任何东西。
3. **上座部把移交线写成道次第**：遍作相（粗息触）→ 取相（心中忆持的触相）→ **似相**（纯意识现起的净相）——**安止定的正所缘就是[似相](../../../resources/cards/禅相.md)，一个纯意识对象**。安般设计本来就是把所缘从身识粗触逐步移交给意识细相。
4. **关口 = 移交点**：身识供料降到觉察阈下、意识自持力未立——两轨之间的空档即是空档。

**"守触处"不是想象——两种意识作意分辨**〔第二层·操作分辨〕：

| | 内容性构画（该避免） | 位置性开放作意（教授本义） |
|---|---|---|
| 动作 | 在心里**画出**"息的样子"、造一个触感 | 把觉照**安放在那片区域**，开放地等 |
| 结构 | 播放内容（闭环、独影构画） | 天线指向（待缘、等真信号） |
| 结果 | 自我供给的假所缘，可自欺 | 真细触一现即被捕获 |

两个支撑：息实未断（《清净道论》教行者自审：死者、入灭定者、四禅者无息，我非彼等——**息实在而细，唯慧未利故不现**〔大意〕）；那片区域本身有微弱身识背景在场（温度、皮肤常触），"位置"不是凭空坐标。似相的传统教诫也是不可故意构画、功夫到自现——对"想象"的警惕是防造作修的正确本能，保留它，别让它拦住合法的位置性作意。唯识究竟一句收底：触尘亦识变——"身识所缘比意识所缘更实在"的预设本就不成立，粗细有别、实虚无别。

### 5.6 培育型非识破型——三证与两关结构

**失念确认为大随第二主修区，但性质与懈怠分开标**：懈怠是染现行主修区，失念是**功能底板训练区**。三证：

1. **经典断行分配**：八断行给忘圣言配**念**（培育型），给沉掉才配正知（侦察型）——经典自己判定这格是能力问题非侦察问题；
2. **两关现量都"无贼可破"**：座前贼看得清而识破不解决（缺点火）；坐中根本无贼、只有空档（无可识破——§3.4 场内无观测者）——最强的识破线在两个主修区双双无效，是结构使然非巧合；
3. **对治收束于主座 A 自身**：守细 + 熏念力，不另立通道。

**场域判定**：失念不开第三烦恼场域。座前归场域 B（懈怠场）；坐中细所缘关口**在主座 A 内部**——是主座 A 的**纵深前沿**（深度轴，非场域轴）。两个真主修区呈两关结构：

> **懈怠守上座关，失念守入细关**——同一定工程的前门与深门；两关断行全在表侧（信欲勤安 / 念培育）。遮强表弱至此有第三条独立路径：动力层（懈怠）、配置层（放逸）、**机能层（失念）**〔第三层候选·修行者自我诊断·不入假说表，并入专题[《修道点火与遮强表弱》](../../修行学/修道点火与遮强表弱——懈怠根诊断与欲钩双线.md) §3.1〕。

### 5.7 守细善巧修订——从事件响应到预装配置〔2026-07-06 更正 6/25 手法·回填条③理论侧〕

**失效归因**：6/25 安装的"数→随"是**事件响应型**操作（察觉息变细→切换手法），但现量是"每次都有，用不上，**到那个点就进空档**"——逼近段不可感、没有操作窗口，响应型对治遇上无窗口的关口结构上必然失效。（同时"每次都有" = 每座稳定抵达关口 = 粗所缘段功夫够、瓶颈单点集中——单点瓶颈比弥散问题好修。）

**修订 = 预装配置三件套**（不等信号、先装好）：

1. **锚的重定位**：从"息相"改锚到**触处**——于触处作**位置性开放作意：安放、等待、不构画**（§5.5 分辨表）。息可隐，位置不隐。
2. **前置地标**：操作点从"阈"（不可感）移到**预告牌**（可感）——"数变得毫不费力 / 息明显转柔"出现时轻提一分明利、重申一次锚——上坡前换挡，不等失速。
3. **座前决意预装**：临场想不起是必然的（想起靠念，而念正是要失的那个）——把教授做成**座前决意**（"息转细时，我守触处、不追息、不起座"），每座重复、熏成自动配置。正是看破→熏种→常态路径的应用：闻思 = 看破已完成，剩下是熏。

**单一现量检验 = 入口可感化**：进空档前有没有出现过哪怕一刹那"息细了 / 要丢了"的知（真实细触闪现是同一读数）——从零到偶尔出现，即底板在长。空档场内无观测者，唯边缘可测进步；**坠窗不是训练，接住才是**——接杆次数 = 有效训练量。

### 5.8 念持境、定稳台、慧照破——三轮模型与等高线〔修行者现量综合·修正版〕

**等高线**〔修行者综合·第二层〕：失念不是固定的敌人，是**念力等高线的边缘现象**——等高线内明记自持、线外痴覆现前，失念永远发生在线上；训练 = 等高线外推。这一句同时收拢颗粒度假说（等高线内外）、关口（线历来停在细息处）、命题③机制（§7.3）、凡夫全景（凡夫等高线贴着零）。失念因此是**测量仪**："每次都有" = 每座准点抵达训练区。

**三轮修正**〔第二层〕：念的明与慧的明是两个明——念的明 = **明记**（持境分明，在场能力）；慧的明 = **简择照见**（抉择实相，洞穿能力）。念力外推的是明记域，全在"养明"线内；**破无明是"断暗根"线的事，作业者是慧**（现观无我的无分别智）。归谬：若正念强度自身能穿透痴覆，外道四禅八定念定俱极强、应破无明——而经说非想非非想仍轮回，**定与念是共世间法，慧观才是不共**。

> **念持境、定稳台、慧照破**——念的强度决定能把多细的境端上台面，定的稳度决定台面撑得住多久的照，慧的力决定照下去见不见得到无我。

"照到[末那](../../../resources/cards/末那.md)那一刻"是慧现观的**质变点**（加行位四寻思逼近、真见道根本智现前，转依次第"六七因中转"），不是念力渐进的顶点——渐进的是脚手架（念定等高线外推 + 慧的比量熏习），质变的是现观。等高线推得再远，慧不在台上作业，得到的只是更深的世间定。

**伏断分层**〔第一层教理〕：正念**伏**现行（在场排挤染心刹那——意识层）/ 慧**断**种子；"穿透 / 破"两个词留给慧。**目的层**：念定增长是**当前主修的核心工作**，服务于**[止观双运](../../../resources/cards/止观双运.md)破无明的核心目的**——对修行者二者暂时重合，因短板恰在念定（议题①慧定不匹配：慧已先行、定念在追）。

## 六、见众生——全程基底缺位

凡夫失念不是事件，是**默认态**。严格说凡夫常态是"未曾持"而非"持而失"——**空缺型的全程版**：正念从未上岗，谈不上失去。（此读法为骨架 §6.4 修行者自主所立："失念并不是一个特定的阶段，正是因为路径全程失念，最终才滑入恶见"——本法精修核验成立。）

- **被动聚焦**：凡夫的"专注"靠境的强度拉（强刺激、危机、娱乐），不是念力持——境强则聚、境弱则散。当代注意力经济正是向这个结构收租：平台竞争的就是"谁的境更强"〔第二层映射〕。
- **利他认知路径一填**：凡夫"道理转头就忘、修行记不住"不是不诚心，是**念力底板从未被训练** + 失念自障觉照（失时不知失，凡夫连事后追认的框架都没有）——结构必然，非品行问题。帮的入口 = **补念之缘**：外部提醒结构（日课、钟板、念珠、共修节律 = 传统早就造好的**外置念力假肢**，借境的强度补念的弱），不框"你要用心记住"。与懈怠"补缘非鞭策"、放逸"补配置非断染"同款语法。（修行者确认身边有此类样本，未展开。）
- **见自见众合流于同一根轴**：凡夫连粗境都要境强拉着，修行者粗境自持已稳、卡在细境——**同一条念力轴上的两个刻度**（直接喂给 §7.3 元命题③）。

## 七、"大"三尺与元命题③

### 7.1 三尺齐证〔按经典 + 见众生位 + 见自位〕

a. **看破难度深**——失时不知失、场内无观测者，看破只能在边缘（痴覆失的结构性遮蔽）✓；b. **对治时间长**——念力底板是纯熏习工程、经年累月（修行者定天花板历来即此）✓；c. **定力配合强**——对治本身就是修定核心工序（八断行之念），念定互为增上 ✓。= **基底配置级 ✓**。

### 7.2 证据类型：执行层基底

失念障的是正念，而**正念是一切对治的执行者**——其他烦恼障某个善法，失念障"守护任何善法的能力"：对治系统整体离线。三个纯形态分层不重复：不信污染**资粮侧**（心净基底质地）、放逸撤**配置侧**（守护总闸）、**失念断执行侧**（明记锚点——配置了也执行不了）。

且失念是**现量位证据第二例**（懈怠后），性质不同：懈怠是染现行现量、失念是**功能缺口现量**——"每次都有"，它是大随八中修行者**现量撞击频率最高**的一法。

### 7.3 元命题③——定义级样本、结构解释、末那地板

候选元命题③：大随八基底化程度与念力稳态成反比。失念是它的**定义级样本**——其他七法与念力的关系是间接的，失念与念力的关系是恒等的：**失念就是念力之失**。反比逐域成立：粗所缘域念力稳 → 失念该域降级（生活场排除 ✓）；细所缘域念力未及 → 该域全活（每座都有 ✓）；凡夫全域未训练 → 全程基底 ✓——同一人内按域滑动、人际间按训练度滑动。

**防膨胀标注**：命题③对失念是**分析真**（定义使然），不算经验证据、不投票。它的真贡献是**结构解释候选**〔第三层·不入假说表〕：

> 为什么八法整体与念力反比？因为染心的边界特征就是"正念不在场"（染心中可有染念、无正念）。念力稳态升高 = 染心刹那占比收缩 = **一切遍染法（大随八全体）现行域同步收缩**。命题③不是八条独立的相关性，是**一个机制的八个投影**——失念是投影角为零的那一个（与机制重合），所以看起来"最直接"。

**边界条件 = 末那地板**〔第一层：《成唯识论》末那相应心所十八——五遍行 + 四惑 + **八大随** + 别境慧〕：八大随与末那**恒行相应**——不论第六识正念多稳，末那层大随八照转不误（有覆无记、无始恒行、与[恒行不共无明](../../../resources/cards/恒行不共无明.md)俱、非第六识正念所及）。所以命题③的精确形状是〔第二层〕：**反比成立域 = 意识层现行；末那层是凡夫位常数项**——等高线外推收缩的是意识层染域，收缩到极限剩下的就是末那地板，唯见道转依起递减。这正回环三轮模型："真正破无明须照到末那"——正念推不动的那一块，恰是必须由慧现观去动的那一块。
