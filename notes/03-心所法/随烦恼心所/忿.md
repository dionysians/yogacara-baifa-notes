## 一、经典概念（闻）

### 定义原文

[《成唯识论》](../../../resources/cards/《成唯识论》.md)卷六：

> 云何为忿？依对**现前不饶益境**，**愤发**为性。能障**不忿**，**执杖**为业。谓怀忿者，多发暴恶身表业故。此即**瞋恚一分**为体，离瞋无别忿相用故。

（"执杖"亦作"执仗"，乃至举手动杖之粗显身业。梵语 krodha。）

### 体性拆解

| 项 | 内容 |
|---|---|
| **所缘** | 现前不饶益境——"现前"是关键简别：当前正对的违损境，非回忆 / 想象的过去境 |
| **体性** | 愤发——心所层的发动向外 |
| **业用** | 执杖：多发暴恶身表业（"多发"= 常发，**非必发**）|
| **所障** | 不忿（无瞋善根在"不愤发"上的分位）|
| **本体** | 瞋恚一分，离瞋无别相用 → **E 分位假立** |

### 判准精确化（本次精修订正 · 第二层）

精修讨论澄清了忿的判准只钉两条——**现前境 + 愤发**——并订正三处常见误读：

1. **强度、时长不入判准**：愤发只描述"发动"的行相，不要求高强度或短时。只要现前不饶益境还在、心仍在向外发作，持续数小时也仍是忿（同一现前境上忿的相续 / 反复现行），**不因时间长就转成恨**。"短时"是现前境多半短暂带来的常态相，非判准。
2. **体是心所、外显是业用**：忿的体是"愤发"这个心所；执杖 / 暴恶身表业是它的业用，且经典作"**多**发"（常发非必发）。忿可现行而外显被压住——那时忿仍现行，只是业用未流出。故判准落在"心是否对现前境愤发"，不在"外面是否看得见动作"。
3. **嗔系槽位唯一**：在嗔系五小随里，"对**现前境直接发作**的不满"这个槽位唯忿独占（详见 §二）。

## 二、与相邻法的辨异（嗔系五小随同属瞋一分）

忿、恨、恼、嫉、害五小随皆"瞋一分为体"。忿与最易混的恨、恼，分界**都不靠外显**，而在所缘相位 + 行相 + 质地：

| 法 | 所缘 | 体性（行相）| 动 / 静 | 独有质地 | 业用 |
|---|---|---|---|---|---|
| **[嗔](../烦恼心所/嗔.md)**（根本）| 通现前 / 非现前、通缓急 | 憎恚 | — | — | 不安隐 / 恶行所依 |
| **忿** | 现前违境 | 愤发·**发出** | 明火爆燃 | — | 执杖（身业）|
| **[恨](./恨.md)** | 境过·过去违境 | 怀恶不舍·结怨·**收结不放** | 埋炭闷烧 | **不舍**（黏着）| 内热恼 |
| **[恼](./恼.md)** | 追忆触动的旧忿恨 | 追触暴热·**狠戾**·再发 | 死灰复燃 | **狠戾**（凶毒）| 蛆螫（毒言）|

→ 两条硬分界（第一层经典体性）：

- **恨与恼不靠外显**：恨是"咽不下、结成疙瘩、收起来闷烧"的**静态储存相**；恼是把旧怨**追触出来、重新点火**的**动态再发相**。
- **狠戾是恼独有**：恼比恨多出忿、恨都没有的**狠戾**（凶狠暴戾）。恨只是"放不下"，恼是"放不下 + 翻出来 + 变得凶毒"。

[害](./害.md)（损恼有情、无悲愍）可冷可算计，未必带愤发，与忿不在同一相位。

## 三、主线 1：分位机制 + 嗔系生起次第起点

### 3.1 一股瞋换相位，不是三颗种子（第一层 + 第二层）

忿恨恼"离瞋无别相用"——种子层只有**一股瞋种**，忿 / 恨 / 恼是它现行的三个相位（现前发作 / 过去怀结 / 追触暴热狠戾）。每次现行又**等流熏厚瞋种**（参[五果](../../../resources/cards/五果.md)·等流果）。

→ 故"忿熏成恨"**不是**忿种生出恨种，而是**同一股瞋的现行从"现前发作"相位滑入"过去怀结"相位，沿途把瞋种熏厚**。

### 3.2 忿是"现前违境链"的起点，但不是全嗔系的起点（第二层）

经典明文：恨"**由忿为先**"、恼"**忿恨为先**"。故：

```
境违 → 忿（现前发作）→ 恨（境过怀怨）→ 恼（追触暴热）
```

忿不起，恨恼即失先导——这条链的釜底抽薪点在忿。**但须收紧**：这只是"忿恨恼"这条**现前违境反应链**。[嫉](./嫉.md)（起于他荣境）、[害](./害.md)（起于损恼境 / 无悲愍）经典**无**"由忿为先"明文、各有独立起境，**不在此链下游**。所以"忿是嗔系起点"应限定为"**忿恨恼三法链**的起点"。

### 3.3 截断点定位——忿是"已发作"的较晚点（第二层 · 接子阶段 1 嗔操作核）

把忿放回完整缘起链，它坐落靠后：

```
触 → 受(苦) → 爱憎(憎) → 我所强加(层4) → 忿(显粗发作 = 层3a)
              ↑              ↑              ↑
          受→爱憎识破     层4看穿       已发作
          (上游)         (釜底抽薪)    (热态局部辅助)
```

→ **忿 ≈ 子阶段 1 [嗔操作核](../../教学操作核/教学操作核-02-嗔事件层.md)里"层 3a 反应式嗔的显发点"**。真正的截断主轨在它**上游**（受→爱憎 / 层 4 强加）；到忿这步已发作，截断忿只是热态局部辅助。与嗔操作核修法序"层 4 看穿优先 → 层 3a 直接触发识破辅助"严格吻合。

## 四、见自维度（修行者位置现量分诊）

### 4.1 截断点上移——本次精修的跃迁信号

修行者现量报告了一处跃迁，对照旧态 / 新态：

| | 旧态 | 新态（闻思识破后）|
|---|---|---|
| 截断点 | **忿之后**（忿必然出现 → 惭愧快速终止）| **上移到"我所强加"阶段**（很多时候善心所在此升起 → 忿不现行）|
| 前端 | "无法操作"——俱生种子直接现行到忿 | 已能在 受→爱憎→我所强加 段切入 |
| 俱生快道兜底 | — | 受→忿几乎直发时，**自省中能发现"我所强加"的现行过程** |

→ 这是嗔操作核修法序"层 4 看穿优先 → 釜底抽薪解构 A 类"的现量落地，是**真跃迁非想通**（忿从"必然出现"降到"不现行"，命中"反应强度下降 = 下沉种子层"判准）；也是"看破→熏种→常态"三步循环在嗔系跑通一轮。

### 4.2 截断点的心所构成——感应器先起 + 愧惭时序双点

**（一）识破在闻思、惭愧在事件**（现量订正模型的"事件层先识破"框定）：

```
闻思阶段：识破（建立见 / 发现机制）—— 不在事件里，是预载
   ↓（熏种）
事件中：惭愧"感觉不对头"（先起）→ 无痴 / 慧"分辨哪里出问题"（随后）
```

→ 确认[假说 10](../../假说/假说-10-惭愧触发感应器.md)：惭愧作"事件触发感应器"，先于分析性的慧起，是前概念的"不对头"快信号；慧是随后的**分辨**，不是触发。"看穿"必然落在闻思阶段（当场识破来不及），事件里跑的是被熏成常态的任运响应。

**（二）愧在前、惭在后——[假说 12](../../假说/假说-12-惭愧末那二维辐射.md) 精化为嗔链"时序双点"**：

| 链位 | 阶段 | 善心所 | 假说 12 对治轴 | 能力状态 |
|---|---|---|---|---|
| **上游（忿前）** | 我所**强加 / 对外扩张** | **愧** | 外向扩张"我所"（不强加）| 新跃迁（闻思识破后熏成）|
| **下游（忿后）** | 开始**累计我所** | **惭** | 内向凝聚"我" | 旧有能力 |

→ 扩张（外向强加动作，愧截）在前；累计 / 凝聚（向内沉淀成"我"的受损立场，惭截）在后。我所在"扩张"时尚未累计，故那一点惭不生效。这轮跃迁的实质 = **愧被熏到能在"扩张"上游点任运起**，把忿截在现行之前；惭（忿后累计点）作下游兜底。

### 4.3 嗔系链在修行者位置双重断裂

```
现前违境
  ├─[很多时候] 愧上游任运起 → 忿不现行          ← 上游断（4.1 跃迁）
  └─[仍经常]  忿现行 → 对外即止 → 不入恨
                        → 自省"发现-分析-解决-放弃"四步循环 → 放下   ← 下游断
恨 / 恼：不现行（不记得体验，唯见众生）
```

→ 忿现行后这股势力不走"怀恶不舍（恨）"，而向内转成自省对治。"发现-分析-解决-放弃"四步循环即[修行者画像 §45-58](../../实修/修行者画像.md) 已记的基态正念成熟操作核——本次揭示其适用面**从弥散"莫名烦躁"场扩到"忿后粗显场"**。

### 4.4 层 5 自责式嗔结清

修行者自陈："做错了立正，该认错认错，该罚认罚，然后想清楚下次别犯，自责没意义。"

→ **层 5 自责式嗔：结构性不现行**（嗔系多层表"待观察"→ 结清）。认错（惭"本来不应如此"）+ 认罚（愧"敬共业秩序"）+ 想清楚（慧 + 精进），**全程无自责**——正是惭愧 ≠ 自责式嗔的分界（惭愧是断恶感应器、不是自我攻击），再印证惭愧**究竟层运作**。

### 4.5 场域归属 + 法染色层降级

- **场域 A（触受激活场）**：忿 = 现前不饶益境 = 外缘激活 → 严格归场域 A，由主座 A 三重统一 + 现量识破覆盖。
- **法染色层降级验证**：忿在修行者位置是"事件层遮蔽"（现前境起、即止），不构成基底配置——印证骨架 §六主线 1 的"大随八降级"假说在小随侧也成立。

## 五、见众生维度

### 5.1 经典为何特标"多发暴恶身表业"

忿是二十随烦恼里**从心到身口路径最短**的一个：现前境一触，瞬间外显成拍案、动手、暴言、执杖。它是**最粗显、最看得见**的随烦恼，故列小随之首、作整条嗔系链的可见入口。

### 5.2 凡夫的忿 = 修行者那条断裂链的"完整默认版"

```
凡夫：现前违境 → 忿（直发）→ 沉淀成恨 → 追触成恼 → 乃至害
   缺三道修行者已有的防线：① 无愧上游截断  ② 无"自省四步"  ③ 无看破见（不知是俱生种子直发）
```

→ 见众生要点：所见"别人在忿"是一条链的头部——对他而言大概率会沉淀成恨、升级成恼，而他没有受训过的刹车。他不是"坏"，是**被现前境 + 俱生种子直推、又缺对治**。

### 5.3 触发点 2 最深层 = 修行者嗔系最大问题（现量自陈）

修行者现量揭示其嗔系**最大问题**：

> 对"就应该这么做"而别人没这么做，发生嗔。"不理解别人为什么这么想这么做、这都想不通么"——**不是评判（对人下判词），是我所强到"别的活法不可解"，那个"不可解"本身在强化我所**（我的标准 = 唯一标准）→ 别人不符 → 嗔。

→ 字字命中嗔操作核**触发点 2 最深层**："对他人因缘流的'应该如何'标准投射"。这是 CLAUDE.md 该条的现量印证（修行者主动确认）。

### 5.4 悲悯理解开始——利他善巧轴通道 2 早期活化

修行者现量报告："当前我能开始理解别人的现行状态的原因，也能开始有悲悯理解的念头了。"

→ **见自 / 见众生是同一跃迁的两面**：

| 侧 | 现量 | 机制 |
|---|---|---|
| 见自（§4.1）| 愧在"我所强加"阶段任运起 → 忿不现行 | 愧 = 停止向他人扩张我所 |
| 见众生（本节）| 开始理解他人现行原因 → 悲悯理解念头起 | 我所强加一松 → 看见他的因缘 → 悲生 |

→ **愧（不强加）是负向清场，悲悯理解是正向涌现，同一动作两头**：停止"应该如何"的强加，遮在他人因缘上的我所滤镜撤去，**无嗔之悲 + 无痴见他因缘**才有空间起来。这是[利他善巧轴缺口](../../实修/修行者画像.md)（诊断性知人强 + 缺悲悯理解）通过"见众生线（通道 2）"开始填补的**早期信号**（"开始"= 未稳，待后续看是否任运先起）。

## 七、学术诚实三层标注

**第一层（经典）**：忿定义原文（愤发 / 现前不饶益境 / 执杖 / 不忿 / 瞋一分）；恨"由忿为先"、恼"忿恨为先"明文；嫉 / 害无"由忿为先"明文且各有独立起境；忿恨恼"瞋一分为体、离瞋无别相用"；等流果（五果）。

**第二层（框架应用映射）**：忿判准精确化（强度 / 时长不入判准、体 / 用之分、嗔系槽位唯一）；忿恨恼三相整理（明火 / 埋炭 / 死灰）；"现前违境链 / 嫉害另起"结构读；忿 = 层 3a 显发点的缘起链定位；愧惭时序双点（假说 12 精化）；见自见众同一跃迁两面。

**第三层（自主推论）**：截断点上移作"真跃迁非想通"的判定；"看破在闻思 / 常态在事件"的时序论断；悲悯理解开始作利他善巧轴通道 2 早期活化——均属修行者位置的现量分诊产出，状态为"与唯识框架内在一致的现量报告"，悲悯理解一条标"早期信号 · 待验证稳态"。
