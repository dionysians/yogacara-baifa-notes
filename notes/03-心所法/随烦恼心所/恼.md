## 一、经典概念（闻）

### 定义原文

[《成唯识论》](../../../resources/cards/《成唯识论》.md)卷六：

> 云何为恼？**忿恨为先**，**追触暴热**，**狠戾**为性。能障**不恼**、**蛆螫**为业。谓**追往恶、触现违缘**，心便狠戾，多发嚣暴凶鄙麤言，蛆螫他故。此亦瞋恚一分为体，离瞋无别恼相用故。

[窥基](../../../resources/cards/窥基.md)《百法明门论解》：恼者，嗔之一分，忿恨已后，追触暴热，狠戾为性。（梵语 pradāśa。）

### 体性拆解

| 项 | 内容 | 恼的独有处 |
|---|---|---|
| **所缘** | **双重叠加**：追**往恶**（已结之怨 = 恨的储存）+ 触**现违缘**（当下新违境）| 唯一一个"过去 + 现在"两时所缘叠加点燃的小随 |
| **体性** | **狠戾**（很戾）= 凶狠乖戾、带毒带刻 | 比忿的"暴热"多一层**毒性 / 戾气**——不只是热，是热里带狠 |
| **业用** | **蛆螫**（如毒虫蜇咬）= 多发嚣暴凶鄙麤言、刺伤他人 | 落在**口业暴戾**；忿是「执仗」（身业、抓杖），恼是「蛆螫」（口业、阴毒缠刺）|
| **所障** | 障**不恼**——障"旧怨不被追触勾起、心不暴戾"的安稳态 | — |
| **本体** | 瞋一分（离瞋无别相用）→ **E 分位假立** | 与忿恨同股瞋种；**无内部体性诤议**（覆有安慧 / 护法之争，恼无）|

### 三个"恼独有"的锚点

1. **双所缘叠加（追往恶 + 触现违缘）**：忿所缘单（现前境）、恨所缘单（过去怨），恼所缘**双爪并立**——一爪扒着**已结之怨**（恨的储存），一爪触着现前新违缘。「忿恨为先」是**硬前提**：没有恨结的怨这根过去爪，现前境再强也只生忿、生不出恼。

2. **狠戾的毒性（质变非强度）**：「戾」= 乖戾、不讲理、扭曲，是忿没有的新质。忿的热可带"我有理"的鲜怒；恼的狠戾是**已结之怨在库存里发酵**后的阴毒——是质变出的另一种东西（毒），不是同一种东西（火）烧得更旺。**恼 ≠ 强忿**（§3.1 详辨）。

3. **回到嗔系的"干净" + 修行者位置结构性不现行**：覆是首个跨出嗔系、首个有内部体性诤议的小随；恼**没有诤议**，落回纯瞋一分的平地。恼在修行者位置上**结构性不现行**（因恨不现行 → 无往恶可追，§4.1）——这一法的产出主要在**辨异（恼 ≠ 强忿）+ 见众生**，不在见自现行。

## 二、与相邻法的辨异——一股瞋三换相位之**第三相（暴发点）**

恼与忿恨"离瞋无别相用"——种子层只有**一股瞋种**（[忿 §3.1](./忿.md)），忿 / 恨 / 恼是它现行的三个相位，每次现行又等流熏厚瞋种（[五果·等流果](../../../resources/cards/五果.md)）：

```
境违 → 忿（现前发作）→ 恨（境过怀怨储存）→ 恼（追触暴热狠戾）
        现前 · 热          过去 · 冷储存         过去+现前 · 毒发
```

| 法 | 时相 | 温度 | 签名动作 |
|---|---|---|---|
| **忿** | 现前违境 | 热（鲜怒）| 当下暴发，多发暴恶身表业（执仗 / 拳脚）|
| **恨** | 境过怀怨 | 冷（储存）| 怀怨不舍，结于内不发 |
| **恼** | 追往 + 触现 | **毒（热里带狠）** | **蛆螫**——嚣暴凶鄙麤言刺人（口业）|

- **恼 / 忿**：都"发作"，但忿是**无旧怨的鲜怒**、恼是**翻旧怨的毒发**；忿多身表业（执仗）、恼多**口业**（凶鄙粗言）。**恨是恼的燃料库，恼是恨的出口**——没有恨的库存，现前境只生忿不生恼。
- **恼 / 恨**：恨是**储存态**（结于内、冷、不发）、恼是**点燃态**（恨的库存被现前境追触引爆）。
- **恼 / [害](./害.md)**：害也在嗔系，但起于**损恼境 / 无悲愍**、各有独立起境（不在"忿恨恼"现前违境链下游，[忿 §3.2](./忿.md)）；恼偏**口业暴戾**，害偏**损恼有情的意乐**（可身可意，根在不悲愍）。

## 三、主线 1：体性机制（恼 ≠ 强忿 + 恨为先双爪 + 狠戾从恨怨发酵）

### 3.1 恼 ≠ 强忿——唯识按"行相"分立、不按"强度"分立（双刃）

一个自然的归约假说：恼是不是就是"累计出更高强度的忿"？经典顶回来的关键事实——**唯识从不用强度分立心所**（贪有强弱、强弱皆贪，不另立一法；慢分七慢九慢靠所缘行相不同、非强度）。规则是：**同行相、强度不同 → 同一法（只是更猛）；行相不同 → 才另立**。

经典给恼的是**三处行相差异**，非强度：

| | **忿** | **恼** |
|---|---|---|
| **所缘** | 现前不饶益境——**单爪** | 追往恶 + 触现违缘——**双爪叠加** |
| **体性** | 愤发（热）| 狠戾（毒 / 戾，质变出的新质）|
| **业用** | 执仗（身业、冲动）| 蛆螫（口业、阴毒缠刺）|

**这把刀是双刃的**（本次精修要害）：

- **一个很强的忿，依然是忿**——强度不是判据。现前境直发的强烈愤发，哪怕烈度很高，只要无"追往恶（恨怨）"、无狠戾毒，就**不升格成恼**（见 §4.2 修行者亲子场实例）。
- **恼也不是"强忿"**——它需要**恨为先（已结之怨可追）+ 狠戾（毒）+ 蛆螫（口业刺人）**，这是行相级的另立，不是把忿调强。

### 3.2 恼的双爪——现前违缘 + 追往恶（**追往恶严格 = 恨结怨之追忆**）

恼的「追往恶」**不是"凡是想起过去的错"**，经典里它和狠戾、蛆螫**锁成一条机制**：「追往恶、触现违缘，**心便狠戾**，多发嚣暴凶鄙麤言，蛆螫他故」——**追往恶 = 追忆那个已结之怨、把怨重新烧成毒**，功能是给狠戾供燃料。故恼的两根爪：

```
现前爪：触现违缘（当下新违境）         ← 与忿共用
往恶爪：追往恶 = 追忆已结之怨（恨储存）  ← 恼独有，严格依赖恨
```

→ **没有恨结的怨，就没有往恶可追，就够不成恼。** 这条把恼牢牢锁在"忿恨为先"上。

**要与"忿的强度源"分清**（本次精修订正一处膨胀）：现前境直发的忿，其**强度**可由瞋种厚度（俱生 / 等流熏厚 / 见解嗔分位）顶高——但这是**忿为什么强**，**不是恼的往恶爪**。往恶爪只认**恨结怨之追忆**（追怨生毒）；瞋种厚度是**现前直发、不经追忆、不出毒**。把"瞋种厚度 / 类化看不惯"误装进"恼的往恶爪"，是把忿的强度源错当成恨——经典不容此混（详见 §4 修行者现量校正）。

### 3.3 狠戾从哪来——恨怨在库存里发酵成毒

恼的「追触暴热」「狠戾」之**毒**，来自**已结之怨在恨的储存里反复发酵**（恨"怀恶不舍"、业用"热恼"即此发酵），被现前境一追触即引爆成狠戾毒言。**怨发酵得越久、越毒**——这是恼比忿"多一层戾"的来源：忿是当下鲜怒（无发酵），恼是陈怨毒发。

### 3.4 双爪对治——忿对治 + 恨对治，戾毒不需第三味药

恼 = 忿（现前爪）+ 恨（往恶爪）的结构结合，对治即**两爪全断**：

| 法 | 对治的那一爪 |
|---|---|
| 忿 | **现前爪**——对违境不生嗔（上游 受→爱憎→我所强加 识破）|
| 恨 | **往恶爪**——放下贪 / 我执那部分（所爱不舍），怨随之松、不再发酵 |
| **恼** | **两爪全断** |

**关键**：恼的签名"狠戾（毒）"是恨怨发酵 + 现前触发的**果**、不是独立的根——**两个进料口一断（现前不再受触 + 恨怨清空），毒没有发酵原料，自己就熄**。不需单独对治"毒"。这也再证恼是结构叠加非强度标量。

## 四、见自维度（修行者位置现量分诊）

### 4.1 恼结构性不现行——恨不现行则无往恶可追（预判成立）

恼需「忿恨为先」+「追往恶」，往恶 = 恨结怨之追忆。而修行者**恨结构性不现行**（[恨 §4.4](./恨.md)：归因改道双锚抽掉可怨对象、无结怨、无热恼）——**无怨可结 → 无往恶可追 → 经典上够不成恼**。骨架"恼结构性不现行"的预判**成立**。嗔系链三相在修行者位置：**忿（现行，见 §4.2 亲子场强忿）/ 恨（不现行）/ 恼（不现行）**。

### 4.2 亲子场重判——曾误判为恼、现量校正为**强忿**

修行者亲子场对孩子覆藏的"**不假思索翻脸、严厉训斥**"，精修中一度判为恼；经经典判别 + 两点现量校正，**坐实为强忿、非恼**：

| 经典判别 | 恼需 | 修行者现量 | 判 |
|---|---|---|---|
| 体性 / 业用 | 狠戾 + 蛆螫（刺伤毒）| **愤发**——凶、大声、纠正性，**明确无刺伤意**（"希望严厉让他认识到这是不对的"）| 无狠戾 → **非恼** |
| 往恶爪 | 追往恶（恨结怨之追忆）| 会**翻旧账**（屡犯则想起前事），但现量**无恨累积**——"只是让我感到这件事的严重性" | 翻的是**严重性证据**、非怨 → **非恼** |

→ **第 2 点独立判死恼**（狠戾是恼的体，无狠戾即不成恼）；**第 1 点的"翻旧账"亦不能救恼**——经典"追往恶"是追怨生毒，修行者翻旧账是**追忆屡犯以评估严重性**，喂给的是"覆该禁"的判断权重、产物是更强的愤发，**全程不结怨、不出毒**。"只是感到严重性，不是恨累积"正是经典"追往恶（追怨）"与"追往（评估严重）"的分界。

### 4.3 强忿的强度源 = 见解嗔"覆该禁" + 屡犯严重性评估；惭愧为何不亮 + 对治

```
见解嗔"覆该禁"我所强加（根深蒂固）── 厚
        +
翻旧账（屡犯 → 评估"此事严重"）── 加权重
        ‖
     忿的强度源（都不是恨、都不是恼）
        ↓
现前境（这次又覆）→ 强忿（愤发、纠正性、无狠戾毒）
```

- **强度源 = 见解嗔（[触发点 2 我所强加](../../教学操作核/教学操作核-02-嗔事件层.md)"覆该禁"）**根深蒂固 + 翻旧账加严重性权重。二者皆非恨——[覆案 003](../../实修/logs/生活修日志/2026-06-亲子场孩子覆藏与我的见解嗔.md) 最初判的"见解嗔"**判对了**，是精修中途误升为恼、现已校回。
- **惭愧为何没亮**：见解嗔"覆该禁"**伪装成客观道德标准**（"覆就是坏的"），既不挂恨相（无热恼可认）、又不挂瞋相（像客观判断）→ 惭愧感应器（调来认烦恼相的）不被触发 = **没认识到**（不是来不及）。
- **"没认识到 ≠ 来不及"= 分别出身判定锁**：修行者订正——这条上根本没有正见可赶（"看不惯覆 = 强加"的认识从来不在），闻思一补即化解。由此立经典级出身锁——**[见道](../../../resources/cards/见道.md)断[分别起](../../../resources/cards/分别起.md)、[修道](../../../resources/cards/修道.md)断[俱生起](../../../resources/cards/俱生.md)**：闻思后仍现行 = 俱生；**闻思一拆即松 = 分别**。覆案"看通孩子三段皆缺后已能不发脾气"= 闻思拆得动 ⟹ "覆该禁"出身**分别**（道德习得的类化标准、非真俱生）。
- **对治（双爪耦合）**：**闻思**揭穿"看不惯覆 = 类化强加（非客观真理）"→ 减薄见解嗔这个**强度源** + 把"伪装成客观标准"还原为可见我执 → **实修**截断现前忿、熏到任运。闻思是给实修开路的一步。

> 注：此节虽列于"恼"的见自下，实质讲的是**强忿及其见解嗔强度源**（恼本身在修行者位置不现行）。保留于此，因它是"亲子场为何曾被误判为恼"的完整校正与对治。

## 五、见众生维度

### 5.1 嗔系链见众生封顶——恼 ← 恨 ← 贪，皆众生苦非"坏人"

凡夫真有恼（与修行者不同——凡夫恨现行、有怨可结可发酵）。一个翻旧怨、刻毒伤人的人，顺嗔系链往回看，根上是一个没放下的贪：

```
贪（所爱 / 我执粘着物没放下）
   ↓ 被夺 / 被犯
恨（怀怨不舍——底层其实是抱着那个爱，[恨 §5.1](./恨.md)）
   ↓ 怨在库存发酵成毒、现前境追触
恼（狠戾翻怨、蛆螫伤人）
```

→ "他坏"看到的是链末的毒；"他苦"看到的是链根的爱执。**这就是苦因，不是坏人。** 帮困在恼里的人，不是劝他"别那么刻毒"（表层无用），而是松动链根"对所爱的不舍"、指向无常无我。

### 5.2 越陷越深苦——利他善巧轴第三层最彻底一填

恼这一站"显得坏"和"实际苦"是**反着的**：恼的"戾"= **陈怨发酵到极毒**（怨抱得越久越死、发酵越透、毒越重）。**越是"刻毒伤人、看着就是个坏种"的人，恰恰贪执抱得越死、恨怨发酵越久、陷得越深**——让他在外面显得最"坏"的那个戾，正是他苦最深的签名。

→ 恼把利他善巧轴第三层（理解烦恼内在机制）填得**最彻底**：恨那站化解的是"他坏"的中度版（怀怨者），恼这站化解的是**最极端版**（刻毒伤人者）——连"看着最像坏人"的都能还原成"陷得最深的苦"，评判线彻底拆完。与 [恨 §4.3](./恨.md)"觉得人坏本身是恨恼染出来的判断"两头对上：**见自侧不生这个标签，见众生侧拆掉这个标签**，同一件事的两面。

> **第三层·自主推论**："越陷越深苦"是嗔系见众生的反向推论，与"恼之戾来自恨怨发酵"一致，非经典明文。

## 六、结构关联

- **E 分位假立（瞋一分）**：恼 = 一股瞋在"追触暴热狠戾"分位的假立名，无独立别体；回到嗔系纯瞋平地，无内部体性诤议（区别于覆的安慧 / 护法之争）。
- **一股瞋三换相位之第三相**：忿（现前发作）→ 恨（过去怀结）→ 恼（追触毒发），同股瞋种、相位不同，每现行熏厚瞋种（[五果·等流果](../../../resources/cards/五果.md)）。
- **生起次第**：骨架 §七 凡夫染心链"恨 → 覆 → **恼**（忿+恨+覆累积 → 追触暴热）→ 嫉"中的暴发点。
- **善心所接续**：恼 ↔ 无嗔（正面对偶）；双爪对治 = 忿对治（现前爪 · 无嗔）+ 恨对治（往恶爪 · 无贪松所爱），戾毒为果、断两源即熄。
- **恼 ≠ 强忿 的双刃 + 强忿辨异**：唯识按行相非强度分立——强忿仍是忿（修行者亲子场实例）/ 恼非强忿（需恨 + 狠戾）。修行者亲子场"严厉训斥"= 强忿（强度源 = 见解嗔"覆该禁" + 屡犯严重性评估），非恼；对治走 [嗔操作核触发点 2](../../教学操作核/教学操作核-02-嗔事件层.md) 我所强加 + "没认识到=分别"判定锁。
- **见自见众分流**：修行者侧恼不现行（恨无往恶）；见众生侧凡夫恼←恨←贪封顶，利他善巧轴第三层最彻底一填。

## 七、学术诚实三层标注

**第一层（经典）**：恼定义原文（忿恨为先 / 追触暴热 / 狠戾为性 / 不恼 / 蛆螫 / "追往恶、触现违缘，心便狠戾，多发嚣暴凶鄙麤言"）；忿 / 恨 / 恼三定义并排（忿唯现前·执仗 / 恨结怨·热恼 / 恼追往恶·狠戾·蛆螫）；恼瞋一分、忿恨为先（生起次第明文）；唯识按行相业用分立心所、非按强度（方法论事实）；见道断分别起、修道断俱生起（断惑次第经典）。

**第二层（框架应用映射）**：忿恨恼"现前 / 储存 / 毒发"三相位图（基于一股瞋换相位）；"恼 ≠ 强忿"三处行相差异表 + 双刃整理；"恼的往恶爪（恨结怨追忆）≠ 忿的强度源（瞋种厚度）"的辨异；狠戾 = 恨怨发酵成毒的机制说明；强忿强度源（见解嗔 + 严重性评估）的结构；"我执伪装成客观标准 → 惭愧不亮"的机制说明。

**第三层（自主推论）**：亲子场"严厉训斥"经经典判别 + 现量两点校正为**强忿（非恼）**、强度源 = 见解嗔"覆该禁" + 屡犯严重性评估；"翻旧账作严重性评估 ≠ 恼之追往恶（追怨生毒）"的分界；"没认识到 ≠ 来不及"= 分别出身判定锁（闻思可拆 ⟹ 分别）；"越陷越深苦"利他善巧轴第三层反向推论（§5.2）——均属修行者位置现量分诊产出，状态为"与唯识框架内在一致的现量报告"。
> **本法一处自我校正记录**：精修中途曾把亲子场强忿误判为恼、并以"类化 / 俱生装载"顶替缺位的恨——经"严格回经典 + 拒立膨胀"校正：恼的往恶爪经典上**只认恨结怨之追忆**，类化 / 俱生瞋种厚度属**忿的强度源**、非恼库存；修行者恨不现行 → 恼结构性不现行。此校正即"经典 > 假说"的现量演练。
