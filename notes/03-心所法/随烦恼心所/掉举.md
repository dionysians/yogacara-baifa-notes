## 引言

掉举是大随烦恼八法的第一法，也是大随中**派系诤议最大**的一法。本笔记是大随八层精修的开篇（2026-06-25）——小随（事相级·表层）、中随（不善心位结构标记·善心所对偶级）走完后，进入随烦恼最深的一层。

按 [骨架 §2.6 看破深度尺](./随烦恼整体认知.md)的预测，大随 = 染心**最深的一层 · 基底配置级**，对治上升到禅定 / 念力 / 信力的整体建设。掉举一法既要定夺别有体（与刚学完的[无惭无愧别有体诤议](./无惭无愧合论.md)同构），又是**法染色层主战场在大随层的精确显现点**，还起步累积"大"之指代——故铺得厚。

本笔记按五条主线展开：体性机制（举我）→ 见自（掉举罕现）→ 对治理解（功能-染色 / 后得智）→ 诤议定夺 → 见众生 + "大"起步。

## 一、定义与四维拆解

### 经典原文

> **《成唯识论》卷六**：「云何掉举？令心于境**不寂静**为性。能障**行舍、奢摩他**为业。」
>
> **窥基《百法明门论解》**：「掉举者，令心于境不寂静为性，是**贪分**所摄。」（注意：窥基此处取"贪一分摄"一系，与护法正义有张力——见 §五诤议）

**梵文**：auddhatya（音译"邬达底耶"）；词源 ud（上、高）+ √dhā（置）= **心高举不安**。"掉"不是掉落，是**心向上浮举、嚣动飞扬**——与惛沉的"向下沉钝"恰成上下两极。

### 四维拆解

| 维度 | 内容 |
|---|---|
| **所缘** | **不固定**——掉举不像小随有专属境（忿缘违境、嫉缘他荣）。"于境"泛指心当下所对的任何境；倾向性 = 常由**忆念昔日乐事**而起飞扬（"贪一分摄"一系的立论点）|
| **体性** | **令心于境不寂静**——心在所缘上**嚣动、浮举、不能安住**。是"于境不寂静"（心仍在境上但动荡），区别于散乱"流荡到别境"|
| **业用** | **障行舍、障奢摩他（止）**——双重障：① 障善心所"行舍"（平等正直无功用住）；② 障"奢摩他 / 止"（禅定寂止支）。是**五盖之一**（掉举恶作盖）|
| **正障** | **行舍**（A 对称对偶，骨架 §3.1）；功能上障 = **奢摩他 / 定** |

**体性的关键处**：掉举的体性词是"**不寂静**"。这个词后面成为诤议核心——"不寂静"听起来太像一切烦恼的共相，反对派由此说"掉举无别相、无别体"。护法守"别有体"必须回应这一刀（§五）。

## 二、体性机制：掉举的"举"从何来（主线 A）

### 2.1 "举我"是掉举的引力中心

经典讲到"飞扬依烦恼势力起"，但**没明说飞扬的引力源是什么**。以下是机制整理：

> **〔第三层·自主推论，现量未印证〕** 心要"飞扬"，必有一个**引力中心**把它往外牵。寂静的心（行舍 / 禅定扩散无我相态）没有引力中心、不飞扬。引力中心 = 末那"**举我**"——立一个"我"作攀缘重心，心于是对"与我相关 / 我所恋 / 我所关切"的境产生引力、向它扑 = 掉举。
>
> **现量状态说明**：此"举我 = 引力源"是结构推论，**修行者现量未能印证**——掉举现起时捕捉不到末那举我那一动（2026-06-25 章末检验）。这符合末那恒行、在第六识内省下本难现量捕捉的性质，但也因此**不能把"举我 = 引力源"抬成现量事实**，只记为待验证假说。

这套整理统一了三家诤议里"贪相显但通染心"的张力：

| 层 | 内容 |
|---|---|
| **引力源（底层）** | 末那"举我"——任何烦恼现行都把"我"举为中心，故掉举**通一切染心**（护法对） |
| **引力方向（表层）** | 具体烦恼给引力一个方向：贪 = 扑向忆乐境（最典型，故集论**偏说贪分**）/ 嗔 = 扑向违境 / 慢 = 扑向胜境 |

→ "贪相显"与"通染心"不矛盾：举我是共同引力源（通染心），忆乐是最显眼的引力方向（贪相显）。这一步为 §五护法定夺铺路。

### 2.2 慢 ↔ 掉举的不对称（L4 ⊃ 掉举）

> **〔第三层·§6.4 现量产出〕** 以举我为公因子，慢与掉举是举我的两种显现：

| | 显现域 | 状态 | 能否独立 |
|---|---|---|---|
| **L4 位置慢** | 末那层 | 举我的**静态位置感**（"我具有"暗位置感，撤一切对照仍在） | **能独立** |
| **掉举** | 第六识层 | 举我**牵动出的动态飞扬** | **不能独立**（必伴举我） |

→ **L4 位置慢 ⊃ 掉举**——层次差（末那 / 第六识）+ 依存关系（动态依静态），非严格同构。修行者现量确认"能分 L4 静态 / 掉举飞扬"，印证"不同层面、可独立"。

**修行学含义**：掉举对治与 L4 位置慢对治**共一命门**——都是松"举我"。[主座 A](../../教学操作核/教学操作核-04-轻安anchor.md) 既是 L4 扩散主轨，也自然是掉举主轨（§6.5 通道分工图：掉举 = L4 扩散主轨）。同源故一举两得。

### 2.3 三法辨异：掉举 / 散乱 / 惛沉

用"引力 + 明性"两参数看，三法边界清：

| 法 | 行相 | 引力 / 明性 | 五象限 | 调弦 |
|---|---|---|---|---|
| **掉举** | 浮举·原地嚣动飞扬（向上） | 引力中心强，但心在中心周围**剧烈振荡、停不到所缘** | A（↔ 行舍） | 太紧 / 太亢 → **松之** |
| **散乱** | 驰散·流转到别境（跑题） | 引力中心**被别境拉走、不稳** | C（↔ 定，别有体 + 业用反对） | 收摄令归所缘 |
| **惛沉** | 沉钝·昏沉下坠（向下） | **明性整体衰减** | A（↔ 轻安） | 太松 / 太钝 → **策之** |

- **掉举 vs 散乱**：动而不离境（风中火苗）vs 流而离境（水四溢）。
- **掉举 vs 惛沉**：禅修**调弦两端**——掉举太亢要松、惛沉太钝要策。下一法惛沉配套验证。

## 三、见自：掉举罕现，主战场是驱动力三态分诊（主线 B）

### 3.1 现量核心更正——掉举不是修行者闻思场的主现行

原命题（§6.2 / §6.6 揭示 3）："掉举 = 法染色层主战场在大随层的精确显现（法贪境激活 → 心举）"。修行者现量否决了"心举（掉举）"是主显现：

> **掉举（心于境不寂静飞扬）≠ 闻思场的主现行**。主现行是"**想搞明白的驱动力**"——这是一个**引力 / 方向（欲性）**，不是"不寂静飞扬"。专注钻研的驱动力可以相当寂静（近一境性），恰是掉举的反面。掉举只在驱动力**变得不寂静、停不下来反刍飞扬**时才现起，而此体验不多。

→ **现量修正**：法染色层主战场在闻思场的真正主显现是**法贪 / 欲驱动**（议题②"法贪伪装善法欲"），**不是掉举**；掉举在修行者位置是**罕现的潜在伴生**（驱动力飞扬化时才起）。印证候选假说"**大随八在修行者位置从基底配置降级为事件遮蔽**"（§6.1 不信已降级，掉举再加一例）。与 §6.6 揭示 3 自洽——经典侧掉举本是"法贪境激活的**伴生**现象"，现量只是进一步说这伴生很淡。

### 3.2 驱动力三态分诊（修行者自立现量操作·议题②法贪层精化）

修行者已成习惯：一起驱动力先辨析其目标，分三态——

> **〔第一层·经典〕** 欲（别境）**通三性**，故"驱动力"三态：
> - **精进驱动 = 善欲（善法欲）**——朝向善法 / 解脱的希求；
> - **纯粹好奇心 = 无记欲（无覆无记）**——希求缘境、不染不善、亦无解脱方向；
> - **法贪 = 染欲**——欲被贪染、于法尘抓取。

把"好奇"从"善学 / 恶贪"二元里独立切为**无记**，与"欲通三性"严格对上，是对议题②"善法欲 vs 法贪"二分的**三分精化**〔第二层〕。

**核心现量判准**（议题②法贪层从"识别"进到"对治"）：

> **观照贪心所是否现行、有无"抓取放不下"**——有则停。

这正命中贪的体性签名（"于境染著、不舍"），比原"追究封闭 / 过度挖掘"（行为相）更靠体性一层（直接看贪心所在不在）。**进展信号**：法贪现行时大多数能**定力支撑识破 + 及时中断**。

**边界两条**：
- **末那附着层仍在判准之外**：抓取核查 精确抓**法贪（对法尘的抓取）**层；议题②法染色层另有**末那附着（"我所立见"身份附着）**层，不以"抓取"显、以"这是**我**立的见"显——后者更隐（与举我捕捉不到一致），**仍待现量化**。
- **无记好奇的时间维度**：无记好奇过得了抓取核查（无染），但**不染 ≠ 对修行中性**——纯好奇仍吞噬精进 / 时间（接[议题③ AI 探索吞噬时间](../../实修/修行者画像.md)）。该不该停由"是否朝向善法 / 值不值得花这时间"决定——这是三分里要补的**第二把尺**（贪核查管法贪、方向核查管无记好奇）。

### 3.3 念力反比双因素 + 惛沉为主

修行者掉举低，是**双因素叠加**（非单一念力反比）：
- **低基线 / 低强度**——闻思驱动多是"专注钻研型"（近一境性、本就不飞扬）= "根本没起掉举"；
- **定力提升能收住**——念力稳态那一面 = "起了被念力收"。

→ 候选假说"大随八基底化程度与念力稳态成反比"得**部分印证**（念力助收掉举），但须加注：**掉举低不能全归念力，还有"现行模式本就专注 / 沉倾向"这个独立因素**。

**禅定中惛沉 > 掉举**——修行者现量确认"惛沉才是更需对治的、掉举很少"，正面坐实 §6.2：掉举属**场域 A（触受激活·浮）罕现**、**惛沉是场域 B（无所缘 / 双不足·沉）唯一仍基底化的法**。调弦两端定位：**修行者偏"太松 / 沉"端（需策举），不偏"太紧 / 浮"端**，与[双不足模式](../../实修/修行者画像.md)一致。**故下一法惛沉才是大随主修区，掉举此法在修行者位置 = 结构归位、现量罕现。**

## 四、对治的正确理解：功能-染色二分 → 后得智 + 中道（主线 C）

> 本节详细展开见专题 [默认模式网络与掉举-色法镜像与转依](./默认模式网络与掉举-色法镜像与转依.md)，此处留掉举侧落地骨架。

### 4.1 核心切分：对治的是"质地"不是"功能"

掉举 = 功能运转时的"不寂静飞扬"质地，**不是功能本身**。三样东西分开：

| | 内容 | 修行处理 |
|---|---|---|
| **认知功能** | 建模他人 / 自传记忆 / 未来规划 | **不删**——可带正念寂静地做 |
| **掉举（不寂静质地）** | 功能运转时的飞扬、亢进、反刍 | **对治**——松染色，功能照做而心寂静 |
| **我执着色** | 一切绕"维持我的存在 / 位置"而转 | **转依渐断** |

→ **〔第二层〕** 对治掉举 = 让功能"不再被我执驱动地亢进飞扬"，**不是删功能**。

### 4.2 掉举对治的"圣位终点"= 功能转后得智

> **〔第一层·经典〕[转识成智](../../../resources/cards/转识成智.md)**：末那不被消灭、**转成[平等性智](../../../resources/cards/平等性智.md)**……功能继续，转掉的是我执着色。**[后得智](../../../resources/cards/后得智.md)**：[根本智](../../../resources/cards/根本智.md)证空性后，后得智重回世间——理解众生、行方便、做规划利他，正是"建模他人 / 规划"功能的**净化圣位形态**。

→ **〔第三层·结构映射〕** 掉举给出纵深：凡夫位"功能 + 掉举 ↔ 功能 + 行舍"，圣位"染功能 ↔ 后得智"。**掉举 ↔ 行舍 = "染功能 ↔ 后得智"在凡夫位的缩影**，同一条线、凡圣两端。

### 4.3 中道贯穿身 / 心两层

> **〔第二层·框架整理〕** 中道是同一原则在两层显现：

| 层 | 两端 | 中道 |
|---|---|---|
| **色身层** | 苦行（太紧）↔ 纵欲（太松） | **不自苦不纵欲、依身修道**（〔第一层〕佛陀舍苦行、琴弦喻） |
| **定心层** | 掉举（太紧 / 浮）↔ 惛沉（太松 / 沉） | **调弦——掉则松之、沉则策之** |

→ "维护色身"不是修行的让步，是中道在身层的落实——与本项目 [假说 9 种子反向作用身体](../../假说/假说-09-种子反向作用身体.md)同向。这把掉举与惛沉锁进同一"调弦"框架。

### 4.4 破"消解我执 = 丧失生存功能"伪问题

> **〔第一层·经典〕存在性证明**：佛陀住世说法四十九年、阿罗汉托钵管僧团应对国王——已断 / 转我执，却社交、记忆、规划、利他样样运作且**更善巧**。生存功能 ≠ 我执；被消解的是我执额外加的那层**苦**（焦虑 / 反刍 / 患得患失），功能毫发无损。**凡夫渐断**——三大阿僧祇劫渐断，没有"功能被一刀删掉"的点，每薄一层功能更清明。

→ "完全消解带来生存问题"是伪问题：它把"消解我执着色"误读成"删除认知功能"。

**接议题⑤**：修行者担心丢失的"建模他人 / 规划"，其净化版 = 后得智 = 权智，正是 [议题⑤ 利他善巧轴缺口](../../实修/修行者画像.md)（"看节点 = 后得智、权智缺口 = 后得智缺口"）。**消解的是染、生长的是智，同一功能两种命运。** 现量印证：修行者现量确认"我执着色变薄时，看系统 / 理解他人 / 规划**更清明**"——功能-染色二分在自身的存在性证明，给后得智路径补了现量锚。

**延伸边界**：后得智 / 中道的完整修法属菩萨道次第（跨法），本节只做掉举侧落地，完整展开挂回填清单"加行位 / 后得智 / 五明"条。

## 五、别有体诤议的定夺（主线 D）

### 5.1 三家立场

| 家 | 立场 | 论据 |
|---|---|---|
| **集论 / 安慧传**（窥基《百法解》亦取） | **贪一分摄**——无别体、是贪分 | 掉举多由"忆昔乐事"生 → 于境飞扬，驱动力是贪 |
| **瑜伽传** | **俱一分摄**——一切烦恼的"不寂静"共相 | 任何烦恼现行心都不寂静，掉举即此遍染共相、无别相 |
| **护法**（本项目宗 → 骨架归 A 对称对偶） | **别有自体** ↔ 行舍 | 见 5.2 两刀 |

### 5.2 护法两刀

**第一刀·驳"贪一分摄"——通一切染心，贪分不能尽**

> 掉举不只贪起时有：嗔、痴、慢现行时心也飞扬嚣动。若体即贪分，无法解释嗔位、痴位的掉举。经典常"偏说贪分"是因贪相最显（忆乐飞扬最典型），不是因体是贪。

→ 正是 §2.1 机制的兑现：举我是共同引力源（通染心）、忆乐只是最显眼的引力方向（贪相显）。

**第二刀·驳"俱一分摄 / 共相无别体"——依他起 ≠ 无自体**

> 承认掉举依烦恼势力起（是等流），但"依他而起"不等于"无自体"。掉举有**独立业用**（专障行舍、奢摩他）+ **独立行相**（嚣动浮举，可与沉钝、流荡分别识别）→ 别有体。

### 5.3 与无惭无愧别有体诤议——同构 + 一处差别

**同构（招式相同）**：两法都用"**没有现成根本烦恼能覆盖它的外延**" + "**独立业用**"逼出别立。这是护法对治一切"还原论"的通用招式（无惭无愧那场见过一次，这是第二次）。

**一处差别（外延宽度不同）**：

| 法 | 外延论据 | 外延宽度 |
|---|---|---|
| 无惭无愧 | 遍一切**不善心**（贪嗔各偏、痴太宽都不能尽） | 不善心 |
| 掉举 | 遍一切**染心**（贪分不能尽） | 染心（= 不善 + 有覆无记，**更宽**） |

→ 修行者定夺：**同构 = 独立体性 + 外延宽度不同**。这预告 §六"大"之指代——**别有体的外延论据（遍染心）= 大随的判定轴**；中随"遍不善心"、大随"遍染心"宽度差一层，正是"中 → 大"深一层。

**忆乐飞扬一例的精度**：现量里其实**贪和掉举二法俱起**——贪（抓取那乐境）+ 掉举（心飞扬）各有体。护法不是说"这里没有贪"，而是"飞扬那一分不是贪、是别有体的掉举"；偏说贪分只因贪相显。修行者用 §3.2 自立的"抓取核查"切：**抓取那一分是贪、飞扬那一分是掉举**——现量工具与教理判准在同一把尺上收口。

## 六、见众生 + "大"之指代起步（主线 E）

### 6.1 见众生：凡夫掉举为何"遍染心"、时时不自知

> **〔第二 / 三层·见众生机制〕** 凡夫掉举是最普遍、最不被察觉的染心基底（刷手机停不下来、杂念纷飞、睡前思绪万千、掉举盖障定）。机制 = **末那举我恒行（默认模式网络自我枢纽恒转）+ 触受不断激活 → 心常向"我所关切"飞扬**，而凡夫**无念力收**，故飞扬常态化 = 基底配置。

→ **利他善巧轴第三层落点（认知路径）**：凡夫"停不下来 / 反刍 / 刷不停"**不是意志薄弱、是结构必然**（举我恒转 + 无定力收）。教学走认知路径理解机制，**不框"叫人专注 / 自律"**。这是大随见众生线第一笔。

### 6.2 见自见众对照 = "大"的基底性现量显形

| 线 | 掉举状态 | 揭示 |
|---|---|---|
| **见众生**（凡夫） | 遍染心、基底常在 | "大 = 基底配置级"在凡夫位的本相 |
| **见自**（修行者） | 降级为事件遮蔽、罕现（§三） | 念力 / 专注把基底配置降级 |

→ 两线对照显形候选假说"**大随八基底化程度与念力稳态成反比**"：大随的"基底配置"性 = 凡夫位常在基底，修行（念力）把它降级。掉举给这条假说添了第一个大随样本。

### 6.3 "大"之指代起步（预演·不落实）

承 §5.3 外延轴，**"大"有两个独立但共变的维度**（修行者 2026-06-25 自立）：

> **影响范围（宽 / 遍染心）** 与 **对治深度（深）** 是两条独立轴，但**共变**——因"**能在浅层处理就不会成为基底**"，凡宽到成基底者必然也深。但仍**分别对待**（宽→深是趋势、由基底性驱动，不是定义）。

**对治深度三把尺**（修行者操作化，量小 / 中 / 大三层级；非连续谱）：

| 对治深度尺 | 小随 | 中随 | 大随 |
|---|---|---|---|
| **a. 看破难度** | 浅（事相一看即破） | 中（须立惭愧换质地） | 深（基底、须禅定下沉才看破） |
| **b. 对治需要的时间** | 短（事件场即时识破） | 中（惭愧任运需熏） | 长（念力 / 信力整体建设、经年累月） |
| **c. 需要的定力配合强度** | 几乎不需（慧简择即可） | 中（须一定相续） | 强（须主座 A 强定力配合） |

三尺单调同向递增，坐实"三层级对治深度"。尺 c 接[慧定不匹配 / 主座 A](../../实修/修行者画像.md)（大随对治 = 主座 A 整体建设）、尺 b 接[看破→熏种→常态](../../../CLAUDE.md)（大随熏种周期最长）。

**目前"大"的指代证据**（待大随八法收官落实）：

| 维度 | "大"的内容（目前证据） | 来源 |
|---|---|---|
| 行相 | 微细（不寂静、无外显行为相） | 经典轴一 |
| 自类 | 互相俱起（染心背景配置） | 经典轴二 |
| 影响范围 | **遍一切染心**（比中随"遍不善心"宽一层） | 经典轴三 + §5.3 外延论据 |
| **对治深度（预测）** | **基底配置级——禅定 / 念力整体建设**（比中随对偶级再深一层） | 看破深度尺预测 |

→ 看破深度尺到目前连续：小（事相级·表层破建构）→ 中（对偶级·立惭愧换质地）→ 大（基底配置级·整体建设）。**掉举一法符合预测，但单法不足以落实"大"**——待惛沉 / 不信 …… 八法走完，用三把尺量八法是否齐证"基底配置级"，再回填骨架 §2.8（与"小"在憍收官、"中"在无惭无愧收官同节奏）。

- 掉举体性"令心于境不寂静"、业用"障行舍奢摩他"（《成唯识论》卷六）；五盖之掉举恶作盖

- 中道（佛陀舍苦行、琴弦喻）/ 依身修道
- 贪体性"于境染著不舍"

### 第二层（框架应用映射）
- **举我作引力中心、贪相显 vs 通染心二层** = 对经典"飞扬依烦恼起"的机制整理
- **驱动力三态分诊**（善欲 / 无记 / 法贪）= 议题②"善法欲 vs 法贪"二分的三分精化
- **功能-染色二分**（对治掉举 = 释放染色质地、非删功能）= 转依立场的应用表述
- **中道贯身 / 心两层** = 中道原则的整理性扩展
- **默认模式网络（DMN）↔ 掉举 / 散乱 / 举我色法镜像** = 浮尘根 / 色法镜像立场的应用（详见专题）

### 第三层（自主推论）
- **"举我 = 掉举引力源"** = 结构推论，**现量未印证**（末那层难捕捉），待验证假说
- **掉举对治终点 = 后得智（染功能 ↔ 后得智在凡夫位的缩影）** = 结构映射
- **大随八在修行者位置从基底配置降级为事件遮蔽** = 候选假说，掉举添第二样本（§6.1 不信首例）
- **大随八基底化程度与念力稳态成反比** = 候选假说，掉举见自见众对照添样本
- **"大"之指代 = 影响范围 + 对治深度两维（共变·分别对待）+ 三把尺** = 待大随收官落实
