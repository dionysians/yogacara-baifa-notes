# 不正知——监察失真：俱一分摄、毁犯两门与大随收官

> **经典定义**：[《成唯识论》](../../../resources/cards/《成唯识论》.md)卷六：“云何不正知？于所观境，谬解为性。能障正知，毁犯所依为业。谓不正知者，多所毁犯故。”
>
> **位置**：心所法 → 随烦恼心所 → 大随烦恼第八法
>
> **完成日期**：2026-07-17

---

## 一、定义四维与“谬解”两形态

| 维度 | 内容 |
|---|---|
| **所缘** | **所观境**——当下应被观察、审察、简择的境。[《杂集论》](../../../resources/cards/《大乘阿毗达磨杂集论》.md)以“起不正知身语心行”将第一现场落在身、语、意三业[现行](../../../resources/cards/现行.md) |
| **体性** | **谬解**——观察与简择失真。它不只是“不知道”，还包括“以为自己知道，但解得歪” |
| **业用** | 能障[正知](../../../resources/cards/正知.md)，并为毁犯提供认知条件。“所依”表示地基、空隙，不表示每一刹那不正知都必然立即成为一条具体毁犯 |
| **对偶** | 正知即[慧](../别境心所/慧.md)在如实监察岗位上的功用，百法不另立一个“正知心所” |

### 1.1 谬解型与无检型

护法将不正知定为慧一分与痴一分俱摄。从现象侧看，两分有两种突出形态：

| 形态 | 体性配方 | 行相 | 一句辨识 |
|---|---|---|---|
| **谬解型** | 慧分显著 + 痴分 | 积极形成错解，且带“就是如此”的真值感 | **看错了** |
| **无检型** | 痴分单撑，慧的简择未起 | 该分辨时没有分辨，以“没问题”的默认形式直接放过 | **没检查** |

修行者回照早年定中空档时，明确校正：当时未形成“修得好”的解，只是没有分辨能力，既不认为好，也不认为有问题。此例不是谬解型，而是**无检型的现量样本**。

### 1.2 痴在不正知中的两重作用

基于痴“迷闇为性”的经典定义，本项目作第二层拆解：

1. **覆真**：当前所缘不如实显现，解只能循染而构成；
2. **覆谬**：“解歪了”这件事本身也被藏起来，查证刹那不会自发起来。

无检型下，两重作用都由痴分单撑：检察岗位空着是它，空着而不觉得需要检查也是它。

## 二、正知原型——戒门与定门双岗位

### 2.1 正知而住

[《瑜伽师地论》](../../../resources/cards/《瑜伽师地论》.md)卷二十四以“正知而住”教授覆盖往来、顾视、屈伸、饮食、着衣、行住坐卧、语默等一切威仪。其核心不是记忆一张静态规则表，而是于当前所缘如实知道自己正在做什么，依当前因缘辨别应行、应止。

### 2.2 两个岗位

| 岗位 | 经典位置 | 监察对象 | 失守后果 |
|---|---|---|---|
| **戒门** | 《瑜伽师地论》正知而住 | 身、语、意行为现行 | 不知当行当止，为毁犯留出空隙 |
| **定门** | [《辨中边论》](../../../resources/cards/《辨中边论》.md)所立的[修定五过失与八断行](../../../resources/cards/修定五过失与八断行.md) | 定中惛沉、掉举的起没 | 侦察不报，下一格“思”无从发动对治 |

两岗位是同一慧用：**如实监察当下现行**。对外监察威仪与行为，对内监察定中沉掉。

### 2.3 正知是报告者，不是执行者

八断行在正知之后另立“思”对治不作行，这显示正知只负责如实报告，不替代行为的发动或停止。基于此经典岗位的第二层整理：

```
正知：如实报告
惭愧：对所见染相起遮止力
思：将停止或继续落成行为
```

因此，不正知可解释“不知而犯”；正知已在场时，贪嗔仍可能推动思作业，形成“知而仍行”。不正知是毁犯的重要所依，但不是一切毁犯唯一必经的近因。

## 三、本体定夺——慧一分与痴一分俱摄

### 3.1 三家争议

| 立场 | 主张 | 论据 |
|---|---|---|
| 第一家 | 慧一分摄 | 不正知即烦恼相应慧，谬解仍是一种简择 |
| 第二家 | 痴一分摄 | 痴令知不正，故名不正知 |
| [护法](../../../resources/cards/护法.md)正义 | **俱一分摄** | 两处论文为[影略说](../../../resources/cards/影略说.md)；且不正知[遍染心](../../../resources/cards/遍染心.md)，必须由痴分补遍 |

### 3.2 遍染心论证

慧是别境心所，不遍一切心。极昵钝的染心中，慧的简择可不现起；若不正知唯是慧分，这些染心便没有不正知，与大随烦恼遍一切染心的身份相违。因此必须由痴分补遍。

反过来，不正知又不只是痴：在缘所观境、确有简择的染心中，“谬解”有自己突出的慧分行相，故另立不正知之名。

### 3.3 业用格反推的第二条路

修行者提出另一条第二层论证：不正知的岗位是障正知，那么“正知的反面”天然包含两态——解歪与该分辨未分辨。唯慧分摄无法覆盖第二态。它与护法从外延与遍染心所作的论证，两路收敛于俱一分摄。

### 3.4 与有部的对照

[《俱舍论》](../../../resources/cards/《俱舍论》.md)会通[《品类足论》](../../../resources/cards/《品类足论》.md)“十大烦恼地法”时，将失念、心乱、不正知判为大地法念、定、慧的染污位，故不重立。

有部对失念、不正知同作“染位不别立”的判摄；唯识侧对两法同作“立名不立体”的俱一分摄。双侧重复显示：这不是失念的偶然个案，而是念、慧染位切片的稳定类型。

## 四、与相邻法的边界

| 对比 | 边界 |
|---|---|
| **不正知与痴** | 痴是迷闇，可无解；不正知在慧分显时是有解而歪，在慧不起时则由痴分构成无检型 |
| **不正知与失念** | 失念是念位“没持住”；不正知是慧位“没查对”。前者断持，后者断查 |
| **不正知与散乱** | 散乱是心于所缘流荡；不正知时心可仍在境上，但对当下境与行为的解失真 |
| **不正知与恶见** | 两者都属[染慧](../../../resources/cards/染慧.md)家族。不正知缘所观境谬解，恶见于诸谛理颠倒推度、印持成执 |

同为染慧，恶见升为根本烦恼，不正知居随烦恼，分判的尺在**能生力**：推度成执后，恶见能成为多惑发生器；不正知主要使监察失真、为毁犯开门。即：**推度成执者为本，失察放行者为随。**

## 五、染慧家族——分别恶见发生学与俱生边界

### 5.1 分别起恶见的三阶段

基于经典对“所观境谬解”与“于诸谛理颠倒推度”的梯度，本项目将分别起恶见整理为：

```
一次带染分判
  → 谬解叙事相续
    → 推度、印持而成见
```

- **第一边界——相续化**：从一次染分判变成被维持的错误叙事；
- **第二边界——成执化**：推度与印持进场，从“一直这么以为”变成“就是如此”。

这是有经典梯度支撑的第二层发生学，不是经典明立的三阶段。其动力可用[种子](../../../resources/cards/种子.md)、现行、[熏习](../../../resources/cards/熏习.md)循环说明，但三阶段不可直接冒充经典原话。

### 5.2 俱生见只许共时局部同构

上述发生学严格限于分别起恶见。[俱生](../../../resources/cards/俱生.md)见由无始熏成的种子直接现行，今生每次现行不需重走三阶段。尤其[末那](../../../resources/cards/末那.md)俱生我见，与四惑、八大随等同时俱起。

因此只能说：

- 恶见本身仍是染慧；
- 当下染心仍有失念之“不持”与不正知之“不查”；
- 三者在现行刹那是共时功能配置，不是先后阶段。

**校正结论**：俱生见处只有“染慧、正念缺位、正知缺位”的共时局部同构；其时间轴与阶段发生学整体悬置。不能因为说“无始”，便反推它在不可追溯的过去必然走过同一序列。

### 5.3 持查双轨的证据档位

分别恶见长期成立，可从两个缺位岗位拆解：

- **失念——不持**：没有将心持在如实境上；
- **无检型不正知——不查**：没有抽查错误叙事。

但若将“一轨真正稳定在场”定义为“持续如实作用于同一内容”，那么错误见解仍能长期成立在逻辑上已不可能。因此“持查双缺”是解释性拆解，不可因“找不到反例”而宣称它获得了独立现量证据。

## 六、毁犯所依与四环依存图

### 6.1 四环的经典文面与整理层分开

大随后四法的业用格都有“所依为业”句式，但经典并未明立一条完整四步因果链。证据强度应分级：

| 关系 | 文面强度 | 精确读法 |
|---|---|---|
| 放逸 → 失念 | 非直接点名 | 放逸只说“增恶损善所依”；把它接到失念，是守护配置撤防的第二层整理 |
| 失念 → 散乱 | **经典直接点名** | “散乱所依为业，谓失念者心散乱故” |
| 散乱 → 恶慧 | **经典直接点名** | “恶慧所依为业，谓散乱者发恶慧故” |
| 恶慧 → 不正知 | 部分包含，不可画等号 | 不正知的慧分属恶慧，但恶慧还可表现为恶见 |
| 不正知 → 毁犯 | **经典直接点名** | 是毁犯的所依，不是每次必然毁犯 |

因此，“四环依存图”的精确定性是：**以四条同构业用格为基础的机制依存图，不是经典明立的完整因果链，也不是时间顺序链。**

```
放逸：守护配置撤防
  ↓
失念：所缘锚点失守
  ↓
散乱：心流荡
  ↓
不正知：当恶慧落到监察身语意时，形成谬解或失检
  ↓
毁犯：染心塌陷穿出心识，进入行为
```

图中上下表示功能层次，不表示诸法先后才出现。八大随遍染心，同一染心刹那中各岗位俱在。

### 6.2 毁犯的两条通道

修行者对“明知故犯”的辨析校正了原先过重的“不正知签发通行证”解释。戒行本就须依当前所缘辨别应行、应止，毁犯可由两门进入：

```
认知失守：不正知 → 不知当行当止 → 毁犯

执行失守：正知已报 → 贪嗔势强或思不作行 → 毁犯
```

若严格分刹那，正知报告与贪嗔推动作业可是极快相续中的相邻刹那；在事件层，完全可以如实说“明明知道，仍然做了”。

### 6.3 修行者位置：正知通常接通惭愧截断

修行者现量显示两种情况同时存在：

```
常见：正知识别法贪 → 惭愧迅速现行 → 思停止 → 法贪相续被截断

偶见：正知已识别 → 惭愧未及形成足够截力，或贪势更强 → 思仍继续操作
```

这与[惭愧](../善心所/惭愧合论.md)精修所见“三毒势力弱 + 惭愧截得快”的守护结构一致。不能写成“正知必然消灭法贪”，应写成：**正知通常能迅速接通惭愧遮止通道，故法贪多数被截断；但正知与执行之间并非逻辑必然。**

## 七、见自——正知底色强，负载阈值处双相失守

### 7.1 早年整体持境原型

修行者童年接受的课堂引导，是将身体、课堂、教师讲课的整体都摄入当下所缘；后来的工作引导，是在打扰中仍能随时提起、随时放下。这与当前提出的“多任务摄入一个复合总境”同构。

所以修行者不缺多任务正知的原型；当前工作场问题更像是任务密度、外部通知与法贪将负载推过了现有念定承载阈值。

### 7.2 复合总境与子任务调度

多任务不只有“健康串行切换”一种净态，还可在更高层摄成一个复合总境。围棋棋手同时应对多盘棋时，每一刹那仍只处理当前一盘、当前一着；但在更高一层，所有棋局及其状态可被摄成“这一组同时对局”的复合总境。

```
上层：整组棋局／整个任务集 = 一个复合总境
  ├─ 第一子任务当前状态
  ├─ 第二子任务当前状态
  └─ 其余子任务当前状态

下层：每一刹那只进入其中一个局部所缘
```

| 心所岗位 | 多任务中的功能 |
|---|---|
| **念** | 明记整个任务集及各子任务停在何处，不令线头丢失 |
| **正知** | 如实判断当前正在处理什么、此时应处理哪一个 |
| **作意** | 将心实际引向被选中的子任务 |
| **定** | 落入当前任务后不漏残、不被其余任务夺走，维持[心一境性](../../../resources/cards/心一境性.md) |
| **慧** | 在当前任务内分析与解决问题 |
| **思** | 依分判实际发动操作 |

“同分可合”因此获得层级精化：**能否合为一境，不只看内容是否天然相同，也看它们是否被组织为一个有关系、有状态、有次序的任务整体。**

### 7.3 三种“多”的边界

| 形态 | “多”所在层 | 整体结构 |
|---|---|---|
| 王昱珩访谈报告的多视角形态 | 同一问题的多个观察角度 | 一个所知事，多种行相 |
| 围棋多盘对局 | 一个比赛任务集中的多个子任务 | 一个复合总境，多个子所缘 |
| 工作场染态切换 | 多个任务未被稳定摄入总图 | 多境漏残，外缘他转，心流荡 |

此框架为基于唯识心王心所、总相别相与心一境性所作的第二层映射；对王昱珩本人的实际心所配置不作断言。

### 7.4 染念不等于散，而是可能“持错了”

修行者现量提出：正念在的高效工作场可进入复合总境状态；染念状态则容易分神。法相上应再分一层：染念本身可很牢，如记仇、执著某理论，未必立即散乱；工作场的“容易分神”，是染念将不应占据当前中心的旧线或新线持得过强，使任务总境的正念减弱，遂为散乱开窗。

### 7.5 过度挖掘的三分诊

骨架预演曾把“追究理论封闭、追求更多关联、过度挖掘”直接立为不正知的事件入口。精修后应分为：

| 现场 | 主法 |
|---|---|
| 未检查是否还值得继续，直接往下挖 | **无检型不正知** |
| 误认为“只有再补完这一层才算真正理解” | **谬解型不正知** |
| 已经准确知道足够了、继续是法贪，但仍想再挖 | **法贪推动思继续操作**；正知可在场，不正知不是主因 |

修行者确认第三种真实存在；同时，正知真正照到时，法贪通常会由惭愧快速截断。所以“过度挖掘”只是可能出现不正知的场域，不是不正知的充分判据。

### 7.6 见自定稿

> **负载阈值型双相现行：正知底色强，高负载时出现谬解与失检两种局部破口。**

- 基态：正知侦察力强，早年已有整体持境种子；
- 高效工作：能进入复合总境 + 子任务调度的正面状态；
- 高负载工作：谬解型与无检型均有现行；
- 探索场：须逐次分清不正知与“正知已报、法贪仍推思”；
- 对治：谬解、失检补正知抽查；正知已报而仍行，转治法贪、惭愧与思的执行失守；
- 归档：有真实现行，但不另立主修区，现有[工作场对治案](../../实修/logs/生活修日志/2026-06-工作场任务切换与正知而住.md)与法贪识破通道已覆盖。

**主座近期状态（2026-07-17）**：修行者近期一段未上座，前一日刚恢复。现阶段不依一座判断进展，仍只保留失念精修已立的单一检验：**细所缘入口是否变得可感**。

## 八、见众生——“不知”与“知而不能行”分诊

凡夫的不正知并不只是抽象认知错误，更常显为行为层自动驾驶：

- 于所作不知所作：身语行为已在跑，检察岗位未起；
- 自我叙事失真：实做甲事，自认在做乙事，事后合理化又将谬解熏稳；
- 毁犯不自知：伤人、越界常不以“我在犯”的面目显现，而以“本来就该如此”显现。

但帮助众生时不能一概归因为“道理没讲明白”：

| 毁犯通道 | 真实缺口 | 帮助入口 |
|---|---|---|
| **不正知而犯** | 对当前所缘误判，或该分辨未分辨 | 帮他看清当前因缘、行为与后果，不只是背诵规则 |
| **正知而仍犯** | 贪嗔势强，思不依所知，守护配置不足 | 继续讲道理通常无效；应处理贪嗔、惭愧、不放逸及环境诱因 |

利他善巧因此多一把分诊尺：**先问他是不知道该怎么做，还是知道却做不到。**前者补慧与正知，后者补守护与执行。

## 九、“大”三尺与念力反比命题收官

### 9.1 “大”三尺齐证

| 尺 | 判定 | 理由 |
|---|---|---|
| **看破难度** | 深 | 谬解以真相面目出现；无检型连“该检查”都不起，两形态都能遮蔽自身 |
| **对治时间** | 长 | 正知而住须贯穿行住坐卧、身语意一切威仪，不是纠正一个观点即完成 |
| **定力配合** | 强 | 正知虽属慧用，持续监察必须由正念持住整体、由定承载相续；高负载工作场是其现量差分 |

不正知的独特证据类型是：

> **监察—出口型基底。**

不信污染资粮质地，放逸撤守护配置，失念断执行锚点，散乱贯穿诸尺度，不正知则决定染心如何被解读，并为它如何输出为身语意行为开门。至此，大随八法全部通过基底配置级检验。

### 9.2 念力稳态反比命题的第八票

候选命题：大随八在意识层的显现程度，与正念稳态成反比。不正知给出有条件的赞成票：

- 正念在场时，复合任务总境被持续明记，正知才有稳定材料可查；
- 染念占位时，正念对当前任务总境的统摄退失，正知易失检或谬判；
- 正念不是不正知的直接对治，直接对治是正知；正念只是正知持续工作的承载平台。

八法齐检后，命题定稿为：

> **在意识层，正念稳态越强，染心刹那的可占域越窄，大随八的显现域整体随之收缩。这是平台性反比，不表示正念直接对治八法，也不表示正知在场即可保证行为服从。末那层仍是凡夫位常数项，非第六识正念所能直接收缩。**

状态：这是有统一机制、有八法逐项检验、有末那边界的第三层结构假说，仍不是经典明立的普遍定律。

## 十、五随岗位图与大随本体谱系收官

### 10.1 五随烦恼是岗位网络，不是单线事件链

| 失守岗位 | 染方 | 清净方 |
|---|---|---|
| **动力** | 懈怠 | 精进 |
| **守护配置** | 放逸 | 不放逸 |
| **持境** | 失念 | 正念 |
| **安住** | 散乱 | 正定 |
| **监察** | 不正知 | 正知 |

经典明文接口仍保留：懈怠是放逸的构成成分，失念是散乱所依，散乱是恶慧所依，不正知是毁犯所依。但五法不是依次排队才发生，行为出口还须接思、惭愧与贪嗔势力的分诊。

一句话定稿：

> **五随网络是修行执行系统从动力、守护、持境、安住到监察五个岗位的协同失守图。**

### 10.2 大随八本体谱系定稿

| 本体类型 | 法 | 数量 | 判定机制 |
|---|---|---:|---|
| **别有体** | 掉举、惛沉、不信、懈怠、散乱 | 五 | 外延缺口式与行相统一式论证；懈怠无争议 |
| **俱一分摄** | 失念、不正知 | 二 | 影略说 + 遍染心论证；别境染位切片可切出 |
| **复合分位** | 放逸 | 一 | 离懈怠及贪嗔痴之功能无剩余，特性真而体假 |

护法论证工具箱至此完整：别有体用“还原有剩余 + 独立业用”立体；放逸用“推究无剩余”拆体；失念、不正知用影略与遍染心立名而拒立新体。
