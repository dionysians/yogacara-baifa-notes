# 诳

> **类别**：心所法 > 随烦恼心所 > 小随烦恼（第七法）
> **本体**：贪痴一分 · E 分位假立 · 无内部诤议
> **梵文**：māyā（与"幻"同词根，本义即变现假相）
> **对治通道**：小随通道 → 愧感应器 → 无痴 → 无贪；究竟收于惭愧（停止演）
> **学习日期**：2026-06-13（随烦恼单法精修第七法，沿用"单法学习循环"五段）

## §一 经典概念

### 1.1 定义原文

[《成唯识论》](../../../resources/cards/《成唯识论》.md)卷六：

> 「云何为诳？为获利誉，矫现有德，诡诈为性。能障不诳，邪命为业。谓矫诳者心怀异谋，多现不实邪命事故。此即贪痴一分为体，离二无别诳相用故。」

### 1.2 拆解

| 要素 | 内容 | 解读 |
|---|---|---|
| 动机 | 为获利誉 | 利（财利供养）+ 誉（名声敬重）= 贪的所缘 |
| 动作 | 矫现有德 | 矫 = 造作不实，现 = 演示给人看——伪造增益面 |
| 体性 | 诡诈（心怀异谋）| 心里图利、现出有德——心口两层结构性背离 |
| 障 | 不诳（实心实语）| 对治方向 = 如实 |
| 业用 | 邪命 | 以不实形象为谋生手段：欺骗固化为生存方式 |

### 1.3 本体归属

- **贪痴一分、E 分位假立、无别体**——「离二无别诳相用」：贪分 = 图利誉的动力源；痴分 = 对"假相终不可持"的无明 + 利誉实执。抽贪则不必演、抽痴则演而无义，二者缺一诳无处立。
- **无显著派系诤议**——覆有安慧"唯痴"与护法"贪痴"之诤，诳、谄各家基本一致取贪痴一分。覆 / 诳 / 谄构成小随中的"贪痴一分组"。
- **生起次第**（骨架 §7.3）：诳是名利场域的开启法——嫉 / 悭守既得，诳 / 谄转入进攻性获取（伪造形象 / 曲意逢迎）。

### 1.4 邪命与正命（业用落点）

诳的业用是[邪命](../../../resources/cards/邪命.md)——[《大智度论》](../../../resources/cards/《大智度论》.md)立五邪命（针对出家众）：①诈现异相奇特 ②自说功德 ③占相吉凶 ④高声现威 ⑤说所得利以动人心。其中①②正是"矫现有德"的直接展开。对应八正道的[正命](../../../resources/cards/正命.md)：谋生手段本身须如实。

〔订正：旧笔记初稿误标诳梵文为 śāṭhya——那是谄；诳的梵文是 māyā。〕

## §二 与相邻法辨异

| 对比 | 分界 |
|---|---|
| 诳 ／ 覆 | 同走利誉轴、同贪痴一分，方向相反：覆 = 遮断减损面（藏坏的、防露 · 守）/ 诳 = 伪造增益面（演好的、引利 · 攻）|
| 诳 ／ 谄 | 诳 = 伪造自身形象（对自轴）/ 谄 = 曲顺他人（对他轴）。常协同，行相可分。〔诳谄对仗待谄精修验证〕|
| 诳 ／ 妄语 | 妄语 = 语表业（戒所摄行为）/ 诳 = 心所（心理引擎）。诳特指"利誉—形象"领域，非一切说谎 |
| 诳 ／ 憍 | 憍 = 于真实自盛事染著醉傲（真有所恃）/ 诳 = 无德而装（凭空伪造）。真货上的醉 ／ 假货的演 |

## §三 主线 1 · 体性机制

### 3.1 覆诳无独特核——都是利誉实执的"假因换真果"

修行者现量分诊：诳无独特体性核，与覆相比无真正额外独特的部分。两者都是**伪造假因换真果**：

- 覆：假装一个减损 / 罪**不存在**（假因）→ 让本该失去的不失去
- 诳：假装一个增益 / 德**存在**（假因）→ 获取本不该获取的

一守一攻，对偶工整，**同是利誉实执的表现**。这正是经典「离二无别」的现量重印——诳无独立体性、相对覆也无独特核（体性层）。

需保住的精度：经典仍立覆、诳为两法，依据是**分位差异**（守 / 攻、藏 / 演、减损面 / 增益面）；分位异 ≠ 体性独特核。

### 3.2 贪痴两分的精确分工

- **贪分**：图利誉的动力源。与悭 / 憍同是贪，朝向不同——悭守已得、憍醉已有、**诳求未得**。
- **痴分**：覆精修立的三层框架（后果之痴 / 利誉实执 / 负罪我执）大部可沿用；诳不另立独特痴核（见 3.1）。

### 3.3 维持动力学的差异——不在体性，在分位方向

诳"演越久越易穿帮、难长期维持"是真实差异，但源自分位方向（增益 / 减损），非体性：

| | 覆（守 · 藏减损）| 诳（攻 · 造增益）|
|---|---|---|
| 伪造内容 | 一个已存的减损 / 罪 | 一个不存的增益 / 德 |
| 维持动力学 | 只需"不被发现"→ 可长期稳态遮蔽 | 需"持续兑现增益相"→ 增益面可被要求验证、演越久越易穿帮 |
| 自然结局 | 罪可藏一辈子（稳态）| 难持久：要么穿帮、要么演成真则脱离诳 |

关键不对称：**减损面只需遮蔽（被动防御），增益面可被要求兑现（主动暴露面）**——"说会弹琴"一被要求当场弹就穿帮。诳天生带自拆解压力，覆不带。

### 3.4 对治枢纽永远是惭愧，不是"填实"

修行者校正一处膨胀候选（"演成真则诳灭"作对治出口）：

- 任何情况对治都**惭愧在前**（认识到要停止演）；"填实"若发生，也因"决定停止演"已生在前——枢纽是惭愧。
- "被迫必须修出来否则极大后果"驱动的填实 = 另一个贪（怕后果）在驱动，**不是对治，反熏厚诳种**（诳成功了）。
- 现实观察（决定性）：诳获利者一处演不下去，只要没真正认识到问题，**就换地方继续诳，不在原场域填实**。

→ 判对治须判驱动心所，不能判外显结果。"演成真"只是结果形态，不能据以判对治——又一次"判心相不判形式"。

## §四 如实展示的边界

> 本节是诳精修开篇的究竟层边界探讨——回答"哪些真正才算诳"。修行者举三例（产品定位 / 销售话术 / 自媒体人设）质疑"不实形象 + 谋生 = 诳"的草率判定。

### 4.1 判准不在符实度，在心相

诳是心所，判准不在"表述是否符实"。很多不百分百符当下事实的表述（愿景 / 如实扬长 / 风格化呈现）**不是诳**；一句字面全真的话也可以是诳（用真话拼误导性整体印象、心怀异谋）。符实度既非充分也非必要。

### 4.2 诳核两要素 + 第三剥离层

| 要素 | 经典 | 检验 |
|---|---|---|
| 异谋（二层背离）| 心怀异谋 | 所现之相与心中真实，是扬其真还是造其假？|
| 矫现"有德"（伪造增益）| 矫现有德 | 是"有而善呈"（扬长 / 选切面）还是"无而装有"（凭空造）？|

第三剥离层（场域）：该表述在该场域的**共业约定**下，是否被解读为"事实断言"并据以受损？双方共享其非事实性质（愿景 / 定位 / 风格）→ 无背离 → 非诳；伪装成事实断言令对方据以决策受损 → 诳 / 妄语。

### 4.3 三例逐案

- **产品定位**：多非诳——商业共业约定下是"方向陈述"，各方都懂 ≠ 当前事实。**线**：滑成"宣称当前不存在的功能已存在"、买家据此受损 → 越线入诳 / 妄语。
- **销售话术**：尽责与不诳**正交**，非对立。冲突只在"产品真实价值 < 成交所需"那一刻——那一刻如实 = 正命、伪造 = 邪命诳借"尽责"的壳。之前（扬长 / 迎合 / 呈现真实优点）既尽责又不诳。
- **自媒体人设**：最近诳。线在"呈现真实自我的切面"（扬长 / 选切面，非诳）／"建构本人不具有的人格"（矫现，诳）。

### 4.4 两个范围归位

- **诳是个人染心所，不是对"商业行为 / 职业"的伦理判定**——落到某人某心识刹那；同一销售动作，张三心怀异谋伪造是诳、李四如实扬长履职不是。〔同悭"悭≠我所执"的范围归位〕
- **谋生动机中性，"不实"才是毒**——邪命的"邪"不在"为谋生"（正命也谋生），在"以不实为手段"。

### 4.5 新情形：重大机缘伪造增益接住

重大机缘、能力不够、伪造增益获取、随后励精图治完成、不为损他。修行者认为"不完全算诳"——拆为对错各半：

- **错的一半**：接机会那一刻有诳核（二层背离 + 矫现增益 + 为自己获取），判**那一刻的心相**；"不损他发心 / 后来做成"不能撤销那一刻的心所配置（范围归位：不能用总发心 / 最终结果给那一刹那撕标签）。
- **对的一半**：损他与否是**业相轻重变量**——无损他心 + 后续兑现，业相远轻于邪命诳；那一刻是**复合心所**（诳 + 担当 / 勇 + 一点贪），夹善法但善法不消同在的诳核。落在"邪命诳"与"菩萨善巧方便"之间，偏自利诳侧。〔菩萨开许方便妄语 = 第一层经典；居中地带 = 第三层〕

### 4.6 收口

判心相不判形式——与持戒、施的究竟层严格同构。三例"很难说就是诳"是诊断正确：诳成分（若有）被合法共业约定 + 正当角色履行紧紧缠住，须剥离纯化到"心怀异谋的伪造增益"那个核才判得出；大量场景剥完根本不是诳。

## §五 见自——诳结构性不现行 + 一个邻区现象

### 5.1 诳本身：连那一闪都不起

修行者现量：开口说"我能干"前，心底先盘算"是否真能胜任"+"怕辜负别人"——**惭愧感应器在源头先起**（盘算胜任 = 无痴如实 / 怕辜负 = 愧），堵死矫现的发动。不是覆那种"动意一闪被拦截"，而是**连闪都不起**。与覆同走惭愧感应器通道（预判命中），感应器臂偏愧（对他 / 怕辜负）。诳结构性不现行，归档。

### 5.2 邻区现象：叙事感染力抬高他人意愿——非诳，是愧的认知 / 受欲层缺口

修行者自我揭示：天然善于把事情放进更大的故事背景，使之更有条理、故事性、吸引力，别人更易忽略风险、愿意同行；自己**不会不安**（因真信愿景、自己也按它推进、自己也担风险）。

- **定性：不是诳**——真信、共担、无矫现无异谋（邀请共担，非诱骗替担）。
- **精确归位：愧**——客观上叙事降低对方对风险的如实认知，是"我所（我的愿景）"风险向他人的细微外溢。"不会不安" = 从"我是否诚实"看无愧可起（确实诚实），但从"对方是否在如实认知下承担风险"看，愧在此点未现起。轻沾不害（可能令信他者受损），因共担 + 夹利他潜质，性质轻。
- **更深一层（修行者补充，证伪"如实告知"补全）**：知情他已做，但**信息如实也挡不住**——故事讲得好时，对方的**受 / 欲被激发抬高**，风险接受阈值被推高，对方还**自以为是确定风险才来的**（对方一层不正知）。问题在受 / 欲层，非信息层。
- **对治必上移到初心 / 方向**：感染力必然抬高意愿、信息如实挡不住，唯一解 = 确保导向真利他方向。修行者方案（欲 → 精进、初心利他）抓住根（拔我所）；其自然外显本含"导向真实利益"。**五度如盲、般若如导**（[《大智度论》](../../../resources/cards/《大智度论》.md)）——感染力是力大而"盲"的部分，须由利他初心导，否则力越大风险越大。〔受 / 欲激发 = 经典心所；般若如导 = 第一层；对治上移 = 第三层〕

## §六 见众生——凡夫诳的底层机制

### 6.1 三段全断对仗覆

诳不现行须三段全断（贪痴一分组共性，与覆同构）：**愧感应器 → 无痴 → 无贪**，顽固度 = 三段难度乘积。感应器臂对仗：覆偏惭（自罪）/ 诳偏愧（怕辜负、欺他）。

### 6.2 常驻动机 + 自欺强化（诳比覆多一层）

诳的常驻动机三要素齐备：动力 = 贪利誉 / 失则损 = 暴露则利誉崩 + 穿帮 / 保全 = 实际获利（诳能事实得好处）。**常驻动机候选第三复证**。

**自欺 = 诳独有的强化项**（非独特体性核，是常驻动机强化形态）：在一个场域被反复认可、且未被暴露 →"我其实就是很行"的自欺 → 痴分反向吃掉自知 → 诳种增厚。

与覆对仗（很深，也很黑暗）：

- 覆：藏已知之罪、**始终自知**（自苦闭环 = 悔恼，惭愧随时有对象可触）
- 诳：装未有之德、演久**自知被吃**（连"我在诳"都不自知）

→ 诳常驻动机比覆 / 悭多一个维度：**自欺把刹车也吃了**。覆、悭都自知（惭愧理论上随时可起）；诳到自欺态，惭愧的触发对象（"我在装"的自知）消失，这是诳在**自我认知层**最顽固处。也解释"凡夫为何换地方继续诳不填实"——自欺态下他已以为自己真行、根本不觉得需要填实。

### 6.3 装有德则不修德——障道 + 利他善巧轴

诳在修行场域 = 矫现修行有得（五邪命原型"自说功德"），自欺层最毒——演证量演久了以为自己真有证量、**障真修**。利他善巧轴第三层：凡夫诳 = 被利誉回路 + 自欺双重绑架 = 看不破"假因换真果"的结构性必然，非品行问题；出口仍收在惭愧（戳破自欺、停止演）。

## §七 结构关联

### 7.1 双重假候选第四复证（纯符号建构最强样本）

- 体上：贪痴一分、E 分位假立、无别体 ✓
- 所缘上：诳所缘 = "德 / 利誉的形象（人设）" = 世俗概念建构 ✓——且**纯度最高**：覆的"罪"、嫉的"排名"、悭的"我的"都还挂在某载体上，诳的"德的形象"**连物理载体都没有**，是纯认知建构。

### 7.2 常驻动机候选第三复证 + 自欺维度

见 §6.2。诳为常驻动机加一个新维度——自欺让动机连"知道自己在诳"这个刹车都吃掉，自我认知层最顽固。

### 7.3 覆诳谄网络 + 可迁移到谄

覆诳 = 利誉同轴守 / 攻；诳谄 = 对自 / 对他轴。贪痴一分组三法对仗网络，谄精修时验证。三段全断、常驻动机、施 / 展示边界判法（判心相不判形式）可平移到谄。

## §八 学术诚实三层标注

### 第一层（经典）

- 诳定义、贪痴一分、离二无别（《成唯识论》卷六）；[窥基](../../../resources/cards/窥基.md)《百法明门论解》
- 邪命、五邪命（《大智度论》）、正命（八正道）
- 菩萨开许方便妄语（菩萨戒 · 饶益有情）
- 五度如盲、般若如导（《大智度论》）

### 第二层（框架应用映射）

- 覆诳"守 / 攻、藏 / 演"对仗、诳谄"对自 / 对他"对仗 = 基于体性分位的整理性观察
- "扬长 ／ 伪造"、"共业约定下事实断言性质" = 诳核判准的整理表达
- 三段全断（愧感应器 → 无痴 → 无贪）= 覆框架向诳的延伸
- 叙事感染力归位到愧的认知 / 受欲层 = 已学心所对修行者现量的整理

### 第三层（自主推论）

- 维持动力学差异（增益面可兑现 / 减损面只需遮蔽）= 分位方向的派生，非体性
- 新情形居中地带（邪命诳与菩萨善巧之间偏自利诳侧）
- 自欺强化"刹车被吃" = 诳常驻动机在自我认知层最顽固（修行者主导现量 + 推论）
- 双重假第四复证、常驻动机第三复证 = 已立候选的持续验证
