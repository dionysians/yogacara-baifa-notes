# 谄

> **类别**：心所法 > 随烦恼心所 > 小随烦恼（经典顺序第八法）

> **梵文**：śāṭhya（义为曲、不直、阴险）

> **学习日期**：2026-06-14（随烦恼单法精修第八法，沿用"单法学习循环"五段；贪痴一分组三法收口）

## §一 经典概念（闻）

### 1.1 定义原文

[《成唯识论》](../../../resources/cards/《成唯识论》.md)卷六：

> 「云何为谄？**为罔他故，矫设异仪，险曲为性。能障不谄、教诲为业**。谓谄曲者为网他故，曲顺时宜，矫设方便，以取他意。或藏己失，不任师友正教诲故。此亦**贪痴一分为体**，离二无别谄相用故。」

### 1.2 拆解

| 要素 | 内容 | 解读 |
|---|---|---|
| 所缘 | **他人 / 他意** | 缘"对方想要什么"——谄区别于覆诳的根本转向：覆缘自罪、诳缘自德形象，谄缘**他人** |
| 动机 | 为罔他故（网他）| "罔 / 网" = 把对方网住、套住——心怀异图地操控关系 |
| 动作 | 矫设异仪 + 曲顺时宜 + 矫设方便 | 造作不实的姿态仪容、随对方与时机弯转、设计种种手段以取他意 |
| 体性 | **险曲** | 心不平直（曲）+ 内藏异心难测（险）——体性核就在"心曲"（= 发心曲）|
| 业用 | **障教诲**（不任师友正教诲）| 谄独有的业用，详 §三 2 |
| 障 | 不谄（质直、直心）| 对治方向 = 心直 |

### 1.3 本体归属

- **贪痴一分、E 分位假立、无别体**——「离二无别谄相用」：贪分 = 图从对象获利 / 好感的动力源；痴分 = 实执"迎合对方 → 将来能获利"这条想象的因果 + 不知谄断善缘。抽贪则无所图、抽痴则不信"顺能得利"，二者缺一谄无处立。
- **无显著派系诤议**——谄与诳各家基本一致取贪痴一分（不像覆有[安慧](../../../resources/cards/安慧.md)"唯痴"与[护法](../../../resources/cards/护法.md)"贪痴"之诤）。覆 / 诳 / 谄 = 小随中的"贪痴一分组"，谄是此组收口法。
- **生起次第**（骨架 §7.3）：名利场域中，诳（矫现自身德行）→ 谄（曲顺他人取意）→ 害。诳转向自身形象的伪造，谄转向他人关系的操控。

### 1.4 梵文订正

旧桩稿（2026-03-05）误标谄梵文为 **māyā / 摩耶**——那是**诳**的梵文（已于 [诳.md §1.4](./诳.md) 订正）。谄的梵文是 **śāṭhya**。三法梵文各别：覆 = mrakṣa / 诳 = māyā / 谄 = śāṭhya。

## §二 与相邻法辨异

| 对比 | 分界 |
|---|---|
| 谄 / 诳 | 同贪痴一分、同心怀异图。**真差异不在"对自 / 对他"对仗**（该对仗已证伪，见 §三 1）——在**贪对象 + 抓取方式**：诳贪利誉、矫现一个固定的德相；谄贪网住他人、随对象实时违心曲顺 |
| 谄 / 覆 | 谄"或藏己失"与覆交叠，但覆纯是**藏自罪**（对内防露），谄是**对他曲顺取意**（对外操控关系）；藏己失只是谄网他的手段之一 |
| 谄 / 恭敬随顺 | **关键边界**（§四 详）：外形都是"顺"，判准纯在**发心**——谄 = 险曲心（网他取利）/ 恭敬随顺 = 直心（敬 / 利他）|

## §三 主线 1 · 体性机制（贪痴一分 × 发作方式 · 无独特核）

### 3.1 "对自 / 对他"对仗证伪——真差异是两参数

诳.md 留的"诳谄对自 / 对他对仗待验"，本法**证伪**：谄"矫设异仪"也在造作自身姿态，所以"对自 / 对他"既不互斥、也不指向真差异，只是个附带外形描述，不做解释工作。

真差异是**两参数**（修行者现量立）：

| | 贪对象（贪什么）| 抓取方式（怎么抓）|
|---|---|---|
| **诳** | 利誉（自身标的）| 矫现有德——静态伪造一个固定的"德"相 |
| **谄** | **网住他人**（对他人的关系性把控）| **随所关注对象实时违心曲顺**——动态、响应式 |

→ 诳的贪对象是"我自己的标的"（利誉），谄的贪对象**整个换了类**——从"内容标的"变成"对他人的关系性把控"（取他意 / 网他）。这比"对自 / 对他"深：是**所贪之物的种类变了**，不只是朝向变了。

### 3.2 谄无独特核——障教诲为业是抓取方式的派生

谄相对覆 / 诳**无独特体性核**（经典「离二无别」现量重印）：它 = 贪（对象 = 网他）+ 痴（实执"迎合→获利"想象）+ 发作方式（违心实时曲顺），抽掉哪个都塌。

**障教诲为业不是第二个独立核，是"实时曲顺"这个抓取方式的直接派生**：

```
抓取方式 = 实时随对方违心弯转（心曲成习）
   ↓ 习惯对一切人 / 境做响应式弯转
呈现给师友的永远是"调好的版本"（矫设异仪 + 藏己失）
   ↓
师友照见 / 对治不到真问题 → 直话进不来 → 不任正教诲
```

→ 谄"障教诲"= 抓取方式作用到师友关系上的必然结果。覆诳损的是"如实"，谄损的是**"被纠正的可能"本身**——这是「直心是道场」（《维摩经》）反面的精确含义。

### 3.3 贪痴一分组网络收口（覆诳谄三参数表）

| 法 | 贪对象 | 抓取方式 |
|---|---|---|
| **覆** | 利誉（恐失利誉）| 藏——遮蔽**已有**的减损 / 自罪（守）|
| **诳** | 利誉 | 矫现——伪造**未有**的增益（攻）|
| **谄** | 网住他人 | 实时违心曲顺——随对象动态表现 |

- 覆诳**同贪对象（利誉）、异抓取方式（藏 / 现、守 / 攻）**——诳.md 立的"假因换真果一守一攻"，是"贪对象相同、抓取方式相反"的特例。
- 谄是**贪对象本身换类**的那一个——在三法里"最不一样"处不在动作，在它贪的是**关系把控**而非内容标的。
- 三法**全部无独特核**：每一个 = 贪(对象 × 方式) + 痴分。整组「离二无别」成立。

### 3.4 候选研究纲领——"小随 = 根本分 × 发作方式、无独特核"（修行者主导 · 先记不立）

修行者立：把"无独特核"设为小随（E 分位假立）的**默认前提**，研究每一法只剩两问——㈠ 经典所标的根本分（贪 / 嗔 / 贪痴，照经典不自造）；㈡ 这一分以什么独特发作方式（对象 + 动作）发作。

```
小随（E 分位假立）= 经典所标根本分 × 发作方式
  · 痴分定则：经典标了（如覆诳谄 = 贪痴一分）就分析其落点；
            没标（如忿恨恼嫉害只标嗔一分）就默认痴是共同底、不专写
  · 无独特核：默认前提
```

**逻辑闭合点**：若真无独立体，则每法必能由"根本分 + 发作方式"完全重构、不留剩余；有剩余 = 它有独特核（就不是纯分位假立）。此标准**重建了经典"分位假立 vs 别立实有"边界**——E 类应无剩余，而经典立别有体的 A 类（无惭无愧 / 不信 / 懈怠 / 掉举 / 惛沉）、C 类（散乱）应留归约不尽的剩余。

**痴分双维度厘清**（修行者纠正一处模型混淆）：痴作"共同底"是说痴的**角色**（无明实执恒为一切烦恼之底）；痴实执什么是其**内容**，随各法所缘不同而变（覆实执罪可藏 / 诳实执德可装 / 谄实执迎合可获利）。**内容随所缘变正是共同底该有的行为，不是它升格为独特核的反例**。故谄痴分有具体内容不动摇"痴是共同底"的结论；经典标痴一分处就分析其落点（谄 = 实执将来获利想象），是路径必然内容、属经典衍生。

**候选状态**：先记不立。验法 = ㈠ 小随其余法逐法确认无剩余；㈡ **重点撞 A / C 类验"有剩余"**（若也能套干净，标准太松、命题废）。验够 → 升为小随通性并入随烦恼整体认知 §二；A / C 类套得进 → 废。

## §四 恭敬随顺 vs 谄曲的边界（判心相不判形式 → 判发心）

> 本节是谄精修对修行者现量价值最高的一条——它是利他善巧轴的正面镜像。

### 4.1 判准纯心相，不看行为；真签名是发心

谄的外形（曲顺、迎合、矫设方便、随对象调整）和一批合法甚至高阶的"顺"长得一样：礼貌恭敬、谦虚、方便善巧、**菩萨爱语 / 同事 / 恒顺众生**（四摄）。

判准**纯在心相、不挂任何外显 marker**——"实时随对象调整"是谄的**发作方式**（描述谄怎么动），不是**判准**（判它是不是谄）；否则就破"判心相不判形式"。

判准的最终落点（修行者两轮纠正后锁定）= **发心**：

> 谄完全看发心（**网他 vs 利他 / 解决问题**），不在动作、也不在"违心"字面义。说对方爱听的话——只要发心是让对方更易接受、更易解决问题，**完全没问题、不是谄**；只有发心是"网住他人取利"，才是谄。

这才对上体性"险曲"的真义：**险曲 = 发心曲（藏着网他异图）**，不是"言语不符字面真实"。"夸味道一般的饭好吃"为让家人开心 = 言语或许不符字面味觉、但发心直（利他）→ 非谄；同一句话发心为网住对方捞好处 = 发心曲 → 谄。

### 4.2 贪不现行 = 不是谄

谄是贪一分，天然动机是对对象**有所图（或有可能有所图）**。贪不现行时，外形再像"顺"也不是谄——抽掉贪，谄整个塌，没有剩下的"谄核"。

**避冲突 / 为安全随顺 ≠ 谄**：有危险时为保全自己、随顺他人说话以不激怒对方（且绝大多数激怒对方的行为本就不对），发心是安全 / 不造恶，不是图从对象获利，是合理的动机和行为。

### 4.3 菩萨"直心 + 恒顺"不悖

对治善是**直心**（不谄 = 质直；《维摩经》「直心是道场」）。表面悖论——菩萨既要直心、又要恒顺众生？**不悖：直在心（无异谋），顺在形（善巧应机）**。直心 ≠ 直言 / 刚硬；直心 = 心无异曲。恒顺众生 = "直心地顺"，谄 = "曲心地顺"。同一"顺"字，发心相反。

## §五 见自——谄结构性不现行 + 母态过直 + 表达域反转

### 5.1 谄结构性不现行——发心从不网他 + 母态在谄的反极

谄在修行者位置**结构性不现行**，理由与诳预判的相反：不是"网他贪被惭愧截断"，而是这个动力**异质**。

修行者自陈修行史（第一层事实）：长期**根本不知道"仅仅说实话会让人不高兴"**，被家人多次指出后才意识到，**逐渐学会随顺对方说话**。→ 母态在**谄的反极——过直**（说实话不顾对方感受且不自知），谄不是诱惑；修行史是**反方向**的：从过直**学习随顺**这个善巧。

### 5.2 表达域反转——调整表达非谄，表达域的染污镜像是诳

模型曾预判"按对方理解框架调整表达"可能沾谄（取他意），被修行者**反转**：

- **调整表达让对方懂 = 结构性清净**——表达的目的只有教授 / 交流，**任一目的都内在要求**用对方能理解的方式说。所以"调整表达"不是"顺对方"（不是谄候选），是**目的（利他 / 沟通）的必然外显**：目的对，调整自动清净，不经过"要不要顺"这一念。
- **真正的染污在反方向（且是诳不是谄）**——用对方不在的场景词 / 不懂的术语去表达 → 天然在抬高自己位置 / 显得专业 = **诳的现行**（矫现"我很专业"的形象）。这是诳在表达域的精确微细形态（补诳.md "诳结构性不现行"的"万一现行长什么样"）。

→ 同一"表达"场景，两个染污由两参数区分：**诳**（利誉 × 矫现 → 对自抬高）/ **谄**（网他 × 违心顺 → 对他迎合）。主线 1 的两参数在现量里跑了一遍。

### 5.3 利他善巧轴输出侧的实地填补

利他善巧轴（画像 §⑤）缺口有一个**具体历史形态**——母态过直，经现实**走认知路径**意识到"实话会伤人"，从而学会随顺。这是议题 ⑤"补法走认知路径"在**输出侧**的运作：不只"理解他人烦恼机制"，还有"如何把真实 / 关心用对方接得住的方式给出去"。**护栏 = 发心（利他 vs 网他）**：随顺善巧发展起来后，防它滑入谄的判准就是这一条；修行者发心一直在利他侧 → 护栏天然在位。

## §六 见众生——凡夫谄的贪种熏习循环

### 6.1 底层机制（贪 × 违心顺 + 痴）

```
贪对象 = 网住他人（好感 / 被接纳 / 利益）
   × 发作方式 = 违心地实时曲顺取他意
   + 痴分 = 实执"迎合 → 将来获利"想象 + 不知谄断善缘
```

### 6.2 谄不即时奏效——常驻动机是"保住贪念"，不是"即时保全"（修行者纠正）

模型曾把覆 / 悭的"即时保全"框架硬搬到谄，**纠正**：谄对发出者**不立即奏效**（没当场拿到利益）。它真正做的是——**维持"将来可能从对象获利（网住对方）"的可能性 → 由此保住"从对象获利"的贪念**。**痴分**精确落点：这个"维持"本身仅仅是他的想象（他以为迎合了将来就有机会获利，可能性是空的、他实执为实）。

### 6.3 真正的强化循环——贪种熏习正反馈环（修行者核心贡献）

```
谄行为常驻
   ↓ 时时刻刻熏"贪"的种子
贪种变强
   ↓ 贪的粘着特性增强
更想从贪对象获取好处
   ↓
谄的频率 / 行为 ↑ ──→（回到顶部，循环加固）
```

→ 谄"不中断而强化"靠的**不是外部即时奖励，是内部贪种的熏习循环**：谄动作本身常驻地熏贪种，贪种越熏越粘，粘着反逼出更多谄。比"保全概率"框架更贴熏习卫生学。

**常驻动机机制 = 贪对象（时态）派生，非通用模板**：悭保全**已得**（concrete，即时奏效）/ 诳获**实际**利誉（实得）/ 谄维持**将来可能**（imagined，靠熏种续命）。常驻动机不是可平移的模子，是两参数派生的——主线 1 在常驻动机维度又跑一遍。**常驻动机第四复证成立，形态 = 熏种循环变体**（非覆 / 悭的即时保全变体）。

### 6.4 障教诲 + 见自见众合流

谄"障教诲为业"（经典）在见众生层最毒：习惯曲顺取意者呈现给师友的都是"调好的版本"，师友照见不到真问题，**修道最关键的"被纠正"通道被关闭**。凡夫谄 = 被"网他得好感"回路 + "不知断善缘"双重绑架 = 看不破"曲顺取意终断真实连接"的结构性必然，**非品行问题**。

**见自见众合流点**——修行者与凡夫卡在谄轴两个相反极：

| | 母态 | 缺口 | 修行方向 |
|---|---|---|---|
| **修行者** | 过直（说实话伤人不自知）| 缺**随顺善巧** | 学随顺（发心利他）|
| **多数凡夫** | 偏谄（求被接纳）| 缺**直心** | 破谄回直心 |

两极相反，合流于同一点：**发心利他地直心随顺**（菩萨爱语 / 恒顺众生的心相）。这是见自见众在谄处的合流，也是利他善巧轴见众生线的一次清晰填补。

## §七 结构关联

### 7.1 双重假第五复证

- 体上：贪痴一分、E 分位假立、无别体 ✓
- 所缘上：谄所缘 = "网住他人 / 他人的好感"= **关系性世俗建构**（他人好感、社交位置，想网则有、不网则无，无自性）✓——与嫉"排名"、悭"我的"、诳"德相"同族的世俗概念假立。

### 7.2 常驻动机第四复证（熏种循环变体）

见 §6.3。谄为常驻动机给出**新形态**——不靠即时保全，靠贪种熏习正反馈续命；机制由贪对象时态（将来可能）派生。

### 7.3 覆诳谄网络收口 + 两参数模型

贪痴一分组三法网络在谄处收口（§3.3 三参数表）。两参数模型（贪对象 × 抓取方式）+ "小随 = 经典根本分 × 发作方式、无独特核"研究纲领（§3.4）= 谄精修的最大结构产出，候选待复证。

- 不谄 = 质直；「直心是道场」（《维摩经》）
- 菩萨爱语 / 同事 / 恒顺众生（四摄，经典）
- 谄梵文 śāṭhya（订正旧桩稿误标 māyā）

### 第二层（框架应用映射）

- **两参数模型（贪对象 × 抓取方式）**= 对经典"离二无别 / 贪痴一分"体性结构的整理性显化
- 覆诳谄三参数表、"对自 / 对他对仗证伪" = 体性分位的整理性观察
- **判准 = 发心（网他 / 利他）**= 经典"险曲为性"的现量落点修正
- 谄痴分落点（实执将来获利想象）= 经典标贪痴一分后路径必然内容的分析

### 第三层（自主推论）

- **障教诲由抓取方式派生**（非独立核）= 修行者现量主导
- **"小随 = 经典根本分 × 发作方式、无独特核"研究纲领** + "无剩余 ⟺ 无核重建五象限边界" = 候选，待 A / C 类撞验
- 痴分双维度厘清（共同底角色 / 内容随所缘变）= 修行者纠正模型混淆后的整理
- **谄常驻动机 = 维持想象可能性保贪念 + 贪种熏习正反馈循环**（取代模型误搬的"即时保全"）= 修行者现量主导
- 表达域反转（调整表达非谄、染污镜像是诳）+ 利他善巧轴输出侧填补（过直→学随顺、发心作护栏）= 修行者现量分诊
- 双重假第五复证、常驻动机第四复证 = 已立候选的持续验证

### 本法元记录 · 模型反复自创非经典衍生议题 + 判准精化

本法讲法 / 讨论阶段，模型连续自起或硬搬不合法议题——① "对自 / 对他对仗"过度建构（被修行者证伪）；② "即时保全"从覆 / 悭硬搬到谄（被现量纠正为熏种循环）；③ "痴 load-bearing 维度"自造一套机制去解释"经典为何此处标痴、彼处不标"（被剥除——它够不上经典衍生：既追溯不到具体经典文句 / 框架，也非讨论路径上必然出现的内容）。

**判准精化**：模型一度把来源约束误述为"看谁打开议题（源）"；修行者校正回**"看议题是否经典衍生 / 修行者诉求，与谁出声无关"**——模型可以另起议题，只要它满足㈠经典衍生（具体经典依据，或讨论路径上必然出现的内容）或㈡修行者诉求。痴 load-bearing 的真违规点 = 够不上㈠，不在"我开的头"。规则在 [CLAUDE.md 学习流程 ①](../../../CLAUDE.md) 已完整（来源约束 + "细微 / 必然出现"界定），缺的是模型落笔前未跑这条已有检验。此为诳"研究议题来源约束"确立后的一次实地复演 + 判准精化。详见 [CLAUDE演化 2026-06-13_研究议题来源约束](../../历史/CLAUDE演化/2026-06-13_研究议题来源约束.md)。

另含两处现量自我校正：① 模型把修行者的结构分析（"用术语显专业 = 诳"）误读成修行者本人的个人现行（"显专业残留"）= 杜撰对用户的归因（纪律 ②），经修行者质问撤回；② 判准一度锁"违心"= 判形式冒充心相，经修行者纠正回"发心"。
