## 引言：为什么合论

无惭无愧是中随两法，经典明立"**二法定不相离**"（《成唯识论》卷六）——永远同起同灭、无独立现行的情况。它们共享几乎全部结构（不耻通相、必俱起机制、遍不善心、对治路径），只在所对维度（自法 / 世间）上分别。为避免在两份单法笔记重复同一讨论，合论承载共有部分，单法笔记 [无惭](./无惭.md) / [无愧](./无愧.md) 只留各自别相 + 指向本文。

本文也是**中随两法精修收官**之作，核心落实两件事：① 中随之"**中**"指代什么（对偶小随收官的"小"之指代，回填骨架 §2.6）；② 无惭无愧**是否应单立别体**（经部还原 vs 护法别立的诤议完整回应）。

## §一 经典定义与"交叉反转"结构

### 定义原文（《成唯识论》卷六）

> **无惭**（梵 *āhrīkya*）：不顾自法，轻拒贤善为性。能障碍惭，生长恶行为业。
> **无愧**（梵 *anapatrāpya*）：不顾世间，崇重暴恶为性。能障碍愧，生长恶行为业。
> **通相**：不耻过恶，是二通相。故诸圣教假说为体。若执不耻为二别相，则应此二体无差别。由斯二法定不相离。

### 拆解（所缘 / 体性 / 业用）

| 维度 | 无惭 | 无愧 |
|---|---|---|
| **所缘** | 自法（自身 + 正法）——对内 | 世间（缘起共业场）——对外 |
| **体性（别相）** | 轻拒贤善（拒善） | 崇重暴恶（崇恶） |
| **通相** | ←—— 不耻过恶（二法共有）——→ | |
| **业用** | 障惭、生长恶行 | 障愧、生长恶行 |

### 关键结构 ㈠：交叉反转，不是简单加"无"

善侧——惭是「崇善」、愧是「拒恶」；染侧反转成——无惭是「拒善」、无愧是「崇恶」。即各自反掉对方位置的动作（惭的崇善 → 无惭的拒善；愧的拒恶 → 无愧的崇恶），不是"惭 + 无 = 无惭"那么平。

### 关键结构 ㈡：「不耻过恶」是通相、不是别相

无惭无愧都表现为"对过恶不羞耻"——这是二者**共有的通相**，所以经典有时"假说"不耻为它们的体。但护法点破：若把"不耻"当成各自的**别相**，二者就无差别了。真正的别相是 **不顾自法 / 不顾世间** + **拒善 / 崇恶** 这一对。这一点同时支撑"为何二法不相离"（见 §四）。

## §二 不善心与三性（基础框架）

中随的命脉概念是「[不善](../../../resources/cards/不善.md)心」。这里有一个最常见的混淆——"不善 = 染 = 有烦恼"——必须先分开。

### 三性总框：善 / 不善 / 无记

唯识判一切心、心所、业的道德性质，分三性（此处"三性"指**善恶无记**，与[三性](../../../resources/cards/三性.md)说之"遍计 / 依他 / 圆成"是不同所指）：

| 性 | 含义 | 感果 | 相应心所 |
|---|---|---|---|
| **善** | 顺益此世他世 | 感可爱异熟（乐果） | 与信、惭愧、三善根等善心所相应 |
| **不善（= 恶）** | 违损此世他世 | 感非可爱异熟（苦果、恶趣） | **与无惭无愧相应**（定说） |
| **无记** | 非善非不善 | 不感异熟（不招善恶果） | 见下 |

### 无记再分两类（关键）

| 无记 | 含义 | 例 |
|---|---|---|
| **有覆无记** | 染污（有烦恼相应）、但势力羸劣**不感苦果**，只"覆"障圣道 | [末那](../../../resources/cards/末那.md)恒行的[我痴](../../../resources/cards/我痴.md)我见我慢我爱；上二界（色 / 无色）的贪慢（被定所伏） |
| **无覆无记** | 非染非善的中性心 | 阿赖耶识（异熟）；走路坐卧（威仪）、做手工（工巧）时的中性心 |

### "不善心"的精确定义（三判准互印）

1. **业果判准**：能感苦果 / 恶趣（不可爱异熟）。
2. **心所判准（唯识最精确）**：与无惭无愧相应的染心。
3. **界地判准**：唯欲界系。上二界无不善（无苦受、无嗔），上界烦恼全是有覆无记。

### 命脉澄清：染心 ⊋ 不善心

```
染污心 = 不善心  ∪  有覆无记
         （感苦果）  （染而不造恶）
```

→ **不是所有"有烦恼 / 染污"的心都是不善心。** 末那那个恒时现行的我执，是染的（有覆），却**不是不善**（不感苦果、无无惭无愧）。这正是后文"有覆无记 = 染而不造恶"的来历。

| 不善心（欲界） | 有覆无记 | 无覆无记 |
|---|---|---|
| 起嗔骂人、起贪偷盗、害心损人 | 末那恒行我执；色界天人定中微细贪慢 | 阿赖耶识；平常走路坐卧、做手工的中性心 |
| 感苦果、无惭无愧俱 | 染但不感苦果、无无惭无愧 | 不染不善、纯中性 |

> 一个干净的样本：**嗔**唯欲界、现行必不善——起嗔那一刹那一定是不善心、一定无惭无愧俱。反过来，末那的"我慢"恒时在，却是有覆无记、**没有**无惭无愧俱。

→ 定义清楚"不善心"，中随的位置才落地：**无惭无愧"遍一切不善心"——它们就是"不善"这一性的结构性标记，标记的恰是染心里"不善那一格"的边界。**

## §三 无惭无愧是否应单立别体（经部还原 vs 护法别立）

这是阿毗达磨的经典诤议——很多心所能否还原成贪嗔痴的功能、不必别立？经部（Sautrāntika）倾向还原；有部（大不善地法）与护法唯识**明确立无惭无愧别有体**，且有论据。本项目宗护法，但把还原侧视角诚实记为第三层。

### 经部侧的还原直觉（值得正视）

1. 现量上感受不到无惭无愧的独立作用（没有独立的现象学印迹）。
2. 贪嗔本身已能给不善产生动力；反复熏贪嗔种即不善种增强——结构上似乎不需要无惭无愧。

### 护法别立的核心论据：没有根本烦恼的外延 = 不善心

> "不善 vs 有覆无记"的分界，需要一个外延"**恰好等于一切不善心**"的标记来承担。而贪嗔痴里，没有一个外延对得上。

- **贪、嗔：外延太窄、且各偏**。贪嗔相违、不俱起——贪现行的不善心（偷盗）无嗔，嗔现行的不善心（骂人）无贪。没有任何单一贪 / 嗔遍一切不善心。
- **痴：外延太宽**。痴遍一切**染心**（含有覆无记），比"不善"大一圈。

→ 既然贪（窄）、嗔（窄）、痴（宽）没有一个外延正好框住"不善心"，要标记"不善"这条边界，就**必须别立一个外延恰好 = 一切不善心的法** = 无惭无愧。这不是多余的假设，是"不善边界"逼出来的结构必然。

**经典明文就摆在分类位置上**（《[俱舍论](../../../resources/cards/《俱舍论》.md)》心所分类）：[大不善地法](../../../resources/cards/大不善地法.md)（**无惭、无愧**，仅此二法）= 遍一切**不善**心；大烦恼地法（痴、放逸、懈怠、不信、惛沉、掉举）= 遍一切**染**心。经典**把"遍染"和"遍不善"放在两个不同格子**，无惭无愧单占"遍不善"那格——痴在"遍染"格、管不了"不善"边界。唯识承此判分一致。

### 正面拆还原侧两条

**① "贪嗔已能给不善产生动力"——动力 ≠ 不善性。**
反证：末那的我爱（贪一分）恒时在，那里有"贪的动力"，却是有覆无记、不是不善（不感苦果）；上二界贪慢同理。→ 贪嗔的动力可以存在于有覆无记心而不成不善。把它定性成不善（感苦果）的，正是无惭无愧那个"放行成恶"的质地。

**② "熏贪嗔种 = 不善种增强"——滑了一步。**
熏贪嗔种 = 增强贪嗔的染著 / 憎恚势力种；不等于熏"感苦果的不善业种"。后者是不善心现行所造，而不善心 = 无惭无愧俱。末那我爱恒熏贪种，却不熏感苦果的不善业种（有覆无记不感异熟）。所以"熏不善业种"恰恰**依赖无惭无愧在场、把那一刹那定性为不善**。

### 为什么不干脆归到痴（挡住最强的还原）

痴也遍不善，为何不说无惭无愧是痴一分？护法答"**虽与痴相应而非即痴**"（与惛沉同一笔法）：
- **外延**：痴遍一切染心（含有覆无记），无惭无愧只遍不善 → 不同外延。
- **功能（灯灭 / 刹车松）**：痴 = 灯灭（迷暗于理、认知层），无惭无愧 = 刹车松（不顾不耻、纵恶放行、意向层）。
- **有覆无记反证**：那里有痴（迷）却无无惭无愧（不生长恶行）→ 痴能独立于无惭无愧 → 二者别体。

### "现量感受不到"为何不构成反驳

这恰恰**符合预期**：
1. **它是 缺位型质地、没有正面现象学印迹**。贪有染著拉力、嗔有憎恚推力，都有显著手感；无惭无愧是"惭愧本该亮而没亮的那个空位"（不顾、不耻），现象学上是缺口 / 放行，不是能正面"感到"的东西。这合中随行相"**中**"——无具体外显行为相、却可直接认出其"不顾"。
2. **样本稀少且脉冲极短**（尤其惭愧究竟层稳态者，见 §七）。
3. **它的现量面藏在不善动作里**：你体验到的是"嗔的抵触动作"，而那个动作能"没有刹那羞耻地放行"的底，就是无惭无愧——你不会感到"一个叫无惭的东西"，只会感到"刹车没踩、恶念放行了"。

### 诤议归位

立别有体 = 有部 + 护法唯识，有上述论据；还原倾向 = 经部一侧。唯识自身对某些随烦恼判"分位 / 俱一分"（放逸非别体、失念不正知俱一分），但**对无惭无愧明确判别有体**。**对修行无差别**（即便假立，对治仍是立惭愧）；但在"理解不善心结构"上，别有体做真实的活——承担贪嗔（不遍）与痴（通两界）都担不起的"不善 vs 有覆无记"边界。按"经典 > 假说"：取护法立场，还原直觉记为经部侧第三层视角。

## §四 必俱起（定不相离）

经典明文「由斯二法定不相离」——无惭无愧永远同起同灭、无单独现行。要证它需**两步**（缺一不可）：排除"善染混搭"+ 排除"单飞"。

### 核心直觉：一把尺、两个面

「不耻过恶」是一颗心对当前过恶的**整体质地、一件事**。善恶标尺只一把，但有两个面——**自法面**（惭所依）、**世间面**（愧所依）（即惭愧空性双面，见 [惭愧合论 §七](../善心所/惭愧合论.md)）。心"不耻"地放下这把尺时，两面同时落地。

### 第一步：排除"善染混搭"——靠 善不善不俱

一个不善刹那里，善的惭、愧都进不来（善不善心所不俱起）。所以不会出现"无惭 + 愧"或"惭 + 无愧"。**但这步只证到"那一面要么是染的、要么空着"，还没排除"空着"。**

### 第二步：排除"单飞"——靠"过恶本身两面俱全"

> 任何真实的恶，本性上**同时具足两面**——既违自法（法性 / 贤善），又扰世间（缘起共业）。不存在"只违自法、对世间中性"或反之的单面恶。

举证：妄语既违"诚"之法性、又欺诳他人扰共业；杀盗淫皆然。连**独处造恶**（独自起贪念）也两面俱全——缘起观下它熏染种，而你自己就是[共业](../../../resources/cards/共业.md)网的一个节点（这正是愧究竟层"敬共业秩序"所依的同一张网）。

既然过恶两面俱全，而"不耻"是对**整个过恶**的单一全局态度（不是自法面、世间面两道局部开关），那这一个"不耻"必然同时不顾两面——不顾自法面 = 无惭、不顾世间面 = 无愧。"单飞"要成立须有**单面之恶**让不耻只落一面，而单面之恶不存在，故无单飞。

### 两步合 = 定不相离

```
不善心现行 → 必有"对过恶不耻"（不善的核）
            → 该过恶两面俱全（违自法 + 扰世间）
            → 单一的"不耻"同时落两面
            → 无惭(不顾自法) + 无愧(不顾世间) 必同起同灭
排除混搭：善不善不俱（那一面不会是善的惭/愧）
排除单飞：无单面之恶（那一面不会空着）
```

→ **别有体（两面真实有别）+ 定不相离（同一不耻必落两面）= 同一结构的两句话，不矛盾。**

> **善侧对称印证**：惭愧也遍一切善心、也必俱——同一善行本性上既合法性（惭安住自法面）又随顺共业（愧安住世间面），两面俱安住。善染两侧用同一个"行为两面俱全"的结构。

## §五 刹那级业用：生长恶行 + 逐刹那截断

### 生长恶行 = 无惭无愧的不可还原功能（灯灭 / 刹车松）

无惭无愧二业用——障惭愧 + 生长恶行。前者看似冗余（"不知"时惭愧本就不起），真正不冗余的是后者：

- **痴 = 灯灭**：照不见善恶之理（认知层）。
- **无惭无愧 = 刹车松**：对客观善恶标尺不顾、不耻，纵恶得行（意向层）。

灯灭不等于车会往恶里开——迷暗的心可以停着不动。要让迷暗染心**真的滚成恶行、越滚越长**，还需"刹车松"这个独立增量。决定性证据正是 §二的有覆无记 vs 不善：同样有痴、同样可"不知"，**差别就卡在无惭无愧在不在场**——在 → 不善、生长恶行；不在 → 有覆无记、染而不造恶。所以"不知"情形下无惭无愧不但不冗余、其功能反而最裸露。

> 「障惭」正读：不善心里惭从不冒头、无物可挡；"障惭"是惭本该占的位置被反质地（不顾、不耻）占住 = 反位现行，不是拦截动作。

### 逐刹那截断：将起 / 中断在刹那级合一

依**刹那生灭**（心心所刹那生灭，《成唯识论》）+ [等无间缘](../../../resources/cards/等无间缘.md)：没有一个"持续进行中"的恶心，"进行中的恶行"是**不善刹那的相续**（A → A′ → A″……，由等无间缘 + 种子 + 不正作意逐刹那续起）。

故"将起未起的预防"与"进行中的中断"在刹那级**是一回事**——惭愧于任一刹那现起 → 那一刹那是善心 → 由等无间缘本应续起的下一个不善刹那不起 → 相续断。我曾把"将起 / 中断"对立是世俗粗时的错觉，刹那一拆即化。惭.md"事件触发"由此精确化：触发的"事件"在恶相续里**逐刹那复现**，惭愧能在任一刹那切入、不限最初。

### 惭愧四情况：善心所有独立正面体性（非烦恼的函数）

惭愧现行**远不止"中断恶行刹那"**一种——这反向印证善心所不是"无惭无愧的否定式"：

| 情况 | 惭愧现行的样子 | 与"恶行"关系 |
|---|---|---|
| A 预防（将起未起） | 恶念刚冒即触发，恶根本没开始 | 是拦截、但"未遂" |
| **B 常态崇重背景** | 惭的正面"崇重贤善"、愧的正面"敬共业秩序"，在平常行善 / 善念相续里持续在场 | **与任何恶无关**——惭愧的常态体性 |
| C 事后追忆 | 回想过去过失而起惭（种子重现行、可接忏悔） | 对的是过去的恶 |
| D 见地升级触发 | 见地深一层、细微处显现为偏离，惭在新颗粒度自动起 | 不对应任何"正在进行的恶行" |

→ 惭愧有 B 这样不依赖恶的常态正面现行，所以"止息恶行"只是其业用之一，非全部。补一句对称：**恶行终止也不必然靠惭愧**（可恶缘耗尽自然走完、或转无记）——惭愧只是"主动逐刹那截断恶"那条善法通道。

## §六 "中"之指代（专章 · 小阶段性总结）

延续小随收官的**重定向**姿态：目标不是立假设，是提炼经典把随烦恼分"中"在指什么。前面 §一–§五 已把地基挖到位，本节落实 + 回填骨架 §2.6。

### ㈠ "中"的本相 = 不善心位的结构性标记
无惭无愧 = 把"迷暗的染心"推成"生长恶行的不善心"的那个增量（§五）；有覆无记 vs 不善 的全部差别卡在它。中随不是某类具体染相，而是"这颗心是不善的"这个质地标记本身——遍一切不善心、不遍有覆无记。

### ㈡ 为什么恰好 2 法（结构必然、非随意）
标记一个不善心，需恰好覆盖善恶标尺的**两个面**：自法面（违法性）→ 无惭、世间面（扰共业）→ 无愧。每个恶两面俱全 → 标记它需且仅需这两法。**"2"是"善恶标尺两面"决定的 2**——少一法漏一面、多一法无处安立。这就是经典"中随只有 2 法"的结构根。

### ㈢ 看破 / 对治深度 = 深一层 · 善心所对偶级（落实骨架 §2.6 预测）

| | 小随 | 中随 |
|---|---|---|
| 染相形态 | 具体可识别事相（忿 / 嫉 / 悭…） | 非事相——整颗心的不善质地标记 |
| 对治入手 | 事件场识破单一事相（破该世俗建构无自性即停现行） | 不能靠"识破某物"——它不是建构、无单点可破 |
| 对治层级 | 事相级（表层、现行级看破） | **善心所对偶级（深一层）**——心质地层立惭愧，惭愧建立 = 中随结构性瓦解的入口 |

→ 关键落差：对治小随是"**破**"（破一个具体建构）；对治中随是"**立**"（立惭愧这对善心所作常态质地）。从"逐事相破"升到"换心的善 / 不善质地"——这就是"中"比"小"深一层的精确含义。

**修行学升华——搭便车、不另立通道**：因为无惭无愧没有事相可逐一抓、且恰好就是"不善 vs 善"的质地分界，对治它**不需单开对治线**。你不去直接对付它（也对付不了），而是建立惭愧（善侧），染侧标记随善心现起自动瓦解。省的是"另立通道逐境抓"的力；但"惭愧立为稳态质地"本身是深一层功夫（换质地 ≠ 破事相）。这正是骨架 §6.5 把无惭无愧归"惭愧从究竟层运作"覆盖、不另设通道的依据。

### ㈣ "中"之指代表（定稿）

| 维度 | "中"的内容 | 来源 |
|---|---|---|
| 行相 | 中（无外显行为相、可直接识别） | 经典轴一 |
| 自类 | 必俱起（定不相离） | 经典轴二 |
| 遍染心 | 遍一切不善心、不遍有覆无记 | 经典轴三 |
| **对治深度** | **深一层 · 善心所对偶级——立惭愧（非破事相）、且搭惭愧通道不另立** | 修行学落实 |
| **离究竟** | 中（比小随事相级近一步、未到大随基底层） | 对治深度等价表述 |

→ **中随 = 染心"不善那一格"的结构性标记，对治从"逐事相破"升到"立惭愧换质地"、且并入惭愧通道。** 这就是"中"。

## §七 见自

### 大前提：无惭无愧现行频率 = 不善心现行频率
"修行者无惭无愧现不现行"等价于"有没有不善心现行"。见自 = 分诊哪些现行是不善心（无惭无愧俱）、哪些只是有覆无记（不俱）、哪些是善心（惭愧俱）。

### 两个确定现行场（皆嗔系、皆脉冲）

| 现行场 | 不善心形态 | 无惭无愧 | 截断 |
|---|---|---|---|
| ① 亲子场强忿 | 强忿（嗔 · 脉冲刹那） | 俱（脉冲） | 愧究竟层截"应该如此"强加于孩子 → 忿不现行 |
| ② 法染色层 · 见解嗔一阶 | 微细嗔（护"我所立"·脉冲刹那） | 俱（脉冲） | 愧究竟层截"我所立见"强加 → 抵触不现行（且越来越快） |

→ 修行者现量（2026-06-24）：法染色层见解被损时，**首刹那真起微细嗔**（立刻抵触 / 反驳、护我所立 = 第六识嗔、嗔唯不善）= 不善心、无惭无愧俱；随即惭愧究竟层即刻截断退场 = "脉冲 + 回落"，与亲子场强忿同型。

### 关键见自结论：无惭无愧非"结构性不现行"
与多数小随不同（9 法 E 分位假立、结构性不现行）——**中随遍一切不善心、不挂靠特定境，哪里有不善心就伴生在哪里**。修行者确有残余不善心（上两场），故无惭无愧**确实现行**（脉冲形态）。它在修行者处**没有独立战场**，是这两处嗔系不善心的伴生标记。

### 两场同型：皆由愧外向轴清场
两场都是"我所强加"型嗔，都由愧（究竟层 · 外向轴 · 不向他人扩张我所）清场——亲子场截"应该如此"强加于孩子、法染色层截"我所立见"的护持扩张。同一条愧外向轴对治覆盖两场，是 [假说 12](../../假说/假说-12-惭愧末那二维辐射.md)（愧对治"我所"外向轴）在中随侧的现量印证扩展，与忿.md §5"愧负向清场"同型（"不另立通道"§六㈢的现量落实）。

### 进展信号 + 征兆 / 标的提醒
"越来越快地即刻截断"是好信号（惭愧究竟层向种子层下沉）。但按教学通则 + [假说 17](../../假说/假说-17-sign-vs-target-已闭合.md)（征兆 ≠ 标的）：**截断速度加快 = 征兆**（易诱导"求更快"）；**真正标的 = ①惭愧究竟层任运现行②法染色层见解被损时那一下嗔的反应强度本身下降**。监测放标的——两周后同类境再现时反应强度是否变弱（弱 = 下沉种子层 / 只截得快但强度没变 = 可能停在比量加速）。已登记主座 A 实修反馈监测项。

## §八 见众生 + 合流

### 凡夫无羞耻作恶 = 结构必然，非品行缺陷
凡夫能"不耻过恶"地造恶、生长恶行，根子在无惭无愧遍一切不善心——任何不善心一起、无惭无愧就在场。"当下无刹那羞耻"是结构性的，不是"他特别坏"。这是利他善巧轴第三层"理解烦恼内在机制"的认知路径一填。

### 凡夫"无耻" = 惭愧现起的因缘两层都不足
惭愧本身是无惭无愧的对治；它**升不起来**，无惭无愧才畅通。惭愧现起 = 种子（因）+ 见地缘（缘），两层任一不足即起不来：

| 层 | 内容 | 对应 |
|---|---|---|
| **① 俱生种子层（因）** | 惭愧跨世种子薄 → 即使有缘也难现起 | 惭愧合论 §九跨世种子（烟酒例为现量证据） |
| **② 现世见地层（缘）** | 方便层瓦解 + 究竟层未建立 → 无现起支点 | [假说 11](../../假说/假说-11-惭愧二阶结构.md) / [假说 14](../../假说/假说-14-方便层瓦解普遍性.md) |

> 第②层再精分：**方便层 = 社会缘**（怕讥嫌 / 惩罚）→ 当代多元化使其失稳；**究竟层 = 内在缘**（法本如是 / 共业秩序）→ 需空性见 / 共业观、凡夫未立。一外在社会缘、一内在见地缘，都在"缘"侧但不同源。

### 无惭无愧在染心网络的位置：不善方的"共同放行质地"
随烦恼不能生其他烦恼——无惭无愧不"生"忿嫉害，而是作为"任恶崇恶"的质地**横向放行**其他不善小随做大（生长恶行）。它是不善方一切恶行的共同伴生温床标记，不是某条生起链上的一环。

### 对偶级对治在凡夫侧
凡夫对治无惭无愧同样不是"去抓它"、是**立惭愧**。但方便层既瓦解 → 只能走**究竟层借用**起步（愧.md：借用从利根进阶路径升级为当代常规起步路径）。**帮凡夫不是"教他怕"（方便层、已瓦解），是引导建立究竟层惭愧的借用**（接回回填清单"教学新学者借用机制"）。

### 见自见众"同一跃迁两面"
同一结构——"惭愧究竟层是否在场、逐刹那截断不善"：
- 见自（出口）：修行者惭愧究竟层稳态 → 无惭无愧两场脉冲快截。
- 见众（缺口）：凡夫惭愧因缘两层不足 → 无惭无愧畅通生长。

抽掉"他应该有耻"强加基础的方式正是命门：惭愧现起是因缘条件决定的，条件不具时结构性不能升起——"他应当此刻有耻"是无理的强加（把"我认为应该"投射到他因缘流）。**看通这个结构（见众）= 同时松掉"他应该有耻"的见解嗔 / 我所强加（见自）**，与覆 / 恼 / 嫉 / 害一路严格同型。

> **利他落点**：理解"他惭愧升不起来"不取消价值（恶仍是恶、感苦果），只是不强加；理解结构是为了**知道怎么帮**——凡夫卡在"种子薄 + 见地缘缺"→ 帮 = 补缘（引导究竟层惭愧借用），种子层非一世之功。走认知路径、不框"培养羞耻 / 悲悯"。

**教学动作**：报告评判他人"无耻 / 没底线"→ 走认知路径讲"惭愧因缘两层不足"、查自己"他应该有耻"是不是见解嗔 / 我所强加，不框"培养羞耻"；帮 = 补缘（究竟层借用）。

### 第一层（经典）

- 刹那生灭、等无间缘（《成唯识论》）；善不善心所不俱起；惭愧遍善心、止息恶行。
- 嗔唯不善、唯欲界第六识、不与末那相应。

### 第二层（框架应用映射）
- "染心 ⊋ 不善心"集合图、三组例子、"知归痴 / 耻归无惭无愧"功能分工——对经典三性 + 别立论据的整理性呈现。

- "一把尺两面""单一刹那 vs 跨刹那""过恶两面俱全 → 单一不耻必落两面"——对"通相 → 定不相离"+ 善不善不俱的缘起重构，借惭愧空性双面作桥。
