> **类别**：心所法 > 随烦恼心所 > 小随烦恼（经典顺序第三法）

## 一、经典概念（闻）

### 定义原文

[《成唯识论》](../../../resources/cards/《成唯识论》.md)卷六：

> 云何为覆？**于自作罪**，**恐失利誉**，**隐藏**为性。能障**不覆**、**悔恼**为业。谓覆罪者，后必悔恼，不安隐故。

派系诤议明文（同卷）：

> 有义（[安慧](../../../resources/cards/安慧.md)）：覆**唯痴一分**摄，论唯说此痴一分故。
> 有义（[护法](../../../resources/cards/护法.md)，本论采用）：覆是**贪痴一分**摄，亦恐失利誉、覆自罪故；论据粗显，唯说痴分。

[窥基](../../../resources/cards/窥基.md)《百法明门论解》从护法："贪痴一分为体"。（梵语 mrakṣa。）

### 体性拆解

| 项 | 内容 | 与嗔系前法（忿恨恼）的关键转换 |
|---|---|---|
| **所缘** | **自作罪**——自己已犯、已发生的过失 | 忿恨恼缘**他 / 违境**（向外）；覆缘**自身已作之罪**（向内）|
| **体性** | **隐藏**（覆藏遮掩、不令人知）| 忿是发出、恨是怀怨储存；覆是**遮掩** |
| **业用** | 能障不覆；**悔恼**——覆罪者"后必悔恼，不安隐" | 主要伤的是自己（与恨"恒热恼"同类、机制不同）|
| **所障** | 不覆（坦诚发露——无独立善心所别体，障的是惭愧 / 无贪无痴的发露功能）| — |
| **本体** | 贪痴一分（恐失利誉=贪分 / 不知覆招重苦=痴分）→ **E 分位假立** | 忿恨皆**瞋一分**；覆是**首个换根**的小随 |

### 三个"覆独有"的锚点

1. **所缘首次转向自身**：忿 / 恨 / 恼 / 嫉所缘皆"他 / 违境"，覆是小随中**第一个所缘 = 自作罪（向内）**的法。覆不是面对罪的反省，是面对"罪被知道"的防御——发动机是"**恐失利誉**"（怕罪暴露后失利养名誉），不是怕罪本身。

2. **首个跨出嗔系 + 首个有内部体性诤议**：前两法忿恨皆瞋一分，覆 = **贪痴一分**（换根）。且覆是小随 10 法中**第一个体性有派系诤议**的法——安慧立"唯痴一分"、护法立"贪痴一分"（本论从护法）。诤议焦点：贪分（恐失利誉）是否真在场。

3. **"悔恼为业"= 对内自苦**：覆的业用方向**对内**——覆罪者"后必悔恼，不安隐"。与恨"恒热恼"呼应（都是对内自苦），但**机制不同源**：恨的自苦 = 反复重新结怨续命；覆的自苦 = 罪未忏净 + 怕暴露的持续不安隐。两种自苦不要并成一类。

## 二、与相邻法的辨异

**覆 / 嗔系（忿恨恼）——体性 + 所缘双重换根**：忿恨恼是瞋一分、缘他境；覆是贪痴一分、缘自罪。经典顺序到覆是第一次"换根"，从瞋系向外发作 / 怀怨，转到贪痴系向内遮掩。

**覆 / [诳](./诳.md) / [谄](./谄.md)——同涉"不实"，三种结构不同**：

| 法 | 所缘时态 | 动作 | 一句话 |
|---|---|---|---|
| **覆** | 过去**已作之罪** | **藏**（消极遮掩）| 藏已有之恶 |
| **诳** | 现在**未有之德** | **矫现**（积极伪造）| 诈现未有之德 |
| **谄** | 对**他人** | **曲顺**（罔他 / 网住）| 曲意奉承以网他 |

→ 覆是"减"（把已有的罪盖住），诳是"加"（把没有的德装上），谄是"曲"（顺着对方织网）。

## 三、主线 1：体性机制（贪痴一分 + 障忏悔 + 三段接力）

### 3.1 痴分三层——不止"后果之痴"（修行者现量延伸）

经典明文的痴分窄（**第一层**）：「不顾后世苦」「不知覆招重苦、发露能净罪」= 世俗谛之内的**后果之痴**。修行者现量指出痴还罩在"罪"概念本身上——唯识框架直接支持（一切烦恼皆无明所遍；"罪 / 利誉 / 负罪的我"实有皆遍计所执；经典自身在究竟层立"罪性本空由心造"）：

```
覆的痴 ── 三层 ──
  浅（世俗谛内）：不知覆藏招更重苦、不知发露能净罪      ← 经典明文
  中（所缘实执）：执"罪""利誉"为实有                    ← 修行者现量延伸
  深（能负罪我执）：执"负罪的我"为实有 = 根本无明         ← 修行者现量延伸
```

护法立"贪痴一分"时，**贪分（恐失利誉）已预设利誉实有**——经典在体性结构里已暗含中层实执，修行者只是把这条暗线显化。

### 3.2 所缘的三层前提栈——覆的非究竟性

覆要现行，须先成立三层前提，**抽掉任一层覆即无处可挂**：

```
① 有"罪"这回事（世俗道德 / 业果的认定）
② 这罪是"我"作的（我执负罪者 + 主观认定者）
③ 暴露会"失利誉"（利誉实有、可贪、值得护）
── 三层全是世俗谛 + 我执脚手架
```

注：覆所缠的是**他自己认定的罪**，认定因人而异、未必合世间通行的礼法道德。这正暴露覆所缘的非究竟——它建立在一层世俗概念 + 我执脚手架上（接 [小随"双重假"候选](#六结构关联)：体上分位假立 + 所缘上世俗概念假立）。

### 3.3 障"不覆"→ 自苦闭环

覆障的"不覆"不在善心所 11 内、无独立别体——**障的是惭愧 / 无贪无痴在事上的"发露功能"**。业用因此是一个闭环：

```
自作罪 → 覆（藏）→ 障不覆 = 堵死发露出口
            ↓
   罪无从忏净（留种）+ 怕暴露的持续不安隐
            ↓
   「后必悔恼，不安隐」= 悔恼为业（对内自苦）
            ↓
   悔恼又成新的"不愿面对" → 更藏（闭环自续）
```

### 3.4 覆 ↔ 惭愧对照 + 三段接力对治（现量印证护法"贪痴一分"）

覆与惭愧是**同一个"面对自作罪"岔路口的两条相反出路**：

| | 覆 | 惭愧 |
|---|---|---|
| 动作 | **藏** | **露**（发露）|
| 所依 | 恐失利誉（世俗谛实执）| 本来不应如此 / 敬共业秩序（究竟层）|
| 对罪 | 留罪自苦 | 露罪可净 |

修行者位置的**三段接力对治序列**（现量自陈）——"藏"念一起到松开，是三段顺序：

```
① 惭·感应器（先）  ── "藏"念一起 → 本能不适（"像闻到烟味般"，先于慧分辨）── 检测 / 亮灯
② 无痴（中）       ── "藏也没用，在那儿藏着改变不了什么" ──────────────── 拆理由
③ 无贪（后·必需）  ── "就算失了那个利誉也没什么大不了" ─────────────────── 真正松手
```

**两个关键产出**：

- **感应器先起是共性、具体哪一臂依法不同**：忿用愧（上游截扩张）、覆用**惭**（对自作罪不诚、本应发露而藏 = "本不应如此"的本能不适）。"像闻到烟味般不适"正是画像里记的跨世惭愧种子签名（天然抗拒烟酒、味觉 / 身体直接反感）。[假说 10](../../假说/假说-10-惭愧触发感应器.md)（惭愧 = 事件触发感应器、看穿预载、先于慧）跨到覆再确认。
- **无贪收尾必需 = 现量印证护法"贪痴一分"、否安慧"唯痴"**：若覆真是安慧"唯痴一分"，看破（无痴）到位覆就该散、不需无贪收尾；但修行者现量上**无贪收尾是必需的**，因俱生贪（利誉）真在生效、是"想藏"一闪的真正动力源。→ **贪分真在场真生效 ⟹ 现量从修行者位置独立印证护法立场**。

## 四、见自维度（修行者位置现量分诊）

### 4.1 分别覆塌 + 俱生覆动意一闪不成操作

骨架 §六主线 2 预判覆"结构性不现行"，修行者现量把它**修细一层**——不是"动意都不起"，是"**动意一闪、不成操作**"：

| 层 | 覆的状态 | 现量 |
|---|---|---|
| **分别层（认知层）** | 前提栈②③塌、**结构性不现行** | "修行人形象 / 已无我相 / 看破"在认知层**真挂不上** |
| **俱生层** | 护我所反射仍在——"**想隐藏**"一闪现行，但不成操作 | 能真实体验到"想这样做的感觉"，一闪而过；记忆中没有真正做出隐藏操作 |

→ 分别覆（依世俗概念前提栈）死了；俱生覆（护我所的一闪动意）种子还活着，被触即闪，但**走不到"藏"的操作**。拦截点落在"**想隐藏意愿 → 隐藏操作**"之间——和忿"动意起后不入业"、恨"归因改道抽所缘"是**同一族的上游截断**。

### 4.2 分别层前提栈是被"主动拆"、不是默认空缺

"修行人形象 / 看破"挂不上是**究竟层在运作**，不是恰好没有：

- "**看破永远是对自己的**——放得下就是看破，放不下就是没看破，别人认不认可毫无价值"= **无贪（利誉不可贪）+ 无痴（看破对自己）在认知层**直接拆掉②③前提。
- "**说人话、尊重共业**"= **愧在认知层主动清场**（画像已记"B 类细颗粒愧扩展到认知层：按对方理解框架调整表达"）。

→ 三善根 + 愧在认知层联合**主动拆**前提栈。这也连带使 §3.3 自苦闭环在修行者位置**不闭合**——闭环要"完成的藏"才转得起来，操作不成，悔恼无从生。

### 4.3 见自侧闭合

覆在修行者位置 = **分别覆塌（认知层无贪无痴 + 惭主动拆前提栈）+ 俱生覆动意一闪不成操作（惭感应器→无痴→无贪三段接力截断）**；俱生贪真在场 = 现量印证护法贪痴一分。

## 五、见众生维度

### 5.1 覆不现行须三段全断——顽固度是乘积（修行者现量）

覆要现行到"隐藏操作"完成，须惭感应器、无痴、无贪**三段全部被截断**才不发生；缺一段，覆就能做完。**顽固度 = 三段难度的乘积、不是某一段特别难**：

| 段 | 凡夫 / 孩子为何难断 |
|---|---|
| ① 惭·感应器 | **没有俱生惭种子，就根本不觉得藏有什么不舒服** |
| ② 无痴 | 哪怕只从**世俗**（非世代因果）看穿藏的后果都极难——藏后不能安心 / 信用的长期复利价值（一谎需无数谎掩盖、成本得不偿失）/ 不自欺才是成长前提；**而这些根本不是一个不到 10 岁孩子的认知能装下的** |
| ③ 无贪 | **只要放不下贪，覆就一定存在**——贪是覆的真正动力源 |

→ 凡夫**三段同时具足**几乎不可能，孩子**三段几乎全缺**——所以"反复藏"对孩子是**结构性必然**，不是品行问题。

### 5.2 覆的"常驻动机"结构（第一层现量 → 第三层结晶候选）

> **覆的常驻动机 = 有贪（可护内容）+ 露则失 + 藏有非零保全概率。** 三者齐备，覆即有"站着不走"的动机，无须每次重新发动。

对孩子：每次藏过失后总有一定机会保住他贪的内容——这个**非零保全概率是间歇强化器**，每保住一次就熏厚一次覆种。这解释了"为什么**反复**"——不是不长记性，是藏偶尔真能成功、**间歇强化最顽固**。（**第三层·自主推论**，已记 CLAUDE.md「当前阶段未处理内容」待小随复证。）

### 5.3 亲子样本——见解嗔与覆机制在此合流（见自见众同一跃迁）

覆是修行者亲子场高频现行场（孩子覆藏问题"特别重"）。修行者自身对覆**几乎无感** + 清楚看到后果严重 → 对孩子**训斥严厉** = **见解嗔现行重场**。机制看通后，反过来抽掉见解嗔的根：

- 训斥的隐含前提 = "**他应该不藏 / 应该懂**"= [嗔事件层操作核](../../教学操作核/教学操作核-02-嗔事件层.md) 触发点 2 最深层"对他人应该如何的强加"。
- 但孩子**结构性三段皆缺**，"他应该不藏"**根本不是缘起如实见**，是"我无感所以以为人人都该无感"的比量强加。
- **如实见孩子（三段皆缺）→ "应该"的强加基础被抽掉**——与 [恨.md §4.1](./恨.md)"归因改道抽所缘"同一招。**理解孩子的覆机制（见众）= 同时松开自己的见解嗔（见自）**，又一次见自见众同一跃迁两面。

→ 这是利他善巧轴在百法内的又一现量填补：从"不理解孩子为何反复这么做"到看通三段机制，走的是**认知路径**（非悲悯热质地），与恨场立的"见众生线 = 学烦恼底层机制"一致。完整善巧行法（怎么帮孩子）属四摄 / 方便波罗蜜、百法外待菩萨道；本法只把**诊断**给全。实修追踪见 [生活修对治案 003](../../实修/logs/生活修日志/2026-06-亲子场孩子覆藏与我的见解嗔.md)。

## 六、结构关联

- **E 分位假立（贪痴一分）**：覆 = 贪痴在"覆藏自罪"分位的假立名，无独立别体；首个跨出嗔系、首个有内部体性诤议（安慧唯痴 / 护法贪痴）的小随。
- **小随"双重假"候选**：体上分位假立（无别体）+ 所缘上世俗概念假立（"罪"是世俗道德 / 业果认定 + 我执脚手架）——覆是这条候选结晶的第一个样本（已记 CLAUDE.md 待小随复证）。
- **生起次第**：骨架 §七 凡夫染心链"恨 → 覆（因恶恐失利养 → 隐藏）→ 恼"中的一环。
- **善心所接续**：覆 ↔ 惭愧（藏 / 露）正面对偶；三段接力对治 = 惭感应器（[假说 10](../../假说/假说-10-惭愧触发感应器.md)）→ 无痴 → 无贪，无贪收尾必需 = 现量印证护法贪痴一分。
- **嗔操作核接续**：亲子场覆 → 见解嗔（触发点 2"应该强加"），见众如实见抽掉强加 = 见自见众合流，同 [恨.md §5](./恨.md) 归因改道族。

## 七、学术诚实三层标注

**第一层（经典）**：覆定义原文（于自作罪 / 恐失利誉 / 隐藏 / 不覆 / 悔恼 / "后必悔恼不安隐"）；安慧"唯痴一分" / 护法"贪痴一分"两家诤议明文；窥基《百法明门论解》"贪痴一分为体"；痴分明文 = 不顾后世苦 / 不知覆招重苦；"罪性本空由心造"（究竟层罪无自性，经典立场）。

**第二层（框架应用映射）**：覆 / 诳 / 谄"减 / 加 / 曲"三结构整理；痴分三层（后果之痴 / 所缘实执 / 能负罪我执）= 无明遍染 + 遍计所执框架的延伸；所缘三层前提栈；障不覆自苦闭环图；覆↔惭愧"藏 / 露"对偶；三段接力对治序列的框架命名。

**第三层（自主推论）**：痴分中层 / 深层（罪概念实执 + 负罪我执）作覆所缘非究竟的判定；"无贪收尾必需 ⟹ 现量印证护法贪痴一分"的派系校准；分别覆塌 + 俱生覆动意一闪不成操作的见自分诊；**覆"常驻动机"结构**（贪 + 露则失 + 藏有保全概率，间歇强化最顽固）= 候选结晶待小随复证；顽固度 = 三段难度乘积；"小随双重假"候选；见解嗔"应该强加"被见众如实见抽掉 = 见自见众合流——均属修行者位置现量分诊产出，状态为"与唯识框架内在一致的现量报告"。
