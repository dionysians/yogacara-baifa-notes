# 嫉

> **类别**：心所法 > 随烦恼心所 > 小随烦恼（经典顺序第五法）
> **五象限归属**：E 分位假立（瞋一分）
> **对治通道**：小随通道 → 究竟收于无痴双线（了无自性锚照破"排名无自性"）；随喜 / 喜无量心正面对治
> **学习日期**：2026-06-12（子阶段 2 · 随烦恼单法精修第五法 · 首个离开嗔系"违境链"、起于他荣境的小随）
> **骨架**：[随烦恼整体认知](./随烦恼整体认知.md)

## 一、经典概念（闻）

### 定义原文

[《成唯识论》](../../../resources/cards/《成唯识论》.md)卷六：

> 云何为嫉？**殉自名利**，**不耐他荣**，妒忌为性。能障**不嫉**、**忧戚**为业。谓嫉妒者，闻见他荣，深怀忧戚，不安隐故。此亦瞋恚一分为体，离瞋无别嫉相用故。

[窥基](../../../resources/cards/窥基.md)《百法明门论解》：嫉者，嗔之一分，殉自名利、不耐他荣、妒忌为性。（梵语 īrṣyā。）

### 体性拆解

| 项 | 内容 | 嫉的独有处 |
|---|---|---|
| **所缘** | **他荣**——他人的荣盛：名利、地位、才能、称誉、福报、眷属……凡他人胜己 / 优己之处 | 嗔系前四起于**违境**，嫉起于**他荣（顺境）**——首个所缘从"违我者"转向"胜我者"的小随 |
| **体性** | **妒忌**——三段链：①「殉自名利」（殉 = 以身命相殉，执自名利如命）→ ②「不耐他荣」（他荣反衬己劣，不能忍）→ ③ 妒忌现起 | 体在瞋（不耐 = 违逆相），但根写明在贪（殉自名利）|
| **业用** | **忧戚 / 不安隐**——令**自心**忧苦热恼、失寂静 | 业用落在**自苦**（不是害他；虽可引生害行，但体性业用本身是自忧戚）|
| **所障** | 障**不嫉**——障"见他荣而欢喜（随喜 / 喜无量）"的安隐态 | — |
| **本体** | 瞋一分（离瞋无别相用）→ **E 分位假立** | 同股瞋种；**无内部体性诤议**（覆有安慧 / 护法之争，嫉回到嗔系纯瞋平地）|

### 三个"嫉独有"的锚点

1. **根在贪、相在瞋**：嫉的动力源是贪（殉自名利），但现行体相是瞋（不耐他荣）。经典据**现行相**判它为瞋一分，不据根源判为贪一分——这是"贪是它的根、瞋是它的现行面"的典型一法（§3.2 详）。

2. **顺境被我执读成逆境**：嫉脱离忿恨恼"违境链"的机关。前四法的逆境是**境本身违我**（现前 / 过往不饶益），嫉的"逆"纯是**我执对一个顺境的二次加工**——他荣本是好事，"殉自名利"这把尺把它量成了"我损"。

3. **究竟根是我痴**（本次精修逼到底）：连"我他对比 / 排名"本身都是不实——**排名是比较心的产物（想比则有、不想比则无），不是境里天然之物**。所以嫉究竟收于**我痴**（立实我中心 → 造比较 → 默认"别人有 = 我损"）。结构归属仍是瞋一分（不改体性），我痴是它的**究竟所依根**（§4.3）。

## 二、与相邻法的辨异——嗔系所缘的断点

| 对比 | 嫉 | 对照法 |
|---|---|---|
| **与 忿恨恼**（嗔系前四） | 起于**他荣境**（顺境被我执读成逆）| 忿恨恼皆起于**违境**（现前 / 过往不饶益境）。嫉是小随中第一个把所缘从"违境链"断开、转向"他境"的法——嗔系对境从「违我者」扩展到「胜我者」|
| **与 [悭](./悭.md)**（下一法 · 常并提"悭嫉"）| 于**他荣不耐**（瞋一分 · 憎他得）| 悭 = 于**自财法吝惜不舍**（贪一分 · 守自有）。一个憎外 / 一个守内，同根于自我中心的得失计较 |
| **与 [慢](../烦恼心所/慢.md) / [憍](./憍.md)** | 「他胜我」→我执受挫→不耐 | 慢 =「我胜他」→高举；憍 = 染著自盛（未必对比他）。三者都依**我他对比**，是同一底层的三个朝向（§4.4）|

## 三、主线 1：体性机制（三段链 + 反转 + 根在贪相在瞋）

### 3.1 三段链与反转点

```
殉自名利 ──→ 不耐他荣 ──→ 妒忌(忧戚)
 (根·贪)      (反转点)     (相·瞋)
```

1. **殉自名利**（根）——把自我价值系于"自己的名利"，且系得如命相殉。动力源，体性属贪。
2. **不耐他荣**（反转点）——因自我价值系于相对位置，**他人的荣盛被读成对"我"的反衬 / 折损**；他荣（顺境）被我执翻转成逆境。
3. **妒忌·忧戚**（相）——对被读成逆境的他荣起"不耐 / 憎"，现行为妒忌，业用是**自心忧戚不安隐**。

### 3.2 根在贪、相在瞋——"嗔←我爱←我痴"通则的显式书写

嫉根在贪（殉自名利）、经典却判瞋一分，**不是嫉独有的结构谜题**，而是一条通则在嫉身上的显式书写：

> **归根结底，所有嗔的来源都来源于贪 / [我爱](../../../resources/cards/我爱.md)。**

- **经典依据（第一层）**：末那俱生相应四烦恼「[我痴](../../../resources/cards/我痴.md)、我见、我慢、[我爱](../../../resources/cards/我爱.md)」，我爱即贪着自我，是俱生位常起所依。嗔的生起必依「**违我所爱**」为缘——凡所嗔者，必是违逆了我 / 我所所贪爱执取之境；**无所爱则无所嗔**（"由爱生嗔""爱憎一体两面"——亦即 [恨 §5.1](./恨.md)"恨底层是爱"的推广）。三毒内在次第 **痴 → 贪（我爱）→ 瞋**。
- 所以嫉的「殉自名利」不需要在结构里另找一个"身份"——它**就是嫉体性定义里的前提部分**（动力 / 所依），现行体相落在瞋，故判瞋一分。

### 3.3 嫉为何把贪根挑明（接住反转）

忿恨恼的贪根（我所爱被违）**藏在定义背后**、不写出来；嫉却把贪根（殉自名利）**直接写进定义**。原因在反转点：

- 忿恨恼的"违"是**境直接违我所爱**（违境现成），贪根不必点破。
- 嫉的"违"是**顺境被我执二次加工成逆境**——不点破"殉自名利"这把尺，就解释不了"他荣（好事）凭什么成了我的逆境"。**贪根必须挑明，才接得住那个反转。**

## 四、见自维度（修行者位置现量分诊）

### 4.1 二分定位 → 拆掉"零和"（排名无自性）

他荣现起时，修行者现量上"忧戚 / 不安隐"转瞬**有**，细分两种场域：

| | 场域性质 | 现量 | 机制 |
|---|---|---|---|
| **情况 1** | **非零和**（贪的是内容本身，他人成就不折损我）| 嫉基本不起，**转研究姿态**（好奇他怎么做、具备什么特性）| 他荣只是境上事实，"我"没插进来当反衬→反转链断在第一环 |
| **情况 2** | **真实零和**（贪的是排名 / 排名带来的名利）| 忧戚现量明显 | 他荣＝我损看似"真实" |

**修行者自主究竟（本次看破）**：情况 1 / 2 的二分**本身默认了排名实有**。但——

> **排名不是境里天然之物：想比则有、不想比则无，它是比较心的产物。** 没有一个天然带排名的现实场域。

→ 一旦看穿这一点，"是否零和"的界限消失，情况 2 也能拆成纯境。"我之所以更容易在零和场显现，正因这场更难看破"——最难拆的场域一拆开，反证拆法普适。

> **一个精度护栏**：所空的是"我相对于他的价值序"（比较心产物），**不否认物理结果**（谁拿到那个名额仍是纯境）。我痴加工的是把"他拿到"读成"我的价值受损"。护栏在，"想比则有"不会被误用成空掉物理事实。

### 4.2 对治双入口分离

这一拆把嫉的对治从"回贪根"校准为双入口分离：

| 苦 | 是什么 | 对治 |
|---|---|---|
| **贪的求不得** | 我想要好结果而没得到（我自己的苦）| 回贪根——这是**另一回事**，可保留贪作世俗动力 |
| **嫉（不耐他荣）** | 把"他得"读成"我损"的**我他对立动作** | **拆对立动作**，把他荣读回纯境→随喜。**不必动贪根** |

→ 嫉的命门精确说不是"贪目标结果"，而是**"我他对立"这个瞋相的现起机关**。而且：**随喜他的成功，本身反过来松动我对结果的贪**（第三层：随喜功德对治嫉，经典立场）——一个动作同时破嫉 + 磨贪，比"回贪根硬断"善巧。

### 4.3 究竟收于我痴——嫉收进无痴双线 / 双锚

既然连"排名"都是比较心造出的不实之物，嫉的究竟根落到**我痴**：

```
我痴(立实我中心) ──→ 造比较(想比则有排名) ──→ 默认"别人有=我损" ──→ 不耐他荣(瞋) ──→ 嫉
  无明              缘起被读成对立                                     体相
```

对治随之究竟化：不在"回贪根"、也不在"逐场拆我他对立"，而是 **「了无自性」锚直接照破排名的不实**——排名一旦现量见为无自性，比较心失所依、我他对立无从焊、嫉自动消。**嫉不需要独立对治通道**，收进修行者早已运作的[无痴双线 / 双锚](../../教学操作核/教学操作核-03-无痴双线.md)（了无自性 + 所有错＝无知）。

### 4.4 慢 / 憍 / 嫉同一把钥匙的三个朝向

| 法 | 我他对比朝向 | 同一看破 |
|---|---|---|
| 慢（[L4 位置慢](../../教学操作核/教学操作核-07-慢L4位置慢.md)） | 我胜他 | |
| [憍](./憍.md) | 自盛 | **了无自性 → 破实我中心** |
| 嫉 | 他胜我 | |

→ 慢 / 憍 / 嫉究竟同收于"破实我中心"——不是三个对治，是一把钥匙（与[假说 18 对象转换](../../假说/假说-18-对象转换元假说.md)一致：评价对象留在境侧则不起，替换为"我"则起）。

### 4.5 随喜质地校正——一处"表层标签转移"自查

精修中曾埋一个推断："修行者随喜大概率走冷质地、缺为他高兴的情感"。此推断被现量否决——它是**把"信德冷质地"（限定于对三宝）违规泛化到"对人的随喜"**（项目明令警惕的表层标签转移）。据修行者自陈校正：

- 能**感受**他人的成就、努力、因缘成果，生**信服、认可**，**会为他高兴**；
- 不走的只是**膜拜 / 狂热**那个极端；
- 关键：自身"高兴"的**情感基线本就低波动**，故**为他欢喜 ≠ 比为己欢喜更低，二者等量**。

→ 校正后实相：随喜对治嫉**不是"冷"（缺情感）、而是"平"（基线平稳、为他为己等量、无狂热极端但有真实信服与高兴）**。修行学含义：**随喜的情感基质本来具足**，不需刻意"培养为他高兴的热情"（那反成装相）——缺的从不是随喜情感，缺的只是在"容易显现的零和场"把我他对立动作拆掉，而这次已拆开。

## 五、见众生维度

凡夫为什么拆不掉那个焊点、而修行者这次能拆？——**我痴未破**：把比较心的产物（排名）当实有，默认"别人有就是我损"，于是终生在自己造出来的排名场里受忧戚。

> 而修行者能拆，是因为有"了无自性 / 缘起"的现量底子——他得是他的因缘、我不得是我的因缘，本是两条独立缘起线；凡夫把"我"当实有中心，一切得失都绕着这个原点算账，两条缘起线必被焊到"我"上。**焊点 = 实我中心（我痴）。**

→ 这是利他善巧轴第三层（理解烦恼内在机制）在嫉上**最深的一填**：众生的嫉**不是"心眼小"的品行问题，是看不破排名无自性的结构性必然**——与"看通孩子'覆'三段皆缺"([覆 §5.3](./覆.md))、"恼←恨←贪封顶"([恼 §5](./恼.md)) 一脉：是机制，不是人品。见自侧不生这个标签、见众生侧拆掉这个标签，同一件事的两面。

> **第三层·自主推论**："排名无自性 → 嫉究竟是我痴"是修行者位置现量分诊产出，与"了无自性"双锚一致；状态为"与唯识框架内在一致的现量报告"。

## 六、结构关联

- **E 分位假立（瞋一分）**：嫉 = 一股瞋在"不耐他荣"分位的假立名，无独立别体，无内部体性诤议。
- **嗔系所缘断点**：忿恨恼起于违境链，嫉起于**他荣境**——嗔系对境从"违我者"扩展到"胜我者"（[忿 §3.2](./忿.md)：嫉害不在忿恨恼链下游、各起独立境）。
- **生起次第**：骨架 §七 凡夫染心链"恼 → **嫉**（他荣现起）→ 悭"中，由违境链转入他荣境的起点。
- **"嗔←我爱←我痴"通则**：嫉把贪根（殉自名利）显式写进定义，是这条通则的显式书写；究竟收于我痴。
- **慢 / 憍 / 嫉同一钥匙**：三个"我他对比"朝向，究竟同收于"了无自性破实我中心"（[假说 18](../../假说/假说-18-对象转换元假说.md)）。
- **对治收编**：嫉不需独立通道——了无自性锚照破排名不实即对治，收进[无痴双线](../../教学操作核/教学操作核-03-无痴双线.md)；随喜 / 喜无量正面对治，且随喜反向磨贪（接 [无嗔 §八](../善心所/无嗔.md)）。
- **见自见众分流**：见自侧嫉可拆（最难的零和场已拆开、究竟收我痴）；见众生侧凡夫嫉 = 我痴运行看不破排名无自性，利他善巧轴第三层最深一填。

## 七、学术诚实三层标注

**第一层（经典）**：嫉定义原文（殉自名利 / 不耐他荣 / 妒忌为性 / 不嫉 / 忧戚为业）；嫉瞋一分、离瞋无别相用；末那俱生四烦恼（我痴 / 我见 / 我慢 / 我爱）；嗔依"违我所爱"而起、无所爱则无所嗔（由爱生嗔）；痴为诸烦恼根本、三毒次第痴→贪→瞋；嫉障不嫉（随喜）、喜以无嗔为体。

**第二层（框架应用映射）**：三段链 + 反转点图；"根在贪、相在瞋"作为"嗔←我爱←我痴"通则的显式书写；"嫉把贪根挑明以接住反转"的整理；"非零和 / 真实零和"二分及其被"排名无自性"拆解；对治双入口分离（贪求不得 ／ 我他对立动作）；"慢 / 憍 / 嫉同一钥匙"整理（接假说 18）。

**第三层（自主推论）**：
- **排名无自性（想比则有、不想比则无）→ 嫉究竟收于我痴** = 修行者本次现量看破，与"了无自性"双锚一致；
- **对治不必回贪根、拆我他对立动作即可，随喜反向磨贪** = 修行者现量产出的对治路径；
- **随喜情感基质本具足（为他＝为己等量、基线平稳）** = 修行者自陈现量；
- **凡夫嫉 = 看不破排名无自性的结构性必然**（利他善巧轴第三层最深一填）= 见众生侧反向推论；
- 均属修行者位置现量分诊产出，状态为"与唯识框架内在一致的现量报告"。

> **本法一处自我校正记录**：精修中途模型提出"假说 18 在真实零和场无处可转、嫉必回贪根对治"——经修行者现量拆解（排名本身不实、想比则有不想比则无）证伪：零和场也能拆成纯境，嫉究竟收于我痴而非"必回贪根"。另自查一处"表层标签转移"（把信德冷质地泛化到随喜，§4.5）。二者皆"经典 / 现量 > 假说"的演练。
