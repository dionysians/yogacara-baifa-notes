# 放逸（pramāda）—— 守护总闸 · 大随八唯一复合分位

> **类别**: 心所法 > 随烦恼心所 > 大随烦恼（第五法）
> **本体归属**: D 复合分位——护法明文「非别有体」（大随八唯一、本体谱系拐点）
> **对偶善法**: [不放逸](../善心所/不放逸.md)（善染双侧唯一"假立 ↔ 假立"对偶）
> **见自判定**: **伴生降级**——[懈怠](./懈怠.md)在守护维度的投影，无独立主修区，归档不花常规带宽
> **学习日期**: 2026-07-02（覆盖 2026-03-05 桩文件）

---

## 引言

放逸是大随第五法，也是学习顺序里第一个**非别有体**的大随。前四法（掉举 / 惛沉 / 不信 / 懈怠）走的都是"别有体"路线，到放逸翻面：它没有自己的独立行相，是**懈怠 + 贪嗔痴四法在"防修"功能上的缺位之总名**。本法最重的产出不在见自（对修行者只是懈怠的伴生投影），而在**复合分位的组合逻辑**——它既不是"四法俱起才现行"（与），也不是"任一在场就现行"（或），而是**不放逸守护配置的逐位反占**。这个正解同时回答了"既然可拆回四法、为何还要立此名"——因为道的操作单位在配置层。

## 一、经典定义与四维拆解

**《成唯识论》卷六**：

> 「云何放逸？于染净品不能防修，纵荡为性。障不放逸，增恶损善所依为业。谓由懈怠及贪嗔痴，不能防修染净品法，总名放逸，非别有体。」

| 维度 | 内容 |
|---|---|
| **所缘** | 染净品——该**防**的染（已起恶令断、未起恶令不起）与该**修**的净（未生善令生、已生善令增长） |
| **体性** | **纵荡**——不防恶、不修善，放纵流荡（守护维度的总失守） |
| **业用** | 障[不放逸](../善心所/不放逸.md) + **增恶损善所依**为业 |
| **本体** | **非别有体**——即懈怠 + 贪嗔痴四法之"不能防修"，离此四法无独立放逸体 |

### 1.1 「增恶损善**所依**」的深义——总闸 / 温床

放逸不直接造恶损善，它是增恶损善的"**所依**"（地基 / 温床）〔第一层〕：防护一撤，已起的恶**自然**增长、未修的善**自然**损减。放逸是这个"任其增损"的**总闸**——它不添新染，是**撤掉所有防线让染自长**。这与[懈怠](./懈怠.md)"增染为业"衔接（懈怠滋长染、放逸给滋长供土壤），也接[憍](./憍.md)精修已立的"染依为业宽口温床、**放逸最直接失闸**"。

### 1.2 三法辨异

| 对比 | 区别点 |
|---|---|
| **放逸 vs 懈怠** | 懈怠 = **动力维度**（于修断事不策励·懒惰·别有体）；放逸 = **守护维度**（防线整体撤除令染自长·纵荡·复合假立）。懈怠是放逸的主成分，但层次不同：懈怠管"不去修"，放逸管"连守成都放弃" |
| **放逸 vs 失念** | [失念](./失念.md) = 明记力失（念缺位·俱一分摄）；失念是放逸滑落的一个通道、非放逸本身 |
| **放逸 vs 不正知** | [不正知](./不正知.md) = 带染的认知（慧染·俱一分摄）；放逸是守护撤除、不正知是认知污染 |

## 二、非别有体——复合分位的组合逻辑（本法最重一节）

### 2.1 本体谱系的拐点——招式线终结

大随八的本体谱系到放逸出现**拐点**。前四法的"别有体"张力曲线：

```
掉举（诤议·护法两刀第二次落地）
  → 惛沉（诤议·第三次落地）
    → 不信（论证压力最大·第四次落地）
      → 懈怠（无诤议·招式收束 / 终点）
        → 放逸【翻面：根本不立别体 = D 复合分位】
```

懈怠是"别有体"的终点，放逸是"别有体"的**反面**。这不是论证失败（找不到独立体性），而是本来就不该找——放逸的存在方式就是复合假立。

### 2.2 破「与」——四成分永不齐现

若放逸的现行条件是"懈怠 + 贪 + 嗔 + 痴四法俱起"，则放逸**永无现行**——因为**贪嗔不俱起**〔第一层：同一刹那对同一境，染著与憎恚行相相违不能并生〕，四法从来没有全体到齐的时候。这与"大随八遍一切染心"直接矛盾。

由此可见放逸与不放逸虽同为复合假立，**组合逻辑天然不对称**：不放逸的四成分（精进 + 三善根）无相违、可以也必须齐现（合取的成就）；放逸的四成分构造上不可能合取。

### 2.3 破「或」——放逸不是被触发的事件法

"任一成分在场就现行"这个读法，错在把放逸想成事件法（某成分点火 → 放逸跟着点火）。但大随八**遍一切染心**——放逸不是在染心里"被触发"的东西，是**每一个染心刹那本来就有的一个面**。

而且"只有一个成分在场"的情形根本不存在：**懈怠与痴都是遍染心法**（懈怠属大随八、痴是遍染根本烦恼），任何染心里放逸的所依**最少恒有｛懈怠、痴｝两位**，再加贪或嗔按境向择一现起。所依永远不会掉到"一个"。

### 2.4 正解——不放逸守护配置的逐位反占

经典自己给了选这四法的理由〔第一层〕：

> 「虽慢疑等亦有此能，而方彼四势用微劣，障三善根遍策法故。」（《成唯识论》卷六）

慢、疑等也有"不能防修"之能，为何不算入所依？因为势用弱，且——关键在后半句——**这四法恰是不放逸四成分的逐位对障**：

```
不放逸四位：  精进    无贪    无嗔    无痴    （四位齐守 → 防修涌现）
              ↕障     ↕障     ↕障     ↕障
放逸四所依：  懈怠    贪      嗔      痴      （同一配置的失守态）
```

〔第二层·基于「障三善根遍策法」的框架整理〕**四法不是一张触发清单，而是一个配置模板的四个岗位**。不放逸 = 守护配置的"四岗齐守"态；放逸 = 同一配置的"失守"态——描述失守态时点名的是"失守时占据四个岗位的是什么"（精进位被懈怠占、三根位被三毒占，贪嗔按境向轮替）。在任一染心刹那，配置由｛懈怠、痴｝（恒在）加当场的贪或嗔实例化，其"守护缺位 + 纵荡"的功能面即放逸。

### 2.5 纵荡 = 无守 × 被载——「特性是真的，体是假的」

四法组合确有一个成分层没有的特定相状——**纵荡**。拆开看没有任何一个成分单独具有它：

- **懈怠**夺走守护的**动力**（岗哨无人）；
- **痴**夺走守护的**知见**（不知防修之要——不知道需要设岗）；
- **贪 / 嗔**提供把无守之心**载走的流向**（趋所欲 / 抵所违）。

〔第三层·现象学拆解〕纵荡 = **无守 × 被载**的乘积效应。单独的懈怠只是"不动"（停着的车不叫漂移）；单独的贪在有守护的心流里起来即被截（修行者的法贪识破即是实例）。只有"岗哨空 + 有水流"同时成立，心才**漂**。

但护法的下半句同样重要：这个相状虽特定，推究到底**没有超出四法功能缺位之外的剩余行相**——把懒惰和毒流都指完，纵荡没有剩下的东西可指（对照不放逸的判词「非别有体，无异相故；于防恶事修善事中，离四功能无别用故」，放逸同判）。结论一句话：**特性是真的，体是假的**。这就是"分位假立"的严格含义——不是"没有特定特性所以不立体"，而是"特性可由所依完全重构、无剩余，所以不立体"。

### 2.6 俱舍有部对照——招式线的反向验证

[《俱舍论》](../../../resources/cards/《俱舍论》.md)／有部恰恰给放逸立了**实体**（[大烦恼地法](../../../resources/cards/大烦恼地法.md)六法之一：痴、放逸、懈怠、不信、惛沉、掉举）。护法在这里站到了**还原方**——前四法的诤议里护法一路论证"别有体"，到放逸反过来判"非别有体"。

这说明护法两刀（通染心不能尽 + 独立业用 / 行相）是**真检验、不是橡皮图章**——它能输出"否"。掉举有嚣动、惛沉有蒙昧、不信有心秽、懈怠有懒惰，各有推究不尽的剩余行相，所以别立；放逸的纵荡推究到底无剩余，所以不立。**一个能失败的检验，它的四次"通过"才有分量**——放逸的"否"反向加固了前四法的"是"。方法论一贯：**有无独立行相 / 业用决定别体与否，不是一揽子政策**。

## 三、假立 ↔ 假立唯一对偶——完整复合镜像

### 3.1 四对四逐位取反

不放逸也非别有体〔第一层〕：《成唯识论》「不放逸者，精进三根，于所断修防修为性；对治放逸，成满一切世出世间善事为业」——依精进 + 三善根**分位假立**。故：

- **放逸 ↔ 不放逸 = 基底配置 10↔10 里唯一"假立 ↔ 假立"对偶**（其余信 / 不信、惭愧 / 无惭无愧、精进 / 懈怠皆别有体 ↔ 别有体）；
- 完整复合镜像，四对四逐位取反（精进 ↔ 懈怠、三善根 ↔ 三毒）：

```
不放逸 = 【精进 + 无贪 + 无嗔 + 无痴】→ 防修（守护涌现）
放逸   = 【懈怠 + 贪   + 嗔   + 痴  】→ 纵荡（守护失守）
```

这呼应[精进](../善心所/精进.md)三法分工（精进 / 不放逸 / 行舍 = 精进三根的三种功能模式：动力 / 守护 / 平衡）——**放逸精确对应"守护模式"的反面**。

### 3.2 为什么必须立这个名——道的操作单位在配置层

既然特性可拆回四法，为何经典还要立名？三条理由：

1. **它命名了成分层语言说不出的因果角色**——「增恶损善**所依**」（土壤）。懈怠的业用是障精进，三毒各障自家对治，但"染品得以**滋长**的土壤"是系统角色。〔第三层〕且"滋长"是**相续层**现象（增长是时间轨迹），成分法都是刹那层的——放逸这个名的真正工作层面在相续 / 配置层：一个染念**起**（凡夫位不可免）和一个染念**滋长成势**（放逸为壤）之间的差别，要靠配置级名字才说得出。
2. **道的操作单位就在配置层**〔第一层〕。佛陀临终遗教（巴利《大般涅槃经》）总摄一切法为一句"**以不放逸成办**"（appamādena sampādetha）；《法句经》不放逸品："不放逸是不死道，放逸是死路。"整条道的最终概括没有选任何成分法的名字，选的是配置层的名字——修行操作的不是逐个成分，是**整个守护配置的设防状态**。
3. **诊断回报**：只有配置层语言才能说出"守护配置四位中，三根位是满的、只缺精进一位"这种判断——"位"这个概念只在配置模板上存在，成分层语言（懈怠如何、贪如何……）永远拼不出"缺一位"。见 §四。

## 四、见自——懈怠主导型放逸（场域 B · 伴生归档）

### 4.1 懈怠主导型放逸 = 清净型纵荡

修行者现量自陈："当前是精进力不够强、懈怠间或出现，**三毒的防线还是比较稳的**。"放逸的完整体是四成分都纵荡；修行者的现行只有**懈怠这一成分松**、三毒三位守得住。故〔第三层·见自判定〕：

- 修行者的"放逸"（若论）= **懈怠主导型放逸 = 清净型纵荡**——"不防修"来自懈怠（不策励去修）、不来自三毒纵荡；
- 现象上**就是"不修"，而非"耽欲放纵"**——闲时不滑向感官耽著，只是善法那边起不来；
- 与凡夫放逸（三毒主导·耽欲纵荡型）质地不同：凡夫是"防线撤了、染水涌进来"；修行者是"防线基本在、只是修善的泵没开"。

### 4.2 三根位守护的双机制现量（势力弱 + 截得快）

对"三毒防线稳"追问了一层：是**主动防住**（相续层守护在运作），还是**缘缺不现**（毒流根本没来）？修行者现量分判为**双机制并行**：

> "种子势力弱，本就不起，肯定不能完全做到。所以我的现量分判是截得快，同时势力弱。在很多时候，我能清晰地感觉到贪嗔起来的那一下，也能清晰地感觉到被惭愧迅速瓦解的那个过程。"

- **㈠ 种子势力弱为主**：多数时候毒流本就不起——但明确不作全称（"肯定不能完全做到"），守界姿态与不信精修"未发现 ≠ 确证无"一贯；
- **㈡ 相续层守护真实在运作**：贪嗔起来"那一下"清晰可感、被**惭愧**迅速瓦解的过程清晰可感——不是纯缘缺不现，岗哨真的在值班；与[无惭无愧合论](./无惭无愧合论.md)锁定的"脉冲 + 惭愧即刻截断"完全同型。

### 4.3 配置侧再证遮强表弱

〔第三层·两侧有现量支撑〕修行者截断毒流用的是**惭愧瓦解——[遮](../../../resources/cards/遮诠与表诠.md)性操作**（斩断、清场）。故守护配置四位的守法分化：

```
三根位（无贪 / 无嗔 / 无痴）→ 靠【遮】守住（惭愧截断·强项）→ 满
精进位                    → 需要【表】生起（正向动力·弱项）→ 缺
```

**放逸的配置分析独立重推了一遍"遮强表弱"**：守护配置里唯一失守的岗位，恰好是唯一需要"表"性操作的岗位。[懈怠](./懈怠.md)精修从动力层挖出的签名、放逸精修从配置层看到的缺口，两条独立路径同一结论 = 互证（已并入专题[修道点火与遮强表弱](../../修行学/修道点火与遮强表弱——懈怠根诊断与欲钩双线.md) §3.1 配置侧续证）。

### 4.4 归档判定——大随五法见自全景

修行者的场域 B 问题**根本上是懈怠（及其痴一分根），不是放逸**。放逸只是"懈怠现行时、防修总闸那一格跟着松了"的伴生描述，无独立主修价值——与前三法同为降级，形态是第四种（**伴生投影型**）：

| 大随 | 见自形态 |
|---|---|
| 掉举 | 罕现（事件遮蔽型降级） |
| 惛沉 | 不现行 |
| 不信 | 降级首例（无遮蔽可降） |
| **懈怠** | **现行（真主修区）** |
| **放逸** | **伴生（懈怠守护维度投影）** |

→ 大随八至此，**真主修区唯懈怠一个**。放逸对治不另立通道：**补精进位（欲钩双线点火）→ 不放逸"防修模式"涌现（三根位本就稳、缺口只在精进一位）→ 放逸自然不现行**。接[教学操作核 05](../../教学操作核/教学操作核-05-不放逸.md)"精进力层未稳 → 不放逸未涌现"——该诊断的缺口现在被配置语言精确到一位。

## 五、见众生——总闸枢纽（由懒到烂）

凡夫放逸的现行链（接骨架 §七生起次第）：

```
不信（心不趋向实德能）→ 懈怠（不策励修断）
        ↓ 守护配置整体失守（懈怠主成分 + 三毒纵荡）
放逸（不防恶不修善·纵荡）
        ↓ 增恶损善所依（总闸打开）
失念 / 散乱（守护撤后念力溃散）→ 一切染品滋长
```

- **放逸是凡夫"由懒到烂"的枢纽**：懈怠只是不前进，放逸是**连守成都放弃**——三毒于是各自纵荡（贪耽五欲 / 嗔纵违境 / 痴不知防）；
- **见众生落点**〔利他认知路径一填〕：凡夫放逸非"主动作恶"，是**防线全撤后的自然滑落**——不是品行问题，是配置失守的结构必然；
- **帮的入口 = 补不放逸缘（重设守护配置）**、非逐个断染——逐个断染在配置失守态下是打地鼠，重设防线（对凡夫常从最可得的一位入手：念死 / 业果生起码的防护心）才对机。配置层语言给利他认知路径添了个新工具："他不是坏，是配置失守。"

## 六、「大」续推——衍生型大

放逸是复合假立，其"大"的来源与别有体四法不同〔第二层·续证〕——是**衍生型**：

| 维度 | 放逸的"大"来源 |
|---|---|
| **影响范围宽** | **借成分 + 总闸遍在性**——四所依本身就宽（懈怠遍染 + 三毒各遍），且放逸是防修总闸，一撤则遍一切染品滋长（比单一成分更宽） |
| **对治深度深** | **借成分深**——对治放逸 = 补精进位 + 断三毒 = 动整个基底配置；且不放逸须四位齐守才涌现，缺一位防修即不成 |

对治深度三尺照量：a. 看破难度**深**（纵荡无自相、藏在四法后面，须配置层眼光才见其为一事）/ b. 对治时间**长**（不放逸涌现 = 精进力层整体建设）/ c. 定力配合**强**（同懈怠、主座 A）= **基底配置级 ✓（衍生型）**。

**独特贡献**：放逸是"大 = 基底配置级"**最纯字面的第二例**（继不信之后）——不信污染基底质地、放逸撤除基底防线；放逸**不添内容、只管"配置是否设防"**，是站在整个基底配置总防线位置上的法。

## 七、五随烦恼网络起头（放逸 = 枢纽 · 登记回填）

放逸 / 懈怠 / 失念 / 散乱 / 不正知五法构成"守护失守网络"，失念 / 散乱 / 不正知未学，本节只落**放逸的网络位置**：

```
懈怠（动力松）→ 放逸（守护总闸撤）→ 失念（明记失）+ 散乱（心流散）→ 不正知（认知染）
                   ↑ 放逸 = 枢纽：懈怠的下游、失念散乱的上游
```

完整五法精确分判待失念 / 散乱 / 不正知学完（已登记跨阶段回填清单：回填[不放逸.md §五](../善心所/不放逸.md)五随烦恼网络 + [从欲到精进](../别境心所/从欲到精进：修道动力如何形成.md)障道作用小节），本节不预判未学三法。

## 八、学术诚实三层标注

**第一层（经典）**：
- 放逸定义、非别有体、「谓由懈怠及贪嗔痴不能防修染净品法总名放逸」、「虽慢疑等亦有此能，而方彼四势用微劣，障三善根遍策法故」（《成唯识论》卷六）；
- 不放逸依精进三根分位假立、「非别有体，无异相故，离四功能无别用故」（《成唯识论》卷六）；
- 贪嗔不俱起；大随八遍一切染心；
- 俱舍 / 有部立放逸为大烦恼地法实体（《俱舍论》卷四）；
- 佛陀遗教 appamāda（巴利《大般涅槃经》）、《法句经》不放逸品。

**第二层（框架应用映射）**：
- "配置模板逐位反占"框架（基于「障三善根遍策法」的整理）、"岗位 / 总闸 / 温床"比喻；
- "招式线反向验证"（护法两刀作为可证伪检验的方法论解读）；
- 遮 / 表从"诠"到"操作"的引申（见[遮诠与表诠](../../../resources/cards/遮诠与表诠.md)卡）；
- "懈怠主导型放逸 / 清净型纵荡"命名；"衍生型大"归类。

**第三层（自主推论·标注不作定论）**：
- 纵荡 = 无守 × 被载的现象学拆解（"痴不知防修之要"有疏解依据，"贪嗔供流向"是我们的解读）；
- 放逸之名的工作层面在相续 / 配置层（刹那起 vs 相续滋长之别）；
- 见自判定（伴生投影型降级 / 三根位双机制 / 遮强表弱配置侧再证）= 修行者自我诊断，不作跨人假说、不入假说表。
