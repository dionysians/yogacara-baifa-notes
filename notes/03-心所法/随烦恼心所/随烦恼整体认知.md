## §一 随烦恼的总安立——"随"字的体性意义

### 1.1 "随"字两义

经典对"随烦恼"的定义涵盖**两个独立含义**：

| 维度 | 经典表述 | 解读 |
|---|---|---|
| **随他起** | 随根本烦恼分位起 / 等流起 | 业用上的依赖性——随烦恼不能脱离根本烦恼独立现行 |
| **唯染心起** | 唯于染污心位现行 | 业用范围上的限定——不通三性，只在染心位现行（区别于遍行 / 别境通三性） |

二义合起来 = 随烦恼是"于染污心位、随根本烦恼起的染心所"。

> **经典依据**：《成唯识论》卷六：「随烦恼，谓唯是烦恼分位差别，等流性故，名随烦恼。」
> 《瑜伽师地论·本地分》卷五十八：随烦恼分四类（缠 / 随眠 / 随烦恼 / 缠之等流），本项目所学的"随烦恼 20 法"对应于"随他起 + 唯染心"的狭义安立。

### 1.2 "随他起"的精确化——分位 vs 等流

"随他起"内部还需精确分判，这是理解每一随烦恼归属的核心结构：

| 类型 | 含义 | 是否别立实有 | 典型例 |
|---|---|---|---|
| **分位假立** | 是根本烦恼在特定分位（特定境 / 特定时段）的别名，无独立体 | 否（依根本立） | 忿 = 嗔的现前粗相分位 / 恨 = 嗔的怀怨分位 |
| **等流性** | 是根本烦恼的等流果，与根本烦恼同类相续，但有自体 | 是（别立实有） | 无惭 / 无愧 / 不信 / 懈怠等（《成唯识论》立别有体） |

**关键诤议**：哪些随烦恼是分位假立、哪些是等流别立实有——各家不同（小乘有部 / 经部 / 唯识各异）。《成唯识论》倾向"无惭无愧 + 不信懈怠放逸 + 失念不正知散乱"等大随中部分为别有体，其余多为分位假立。这是 §三 归属网络图必须直面的细节问题。

### 1.3 随烦恼为何独立列出而非归入根本烦恼

如果随烦恼"随根本而起"，为何不直接归入根本烦恼？三个理由：

**理由一：行相业用差异**——随烦恼的现行相状与根本不同。如"忿"现起时虽以嗔为体，但有自己特殊的现行相（暴怒 / 拳脚 / 言语攻击的具体形态），与单纯的"嗔"在事相上可分别识别。修行对治需要这种事相级精度。

**理由二：部分别立实有**——若全是根本的分位，归入根本即可。但《成唯识论》立"无惭无愧 / 不信懈怠放逸 / 失念不正知散乱"等为别有体（非根本之分位），它们必须单列。

**理由三：对治善心所的对偶要求**——善心所 11 法中有 8 法（精进、不放逸、行舍、惭、愧、信、轻安、不害）与随烦恼直接对偶：
- 惭 ↔ 无惭 / 愧 ↔ 无愧 / 信 ↔ 不信 / 精进 ↔ 懈怠 / 不放逸 ↔ 放逸 / 行舍 ↔ 掉举 / 轻安 ↔ 惛沉 / 不害 ↔ 害
- 若不立随烦恼，善心所的对治对偶失去对象。这反过来证明随烦恼必须单列。

### 1.4 与"根本"的本体差异

| 维度 | 根本烦恼（6） | 随烦恼（20） |
|---|---|---|
| **体** | 各别立实有体 | 部分别立、部分分位假立 |
| **生起力** | 能生其他烦恼（"本"义） | 不能生其他烦恼（"随"义） |
| **遍三界 / 三性** | 遍三界（欲 / 色 / 无色），唯染 | 范围因法而异（小随只在欲界第六识 / 大随通三界） |
| **现行场域** | 任运 + 分别 | 部分仅分别（如忿恨多分别）、部分通俱生（如无惭无愧、大随八） |

## §二 小/中/大三类的安立依据

### 2.1 三轴判定标准

《成唯识论》卷六立**三轴**判定随烦恼的三类归属：

| 轴 | 判定问题 | 三类对应 |
|---|---|---|
| **轴一：行相粗细** | 现行的相状粗暴还是微细？ | 小（粗）→ 中（中）→ 大（微细） |
| **轴二：自类俱起** | 同类随烦恼之间能否同时现行？ | 小（各别起，不俱）→ 中（无惭无愧必俱起）→ 大（八法之间互相俱起，常多法并现） |
| **轴三：遍染心程度** | 现行的染心范围有多广？ | 小（行相粗、范围窄）→ 中（遍一切不善心）→ 大（遍一切染心 = 不善 + 有覆无记） |

三轴是**联动**的，不是独立判定：行相微细 → 自类相互能俱起 → 遍染心范围广，三者共同指向"染污心的基底"性质。

> **经典依据**：《成唯识论》卷六：「言小随者，自类俱起，行相粗猛，各别现行，故名小随。」「中俱遍不善心故名为中。」「染心皆遍故名为大。」

### 2.2 小随烦恼 10 法的安立特征

**10 法**：忿、恨、覆、恼、嫉、悭、诳、谄、害、憍

| 维度 | 特征 |
|---|---|
| 行相 | 粗（暴怒 / 怀怨 / 隐藏 / 嫉妒 / 吝啬 / 欺诈 / 谄媚 / 加害 / 傲慢 / 憍举——都是具体可识别的行为相状） |
| 自类俱起 | **各别起**——忿起时无恨同时起 / 嫉起时无悭同时起 / 等。一时一法 |
| 遍染心 | **窄**——主要在欲界第六识相应、部分通色界。不遍欲界 |
| 现行场域 | 主要在**分别**位（依特定境、特定时段、特定经验起），不通俱生 |

**根本烦恼归属（先列，§三 细化）**：
- **嗔系**（5）：忿、恨、恼、嫉、害
- **贪系**（2）：悭、憍
- **贪痴一分**（3）：覆、诳、谄

### 2.3 中随烦恼 2 法的安立特征

**2 法**：无惭、无愧

| 维度 | 特征 |
|---|---|
| 行相 | 中（不像小随那样有具体外显行为相，但能直接识别） |
| 自类俱起 | **二法必俱起**——无惭起时无愧也起、反之亦然。是一对结构性绑定的染心所 |
| 遍染心 | **遍一切不善心**（关键限定：只在"不善"心位、不在"有覆无记"心位） |
| 现行场域 | 通分别 + 俱生（不善心位必现行） |

**为什么"中"只有 2 法？** 答案在**"不善"的定义本身**：

> 唯识立"不善心"的定义 = "与无惭无愧相应的染心"。
> 反之，染心若无无惭无愧俱起，即不是"不善"，而是"有覆无记"。

→ 无惭无愧是"不善心位"的**结构性标记**，二法成对承担"不善 vs 有覆无记"的区分功能。这就决定了中随不能多——多了就破坏这个标记的紧密性。

### 2.4 大随烦恼 8 法的安立特征

**8 法**：掉举、惛沉、不信、懈怠、放逸、失念、散乱、不正知（沿用《成唯识论》顺序）

| 维度 | 特征 |
|---|---|
| 行相 | **微细**（不一定有外显行为，多为心识内部的扰动 / 钝重 / 不信 / 懈怠 / 失念等基底状态） |
| 自类俱起 | **互相俱起**——八法之间常多法并现，几乎是染心的"背景配置" |
| 遍染心 | **遍一切染心**（不善 + 有覆无记都遍）——这是最广的范围 |
| 现行场域 | **俱生 + 分别都遍**——特别是俱生位的染心基底 |

### 2.5 三类划分的修行学含义

| 类 | 修行对治姿态 |
|---|---|
| **小随**（行相粗、各别起、分别为主） | **事相级对治**——每一法对应具体场域，事件场识破即可 |
| **中随**（无惭无愧、不善心位的结构性标记） | **善心所对偶级对治**——惭愧建立 = 中随结构性瓦解的入口 |
| **大随**（行相微细、染心基底配置） | **基底配置级对治**——禅定 / 念力 / 信力 / 精进力的整体建设，对应主座 A + 不放逸触发点 + 信的修习路径 |

### 2.6 小随 10 法收官 · "小"的指代提炼（2026-06-16 憍精修产出）

小随 10 法精修走完（憍收口）后回填。**出发点不是立假设，是搞清楚经典把随烦恼分小 / 中 / 大到底在指什么**——以下是整理 10 小随特性提炼出的"小"之指代（主要是**第二层框架整理**，在经典三轴之上、离经典近）。详见 [憍.md §四](./憍.md)。

**两种"看破深度"先分清**（关键厘清）：① **现行级看破深度**（停这一次现行要多深）；② **究竟断深度**（断种子要多深）。**"小"指前者、不指后者**——小随之"小"= 它现行出现时就处在浅层；害的深层俱生颠倒属究竟断（跟嗔根走），不是衡量"小"的尺。故"**看破深度（现行级）= 表层**"覆盖**全体 10 小随含害**（早期"脚手架厚薄"度量被害打破已弃；不需害的两形态）。

**"小"的指代**（经典三轴 + 修行学侧共变、同指一件事）：

| 维度 | "小"的内容 | 来源 |
|---|---|---|
| 行相 | 粗（具体可识别事相）| 经典轴一 |
| 自类 | 各别起 | 经典轴二 |
| 遍染心 | 窄（欲界第六识为主）| 经典轴三 |
| **看破深度（现行级）** | **浅层——现行出现即在表层，浅层看破即停现行** | 修行学侧整理 |
| **离究竟** | **远（事相级对治，事件场识破即可）** | 看破深度等价表述 |

→ **小随 = 染心最表层、最事相的一类**。贯穿小随的三条整理**归位为"小"之指代的角度**（非待立假说）：**双重假**（所缘世俗建构无自性 → 故浅层破建构即停）/ **常驻动机**（贪系维持机制、保全型覆悭诳 / 自熏型谄憍，作用域限贪系）/ **两参数无剩余**（根本分 × 发作方式、E 类可完全重构无独立深度）。

**据此预测中 / 大**：小 / 中 / 大 = 染心**由表及里的深浅层次**，看破深度 / 对治深度是贯穿三者的统一尺——中随 = 不善心位结构性标记（深一层 · 善心所对偶级）/ 大随 = 染心基底配置（最深 · 基底配置级）。**"小"已提炼实；"中"已于 2026-06-24 中随两法精修落实（见 §2.7）；"大"待提炼。**

### 2.7 中随两法收官 · "中"的指代落实（2026-06-24 无惭无愧精修产出）

中随两法（无惭无愧）精修走完后回填，**确认 §2.6 的"中"预测成立**。详见 [无惭无愧合论 §六](./无惭无愧合论.md)。

**"中"的本相 = 不善心位的结构性标记**：无惭无愧 = 把"迷暗的染心"推成"生长恶行的不善心"的那个增量；[不善](../../../resources/cards/不善.md)（感苦果）vs 有覆无记（染而不造恶）的全部差别卡在它。中随不是某类具体染相，而是"这颗心是不善的"这个质地标记本身——遍一切不善心、不遍有覆无记。

**为何恰好 2 法**：标记一个不善心需恰好覆盖善恶标尺**两面**（自法面 → 无惭 / 世间面 → 无愧），每个恶两面俱全 → 需且仅需二法。"2"是"两面"决定的，非随意。

**"中"的指代**（经典三轴 + 修行学侧共变、同指一件事）：

| 维度 | "中"的内容 | 来源 |
|---|---|---|
| 行相 | 中（无外显行为相、可直接识别） | 经典轴一 |
| 自类 | 必俱起（定不相离） | 经典轴二 |
| 遍染心 | 遍一切不善心、不遍有覆无记 | 经典轴三 |
| **对治深度** | **深一层 · 善心所对偶级——立惭愧（非破事相）、且搭惭愧通道不另立** | 修行学侧落实 |
| **离究竟** | 中（比小随事相级近一步、未到大随基底层） | 对治深度等价表述 |

→ **中随 = 染心"不善那一格"的结构性标记**。对治从小随的"逐事相**破**（破世俗建构）"升到"**立**惭愧换心的善 / 不善质地"，且**搭惭愧通道、不另立**（骨架 §6.5 已安排）。**统一尺确认**：小 = 现行级表层事相破 / 中 = 善心所对偶级立质地 / 大 = 基底配置级（待大随落实）。

### 2.8 大随八法收官 · “大”的指代落实（2026-07-17 不正知精修产出）

**状态：八法齐检，正式落实**。“小”在憍收官落实（§2.6）、“中”在无惭无愧收官落实（§2.7）；大随八法至不正知全部走完，均通过下述三尺的“基底配置级”检验。“大”因此不只指遍一切染心的影响范围宽，也指其对治深入心的基础配置，须以念、定、慧及善法守护作长期建设。

**框架精化一 · "大"有两个独立但共变的维度**（2026-06-25 修行者自立）：

> **影响范围（宽 / 遍染心）** 与 **对治深度（深）** 是两条**独立轴**，但**共变**——因"**能在浅层处理就不会成为基底**"，凡宽到成基底者必然也深。但仍须**分别对待**（宽→深是趋势、由基底性驱动，不是定义；落实"大"时两维分列、注明共变机制，不合并）。

**框架精化二 · 对治深度三把尺**（修行者操作化，量小 / 中 / 大三**层级**·非连续谱）：

| 对治深度尺 | 小随 | 中随 | 大随 |
|---|---|---|---|
| **a. 看破难度** | 浅（事相一看即破） | 中（须立惭愧换质地） | 深（基底、须禅定下沉才看破） |
| **b. 对治需要的时间** | 短（事件场即时识破） | 中（惭愧任运需熏） | 长（念力 / 信力整体建设、经年累月） |
| **c. 需要的定力配合强度** | 几乎不需（慧简择即可） | 中（须一定相续） | 强（须主座 A 强定力配合） |

三尺单调同向递增、坐实"三层级对治深度"；尺 c 接慧定不匹配 / 主座 A（大随对治 = 主座 A 整体建设）、尺 b 接看破→熏种→常态（大随熏种周期最长）。**落实"大"时即用三把尺量八法是否齐证"基底配置级"。**

**掉举起步证据**（详见 [掉举 §六](./掉举.md)）：行相微细 / 自类俱起 / **遍一切染心**（比中随"遍不善心"宽一层，= 别有体外延论据，§5.3）/ 对治深度预测 = 基底配置级（禅定 / 念力整体建设）。看破深度尺到目前连续：小（事相级·表层破建构）→ 中（对偶级·立惭愧换质地）→ 大（基底配置级·整体建设）。

**惛沉续证（2026-06-25·详见 [惛沉 §六.3](./惛沉.md)）**：惛沉 = "大"之指代第二法证据，但属**经典位 / 见众生位证据**（非现量位——修行者位惛沉降级、两形态不现行，详见 [惛沉 §四](./惛沉.md)）。对治深度三尺齐证：a. 看破难度**深**（自障觉照 + 伪装舒适不报警）/ b. 对治时间**长**（轻安建立 + 提堪能整体身心建设）/ c. 定力配合**强**（取光明想 / 奢摩他修定提堪能）= **基底配置级 ✓**。两维共变（遍一切染心**宽** + 基底级**深**）+ 别有体外延（遍染心、比中随宽一层）再加一证。**降级第三例**（不信 / 掉举 / 惛沉）累积——"大"多数法对修行者降级、但**失念 / 懈怠例外（现行）**，现量位三尺待该二法补。

**不信续证（2026-06-29·详见 [不信 §六](./不信.md)）**：不信 = "大"之指代第三法证据，同属**经典位 / 见众生位**（不信对修行者降级首例）。三尺齐证：a. 看破难度**深**（心秽无报警·不痛不痒最难自察）/ b. 对治时间**长**（信如水清珠正向工程·把心趋向总质地从浑浊养到澄净 = 基底质地整体转化）/ c. 定力配合**强**（亲近善知识 + 长期熏信 + 定中令心净相现前）= **基底配置级 ✓**。两维共变（遍染心**宽** + 基底**深**）+ 别有体外延（遍染心、比中随宽一层·招式第四次落地）。**独特贡献 = "基底"义最纯的一法**：其余大随障某一善法（止 / 观 / 惭愧 / 念），不信障的是**善心所运作的公共基底（心净趋向质地）本身** = 最贴"大 = 基底配置级"字面的一例。**三种降级形态俱全**：不信（首例·几乎无遮蔽可降）/ 掉举（事件遮蔽）/ 惛沉（不现行）；现量位三尺仍待失念 / 懈怠补。

**懈怠续证（2026-06-29·详见 [懈怠 §六](./懈怠.md) + 专题 [修道点火与遮强表弱](../../修行学/修道点火与遮强表弱——懈怠根诊断与欲钩双线.md)）**：懈怠 = "大"之指代第四法证据，且是大随八**第一个"现量位"证据**（懈怠对修行者确实现行、真主修区；前三法掉举罕现 / 惛沉不现行 / 不信降级，三尺只有经典 + 见众生位）。三尺齐证：a. 看破难度**深**（根藏在"正确法理"背后·伪装"合理配速"·遮强表弱结构签名难自察·整场讨论才挖到根）/ b. 对治时间**长**（欲钩点火 + 现行熏显 + 暇满 / 行苦建比量 + 利他轴成长·经年累月）/ c. 定力配合**强**（现行熏显靠主座 A·续火靠定力相续加行→任运）= **基底配置级 ✓**（首次有修行者**现量**支撑）。两维共变（遍染心宽 + 基底深）。**别有体外延**遍染心、但懈怠**别有体无诤议、不走招式**——对偶精进体性最鲜明（vīra）、别立无压力 = **护法招式落地的自然收束 / 终点**（掉举有诤议→惛沉有→不信压力最大→懈怠归零）。现量位三尺另一例待失念补。

**放逸续证（2026-07-02·详见 [放逸 §六](./放逸.md)）**：放逸 = "大"之指代第五法证据，**证据类型新——衍生型**（大随八唯一非别有体·D 复合分位）：影响范围宽 = 借成分（懈怠遍染 + 三毒各遍）+ **总闸遍在性**（防修总闸一撤、遍一切染品滋长、比单一成分更宽）；对治深度深 = 借成分深（对治放逸 = 补精进位 + 断三毒 = 动整个基底配置；不放逸须四位齐守才涌现）。三尺照量齐证：a. 看破难度**深**（纵荡无自相、藏在四法后面，须配置层眼光才见其为一事）/ b. 对治时间**长**（不放逸涌现 = 精进力层整体建设）/ c. 定力配合**强**（同懈怠·主座 A）= **基底配置级 ✓（衍生型）**。**独特贡献两条**：① "大 = 基底配置级"**最纯字面第二例**（继不信后——不信污染基底质地 / 放逸撤除基底防线，放逸不添内容、只管"配置是否设防"）；② **招式线反向验证**——护法两刀在放逸输出"否"（纵荡推究无剩余行相、离四无体），俱舍有部反立实体（大烦恼地法）；能输出"否"的检验，前四次"是"才有分量。见自 = **伴生投影型降级**（懈怠守护维度投影·降级第四形态），现量位三尺仍待失念补。

**失念续证（2026-07-06，2026-07-20 眠侧校准·详见 [失念 §七](./失念.md)）**：失念 = “大”之指代第六法证据，**证据类型再新——执行层基底**：失念障的是正念，而**正念是一切对治的执行者**——其余大随障某一善法，失念障“守护任何善法的能力”；三个纯形态分层不重复（不信污染**资粮侧**心净质地 / 放逸撤**配置侧**守护总闸 / 失念断**执行侧**明记锚点——配置了也执行不了）。三尺齐证：a. 看破难度**深**（失时没有正知报告，看破主要依赖边缘追认）/ b. 对治时间**长**（念力底板纯熏习工程·修行者定天花板历来即此）/ c. 定力配合**强**（对治本身就是修定核心工序〔八断行之念〕·念定互为增上）= **基底配置级 ✓**。且是**现量位证据第二例**（继懈怠·性质不同：懈怠染现行现量 / 失念**功能缺口现量**——细所缘关口“每次都有” = 大随八中修行者现量撞击频率最高一法）。空档内部是否进入眠的有心 / 无心位不参与失念主故障定性，仍待样本。另供**元命题③定义级样本 + 结构解释 + 末那地板边界**（详见 §6.6 揭示 4 更新 + [失念 §7.3](./失念.md)）。见自 = **染相微、功能缺口实（主修区·培育型）**——见自形态序列第五种。现量位三尺至此两例（懈怠 / 失念）。

**散乱续证（2026-07-15·详见 [散乱 §八](./散乱.md)）**：散乱 = "大"之指代第七法证据，**证据类型再新——全尺度贯穿型**：前六法的"基底"各据一侧（资粮 / 配置 / 执行……），散乱是唯一一法**经典亲自给出多尺度分类学**（六散乱：刹那所缘 → 业处 → 目的框架 → 体验归属 → 道的方向）——"基底"在它这里显示为**从一刹那注意力到整条道的方向全尺度有格**，且尺度越大越不像散（相 / 粗重 / 作意层的偷换以月年计、坐相完好精进如常，还被文化包装成"多任务并行能力"）。三尺齐证：a. 看破难度**深**（表层的散只见现行层〔上游两环缺位不可见·打地鼠〕+ 深层的散最不像散）/ b. 对治时间**长**（正定建立九住心整程·深层随道次第全程）/ c. 定力配合**强**（对治散乱即修定本身·且深层对治摊到惭愧 / 无我观 / 胜解全配置面）= **基底配置级 ✓**。且是**现量位证据第三例（轻量）**：继懈怠（染现行型）、失念（功能缺口型）后第三种性质——**场景激活交织型**（附庸型双通道〔贪推 / 懈怠撤〕·有真现行〔工作场 + 探索场 + 懈怠日座中〕·已有通道覆盖不成主修区）。另供元命题③第七票 + 系猿猴喻教证锚点（§6.6 更新）。见自形态序列第六种。

**不正知收官证据（2026-07-17·详见 [不正知 §九](./不正知.md)）**：不正知 = “大”之指代第八法证据，证据类型为**监察—出口型基底**。谬解型把所观境解歪，无检型使该分辨时不分辨；两者都让染心以“无须再查”的面目获得行为出口。三尺齐证：一、看破难度**深**（谬解伪装成真相，无检型连检查需求都不起）；二、对治时间**长**（正知而住须贯穿行住坐卧及身语意一切威仪）；三、定力配合**强**（正知属慧用，但持续监察须由正念持境、由定承载）= **基底配置级 ✓**。见自为**负载阈值型双相现行**：正知底色强，高负载时谬解与失检局部出现；有真现行而不另立主修区，既有工作场与法贪通道足以覆盖。

**“大”的最终指代**：八法虽各从资粮、身心堪能、动力、守护、持境、安住、监察等不同岗位显现，所共同标出的不是某一件烦恼事相，而是**一切染心都会占据的基础配置层**。影响范围宽与对治深度深是两条独立轴；因基础配置不可能只靠一次事相看破完成，两轴在大随层稳定共变。

| 三类 | 最小修行学指代 | 典型对治动作 |
|---|---|---|
| **小随** | 现行事相级 | 就具体发作看破、截断 |
| **中随** | 不善质地级 | 立惭愧，转换善与不善的心质地 |
| **大随** | 染心基础配置级 | 长期建设念、定、慧与善法守护网络 |

## §三 五象限归属网络

### 3.1 五象限分判

基于 §一 已建立的"分位假立 vs 等流别立"+ 经典核对《成唯识论》卷六三家立场，随烦恼的归属分为**五象限**（经典护法立场严格归类）：

| 类型 | 安立机制 | 大随 | 小随 | 中随 |
|---|---|---|---|---|
| **A. 对称对偶**（6 法）| 别立实有染心所 ↔ 唯善的善心所 | 不信、懈怠、掉举\*、惛沉 | — | 无惭、无愧 |
| **B. 染分对偶**（2 法）| 别境（通三性）+ 痴俱起 = "俱一分摄" | 失念、不正知 | — | — |
| **C. 功能性反对**（1 法）| 别立实有 + 业用反对别境的善功能 | 散乱 | — | — |
| **D. 复合分位**（1 法）| 多根本烦恼 + 别立的复合分位 | 放逸 | — | — |
| **E. 分位假立**（10 法）| 是某根本烦恼在特定境的别名 | — | 全部 10 法 | — |

\* **掉举**派系诤议最大（贪一分摄 / 别有自体 / 俱一分摄三家），本项目沿用《成唯识论》护法立场归 A，但**掉举单法精修时需处理三家立场张力**。

> **B 类经典明文支持**：《成唯识论》卷六立场三明立"俱一分摄"——失念 = 念分 + 痴分俱起 / 不正知 = 慧分 + 痴分俱起。详见 [定.md §定的通三性与"染分对偶"](../别境心所/定.md)。
>
> **C 类经典明文支持**：《成唯识论》卷六护法立场——散乱「别有自体，说三分者是彼等流。如无惭等非即彼摄。若离彼三无别自体，不应别说障三摩地」。

### 3.2 大随 8 法的内部分组

| 大随 | 归属 | 安立机制（《成唯识论》卷六） |
|---|---|---|
| 不信 | A 对称对偶 | 护法别有体 ↔ 信（归类无诤议）——招式第四次落地：自秽 + 秽他·污染"心净趋向"公共基底 |
| 懈怠 | A 对称对偶 | 别立实有 ↔ 精进（**无诤议**·对偶精进体性最鲜明 vīra → 别立无压力 = 护法招式收束 / 终点） |
| **掉举** | **A 对称对偶**（三家诤议）| 护法：别有体 ↔ 行舍 / 集论传：贪一分摄 / 瑜伽传：俱一分摄 |
| 惛沉 | A 对称对偶 | 护法：别有体 ↔ 轻安——「虽与痴相似而非即痴」 |
| **失念** | **B 染分对偶** | 立场三"俱一分摄"：念分 + 痴分俱起——2026-07-06 精修：三家定夺（影略 + **遍染心论证**〔念唯缘曾习境、不遍染心 → 痴分补遍〕）；"一分" = **外延切片**（念通三性、切染相应一片，异于 D 之"分位" = 功能合名）；两形态 = **劫持型**（贪嗔征用染念）/ **空缺型**（唯痴分单撑·覆境 + 覆失）；俱舍**不立此法**（染污念即大地法念之染位）→ 唯识"立名不立体"、与放逸反向互证，详见 [失念 §二 §三](./失念.md) |
| **不正知** | **B 染分对偶** | 立场三“俱一分摄”：慧分 + 痴分俱起——2026-07-17 精修：影略说 + **遍染心论证**〔慧不遍一切染心，痴分补遍〕；“一分”同失念，属别境染位外延切片；两形态 = **谬解型**〔慧分显著 + 痴分〕/ **无检型**〔痴分单撑〕；俱舍同样不重立染污慧，故与失念共同完成“立名不立体”类型，详见 [不正知 §一 §三](./不正知.md) |
| **散乱** | **C 功能性反对** | 护法：别有自体 + 业用反对定——2026-07-15 精修：三家定夺（瑜伽痴分 / 集论三分 / 护法别体）；**两刀 + 一变体**（对手从单根还原换成三分合摄、外延无缺口 → 第一刀变形为**行相统一式**〔别相躁扰一相不能由三体拼出 + 令俱生法皆流荡〕+ 独立业用〔不应别说障三摩地〕= 招式线第五次"是"）；C 型结构解释 = **劫持 / 破坏 / 反面三分**（染定仍是"住"、"不住"切不出切片 → 散乱是定的**矛盾项**、掉举是**干扰项**〔对行舍〕），详见 [散乱 §二](./散乱.md) |
| **放逸** | **D 复合分位** | 护法明文「非别有体」：「由懈怠及贪嗔痴，不能防修染净品法，总名放逸」——2026-07-02 精修：组合逻辑正解 = **不放逸守护配置的逐位反占**（非"与"〔贪嗔不俱〕非"或"〔遍染非触发·所依恒 ≥ 懈怠 + 痴〕）；纵荡"特性真体假"（推究无剩余）；俱舍立实体对照 = **招式线反向验证**（两刀能输出"否"），详见 [放逸 §二](./放逸.md) |

→ **大随 8 法跨四类**（A 4 + B 2 + C 1 + D 1），不是齐一的"染心基底配置"，而是**四种不同体性来源**的染心合集。

### 3.4 慢 / 疑 / 恶见无直接对应随烦恼

观察上图，**慢 / 疑 / 恶见三法没有直接对应的随烦恼**。可能的解释（§六 主线 4 验证后的最终归位）：

| 候选解释 | 内容 | §六 验证结论 |
|---|---|---|
| 已有细分 | 慢有七慢九慢、恶见已分五见——慢 / 见在根本烦恼内部已细化 | 部分成立 |
| 行相不属"染心基底配置" | 慢 / 疑 / 见的现行更属"分别智判断层"，不构成大随基底 | 部分成立 |
| **间接对应** | 通过染分 / 复合机制间接对应 | **部分成立**（详见 §六 主线 4） |

**间接对应的最终归位**（§六 主线 4 现量验证后）：

| 间接对应 | 验证结论 |
|---|---|
| 疑 ↔ 不信 | **部分成立**——不信涵盖染疑某些功能分量，但俱生疑通过根本疑直接显现，不通过大随通道 |
| 慢 ↔ 掉举 | **部分成立**——掉举是 L4 位置慢在第六识层的事件层显现（依末那"举我"而起），但 L4 位置慢有更广场域 |
| 慢 ↔ 憍 | 修行者位置上憍**不现行**（假说 18 现量印证）|

## §五 元结构反思——随烦恼为何"纷繁复杂"

### 5.1 观察验证

百法心所法 51 中：随烦恼 20 法 = **单类心所法中最多**；染心心所合计 26 法（根本 6 + 随烦恼 20）= 心所法 51 中的 **51%**；善心所 11 法 = 染心心所的 **42%**。

复杂性体现在**三个维度**：
- 数量维度：20 法 = 单类最多
- 结构维度：§三 五象限分类（A 6 / B 2 / C 1 / D 1 / E 10）= 跨 5 类对偶机制
- 派系诤议维度：散乱 / 失念 / 不正知 / 掉举 / 惛沉 / 放逸 等多家立场 = **大随 8 法中 6 法有派系诤议**

对比善心所：11 法，基本同性质（唯善），派系诤议**极少**。

### 5.2 为什么有这个结构——三层原因

**原因一：凡夫位的现量基础**——经典安立基于凡夫位的现量观察。凡夫位染心现行远多于善心，所以染心心所细分必然多于善心。

**原因二：染心的"颠倒性"本身要求多样化**——善向道一，染道百千。善心朝向解脱方向统一，染心多样化（"颠倒"有无量种类）。

**原因三：修行学对治的精确需要**——粗糙的"我有烦恼"无对治入口；精确到具体心所形态 → 对治路径精确。**染心心所精细化 = 对治精度的前置条件**。

### 5.3 经典精细化的修行学目的

| 层次 | 精细化的目的 |
|---|---|
| **认识层（闻）** | 提供"染心多样形态"的精确诊断框架——修行者认得自心烦恼的具体类型 |
| **修行层（思）** | 提供事相级 + 基底配置级 + 法染色层 的多层对治入口 |
| **解脱层（修）** | 染心细分越精确 → 对治越精准 → 染种势力逐法递减 |

→ 这与经典立场"佛说八万四千法门对治八万四千烦恼"严格同构——**烦恼的精细化 ↔ 对治法门的精细化**。

### 5.4 精细化的边界——三重条件筛选

经典精细化并非无限细分，**20-24 是经典共识的边界**。三重条件筛选：
- **体性差异**（必要条件）：每一法必须有独立可辨的体性
- **业用差异**（必要条件）：每一法必须有独立的业用
- **修行学需要**（必要条件）：每一法必须对应独立的对治入口

→ 经典 20 法是三重条件筛选后的最简精细化集合，不是任意切分。

### 5.5 与子阶段 1 收官产出的深层接续

**接续 1：染心精细化 → 修行者现量分诊精度持续深化**

子阶段 1 收官评估"修行者已具备自身修行学的现量分诊师姿态"——这正是染心精细化的修行学落地。

**接续 2：染心多样化 vs 修行者单一对治通道（主座 A 三重统一）**

> **修行学的"诊断精细化 + 对治通道统一化"双线**：诊断侧精细化（经典立场）+ 对治侧通道统一（主座 A）——看似矛盾实则严格互补。

**接续 3：法染色层主战场命题 = 染心精细化在慧根利者位置的具体显现**

慧根利者已穿透方便层，必然要面对俱生层的精细化（法贪 + 末那附着 + L4 复合 + 法嗔 + 微细谤圣贤）。

### 6.1 主线 1：不信作为染疑的"基底配置"形态

**经典依据**：不信四要素结构（《成唯识论》卷六）：
- **所缘三面**：实（真实道理）/ 德（三宝功德）/ 能（自他修证能力）
- **作用三分量**：忍（深忍可）/ 乐（欣乐）/ 欲（希求）
- **体性**：心净（信）/ 心秽（不信）

**现量分诊产出**：

| 不信分量 | 修行者位置上的现行 |
|---|---|
| **不忍**（对实不深忍可） | **结构性不现行**（思维底层深忍可已稳） |

| **不欲**（对能不希求） | **结构性不现行**（善法欲已动，信能胜解强） |
| **心秽**（心质地浊） | **不是基底浑浊，是烦恼现行时的事件层遮蔽** |

**关键揭示**：

> **修行者位置上不信结构性不构成"基底配置"——四要素全部降级为事件层偶发遮蔽**。这与经典"心性本净，客尘所染"立场严格对接（修行者已现量印持）。

**衍生候选第三层假说**：**大随八在修行者位置上从基底配置降级为事件遮蔽**——这是与凡夫位"染心基底"普遍立场不同的修行者位置精确分诊（不是命题矛盾，是适用位置差异）。

**信乐两种质地路径**（修行者画像信德冷质地的精化）：

| 路径 | 修行者位置现行 |
|---|---|
| (a) 热质地路径（虔诚 / 情感欢喜） | 不升起（信德冷质地）|
| (b) 冷质地路径（法理认可 + 功绩印持的底层欣乐） | **强烈存在** |

> **2026-06-29 单法精修落实（降级首例 + 信乐分面校正）**：① 四要素经现量复核**未发现残留**（守"未发现 ≠ 确证无"、不下强断言）——降级首例成立、且是大随**最强降级形态**（连掉举那种事件层残形都现量未发现；因不信着力点 = 心净趋向公共基底，恰是修行者最先稳的地基）。② 上"信乐两种质地路径"表**精化为按所缘面分质地**：实面（法理）= **热质地法喜**（闻思打通现场起毛喜·浑身发麻毛孔竖立 = 《清净道论》小喜）/ 德面（三宝人格化）= 冷质地；"信德冷质地"**精确限定为"德面冷"、不泛化到实面**（实面强热），冷质地 ≠ 不乐（趋向在欣乐在、只是不热）。③ 修行者懈怠**不走"不信 → 懈怠"链**（不信不现行），懈怠根 = 精进力 + 痴一分（saṃvega 紧迫感未通透）。详见 [不信 §三 §五](./不信.md)。

| **不信不澄净** | 心质地未趋向（质地维度）|

→ 俱生疑独立于大随通道——通过根本疑直接显现，不通过随烦恼层安立。

**慢 ↔ 掉举（关键不对称发现）**：

| 关系 | 现量结构 |
|---|---|
| 掉举现行 → | **必有**末那"举我"伴随（不可分离）|
| L4 位置慢现行 → | **不必有**掉举伴随（可独立现行）|

→ L4 位置慢（末那层基底，可独立）⊃ 掉举（第六识事件层，依末那"举我"而起）。**层次差 + 依存关系**，非严格同构。

**慢 ↔ 憍**：

修行者位置上憍**不现行**——"秉持评判'境'而不评判'我'"= **假说 18（对象转换元假说）的现量稳态化印证**。

**恶见 ↔ 不正知 + 失念（不正知精修后的边界校正）**：

分别起恶见可依经典行相梯度，整理出“**一次带染分判 → 谬解叙事相续 → 推度、印持成见**”的第二层发生学；失念之“不持”与无检型不正知之“不查”，可解释错误叙事何以长期未被校正。但须守三重边界：

1. 三阶段是项目基于经典行相梯度所作的整理，不是经典明立的次第；
2. 失念与不正知是解释性缺位，不能抬成一切恶见形成的独立必要条件；
3. **俱生见不重走三阶段**。它由无始熏成的种子直接现行，只能说现行刹那有染慧、正念缺位、正知缺位的共时局部同构，时间轴与发生学整体悬置。

### 6.6 §六 综合新揭示（候选第三层假说）

**揭示 1：正念是修行者位置的全场域元基底通道**

主座 A 三重统一的实质 = 稳定正念 + 扩散无我相，在 4 个维度（触受激活 / 染心三阶段 / 场域 B / L4 慢）上均是元守护。"明记的自然度"作为单一现量检验，是此元命题的修行学落实。

**揭示 2：分别起染见与善修三步只有有限的时间结构对照**

| 善方修行三步循环 | 染方现行三阶段 |

| 常态（任运稳态） | 恶见（染种稳态） |

→ 这张表只适用于**分别起染见**的解释性发生学，可帮助观察“单次分判如何被重复熏成稳定倾向”。它不是严格对称律：不正知不等于一切染认知累积，恶见也不等于一般染种稳态；俱生见更不在此时间序列中。保留的是有限类比，撤回“染心与善心三阶段严格对称”的普遍命题。

**揭示 3：法染色层主战场命题在大随八层的精确显现**

**揭示 4：意识层大随八显现域与正念稳态成平台性反比（八法齐检后的定稿）**

正念稳态越强，染心刹那在意识相续中的可占域越窄，大随八的显现域整体随之收缩。这个关系只说正念为清净心所运作提供共同平台，不把正念写成八法的逐一直接对治。
