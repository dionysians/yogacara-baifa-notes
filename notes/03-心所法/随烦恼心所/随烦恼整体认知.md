## §一 随烦恼的总安立——"随"字的体性意义

### 1.1 "随"字两义

经典对"随烦恼"的定义涵盖**两个独立含义**：

| 维度 | 经典表述 | 解读 |
|---|---|---|
| **随他起** | 随根本烦恼分位起 / 等流起 | 业用上的依赖性——随烦恼不能脱离根本烦恼独立现行 |
| **唯染心起** | 唯于染污心位现行 | 业用范围上的限定——不通三性，只在染心位现行（区别于遍行 / 别境通三性） |

二义合起来 = 随烦恼是"于染污心位、随根本烦恼起的染心所"。

> **经典依据**：《成唯识论》卷六：「随烦恼，谓唯是烦恼分位差别，等流性故，名随烦恼。」
> 《瑜伽师地论·本地分》卷五十八：随烦恼分四类（缠 / 随眠 / 随烦恼 / 缠之等流），本项目所学的"随烦恼 20 法"对应于"随他起 + 唯染心"的狭义安立。

### 1.2 "随他起"的精确化——分位 vs 等流

"随他起"内部还需精确分判，这是理解每一随烦恼归属的核心结构：

| 类型 | 含义 | 是否别立实有 | 典型例 |
|---|---|---|---|
| **分位假立** | 是根本烦恼在特定分位（特定境 / 特定时段）的别名，无独立体 | 否（依根本立） | 忿 = 嗔的现前粗相分位 / 恨 = 嗔的怀怨分位 |
| **等流性** | 是根本烦恼的等流果，与根本烦恼同类相续，但有自体 | 是（别立实有） | 无惭 / 无愧 / 不信 / 懈怠等（《成唯识论》立别有体） |

**关键诤议**：哪些随烦恼是分位假立、哪些是等流别立实有——各家不同（小乘有部 / 经部 / 唯识各异）。《成唯识论》倾向"无惭无愧 + 不信懈怠放逸 + 失念不正知散乱"等大随中部分为别有体，其余多为分位假立。这是 §三 归属网络图必须直面的细节问题。

### 1.3 随烦恼为何独立列出而非归入根本烦恼

如果随烦恼"随根本而起"，为何不直接归入根本烦恼？三个理由：

**理由一：行相业用差异**——随烦恼的现行相状与根本不同。如"忿"现起时虽以嗔为体，但有自己特殊的现行相（暴怒 / 拳脚 / 言语攻击的具体形态），与单纯的"嗔"在事相上可分别识别。修行对治需要这种事相级精度。

**理由二：部分别立实有**——若全是根本的分位，归入根本即可。但《成唯识论》立"无惭无愧 / 不信懈怠放逸 / 失念不正知散乱"等为别有体（非根本之分位），它们必须单列。

**理由三：对治善心所的对偶要求**——善心所 11 法中有 8 法（精进、不放逸、行舍、惭、愧、信、轻安、不害）与随烦恼直接对偶：
- 惭 ↔ 无惭 / 愧 ↔ 无愧 / 信 ↔ 不信 / 精进 ↔ 懈怠 / 不放逸 ↔ 放逸 / 行舍 ↔ 掉举 / 轻安 ↔ 惛沉 / 不害 ↔ 害
- 若不立随烦恼，善心所的对治对偶失去对象。这反过来证明随烦恼必须单列。

### 1.4 与"根本"的本体差异

| 维度 | 根本烦恼（6） | 随烦恼（20） |
|---|---|---|
| **体** | 各别立实有体 | 部分别立、部分分位假立 |
| **生起力** | 能生其他烦恼（"本"义） | 不能生其他烦恼（"随"义） |
| **遍三界 / 三性** | 遍三界（欲 / 色 / 无色），唯染 | 范围因法而异（小随只在欲界第六识 / 大随通三界） |
| **现行场域** | 任运 + 分别 | 部分仅分别（如忿恨多分别）、部分通俱生（如无惭无愧、大随八） |

## §二 小/中/大三类的安立依据

### 2.1 三轴判定标准

《成唯识论》卷六立**三轴**判定随烦恼的三类归属：

| 轴 | 判定问题 | 三类对应 |
|---|---|---|
| **轴一：行相粗细** | 现行的相状粗暴还是微细？ | 小（粗）→ 中（中）→ 大（微细） |
| **轴二：自类俱起** | 同类随烦恼之间能否同时现行？ | 小（各别起，不俱）→ 中（无惭无愧必俱起）→ 大（八法之间互相俱起，常多法并现） |
| **轴三：遍染心程度** | 现行的染心范围有多广？ | 小（行相粗、范围窄）→ 中（遍一切不善心）→ 大（遍一切染心 = 不善 + 有覆无记） |

三轴是**联动**的，不是独立判定：行相微细 → 自类相互能俱起 → 遍染心范围广，三者共同指向"染污心的基底"性质。

> **经典依据**：《成唯识论》卷六：「言小随者，自类俱起，行相粗猛，各别现行，故名小随。」「中俱遍不善心故名为中。」「染心皆遍故名为大。」

### 2.2 小随烦恼 10 法的安立特征

**10 法**：忿、恨、覆、恼、嫉、悭、诳、谄、害、憍

| 维度 | 特征 |
|---|---|
| 行相 | 粗（暴怒 / 怀怨 / 隐藏 / 嫉妒 / 吝啬 / 欺诈 / 谄媚 / 加害 / 傲慢 / 憍举——都是具体可识别的行为相状） |
| 自类俱起 | **各别起**——忿起时无恨同时起 / 嫉起时无悭同时起 / 等。一时一法 |
| 遍染心 | **窄**——主要在欲界第六识相应、部分通色界。不遍欲界 |
| 现行场域 | 主要在**分别**位（依特定境、特定时段、特定经验起），不通俱生 |

**根本烦恼归属（先列，§三 细化）**：
- **嗔系**（5）：忿、恨、恼、嫉、害
- **贪系**（2）：悭、憍
- **贪痴一分**（3）：覆、诳、谄

### 2.3 中随烦恼 2 法的安立特征

**2 法**：无惭、无愧

| 维度 | 特征 |
|---|---|
| 行相 | 中（不像小随那样有具体外显行为相，但能直接识别） |
| 自类俱起 | **二法必俱起**——无惭起时无愧也起、反之亦然。是一对结构性绑定的染心所 |
| 遍染心 | **遍一切不善心**（关键限定：只在"不善"心位、不在"有覆无记"心位） |
| 现行场域 | 通分别 + 俱生（不善心位必现行） |

**为什么"中"只有 2 法？** 答案在**"不善"的定义本身**：

> 唯识立"不善心"的定义 = "与无惭无愧相应的染心"。
> 反之，染心若无无惭无愧俱起，即不是"不善"，而是"有覆无记"。

→ 无惭无愧是"不善心位"的**结构性标记**，二法成对承担"不善 vs 有覆无记"的区分功能。这就决定了中随不能多——多了就破坏这个标记的紧密性。

### 2.4 大随烦恼 8 法的安立特征

**8 法**：掉举、惛沉、不信、懈怠、放逸、失念、散乱、不正知（沿用《成唯识论》顺序）

| 维度 | 特征 |
|---|---|
| 行相 | **微细**（不一定有外显行为，多为心识内部的扰动 / 钝重 / 不信 / 懈怠 / 失念等基底状态） |
| 自类俱起 | **互相俱起**——八法之间常多法并现，几乎是染心的"背景配置" |
| 遍染心 | **遍一切染心**（不善 + 有覆无记都遍）——这是最广的范围 |
| 现行场域 | **俱生 + 分别都遍**——特别是俱生位的染心基底 |

### 2.5 三类划分的修行学含义

| 类 | 修行对治姿态 |
|---|---|
| **小随**（行相粗、各别起、分别为主） | **事相级对治**——每一法对应具体场域，事件场识破即可 |
| **中随**（无惭无愧、不善心位的结构性标记） | **善心所对偶级对治**——惭愧建立 = 中随结构性瓦解的入口 |
| **大随**（行相微细、染心基底配置） | **基底配置级对治**——禅定 / 念力 / 信力 / 精进力的整体建设，对应主座 A + 不放逸触发点 + 信的修习路径 |

### 2.6 小随 10 法收官 · "小"的指代提炼（2026-06-16 憍精修产出）

小随 10 法精修走完（憍收口）后回填。**出发点不是立假设，是搞清楚经典把随烦恼分小 / 中 / 大到底在指什么**——以下是整理 10 小随特性提炼出的"小"之指代（主要是**第二层框架整理**，在经典三轴之上、离经典近）。详见 [憍.md §四](./憍.md)。

**两种"看破深度"先分清**（关键厘清）：① **现行级看破深度**（停这一次现行要多深）；② **究竟断深度**（断种子要多深）。**"小"指前者、不指后者**——小随之"小"= 它现行出现时就处在浅层；害的深层俱生颠倒属究竟断（跟嗔根走），不是衡量"小"的尺。故"**看破深度（现行级）= 表层**"覆盖**全体 10 小随含害**（早期"脚手架厚薄"度量被害打破已弃；不需害的两形态）。

**"小"的指代**（经典三轴 + 修行学侧共变、同指一件事）：

| 维度 | "小"的内容 | 来源 |
|---|---|---|
| 行相 | 粗（具体可识别事相）| 经典轴一 |
| 自类 | 各别起 | 经典轴二 |
| 遍染心 | 窄（欲界第六识为主）| 经典轴三 |
| **看破深度（现行级）** | **浅层——现行出现即在表层，浅层看破即停现行** | 修行学侧整理 |
| **离究竟** | **远（事相级对治，事件场识破即可）** | 看破深度等价表述 |

→ **小随 = 染心最表层、最事相的一类**。贯穿小随的三条整理**归位为"小"之指代的角度**（非待立假说）：**双重假**（所缘世俗建构无自性 → 故浅层破建构即停）/ **常驻动机**（贪系维持机制、保全型覆悭诳 / 自熏型谄憍，作用域限贪系）/ **两参数无剩余**（根本分 × 发作方式、E 类可完全重构无独立深度）。

**据此预测中 / 大**：小 / 中 / 大 = 染心**由表及里的深浅层次**，看破深度 / 对治深度是贯穿三者的统一尺——中随 = 不善心位结构性标记（深一层 · 善心所对偶级）/ 大随 = 染心基底配置（最深 · 基底配置级）。**"小"已提炼实；"中"已于 2026-06-24 中随两法精修落实（见 §2.7）；"大"待提炼。**

### 2.7 中随两法收官 · "中"的指代落实（2026-06-24 无惭无愧精修产出）

中随两法（无惭无愧）精修走完后回填，**确认 §2.6 的"中"预测成立**。详见 [无惭无愧合论 §六](./无惭无愧合论.md)。

**"中"的本相 = 不善心位的结构性标记**：无惭无愧 = 把"迷暗的染心"推成"生长恶行的不善心"的那个增量；[不善](../../../resources/cards/不善.md)（感苦果）vs 有覆无记（染而不造恶）的全部差别卡在它。中随不是某类具体染相，而是"这颗心是不善的"这个质地标记本身——遍一切不善心、不遍有覆无记。

**为何恰好 2 法**：标记一个不善心需恰好覆盖善恶标尺**两面**（自法面 → 无惭 / 世间面 → 无愧），每个恶两面俱全 → 需且仅需二法。"2"是"两面"决定的，非随意。

**"中"的指代**（经典三轴 + 修行学侧共变、同指一件事）：

| 维度 | "中"的内容 | 来源 |
|---|---|---|
| 行相 | 中（无外显行为相、可直接识别） | 经典轴一 |
| 自类 | 必俱起（定不相离） | 经典轴二 |
| 遍染心 | 遍一切不善心、不遍有覆无记 | 经典轴三 |
| **对治深度** | **深一层 · 善心所对偶级——立惭愧（非破事相）、且搭惭愧通道不另立** | 修行学侧落实 |
| **离究竟** | 中（比小随事相级近一步、未到大随基底层） | 对治深度等价表述 |

→ **中随 = 染心"不善那一格"的结构性标记**。对治从小随的"逐事相**破**（破世俗建构）"升到"**立**惭愧换心的善 / 不善质地"，且**搭惭愧通道、不另立**（骨架 §6.5 已安排）。**统一尺确认**：小 = 现行级表层事相破 / 中 = 善心所对偶级立质地 / 大 = 基底配置级（待大随落实）。

### 2.8 大随八法 · "大"之指代待落实区（2026-06-25 掉举起步·证据累积中）

**状态：起步预演、未落实**。"小"在憍收官落实（§2.6）、"中"在无惭无愧收官落实（§2.7）；"大"待大随八法（掉举 → 惛沉 → 不信 → 懈怠 → 放逸 → 失念 → 散乱 → 不正知）走完后落实、回填本节。掉举一法（首法）已起步累积证据、符合"基底配置级"预测。

**框架精化一 · "大"有两个独立但共变的维度**（2026-06-25 修行者自立）：

> **影响范围（宽 / 遍染心）** 与 **对治深度（深）** 是两条**独立轴**，但**共变**——因"**能在浅层处理就不会成为基底**"，凡宽到成基底者必然也深。但仍须**分别对待**（宽→深是趋势、由基底性驱动，不是定义；落实"大"时两维分列、注明共变机制，不合并）。

**框架精化二 · 对治深度三把尺**（修行者操作化，量小 / 中 / 大三**层级**·非连续谱）：

| 对治深度尺 | 小随 | 中随 | 大随 |
|---|---|---|---|
| **a. 看破难度** | 浅（事相一看即破） | 中（须立惭愧换质地） | 深（基底、须禅定下沉才看破） |
| **b. 对治需要的时间** | 短（事件场即时识破） | 中（惭愧任运需熏） | 长（念力 / 信力整体建设、经年累月） |
| **c. 需要的定力配合强度** | 几乎不需（慧简择即可） | 中（须一定相续） | 强（须主座 A 强定力配合） |

三尺单调同向递增、坐实"三层级对治深度"；尺 c 接慧定不匹配 / 主座 A（大随对治 = 主座 A 整体建设）、尺 b 接看破→熏种→常态（大随熏种周期最长）。**落实"大"时即用三把尺量八法是否齐证"基底配置级"。**

**掉举起步证据**（详见 [掉举 §六](./掉举.md)）：行相微细 / 自类俱起 / **遍一切染心**（比中随"遍不善心"宽一层，= 别有体外延论据，§5.3）/ 对治深度预测 = 基底配置级（禅定 / 念力整体建设）。看破深度尺到目前连续：小（事相级·表层破建构）→ 中（对偶级·立惭愧换质地）→ 大（基底配置级·整体建设）。

## §三 五象限归属网络

### 3.1 五象限分判

基于 §一 已建立的"分位假立 vs 等流别立"+ 经典核对《成唯识论》卷六三家立场，随烦恼的归属分为**五象限**（经典护法立场严格归类）：

| 类型 | 安立机制 | 大随 | 小随 | 中随 |
|---|---|---|---|---|
| **A. 对称对偶**（6 法）| 别立实有染心所 ↔ 唯善的善心所 | 不信、懈怠、掉举\*、惛沉 | — | 无惭、无愧 |
| **B. 染分对偶**（2 法）| 别境（通三性）+ 痴俱起 = "俱一分摄" | 失念、不正知 | — | — |

## §五 元结构反思——随烦恼为何"纷繁复杂"

### 5.1 观察验证

百法心所法 51 中：随烦恼 20 法 = **单类心所法中最多**；染心心所合计 26 法（根本 6 + 随烦恼 20）= 心所法 51 中的 **51%**；善心所 11 法 = 染心心所的 **42%**。

复杂性体现在**三个维度**：
- 数量维度：20 法 = 单类最多
- 结构维度：§三 五象限分类（A 6 / B 2 / C 1 / D 1 / E 10）= 跨 5 类对偶机制
- 派系诤议维度：散乱 / 失念 / 不正知 / 掉举 / 惛沉 / 放逸 等多家立场 = **大随 8 法中 6 法有派系诤议**

对比善心所：11 法，基本同性质（唯善），派系诤议**极少**。

### 5.2 为什么有这个结构——三层原因

**原因一：凡夫位的现量基础**——经典安立基于凡夫位的现量观察。凡夫位染心现行远多于善心，所以染心心所细分必然多于善心。

**原因二：染心的"颠倒性"本身要求多样化**——善向道一，染道百千。善心朝向解脱方向统一，染心多样化（"颠倒"有无量种类）。

**原因三：修行学对治的精确需要**——粗糙的"我有烦恼"无对治入口；精确到具体心所形态 → 对治路径精确。**染心心所精细化 = 对治精度的前置条件**。

### 5.3 经典精细化的修行学目的

| 层次 | 精细化的目的 |
|---|---|
| **认识层（闻）** | 提供"染心多样形态"的精确诊断框架——修行者认得自心烦恼的具体类型 |
| **修行层（思）** | 提供事相级 + 基底配置级 + 法染色层 的多层对治入口 |
| **解脱层（修）** | 染心细分越精确 → 对治越精准 → 染种势力逐法递减 |

→ 这与经典立场"佛说八万四千法门对治八万四千烦恼"严格同构——**烦恼的精细化 ↔ 对治法门的精细化**。

### 5.4 精细化的边界——三重条件筛选

经典精细化并非无限细分，**20-24 是经典共识的边界**。三重条件筛选：
- **体性差异**（必要条件）：每一法必须有独立可辨的体性
- **业用差异**（必要条件）：每一法必须有独立的业用
- **修行学需要**（必要条件）：每一法必须对应独立的对治入口

→ 经典 20 法是三重条件筛选后的最简精细化集合，不是任意切分。

### 5.5 与子阶段 1 收官产出的深层接续

**接续 1：染心精细化 → 修行者现量分诊精度持续深化**

子阶段 1 收官评估"修行者已具备自身修行学的现量分诊师姿态"——这正是染心精细化的修行学落地。

**接续 2：染心多样化 vs 修行者单一对治通道（主座 A 三重统一）**

> **修行学的"诊断精细化 + 对治通道统一化"双线**：诊断侧精细化（经典立场）+ 对治侧通道统一（主座 A）——看似矛盾实则严格互补。

**接续 3：法染色层主战场命题 = 染心精细化在慧根利者位置的具体显现**

慧根利者已穿透方便层，必然要面对俱生层的精细化（法贪 + 末那附着 + L4 复合 + 法嗔 + 微细谤圣贤）。

**接续 4：触受爱憎链统一开关命题——精细化的统一基础**

所有俱生层染心现行的"开关"= 触受激活状态。**染心精细化（20 法）= 触受激活后的具体分形**。

## §六 子阶段 1 命题在随烦恼中的预演关联（五条主线）

> 本节是骨架文档中**允许节内现量预演**的章节。按 CLAUDE.md 子阶段 2 持续验证目标的优先级，整理为 5 条主线，分别完成现量验证。本节的现量产出直接影响 §七 学习顺序 + 单法精修阶段的对治路径设计。

### 6.1 主线 1：不信作为染疑的"基底配置"形态

**核心命题**：大随"不信"是否是子阶段 1 染疑（俱生疑 + 染疑）在染心基底配置层的稳态化形态？

**经典依据**：不信四要素结构（《成唯识论》卷六）：
- **所缘三面**：实（真实道理）/ 德（三宝功德）/ 能（自他修证能力）
- **作用三分量**：忍（深忍可）/ 乐（欣乐）/ 欲（希求）
- **体性**：心净（信）/ 心秽（不信）

**现量分诊产出**：

| 不信分量 | 修行者位置上的现行 |
|---|---|
| **不忍**（对实不深忍可） | **结构性不现行**（思维底层深忍可已稳） |
| **不乐**（对德不欣乐） | **结构性不现行**（信乐走非情感性的法理认可路径 = 冷质地路径，不是"不乐"）|
| **不欲**（对能不希求） | **结构性不现行**（善法欲已动，信能胜解强） |
| **心秽**（心质地浊） | **不是基底浑浊，是烦恼现行时的事件层遮蔽** |

**关键揭示**：

> **修行者位置上不信结构性不构成"基底配置"——四要素全部降级为事件层偶发遮蔽**。这与经典"心性本净，客尘所染"立场严格对接（修行者已现量印持）。

**衍生候选第三层假说**：**大随八在修行者位置上从基底配置降级为事件遮蔽**——这是与凡夫位"染心基底"普遍立场不同的修行者位置精确分诊（不是命题矛盾，是适用位置差异）。

**信乐两种质地路径**（修行者画像信德冷质地的精化）：

| 路径 | 修行者位置现行 |
|---|---|
| (a) 热质地路径（虔诚 / 情感欢喜） | 不升起（信德冷质地）|
| (b) 冷质地路径（法理认可 + 功绩印持的底层欣乐） | **强烈存在** |

→ 信德冷质地 ≠ 不乐分量。冷质地路径走的是法理认可层的欣乐 = 经典"信乐"分量的非情感性形态。

### 6.2 主线 2：触受爱憎链统一开关命题的边界扩展——两场域结构性分离

**核心命题**：俱生层烦恼现行的开关 = 触受爱憎链的激活状态。本主线验证命题在随烦恼层的边界。

**现量分诊产出（关键修正）**：

子阶段 1 命题在大随八层不是简单成立，而是揭示**两场域结构性分离**：

| 场域 | 状态 | 对治通道 |
|---|---|---|
| **场域 A：触受激活场域** | 有外缘激活 → 触受爱憎链启动 → 烦恼现行（含俱生层） → **正念在此场域运作正常** → 能如实快速消化 | 主座 A 三重统一 + 现量识破 |
| **场域 B：无所缘 / 懈怠懒散场** | 无明确目标 / 无事 / 双不足模式 → **触受爱憎链未启动** → 惛沉 / 懈怠通过身心条件 + 痴根直接基底化 | 不放逸触发点 + 念力稳态化 + 善法欲激活 |

→ **两场域结构性分离**——不存在"念力上层守护"的连续谱，两场域各自独立运作各自的染心通道，对治路径也各自独立。

**触受爱憎链统一开关命题的精确归位**：

> 命题在**场域 A（触受激活场域）严格成立**——大随八作为伴生遮蔽随触受消退而消退。
> 命题**不覆盖场域 B（无所缘 / 懈怠懒散场）**——这是独立的"双不足模式"通道，惛沉 / 懈怠在此场域通过身心条件 + 痴根直接基底化，由不放逸触发点 + 念力稳态化独立对治。

**各法在两场域的归位**：

| 法 | 现行结构 |
|---|---|
| **覆** | 结构性不现行（修行者立"心口相应、知行合一"原则；自主分诊真正问题在见取见维度）|
| **掉举** | 场域 A 严格符合——法贪境激活 → 心举（**法染色层主战场在大随层的精确显现**）|
| **惛沉** | **场域 B 为主**——大随八中**唯一仍有基底化通道**的法（"正念不在场时，惛沉就是基底"）|
| **无惭无愧** | 候选符合主线 1 结论——"烦恼不过夜" → 不善心位无稳态化机会 |

### 6.3 主线 3：B 染分对偶 + C 功能性反对的现量验证

**失念现量产出**：
- 实修主战场（主座 A）现量进展信号——正念熏稳趋势在累积，"差距很远"诚实评估
- **染念分诊能力 ✓**——能现量分诊善念形态 vs 染念形态
- 场域 B 双不足模式伴随失念现行

**不正知现量产出**：
- **法染色层主战场的精确事件层入口**（修行者自主立）：

> **"追究理论封闭、追求更多关联、过度挖掘的时候"**

这是子阶段 1 收官路径风险 #4（法贪伪装为善法欲）的事件层警觉点**现量精确化**——法贪部分的现量入口。

**关键结构性新揭示（修行者自主立）——染慧 / 不正知 / 恶见 三阶段分诊**：

> **不是连续谱，是三个不同阶段，有明确的边界**：
> - **染慧** = 一次带染的分判（刹那级事件）
> - **不正知** = 带染的认知（多刹那级累积）
> - **恶见** = 已成内容的理解（跨刹那种子级稳定化）

→ **染心三阶段严格对应种子-现行-熏习模型**。

**散乱现量产出**：
- 修行者位置散乱**极少现行**——场域 A 偶现 / 场域 B 不现行 / 主座 A 中极少
- **散乱 ≠ 惛沉**（修行者自主立结构性区分）：散乱（C 功能性反对）= 心流荡到多境 / 惛沉（A 对称对偶）= 心钝重沉重，二者不在同一维度

### 6.4 主线 4：慢 / 疑 / 恶见无直接对应随烦恼的间接对应假说现量验证

**疑 ↔ 不信 补充验证**：

| 维度 | 现量本质 |
|---|---|
| **俱生疑** | 现量印持未到位（现量维度）|
| **不信不澄净** | 心质地未趋向（质地维度）|

→ 俱生疑独立于大随通道——通过根本疑直接显现，不通过随烦恼层安立。

**慢 ↔ 掉举（关键不对称发现）**：

| 关系 | 现量结构 |
|---|---|
| 掉举现行 → | **必有**末那"举我"伴随（不可分离）|
| L4 位置慢现行 → | **不必有**掉举伴随（可独立现行）|

→ L4 位置慢（末那层基底，可独立）⊃ 掉举（第六识事件层，依末那"举我"而起）。**层次差 + 依存关系**，非严格同构。

**慢 ↔ 憍**：

修行者位置上憍**不现行**——"秉持评判'境'而不评判'我'"= **假说 18（对象转换元假说）的现量稳态化印证**。

**恶见 ↔ 不正知 + 失念（最关键修正，修行者自主立）**：

> **失念并不是一个特定的阶段，正是因为路径全程失念，最终才滑入恶见。**

→ **失念位置的精确修正**：

| 法 | 修行学位置 |
|---|---|
| **染慧 / 不正知 / 恶见** | 染心三阶段的内在演化序列 |
| **失念** | **不在三阶段内**——是三阶段演化的**全程基底缺位**（正念缺位）= **必要条件**，不是事件 |

→ 失念 = 正念缺位（与经典严格一致：失念 = "于所缘境不能明记为性"= 明记力失 = 正念的缺位）。

### 6.5 主线 5：主座 A 三重统一通道在随烦恼层的具体落地路径

主座 A 三重统一的实质（主线 4 元命题归位）：

> **稳定正念 + 扩散无我相 = 全场域元基底通道**

**通道分工图（最终版）**：

```
─── 场域 A: 触受激活场域 ───
  主座 A 三重统一 = 稳定正念 + 扩散无我相
  
  覆盖法 (7 法 = 5 大随 + 2 中随):
  ├─ 不信 (主线 1 — 不构成基底, 主座 A 自然守护)
  ├─ 掉举 (L4 扩散主轨)
  ├─ 失念 (核心通道 — 稳定正念本身)
  ├─ 不正知 (比量披甲下沉)
  ├─ 散乱 (心一境性扩散)
  ├─ 无惭 (惭愧从究竟层运作) — 中随
  └─ 无愧 (惭愧从究竟层运作) — 中随

─── 场域 B: 无所缘 / 懈怠懒散场 ───
  不放逸触发点 + 念力稳态化 + 善法欲激活
  
  覆盖法 (3 法 = 3 大随):
  ├─ 惛沉 (双不足模式精确显现)
  ├─ 懈怠 (双不足模式精确显现)
  └─ 放逸 (D 复合分位)

─── 小随 10 法 (E 分位假立) ───
  根本烦恼对治通道 (子阶段 1 已建立)
  
  覆盖法 (10 法):
  ├─ 嗔系 5: 忿、恨、恼、嫉、害 → 嗔操作核 (子阶段 1 已闭合)
  ├─ 贪系 2: 悭、憍 → 无贪
  ├─ 贪痴一分 3: 覆、诳、谄 → 无贪 + 无痴 双通道
```

**总数验证**：场域 A (7) + 场域 B (3) + 小随通道 (10) = 20 = 中随 2 + 大随 8 + 小随 10 ✓

**重要学术原则**（修行者主动立）：**结构归属（按经典体性）vs 现量现行（按修行者位置）是两个独立维度**。修行者位置不现行 ≠ 通道覆盖。小随中即使修行者位置不现行的法（如覆 / 憍），通道仍归"根本烦恼对治通道"，单法精修时需做现量验证。

### 6.6 §六 综合新揭示（候选第三层假说）

**揭示 1：正念是修行者位置的全场域元基底通道**

主座 A 三重统一的实质 = 稳定正念 + 扩散无我相，在 4 个维度（触受激活 / 染心三阶段 / 场域 B / L4 慢）上均是元守护。"明记的自然度"作为单一现量检验，是此元命题的修行学落实。

**揭示 2：染心 / 善心三阶段严格对称**

| 善方修行三步循环 | 染方现行三阶段 |
|---|---|
| 看破（慧+无痴一次识破） | 染慧（一次染分判） |
| 熏种（念定反复熏） | 不正知（染认知累积） |
| 常态（任运稳态） | 恶见（染种稳态） |

→ **善 / 染都在同一时间-结构中演化**——修行学元命题候选：修行 = 把善方时间结构推向纵深 + 把染方时间结构反向解构。

**揭示 3：法染色层主战场命题在大随八层的精确显现**

掉举 = 法贪境激活的伴生现象 = 法染色层主战场（法贪 + 末那附着 + L4 复合 + 法嗔）在大随层的精确显现。对治掉举不需要新增独立通道——对治法染色层主战场 = 自动对治掉举。

**揭示 4：大随八基底化程度与念力稳态成反比（候选假说）**

念力稳态化越深 → 大随八基底化越降级为事件遮蔽；念力失念时 → 大随中"身心基底型"染心所（惛沉 / 懈怠）可基底化。

## §七 学习顺序——经典顺序（生起次第解读）+ 见自见众双线

### 7.1 学习顺序最终方案

```
  忿 → 恨 → 覆 → 恼 → 嫉 → 悭 → 诳 → 谄 → 害 → 憍

第二组 (中随 2 法):
  无惭 → 无愧

第三组 (大随 8 法, 按经典顺序):
  掉举 → 惛沉 → 不信 → 懈怠 → 放逸 → 失念 → 散乱 → 不正知
```

### 7.2 学习思路——生起次第解读 + 见自见众双线

每学一法同步做**四件事**：

| 维度 | 操作 |
|---|---|
| **染心动态网络** | 追问"前一法如何导致这一法的现行？后一法如何被这一法推动？" → 形成染心生起次第的动态认识 |
| **见自维度**（子阶段 1 已成熟） | 修行者现量分诊——该法在修行者位置上的现行 / 不现行 / 通道归属（参 §6.5 分工图） |
| **见众生维度**（本主线引入） | 该法在凡夫普遍现行的形态 / 触发条件 / 修行学含义——为后续菩萨道学习储备见众生染心运作的精确认识 |
| **结构关联**（§一-§六 已建立） | 该法在五象限的归属 / 与根本烦恼的关系 / 与子阶段 1 命题的接续 |

### 7.3 经典顺序的合理解读——生起次第（凡夫染心现行链）

经典安立从凡夫日常染心的**自然现行链条**出发：

```
境违 (对违缘) → 忿 (当下暴怒)
              ↓
              恨 (忿后怀怨不舍)
              ↓
覆 (因恶恐失利养 / 怕被发现 → 隐藏过失)
              ↓
              恼 (忿+恨+覆的累积 → 追触暴热)
              ↓
他荣现起 → 嫉 (不耐他荣)
              ↓
              悭 (向己物吝啬不施)
              ↓
名利场域 → 诳 (矫现德行欺人)
              ↓
              谄 (奉承曲意)
              ↓
              害 (损恼有情)
              ↓
自盛现起 → 憍 (染著自盛事)
```

→ 这是一个**凡夫染心的现行剧本**：从对境（违境 / 他荣境 / 自盛境）的反应展开。

### 7.4 子阶段 2 的修行学双线（首次明确）

> **子阶段 2 学习随烦恼 = "见自 + 见众" 双线**：
> - **见自线**：延续子阶段 1 的现量分诊师姿态——每法在修行者位置上的现量验证
> - **见众生线**：通过染心生起次第学习凡夫普遍现行链条——为利他善巧轴 / 权智补缺奠定染心认知基础

→ 这是子阶段 1 → 子阶段 2 的**质的演化**：从"自我分诊"扩展到"自他兼诊"，与[修行者画像 §九 利他善巧轴缺口](../../实修/修行者画像.md) 形成**主动呼应**而非被动等待菩萨道学习。
