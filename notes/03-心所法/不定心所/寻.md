## 一、概念定义

### 原文
> 寻者，令心匆遽，于意言境，粗转为性，以为依止，发杂语业为业。

又《成唯识论》云：
> 寻谓寻求，令心匆遽，于意言境，粗转为性。

### 白话解释
寻，即寻求、寻思，是心对意识所缘境界进行粗略探索、推度的心理活动。它使心匆忙急促地在意言境（意识中的语言概念境界）上运转。"粗转"指其运作方式比较粗糙、浮泛。寻能引发各种言语活动（杂语业），因为我们说话前总要先在心中寻思。善恶不定——如寻求佛法义理是善，寻思恶计是恶。

### 梵文/巴利文
- **梵文**: vitarka
- **音译**: 毗怛迦
- **词源**: vi（分别）+ tarka（推度），意为粗略的推度、寻思

## 二、详细说明

### 核心特征
1. **令心匆遽**：使心匆忙急促地运转
2. **于意言境粗转**：在意识语言概念的层面粗略运作
3. **善恶不定**：寻善则善，寻恶则恶
4. **发杂语业**：是言语活动的内在基础

### 作用与功能
- 在心中进行粗略的探索和推度
- 引发言语活动
- 对境界进行初步的概念化把握
- 是思维活动的粗分

### 生起条件
- 意识的活动
- 对境界的关注
- 概念和语言的运用
- 只在意识中生起（不在前五识和第七、八识）

### 相关概念
- **相似概念**: 伺（细察，与寻相对，寻粗伺细）
- **对立概念**: 无寻无伺（二禅以上的境界）
- **协同概念**: 伺（寻伺常一起讨论，寻粗伺细，二者配合运作）

### 关系图示
```
不定心所之"寻"：

寻 vs 伺：
- 寻：粗转 → 对境界的粗略推度、搜寻
- 伺：细转 → 对境界的细致审察、伺察

禅定中的寻伺：
初禅：有寻有伺 → 粗细思维都有
二禅：无寻唯伺 → 只有细察
三禅以上：无寻无伺 → 超越概念思维

寻 → 发杂语业 → 言语活动
（心中先寻思，然后才说出来）
```

## 六、学习心得

### 理解要点
- 寻与伺是一对：寻粗伺细，如同大范围搜索与精细审查
- "意言境"很关键：寻是在语言概念层面的活动，是内心的自言自语
- 寻与禅定密切相关：初禅有寻伺，到二禅以上就逐渐超越
- 寻是言语的内在基础——先有内心的寻思，才有外在的语言

### 理解难点
- 寻与一般"思"的区别
- "意言境"的确切含义
