## 一、经典定义与基本槽位

《成唯识论》卷七说：

> 寻谓寻求，令心匆遽，于意言境，粗转为性；伺谓伺察，令心匆遽，于意言境，细转为性。此二俱以安、不安住身心分位所依为业。并用思、慧一分为体，于意言境不深推度及深推度，义类别故；若离思、慧，寻、伺二种体类差别不可得故。

《瑜伽师地论》卷五又说：

> 寻伺所缘者，谓依名身、句身、文身，义为所缘。寻伺行相者，谓即于此所缘，寻求行相，是寻；即于此所缘，伺察行相，是伺。寻伺等起者，谓发起语言。

据此可立六个基本槽位：

| 槽位 | 内容 |
|---|---|
| 所缘 | 依名、句、文所表之义，即意言境 |
| 行相 | 令心匆遽，于意言境粗转、不深推度 |
| 体性 | 思、慧一分所假立；离开思、慧，不能另得寻的独立体性 |
| 业用 | 作为身心安住或不安住分位的所依，并可成为发起语言的条件 |
| 识位 | 护法正义判唯与第六意识相应 |
| 性类 | 通善、不善、无记三性，依相应心、所缘与造作方向分判 |

“不定”不表示寻没有体性或恒属无记，而表示它的善染性质和现起分位都不能预先固定。

## 二、寻何以成立

### 2.1 意言境不是单指内心语言

“意言”不能简单等同于心里正在说一句话。《瑜伽师地论》把寻伺所缘说成依名身、句身、文身所表之义，重点在**名义所表的对象**：意识已经把某境安立为可以指认、比较、推求的意义单位，寻才在其上运转。

例如听见异响时：

1. 耳识直接取得声音；
2. 第六意识把它现为“这个尚未辨明的声音”；
3. 寻在“它可能是什么”这一意言境上粗略探求；
4. 若已经确定“这是窗户被风吹动的声音”，其中还会有想的取相、慧的判断和胜解的印持，不能把整个辨认过程都归给寻。

寻不负责从完全没有对象的状态中创造对象，也不要求意识事先已经知道正确答案。它需要的是一个最低限度已形成的意义单位；“这个尚不知道是什么的声音”本身便足以成为待探求之境。

### 2.2 意识如何先形成并铭记对象

同一认知事件中，各法岗位不同：

| 心法或心所 | 主要岗位 |
|---|---|
| 前五识 | 直接取得色、声等各自境 |
| 第六意识 | 取得其可被名言分别的意义面 |
| 想 | 于境取相，安立可以辨认、称说的标记 |
| 念 | 对已经取得之境明记不忘 |
| 作意 | 引心趣向该境 |
| 思 | 推动心朝某一方向造作 |
| 慧 | 对所缘作简择判断 |
| 寻 | 在已形成的意言境上粗略探求可能方向 |

因此，区分和铭记一个对象并不是寻单独完成的。想使对象成为可指认之相，念使其不失，已有名言与经验种子提供可用的辨认材料；寻只承担其中的粗略探求。

> **第二层：经典框架的应用整理。**“最低限度意义单位”和上表的岗位分工，是依想、念、思、慧及寻的经典体性所作的结构化说明，不是论典原有的一套认知流程术语，也不表示每次事件都机械地依此顺序发生。

### 2.3 匆遽与粗转

“匆遽”描述心在意言境上趋求、转动的行相，不等于焦虑、慌乱，也不能单凭钟表速度判断。一个人外表安静，意识仍可能在若干候选意义之间迅速探求；另一个人动作很快，却可能只是熟练执行，并无寻现行。

“粗转”也不是粗糙、错误或浮泛，而是相对于伺的细转而言：

- 寻先粗略取得方向，属于不深推度；
- 伺沿已经取得的方向细加审察，属于深推度。

所以，寻佛法义理可以正确而属粗转；细密谋划不善之事也可以精细而属伺。粗细说的是处理层级，不是善恶与正确程度。

### 2.4 思慧一分：可单独安立，不是别有实体

《成唯识论》总判寻伺并用思、慧一分为体；《瑜伽师地论》从粗细差别侧重说，不深推度的寻以思为体，深推度的伺以慧为体。共同结论是：寻伺离开思慧没有另一个独立体性，因此论中判二者定是假有。

“假有”不表示寻没有作用，而表示：

1. 本体上不能在思慧之外再找到一个寻；
2. 功能上又确有“在意言境上粗略探求”的稳定构型；
3. 为保存这一可辨认的作用、善染差别、发语关系及禅定界地，唯识将它单独安立为一法。

> **第二层：复杂系统类比。**思、慧等成分共同运作，可以形成单个成分名称未直接表达的新功能；新功能值得单列研究，却不因此成为离开诸成分的实体。这一类比帮助理解“假有而有用”，不是经典原有表述。

### 2.5 与相邻心所的辨异

| 心所 | 判准 | 与寻的区别 |
|---|---|---|
| 想 | 于境取相、安立名言 | 使对象可辨认，不等于在候选方向中探求 |
| 作意 | 引心趣境 | 只说明心被引向哪里，不说明如何粗略搜索 |
| 思 | 令心造作 | 提供推动力，但不必具有意言境上的探求行相 |
| 慧 | 于所观境简择 | 判断功能比寻更宽，不必处于寻找方向的阶段 |
| 伺 | 于意言境细转、深推度 | 已沿某一方向细察，不是粗略取得方向 |
| 散乱 | 令心于诸所缘流荡 | 判准是偏离应住所缘，不是有没有搜索或切换 |

由此，内容丰富、语言很多、思考很久或注意发生切换，都不能单独证明有寻；关键仍是当下是否在意言境上作粗略探求。

## 三、寻何以善染不定

### 3.1 三性看当前配置与方向

寻通三性，不能由“思考”这个表面名称直接判断：

| 性类 | 典型结构 |
|---|---|
| 善寻 | 为理解正法、利益他人或完成善行，粗略探求可行方向，并由善心所摄持 |
| 不善寻 | 为伤害、欺骗、贪取等目的寻找办法，由烦恼与不善方向摄持 |
| 无覆无记寻 | 寻找普通物品、安排日常工巧事务，没有明显善恶方向 |

同一题目也可能前后变性。例如先为如实解决问题而寻，后来转成维护自我位置或压倒他人，事件名称未变，寻的相应配置已经改变。

### 3.2 善染与安住是两条轴

《成唯识论》说寻伺是身心安住或不安住分位的所依，不能把“安住”直接等同于善，把“不安住”直接等同于染：

| 寻的性质 | 身心分位 | 可能情形 |
|---|---|---|
| 善寻 | 不安住 | 为找到正确修法或解决善行中的难题，心暂时在多个方向间探求 |
| 善寻 | 安住 | 已善巧掌握探求范围，在总境内有序寻找 |
| 染寻 | 安住 | 专心寻找报复、欺骗或满足贪欲的办法 |
| 染寻 | 不安住 | 烦恼牵引下反复搜索，身心躁动不定 |

这里的身心安住也不自动等于别境定，更不等于已经证得静虑。善染、安住、定境必须分别判断。

### 3.3 有寻不等于散乱

寻可以在总所缘内部寻找不同方面，而不离开当前任务；散乱则令心离开应住所缘而流荡。因此：

- 有寻，可以没有散乱；
- 无寻，也可以有散乱；
- 多个候选方向，只要都受同一总任务统摄，不因数量多便直接判散乱。

例如围绕同一问题列出若干解释，仍持有“解决此问题”的总境，可以有寻而无散乱；已经停止寻找，却转去攀缘无关内容，则可以无寻而有散乱。

> **第二层：经典框架的应用映射。**以“是否仍受当前应作的总境统摄”分判寻与散乱，接续本项目此前建立的复合总境判准，不是经典原句。

### 3.4 发起语言不等于必然说话

《瑜伽师地论》说寻伺的等起是发起语言，表明语言表达往往需要先在意言境上寻求或审察。但三点必须分开：

1. 有寻不必实际开口，内在探求可以止于意识；
2. 熟练、背诵或习惯性的语言，可以依既有势力迅速发出，不必在发语前另起明显的寻；
3. 寻提供内容方向，真正推动身语造作仍须依思及其他因缘。

所以，寻是发语的重要条件之一，不是每一句话唯一而必经的原因。

### 3.5 “想得多”不等于“思得深”

日常把搜索量、内容量、处理深度混成一个“思考很多”，会同时误判寻与伺：

- 候选多而仍在粗略找方向，可能是寻；
- 只审察一个方向而层层深入，可能是伺；
- 大量无关念头流荡，主要是散乱，不因内容多便成为寻；
- 已有明确判断的持续推演，可能主要由慧、念、思等运作，不必仍有寻。

判准不在“多少”或主观上觉得“深入”，而在心对意言境采取的是粗略探求、细密审察，还是已经离开探求阶段。

## 四、寻在识与禅定中的位置

### 4.1 护法正义：唯与第六意识相应

《成唯识论》先记载寻伺也可与前五识相应的异说，随后以护法正义判定寻伺唯与第六意识相应，理由包括：

1. 寻求、伺察是意识不共法；
2. 寻伺以名身等所表之义为境，前五识不以名义为所缘；
3. 经典说五识“有寻伺”，是显示五识多由与其俱起的分别意识所引，不表示寻伺直接与五识相应。

因此，耳识取得异响，第六意识中的寻探求“这是什么声音”。若已经认定声音来源，则不能继续把想、慧、胜解等整个辨认过程统称为寻。

### 4.2 寻伺同类粗细有异，不能同一刹那俱起

《成唯识论》说：

> 四中寻、伺定不相应，体类是同，粗、细异故。

同一刹那对同一意言境的处理方式，不能既是不深推度，又是深推度。但一个连续事件可以迅速交替：

```
列出几个可能方向（寻）
        ↓
沿一个方向细察（伺）
        ↓
发现不合，再找方向（寻）
        ↓
细察新的方向（伺）
```

事件层可以说寻伺都有，刹那层则不能说二者俱起。经典把初静虑立为有寻有伺，也是在该地、该定的相续与支分中二者俱可现行，不推翻护法系的刹那不相应。

值得补记的是：《俱舍论》卷四论主本人已破婆沙师"寻伺一心相应"之说，断言"寻伺二法定不可执一心相应"，并以「具五支言**就一地说，非一刹那**」会通初静虑五支——与唯识判断一致。故"不俱"不是唯识独有的立场（详见[伺 §三](./伺.md)）。

### 4.3 寻为什么可以与定俱起

《成唯识论》说四不定皆容与五别境相应，寻伺又可在初静虑中与轻安俱起；《瑜伽师地论》卷十一把寻、伺、喜、乐、心一境性列为初静虑五支。因此，寻与定并不相违。

定的一境性不要求所缘内部完全没有处理活动：

- 定使心持续持有同一总所缘；
- 寻可在该总所缘内部粗略寻找某一方面。

例如守住呼吸总境，同时寻找当下最清楚的触点，可以有定也有寻。这里只能证明两个心所相容，不能据此认定已经证得初静虑。

> **第二层：经典框架的应用映射。**“总境稳定、境内探求”的说明，接续本项目的复合总境结构，用来解释寻与心一境性为何不矛盾；经典没有使用“复合总境”这一术语。

### 4.4 随定境深化而舍离

《瑜伽师地论》卷十一说，初静虑尚未能观察寻伺之过，第二静虑能见其过，所以称为寻伺寂静。这里的“过”不是说寻伺伦理上必然染污，而是说：相对于更加一味、平等的定心，粗略探求与细密审察仍属内在动摇。

《瑜伽师地论》卷十二形容无寻无伺三摩地：

> 于寻伺心生弃舍，唯由一味，于内所缘而作胜解，又唯一味平等显现。

所以，定境深入时不是把善寻判为恶，而是连善性的探求功能也因不再适合该层安住而被舍离。

### 4.5 三地的准确边界

| 三地 | 界地边界 | 寻伺结构 |
|---|---|---|
| 有寻有伺地 | 欲界及初静虑 | 寻、伺在该地俱可现行 |
| 无寻唯伺地 | 静虑中间 | 已离寻，尚有伺 |
| 无寻无伺地 | 第二静虑以上至有顶 | 寻、伺俱离 |

“静虑中间”是初静虑与第二静虑之间的特定定地，不是泛指一个模糊过渡阶段。第二静虑已经无寻无伺；旧稿把第二静虑写成无寻唯伺、把无寻无伺推迟到第三静虑以上，属于错位，现已改正。

《成唯识论》卷七说：「依于寻、伺有染、离染立三地别，**不依彼种现起有无**，故无杂乱。」《瑜伽师地论》卷四更把这条讲成双向的：

> 由离寻伺欲道理故，说名无寻无伺地，**不由不现行故**。所以者何？未离欲界欲者……于一时间亦有无寻无伺意现行；已离寻伺欲者，亦有寻伺现行——如出彼定及生彼者。

即：欲界人有一段无寻无伺的心，不成无寻无伺地；已离寻伺欲者出定起寻伺，也不因此退失离染。因此必须分开：

| 层级 | 所回答的问题 |
|---|---|
| 刹那配置 | 当下有没有寻或伺现行 |
| 三地归属 | 该界地是否容许、是否已经远离寻伺 |
| 定境证得 | 修行者是否实际成就相应静虑 |

欲界中的一段心流即使暂时没有内语、寻或伺，仍属于欲界，不会因此成为无寻无伺地；打坐时一时无寻无伺，也不能据此认定证得第二静虑。

## 五、综合分诊与实例

### 5.1 四问分诊

> **第二层：经典框架的结构化整理。**以下四问是本项目整理的辨法次序，不是经典原有术语。

1. **有没有可探求的意言境**：若连最低限度的意义单位都未形成，寻无从现行。
2. **当前是否在粗略寻找方向**：已有方向后的细察偏于伺，明确判断偏于慧，单纯推动偏于思。
3. **是否仍在应住所缘内**：在总境内寻找不必散乱；离开总境流荡才需判散乱。
4. **由什么心所和方向摄持**：依相应配置判善、不善或无记，不能以安静、专注或内容复杂代替。

### 5.2 实例速查

| 情境 | 分判 |
|---|---|
| 听见异响，粗略寻找可能来源 | 耳识取声；第六意识中的寻在意言境上粗转 |
| 围绕同一佛法问题列出若干解释，始终未离总题 | 可有善寻而无散乱；候选多不等于流荡 |
| 专心寻找伤害或欺骗他人的办法 | 不善寻；安住、专注不能使它转成善 |
| 寻找放错位置的普通物品 | 通常可判无覆无记寻 |
| 已有一个解释，逐项核查其内在关系 | 偏于伺，不再是粗略寻求 |
| 停止寻找，却转而攀缘无关内容 | 可以无寻而有散乱 |
| 守住呼吸总境，寻找最清楚的触点 | 寻可与定俱起，但不足以证明初静虑 |
| 欲界中暂时没有内语与探求 | 当下可无寻，仍不属于无寻无伺地 |
| 人工智能生成多个候选答案，人再逐项审查 | 人工智能不安立心所；人的粗略找方向可判寻，沿候选细察可判伺 |

### 5.3 人工智能边界

> **第三层：自主推论。**依本项目既有立场，当前人工智能没有心识相续，不安立寻、伺等心所。它生成候选内容只能作为色法层面的功能镜像；使用者面对这些候选时，才可能真实现起寻、伺、慧、散乱等心所。输出像搜索或细察，不等于系统自身具有寻伺。

## 六、见众生：寻的常见误判

### 6.1 把“脑中很多话”都判作寻

内语只是可能的表现。若只是在回忆、重复已经确定的句子，可能主要是念与想；若大量内容偏离当前任务，则更应检查散乱。寻必须有粗略探求方向的行相。

### 6.2 把专注的寻判为善

染寻也可以高度集中，甚至使身心暂时安住。善染须看相应心所与造作方向，不能由效率、专注或安静反推。

### 6.3 把快速切换直接判为散乱

若多个对象都被一个复合总境统摄，切换仍可有序而不散乱；真正的散乱在于失去应住所缘。反过来，外表没有切换，心也可能已经黏着于无关境。

### 6.4 把一时没有寻伺当作深定

日常无内语、熟练执行或短暂空白，只能说明当下未见寻伺，不能说明已经离寻伺染，更不能证明证得第二静虑。

### 6.5 把语言生成能力当作有寻伺

能产生连贯语言，不等于存在心所。先检查是否有心识相续，再谈心所配置；不能从外在功能相似直接跨到唯识体性判断。

## 七、学习结论

1. 寻是在已经形成的意言境上粗略探求方向，不负责前五识取境，也不独自完成对象的取相与铭记。
2. 意言境是名、句、文所表之义，不限于明显的内心语言；未知对象只要已形成最低限度的意义单位，便可供寻求。
3. 匆遽不是焦虑，粗转也不是粗糙错误；粗细只表示寻与伺的不深、深推度之别。
4. 寻以思慧一分假立：功能可以单独辨认，本体却不能离开思慧另得。
5. 有寻不等于散乱，无寻也不等于无散乱；判准在是否仍持有应住所缘。
6. 寻通三性，善染与安不安住是两条轴；专注安住的寻仍可能不善。
7. 寻可以成为发语条件，但不必实际发语，也不是每一句语言的唯一必经原因。
8. 护法正义判寻唯与第六意识相应；前五识只直接取得各自境。
9. 寻伺同为思慧一分而粗细有异，不能同一刹那俱起，但可在一个事件中迅速交替。
10. 寻可与定俱起：总境由定持有，寻在境内取得方向；这不能单独证明初静虑。
11. 静虑中间是无寻唯伺地，第二静虑以上才是无寻无伺地。
12. 三地归属不依一刹那寻伺现起的有无；刹那配置、界地归属和定境证得必须分开。

## 八、学术诚实审查

### 第一层：经典依据

- 寻令心匆遽，于意言境粗转；寻伺以安、不安住身心分位所依为业，并用思慧一分为体——《成唯识论》卷七。
- 寻伺以依名身、句身、文身所表之义为所缘；寻为寻求行相，伺为伺察行相；二者能发起语言——《瑜伽师地论》卷五。
- 寻伺定是假有，离思慧不能另得其体；寻伺同类粗细有异，不同一刹那相应——《成唯识论》卷七。
- 护法正义判寻伺唯与第六意识相应；五识“有寻伺”是依俱起分别意识而说——《成唯识论》卷七。
- 寻伺容与五别境相应，并能在初静虑与轻安俱起——《成唯识论》卷七。
- 初静虑有寻有伺；第二静虑观察寻伺之过而得寻伺寂静；无寻无伺三摩地于内所缘一味胜解、平等显现——《瑜伽师地论》卷十一、卷十二。
- "依于寻、伺有染、离染立三地别，不依彼种现起有无，故无杂乱"——《成唯识论》卷七；"由离寻伺欲道理故，说名无寻无伺地，不由不现行故"及其双向说明——《瑜伽师地论》卷四。
- 《俱舍论》卷四论主破婆沙师"寻伺一心相应"说，断言"定不可执一心相应"，会通初静虑五支为"就一地说，非一刹那"。

### 第二层：经典框架的应用整理

- 以“最低限度意义单位”说明未知对象何时能够进入寻的所缘范围。
- 将想、念、作意、思、慧、寻分岗，并说明对象如何成为可探求、可铭记之境。
- 以复杂系统的新功能说明寻为何“可单列而非别有实体”。
- 以善染轴和安住轴分开判断寻，并用复合总境区分寻与散乱、寻与定。
- 区分寻伺在事件层的快速交替与刹那层的不相应。
- 将刹那配置、三地归属和定境证得分成三个层级。

### 第三层：自主推论

- 当前人工智能不安立心识与寻伺，其语言搜索能力只是功能镜像；真实寻伺发生在使用者心识中。这是本项目依唯识框架作出的判断，不是经典对现代人工智能的直接论述。
