## 一、经典定义与基本槽位

《成唯识论》卷七说：

> 悔谓恶作，恶所作业，追悔为性，障止为业。此即于果假立因名，先恶所作业，后方追悔故。悔先不作，亦恶作摄，如追悔言：“我先不作如是事业，是我恶作。”

《显扬圣教论》说：

> 于已作、未作善不善事，若染、不染，怅怏追变为体，能障奢摩他为业。

据此可立五个基本槽位：

| 槽位 | 内容 |
|---|---|
| 所缘 | 自己先前已经做过或没有做的事；论中又说于无记业亦可追悔 |
| 体性 | 追悔，亦即怅怏追变 |
| 业用 | 障碍止，使心难以寂静安住 |
| 识与界地 | 唯与第六意识相应，唯欲界有 |
| 性类 | 通善、不善、无记三性，须依当时条件分判 |

悔只在第六意识中现起，因为它需要缘先前造作并形成追悔性心变，不是前五识的任运取境作用。

---

## 二、“恶作”是于果假立因名

悔的真实体性是追悔，不是过去那件事本身。“恶作”是把原因之名安立在结果心所上：

```
先前已经做或没有做
        ↓
当前认定为“做得不好”
        ↓
随后生起追悔
        ↓
以原因“恶作”之名，称呼结果“悔”
```

因此：

- 后悔先前做了某事，是恶作；
- 后悔先前没有做某事，也属于恶作，因为当前把先前的“不作”认定为做得不好；
- “恶”不只等于客观伦理上的恶，也包含当前之心认定先前造作不合所愿；所以悔可以通三性。

---

## 三、体性定夺：没有“追变”便不是悔

### 3.1 仅仅认定“不该如此”还不够

下列心行都可以缘过去，却不必有悔：

- 念：记得先前发生过什么；
- 慧：判断先前行为的因缘、性质与后果；
- 惭愧：拒绝其中的不善；
- 思：决定现在如何补救及以后如何防护；
- 忧受：想到此事感到不悦。

如果只是如实知道“昨天那样说话不善”，继而决定道歉，心仍可以安住当下。只有当前之心对先前所作发生追悔性的回转，才成立悔。

### 3.2 “怅怏追变”不是三个机械相加的零件

“怅怏”“追”“变”共同描述一种完整的追悔行相，不宜拆成三个可以独立计数的成分：

- **怅怏**：对于已经成立的先前事实生起缺憾、不满；
- **追**：心回转追缘先前造作，不只是中性回忆；
- **变**：当前评价发生反转，认定先前本不应如此。

若“追”只作回忆讲，怅怏加回忆并不必然带有变；哀伤、失落也可满足前两项。因此，从经典定义看，没有追悔性的“变”便不是悔。

但“变”的最低含义是当前对先前造作发生评价反转，不必一律夸大成持续幻想过去真的能够重写。经典没有要求每一悔刹那都形成完整的反事实故事。

### 3.3 思慧可以覆盖部分，不能覆盖整体行相

念可覆盖追忆，慧可覆盖判断，思可覆盖驱动，忧受可覆盖不悦质地；但把这些全部列出，仍不能说明为何同样记得、知道、决定改正的人，有时平静处理，有时却出现独特的追悔回转。

不可还原者不是某一个单字，而是：

> 心缘自己先前所作或未作，生起追悔性心变的整体行相。

一次极短的追悔心变已经足以成立悔；反复持续只表示势力及障止作用增强，不是体性条件。

## 四、本体诤议：为何别立一法

论中对悔、眠是否别有体曾有多种意见：有说以痴为体，有说染分摄痴、净分摄无痴，有说恶作以思慧为体；护法一系判悔、眠各别有体，因为并非思、慧、想等法缠合便能穷尽其性，与其余心所行相有别。

别立悔不是为了无限增加心理名目，而是为了保存一个不能省略的变量：

1. **说明何者真正障止**：知道错误、惭愧拒恶、决定补救都不必然障止；追悔行相才有这一特殊倾向。
2. **解释同境异行**：同样缘过去，有人如实处理，有人持续回转，差别不能只由念、慧、思说明。
3. **显出戒通向定的中间关节**：戒行清净而得不悔，不悔生欢悦，继而趋向喜、止、乐、定；悔正位于戒与定之间的障碍节点。
4. **防止把痛苦等同忏悔**：悔通三性，痛苦与持续时间都不能证明道德性。
5. **解构“后悔的我”**：从百法无我的总方向看，所谓“我在后悔”可以分析为诸心心所因缘和合，不必固化成一个负罪主体。

### 复杂系统类比

> **第二层：经典框架的应用映射。**

不同心所可以共同构成一段复杂心理事件，但“有新功能出现”本身不等于别有体；若新功能可以完全还原为既有成分的分位，更接近假立。悔之所以别有体，是因为其中存在稳定而不可由思慧等完全替代的追悔行相。

---

## 五、综合分诊：定体、定性、定伴、定向

> **第二层：经典框架的结构化整理。**“定体、定性、定伴、定向”是本项目整理的统一分诊法，不是经典原有的四步术语。

### 5.1 定体：当下究竟有没有悔

检查三点：

1. 所缘是否是自己先前已作或未作；
2. 当前是否出现追悔性的评价反转；
3. 心是否仍以“先前本应不同”的方向回转过去。

仅有回忆、判断、拒恶或未来计划，都不足以单独成立悔。

### 5.2 定性：善悔、染悔还是无记悔

| 性类 | 典型结构 |
|---|---|
| 善悔 | 追悔先前不善或未作应作之善，当前由善法方向摄持 |
| 染悔 | 追悔先前行善、未遂染欲，或追悔事件被我相与染心方向统摄 |
| 无记悔 | 对普通生活、威仪或工巧选择产生追悔，没有明显善恶方向 |

先前事件只是所缘，不能单独决定当前悔心的性质。后悔恶行不必然是善悔，例如只因利誉受损而后悔；后悔的痛苦强度也不能证明惭愧深浅。

同一段“后悔经历”可以前后变性：先有善悔，随后转入维护自我形象、嫌恶自己，再出现染悔。日常所说的一次后悔，通常包含许多快速相续的心念，不能整体判作一个刹那。

### 5.3 定伴：区分同一刹那与同一事件

同一悔刹那中，思必然在场，因为思是遍行心所；善悔也可与慧、惭愧等善法共同运作。各法岗位不同：

| 心所 | 在事件中的岗位 |
|---|---|
| 念 | 明记先前事实 |
| 慧 | 分辨因缘、性质与后果 |
| 惭愧 | 拒绝其中的不善 |
| 悔 | 对先前造作发生追悔性回转 |
| 思 | 推动当前心与后续行为 |

染悔与根本烦恼能否同一刹那相应，经典解释有精度差异：《成唯识论》正文直说悔“但容与无明相应”；《成唯识论述记》一解把正文释为依多数情况而说，允许特殊情况下与贪、嗔、邪见、我见相应，另一解则判为快速间起。此处保留诤议，不据日常体验强行定夺。

正文只作事件层表述：维护自我位置的慢、嫌恶自己的嗔及染悔可以快速相续、彼此推动，不把“同一事件出现”直接写成“同一刹那俱起”。完整方法见[心所相应与刹那分判——教理精度与实修价值](../心所相应与刹那分判——教理精度与实修价值.md)。

### 5.4 定向：悔什么时候结束

分界不在于是否还记得过去，而在于当前是否仍在追变过去：

```
“过去本应异于事实”
        ↓
追悔行相占主导
        ↓
如实观察过去因缘
        ↓
处理现在仍可改变之事
```

当心仍记得、承认、分析过去，却已经不再要求过去不同，而完全转向现前可处理的因果时，悔已经结束；念、慧、惭愧、思和防护仍可继续。

## 六、与相邻心所及定的分辨

### 6.1 悔与惭愧

| | 悔 | 惭愧 |
|---|---|---|
| 所缘 | 自己先前已作或未作 | 自身及世间所对的贤善、暴恶 |
| 行相 | 对先前造作追悔、心变 | 崇重贤善、轻拒暴恶 |
| 性类 | 通三性 | 唯善 |
| 作用方向 | 回转过去 | 拒恶止恶，可在事前、事中、事后现行 |

同一过去事件可以同时成为悔与惭愧的所缘，但二者并不互相包含：可以知道其恶、拒绝其恶而没有悔；也可以只因个人得失追悔而没有惭愧。

### 6.2 悔与嗔、慢

自我攻击不是悔的定义。悔负责追变过去；嗔负责憎恚、损恼；慢依自我位置高举。三者可以在同一事件中快速相续，但不能仅凭“我很痛苦”判定当下是什么心所，也不能把整段事件写成一个混合体性。

### 6.3 悔与定、止

“障止”不等于与定心所绝对不相容。《成唯识论》说四不定皆容与五别境相应，因此心可以专注于追悔对象，定心所在场，却仍不具奢摩他的寂静安住。

```
定心所：心是否专注于所缘
奢摩他：心是否寂静、调柔、安住
```

悔障碍的是后者。障碍程度随悔的强度、持续及反复而异，没有一个离开具体条件的固定阈值。

### 6.4 悔与掉悔盖

掉悔盖把掉举与悔合列为障定的一盖，不表示二者同体。掉举令心不寂静，悔使心回转过去；两者都妨碍止，故在盖的功能层合说。

## 七、从悔到忏悔

### 7.1 悔是心所，忏悔是复合行法

悔只完成对先前造作的追悔性心变；忏悔则由多个心所及身语行为共同构成：

```
如实认过
  ↓
不再覆藏
  ↓
善悔先前所作
  ↓
发露、对治、补救
  ↓
建立以后不再造作的防护
  ↓
恢复清净方向
```

### 7.2 四力结构

《开示四法经》所说四力，经《菩提道次第广论》解释为：

| 四力 | 作用 |
|---|---|
| 能破坏现行力 | 对往昔不善生起真实追悔 |
| 对治现行力 | 修持能够对治恶业的善法 |
| 遮止罪恶力 | 建立后不再作的真诚防护 |
| 依止力 | 归依三宝，发菩提心 |

悔直接对应第一力，不能代替其余三力。若没有真实防护，悔罪容易成为空言。

### 7.3 发露、道歉、仪轨与补救各有岗位

| 环节 | 直接处理什么 |
|---|---|
| 发露 | 对治覆藏，不再维护与事实不符的清净形象 |
| 向当事人道歉 | 承认关系中的影响与伤害 |
| 仪轨忏悔 | 集中组织依止、追悔、对治与防护 |
| 实际补救 | 修复仍可改变的外在后果 |

四者不能互相替代，也不是每次都采用同一形式。具体戒律毁犯的发露对象及还净程序，须依相应戒律另行学习；百法阶段不自行设计。

### 7.4 忏悔改变的是因果延续，不是历史事实

已经发生的行为不会被改成没有发生。忏悔所改变的是这一造作在当前相续中继续被认同、覆藏、重复、增长及感果的因缘结构：

1. 止住合理化、覆藏和继续造作；
2. 以相反善法损减原有势力；
3. 建立防护，改变未来缘；
4. 对已经形成的现实后果尽可能补救。

> **第二层：经典框架的应用映射。**用复杂系统语言说，历史状态不可逆，但后续反馈结构和未来轨迹仍可改变；这不是经典原句。

### 7.5 忏悔以不悔为完成方向

忏悔不是不断加强悔，而是让善悔完成启动作用，由发露、对治、补救与防护接续。过失已经如实承担、能补救者已经补救、防护已经建立后，心不再需要以追悔维持道德方向。

```
犯过 → 善悔启动 → 发露与对治 → 补救与防护
                                      ↓
                                 事毕而不悔
                                      ↓
                                   心得安隐
```

因此，处理完成后坦然而不再追悔，不是惭愧不足，而是忏悔已经完成作用。

## 八、乙类愧边界的回看

悔的学习促成[愧](../善心所/愧.md)中乙类愧判准的收紧。须分两层检查：

1. **先前事件是否成为该愧之境**：检查当时是否确有贪、嗔、痴、慢、强加或损害等不善配置；单纯不够合宜、未达最优或无意差异，不应一律道德化。
2. **当前愧是否真实现行**：过去有过失只说明它适合作为愧的对象；当前还须真实以善心轻拒其恶，才是愧现行。

不善故意并不是承担影响的必要条件。即使先前只是合理误判，也可以由不害、慧和思向对方说明、调整及修复关系，但不必虚构一个“我造了恶”的愧与悔。

“愧对治向他人扩张我所”是本项目的第三层操作映射；经典直接说愧对治无愧、止息恶行，不能把项目映射写成经典原义。

## 九、实例速查

| 情境 | 分判 |
|---|---|
| 知道昨天言语伤人，决定道歉，心不回转过去 | 慧、惭愧、思可以在场，未必有悔 |
| 想到“如果昨天没有说那句话便好了” | 有追悔性心变，悔成立 |
| 捐款后因悭贪方向而追悔 | 染悔事件；贪与悔同刹那关系依论疏两解保留 |
| 对普通路线、工巧选择懊悔 | 可属无记悔 |
| 追悔伤人后发露、道歉、补救并防护 | 善悔进入完整忏悔过程 |
| 处理完成后仍记得并分析事件，但不再追变过去 | 悔已结束，念慧等仍可现行 |

---

## 十、学习结论

1. 悔的体性不是“知道先前不该如此”，而是缘先前造作所生的追悔性心变。
2. “怅怏追变”是完整行相；没有“变”便不是悔，但“变”不必夸大成持续幻想重写历史。
3. 思慧等可覆盖部分功能，却不能穷尽追悔整体行相，所以护法一系判悔别有体。
4. 悔障止，不等于不能与定心所俱起；专注追悔仍可缺少奢摩他的寂静。
5. 一刹那追悔已经成立，反复不是定义条件。
6. 善染须看当前为何追悔及整体心流，不能用所缘名称、痛苦强度或持续时间代替判断。
7. 同一事件不等于同一刹那；经典相应诤议应保留，但不增加实修操作负担。
8. 忏悔不是悔心所的别名，而是发露、对治、补救、防护及依止等共同组成的行法。
9. 忏悔所改变的是当前相续与未来因缘，不是抹除历史；以不悔、安隐为完成方向。
10. 乙类愧须先检查原事件的不善配置，不能把一切不够合宜都道德化。

## 十一、学术诚实审查

### 第一层：经典依据

- 悔以追悔为性、障止为业；“恶作”是于果假立因名——《成唯识论》卷七。
- 悔以怅怏追变为体，缘已作、未作善不善事——《显扬圣教论》相关心所段。
- 悔唯与第六意识相应、唯欲界有、通三性、容与五别境相应——《成唯识论》卷七。
- 悔、眠别有体及思慧等不能穷尽其性，是护法一系的体性定夺；论中同时保存异说。
- 四力为能破坏现行、对治现行、遮止罪恶及依止力——《开示四法经》，参《菩提道次第广论》卷五。

### 第二层：经典框架的应用整理

- “定体、定性、定伴、定向”四步分诊。
- 把“变”解释为最低限度的评价反转，不要求每次都形成完整反事实故事。
- 区分事件层共同出现与刹那层相应，并据实修价值采用双层书写。
- 把发露、道歉、仪轨、补救分岗，并以不悔作为完整忏悔的完成方向。
- 用复杂系统的反馈与轨迹说明忏悔改变未来因缘而不改变历史事实。

### 第三层：自主推论

- “愧对治向他人扩张我所”及惭愧的内外双轴，是本项目既有操作映射，不是经典对愧的直接定义。
- 将慢所维护的自我位置、嗔所形成的自我嫌恶与染悔写成事件层快速相续，是对日常心理事件的结构推理；不据此断定特定刹那必定俱起。
