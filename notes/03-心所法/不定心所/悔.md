## 一、概念定义

### 原文
> 悔者，恶作为性，障奢摩他为业。

又《成唯识论》云：
> 悔谓恶作，恶所作业，追悔为性，障止为业。此即于果假立因名。先恶所作业，后方追悔故。悔先不作，亦恶作摄。

### 白话解释
悔，又名"恶作"，是对自己先前所做之事感到后悔、懊恼的心理活动。它不仅包括对做了坏事的后悔，也包括对没有做好事的后悔。其性质不定——后悔做了恶事是善的，后悔做了善事是恶的。悔能障碍止（奢摩他/禅定），因为追悔会让心不能安定。

### 梵文/巴利文
- **梵文**: kaukṛtya
- **音译**: 恶作
- **词源**: kaukṛtya 源于 ku（恶）+ kṛta（已作），意为"对所做之事感到不好"

## 二、详细说明

### 核心特征
1. **恶作为性**：对先前所做（或未做）之事感到厌恶、后悔
2. **善恶不定**：悔善事则恶，悔恶事则善，故名"不定"
3. **障碍禅定**：追悔令心不能安住，障碍奢摩他（止）
4. **通于三性**：可以是善、可以是恶、可以是无记

### 作用与功能
- 追悔过去的行为（已做或未做）
- 善悔能促使忏悔改过
- 恶悔则障碍修行
- 障碍心的安定（障止）

### 生起条件
- 对过去行为的回忆和反思
- 对行为后果的认识
- 道德意识的觉醒（善悔）
- 贪嗔痴的影响（恶悔）

### 相关概念
- **相似概念**: 惭（对自己过错的羞耻，但惭是善心所，悔则善恶不定）
- **对立概念**: 无悔（心安不追悔）
- **协同概念**: 眠（悔与眠同属不定心所，且悔常在睡眠时扰动心绪）

### 关系图示
```
不定心所之"悔"：

善悔：后悔做了恶事 → 忏悔 → 改过迁善（善）
恶悔：后悔做了善事 → 退失善心（恶）
无记悔：后悔无关善恶之事（无记）

悔 ←→ 障碍 → 奢摩他（止/禅定）
     因为追悔令心不能安定

惭 vs 悔：
- 惭：当下对恶行的羞耻（善心所）
- 悔：事后对行为的追悔（不定心所）
```

## 六、学习心得

### 理解要点
- 悔的关键在于"善恶不定"——同一个心理作用，因对象不同而性质不同
- 悔与忏悔不同：忏悔是有方向的善行，悔则是单纯的追悔心理
- 修行中要善用悔（忏悔恶业）而不被悔所困（反复追悔障碍禅定）
- "悔"是以果立因名——先有恶所作业，后方追悔

### 理解难点
- 悔与惭、愧的区别（惭愧是善心所，悔则善恶不定）
- 如何在修行中正确运用悔（忏悔而不纠结）
