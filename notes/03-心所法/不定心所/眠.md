## 一、概念定义

### 原文
> 眠者，令心昧略为性，障观为业。

又《成唯识论》云：
> 眠谓睡眠，令身不自在，昧略为性，障观为业。谓睡眠时，身不自在，心极昧劣，一门转故。

### 白话解释
眠，即睡眠，是使心识变得昏昧、暗略的心理状态。它使身体不能自在运用，心识变得模糊暗淡，只在意识一门中运转。眠能障碍毗钵舍那（观），因为昏沉暗昧中无法进行清明的观照。其善恶不定——适度的睡眠能恢复精力利于修行（善），过度的贪睡则障碍修行（恶）。

### 梵文/巴利文
- **梵文**: middha
- **音译**: 弥陀
- **词源**: middha，意为睡眠、昏沉

---

## 二、详细说明

### 核心特征
1. **令身不自在**：睡眠时身体不能自由活动和运用
2. **心极昧略**：心识变得昏昧、暗淡、模糊
3. **一门转**：只在意识一门中运转（前五识不起）
4. **善恶不定**：适度为善，过度为恶，故属不定

### 作用与功能
- 令身心休息恢复
- 障碍毗钵舍那（观/正观察）
- 使心处于昏昧状态
- 适度睡眠维持修行体力

### 生起条件
- 身心疲劳需要休息
- 惛沉（随烦恼）的增盛
- 昼夜节律的自然需要
- 过饱、环境等外缘

## 三、与其他概念的关系

### 上位概念
不定心所 → 心所法

### 下位概念
无

### 相关概念
- **相似概念**: 惛沉（随烦恼心所，令心沉重昏暗，但惛沉是清醒时的昏沉，眠是实际睡眠）
- **对立概念**: 掉举（心浮动不安，与眠的昏沉相对）
- **协同概念**: 悔（悔与眠常一起讨论，五盖中有"掉悔盖"和"昏沉睡眠盖"）

### 关系图示
```
不定心所之"眠"：

善眠：适度休息恢复精力 → 有助修行（善）
恶眠：贪睡懈怠 → 障碍修行（恶）
无记眠：普通自然睡眠（无记）

眠 ←→ 障碍 → 毗钵舍那（观）
     因为昏昧中无法观照

惛沉 vs 眠：
- 惛沉：清醒时心的昏暗沉重（随烦恼心所，纯恶）
- 眠：实际的睡眠状态（不定心所，善恶不定）

五盖关系：
- 昏沉睡眠盖 = 惛沉 + 眠
- 掉悔盖 = 掉举 + 悔
```

## 六、学习心得

### 理解要点
- 眠不等于惛沉：惛沉是纯恶的随烦恼，眠则善恶不定
- 佛教不否定睡眠的必要性，但强调要适度
- 眠时仍有意识（做梦），但极为昧劣
- 眠障碍"观"（毗钵舍那），悔障碍"止"（奢摩他），合起来覆盖止观双修

### 理解难点
- 眠与惛沉的精确界限
- 梦中的心理活动如何归类
