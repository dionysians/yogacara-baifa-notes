# 假说 16：慧 + 无痴俱起的事件层分判（看穿 vs 绕过的精确机制）

> **状态**：活跃
> **创建**：2026-05-03
> **最后升级**：2026-06-04（疑学完后通过"疑现行=见的未稳定态"补全位精化——慧 + 无痴是稳定见的双条件）
> **历史升级**：2026-06-01（慢学完后烦恼方反向印证——增上慢 = 染慧的精确变体）
> **回链**：[CLAUDE.md 持续关注 § 假说网络](../../CLAUDE.md#持续关注隐性回填--假说批判性审视)

## 内容

慧通善恶无记三性，本身只是简择能力，简择方向需 锚：

- **无痴作 锚** → 慧的简择必向"如实"（不偏颠倒）
- **慧无无痴俱起** → 简择方向被颠倒驱使 = 染慧 / 邪见 / 当代变形为"看穿者我相"

### 事件层分判

| 配置 | 表现 | 性质 |
|---|---|---|
| 慧 + 无痴俱起 | 简择产物站得住反质疑（锚 不被末那带走），越质疑越如实 | 善慧 / 正见 / 看穿真者 |
| 慧无无痴俱起 | 简择产物 看似可信（因慧厚）但方向被末那"我相需要已看穿"驱使——表面看穿，实际是"看穿者我相" | 路径 风险 #3 的事件层运作 |

### 路径 风险 #3 的精确机制 锚

利根者风险大于钝根者——慧厚但无痴 锚 未稳时，末那能用慧的产出制造高 看似可信 的"看穿者我相"，比钝根者更难自检。

与 [假说 15](假说-15-anchor二阶二维-已闭合.md) 的二阶结构紧密关联：锚 缺位时反应面对治（慧的简择）也都是带我相的假对治。

## 潜在冲突点

经典对"慧通三性"立场明确，但对"慧无无痴时模拟看穿"是否有具体辨析？《成唯识论》护法派立场是否真支持本机制还是仅"染慧 / 邪见"的概念性描述？需在烦恼心所"邪见"学完后校准。

## 2026-06-01 升级：慢学完后烦恼方反向印证——增上慢 = 染慧的精确变体

慢单法精修（[慢.md §七.1](../03-心所法/烦恼心所/慢.md)）确认**增上慢[5]在结构上 = 慧 + 无无痴 = 染慧的精确变体**——具体表现为"**已证我相**"特例。

### 精确机制

| 配置 | 经典慢的对应 | 本假说机制 |
|---|---|---|
| 慧 + 无痴俱起 | 真证位（如实见自身修证状态）| 简择"我证 X / 未证 X"如实 |
| 慧无无痴俱起 | 增上慢（未证谓证 / 已证谓证）| 简择产物被末那"我相需要已证"驱使——表面"我已彻见 / 我已化解"，实际是**"已证者我相"** |

→ **增上慢 = 慧 + 无无痴 = 染慧的精确变体**——本假说原表述"看穿者我相"在修证面的精化形态为**"已证者我相"**，二者结构同质。

### 修行学含义

- **路径风险 #3 在慢面的具体显现**：利根 + 见地厚但无痴锚未稳时，末那能用慧的产出制造"我已证 / 我已彻见"的伪证位 = 增上慢
- **修行者位置**：D 项扫描"无抗拒 + 开放质疑"现量证据 = 固化型"已证者我相"已无；但**评判型增上慢**（"我评判一下我是否已证"——仍立评判主体）仍在场，需通过 v3 完整对治（识破"举我"+ 回到境）持续对治

### 修订表述

本假说原"看穿者我相"扩展为通用形态——**任何"我已 X"形态的染慧表达都是本机制的具体变体**：

| 慧的简择内容 | 慧 + 无痴 | 慧无无痴 |
|---|---|---|
| 实相 | 看穿真者 | "看穿者我相"（原表述）|
| 修证 | 真证位 | **"已证者我相" = 增上慢**（2026-06-01 新增）|
| 化解 | 真化解 | "已化解者我相" |
| 通达 | 真通达 | "已通达者我相" |

→ 所有形态共享同一结构：**慧的简择产物被末那做成"我已 X"位置**。

### 与假说 18 的接通

[假说 18（对象转换元假说）](假说-18-对象转换元假说.md)揭示更底层机制——**"已证者我相" / "看穿者我相" 等形态本质上是评价对象从境侧（实际状态）被替换到"我"侧（我作为持有者）的结果**。本假说"无痴锚 = 让慧不偏" 在假说 18 框架下精化为"**无痴锚 = 让慧的对象保持在境侧不被替换为'我'**"。

详见 [慢.md §七.1 + §九](../03-心所法/烦恼心所/慢.md)。

## 2026-06-04 升级：疑学完后通过"疑现行=见的未稳定态"补全位精化

疑单法精修（[疑.md §9.2](../03-心所法/烦恼心所/疑.md)）揭示**"疑现行 = 见的未稳定态"** —— 疑不是与见并列的另一心所，而是见在两可状态间未稳定的形态。这给本假说增加一个**补全位**：**没有慧的运作时见无法稳定，疑现行**。

### 慧 + 无痴 = 稳定见的双条件

| 状态 | 心所配置 | 见的状态 |
|---|---|---|
| 慧 + 无痴 俱起 | 真简择 | **见稳定**（疑灭）|
| 慧 + 无无痴（染慧）| "看穿者我相" / "已证者我相" | 见似稳但带"我已 X"染色 → 易触发 L4 慢 |
| **慧 缺位**（不简择）| **疑** | **见在两可未稳定** |
| 无痴 缺位 + 简择动作 | 染慧 → 增上慢 | 见错执已稳为"我已 X" |

→ 本假说扩展形态：**慧 + 无痴是稳定见的双条件；缺一则见有问题**：
- 缺慧 → 疑（见未稳定）
- 缺无痴 → 染慧（见错执已稳为"我已 X"）→ 增上慢

→ 见的稳定（疑灭）需要**慧 + 无痴双锚**——这给"为什么疑见所断"提供了机制层精确解释：见道时通过现观四谛 / 缘起 / 真如得见稳定，**就是慧 + 无痴俱起稳态运作**的现量呈现，疑同时消失。

### 修行学含义

- **疑维度的对治路径**：通过加强慧（朝决了简择）+ 无痴（明谛理）→ 见稳定 → 疑灭
- **慧根利者染疑结构性极低的精确机制**：慧根利 → 朝决了简择功能强 + 空性见早年内化 = 无痴锚强 → 见快速稳定 → 染疑入口被结构性截断
- **但俱生疑仍在**：凡夫位见的稳定主要在比量层，现量层仍有微细不稳定（俱生疑表现为"对甚深谛理比量接受但现量无真切印持"）

### 与四元结构（慧 / 疑 / 慢 / 见）的对应

疑精修打开的"慧 / 疑 / 慢 / 见"四元结构（[疑.md §四](../03-心所法/烦恼心所/疑.md)）实质就是本假说在见的不同状态下的运作展开：

| 心所 | 朝向决了 | 见的状态 | 与本假说的关系 |
|---|---|---|---|
| 慧 | 朝向 | 简择中 | 慧的本来运作 |
| 疑 | 反决了 | 两可未稳定 | 慧缺位 |
| 慢 | 已得决了 + 自抬 | 已稳但错用 | 慧 + 无无痴（染慧） |
| 见（恶见）| 偏决了 | 已稳但偏 | 慧 + 痴 + 颠倒推度 |

详见 [疑.md §四 + §9.2](../03-心所法/烦恼心所/疑.md)。
