## 内容（v3 + 5/14 五层 manifest 预演 = 当前生效版本）

### 五层 manifest 分层（2026-05-14 预演完整化，待行舍 / 不害学完后定稿）

5/14 不放逸学习中，修行者 push 行舍体性预演（详见 [行舍.md §0](../03-心所法/善心所/行舍.md)）让 v3 framework 在 11 善心所完整学完后的结构预演扩展为**五层 manifest 分层**：

```
反应面（事件层）:     无贪 / 无嗔            -- 对治染反应
anchor 面（条件层）:  无痴（frame）/ 轻安（phenomenal）  -- 提供见地 / 调畅 anchor
守护面（运作机制层）: 不放逸                 -- time domain 持续在场
任运面（运作质量层）: 行舍                   -- state domain 不被 sign/target 错位扭曲（5/14 预演）
利他面（饶益层）:     不害（待学）            -- 无嗔的特化展开
```

守护面 vs 任运面的 dimension 独立判定基于修行者 5/14 "开车比喻"——不放逸 = "始终在开"（time domain），行舍 = "自如驾驶 / 不追求速度致行驶不稳"（state domain）。两个反面性质对偶但不同层（放逸是 motion 中断，掉举是 motion quality 扭曲）。详见 [行舍.md §0.2](../03-心所法/善心所/行舍.md)。

### anchor 作为 v3 通用判别基准（2026-05-14 内在 derivation）

5/14 不放逸学习中，修行者 push 给出 v3 framework 一个**重要的内在 derivation**：**anchor 面不仅是体性 anchor，还是所有反应面 / 守护面 / 任运面的判别基准**：

```
anchor 面（无痴 / 轻安）  ←──── 提供判别基准
   ↓
反应面（无贪 / 无嗔）     ←── 染对治 in 反应面（事件层）
守护面（不放逸）          ←── 染对治 in 守护面（time domain）
任运面（行舍）            ←── 染对治 in 任运面（state domain）
```

没有 anchor 面在场，三个 manifest 面都退化为染对治（"我能放下 / 我不发火 / 我能不放逸 / 我能任运"我相）——与 [三善根整体认知 §五](../03-心所法/善心所/三善根整体认知.md) B 立场（无痴必随俱起）完全一致。详见 [不放逸.md §六](../03-心所法/善心所/不放逸.md) + [三善根整体认知 §五.5](../03-心所法/善心所/三善根整体认知.md)。

### 三层 manifest（5/12 完整化）

framework 完整化为**"反应面 + anchor 面 + 守护面"三层 manifest 分层**（5/12 不放逸验证通过）：

```
反应面（事件层）:    无贪 / 无嗔
anchor 面（条件层）: 无痴（frame）/ 轻安（phenomenal）
守护面（运作机制层）: 不放逸（精进+三善根力层涌现，跨遍前两层在 time domain 持续在场）
```

对应 11 善心所对治"贪嗔（反应）+ 痴 / 粗重（anchor）+ 放逸 / 惛沉 / 掉举（守护 / 调畅）"的功能分层。守护面 / 调畅面皆为"运作机制层"——非新 dimension 而是 anchor 体性在事件流中持续在场 / 任运 / 调畅的机制层。

### anchor 面二维并立（v3 核心）

```
                  ┌─ frame dimension（见地层）
                  │   ── 无痴 anchor（贯遍所有境的 frame 方向）
二阶（anchor 面）:│
                  └─ phenomenal dimension（身心层）
                      ── 轻安 anchor（贯遍所有现行的身心堪任度）
```

- **无痴 anchor** = frame 方向 anchor（让心识对所缘的 frame 是如实见）
- **轻安 anchor** = 身心系统 anchor（让身心系统处于堪任态以承载善法运作）
- 二者**同级**（不是无痴主 / 轻安次）：都是**条件**而不是**反应**，但在不同 dimension
- 差异不在"是否常态"，而在 manifest layer：无痴 anchor 在 frame layer（没 frame contrast 时不显，像空气）；轻安 anchor 在 phenomenal layer（调畅本身是直接 phenomenal 现象，无需 contrast 即可被觉知）

### 缺位失败模式

- 无痴缺 + 轻安在 = **邪定 / 外道四禅八定**
- 轻安缺 + 无痴在 = **闻思可成就但不能下沉为现量**（**干慧风险 #1 的精确机制 anchor**）
- 二者俱缺 + 反应面善心所现行 = 任何善法立刻被末那 hijack（修行者相 / 看穿者我相 / 慈悲者我相）
- 二者俱在 = 真转依方向

### 反应面（一阶）

```
                  ┌─ 可意境 ──→ 贪 ←── 无贪
一阶（反应面）:
                  └─ 不可意境 → 嗔 ←── 无嗔
```

### 修行学含义

1. v3 直接 read 出修行者当前 path 的精确 bottleneck = phenomenal anchor 的定 capacity 重建
2. **v3 同时是干慧风险 #1 的精确机制 anchor**——禅定主轨不是"另一个修行项目"，是干慧风险的精确对治通道

## 演化历史

### v1（已 retire，2026-05-02）

三善根作为末那"我所"对三受全反应模式的对治结构——三类境（可意 / 不可意 / 中庸）× 三受 × 三毒 × 三善根的严格三角对偶。

**经典 challenge**：痴的所缘是"诸理事"（与无痴严格对偶），不是中庸境；痴遍贪嗔起处（"一切杂染所依"），不限于中庸境的不察。v1 把痴 anchor 在中庸境过窄，已 retire。

### v2（已 retire to v3，2026-05-03）

三善根非平行三角，是**"二境对治 + 一总 anchor"的二阶结构**——
- 一阶（反应面）：无贪 / 无嗔分别对治可意 / 不可意境的染反应
- 二阶（anchor 面）：无痴对治遍贯所有境的诸理事迷暗，作一切善法的总 anchor
- 经典支持：痴 = 一切杂染所依（《成唯识论》卷六）；贪起必痴俱、嗔起必痴俱

**v2 局限**：未解决无痴 anchor 之外是否还有其他 anchor 维度的问题——5/7 轻安学习提供首次外部验证场，发现 v2 不足。

### v3（2026-05-07 升级，当前）

在 v2 基础上扩展为"二阶 + 二维 anchor 结构"——anchor 面是二维并立结构，不是单 anchor。

**核心动因**：5/7 修行者 push"轻安和无痴同级，无痴需境触发，轻安是常态"——经精确化后，二者都是 baseline + 即时响应，差别仅在 manifest layer。

### 2026-05-12 不放逸场首个非三善根验证 + framework 完整化

v3 在不放逸场**不需扩 dimension**。不放逸（基于修行者根→力转变 derivation）作为"守护面（运作机制层）"**正交于** anchor 面 / 反应面，是已有四法（精进 + 三善根）力层涌现的常态守护运作模式。framework 完整化为"反应面 + anchor 面 + 守护面"三层 manifest 分层（见上）。详见 [不放逸.md §四](../03-心所法/善心所/不放逸.md)
