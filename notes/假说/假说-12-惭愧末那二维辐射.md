# 假说 12：惭愧 = 末那二维辐射的双轴对治（内向 / 外向）

> **状态**：活跃
> **创建**：2026-04（惭愧学习）
> **最后升级**：2026-06-01（慢学完后末那四烦恼内向轴**完整成立**——我痴 / 我见 / 我慢入内向轴严密成立 + 我爱在内向轴 + 外向轴交界）
> **历史升级**：2026-05-29（三毒学完后烦恼方反向印证）/ 2026-04-30（从"空性双面投射"到"末那二维辐射的双轴对治"）
> **回链**：[CLAUDE.md 持续关注 § 假说网络](../../CLAUDE.md#持续关注隐性回填--假说批判性审视)

## 内容

原"空性双面投射（法性 / 缘起）"在 2026-04-30 获得更具实操性的运作含义——惭愧不只是体性方向上的对偶，是**末那二维辐射的两个事件级对治轴**：

- **惭**对治内向凝聚（"我"的固化）
- **愧**对治外向扩张（"我所"扩张到他人因缘流）

### 究竟层愧的实操核 = "不向他人扩张我所" = non-imposition

与 harm principle、康德目的论、儒家恕道同一收敛核。

**当代理性人不需先证悟空性**，只需用"我是不是把我所扩到他人因缘流里了"作为愧的事件层判准。

与 [假说 5](假说-05-新学不存在.md) 他人面应用严格同构。

## 潜在冲突点

- 经典严格依"自法力 / 世间力"立体性，对应到"内向 / 外向辐射"是大乘视角的延伸；声闻乘传统是否支持？
- 把 B 类细颗粒愧扩展进"恶行"是否过度泛化经典"恶行"边界？需在烦恼心所学习中（特别是"恶作 / 悔"）寻找经典对"恶"边界的明确表述。
- "non-imposition 作为不依信仰前提的入路"是否真的不喂我相？（理论上无信仰前提的判准也可被末那做成"我是有道德判断力的人"）

## 2026-05-29 升级：三毒学完后烦恼方反向印证

三毒精修（[痴.md](../03-心所法/烦恼心所/痴.md) / [贪.md](../03-心所法/烦恼心所/贪.md) / [嗔.md](../03-心所法/烦恼心所/嗔.md)）完成后，三毒在末那的不对称为本假说"内向 / 外向"双轴框架提供**烦恼方的严格反向印证**：

**末那所缘性质决定烦恼分布**：

末那恒缘自内我（第八识见分被执为"我"）。对"我"自身——
- **摄受性烦恼**（爱 / 慢 / 见 / 痴）→ 可在末那本层（自我执取的内在展开）
- **推拒性烦恼**（嗔）→ 结构上不可在末那（推拒自我 = 末那的自我执取自相矛盾）

**与本假说双轴的严格对应**：

| 末那双轴 | 烦恼分布 | 经典依据 |
|---|---|---|
| **内向凝聚（我）** | 末那本层烦恼（我痴 / 我爱 / 我慢 / 我见）| 《成唯识论》卷六明文末那四烦恼 |
| **外向扩张（我所）** | 末那扩张到第六识 / 前五识层时的派生烦恼（嗔 + 第六识贪 / 痴的相应起）| 经典明文嗔不通末那（嗔只在欲界第六识 / 前五识层）|

→ **内向轴的烦恼可在末那本层 / 外向轴的烦恼必在末那之外**——这与本假说"惭对治内向凝聚 / 愧对治外向扩张"是**同一末那双轴结构在烦恼方和惭愧方的双侧显现**。

→ 这升级了本假说原来的"潜在冲突点"第一条（声闻乘是否支持）：**烦恼方明文支持双轴结构本身**——即使具体到惭愧的双侧对应仍属大乘延伸，但底层双轴框架已被烦恼方反向印证。

详见 [三善根整体认知.md §一·5](../03-心所法/善心所/三善根整体认知.md)。

## 2026-06-01 升级：慢学完后内向轴完整成立

慢单法精修（[慢.md](../03-心所法/烦恼心所/慢.md)）完成后，**末那四烦恼内向轴完整成立**——四烦恼的对治善心所归位与本假说"内向 / 外向"双轴严密对应：

| 末那相应 | 对治善心所 | 假说 12 轴归位 |
|---|---|---|
| **我痴** | 无痴 | 内向轴 ✓ |
| **我见** | 无痴 | 内向轴 ✓ |
| **我慢** | **惭 + 无痴** | **内向轴 ✓**（惭直接对治"我"——慢正是"我"被举起的方向性显现）|
| **我爱** | 惭 + 愧（爱→我所扩张时愧介入）| 内向轴 + 外向轴交界 ✓ |

→ **慢的对治善心所归位（[慢.md §一.3](../03-心所法/烦恼心所/慢.md)）严格落入内向轴**——惭作为事件层对治"我"何足恃 / 无痴作为根因层断"我"作高举所依。这是经典明文反向印证（《成唯识论》对慢的"恃己于他高举为性"+ 末那"我慢"恒俱）。

**升级含义**：

1. **2026-05-29 升级**确立了"内向轴的烦恼可在末那本层 / 外向轴的烦恼必在末那之外"双轴结构本身。
2. **2026-06-01 升级**进一步**填实内向轴**——末那四烦恼全部归入内向轴，且其对治善心所归位严格符合本假说。
3. → 烦恼方反向印证从"双轴框架本身"升级为"**末那四烦恼内向轴对治归位的完整经典支持**"。
