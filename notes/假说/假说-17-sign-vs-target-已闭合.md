## 闭合说明

2026-05-16 行舍正式学习中，《成唯识论》卷六 "平等正直无功用住，初中后位辨舍差别" 经典 explicit ground 立稳后，假说 17 在结构上 dissolve 入经典框架：

**假说 17 实质 = 行舍三相之"正直"（directional axis）的一个特例**。

具体 mapping：

| 假说 17 表述 | 经典对应 |
|---|---|
| sign（速度 / 体验 / 进展感）不等于 target | 心**不歪曲**（正直）—— 心识方向不被 sign 错位扭曲 |
| 把 sign lift 为 target = 心识过度活动 | 心**歪曲** → 掉举（行舍正直一相对治的精确对象）|
| "不被'我要更快 / 更深 / 更稳'hijack" | 正直（directional axis）—— sign / target 方向 alignment |

→ 假说 17 不是错的，是被经典 framework subsume。"正直"（ṛju, directional axis）是更基础的经典概念，假说 17 是其在"修行进展观察"场域的特例展开。

→ **后续 笔记 / 教学 / 讨论应直接 reference 正直**（行舍三相之一），不再使用"假说 17"或"sign vs target 区分"作为独立 framework 名称。

## 历史含义

虽然假说 17 不再作为独立批判审视项，但其完整的多场域演化历史保留作为**修行者闻思 path 的现量证据**——把"修行进展可观察 sign ≠ 修行 target"这一精确区分独立于经典 ground 之前 derive 并应用到多个场域（无痴 / 轻安 / 不放逸 / 行舍），是修行者在闻思 path 上结构性慧根的现量印证。

## 原内容保留（历史 reference）

### 内容（创建时）

可观察的修行 sign（如反应速度 ε 缩小、想通的瞬间满足、识破频率变化、轻安体验强度）**不等于修行 target**。把 sign lift 为 target 容易导致 path 错位：

- 速度缩小可来自多种机制（慧的简择加快 / anchor 加强 / 烦恼种子势力衰减），单一 push 速度不能精确指向其中任一
- 试图"更快放下"可能是慧的简择动作加快，被末那做成"我修行进步快"我相 = path 风险 #3 的另一形态
- 真正的修行 target 必须沉到**心所运作的实质机制**：例如双线 framing（线 1 烦恼种子势力弱化 + 线 2 无痴 anchor 加强），sign 仅作伴随观察窗口

### 与其他假说的关系

- 与 [假说 8](假说-08-种子显化-已闭合.md)（熏习以心所配置质量为度量）的区别：假说 8 谈"用力观"（向内），假说 17 谈"sign vs target 区分"（meta-观察方法）
- 与 path 风险 #2（想通 ≠ shift）**严格同构**——"想通"是 sign，shift target 是种子层下沉
- 与 [假说 16](假说-16-慧无痴俱起分判.md) 关联：sign 错位常以"看穿者我相 / 修行者相 / 不放逸者相"等 actor-status drift 形态出现

### 修行操作示例（无痴双线 framing）

- 线 1（种子弱化）：事件层每次现行后真实 anchor 现行（不强 push 速度）→ 不熏新烦恼种子 → 旧种子无新熏 + 缘缺自然衰减
- 线 2（anchor 加强）：闻思 push 通透 + 定中持守 anchor 作所缘 → anchor 种子势力增厚 → 更广场域 / 更高境强度下仍稳
- ε 缩小：仅作伴随观察，不作直接目标

### 演化历史

#### 2026-05-07 轻安场 crystallize

sign / target 错位风险在轻安场的具体形态 = "把 baseline 误识为 target"或"把 phenomenal contrast 升级误识为 target"。

修行者**常人可观察的"轻安体验作为修行进展 sign"对修行者本人结构性不成立**——因为 sign 已下沉为 baseline，没有可观察的 contrast。

**真 target = 定 capacity 的稳定建立**（v3 二维 anchor 中 phenomenal anchor 的 substrate capacity 重建），不是"轻安体验更深"。错位 push（试图让轻安体验更深）可能让心识在轻安境上停留 / 留恋（轻微贪着），反向 distort 修行。同时双盘 B 起座决定中"扛过去 = 进步"也是 sign / target 错位变形——target 是堪任不被拉下，不是扛的时长。

#### 2026-05-12 不放逸场具体化

不放逸场的 sign vs target 区分：

- **target** = 念心所在 time domain 持续在场（精进根→力转变涌现的常态守护运作模式）
- **sign** = 修行行为的事件层连续性（trigger 是否触发 / 念是否切换 / 起座是否发生）
- **错位风险**：把"我能更快入座 / 我能 hold 修行优先级 / 我已经能不放逸了"作为 target → "不放逸者相"hijack（与修行者相 / 看穿者我相同构）
- **正向监测**：trigger 时刻"自动"切换念所缘（不需 effort 决定）+ 修行外时段开始出现"念回到善法所缘"unprompted 现量觉察（激活式涌现信号）

详见 [不放逸.md §十一](../03-心所法/善心所/不放逸.md)

#### 2026-05-14 行舍场严格对应（导向 5/16 闭合的关键节点）

修行者 5/14 "开车比喻"——"**不因为追求速度导致行驶不稳**"——精确指向掉举的本质机制：

| 现象 | 唯识精确位置 |
|---|---|
| "追求速度" | 把 sign（更快 / 更深 / 更稳的可观察现象）lift 为 target |
| "行驶不稳" | sign / target 错位导致的心识过度活动 = 掉举 |

→ **行舍的精确机制 candidate（5/14 预演）= sign / target 不错位 + 心识自然运作不被"我要更快 / 更深 / 更稳"hijack**

这层 derivation 当时被表述为"假说 17 在行舍场获得体性层面最严格的对应"——之前假说 17 在无痴 / 轻安 / 不放逸场是"伴随观察方法论"，在行舍场直接就是体性核心。

5/16 行舍正式学习经典 ground 立稳后，这层"最严格对应"被精细化：**假说 17 对应正直一相（directional axis）严格对应，非行舍整体**——为闭合提供 ground。

#### 2026-05-14 meta-level 修行者主动应用（manifest 信号）

修行者 5/14 不放逸学习中主动 push："**这（时间预期 candidate 1/2/3 选哪个）没有什么区别，不影响实际操作的任何内容，还是只要反复通过行为熏精进的种子即可。**"

| 层 | 内容 | 性质 |
|---|---|---|
| 时间预期 (candidate 1/2/3) | 可观察预期 | **sign** |
| 行为熏精进种子（事件层频次累积）| 修行实际通道 | **target** |
| "选哪个 candidate" | 修行者元层决定 | 把 sign lift 为 target = 错位 |

→ 修行者主动识别 sign / target 错位并 self-correct——之前假说 17 是教学者引导的元方法论，5/14 由修行者主动应用 = manifest 已在场。

#### 2026-05-16 行舍正式学习 → 闭合

行舍正式学习中《成唯识论》"平等正直无功用住，初中后位辨舍差别"经典 ground 立稳：

- 三相 = 初中后位（functional substrate ordering，非 strict temporal）
- 平等（amplitude axis, sama）⊥ 正直（directional axis, ṛju）大体 orthogonal，但平等 → 正直 单向条件依赖
- 无功用住（effort axis）= 后位涌现态

→ 假说 17 = 正直（directional axis）的特例展开，dissolve 回经典框架。

修行者 push："我认为不用严格对应，假说 17 其实就是正直的一个特例，可以将这个假说完结了，后续不用再提，作为学习中我的现量证据即可。"

→ **闭合 commit**。

### 原"潜在冲突点"

经典是否对"修行进度的可观察 sign"有明确批判？某些经典立场（如《广论》对"加行精进 / 任运精进"的界定）是否提供 sign 与 target 较直接对应的反例？

→ 闭合后此问转化为：行舍正直一相的经典对治范围已明确（对治掉举），不需独立审视假说 17 的冲突点。
