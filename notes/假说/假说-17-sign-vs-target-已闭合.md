## 闭合说明

2026-05-16 行舍正式学习中，《成唯识论》卷六 "平等正直无功用住，初中后位辨舍差别" 经典 明文 立基 立稳后，假说 17 在结构上 消解 入经典框架：

**假说 17 实质 = 行舍三相之"正直"（方向 轴）的一个特例**。

具体 映射：

| 假说 17 表述 | 经典对应 |
|---|---|
| 征兆（速度 / 体验 / 进展感）不等于 标的 | 心**不歪曲**（正直）—— 心识方向不被 征兆 错位扭曲 |
| 把 征兆 拔高 为 标的 = 心识过度活动 | 心**歪曲** → 掉举（行舍正直一相对治的精确对象）|
| "不被'我要更快 / 更深 / 更稳'劫持" | 正直（方向 轴）—— 征兆 / 标的 方向 alignment |

→ 假说 17 不是错的，是被经典 框架 subsume。"正直"（ṛju, 方向 轴）是更基础的经典概念，假说 17 是其在"修行进展观察"场域的特例展开。

→ **后续 笔记 / 教学 / 讨论应直接 reference 正直**（行舍三相之一），不再使用"假说 17"或"征兆 vs 标的 区分"作为独立 框架 名称。

## 历史含义

虽然假说 17 不再作为独立批判审视项，但其完整的多场域演化历史保留作为**修行者闻思 路径 的现量证据**——把"修行进展可观察 征兆 ≠ 修行 标的"这一精确区分独立于经典 立基 之前 推出 并应用到多个场域（无痴 / 轻安 / 不放逸 / 行舍），是修行者在闻思 路径 上结构性慧根的现量印证。

## 原内容保留（历史 reference）

### 内容（创建时）

可观察的修行 征兆（如反应速度 ε 缩小、想通的瞬间满足、识破频率变化、轻安体验强度）**不等于修行 标的**。把 征兆 拔高 为 标的 容易导致 路径 错位：

- 速度缩小可来自多种机制（慧的简择加快 / 锚 加强 / 烦恼种子势力衰减），单一 深挖 速度不能精确指向其中任一
- 试图"更快放下"可能是慧的简择动作加快，被末那做成"我修行进步快"我相 = 路径 风险 #3 的另一形态
- 真正的修行 标的 必须沉到**心所运作的实质机制**：例如双线 框定（线 1 烦恼种子势力弱化 + 线 2 无痴 锚 加强），征兆 仅作伴随观察窗口

### 与其他假说的关系

- 与 [假说 8](假说-08-种子显化-已闭合.md)（熏习以心所配置质量为度量）的区别：假说 8 谈"用力观"（向内），假说 17 谈"征兆 vs 标的 区分"（元-观察方法）
- 与 路径 风险 #2（想通 ≠ 跃迁）**严格同构**——"想通"是 征兆，跃迁 标的 是种子层下沉
- 与 [假说 16](假说-16-慧无痴俱起分判.md) 关联：征兆 错位常以"看穿者我相 / 修行者相 / 不放逸者相"等 行为者地位 偏移 形态出现

### 修行操作示例（无痴双线 框定）

- 线 1（种子弱化）：事件层每次现行后真实 锚 现行（不强 深挖 速度）→ 不熏新烦恼种子 → 旧种子无新熏 + 缘缺自然衰减
- 线 2（锚 加强）：闻思 深挖 通透 + 定中持守 锚 作所缘 → 锚 种子势力增厚 → 更广场域 / 更高境强度下仍稳
- ε 缩小：仅作伴随观察，不作直接目标

### 演化历史

#### 2026-05-07 轻安场 结晶化

征兆 / 标的 错位风险在轻安场的具体形态 = "把 基准 误识为 标的"或"把 身心 contrast 升级误识为 标的"。

修行者**常人可观察的"轻安体验作为修行进展 征兆"对修行者本人结构性不成立**——因为 征兆 已下沉为 基准，没有可观察的 contrast。

**真 标的 = 定 承载力 的稳定建立**（v3 二维 锚 中 身心锚 的 根基 承载力 重建），不是"轻安体验更深"。错位 深挖（试图让轻安体验更深）可能让心识在轻安境上停留 / 留恋（轻微贪着），反向 distort 修行。同时双盘 B 起座决定中"扛过去 = 进步"也是 征兆 / 标的 错位变形——标的 是堪任不被拉下，不是扛的时长。

#### 2026-05-12 不放逸场具体化

不放逸场的 征兆 vs 标的 区分：

- **标的** = 念心所在 时间域 持续在场（精进根→力转变涌现的常态守护运作模式）
- **征兆** = 修行行为的事件层连续性（触发 是否触发 / 念是否切换 / 起座是否发生）
- **错位风险**：把"我能更快入座 / 我能 成立 修行优先级 / 我已经能不放逸了"作为 标的 → "不放逸者相"劫持（与修行者相 / 看穿者我相同构）
- **正向监测**：触发 时刻"自动"切换念所缘（不需 用力 决定）+ 修行外时段开始出现"念回到善法所缘"无外引 现量觉察（激活式涌现信号）

详见 [不放逸.md §十一](../03-心所法/善心所/不放逸.md)

#### 2026-05-14 行舍场严格对应（导向 5/16 闭合的关键节点）

修行者 5/14 "开车比喻"——"**不因为追求速度导致行驶不稳**"——精确指向掉举的本质机制：

| 现象 | 唯识精确位置 |
|---|---|
| "追求速度" | 把 征兆（更快 / 更深 / 更稳的可观察现象）拔高 为 标的 |
| "行驶不稳" | 征兆 / 标的 错位导致的心识过度活动 = 掉举 |

→ **行舍的精确机制 候选（5/14 预演）= 征兆 / 标的 不错位 + 心识自然运作不被"我要更快 / 更深 / 更稳"劫持**

这层 推导 当时被表述为"假说 17 在行舍场获得体性层面最严格的对应"——之前假说 17 在无痴 / 轻安 / 不放逸场是"伴随观察方法论"，在行舍场直接就是体性核心。

5/16 行舍正式学习经典 立基 立稳后，这层"最严格对应"被精细化：**假说 17 对应正直一相（方向 轴）严格对应，非行舍整体**——为闭合提供 立基。

#### 2026-05-14 元-层级 修行者主动应用（显现 信号）

修行者 5/14 不放逸学习中主动 深挖："**这（时间预期 候选 1/2/3 选哪个）没有什么区别，不影响实际操作的任何内容，还是只要反复通过行为熏精进的种子即可。**"

| 层 | 内容 | 性质 |
|---|---|---|
| 时间预期 (候选 1/2/3) | 可观察预期 | **征兆** |
| 行为熏精进种子（事件层频次累积）| 修行实际通道 | **标的** |
| "选哪个 候选" | 修行者元层决定 | 把 征兆 拔高 为 标的 = 错位 |

→ 修行者主动识别 征兆 / 标的 错位并 自我修正——之前假说 17 是教学者引导的元方法论，5/14 由修行者主动应用 = 显现 已在场。

#### 2026-05-16 行舍正式学习 → 闭合

行舍正式学习中《成唯识论》"平等正直无功用住，初中后位辨舍差别"经典 立基 立稳：

- 三相 = 初中后位（功能根基次第，非 strict temporal）
- 平等（振幅 轴, sama）⊥ 正直（方向 轴, ṛju）大体 orthogonal，但平等 → 正直 单向条件依赖
- 无功用住（用力 轴）= 后位涌现态

→ 假说 17 = 正直（方向 轴）的特例展开，消解 回经典框架。

修行者 深挖："我认为不用严格对应，假说 17 其实就是正直的一个特例，可以将这个假说完结了，后续不用再提，作为学习中我的现量证据即可。"

→ **闭合 commit**。

### 原"潜在冲突点"

经典是否对"修行进度的可观察 征兆"有明确批判？某些经典立场（如《广论》对"加行精进 / 任运精进"的界定）是否提供 征兆 与 标的 较直接对应的反例？

→ 闭合后此问转化为：行舍正直一相的经典对治范围已明确（对治掉举），不需独立审视假说 17 的冲突点。
