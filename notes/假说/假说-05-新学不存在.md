# 假说 5："新学"不存在——一切是既有种子的重新组合

> **状态**：活跃
> **创建**：2026-04（别境心所阶段）
> **最后升级**：2026-05-02（扩展到他人面）

## 内容

任何"学到新东西"本质上是既有种子遇缘现行，或旧种子以新方式组合变现。"第一次理解"其实是"种子在此缘下第一次被调动"。与 Wolfram 计算宇宙观（可实现某种计算功能的程序结构本来就存在于计算宇宙中）结构同构。

**修行含义**："天生这样是骗局"——性格/能力不是天生刚性属性，而是无始熟习种子的现行；认为"我天生就这样"是把"缘的稳定性"误认为"因的本质性"。

## 演化历史

### 2026-05-02 扩展（他人面应用）

之前主要在自身面应用——这次修行者通过无嗔学习把假说 5 应用到他人行为上：**他人的"不合理"反应也是种子现行，不是"他天生这样 / 他有毛病"**。

判他人"不合理" = 末那把"我所标准"扩张到他人因缘流上 + 把差异认知为"应该不应该"——这是对治评判心 / 微细嗔的根本入路，与 [假说 12](假说-12-惭愧末那二维辐射.md) (non-imposition) 严格同构。

**注意保留精度**：业感所现确有善恶染净分（杀人是恶业现行），不是"一切都对"——区别在 actor 判别角度（"如实见种子现行"vs"我所标准被违反"），不消除善恶分判，只消除我所扩张层。

### 2026-06-XX 扩展（修法多元化承认）

恶见精修中修行者派系争议中立的现量入路：

> "深刻意识到修法形态的差异是与有情的特质匹配的，能认识到有情本身的差异，就必须尊重修法从对治目的出发导致的差异。"

→ **修法多元化承认**是假说 5 在修法 / 派系维度的扩展：
- 修法差异 = 有情种子特质 + 因缘条件的对治函数
- 没有"唯一正确的修法" — 所有修法都是方便善巧
- 持戒、禅定、念佛、持咒、密法等差异不是优劣高低，而是对治不同根器 / 因缘

**结构性意义**：
- 这给"派系中立"的现量基础（元层立场）
- 但 ≠ 事件场无俱生现行（详见 [恶见.md §五.3 + §五.8 触受爱憎链统一开关命题](../03-心所法/烦恼心所/恶见.md)）
- 元层成熟立场（修法多元化承认）与共业场景俱生现行（见解嗔 + 微细谤圣贤）严格分诊

**修行者位置精确状态**：
