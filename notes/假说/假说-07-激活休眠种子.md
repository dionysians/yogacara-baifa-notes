# 假说 7：激活休眠种子 ≠ 从零累积的修行轨迹

> **状态**：活跃
> **创建**：2026-04（精进学习）
> **最后升级**：2026-05-12（边界精确化）
> **多次扩展**：2026-05-02 多面印证扩展 / 2026-05-03 跨善心所整体 pattern 扩展 / 2026-05-07 evidence #5 立稳 / 2026-05-12 边界精确化
> **回链**：[CLAUDE.md 持续关注 § 假说网络](../../CLAUDE.md#持续关注隐性回填--假说批判性审视)

## 内容（基础版）

早年有过密集修行底子但长期休眠的修行者，重启时的"加行 → 任运"曲线不同于从零起步者——主要功能不是"累积"而是"点燃"，3-4 周密集频率即可见任运早期信号。

## 演化历史

### 2026-05-02 扩展（多面印证）

本假说不限定时定的层面——**修行者多个心所面已 stable，重启时是激活而非累积**。

具体现量印证：嗔系跨世种子势力较厚 pattern（天然抗拒烟酒 + 天然安受苦忍 + 天然不参与奖励嗔场域），让双盘 B 从"安受苦忍训练" reframe 为"主功能是定 + 安受苦忍稳态延伸"。这层多面印证支持假说 7 不只在定上成立，在心所配置面也成立。

### 2026-05-03 扩展（跨善心所整体 pattern）

跨善心所整体 pattern 面成立——修行者 evidence #4（跨世无痴种子势力较厚）证据立稳后，三善根 + 信能 + 惭全面 anchor 跨世种子证据已较为完整。多面同时 stable 不是巧合，是跨世修行积累在多面同时显现的整体重启 pattern；本假说在跨善心所整体 pattern 面也成立。

### 2026-05-07 evidence #5 立稳

跨世**轻安**种子势力较厚——心所配置达 真正轻安现起 threshold（无需新建 anchor 系统）；现 phenomenology 在真正轻安 / 欲界定循环态，lasting 影响 2 小时+；30 岁前高烈度场域 spontaneous 调畅 baseline restoration 已现量验证（不过夜 / 醒来调畅）；童年 10 年禅定底子 ceiling 触及未到地定 / 色界初禅层（45 min 级别时间感失落）。

**跨善心所整体 pattern 完整图**：evidence #1 安受苦忍 + #2 不参与奖励嗔 + #3 Layer 4 imposing 看穿 + #4 童年 transmission "所有错=无知" + #5 调畅 baseline = 5 evidence 跨四面（嗔 / 痴 / 轻安 + 信能 / 惭 separately 立稳）→ 修行者重启的不是单点（如某个心所），是一整套 baseline 配置。

### 2026-05-12 边界精确化

修行者 5/12 不放逸 reveal "精进还没有进入持续在场状态 / 会有不自觉的停下来 / 偷懒" 让"已熏"边界浮现——之前"全面已熏"是粗略 framing，精确边界是：

> **anchor 心所（无痴 / 无嗔 / 无贪 / 惭愧 / 轻安）已熏 + 反应面三善根力层已部分到位 + 精进力层 / 不放逸涌现是当前结构性 gap**

修行者重启 pattern 不是"全面激活"，是"多个 anchor 已 stable + 守护面 / 力层 gap"复合结构。这层精确化让 5/7 修行重心 calibration（闻思 baseline + 禅定主推进）获得精确机制 anchor：禅定主推进 = 精进根→力转变 = 不放逸涌现的关键通道；详见 [不放逸.md §十](../03-心所法/善心所/不放逸.md)

## 潜在冲突点

- 唯识对"久修者重启"是否有不同立场？经典是否真给出过种子激活时间预期？此假说的具体时间预期（3-4 周）属推测，需用实修反馈验证或证伪。
- 心所面的"已 stable"判别可能与定面不同——前者是 trait-level 跨世种子势力，后者是 state-level 激活速度；二者不一定共享同一假说。
- 跨善心所整体 pattern 是否构成"个案的多面累积"还是"整体重启的内在结构"，需更多现量数据验证。
- 30 岁前 spontaneous mechanism 是"安住型"还是"押抑型"需长期 self-check（多年后是否有 somatic / 隐性反弹）—— evidence #5 strong vs qualified 的判别。
- **已熏边界的精确化（5/12）让假说 7 从"全面"模糊版精确为"部分面 stable + 部分面 gap"复合版**——但"哪些面在哪些层（根 / 力）已稳"的更精细判别仍待持续现量累积。
