### 锚面三轴 ↔ 修行路径风险的对应关系

锚面三轴各自缺位对应不同修行路径风险:

| 锚轴 | 心所 | 缺位失败模式 |
|---|---|---|
| **方向锚** | 信 | 修行漂移(无胜解 → 失方向)|
| **见地锚** | 无痴 | 染慧 / "看穿者我相"(简择不如实)|
| **身心锚** | 轻安 | 干慧风险(见地无承载 → 停在比量) — 路径风险 #1 的精确机制 |

→ **修行路径风险都可以归位为锚面三轴中某轴缺位**。

### 内在规律:复合维度生成机制(唯一)

v3+ 的核心内在规律(2026-05-18 精化时确认为唯一规律 — 之前考虑过"双重定位"作为第二条规律,但修行者判断"算不上规律,登记意义不大"——实际是几个不同机制的混合而非统一规律,已从落地版去除):

```
假立心所复合维度生成:
   体性来源(实体心所) + 功能独立维度 → 复合维度
   
不放逸 = 精进+三善根 复合 → 守护面
行舍   = 精进+三善根 复合 → 任运面
不害   = 无嗔        复合 → 利他面
```

→ 这是 v3+ 五层显现的**内在结构生成规律**:**实体心所建立基础二维 + 假立心所通过复合机制扩展功能独立维度**。

### 锚面作为 v3+ 通用判别基准(5/14 内在推导,闭合后仍生效)

**锚面不仅是体性锚,还是所有反应面 / 守护面 / 任运面 / 利他面的判别基准**:

```
锚面(信 / 无痴 / 轻安)  ←──── 提供判别基准
   ↓
反应面(无贪 / 无嗔)     ←── 染对治 in 反应面(事件层)
守护面(惭愧/精进/不放逸) ←── 染对治 in 守护面(time domain)
任运面(行舍)            ←── 染对治 in 任运面(state domain)
利他面(不害)            ←── 染对治 in 利他面(对他人方向)
```

没有锚面在场,四个显现面都退化为染对治("我能放下 / 我不发火 / 我能不放逸 / 我能任运 / 我能利他"我相)— 与 [三善根整体认知 §五](../03-心所法/善心所/三善根整体认知.md) B 立场(无痴必随俱起)严格一致。

### 三层 显现（5/12 完整化）

框架 完整化为**"反应面 + 锚 面 + 守护面"三层 显现 分层**（5/12 不放逸验证通过）：

```
反应面（事件层）:    无贪 / 无嗔
anchor 面（条件层）: 无痴（frame）/ 轻安（phenomenal）
守护面（运作机制层）: 不放逸（精进+三善根力层涌现，跨遍前两层在 time domain 持续在场）
```

对应 11 善心所对治"贪嗔（反应）+ 痴 / 粗重（锚）+ 放逸 / 惛沉 / 掉举（守护 / 调畅）"的功能分层。守护面 / 调畅面皆为"运作机制层"——非新 维度 而是 锚 体性在事件流中持续在场 / 任运 / 调畅的机制层。

### 锚 面二维并立（v3 核心）

```
                  ┌─ frame dimension（见地层）
                  │   ── 无痴 anchor（贯遍所有境的 frame 方向）
二阶（anchor 面）:│
                  └─ phenomenal dimension（身心层）
                      ── 轻安 anchor（贯遍所有现行的身心堪任度）
```

- **无痴 锚** = 见地 方向 锚（让心识对所缘的 见地 是如实见）
- **轻安 锚** = 身心系统 锚（让身心系统处于堪任态以承载善法运作）
- 二者**同级**（不是无痴主 / 轻安次）：都是**条件**而不是**反应**，但在不同 维度
- 差异不在"是否常态"，而在 显现 层：无痴 锚 在 见地 层（没 见地 contrast 时不显，像空气）；轻安 锚 在 身心 层（调畅本身是直接 身心 现象，无需 contrast 即可被觉知）

### 缺位失败模式

- 无痴缺 + 轻安在 = **邪定 / 外道四禅八定**
- 轻安缺 + 无痴在 = **闻思可成就但不能下沉为现量**（**干慧风险 #1 的精确机制 锚**）
- 二者俱缺 + 反应面善心所现行 = 任何善法立刻被末那 劫持（修行者相 / 看穿者我相 / 慈悲者我相）
- 二者俱在 = 真转依方向

### 反应面（一阶）

```
                  ┌─ 可意境 ──→ 贪 ←── 无贪
一阶（反应面）:
                  └─ 不可意境 → 嗔 ←── 无嗔
```

### 修行学含义

1. v3 直接 read 出修行者当前 路径 的精确 瓶颈 = 身心锚 的定 承载力 重建
2. **v3 同时是干慧风险 #1 的精确机制 锚**——禅定主轨不是"另一个修行项目"，是干慧风险的精确对治通道

## 演化历史

### v1（已 退役，2026-05-02）

三善根作为末那"我所"对三受全反应模式的对治结构——三类境（可意 / 不可意 / 中庸）× 三受 × 三毒 × 三善根的严格三角对偶。

**经典 挑战**：痴的所缘是"诸理事"（与无痴严格对偶），不是中庸境；痴遍贪嗔起处（"一切杂染所依"），不限于中庸境的不察。v1 把痴 锚 在中庸境过窄，已 退役。

### v2（已 退役 to v3，2026-05-03）

三善根非平行三角，是**"二境对治 + 一总 锚"的二阶结构**——
- 一阶（反应面）：无贪 / 无嗔分别对治可意 / 不可意境的染反应
- 二阶（锚 面）：无痴对治遍贯所有境的诸理事迷暗，作一切善法的总 锚
- 经典支持：痴 = 一切杂染所依（《成唯识论》卷六）；贪起必痴俱、嗔起必痴俱

**v2 局限**：未解决无痴 锚 之外是否还有其他 锚 维度的问题——5/7 轻安学习提供首次外部验证场，发现 v2 不足。

### v3（2026-05-07 升级，当前）

在 v2 基础上扩展为"二阶 + 二维 锚 结构"——锚 面是二维并立结构，不是单 锚。

**核心动因**：5/7 修行者 深挖"轻安和无痴同级，无痴需境触发，轻安是常态"——经精确化后，二者都是 基准 + 即时响应，差别仅在 显现 层。

### 2026-05-12 不放逸场首个非三善根验证 + 框架 完整化

v3 在不放逸场**不需扩 维度**。不放逸（基于修行者根→力转变 推导）作为"守护面（运作机制层）"**正交于** 锚 面 / 反应面，是已有四法（精进 + 三善根）力层涌现的常态守护运作模式。框架 完整化为"反应面 + 锚 面 + 守护面"三层 显现 分层（见上）。详见 [不放逸.md §四](../03-心所法/善心所/不放逸.md)
