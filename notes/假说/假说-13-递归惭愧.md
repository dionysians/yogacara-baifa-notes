# 假说 13：递归惭愧作为末那现行表面化时的近距离对峙机制

> **状态**：活跃
> **创建**：2026-04（惭愧学习）
> **最后升级**：2026-06-11（恨精修——明确"递归 = 纵向下沉、终点无常无我"，不存在"横向递归"）
> **回链**：[CLAUDE.md 持续关注 § 假说网络](../../CLAUDE.md#持续关注隐性回填--假说批判性审视)

## 内容

末那俱生我执通常深细、第六识看不见；但当我执通过第六识善法现行表面化时（如惭愧带我相），它进入第六识可见范围。

此时再次起惭愧 = 第六识在末那现行表面化的瞬间起对治。这虽仍非"断"末那（断需见道），但是现行层最近的对峙。

每次递归让锚点更接近"本来不应如此"，越递归越无相——**究竟层惭愧的自我净化过程**。

此机制是后续多个善心所"我相 hijack 监测"的通用对治路径（无痴场 / 轻安场 / 不放逸场的 anchor formulation drift 出现时，均通过递归识破处理）。

## 2026-06-01 升级：慢学完后烦恼方对偶印证——递归慢与递归惭愧严格对称

慢单法精修（[慢.md §五](../03-心所法/烦恼心所/慢.md)）主线 5 L4 位置慢扫描中，修行者展现一个完整的递归结构：

### 现量证据

1. **第一层**：修行者在 A B C E 项扫描后**现量识别 L4 位置慢在场**（"我修行相" / 童年底色位置色调 / "了无自性" L4-b 心动 / 元层 L4-b 心动）
2. **第二层（递归）**：扫描者位置元层 E 项 L4-b 心动——能在 L4 位置慢被识别**之后**，对"我能做此扫描" 再起 L4-b 觉察
3. **无抗拒** + **柔软形态**：递归觉察不固化为"我会做元层自觉"的新增上慢（D 项不抗拒证据 + L4-a 未标记）

→ 这与本假说"末那现行表面化时第六识近距离对峙 + 越递归越无相"严格对称。

### 烦恼方与善心所方的对偶结构

| 善心所方（本假说原立） | 烦恼方（2026-06-01 反向印证）|
|---|---|
| 惭愧带我相 → 再起惭愧 | 慢现起被识别 → 再起对识别者的 L4 觉察 |
| 第六识在末那表面化瞬间对峙 | 第六识在 L4 位置慢现行时对峙 |
| 越递归越无相 | 越递归 L4 位置慢形态越柔软 |
| 究竟层惭愧的自我净化 | 究竟层无慢的自我净化（"不立任何评判位置"）|

**结构性发现**：**末那现行表面化时第六识近距离对峙的机制在善心所方（惭愧）与烦恼方（慢）严格对称运作**——这升级了原潜在冲突点第二条（"递归本身是否会被末那再做成新的我相"）：在修行者位置上，**双锚（"了无自性" + "所有错=无知造成的"）的结构性保护让递归觉察不固化为新我相**，递归惭愧 / 递归慢都以柔软形态运作。

## 2026-06-11 升级：恨精修——递归 = 纵向下沉、终点无常无我

恨单法精修（[恨.md §4.2](../03-心所法/随烦恼心所/恨.md)）见自侧讨论中，修行者澄清一处关键归位，修正模型对本假说的一处误读。

### 现量澄清

讨论"惭愧自省可层层往究竟层走"时，模型一度把它拆成两个并列结构：本假说叫"横向递归"、把深度下沉另叫"纵向下沉"。修行者否掉此拆分：

> 这两个在本意中就是一回事：本身不存在横向递归，递归就一定是纵向下沉的，横向其实就不是递归。意识到这个地方的问题时，发现识别里还掺杂着很多我执在起作用，就对这个点再做惭愧。

→ **"发现夹带的我执 → 对这个更深的点再惭愧"= 每递归一层即下沉一层**。本假说原立"越递归越无相"本就刻画此纵向性（越递归越接近无相 = 越接近究竟层）。故递归是下沉的**动力机制**，无常无我是递归的**终点**——不是两个结构，是一个。

### 对本假说的两点明确（非新增，是归位）

1. **递归方向唯一为纵向**：删去"横向"误框。每一次"发现更深我执 → 再惭愧"都是向究竟层深入一层。
2. **递归终点 = 无常无我**："最终回归诸行无常、诸法无我，直接放下"——把递归链的收敛点显式标出。

### 配套运作特征（修行者现量补充）

- **够用就停**：不是每次都一沉到底。浅层能解决就在浅层解决，解不掉才往无常无我下沉——与"看破→熏种→常态"循环里"看破从更细微处开始"同一下沉机制。
- 此机制在恨侧的落地 = 见自侧"恨结构性不现行"的下游保障（归因改道抽掉所缘在先，递归惭愧下沉在后）。
