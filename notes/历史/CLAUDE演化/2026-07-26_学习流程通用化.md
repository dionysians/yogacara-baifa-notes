## 一、背景

修行者提出检视：现行「学习流程」是 2026-06-10 在随烦恼单法精修的现场重建的（见 [2026-06-10_学习流程改为单法学习循环](2026-06-10_学习流程改为单法学习循环.md)），怀疑它**缺乏通用性**——即绑死在心所位上，难以承接后续的色法、心不相应行法、无为法，更难承接《百法》学完后换教材的延续（README 已明文把项目定位为可承载多部经典的闻思 + 实修引擎，方法层与内容层分离）。

检视结论：**「闻 → 思两拍」这个骨架是真通用的**——它来自学习者的闻思不对称（思 / 现量强、闻 / 经典地基弱），与教材无关。缺通用性的是骨架里塞的**心所位专属填充物**，以及流程把三类不同性质的规则平铺成一个编号列表。

三类问题：

1. **位类绑定**：① 概念讲解的拆解模板「所缘 / 体性 / 业用 / 障」是心所专用。色法无所缘（自身即所缘或根）、心不相应行法几乎全是分位假立、无为法无业用可言，三者各需自己的拆解维度。「见众生普遍现行形态」也是烦恼阶段的产物（对应活跃议题⑥利他善巧轴），对色法 / 无为法不成立。另缺一个通用的「修行接口」槽。
2. **单位与密度假定**：单位写死为「每一法」。色法五根五境同构、心不相应行法二十四法多为分位假立群、无为六法是一理六门，逐法各走一遍五段会重复且超配；换教材后单位可能是一章 / 一颂段，「单法」字面失效。逐主线章末检验的密度对轻单元也过重。
3. **结构与位置错配**：#1 是时序流程、#2–#5 是文档归位规则、#6–#9 是项目级机制，三类平铺成一串编号，⑤ 还以「#2–#5」按号回指；「研究议题的来源约束」实际管整个循环却塞在 ① 内；缺「适用范围」声明，导致实修 / 佛法观世 / 规范治理等非闻思会话也可能被套五段；04 / 05 / 06 三个位类已存在 2026-03 一轮的模板化旧稿（含英文梵文项、无三层标注、模板腔），流程对「重访已有旧稿」无任何规则。

时机：伺完成后即不定四法收官，随后进入色法——这是第一个跨位类切换，问题会立刻撞上。

## 二、变更内容

「学习流程」整节重写，由平铺的 #1–#9 改为**适用范围 + 前置约束 + A / B / C 三组**。

### 1. 新增适用范围声明

A 组只适用于**闻思单元学习**；实修、佛法观世、规范治理、回填结算等会话走各自流程，不套五段，但同样受 B 组归位规则与学术诚实三层标注约束。

### 2. 「研究议题的来源约束」提为循环前置

原在 ① 内，实际管 ①③④ 全程（2026-06-13 立此条时的原文即写「讲法与逐主线深入讨论中……」）。按「指导各归其位」的元原则提为独立前置条，并合入 [谄](../../03-心所法/随烦恼心所/谄.md) 处沉淀的判准精化：**判准是议题是否经典衍生 / 修行者诉求，与谁出声无关**。约束内容本身不变。

### 3. A 组：新增 ⓪ 单元切分与旧稿处置

- **学习单元**取代「一法」，可以是一法 / 一组同构法 / 一章 / 一颂段；切分方式由该位类的方法论文档确定并经用户确认。
- 该位类若已有早期笔记，**默认以本循环产出重写覆盖正文**，抽取旧稿可用材料，并在方法论文档中一次性声明处置范围；重写时同步清理不合现行约定处（英文残留、无三层标注、模板腔）。此条由修行者定夺（备选的「保留旧稿另立」「逐条增量精修」未取）。

### 4. A 组 ①：拆解模板 → 通用六槽 + 维度下放

① 概念讲解改为六槽：经典定义原文 + 出处 / **结构拆解（维度由当前位类的方法论文档规定）** / 本体归属 · 假实 + 派系诤议 / 与相邻法辨异 / **世间面** / **修行接口**。

- 「所缘 / 体性 / 业用 / 障」降为心所位的一个取值，不再是模板本身。
- 「见众生普遍现行形态」抽象为**世间面**（众生如何误认 / 执取 / 忽略此法），烦恼位表现为原来的现行形态。
- 新增**修行接口**槽（所对治 / 所观 / 所证），并**允许明说「本单元无直接修行接口」**——防止为每一法硬凑修行意义，这本身是学术诚实的一环（心不相应行法阶段会大量遇到）。

### 5. A 组 ②③：密度伸缩

② 极简单元可跳过主线设计，直接由 ① 的拆解成章；③ 检验密度随单元权重伸缩，轻单元可整单元一次检验、同构组可合组检验。

### 6. B 组：归位规则（原 #2–#5）

原 #3「延伸话题」与 #4「话题聚合」合并为**延伸内容的两级归位**（单篇专题 + 专题索引登记 → 领域级聚合）。⑤ 的按号回指改为命名引用「按 B 组归位规则处理」。

### 7. C 组：项目级机制（原 #6–#9）

- C-4「位类 / 阶段方法论文档」从「按需，不强制」改为**跨位类切换时必写**（位类内部子阶段仍按需）——因为拆解维度、单元切分、旧稿处置三件事都下放到了方法论文档，未定不开工。
- 规定方法论文档**必含四项**：整组先决问题 / 本位类的结构拆解维度 / 单元切分方式 / 既有旧稿处置声明。
- 措辞去心所化：「一组心所」→「一组法」、「跨心所假说」→「跨法假说」、「单法笔记」→「单元笔记」。

### 8. 连带修订

「当前学习阶段（闻思）」节的「（见学习流程 #9）」改为「（见学习流程 C-4）」。

## 四、沉淀的元原则

1. **通用骨架与位类填充分离**：规范里留骨架（闻 → 思两拍、六槽、归位规则），把随教材 / 位类而变的填充（拆解维度、单元切分、旧稿处置）下放到阶段方法论文档。这既保住了流程的可迁移性，也延续了 [2026-06-13 文档反滚雪球治理](2026-06-13_文档反滚雪球治理与演化溯源机制.md) 的取向——规范不因新位类而逐年增厚。
2. **「按需」在下放之后必须重估**：一条规则一旦被指定为承载物（方法论文档承载拆解维度），它的可选性就自动失效。下放与必写是一对，不能只做一半。
3. **流程条目的性质要分组**：时序步骤、归位规则、项目机制混编成一串编号，会产生「步骤按号引用规则」这种结构性混乱，也让新增条目无处安放。分组后按名引用，编号不再是唯一坐标。
4. **允许「无」是学术诚实的一部分**：修行接口槽显式允许明说「无」，与讲法阶段「法体性贫瘠时不造核填补」的模型膨胀对治（见 [诳](../../03-心所法/随烦恼心所/诳.md) 元层记录）同构。
