# 学习图表

此目录用于存放学习过程中创建的各种图表和可视化内容。

## 📊 图表类型

### 1. 结构图

**五位百法结构图**
- 展示五位百法的整体分类
- 各类之间的关系
- 数量分布

**八识关系图**
- 八识的层次结构
- 八识之间的相互作用
- 八识与六根六境的关系

**心所法分类图**
- 51心所的完整分类
- 六种心所的关系
- 善恶性质的分布

### 2. 概念图

**概念关系图**
- 重要概念之间的关联
- 上下位概念关系
- 相似与对立概念

**思维导图**
- 章节内容的思维导图
- 概念的多维度展开
- 学习路径图

### 3. 时间轴

**学习时间轴**
- 学习进度的时间线
- 重要里程碑
- 阶段划分

### 4. 统计图表

**学习统计**
- 学习时长分布
- 概念掌握度统计
- 复习完成情况

## 🛠️ 制作工具

推荐使用以下工具创建图表：

### 图表工具
- **Mermaid**: Markdown中嵌入的图表（推荐）
- **Draw.io**: 在线绘图工具
- **XMind**: 思维导图工具
- **Excalidraw**: 手绘风格图表

### 在Markdown中使用Mermaid

### 1. 逻辑关系图
[查看逻辑关系图](relation_logic.md)
- 展示“一切法”如何展开为五位的逻辑推演。
- 包含：最胜故、与此相应故、二所现影故、三位差别故、四所显示故。

### 2. 全览思维导图
[查看全览图](full_map.md)
- 包含完整的五位百法分类树。
- 适合快速查找和宏观概览。

### 3. 交互式探索工具 (推荐)
[打开交互式图谱](explorer.html)
- **Web 应用**: 一个单页面的 HTML 工具。
- **功能**:
    - 周期表式布局
    - 颜色编码区分善恶/类别
    - 点击查看详细定义
- **使用方法**: 在浏览器中打开 `diagrams/explorer.html` 文件。

## 💡 创建建议

1. **简洁明了**: 避免过于复杂，突出重点
2. **统一风格**: 使用一致的配色和样式
3. **易于更新**: 优先使用代码生成的图表（如Mermaid）
4. **高清晰度**: 如果是图片，保证清晰度
5. **添加说明**: 每个图表配上简短说明

- **无为法**: 紫色系
