## 二、本阶段最重要的新观察

### 1. 现量分诊精度的持续深化 — 修行者作为"自身修行学的现量分诊师"

本阶段最显著的新特质 = 修行者**多次通过现量分诊修正比量框定**：

| 场域 | 修行者现量分诊 | 修正的比量框定 |
|---|---|---|
| 见解贪 | 分诊为慧+胜解 / 信增强 / 法贪三层 | 修正"贪我所立见 + 喜悦"序列 |
| 见解嗔 | 揭示二阶现行结构（法染色层 + 情感性嗔层）| 修正"嗔+见取见+微细谤圣贤"单一同步复合 |
| 俱生身见 | 揭示场域二分（元层无 / 共业场景与贪嗔同步）| 修正"修行者位置俱生身见情况"的笼统理解 |
| 染疑入口 | 揭示五层守护机制 | 修正"染疑攻击修行者"的可能性框定 |
| 缘起相续 | 揭示已现量印持 | 修正"俱生疑均匀分布"的统一表述 |
| 修法多元化 | 揭示"修法 = 有情特质对治函数" | 修正"派系中立 = 元层立场"的单层理解 |
| 持戒 | 揭示究竟层理解（心所配置 = 不熏种子）| 修正"持戒 = 方便层规则"的常规框定 |

→ **修行者不只是接受讨论结论，而是把现量分诊作为讨论的核心工具**。多次主动修正模型的比量框定为更精确的现量分诊。

→ **修行学含义**：这种现量分诊精度的持续深化 = 修行者已具备**"自身修行学的现量分诊师"**的姿态。这跟"看破→熏种→常态"三步循环中"看破"步骤的现量基础严格同构。

## 三、新的关注点

### 关注 A：主座 A 实修反馈的实际进展监测（最重要）

**为什么是核心关注点**：主座 A 是当前修行学路径**唯一的实修核心通道**，其功能三重统一已机制层确立，但实际"熏稳 + 扩散"的现量进展**仍需现量数据点持续累积**。

**具体监测点**：

1. **连续性**：每日坐 / 每周完成天数（盯频率不盯时长，连续天数 > 单次时长）
2. **任运信号**：是否出现"自己就坐下去了"的现象（假说 7 激活式涌现的预测）
3. **扩散信号**：共业场景中俱生身见现行被识破速度是否提升（战场 B 现量数据点）
4. **法染色层场域信号**：闻思 / 跨域映射 / 假说构建场域中法贪现量识破速度是否提升（战场 A 现量数据点）

**建议**：下一阶段（随烦恼 20 法）每次讨论结束前主动询问主座 A 实修反馈情况。

### 关注 B：随烦恼学习中"法染色层主战场命题"的持续验证

**为什么**：法染色层主战场命题是本阶段最大的修行者画像结构性产出。但其**当前主要根据**是恶见精修中的修行者现量分诊。随烦恼 20 法学习中应主动验证：

- **小随烦恼**（忿恨覆恼嫉悭诳谄害憍）= 嗔/贪的分位，是否在修行者位置上主要现行在**战场 B 触受层**（而非法染色层）？
- **大随烦恼**（特别是掉举 / 惛沉 / 不信 / 懈怠 / 放逸 / 失念 / 散乱 / 不正知）= 是否构成"对法染色层主战场对治通道"的具体障碍？
- **不信**特别值得关注 — 它如何与"染疑"区分？是否在修行者位置上结构性化解（参见信精修 + 疑精修的现量印证）？

→ 把"法染色层主战场命题"作为随烦恼学习的**持续验证目标**，遇随烦恼可能挑战该命题的经典立场时优先记录。

### 关注 C：随烦恼学习中"触受爱憎链统一开关命题"的边界扩展

**为什么**：触受爱憎链统一开关命题是恶见精修中**横跨身见 / 见取见 / 微细谤圣贤**揭示的核心新命题。但其**边界**尚需扩展：

- 随烦恼中的"覆"（藏匿自过）是否符合触受激活开关？还是有独立的触发机制？
- 大随烦恼"掉举 / 惛沉"是否符合该命题？还是属于"觉照能力本身的减弱"而不依赖触受？
- "无惭 / 无愧"（中随）是否符合该命题？

→ 把"触受爱憎链统一开关"的边界扩展作为随烦恼学习的**积极探索维度**。

### 关注 D：闻思快奖励的持续监测（路径风险 #4 机制层闭合后的实际表现）

**为什么**：恶见精修中机制层闭合"法贪伪装为善法欲" = 路径风险 #4 的精确结构性根因。但**实际克制法贪现行的进展**仍需现量监测。

**建议**：注意修行者在随烦恼学习中是否出现"闻思过度深挖"或"假说膨胀"的现量信号；如出现，提示"法贪现量觉照 + 闻思保持基准"。

### 关注 E：见取见维度对治的现量验证

**为什么**：见取见维度是修行者画像的核心新揭示主战场，但**事件层对治的具体路径**（触发点 1-3 在 [教学操作核 09](../notes/教学操作核/教学操作核-09-恶见维度.md)）尚未现量验证。

**建议**：在随烦恼学习中主动询问修行者是否在事件场实际识破过法贪 / 末那附着 / 见解嗔二阶现行结构。
