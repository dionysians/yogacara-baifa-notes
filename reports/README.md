# 进度报告

此目录用于存放定期生成的学习进度报告。

## 📊 报告类型

### 1. 周报告

每周自动生成的学习进度报告：

```
reports/
├── weekly/
│   ├── 2025-W45_report.md
│   ├── 2025-W46_report.md
│   └── ...
```

### 2. 月报告

每月生成的综合报告：

```
reports/
├── monthly/
│   ├── 2025-11_report.md
│   ├── 2025-12_report.md
│   └── ...
```

### 3. 阶段报告

每个阶段完成时的报告：

```
reports/
├── stage/
│   ├── stage_1_report.md
│   ├── stage_2_report.md
│   └── ...
```

### 4. 整体报告

项目级别的综合报告：

```
reports/
└── overall_progress_report.md
```

## 🔧 报告生成

### 自动生成

报告可以通过以下方式自动生成：

1. **手动生成**:
   ```
   /study-progress stats
   ```

2. **定期生成**:
   - 每周日自动生成周报
   - 每月最后一天生成月报

### 报告内容来源

报告数据来自：
- `.aiwork/session.yaml` - 会话统计
- `notes/logs/` - 学习日志
- `.aiwork/review_tracker.yaml` - 复习记录
- `.aiwork/STUDY_PLAN.md` - 进度数据

## 📊 报告的用途

1. **跟踪进度**: 可视化学习进展
2. **发现规律**: 识别学习模式
3. **调整计划**: 根据数据优化策略
4. **保持动力**: 看到具体成果
5. **长期记录**: 完整的学习历程

## 💡 使用建议

1. **定期查看**: 每周至少查看一次
2. **对比分析**: 与之前的报告对比
3. **找出趋势**: 识别上升或下降趋势
4. **及时调整**: 根据报告调整学习计划
5. **庆祝成就**: 认可自己的进步

## 🔗 相关命令

- `/study-progress` - 查看当前进度
- `/study-progress stats` - 生成详细统计报告
