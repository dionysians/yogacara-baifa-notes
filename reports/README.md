# 个人评估

本目录存放本项目的**个人学习评估**——在学习阶段 / 检查点对修行者学习状态所做的总结性评估。它是 [CLAUDE.md](../CLAUDE.md)「用户学习画像」的可溯源底稿：**画像是评估的浓缩活跃版（每次会话加载），评估是画像的完整存档**。CLAUDE.md 画像开头只保留指向本文档的链接，不内联清单——长期评估累积也不撑大 CLAUDE.md。

## 评估类型

- **学习阶段评估**（完整）：一个大阶段（心法 / 心所法各子阶段）结束时的完整重评——核心特质演化、质变信号、活跃议题、跨世种子证据、阶段成绩等。
- **检查点评估**（轻量）：一组心所 / 子阶段完成时的轻量检查点——只记增量与关键判断。

## 命名规范

```
yyyy-mm-dd-<范畴>-<阶段>-<类型>个人评估.md
```

- 日期为评估**完成日**，前缀便于按时间排序。
- 例：`2026-06-06-心所法-烦恼心所根本烦恼-检查点个人评估.md`

## 维护流程

每次完成新评估：

1. 文件按上述命名规范放入本目录；
2. 在上方「历次评估索引」表**顶部追加一行**；
3. 将关键内容同步进 CLAUDE.md 画像（见 CLAUDE.md 学习流程 #7：覆盖更新 评估概览 / 核心特质 / 活跃议题 / 教学通则）。
